# KP03 ARMA模型

## 1. 是什么

**定义：** ARMA(p,q)模型是AR(p)和MA(q)的有机组合——既用历史序列值回归当前值，又包含历史随机扰动的影响：

$$x_t = \phi_1 x_{t-1} + \dots + \phi_p x_{t-p} + \varepsilon_t - \theta_1 \varepsilon_{t-1} - \dots - \theta_q \varepsilon_{t-q}$$

用延迟算子表示：$\Phi(B)x_t = \Theta(B)\varepsilon_t$

**直觉类比：** 奶茶销量既有惯性（上月销量影响本月），又受近期促销冲击的余波影响——ARMA就是两种效应叠加。

**解决什么问题：** 当[[KP02_自协方差与ACF|ACF]]和[[KP04_PACF偏自相关|PACF]]都拖尾时，单纯用AR或MA都不能精确描述序列，需要两者结合。

## 2. 怎么用

### 平稳条件与可逆条件

- **平稳条件**：由AR部分决定。$\Phi(B) = 0$ 的所有根都在单位圆外（即特征根在单位圆内）
- **可逆条件**：由MA部分决定。$\Theta(B) = 0$ 的所有根都在单位圆外

当两个条件同时满足时，模型称为**平稳可逆ARMA模型**，可由[[03_自相关|自相关]]系数唯一识别。

### 均值

$$\mu = \frac{\phi_0}{1 - \phi_1 - \dots - \phi_p}$$

（非[[KP09_中心化_均值化|中心化]]模型才有 $\phi_0$；中心化模型均值为0）

### ACF与PACF：都拖尾

- **ACF**：不截尾（指数衰减），因为ARMA可写成无穷MA形式
- **PACF**：不截尾（指数衰减），因为ARMA可写成无穷AR形式

这是ARMA区别于纯AR和纯MA的关键特征。

### R代码

```r
# 目的：模拟ARMA(1,1)并观察ACF/PACF都拖尾的特征

set.seed(789)

# 模拟ARMA(1,1): x_t - 0.5*x_{t-1} = ε_t - 0.8*ε_{t-1}
# R中：ar=0.5 对应 φ_1=0.5；ma=-0.8 对应 θ_1=0.8
x <- arima.sim(n=1000, list(ar=0.5, ma=-0.8))

ts.plot(x, main="ARMA(1,1)序列")
acf(x, main="ARMA(1,1)的ACF：拖尾")
pacf(x, main="ARMA(1,1)的PACF：拖尾")
# 预期：ACF和PACF都逐渐衰减到零，没有"骤降截尾"的特征
```

### 计算演示

已知ARMA(1,1)：$x_t = 0.5 x_{t-1} + \varepsilon_t - 0.8 \varepsilon_{t-1}$，$\sigma_\varepsilon^2 = 1$

Green函数递推：
- $G_0 = 1$
- $G_1 = \phi_1 G_0 - \theta_1 = 0.5 - 0.8 = -0.3$
- $G_2 = \phi_1 G_1 = 0.5 \times (-0.3) = -0.15$
- $G_3 = \phi_1 G_2 = 0.5 \times (-0.15) = -0.075$

方差：
$$\gamma(0) = (G_0^2 + G_1^2 + G_2^2 + \dots)\sigma_\varepsilon^2 = (1 + 0.09 + 0.0225 + \dots) \approx 1.136$$

1阶ACF：
$$\rho_1 = \frac{G_0 G_1 + G_1 G_2 + \dots}{G_0^2 + G_1^2 + \dots} \approx \frac{-0.3 - 0.045 - \dots}{1.136} \approx -0.304$$

2阶ACF：$\rho_2 = \phi_1 \rho_1 = 0.5 \times (-0.304) = -0.152$

3阶ACF：$\rho_3 = \phi_1 \rho_2 = 0.5 \times (-0.152) = -0.076$

→ ACF按指数衰减，拖尾不截尾。

## 3. 什么时候用

**适用场景：**
- ACF和PACF都拖尾（都不呈现骤降截尾）
- 纯AR或纯MA拟合后残差仍非白噪声
- 样本量足够大（$n \ge 100$，因为参数更多）

**数据条件：**
- 平稳非白噪声序列
- 样本量 $n$ 远大于 $p+q$（通常 $n/(p+q) > 20$）

## 4. 什么时候不能用/易错点

**不适用场景：**
- ACF截尾的序列 → 用MA(q)即可，不需要AR部分
- PACF截尾的序列 → 用AR(p)即可，不需要MA部分
- 非平稳序列 → 先差分再考虑ARMA（即[[KP01_ARIMA模型|ARIMA]]）

**常见错误：**
- 阶数定太高：ARMA参数越多越难估计，应优先用简洁模型
- 不检验可逆性：不可逆模型虽然ACF相同，但预测不稳定
- 把ARMA当成万能模型：简单序列用AR或MA更稳妥

## 5. 与相似方法对比表

| 维度 | AR(p) | MA(q) | ARMA(p,q) |
|------|-------|-------|-----------|
| 方程 | 仅AR项 | 仅MA项 | AR+MA项 |
| ACF | 拖尾 | q阶截尾 | 拖尾 |
| PACF | p阶截尾 | 拖尾 | 拖尾 |
| 参数个数 | p | q | p+q |
| 适用场景 | PACF截尾 | ACF截尾 | 两者都拖尾 |
| 特例 | q=0时 | p=0时 | 一般形式 |

## 6. 为什么用这个不用那个

**决策逻辑：**
- 先看ACF：如果q阶后骤降为零 → MA(q)，结束
- 再看PACF：如果p阶后骤降为零 → AR(p)，结束
- 两者都拖尾 → ARMA(p,q)，然后用AIC/BIC定p和q

**被排除的方法会出什么问题：**
- 对ARMA序列硬拟合AR：MA部分的效应被AR"吸收"，需要很高的p阶，过拟合
- 对ARMA序列硬拟合MA：AR部分的效应被MA"吸收"，需要很高的q阶，估计不稳定

## 7. 完整例子

**书中原例：** 例3-8 拟合ARMA(1,1) $x_t - 0.5x_{t-1} = \varepsilon_t - 0.8\varepsilon_{t-1}$

```r
x <- arima.sim(n=1000, list(ar=0.5, ma=-0.8))
acf(x)   # 拖尾
pacf(x)  # 拖尾
```

结论：ACF和PACF都不截尾，符合ARMA(1,1)特征。

**小白生活实例：奶茶店ARMA(1,1)销量**

假设奶茶店销量模型：$x_t = 50 + 0.6 x_{t-1} + \varepsilon_t - 0.3 \varepsilon_{t-1}$

含义：
- AR部分（0.6）：上月销量对本月的惯性影响
- MA部分（-0.3）：上月随机冲击对本月的余波影响

已知 $x_{t-1} = 200$，$\varepsilon_{t-1} = 10$（上月有个意外热销）。

本月预测：
$$\hat x_t = 50 + 0.6 \times 200 - 0.3 \times 10 = 50 + 120 - 3 = 167$$

注意：上月意外多卖了10杯，这个冲击对本月有-3杯的"回吐"效应。

## 答辩常问（带标准答案）

1. **问：ARMA(p,q) 的识别标志是什么？为什么 ACF 和 PACF 都拖尾？** 答：ARMA 的标志是 ACF 和 PACF 都不截尾、都呈指数衰减（拖尾）。原因：ARMA 既可写成无穷阶 MA 形式（说明 ACF 是衰减的、不会精确截断），又可写成无穷阶 AR 形式（说明 PACF 也是衰减的）。一旦在 ACF 或 PACF 图上看到某阶之后骤降到零，就不该上 ARMA——ACF 截尾是 MA(q)，PACF 截尾是 AR(p)。两者都拖尾时才用 ARMA，并用 AIC/BIC 辅助定 p、q。
2. **问：ARMA 的平稳条件和可逆条件分别由哪一部分决定？** 答：平稳条件由 AR 部分决定——自回归多项式 $\Phi(B)=0$ 的根要在单位圆外（等价于特征根在单位圆内），否则序列发散；可逆条件由 MA 部分决定——移动平均多项式 $\Theta(B)=0$ 的根也要在单位圆外，否则同一个自相关结构对应多个 MA 参数，模型不可唯一识别。两个条件同时满足才叫"平稳可逆 ARMA"，这也是参数能被自[[01_相关系数|相关系数]]唯一识别的前提。
3. **问：样本量要求上，为什么 ARMA 比纯 AR/MA 更苛刻？** 答：ARMA(p,q) 有 $p+q$ 个自回归和移动平均参数要估，纯 AR(p) 只有 $p$ 个、纯 MA(q) 只有 $q$ 个。参数越多，需要的样本越大，经验上要求 $n/(p+q)>20$、总样本 $n\ge 100$ 才稳妥；样本不够就硬上高阶 ARMA，参数估计标准误很大、很容易过拟合，这时宁可用低阶 AR 或 MA。

## 8. 速记卡

- **ARMA = AR + MA**：既有惯性又有冲击余波
- **ACF和PACF都拖尾**：这是ARMA的标志性特征
- **平稳条件**：AR部分特征根在单位圆内
- **可逆条件**：MA部分系数多项式根在单位圆外
- **R代码**：`arima.sim(n=1000, list(ar=0.5, ma=-0.8))`
- **一句话口诀**：ACF和PACF都"滑滑梯"（拖尾）→ 上ARMA
