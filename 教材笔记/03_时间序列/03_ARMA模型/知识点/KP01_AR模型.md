# KP01 AR模型

## 1. 是什么

**定义：** $p$阶自回归模型AR(p)用序列自身的历史值来线性回归当前值：

$$x_t = \phi_0 + \phi_1 x_{t-1} + \phi_2 x_{t-2} + \dots + \phi_p x_{t-p} + \varepsilon_t$$

其中 $\varepsilon_t$ 是零均值白噪声。

**直觉类比：** 本月奶茶销量 = $\phi_1 \times$ 上月销量 + $\phi_2 \times$ 上上月销量 + 随机扰动。AR(1)就是"这个月的销量主要由上个月的销量决定"——惯性思维。

**解决什么问题：** 当序列具有"短期[[03_自相关|自相关]]性"（今天的值受昨天值影响）时，AR模型用历史值的线性组合来描述和预测当前值。

## 2. 怎么用

### 平稳条件

AR(p)平稳的充要条件：**所有特征根都在单位圆内**，即 $|\lambda_i| < 1$。

- AR(1)：特征方程 $\lambda - \phi_1 = 0$，特征根 $\lambda = \phi_1$
  - 平稳条件：$|\phi_1| < 1$
- AR(2)：特征方程 $\lambda^2 - \phi_1\lambda - \phi_2 = 0$
  - 平稳条件：$|\phi_2| < 1$ 且 $\phi_2 \pm \phi_1 < 1$

### 均值与方差

**均值：**

$$\mu = \frac{\phi_0}{1 - \phi_1 - \phi_2 - \dots - \phi_p}$$

[[KP09_中心化_均值化|中心化]]模型（$\phi_0 = 0$）的均值为零。

**AR(1)方差：**

$$\text{Var}(x_t) = \frac{\sigma_\varepsilon^2}{1 - \phi_1^2}$$

#### 【三问】AR(1) 的平稳条件 $|\phi_1|<1$ 是怎么想出来的？为什么方差会是 $\sigma_\varepsilon^2/(1-\phi_1^2)$？

- **怎么来的（直觉推导）**：把 AR(1) $x_t = \phi_1 x_{t-1} + \varepsilon_t$ 不断往回代：$x_t = \varepsilon_t + \phi_1 \varepsilon_{t-1} + \phi_1^2 \varepsilon_{t-2} + \phi_1^3 \varepsilon_{t-3} + \cdots$。也就是说，当前值是**无穷多历史扰动的加权和**，权重是 $\phi_1^k$。要让这个无穷和不发散（即方差有限），必须让 $|\phi_1| < 1$——否则 $\phi_1^k$ 会指数爆炸，序列越跑越偏。对两边取方差（$\varepsilon_t$ 之间不相关）：$\text{Var}(x_t) = \sigma_\varepsilon^2(1 + \phi_1^2 + \phi_1^4 + \cdots) = \sigma_\varepsilon^2 / (1 - \phi_1^2)$（无穷等比数列求和）。
- **为什么用它**：解决"什么时候 AR 模型能用来预测"的问题。如果 $|\phi_1| \ge 1$，序列会沿着某个方向越跑越远（趋势或爆炸），不存在稳定的均值和方差，预测毫无意义。只有平稳的 AR，才能说"未来 x_t 围绕均值 $\mu$ 波动，波动幅度是 $\sqrt{\sigma_\varepsilon^2/(1-\phi_1^2)}$"。
- **知识为什么存在**：早期时间序列研究（1920-30 年代）发现经济数据（股价、销量、气温）不是随机游走，而是"有惯性但会回归"。AR 模型（Yule 1927 年首创）把这种"惯性"用一个系数 $\phi_1$ 量化：$\phi_1$ 越接近1，惯性越强、回归越慢；$\phi_1=0$，序列就是白噪声（无记忆）。平稳条件的提出，让时间序列建模从"随便拟合"变成"先判平稳、再定模型"的规范流程。

### 自[[01_相关系数|相关系数]]

**AR(1)的[[KP02_自协方差与ACF|ACF]]：**

$$\rho_k = \phi_1^k \quad (k \ge 0)$$

- 若 $\phi_1 > 0$：正指数衰减（单调收敛到零）
- 若 $\phi_1 < 0$：正负交替衰减（振荡收敛）

**AR(p)的ACF通解：**

$$\rho_k = \sum_{i=1}^{p} c_i \lambda_i^k$$

因为 $|\lambda_i| < 1$，所以 $\rho_k$ 随 $k$ 增大指数衰减到零——**拖尾性**。

**AR(p)的[[KP04_PACF偏自相关|PACF]]：p阶截尾**

$$\phi_{kk} = 0, \quad \forall k > p$$

### R代码

```r
# 目的：模拟AR(1)序列并观察其ACF/PACF特征

set.seed(123)  # 固定随机种子，保证结果可复现

# 模拟平稳AR(1): x_t = 0.8 * x_{t-1} + ε_t
x1 <- arima.sim(n=100, list(ar=0.8))
# n=100：生成长度100的序列
# list(ar=0.8)：AR系数为0.8
# 若指定非平稳模型（如ar=1.1），系统会报错

# 查看序列时序图
ts.plot(x1, main="AR(1): x_t = 0.8*x_{t-1} + ε_t")

# 查看ACF：预期拖尾（指数衰减到零）
acf(x1, main="AR(1)的ACF：拖尾")

# 查看PACF：预期1阶截尾（1阶后落入虚线内）
pacf(x1, main="AR(1)的PACF：1阶截尾")

# 模拟非平稳AR(1): x_t = -1.1 * x_{t-1} + ε_t
# arima.sim会报错，因为模型不平稳
# 改用filter函数可以模拟任意AR序列
e <- rnorm(100)
x2 <- filter(e, filter=-1.1, method="recursive")
# method="recursive"表示AR模型
# 该序列时序图会显示发散振荡——非平稳特征
```

### 计算演示

已知AR(1)模型：$x_t = 0.6 x_{t-1} + \varepsilon_t$，$\sigma_\varepsilon^2 = 1$

1. **[[02_平稳性|平稳性]]判断**：$|\phi_1| = 0.6 < 1$ → 平稳
2. **方差**：$\gamma(0) = \sigma_\varepsilon^2 / (1 - 0.6^2) = 1 / 0.64 = 1.5625$
3. **1阶自相关**：$\rho_1 = 0.6$
4. **2阶自相关**：$\rho_2 = 0.6^2 = 0.36$
5. **3阶自相关**：$\rho_3 = 0.6^3 = 0.216$
6. **PACF**：$\phi_{11} = 0.6$，$\phi_{22} = 0$，$\phi_{33} = 0$（1阶截尾）

## 3. 什么时候用

**适用场景：**
- 序列具有明显的"惯性"（近期值影响远期值）
- ACF拖尾且PACF在p阶截尾
- 平稳非白噪声序列

**数据条件：**
- 样本量 $n \ge 50$
- 序列已通过平稳性[[08_t检验和F检验|检验和]]白噪声检验

**前提假设：**
- $\varepsilon_t$ 是零均值白噪声（$E(\varepsilon_t)=0$，同方差，无自相关）
- $E(x_s \varepsilon_t) = 0, \forall s < t$（当期扰动与过去序列值无关）
- 平稳条件：特征根全在单位圆内

## 4. 什么时候不能用/易错点

**不适用场景：**
- 非平稳序列（有趋势）：直接拟合AR模型会产生伪回归
- ACF截尾的序列：应选MA模型而非AR模型
- [[02_异方差|异方差]]序列：AR模型假设同方差，否则参数估计不可靠

**常见错误：**
- 不检验平稳性就拟合AR模型：$|\phi_1| \ge 1$时序列发散，模型无意义
- 定阶时把ACF拖尾当成PACF截尾：必须区分ACF和PACF
- 阶数定太高：参数越多过拟合越严重，应用AIC/BIC辅助定阶

## 5. 与相似方法对比表

| 维度 | AR(p) | MA(q) | ARMA(p,q) |
|------|-------|-------|-----------|
| 核心思想 | 用历史值回归当前值 | 用历史扰动的线性组合 | 两者结合 |
| 方程 | $x_t = \sum \phi_i x_{t-i} + \varepsilon_t$ | $x_t = \varepsilon_t - \sum \theta_i \varepsilon_{t-i}$ | 两者相加 |
| 平稳条件 | 特征根在单位圆内 | 永远平稳 | 由AR部分决定 |
| ACF模式 | 拖尾（指数衰减） | q阶截尾 | 拖尾 |
| PACF模式 | p阶截尾 | 拖尾 | 拖尾 |
| 直觉 | "销量有惯性" | "销量受近期冲击影响" | "既有惯性又有冲击" |

## 6. 为什么用这个不用那个

**决策逻辑：**
- PACF在p阶截尾 → 选AR(p)
- ACF在q阶截尾 → 选MA(q)
- 两者都拖尾 → 选ARMA(p,q)

**被排除的方法会出什么问题：**
- 对MA(q)序列硬拟合AR模型：ACF虽然拖尾但PACF不截尾，会被迫选很高的p阶，参数多且过拟合
- 对AR(p)序列硬拟合MA模型：同样需要很高的q阶，不经济

## 7. 完整例子

**书中原例：** 例3-1 四个AR模型平稳性判别

| 模型 | 特征根 | 平稳域判别 | 结论 |
|------|--------|-----------|------|
| $x_t = 0.8x_{t-1} + \varepsilon_t$ | $\lambda = 0.8$ | $\|\phi_1\| = 0.8 < 1$ | 平稳 |
| $x_t = -1.1x_{t-1} + \varepsilon_t$ | $\lambda = -1.1$ | $\|\phi_1\| = 1.1 > 1$ | 非平稳 |
| $x_t = x_{t-1} - 0.5x_{t-2} + \varepsilon_t$ | 复根模=0.707 | $\|\phi_2\|=0.5, \phi_2+\phi_1=0.5<1, \phi_2-\phi_1=-1.5<1$ | 平稳 |
| $x_t = x_{t-1} + 0.5x_{t-2} + \varepsilon_t$ | 实根模=1.366 | $\phi_2+\phi_1=1.5>1$ | 非平稳 |

**小白生活实例：奶茶店月销量AR(1)预测**

假设某奶茶店月销量服从AR(1)：$x_t = 50 + 0.7 x_{t-1} + \varepsilon_t$，$\sigma_\varepsilon^2 = 100$

已知上月销量 $x_{t-1} = 200$ 杯。

1. **均值**：$\mu = 50 / (1 - 0.7) = 50 / 0.3 = 166.67$ 杯
2. **本月预测**：$\hat x_t = 50 + 0.7 \times 200 = 190$ 杯
3. **方差**：$\gamma(0) = 100 / (1 - 0.49) = 196.08$
4. **预测标准差**：$\sqrt{100} = 10$（一步预测的方差就是 $\sigma_\varepsilon^2$）
5. **95%预测区间**：$190 \pm 1.96 \times 10 = (170.4, 209.6)$ 杯

直觉解释：上月卖了200杯，惯性让本月预期卖190杯（向均值166.67回归），随机误差可能让实际值在170-210之间。

## 答辩常问（带标准答案）

1. **问：AR(1) 模型的平稳条件是什么？$|\phi_1|<1$ 背后的直觉是什么？** 答：AR(p) 平稳的充要条件是特征方程的所有根都在单位圆内，即 $|\lambda_i|<1$；对 AR(1) 就是 $|\phi_1|<1$。直觉：把 $x_t=\phi_1 x_{t-1}+\varepsilon_t$ 不断往回代，得到 $x_t=\varepsilon_t+\phi_1\varepsilon_{t-1}+\phi_1^2\varepsilon_{t-2}+\cdots$，当前值是历史扰动的加权和，权重为 $\phi_1^k$。若 $|\phi_1|<1$，权重指数衰减、方差收敛为 $\sigma_\varepsilon^2/(1-\phi_1^2)$；若 $|\phi_1|\ge 1$，权重爆炸、序列发散，均值方差都不存在，预测毫无意义。
2. **问：怎么从 ACF 和 PACF 上识别 AR(p)？** 答：AR(p) 的识别口诀是"ACF 拖尾、PACF p 阶截尾"。ACF 按 $\rho_k=\phi_1^k$（AR(1) 情形）指数衰减，$\phi_1>0$ 单调衰减、$\phi_1<0$ 正负振荡衰减，永远不会精确为零；PACF 则在第 $p$ 阶之后严格为零（$p$ 阶截尾）。所以看到 PACF 某个阶数之后的点全部落入 2 倍标准差虚线内，那个阶数就是 $p$。
3. **问：AR(1) 的方差为什么是 $\sigma_\varepsilon^2/(1-\phi_1^2)$？** 答：平稳 AR(1) 可以展开成 $x_t=\sum_{k=0}^{\infty}\phi_1^k\varepsilon_{t-k}$，而各期扰动 $\varepsilon$ 互不相关，方差可直接相加：$\mathrm{Var}(x_t)=\sigma_\varepsilon^2\sum_{k=0}^{\infty}\phi_1^{2k}=\sigma_\varepsilon^2\cdot\frac{1}{1-\phi_1^2}$（无穷等比级数求和，公比 $\phi_1^2$）。这个公式说明：$\phi_1$ 越接近 1，序列方差被"惯性"放得越大；$\phi_1=0$ 时退化为白噪声方差 $\sigma_\varepsilon^2$。

## 8. 速记卡

- **AR(1)平稳条件**：$|\phi_1| < 1$
- **AR(1) ACF**：$\rho_k = \phi_1^k$（指数衰减，拖尾）
- **AR(p) PACF**：p阶截尾
- **AR(p)均值**：$\mu = \phi_0 / (1 - \phi_1 - \dots - \phi_p)$
- **R代码**：`arima.sim(n=100, list(ar=0.8))`
- **一句话口诀**：AR模型=销量有惯性，PACF在p阶后"断片"（截尾）
