## 1. 是什么

**定义：** 对平稳非白噪声序列进行[[KP03_ARMA模型|ARMA]]建模的完整六步流程：①[[02_平稳性|平稳性]]检验 → ②模型识别（定阶）→ ③参数估计 → ④模型检验 → ⑤模型优化 → ⑥预测。这是Box-Jenkins方法的核心。

**直觉类比：** 像医生看病——先体检（检验），再诊断（定阶），开药（估计参数），复诊（检验），调药（优化），最后跟踪疗效（预测）。

**解决什么问题：** 提供一套[[KP11_标准化_ZScore|标准化]]的、可重复的时序[[05_ARIMA建模流程|建模流程]]，避免"拍脑袋"选模型。

## 2. 怎么用

### 完整六步流程

**第一步：平稳性检验**
- 画时序图：是否在常数附近有界波动？
- 画[[KP02_自协方差与ACF|ACF]]图：是否快速衰减到零？
- 白噪声检验：p值 < 0.05？

**第二步：模型识别（定阶）**
- 看ACF：是否在q阶骤降截尾？
- 看[[KP04_PACF偏自相关|PACF]]：是否在p阶骤降截尾？
- 查表定阶：

| ACF模式 | PACF模式 | 选定模型 |
|---------|---------|---------|
| 拖尾 | p阶截尾 | AR(p) |
| q阶截尾 | 拖尾 | MA(q) |
| 拖尾 | 拖尾 | ARMA(p,q) |

**第三步：参数估计**
- 三种方法：矩估计（简单但粗糙）、极大似然估计（精度高）、条件最小二乘（常用）
- R函数：`arima(x, order=c(p,0,q), method="ML")`

**第四步：模型检验**
- 模型显著性检验：残差白噪声检验（`Box.test(fit$residual, type="Ljung-Box")`）
  - 残差p值 > 0.05 → 残差是白噪声 → 模型有效
  - 残差p值 < 0.05 → 模型不充分，回到第二步重新定阶
- 参数显著性检验：每个参数的t检验
  - |t| > 2 或 p < 0.05 → 参数显著非零

**第五步：模型优化**
- 建立多个候选模型
- 比较AIC和BIC：AIC/BIC最小的模型最优
- AIC $= n\ln(\hat\sigma_\varepsilon^2) + 2(p+q+1)$
- BIC $= n\ln(\hat\sigma_\varepsilon^2) + \ln(n)(p+q+1)$

**第六步：预测**
- R函数：`forecast(fit, h=10)` 预测未来10期
- 输出点预测值和80%/95%置信区间

### R代码（完整流程）

```r
# ============================================
# 完整ARMA建模六步法示例
# 数据：某奶茶店100天日销量
# ============================================

# 【第0步】准备数据
set.seed(2024)
milk_tea <- arima.sim(n=100, list(ar=0.7))  # 模拟一个AR(1)序列
milk_tea <- ts(milk_tea, start=c(2024,1), frequency=365)

# ---------- 第一步：平稳性检验 ----------
plot(milk_tea, main="第1步：时序图")
# 观察：是否在常数附近波动，无趋势无周期？

acf(milk_tea, main="第1步：自相关图")
# 观察：是否快速衰减到零？

for(i in 1:2) print(Box.test(milk_tea, lag=6*i, type="Ljung-Box"))
# 观察：p值是否 < 0.05？（是→非白噪声→值得建模）

# ---------- 第二步：模型识别（定阶） ----------
pacf(milk_tea, main="第2步：偏自相关图")
# 观察：PACF是否在1阶后截尾？
# 假设PACF在1阶截尾 → 候选模型AR(1)

# ---------- 第三步：参数估计 ----------
fit <- arima(milk_tea, order=c(1,0,0), method="ML")
# order=c(p, d, q): p=1, d=0（不差分）, q=0（无MA项）
# method="ML": 极大似然估计
fit  # 查看估计结果：ar1系数、s.e.、sigma^2、AIC

# ---------- 第四步：模型检验 ----------
# 4a. 残差白噪声检验
for(i in 1:2) print(Box.test(fit$residual, lag=6*i, type="Ljung-Box"))
# 残差p值 > 0.05 → 残差白噪声 → 模型有效

# 4b. 参数显著性检验（手工计算t值）
# ar1系数 / 标准误
t_val <- fit$coef[1] / fit$se[1]
pt(t_val, df=97, lower.tail=FALSE)  # p值 < 0.05 → 参数显著

# ---------- 第五步：模型优化 ----------
# 尝试多个候选模型比较AIC
fit0 <- arima(milk_tea, order=c(0,0,1))   # MA(1)
fit1 <- arima(milk_tea, order=c(1,0,0))   # AR(1)
fit2 <- arima(milk_tea, order=c(1,0,1))   # ARMA(1,1)
# 比较AIC：AIC最小的最优

# 自动定阶（推荐）
library(forecast)
auto.arima(milk_tea, max.p=5, max.q=5, ic="aic")
# 基于AIC最小自动搜索最优p和q

# ---------- 第六步：预测 ----------
forecast_result <- forecast(fit, h=14)  # 预测未来14天
forecast_result  # 输出点预测和置信区间
plot(forecast_result, main="第6步：销量预测图")
```

### 计算演示

某序列定阶过程：
1. 时序图：在常数附近波动 → 初步平稳
2. ACF：拖尾（指数衰减）
3. PACF：1阶显著，2阶起落入虚线 → 1阶截尾
4. 定阶：AR(1)
5. 估计：$\hat\phi_1 = 0.72$，s.e. $= 0.08$
6. t值 $= 0.72/0.08 = 9.0$ → 高度显著
7. 残差LB检验：p值 = 0.65 > 0.05 → 残差白噪声
8. AIC = 200.5；对比MA(1)的AIC = 205.3 → AR(1)更优

## 3. 什么时候用

**适用场景：**
- 所有平稳非白噪声序列的建模
- 需要用历史数据预测未来走势
- 量化研究、经济预测、销量预测等

**数据条件：**
- 样本量 $n \ge 50$（理想 $n \ge 100$）
- 序列已通过预处理（平稳+非白噪声）

## 4. 什么时候不能用/易错点

**不适用场景：**
- 非平稳序列：需先差分（[[KP01_ARIMA模型|ARIMA]]）或分解趋势周期
- 白噪声序列：无信息可提取，建模无意义
- [[02_异方差|异方差]]序列：需GARCH类模型

**常见错误：**
- 跳过第一步直接定阶：非平稳序列上做ARMA = 伪回归
- 定阶只看ACF/PACF不做AIC/BIC比较：主观经验容易出错
- 残差不通过检验还硬用：模型没提完信息，预测不可靠
- 参数不显著还保留：增加过拟合风险

## 5. 与相似方法对比表

| 方法 | 原理 | 优点 | 缺点 | 适用场景 |
|------|------|------|------|---------|
| 矩估计 | 用样本ACF解Yule-Walker方程 | 计算简单、无需分布假设 | 精度低 | 初始值、低阶模型 |
| 极大似然估计 | 最大化联合密度函数 | 精度高、渐近有效 | 需假设正态、计算复杂 | 正式建模首选 |
| 条件最小二乘 | 最小化残差平方和 | 计算较快 | 忽略了初始条件 | R默认方法 |
| auto.arima | 自动搜索AIC/BIC最小模型 | 客观、省人力 | 可能过指定高阶 | 快速探索 |

## 6. 为什么用这个不用那个

**决策逻辑：**
- 先确认平稳非白噪声 → 再谈建模
- 定阶优先看ACF/PACF模式，但用AIC/BIC辅助验证
- 残差必须白噪声 → 否则回到定阶步重来
- 多个模型都通过检验 → 选AIC/BIC最小的

## 7. 完整例子

**书中原例：** 例3-9 邮路新增里程数序列（1950-2008）

1. 时序图：无明显趋势 → 初步平稳
2. 白噪声检验：p值 = 1.255e-06 < 0.05 → 非白噪声
3. ACF：拖尾（正弦衰减）
4. PACF：2阶截尾 → AR(2)
5. 估计：$\phi_1 = 0.7185$，$\phi_2 = -0.5294$
6. 残差检验：p值 = 0.9108 > 0.05 → 白噪声 → 模型有效
7. auto.arima自动定阶结果：ARIMA(2,0,0) → 与人工判断一致

**小白生活实例：预测下月奶茶销量**

假设你有100天奶茶店日销量，执行六步法：

1. **检验**：时序图在80杯附近波动；LB检验p=0.003 → 平稳非白噪声 ✓
2. **定阶**：ACF拖尾，PACF 1阶截尾 → AR(1)
3. **估计**：$\hat\phi_1 = 0.65$，截距 $\hat\mu = 80$
4. **检验**：残差LB p=0.45 > 0.05 → 白噪声 ✓
5. **优化**：对比MA(1) AIC=320，AR(1) AIC=310 → AR(1)更优
6. **预测**：今天卖了90杯 → 明天预测 $\hat x = 80 + 0.65 \times (90-80) = 86.5$ 杯，95%区间约 (75, 98)

## 答辩常问（带标准答案）

1. **问：把 ARMA 建模的完整六步流程说一遍。** 答：①平稳性检验——时序图看是否在常数附近波动、ACF 是否快速衰减、白噪声检验 p 值是否小于 0.05；②模型识别——ACF q 阶截尾选 MA(q)、PACF p 阶截尾选 AR(p)、两者都拖尾选 ARMA(p,q)；③参数估计——矩估计初值、极大似然或条件最小二乘正式估计；④模型检验——残差做 LB 白噪声检验（p>0.05 才算提完信息）且每个参数 t 检验显著（|t|>2）；⑤模型优化——多个候选模型比 AIC/BIC，取最小者；⑥预测——`forecast(fit, h=)` 给出点预测和 95% 区间。任何一步不通过都要退回第二步重新定阶。
2. **问：AIC 和 BIC 怎么用来定阶？两者有什么区别？** 答：两个指标都在"拟合优度"和"参数个数"之间做权衡，公式为 AIC $=n\ln(\hat\sigma^2)+2(p+q+1)$，BIC $=n\ln(\hat\sigma^2)+\ln(n)(p+q+1)$。它们都等于"残差方差惩罚项+参数个数惩罚项"，数值越小越好。区别在惩罚系数：AIC 用常数 2，BIC 用 $\ln n$，样本量大时 $\ln n>2$，BIC 对复杂模型惩罚更重、倾向选更简洁的模型，渐近性质上 BIC 能一致地选出真实阶数。实际做法是同时算几个候选模型的 AIC/BIC，优先选两者都小、且残差白噪声、参数都显著的那个。
3. **问：模型检验要过哪两关？残差不通过怎么办？** 答：第一关是模型显著性（整体充分性）：对拟合残差做 Ljung-Box 检验，p 值 >0.05 说明残差是白噪声、序列里的自相关信息已被模型提取干净；第二关是参数显著性：每个系数除以标准误得 t 值，|t|>2 或 p<0.05 才保留。如果残差检验 p<0.05，说明还有自相关没被抓住，要回到第二步重新定阶（通常加大 p 或 q）；如果某个参数不显著，应删掉该项重新拟合，避免过拟合。

## 8. 速记卡

- **六步法**：检验→定阶→估计→检验→优化→预测
- **定阶口诀**：ACF拖尾+PACF截尾=AR；ACF截尾+PACF拖尾=MA；都拖尾=ARMA
- **残差白噪声 = 模型有效**
- **AIC/BIC最小 = 最优模型**
- **R核心函数**：`arima()`, `Box.test()`, `auto.arima()`, `forecast()`
- **一句话口诀**：先看病再开药，药不对就换药，最后跟踪疗效
