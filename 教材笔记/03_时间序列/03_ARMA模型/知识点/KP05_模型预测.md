# KP05 模型预测

## 1. 是什么

**定义：** 利用已拟合的[[KP03_ARMA模型|ARMA]]模型，在已知历史数据的条件下，对未来时刻的序列值进行线性最小方差预测。核心思想：预测值是已知历史数据的线性函数，且预测误差的方差达到最小。

**直觉类比：** 像根据奶茶店最近几天的销量来预估明天卖多少。AR模型说"明天≈上月销量的惯性外推"，MA模型说"明天≈基准均值加最近冲击的余波"，预测区间则告诉我们"大概在这个范围内"。

**解决什么问题：** 建模的最终目的是预测。本节解决"怎么用模型算预测值、预测方差和预测区间"的问题。

## 2. 怎么用

### 线性最小方差预测原则

预测值 $\hat x_t(l)$ 是已知历史 $x_t, x_{t-1}, \dots$ 的线性函数，且满足预测方差最小：

$$\text{Var}[e_t(l)] = \text{Var}[x_{t+l} - \hat x_t(l)] = \min$$

### AR(p)预测公式

$$\hat x_t(l) = \phi_1 \hat x_t(l-1) + \phi_2 \hat x_t(l-2) + \dots + \phi_p \hat x_t(l-p)$$

其中 $\hat x_t(k) = x_{t+k}$（当 $k \le 0$ 时，即用已知值）。

**AR(1)预测特例：** $\hat x_t(l) = \phi_1 \hat x_t(l-1)$，随 $l$ 增大指数收敛到均值。

**预测方差：**

$$\text{Var}[e_t(l)] = (G_0^2 + G_1^2 + \dots + G_{l-1}^2)\sigma_\varepsilon^2$$

其中 $G_j$ 为Green函数。

### MA(q)预测公式

$$\hat x_t(l) = \begin{cases} \mu - \sum_{i=l}^{q}\theta_i \varepsilon_{t+l-i}, & l \le q \\ \mu, & l > q \end{cases}$$

**关键性质：MA(q)只能有效预测q步，超过q步预测值恒等于均值。**

### ARMA(p,q)预测公式

$$\hat x_t(l) = \phi_1 \hat x_t(l-1) + \dots + \phi_p \hat x_t(l-p) - \sum_{i=l}^{q}\theta_i \varepsilon_{t+l-i}, \quad l \le q$$

当 $l > q$ 时，MA项消失，退化为纯AR预测递推。

### 预测区间（正态假设下）

$$\left(\hat x_t(l) - z_{1-\alpha/2}\sqrt{\text{Var}[e_t(l)]},\quad \hat x_t(l) + z_{1-\alpha/2}\sqrt{\text{Var}[e_t(l)]}\right)$$

95%置信区间：$z_{0.975} = 1.96$。

### R代码

```r
# 目的：用拟合好的ARIMA模型做预测

# 先拟合模型
fit <- arima(ts_object, order=c(2,0,0))

# 预测未来10期
library(forecast)
pred <- forecast(fit, h=10)
# h=10：预测未来10步
# 自动输出80%和95%双层置信区间

# 查看预测结果
pred
# 输出列：Point Forecast（点预测）、Lo 80、Hi 80、Lo 95、Hi 95

# 绘制预测图
plot(pred, main="销量预测图")

# 自定义置信水平
pred_95 <- forecast(fit, h=10, level=95)
```

### 计算演示（AR(2)预测）

已知AR(2)模型：$x_t = 10 + 0.6 x_{t-1} + 0.3 x_{t-2} + \varepsilon_t$，$\sigma_\varepsilon^2 = 36$

已知：$x_1 = 101$，$x_2 = 96$，$x_3 = 97.2$（第1-3月销量）

**预测第4月（1步预测，l=1）：**

$$\hat x_3(1) = 10 + 0.6 \times 97.2 + 0.3 \times 96 = 10 + 58.32 + 28.8 = 97.12$$

**预测第5月（2步预测，l=2）：**

$$\hat x_3(2) = 10 + 0.6 \times 97.12 + 0.3 \times 97.2 = 10 + 58.272 + 29.16 = 97.432$$

**预测第6月（3步预测，l=3）：**

$$\hat x_3(3) = 10 + 0.6 \times 97.432 + 0.3 \times 97.12 = 10 + 58.459 + 29.136 = 97.595$$

**预测方差（Green函数）：**
- $G_0 = 1$
- $G_1 = 0.6$
- $G_2 = 0.6 \times 0.6 + 0.3 \times 1 = 0.66$

- 1步方差：$G_0^2 \times 36 = 36$，标准差 $= 6$
- 2步方差：$(1 + 0.36) \times 36 = 48.96$，标准差 $= 6.997$
- 3步方差：$(1 + 0.36 + 0.4356) \times 36 = 64.64$，标准差 $= 8.04$

**95%预测区间：**
- 4月：$97.12 \pm 1.96 \times 6 = (85.36, 108.88)$
- 5月：$97.43 \pm 1.96 \times 6.997 = (83.72, 111.15)$
- 6月：$97.60 \pm 1.96 \times 8.04 = (81.84, 113.35)$

注意：预测步数越多，置信区间越宽——不确定性随预测步长增大。

## 3. 什么时候用

**适用场景：**
- 模型已通过全部检验（残差白噪声、参数显著）
- 需要短期预测（通常1-10步）
- 假设残差近似[[07_正态分布|正态分布]]

**数据条件：**
- 模型已正确识别阶数并估计参数
- 历史数据完整无缺失

## 4. 什么时候不能用/易错点

**不适用场景：**
- 长期预测（步数>10）：方差迅速增大，区间宽到无实际意义
- 非平稳序列：ARMA预测假设平稳，趋势项会导致预测偏误
- 模型未通过检验：残差非白噪声意味着信息未提完，预测不可靠

**常见错误：**
- 只看点预测不给区间：点预测单独使用容易误导，必须配合区间
- MA(q)模型超q步还在用非均值预测：MA(q)超过q步后预测值就是均值
- 预测区间越用越窄：实际上步数越多区间越宽，这是正常的
- 把预测值当确定值：预测是随机变量，有不确定性

## 5. 与相似方法对比表

| 维度 | AR(p)预测 | MA(q)预测 | ARMA(p,q)预测 |
|------|----------|----------|-------------|
| 预测公式 | 递推外推 | 短期冲击余波 | 递推+冲击余波 |
| 长期预测 | 收敛到均值 | q步后等于均值 | 收敛到均值 |
| 预测方差 | 随l增大 | q步后恒定 | 随l增大 |
| 适用步数 | 短期（1-10步） | 仅q步内有效 | 短期（1-10步） |
| R实现 | `forecast(arima())` | 同左 | 同左 |

## 6. 为什么用这个不用那个

**决策逻辑：**
- 先用六步法确定模型 → 再用forecast()预测
- 预测步数根据实际需求：通常只预测1-3步最可靠
- 必须报告预测区间，不能只给点预测

**被排除的方法会出什么问题：**
- 用均值直接预测（不建模型）：浪费了历史数据中的相关信息
- 过度长期预测：方差爆炸，预测区间宽到没用

## 7. 完整例子

**书中原例：** 例3-16 超市月销售额AR(2)预测

已知：$x_t = 10 + 0.6x_{t-1} + 0.3x_{t-2} + \varepsilon_t$，$\sigma_\varepsilon^2 = 36$

已知Q1销量：101, 96, 97.2万元。

| 预测月 | 点预测 | 95%置信区间 |
|--------|--------|------------|
| 4月 | 97.12 | (85.36, 108.88) |
| 5月 | 97.43 | (83.72, 111.15) |
| 6月 | 97.60 | (81.84, 113.35) |

注意预测值向均值 $10/(1-0.6-0.3)=100$ 缓慢回归，区间逐渐变宽。

**小白生活实例：奶茶店下周销量预测**

假设AR(1)模型：$x_t = 80 + 0.7(x_{t-1} - 80) + \varepsilon_t$，$\sigma_\varepsilon^2 = 25$

今天卖了90杯。

- 明天预测：$80 + 0.7 \times (90-80) = 87$ 杯
- 后天预测：$80 + 0.7 \times (87-80) = 84.9$ 杯
- 大后天预测：$80 + 0.7 \times (84.9-80) = 83.43$ 杯

预测逐渐向均值80杯回归（因为 $\phi_1 = 0.7 < 1$，惯性逐渐衰减）。

95%区间（明天）：$87 \pm 1.96 \times 5 = (77.2, 96.8)$ 杯。

## 答辩常问（带标准答案）

1. **问：为什么预测步数越多，预测区间越宽？** 答：$l$ 步预测的误差方差是 $\mathrm{Var}[e_t(l)]=(G_0^2+G_1^2+\cdots+G_{l-1}^2)\sigma_\varepsilon^2$，其中 $G_j$ 是 Green 函数。每多预测一步，就多叠加一个未来新扰动的不确定性，方差随 $l$ 单调不减；95% 区间是 $\hat x_t(l)\pm 1.96\sqrt{\mathrm{Var}[e_t(l)]}$，自然越拉越宽。这不是模型出错，而是"看得越远越没把握"的数学表达，所以 ARMA 只适合做短期预测（一般 1–10 步），长期预测会宽到没有实际意义。
2. **问：MA(q) 模型为什么超过 q 步就只能预测均值？** 答：MA(q) 中 $x_t=\varepsilon_t-\theta_1\varepsilon_{t-1}-\cdots-\theta_q\varepsilon_{t-q}$，当预测步数 $l>q$ 时，预测式里所有 $\varepsilon$ 项的下标都已落在已知历史范围内、期望值为零，剩下的就是常数均值 $\mu$。物理含义是：MA(q) 描述的冲击只影响未来 q 期，q 期之后新冲击还没发生，模型对更远的未来没有任何信息，最优预测就是均值。
3. **问：AR(1) 的多步预测为什么会逐渐收敛到均值？** 答：AR(1) 的 $l$ 步预测满足 $\hat x_t(l)=\phi_1\hat x_t(l-1)$，递推得 $\hat x_t(l)=\mu+\phi_1^l(x_t-\mu)$。因为平稳条件要求 $|\phi_1|<1$，$\phi_1^l$ 随 $l$ 指数衰减到零，预测值就按几何速度向均值 $\mu$ 靠拢。$\phi_1$ 越接近 1 收敛越慢（惯性强），越接近 0 收敛越快。

## 8. 速记卡

- **线性最小方差预测**：预测值是历史数据的线性函数，且误差方差最小
- **AR预测**：递推外推，向均值收敛
- **MA预测**：q步后等于均值
- **预测区间**：$\hat x \pm 1.96 \times \sqrt{\text{Var}(e)}$
- **步数越多区间越宽**：这是正常的不确定性增长
- **R代码**：`forecast(fit, h=10)`
- **一句话口诀**：预测=惯性外推+冲击余波，步数越多越不靠谱
