## 1. 是什么

**定义：** $q$阶移动平均模型MA(q)用当前和过去的随机扰动的线性组合来表示当前序列值：

$$x_t = \mu + \varepsilon_t - \theta_1 \varepsilon_{t-1} - \theta_2 \varepsilon_{t-2} - \dots - \theta_q \varepsilon_{t-q}$$

其中 $\varepsilon_t$ 是零均值白噪声。

**直觉类比：** 本月奶茶销量 = 基准均值 + 本月促销冲击的影响 + 上月促销冲击的余波。MA(1)就是"本月销量受本月和上月两次促销活动的叠加影响"。

**解决什么问题：** 当序列的[[03_自相关|自相关]]关系只持续有限期（[[KP02_自协方差与ACF|ACF]]在q阶后截尾）时，MA模型用有限个扰动的加权组合来描述序列。

## 2. 怎么用

### 永远平稳

MA(q)是白噪声 $\varepsilon_t$ 及其滞后值 $\varepsilon_{t-1}, \dots, \varepsilon_{t-q}$ 的有限线性组合。白噪声本身平稳，有限个平稳变量的线性组合仍平稳。**MA模型永远平稳，无需额外条件。**

### 均值与方差

**均值：**

$$E(x_t) = \mu$$

**方差：**

$$\text{Var}(x_t) = (1 + \theta_1^2 + \theta_2^2 + \dots + \theta_q^2) \sigma_\varepsilon^2$$

### ACF：q阶截尾

**MA(1)的ACF：**

$$\rho_k = \begin{cases} 1, & k = 0 \\ -\theta_1 / (1 + \theta_1^2), & k = 1 \\ 0, & k \ge 2 \end{cases}$$

**MA(2)的ACF：**

$$\rho_k = \begin{cases} 1, & k = 0 \\ (-\theta_1 + \theta_1\theta_2)/(1+\theta_1^2+\theta_2^2), & k = 1 \\ -\theta_2/(1+\theta_1^2+\theta_2^2), & k = 2 \\ 0, & k \ge 3 \end{cases}$$

**核心特征：ACF在q阶后恒为零——q阶截尾。**

### 可逆性条件

为了保证一个ACF对应唯一的MA模型，需要可逆性条件：

- MA(1)可逆：$|\theta_1| < 1$
- MA(2)可逆：$|\theta_2| < 1$ 且 $\theta_2 \pm \theta_1 < 1$

可逆性本质上是MA模型可以表示为收敛的AR(∞)形式。

### [[KP04_PACF偏自相关|PACF]]：拖尾

可逆MA(q)的PACF不截尾，呈拖尾状态（指数衰减到零）。

### R代码

```r
# 目的：模拟MA(1)序列并观察其ACF/PACF特征

set.seed(456)

# 模拟MA(1): x_t = ε_t - 0.5*ε_{t-1}
# 注意：R中arima.sim的ma参数符号与教材相反
# 教材: x_t = ε_t - θ_1*ε_{t-1}
# R中: list(ma = -0.5) 对应 θ_1 = 0.5
x <- arima.sim(n=1000, list(ma=-0.5))

# 查看时序图
ts.plot(x, main="MA(1)序列")

# ACF：预期1阶截尾（1阶显著，2阶后落入虚线）
acf(x, main="MA(1)的ACF：1阶截尾")

# PACF：预期拖尾（逐渐衰减到零）
pacf(x, main="MA(1)的PACF：拖尾")

# 对比不可逆的MA(1): θ_1 = 2（R中ma=-2）
x_irregular <- arima.sim(n=1000, list(ma=-2))
# 注意：arima.sim会检查可逆性
# ma=-2 对应 θ_1=2 > 1，不可逆
# 但ACF仍然1阶截尾——因为ACF对可逆和不可逆模型相同
acf(x_irregular, main="不可逆MA(1)的ACF：仍1阶截尾")
```

### 计算演示

已知MA(1)模型：$x_t = \varepsilon_t - 0.5\varepsilon_{t-1}$，$\sigma_\varepsilon^2 = 1$

1. **[[02_平稳性|平稳性]]**：MA模型永远平稳 ✓
2. **均值**：$E(x_t) = 0$（[[KP09_中心化_均值化|中心化]]模型）
3. **方差**：$\gamma(0) = (1 + 0.5^2) \times 1 = 1.25$
4. **1阶自协方差**：$\gamma(1) = -\theta_1 \sigma_\varepsilon^2 = -0.5$
5. **1阶ACF**：$\rho_1 = -0.5 / 1.25 = -0.4$
6. **2阶ACF**：$\rho_2 = 0$（1阶截尾）
7. **可逆性**：$|\theta_1| = 0.5 < 1$ → 可逆 ✓

## 3. 什么时候用

**适用场景：**
- ACF在q阶截尾（q阶后自[[01_相关系数|相关系数]]骤降到零附近）
- 序列当前值主要受近期随机冲击影响
- 平稳非白噪声序列

**数据条件：**
- 样本量 $n \ge 50$
- 序列已通过平稳性检验

**前提假设：**
- $\varepsilon_t$ 是零均值白噪声
- 通常要求可逆性（保证模型唯一可识别）

## 4. 什么时候不能用/易错点

**不适用场景：**
- ACF拖尾、PACF截尾的序列：应选AR模型
- 非平稳序列：MA只适合平稳序列

**常见错误：**
- 混淆R中ma参数的符号：R中 `list(ma=-0.5)` 对应教材 $x_t = \varepsilon_t - 0.5\varepsilon_{t-1}$
- 忽视可逆性：不可逆的MA模型虽然ACF相同，但不能写成收敛的AR形式，预测不稳定
- 把ACF截尾的位置定错：截尾后应"骤然降到零附近"，而非缓慢衰减

## 5. 与相似方法对比表

| 维度 | AR(p) | MA(q) |
|------|-------|-------|
| 驱动因素 | 历史序列值 | 历史随机扰动 |
| 方程 | $x_t = \sum \phi_i x_{t-i} + \varepsilon_t$ | $x_t = \varepsilon_t - \sum \theta_i \varepsilon_{t-i}$ |
| 平稳性 | 需检验（特征根条件） | 自动满足 |
| 可逆性 | 自动满足 | 需检验 |
| ACF | 拖尾 | q阶截尾 |
| PACF | p阶截尾 | 拖尾 |
| 影响持续时间 | 无限期（指数衰减） | 有限期（q阶后为零） |
| R中参数符号 | `ar=0.8` 直接对应 $\phi_1=0.8$ | `ma=-0.5` 对应 $\theta_1=0.5$ |

## 6. 为什么用这个不用那个

**决策逻辑：**
- ACF在q阶骤降截尾 → 选MA(q)
- PACF在p阶骤降截尾 → 选AR(p)
- 两者都拖尾 → 选[[KP03_ARMA模型|ARMA]](p,q)

**被排除的方法会出什么问题：**
- 对MA(q)序列硬拟合AR模型：ACF拖尾但PACF不截尾，需要很高的p阶才能近似，参数多且不经济
- 对AR(p)序列硬拟合MA模型：同样需要很高的q阶

## 7. 完整例子

**书中原例：** 例3-6 四个MA模型ACF对比

| 模型 | $\theta_1$ | $\theta_2$ | $\rho_1$ | $\rho_2$ |
|------|-----------|-----------|----------|----------|
| (1) $x_t = \varepsilon_t - 2\varepsilon_{t-1}$ | 2 | — | -0.4 | 0 |
| (2) $x_t = \varepsilon_t - 0.5\varepsilon_{t-1}$ | 0.5 | — | -0.4 | 0 |

注意：模型(1)和(2)ACF完全相同（都是 $\rho_1 = -0.4$），因为 $\theta$ 和 $1/\theta$ 产生相同的ACF。这就是需要可逆性约束的原因——只有模型(2)可逆（$|\theta_1|=0.5<1$）。

**小白生活实例：促销活动对奶茶销量的MA影响**

假设奶茶店销量受促销冲击的影响服从MA(1)：

$$x_t = 100 + \varepsilon_t - 0.6\varepsilon_{t-1}, \quad \sigma_\varepsilon^2 = 25$$

含义：本月销量 = 基准100杯 + 本月促销[[07_随机效应RE与Hausman检验|随机效应]] + 上月促销效应的60%余波。

计算：
- 均值：100杯
- 方差：$(1 + 0.36) \times 25 = 34$
- $\rho_1 = -(-0.6)/(1+0.36) = 0.6/1.36 = 0.44$

假设本月促销冲击 $\varepsilon_t = +10$（大促销），上月冲击 $\varepsilon_{t-1} = -5$：

本月销量 $= 100 + 10 - 0.6 \times (-5) = 100 + 10 + 3 = 113$ 杯。

下月预测（若下月无促销）：
- $\hat x_{t+1} = 100 - 0.6 \times \varepsilon_t = 100 - 0.6 \times 10 = 94$ 杯
- 大促销的余波下月还在"反向"影响

## 答辩常问（带标准答案）

1. **问：MA 模型为什么永远平稳，却还要谈可逆性？** 答：平稳性看的是序列本身是不是常均值常方差。MA(q) 是白噪声及其滞后项的有限线性组合，有限个平稳变量的线性组合仍平稳，所以 MA 不需要任何平稳条件。但可逆性是另一件事：同一个 ACF 可以对应两个参数互为倒数的 MA 模型（例如 $\theta_1=2$ 和 $\theta_1=0.5$ 给出完全相同的 $\rho_1=-0.4$），为了保证"一个 ACF 对应唯一模型"，必须要求 MA 的特征根也在单位圆内（MA(1) 即 $|\theta_1|<1$）。可逆性的等价说法是：MA 可以写成收敛的 AR($\infty$) 形式，预测才稳定。
2. **问：AR 和 MA 怎么从 ACF/PACF 上一眼区分？** 答：口诀是"AR 看 PACF 截尾、MA 看 ACF 截尾"。MA(q)：ACF 在 $q$ 阶后骤降到零（$q$ 阶截尾），PACF 指数衰减拖尾；AR(p)：ACF 拖尾，PACF 在 $p$ 阶后截尾。物理含义上：MA(q) 的冲击只影响 $q$ 期，$q$ 期之后两期序列值没有任何共同扰动，所以自相关精确为零；AR(p) 的影响通过惯性无限传导，所以 ACF 永不截尾。
3. **问：R 里 `arima.sim(list(ma=-0.5))` 对应的教材模型是什么？为什么符号反了？** 答：教材写 $x_t=\varepsilon_t-\theta_1\varepsilon_{t-1}$，而 R 的 `arima.sim` 采用 $x_t=\varepsilon_t+\theta_1^{R}\varepsilon_{t-1}$ 的约定，两个符号相反，所以 `list(ma=-0.5)` 才对应教材 $\theta_1=0.5$。这是写代码时最常见的坑，答辩时主动说明能体现你真跑过数据。

## 8. 速记卡

- **MA模型永远平稳**，但需要可逆性（$|\theta_i|$ 在单位圆内）
- **MA(q)的ACF：q阶截尾**（q阶后骤降到零）
- **MA(q)的PACF：拖尾**
- **MA(1) ACF公式**：$\rho_1 = -\theta_1/(1+\theta_1^2)$
- **R代码**：`arima.sim(n=1000, list(ma=-0.5))`
- **一句话口诀**：MA模型=销量受近期冲击影响，ACF在q阶后"断片"（截尾）
