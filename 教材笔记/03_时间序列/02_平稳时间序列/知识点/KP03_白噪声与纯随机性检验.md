# KP03 白噪声与纯随机性检验

## 1. 是什么

**定义：** 白噪声序列（纯随机序列）是满足"零均值、同方差、无[[03_自相关|自相关]]"的最简单的平稳序列。对其做白噪声检验（Q检验/LB检验）是判断"序列中是否还有值得提取的信息"的关键步骤。

**直觉类比：** 白噪声就像抛硬币的结果——前一次抛什么完全不影响后一次。如果你的销量序列是白噪声，那历史销量对预测未来销量毫无帮助，不如直接猜均值。

**解决什么问题：** 不是所有平稳序列都值得建模。白噪声序列"没有记忆"，过去对未来没有任何影响，分析到它就该停下来。纯随机性检验就是用[[KP02_假设检验|假设检验]]的方法，客观判断序列是否"值得继续分析"。

## 2. 怎么用

### 白噪声序列定义

$$EX_t = \mu \quad (\text{常数均值})$$

$$\gamma(t,s) = \begin{cases} \sigma^2, & t = s \\ 0, & t \ne s \end{cases}$$

记为 $X_t \sim WN(\mu, \sigma^2)$。

关键性质：$\gamma(k) = 0, \forall k \ne 0$——任意两期不相关。

### 检验假设

$$H_0: \rho_1 = \rho_2 = \dots = \rho_m = 0 \quad (\text{序列纯随机})$$

$$H_1: \text{至少存在某个 } \rho_k \ne 0 \quad (\text{序列非纯随机})$$

### Q统计量（Box-Pierce）

$$Q = n \sum_{k=1}^{m} \hat\rho_k^2 \quad \dot{\sim} \quad \chi^2(m)$$

- $n$：序列长度
- $m$：指定延迟阶数（通常取6或12）
- 大样本下效果好，小样本不精确

### LB统计量（Ljung-Box）

$$LB = n(n+2) \sum_{k=1}^{m} \frac{\hat\rho_k^2}{n-k} \quad \dot{\sim} \quad \chi^2(m)$$

- LB是Q的小样本修正版
- 实际应用中"Q统计量"通常指LB统计量

### 决策规则

- p值 < $\alpha$（通常0.05）→ 拒绝 $H_0$ → 序列非白噪声 → 有相关信息 → 值得建模
- p值 > $\alpha$ → 不能拒绝 $H_0$ → 序列为白噪声 → 没有分析价值 → 停止

### R代码

```r
# 目的：对序列进行白噪声检验（纯随机性检验）

# 方法一：单次检验
Box.test(white_noise, lag=6, type="Ljung-Box")
# lag=6：检验延迟1到6阶的联合显著性
# type="Ljung-Box"：使用LB统计量（小样本更优）
# type="Box-Pierce"：使用原始Q统计量（默认）

# 输出解读：
# Box-Ljung test
# data:  white_noise
# X-squared = 5.0327, df = 6, p-value = 0.5396
# p-value = 0.5396 > 0.05 → 不能拒绝白噪声 → 停止分析

# 方法二：循环检验多阶（推荐）
for(i in 1:2) print(Box.test(series, lag=6*i, type="Ljung-Box"))
# i=1: lag=6，检验前6阶
# i=2: lag=12，检验前12阶
# 两个p值都>0.05才可靠地判定为白噪声
```

### 计算演示

假设 $n=100$，前6阶样本自[[01_相关系数|相关系数]]为：$\hat\rho_1=0.02, \hat\rho_2=0.05, \hat\rho_3=0.10, \hat\rho_4=-0.02, \hat\rho_5=0.05, \hat\rho_6=0.01$

计算LB统计量（$m=6$）：

$$LB = 100 \times 102 \times \left(\frac{0.02^2}{99} + \frac{0.05^2}{98} + \frac{0.10^2}{97} + \frac{(-0.02)^2}{96} + \frac{0.05^2}{95} + \frac{0.01^2}{94}\right)$$

$$= 10200 \times (0.000004 + 0.000026 + 0.000103 + 0.000004 + 0.000026 + 0.000001) = 10200 \times 0.000164 \approx 1.67$$

查表 $\chi^2(6)$，$\alpha=0.05$ 的临界值为12.59。$1.67 < 12.59$，p值远大于0.05 → 不能拒绝白噪声。

## 3. 什么时候用

**适用场景：**
- 任何平稳序列建模前的必经步骤
- 模型拟合后检验残差是否为白噪声（模型是否充分提取了信息）
- 判断序列是否"值得继续分析"的分水岭

**数据条件：**
- 序列长度 $n \ge 50$（样本太小检验不可靠）
- 延迟阶数 $m$ 通常取 $6$ 或 $12$（月度数据取12，年度取6）

**前提假设：**
- 原假设下 $\hat\rho_k \dot\sim N(0, 1/n)$（Bartlett定理）
- 该近似在大样本下成立

## 4. 什么时候不能用/易错点

**不适用场景：**
- 非平稳序列：应先做[[02_平稳性|平稳性]]检验，非平稳序列的[[KP02_自协方差与ACF|ACF]]衰减缓慢，白噪声检验必然拒绝 $H_0$，但这不意味着有可建模的相关信息
- 样本量太小（$n < 30$）：卡方近似不准确

**常见错误：**
- **搞反原假设**：$H_0$ 是"序列为白噪声"，不是"非白噪声"。p值大=白噪声，p值小=非白噪声。
- 只检验一阶：必须检验联合显著性（前 $m$ 阶同时为零）
- 取太多阶：如果 $m$ 接近 $n$，短期相关性会被长期衰减淹没，反而检不出来
- **把残差白噪声检验当成模型通过的唯一标准**：还需检验参数显著性

## 5. 与相似方法对比表

| 维度 | Q统计量（Box-Pierce） | LB统计量（Ljung-Box） |
|------|---------------------|----------------------|
| 公式 | $Q = n\sum \hat\rho_k^2$ | $LB = n(n+2)\sum \frac{\hat\rho_k^2}{n-k}$ |
| 分布 | $\chi^2(m)$ | $\chi^2(m)$ |
| 适用样本 | 大样本 | 小样本更优 |
| R中参数 | `type="Box-Pierce"` | `type="Ljung-Box"` |
| 实际推荐 | 默认输出 | 普遍采用 |

## 6. 为什么用这个不用那个

**决策逻辑：**
- 拿到平稳序列后，第一件事就是做白噪声检验
- 如果是白噪声 → 停止，不值得建模
- 如果非白噪声 → 进入[[KP03_ARMA模型|ARMA]][[05_ARIMA建模流程|建模流程]]
- 模型拟合后，对残差再做一次白噪声检验 → 残差白噪声 = 模型充分提取了信息

**被排除的方法会出什么问题：**
- 跳过白噪声检验直接建模：对纯随机序列建模，得到的是"伪规律"，预测能力为零
- 只画ACF图不做检验：主观判断容易出错，需要统计检验客观支撑

## 7. 完整例子

**书中原例1：标准正态白噪声（$n=1000$）**

```r
white_noise <- rnorm(1000)
Box.test(white_noise, lag=6, type="Ljung-Box")
# X-squared = 5.03, df = 6, p-value = 0.5396
Box.test(white_noise, lag=12, type="Ljung-Box")
# X-squared = 9.81, df = 12, p-value = 0.6325
```

p值都远大于0.05 → 确认白噪声 → 停止分析。

**书中原例2：北京市城乡居民定期储蓄比例（1950-1998）**

```r
for(i in 1:2) print(Box.test(prop, lag=6*i, type="Ljung-Box"))
# 阶=6: X-squared=68.72, df=6, p-value=7.467e-13
# 阶=12: X-squared=74.74, df=12, p-value=4.115e-11
```

p值极小（接近0）→ 强烈拒绝白噪声 → 序列含相关信息 → 值得建模。

**小白生活实例：奶茶店日销量白噪声检验**

假设你有100天奶茶店销量数据，做白噪声检验：
- 延迟6阶LB检验：p值 = 0.002 < 0.05
- 延迟12阶LB检验：p值 = 0.001 < 0.05

结论：不是白噪声！今天的销量和历史销量有显著关系，可以建模预测明天的销量。

如果检验结果是 p值 = 0.34 > 0.05 → 白噪声 → 销量是随机波动的，历史数据帮不了你预测明天。

## 答辩常问（带标准答案）

1. **问：白噪声检验的原假设是什么？p 值大说明什么？** 答：原假设 $H_0$ 是"序列纯随机"，即 $\rho_1=\rho_2=\dots=\rho_m=0$，备择假设是至少有某阶自相关非零。决策规则：p 值 $<\alpha$（通常0.05）拒绝 $H_0$，说明序列有相关信息、值得建模；p 值 $>0.05$ 不能拒绝 $H_0$，说明是白噪声、历史对未来没有预测价值，应该停止分析。最常见的错误就是把原假设记反——记住"p 大没戏、p 小有戏"。
2. **问：Q 统计量和 LB 统计量有什么区别？实际用哪个？** 答：两者都检验前 $m$ 阶自相关系数是否联合为零，渐近分布都是 $\chi^2(m)$。Q（Box-Pierce）是 $Q=n\sum_{k=1}^m\hat\rho_k^2$，只在大样本下准确；LB（Ljung-Box）是 $LB=n(n+2)\sum_{k=1}^m\frac{\hat\rho_k^2}{n-k}$，对小样本做了修正。实际一律用 `Box.test(x, lag=6, type="Ljung-Box")`，并且推荐同时做 lag=6 和 lag=12 两次检验，两个 p 值都大于 0.05 才算可靠地判定为白噪声。
3. **问：为什么建模完成后还要对残差再做一次白噪声检验？** 答：建模前检验原序列是为了判断"有没有信息可挖"；建模后检验残差是为了判断"模型有没有把信息挖干净"。如果残差通过了白噪声检验（p 值 >0.05），说明剩下的部分全是随机噪声，模型已经充分提取了序列中的相关结构；如果残差仍是非白噪声，说明还有没被 ARMA 捕捉到的自相关，模型阶数或形式需要调整。注意残差白噪声只是模型充分性的标准之一，还要看参数是否显著、AIC/BIC 是否最小。

## 8. 速记卡

- **白噪声**：零均值、同方差、无自相关 = 没有记忆 = 不值得建模
- **原假设 $H_0$**：$\rho_1 = \dots = \rho_m = 0$（序列纯随机）
- **p值 > 0.05** → 不能拒绝白噪声 → 停止分析
- **p值 < 0.05** → 拒绝白噪声 → 有信息可提取 → 建模
- **R代码**：`Box.test(x, lag=6, type="Ljung-Box")`
- **模型检验时**：残差是白噪声 = 模型有效
- **一句话口诀**：白噪声检验就是问"这序列还有没有戏"——p大没戏，p小有戏
