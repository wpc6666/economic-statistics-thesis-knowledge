# KP01 严平稳与宽平稳

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


## 1. 是什么

**定义：** [[02_平稳性|平稳性]]是某些时间序列具有的统计特征——序列的统计性质不随时间的平移而改变。根据条件严格程度分为严平稳和宽平稳。

**直觉类比：** 想象一个奶茶店每天的销量。如果每天的销量都围绕同一个均值波动，且间隔一天的两天销量之间的相关程度和间隔两天的相关程度不随日期变化——就像一个"性格不变"的人，那这个序列就是平稳的。

- **严平稳**：序列的"性格"（整个概率分布）完全不随时间变化。要求最苛刻，实践中几乎无法验证。
- **宽平稳**：只要求"性格的前两阶矩"（均值、方差、相关性）不随时间变化。条件宽松，实践中可操作。

**解决什么问题：** 时间序列在每个时刻 $t$ 只有一个观察值，无法单独估计每个时刻的均值和方差。平稳性假设让所有时刻共用一个均值 $\mu$ 和方差 $\gamma(0)$，从而把一个"每个时刻一个样本"的问题变成"所有时刻都是同一个总体的样本"，极大增加了样本量。

## 2. 怎么用

### 完整步骤

1. 检查二阶矩是否存在：$EX_t^2 < \infty$
2. 检查均值是否为常数：$EX_t = \mu, \forall t$
3. 检查自协方差是否只依赖时间间隔：$\gamma(t,s) = \gamma(k, k+s-t)$
4. 若三条全满足 → 宽平稳；否则非平稳

### 核心公式

**宽平稳三条件：**

$$EX_t^2 < \infty, \quad EX_t = \mu, \quad \gamma(t,s) = \gamma(k, k+s-t)$$

**延迟 $k$ 自协方差：**

$$\gamma(k) = \gamma(t, t+k) = E[(X_t-\mu)(X_{t+k}-\mu)]$$

**延迟 $k$ [[03_自相关|自相关]]系数：**

$$\rho_k = \frac{\gamma(k)}{\gamma(0)}$$

### R代码

```r
# 目的：判断一个序列是否宽平稳（图检验法）
# 第一步：绘制时序图，看是否在常数附近有界波动
plot(ts_object, main="时序图", ylab="序列值")

# 第二步：绘制自相关图，看是否快速衰减到零
acf(ts_object, main="自相关图")
# 虚线为2倍标准差位置
# 平稳序列：前几阶后迅速落入虚线范围内
# 非平稳：衰减缓慢，可能长期在虚线外
```

### 计算演示

假设某宽平稳序列已知：$\mu = 10$，$\gamma(0) = 4$，$\gamma(1) = 2$，$\gamma(2) = 1$

- 均值：$EX_t = 10$（常数）
- 方差：$DX_t = \gamma(0) = 4$（常数）
- 1阶自[[01_相关系数|相关系数]]：$\rho_1 = \gamma(1)/\gamma(0) = 2/4 = 0.5$
- 2阶自相关系数：$\rho_2 = \gamma(2)/\gamma(0) = 1/4 = 0.25$

注意：$\rho_1 = 0.5$ 只跟间隔"1期"有关，跟从哪个时刻算起无关——这就是宽平稳的核心。

## 3. 什么时候用

**适用场景：**
- 几乎所有时间序列建模的前提（[[KP03_ARMA模型|ARMA]]模型只对平稳序列成立）
- 需要用样本均值 $\bar x$ 估计总体均值 $\mu$ 时
- 需要用样本自相关系数 $\hat\rho_k$ 推断总体 $\rho_k$ 时

**数据条件：**
- 样本量 $n$ 足够大（通常 $n \ge 50$）
- 序列无明显趋势、无明显周期

**前提假设：**
- 二阶矩存在（大多数实际序列满足）
- 均值确实为常数（如果有趋势，需先差分或分解）

**违反了会怎样：**
- 若均值随时间变化（有趋势），用 $\bar x$ 估计 $\mu$ 会产生严重偏差
- 若方差随时间变化（[[02_异方差|异方差]]），自协方差估计不可靠
- 若相关性不仅依赖间隔还依赖起点，$\hat\rho_k$ 没有统一解释

## 4. 什么时候不能用/易错点

**不适用场景：**
- 有明显上升/下降趋势的序列（如中国纱年产量）→ 非平稳
- 有明显年度周期的序列（如牛奶月产量）→ 非平稳
- 方差随时间变化的金融收益率序列 → 需[[KP05_GARCH模型|GARCH]]类模型

**常见错误：**
- 把"时序图看起来在某个范围波动"等同于平稳：波动范围可能恒定但均值在漂移
- 认为样本自相关系数小就是白噪声：小样本下即使平稳非白噪声，$\hat\rho_k$ 也可能很小
- 混淆严平稳与宽平稳：本科阶段默认"平稳"指宽平稳

## 5. 与相似方法对比表

| 维度 | 严平稳 | 宽平稳（二阶平稳） |
|------|--------|-------------------|
| 定义 | 所有有限维分布不随时间平移改变 | 二阶矩（均值、方差、自协方差）不随时间改变 |
| 条件严格度 | 非常严格 | 较宽松 |
| 实践可操作性 | 几乎不可验证 | 可通过图[[08_t检验和F检验|检验和]]统计检验判断 |
| 包含关系 | 有二阶矩的严平稳 → 宽平稳 | 宽平稳不一定 → 严平稳 |
| 特殊情形 | — | 正态序列中宽平稳 ↔ 严平稳 |
| 本科阶段用途 | 理论意义为主 | 实际分析的核心概念 |

## 6. 为什么用这个不用那个

**决策逻辑：**
- 如果问题只涉及二阶矩（均值、方差、自相关），用宽平稳就够了
- 如果需要完整分布信息（如计算高阶矩、尾部概率），才需要考虑严平稳
- 实践中我们只检验宽平稳：因为它可操作，且ARMA模型只要求宽平稳

**被排除的方法会出什么问题：**
- 直接假设严平稳：无法验证，也没必要——ARMA建模只需要二阶矩
- 不做平稳性检验直接建模：对非平稳序列拟合ARMA会产生"伪回归"——$R^2$ 很高但预测能力为零

## 7. 完整例子

**书中原例：** 1949-1998年北京市每年最高气温序列
- 时序图：始终围绕 $37^\circ C$ 附近随机波动，无明显趋势或周期
- 自相关图：所有 $\hat\rho_k$ 都在2倍标准差范围内，自相关系数很小
- 白噪声检验：p值 = 0.5417（6阶）、0.9231（12阶），不能拒绝白噪声
- 结论：平稳且纯随机 → 不需要建模

**小白生活实例：奶茶店日销量**

假设你记录了某奶茶店100天的日销量，计算得：
- 样本均值 $\bar x = 80$ 杯
- 样本方差 $s^2 = 100$
- 1阶自相关 $\hat\rho_1 = 0.6$，2阶 $\hat\rho_2 = 0.3$，3阶 $\hat\rho_3 = 0.1$

判断：
1. 时序图：销量在70-90之间波动，无上升/下降趋势 → 初步平稳
2. 自相关图：$\hat\rho_k$ 从0.6快速衰减到0.1 → 短期相关性 → 平稳特征
3. 结论：该序列宽平稳。今天的销量和昨天的相关性是0.6，和前天的相关性是0.3——这个关系在任何时间段都成立。

## 答辩常问（带标准答案）

1. **问：为什么时间序列建模一定要先讲平稳性？不平稳会怎样？** 答：因为每个时刻 $t$ 只有一个观测值，本来没法估计每个时刻的均值和方差。平稳性假设让所有时刻共用同一个均值 $\mu$ 和方差 $\gamma(0)$，样本量从"$n$ 个孤立点"变成"同一个总体的 $n$ 个样本"，$\bar x$ 和 $\hat\rho_k$ 才有意义。如果序列有趋势却不平稳就直接拟合 ARMA，会出现伪回归：$R^2$ 看起来很高，但模型没有预测能力，必须先差分或分解趋势。
2. **问：严平稳和宽平稳到底差在哪？本科答辩说"平稳"指哪一个？** 答：严平稳要求整个有限维分布不随时间平移改变，条件极强、实践中根本无法验证；宽平稳只要求二阶矩不变——二阶矩存在（$EX_t^2<\infty$）、均值为常数 $\mu$、自协方差只依赖时间间隔 $k$ 而不依赖起点 $t$。本科阶段说"平稳"一律指宽平稳；两者的关系是：有二阶矩的严平稳一定是宽平稳，反过来不成立，但正态序列中二者等价。
3. **问：实际拿到一条序列，怎么判断它是不是宽平稳？** 答：先看图再看检验。一看时序图：是否围绕一条水平直线上下波动，均值和波动幅度不随时间漂移；二看 [[KP02_自协方差与ACF|ACF]] 图：平稳序列的样本自相关系数 $\hat\rho_k$ 应该快速衰减到 2 倍标准差虚线以内，衰减很慢、长期在虚线外的多半是非平稳；三做白噪声和平稳性检验（后续章节的 ADF 检验等）。三条都指向"无趋势、无周期、短期相关"才算宽平稳。

## 8. 速记卡

- **宽平稳三条件**：二阶矩存在、均值常数、协方差只看间隔
- **严平稳 vs 宽平稳**：严平稳管分布，宽平稳只管二阶矩；正态序列两者等价
- **本科默认**：说"平稳"=宽平稳
- **平稳的意义**：让每个时刻的样本都能共用一个均值和方差，把"一个时刻一个样本"变成"全序列一个样本"
- **一句话口诀**：均值不动、方差不动、相关性只看间隔——就是宽平稳
