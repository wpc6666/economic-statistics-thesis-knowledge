# KP02 自协方差与ACF

## 1. 是什么

**定义：** 自协方差函数 $\gamma(k)$ 度量同一序列在间隔 $k$ 期的两个取值之间的线性相关程度；[[03_自相关|自相关]]系数 $\rho_k$（ACF）是[[KP11_标准化_ZScore|标准化]]后的自协方差，取值范围 $[-1, 1]$。

**直觉类比：** 自[[01_相关系数|相关系数]]就像"今天的奶茶销量和 $k$ 天前的销量的'相似度'"。$\rho_1 = 0.6$ 意味着今天卖得多，昨天通常也卖得多；$\rho_{30} \approx 0$ 意味着今天和30天前的销量几乎没有关系。

**解决什么问题：** 时间序列的核心特征就是"历史对现在的影响"。ACF用一个数字量化了这种影响随时间间隔的衰减规律，是判断[[02_平稳性|平稳性]]、识别模型阶数的基础工具。

## 2. 怎么用

### 核心公式

**自协方差函数：**

$$\gamma(k) = E[(X_t - \mu)(X_{t+k} - \mu)]$$

- $\mu$：序列均值（宽平稳时为常数）
- $X_t$：$t$ 时刻的随机变量
- $X_{t+k}$：$t+k$ 时刻的随机变量
- $\gamma(k)$ 只与间隔 $k$ 有关，与起点 $t$ 无关（宽平稳性质）

**自相关系数（ACF）：**

$$\rho_k = \frac{\gamma(k)}{\gamma(0)}$$

- $\gamma(0) = \text{Var}(X_t)$ 是序列方差
- 因此 $\rho_0 = 1$（自己和自己完全相关）
- $|\rho_k| \le 1$（规范性）
- $\rho_k = \rho_{-k}$（对称性）

#### 【三问】为什么要除以 $\gamma(0)$ 做标准化？ACF 到底在解决什么问题？

- **怎么来的（直觉推导）**：自协方差 $\gamma(k) = E[(X_t-\mu)(X_{t+k}-\mu)]$ 直接度量两个时刻取值的"联动程度"。但它有个毛病：**量纲依赖方差**。比如月销量（单位：杯）的 $\gamma(1)=100$，月营业额（单位：元）的 $\gamma(1)=10000$，后者绝对数字大，但不代表相关性更强。所以把 $\gamma(k)$ 除以总方差 $\gamma(0)$，相当于"扣掉序列本身的波动幅度"，得到一个 0~1 之间的相对指标 $\rho_k$。这和普通相关系数 $\text{Corr}(X,Y)=\text{Cov}(X,Y)/\sqrt{\text{Var}(X)\text{Var}(Y)}$ 是同一个道理——标准化之后才能跨序列比较。
- **为什么用它**：解决"时间序列的历史对现在到底有多大影响、影响多久"的问题。没有 ACF，你只能对着时序图"凭感觉"说这序列像有惯性。有了 ACF，$\rho_1=0.6$ 告诉你"今天和昨天强相关"，$\rho_{10}\approx 0$ 告诉你"10天前的事基本不影响今天"。更重要的是，**不同 [[KP03_ARMA模型|ARMA]] 模型的 ACF 有截然不同的衰减模式**（AR拖尾、MA截尾），ACF 是模型识别（选 p、q 阶）的核心依据。
- **知识为什么存在**：1920-30 年代，Yule、Slutsky 等人在研究经济周期时发现，普通相关系数只能衡量"两个不同变量"的相关性，无法衡量"一个变量在不同时刻"的相关性。ACF 的提出把相关分析从"横截面"拓展到"时间维度"，是整个时间序列分析（从平稳性判断、ARMA 定阶、到白噪声检验）的基础设施。没有 ACF，就没有后来 Box-Jenkins 的 ARMA [[05_ARIMA建模流程|建模流程]]。

**样本自协方差估计：**

$$\hat\gamma(k) = \frac{1}{n-k}\sum_{t=1}^{n-k}(x_t - \bar x)(x_{t+k} - \bar x), \quad 0 < k < n$$

**样本自相关系数：**

$$\hat\rho_k = \frac{\hat\gamma(k)}{\hat\gamma(0)}$$

### R代码

```r
# 目的：计算并绘制序列的样本自相关图
# 数据：1884-1890年小麦亩产数据

yield <- c(15.2, 16.9, 15.3, 14.9, 15.7, 15.1, 16.7)
yield_ts <- ts(yield, start=1884)

# 绘制自相关图
acf(yield_ts)
# 横轴：延迟阶数 k
# 纵轴：样本自相关系数 \hat\rho_k
# 虚线：2倍标准差位置 ±2/√n
# 判读：如果某根垂线超出虚线，说明该阶自相关系数显著非零
```

### 计算演示

已知宽平稳序列：$\mu = 0$，$\gamma(0) = 4$，$\gamma(1) = 2$，$\gamma(2) = 1$

- $\rho_0 = \gamma(0)/\gamma(0) = 1$
- $\rho_1 = 2/4 = 0.5$
- $\rho_2 = 1/4 = 0.25$
- $\rho_3$ 若为 $0.5 \times 0.25 = 0.125$（AR(1) 衰减模式）

读ACF图的方法：
1. 第0阶恒为1（自己和自己）
2. 看前几阶是否显著超过虚线（2倍标准差）
3. 看衰减速度：快速落到虚线内 → 平稳；缓慢衰减 → 非平稳

## 3. 什么时候用

**适用场景：**
- 判断序列平稳性（衰减速度）
- 识别ARMA模型阶数（截尾 vs 拖尾模式）
- 白噪声检验的输入（Q/LB统计量由 $\hat\rho_k$ 构成）

**数据条件：**
- 宽平稳序列（否则 $\gamma(k)$ 的解释无意义）
- 样本量 $n$ 足够大（通常 $n \ge 50$）

**前提假设：**
- 序列二阶矩存在
- 均值已被正确估计（可用 $\bar x$ 近似）

## 4. 什么时候不能用/易错点

**不适用场景：**
- 非平稳序列的ACF没有统一解释（$\gamma(k)$ 依赖起点 $t$）
- [[02_异方差|异方差]]序列的ACF不可靠

**常见错误：**
- 把样本ACF当作总体ACF：小样本下 $\hat\rho_k$ 有偏差和噪声
- 只看一两个 $\hat\rho_k$ 就下结论：应观察整体衰减模式
- 混淆ACF的"截尾"和"拖尾"：这是第3章模型识别的核心，不能搞反

## 5. 与相似方法对比表

| 维度 | 自协方差 $\gamma(k)$ | 自相关系数 $\rho_k$ |
|------|---------------------|---------------------|
| 定义 | $E[(X_t-\mu)(X_{t+k}-\mu)]$ | $\gamma(k)/\gamma(0)$ |
| 量纲 | 与原序列相同（有单位） | 无量纲，$[-1,1]$ |
| 用途 | 计算方差、构造模型 | 比较不同序列的相关性、画图判读 |
| 特殊值 | $\gamma(0) = \text{Var}(X_t)$ | $\rho_0 = 1$ |
| 谁大谁小 | 取决于序列方差 | 已标准化，可跨序列比较 |

## 6. 为什么用这个不用那个

**决策逻辑：**
- 需要计算方差或建模参数时 → 用 $\gamma(k)$（有量纲）
- 需要画图判读、比较相关性时 → 用 $\rho_k$（标准化后直观）

**被排除的方法会出什么问题：**
- 只用 $\gamma(k)$ 画图：量纲依赖方差，不同序列无法比较
- 不做标准化就判断"相关性强弱"：方差大的序列 $\gamma(k)$ 天然大，不代表相关性强

## 7. 完整例子

**书中原例：** 北京市最高气温序列（1949-1998）
- 时序图：围绕 $37^\circ C$ 波动
- ACF图：所有 $\hat\rho_k$ 都在2倍标准差以内 → 自相关性极弱
- 结论：平稳且接近白噪声

**小白生活实例：奶茶店销量ACF判读**

假设某奶茶店100天销量的ACF图显示：
- $\hat\rho_1 = 0.65$（超出2倍虚线，显著）
- $\hat\rho_2 = 0.40$（显著）
- $\hat\rho_3 = 0.20$（接近虚线边界）
- $\hat\rho_4 = 0.10$（在虚线内）
- $\hat\rho_5 = 0.05$（在虚线内）

判读：
1. 今天和昨天的销量强相关（0.65）
2. 和前天中等相关（0.40）
3. 和3天前弱相关（0.20）
4. 4天以上几乎无相关

这是典型的"短期相关性"模式——平稳序列的特征。

## 答辩常问（带标准答案）

1. **问：自协方差 $\gamma(k)$ 和自相关系数 $\rho_k$（ACF）有什么区别？为什么要除以 $\gamma(0)$？** 答：$\gamma(k)=E[(X_t-\mu)(X_{t+k}-\mu)]$ 是有量纲的，数值大小依赖序列自身方差，不同序列之间无法比较；除以 $\gamma(0)=\mathrm{Var}(X_t)$ 做标准化后得到 $\rho_k=\gamma(k)/\gamma(0)$，落在 $[-1,1]$ 之间，和普通相关系数 $\mathrm{Cov}(X,Y)/\sqrt{\mathrm{Var}(X)\mathrm{Var}(Y)}$ 是同一个道理。标准化后才能跨序列比较、才能画图判读。三条性质要记住：$\rho_0=1$、$|\rho_k|\le 1$、$\rho_k=\rho_{-k}$（对称）。
2. **问：ACF 图怎么读？虚线是什么意思？怎么从 ACF 看平稳性？** 答：横轴是延迟阶数 $k$，纵轴是样本自相关系数 $\hat\rho_k$，图上两条虚线约等于 $\pm 2/\sqrt{n}$（白噪声假设下 2 倍标准差位置）。某阶竖线超出虚线就说明该阶自相关显著非零。判断平稳性看衰减速度：平稳序列的 $\hat\rho_k$ 随 $k$ 增大快速落到虚线以内（短期相关）；如果衰减非常慢、前面好多阶都长期显著超出虚线，通常说明序列有趋势、是非平稳的。
3. **问：样本自协方差的分母为什么是 $n-k$ 而不是 $n$？** 答：计算 $\hat\gamma(k)=\frac{1}{n-k}\sum_{t=1}^{n-k}(x_t-\bar x)(x_{t+k}-\bar x)$ 时，间隔 $k$ 的配对只有 $n-k$ 对，用 $n-k$ 做除数是无偏估计的写法；R 里 `acf()` 实际输出的是用 $n$ 统一归一化的估计，两者差一个 $(n-k)/n$ 的因子，大样本下几乎无差别，小样本定阶时要注意。

## 8. 速记卡

- **公式**：$\gamma(k) = E[(X_t-\mu)(X_{t+k}-\mu)]$，$\rho_k = \gamma(k)/\gamma(0)$
- **三条性质**：$\rho_0 = 1$；$|\rho_k| \le 1$；$\rho_k = \rho_{-k}$
- **ACF图怎么读**：横轴=延迟阶数，纵轴=相关系数，虚线=2倍标准差
- **平稳序列ACF特征**：快速衰减到零附近（短期相关性）
- **一句话口诀**：ACF就是"今天和k天前的相似度"，平稳序列这个相似度随k快速降到零
