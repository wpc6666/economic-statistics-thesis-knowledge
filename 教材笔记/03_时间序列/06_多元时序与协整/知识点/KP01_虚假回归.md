# KP01 虚假回归

## 1. 是什么

**虚假回归**（spurious regression）：两个相互独立的非平稳时间序列，做回归分析时R²很高、t值显著，但实际上毫无因果关系。

**直觉类比**：两个完全不认识的人在街上随机漫步，碰巧有一段时间一个往左走一个也往左走——你以为他们是"同伙"，其实只是巧合。时间越长，这种"巧合"越像真的。

**解决什么问题**：警示研究者——非平稳序列不能直接做回归，否则会得到毫无意义的"显著"结果。

## 2. 怎么用

### 虚假回归的识别

1. R²很高但经济逻辑不通
2. D-W统计量很低（接近0）→ 残差高度[[03_自相关|自相关]]
3. 系数t值很高但模型无法解释

### 关键公式

**两个独立随机游走**：
$$y_t = y_{t-1} + \varepsilon_t, \quad x_t = x_{t-1} + \eta_t$$
其中$\varepsilon_t$和$\eta_t$完全独立。

**做回归$y_t = \alpha + \beta x_t + u_t$**：
- 样本量越大，R²反而越高
- t值越显著
- 但$y_t$和$x_t$实际毫无关系

### R代码

```r
# ========== 虚假回归演示 ==========
set.seed(123)
n <- 200

# 模拟两个完全独立的随机游走
y <- cumsum(rnorm(n))  # 随机游走1
x <- cumsum(rnorm(n))  # 随机游走2（与y无关）

# 画时序图——两条线看起来都有趋势
plot(y, type="l", col="blue", main="两个独立随机游走")
lines(x, col="red")

# 做回归
fit <- lm(y ~ x)
summary(fit)
# 结果：R²可能很高（0.3-0.8），x的系数t值可能显著
# 但实际上y和x毫无关系！

# 检查残差自相关
dwtest(fit)  # Durbin-Watson检验
# D-W值接近0→残差高度自相关→警示虚假回归
```

### 计算演示

**模拟结果**：
- $n=200$次模拟中，x系数t值>2的比例超过60%
- 但x和y完全独立，真实系数应该=0
- 结论：t检验完全失效，"显著"是假的

## 3. 什么时候用

- **警告场景**：看到非平稳序列回归R²很高时，先怀疑是不是虚假回归
- **识别信号**：
  - R² >> D-W统计量（R²很高但残差自相关）
  - 系数符号不符合经济理论
  - 换个样本期结果就完全变了

## 4. 什么时候不能用/易错点

- **把虚假回归当真**：直接用非平稳序列做回归，结论毫无意义
- **不做[[02_平稳性|平稳性]]检验就回归**：这是最常见的错误
- **误以为R²高就模型好**：非平稳序列的R²天然偏高

## 5. 与相似方法对比表

| 方法 | 序列要求 | R²含义 | 结果可靠性 |
|------|----------|--------|-----------|
| 平稳序列回归 | 序列平稳 | 真实拟合度 | 可靠 |
| 非平稳序列直接回归 | 非平稳 | 虚高 | 不可靠（虚假回归） |
| 差分后回归 | 一阶差分后平稳 | 变化量的解释 | 可靠但损失长期信息 |
| 协整回归 | 非平稳但存在协整关系 | 长期均衡关系 | 可靠（有经济意义） |

## 6. 为什么用这个不用那个

- **为什么不能直接回归非平稳序列？** 因为非平稳序列的均值和方差随时间变化，传统回归假设的"Gauss-Markov条件"不满足，t[[08_t检验和F检验|检验和]]R²都会失真。
- **正确做法**：先检验平稳性→若非平稳则检验协整→协整存在才做协整回归，否则做差分回归。

## 7. 完整例子

**经典例子**：某国GDP和某只不相关股票的价格
- 两个序列都逐年增长（非平稳）
- 回归结果：R²=0.85，t值=5.2，"高度显著"
- 但经济逻辑上完全无关
- 真相：只是碰巧都有增长趋势——典型虚假回归

## 答辩常问（带标准答案）

1. **问：什么是虚假回归？它是怎么产生的？** 答：两个本身完全独立的非平稳序列（比如两个互不相干的随机游走 $y_t=y_{t-1}+\varepsilon_t$、$x_t=x_{t-1}+\eta_t$），直接做 $y_t=\alpha+\beta x_t+u_t$ 回归时，会出现 $R^2$ 很高、$t$ 值很显著的假象，但两者实际上毫无关系。原因是 Gauss-Markov 假设要求解释变量和扰动项平稳、渐近独立，非平稳序列不满足，传统 t 检验和 $R^2$ 的分布全部失效；而且样本越大、这种"假显著"反而越严重。
2. **问：拿到一个回归结果，怎么判断是不是虚假回归？** 答：看三个信号：①$R^2$ 很高但 D-W 统计量接近 0（残差高度自相关），典型表现是 $R^2 \gg D-W$；②系数符号和大小不符合经济理论；③换个样本期结果就大变号。根本的判断办法还是先做[[KP01_单位根检验ADF|单位根检验]]：如果自变量和因变量都是非平稳的，又没有证据表明它们协整，那这个高 $R^2$ 回归就是虚假回归。
3. **问：发现两个非平稳序列不能直接回归，那正确做法是什么？** 答：三条路：①如果两个序列同阶单整（比如都是 I(1)），先做协整检验——若存在协整关系，就可以做协整回归、并建误差修正模型，这种回归是合法的长期均衡关系；②若不存在协整，就对两个序列差分后再回归，只解释"变化量"之间的短期关系；③单变量序列则用差分把它变成平稳序列，再上 [[KP01_ARIMA模型|ARIMA]]。核心原则：平稳了才能回归，或者证明协整了才能回归。

## 8. 速记卡

- 虚假回归 = 两个无关非平稳序列的"伪关系"
- R²高≠模型好，D-W低是警示信号
- 非平稳序列不能直接回归
- 一句话口诀：**非平稳别硬回归，虚假回归骗死人**
