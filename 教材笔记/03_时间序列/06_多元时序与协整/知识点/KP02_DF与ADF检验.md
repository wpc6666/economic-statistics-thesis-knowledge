## 1. 是什么

**DF检验**（Dickey-Fuller检验）：检验时间序列是否存在单位根（即是否非平稳）。

**ADF检验**（Augmented Dickey-Fuller检验）：在DF基础上，加入滞后差分项来控制序列的[[03_自相关|自相关]]，是最常用的单位根检验。

**原假设**：序列有单位根（非平稳）
**备择假设**：序列没有单位根（平稳）

**直觉类比**：DF检验像"称重判断"——如果序列"太重"（有单位根），就是非平稳的；"太轻"就是平稳的。ADF则是"先抖掉灰尘再称重"——扣除自相关的干扰后再判断。

**解决什么问题**：判断序列是否平稳，是做回归分析前的必要步骤。

## 2. 怎么用

### DF检验三种类型

| 类型 | 回归式 | 适用场景 |
|------|--------|----------|
| 无常数无趋势 | $\Delta x_t = \gamma x_{t-1} + \varepsilon_t$ | 序列均值为0 |
| 有常数无趋势 | $\Delta x_t = \alpha + \gamma x_{t-1} + \varepsilon_t$ | 序列有非零均值 |
| 有常数有趋势 | $\Delta x_t = \alpha + \beta t + \gamma x_{t-1} + \varepsilon_t$ | 序列有趋势 |

**判断规则**：看$x_{t-1}$的系数$\gamma$的t统计量，与MacKinnon临界值比较。

### ADF检验

在DF基础上加入滞后差分项：
$$\Delta x_t = \alpha + \beta t + \gamma x_{t-1} + \sum_{i=1}^{p}\delta_i \Delta x_{t-i} + \varepsilon_t$$

加入滞后差分项的目的：消除残差自相关，使$\varepsilon_t$为白噪声。

### R代码

```r
# ========== ADF单位根检验完整流程 ==========
library(tseries)
library(forecast)

# 目的：检验GDP序列是否平稳

# 示例序列（非平稳）
x <- cumsum(rnorm(200))  # 随机游走=非平稳

# 方法1：adf.test()（tseries包）
adf_result <- adf.test(x, alternative="stationary")
print(adf_result)
# 输出：Dickey-Fuller = -1.234, p-value = 0.85
# p-value > 0.05 → 不拒绝原假设 → 序列有单位根（非平稳）

# 方法2：tseries包的kpss检验（反向检验）
# KPSS原假设是"平稳"，和ADF相反
kpss_result <- kpss.test(x)
# p-value < 0.05 → 拒绝平稳原假设 → 非平稳

# 对差分后的序列再检验
x_diff <- diff(x)
adf_diff <- adf.test(x_diff)
# p-value < 0.01 → 一阶差分后平稳 → x是I(1)序列

# 完整判断流程：
# adf.test(x)       → 非平稳（p>0.05）
# adf.test(diff(x)) → 平稳（p<0.05）
# 结论：x是一阶单整I(1)
```

### 计算演示

**ADF检验结果解读**：
- 原序列ADF检验：DF统计量=-1.2，p=0.85 → 非平稳
- 一阶差分后ADF检验：DF统计量=-8.5，p=0.01 → 平稳
- 结论：原序列是**一阶单整I(1)**——差分一次就平稳了

**单整阶数判断**：
- $x_t$平稳 → I(0)
- $x_t$非平稳，$\Delta x_t$平稳 → I(1)
- $\Delta x_t$非平稳，$\Delta^2 x_t$平稳 → I(2)

## 3. 什么时候用

- **必用场景**：
  - 任何时间序列回归分析之前
  - 判断序列是否适合用[[KP03_ARMA模型|ARMA]]建模（平稳）还是[[KP01_ARIMA模型|ARIMA]]建模（差分）
  - 协整分析前的单整阶数判断
- **前提假设**：序列足够长（通常>50期）

## 4. 什么时候不能用/易错点

- **p值解读反了**：ADF原假设是"非平稳"，p<0.05=平稳，p>0.05=非平稳
- **滞后阶数p选错**：
  - p太小→残差自相关→检验失真
  - p太大→检验功效下降
- **三种类型选错**：
  - 有趋势的序列用无趋势类型→结论不准
  - 通常先用"有常数有趋势"类型，不显著再降级
- **常见错误**：只看p值不看序列图——有时候ADF[[08_t检验和F检验|检验和]]直觉矛盾，要结合时序图判断

## 5. 与相似方法对比表

| 检验方法 | 原假设 | 适用场景 | 优点 | 缺点 |
|----------|--------|----------|------|------|
| DF检验 | 有单位根 | 残差无自相关 | 简单 | 不能处理自相关 |
| ADF检验 | 有单位根 | 残差有自相关 | 最常用 | 滞后阶数选择 |
| PP检验 | 有单位根 | [[02_异方差|异方差]]序列 | 非参数 | 小样本偏差大 |
| KPSS检验 | 平稳 | 与ADF互为补充 | 方向相反 | 结果可能矛盾 |

## 6. 为什么用这个不用那个

- **为什么用ADF而不用DF？** 实际时间序列几乎都有自相关，DF检验假设残差独立太强，ADF加入滞后差分项解决了这个问题。
- **为什么需要单位根检验？** 非平稳序列直接回归会产生[[KP01_虚假回归|虚假回归]]，必须先判断[[02_平稳性|平稳性]]再决定分析方法。

## 7. 完整例子

**生活实例**：奶茶店月度销量序列
1. 画时序图→逐年增长→看起来非平稳
2. ADF检验（有常数有趋势）：p=0.35 → 不拒绝非平稳
3. 一阶差分后ADF检验：p=0.01 → 拒绝非平稳→差分后平稳
4. 结论：销量序列是I(1)一阶单整
5. 后续：可以用ARIMA(p,1,q)建模，或检验与其他变量是否协整

## 答辩常问（带标准答案）

1. **问：ADF 检验的原假设是什么？p 值大说明平稳还是非平稳？** 答：原假设 $H_0$ 是"序列有单位根、即非平稳"，备择假设是"没有单位根、即平稳"。判读方向和一般检验相反：p 值 $<0.05$ 拒绝原假设，说明序列平稳；p 值 $>0.05$ 不能拒绝原假设，说明序列有单位根、非平稳。最常见的错误就是把原假设记反——记住口诀"p 小就平稳，p 大就有根"。检验形式上要先用"有常数有趋势"的式子，不显著再逐档降级，滞后差分项的个数选到残差无自相关为止。
2. **问：ADF 检验里为什么要加滞后差分项？DF 和 ADF 差在哪？** 答：DF 检验的回归式是 $\Delta x_t=\alpha+\beta t+\gamma x_{t-1}+\varepsilon_t$，它假设扰动 $\varepsilon_t$ 没有自相关；但实际序列几乎总有自相关，残差自相关会让 $\gamma$ 的 t 统计量分布偏离标准 t 分布、检验失真。ADF 在方程右边加入 $\sum_{i=1}^{p}\delta_i\Delta x_{t-i}$ 这些滞后差分项，把残差里的自相关吸收掉，使扰动变成白噪声，这就是"增广"的含义。滞后阶数 p 不能太小（否则残差仍自相关）也不能太大（否则检验功效下降），一般按 AIC 选。
3. **问：什么叫 I(1)、I(2)？怎么判断单整阶数？** 答：单整阶数就是把序列变平稳所需的差分次数。原序列 ADF 检验平稳（p<0.05）就是 I(0)；原序列非平稳、一阶差分后 ADF 检验平稳，就是 I(1)；一阶差分还不平稳、二阶差分后才平稳，就是 I(2)。宏观经济和金融价格绝大多数是 I(1)，价格指数偶尔是 I(2)。这个阶数很重要：协整分析要求两个变量同阶单整，ARIMA 里的 d 就是这个单整阶数。

## 8. 速记卡

- ADF原假设=有单位根=非平稳
- p<0.05=平稳；p>0.05=非平稳
- I(0)=平稳；I(1)=差分一次平稳；I(2)=差分两次平稳
- 一句话口诀：**p小就平稳，p大就有根**
