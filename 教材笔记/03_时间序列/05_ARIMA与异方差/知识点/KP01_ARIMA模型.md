## 1. 是什么

**ARIMA(p,d,q)**（自回归积分移动平均模型）：将非平稳序列经过d阶差分转化为平稳序列后，对平稳序列拟合[[KP03_ARMA模型|ARMA]](p,q)模型。

$$\Phi(B)\nabla^d x_t = \Theta(B)\varepsilon_t$$

其中$\nabla^d = (1-B)^d$为d阶差分算子。

**直觉类比**：ARIMA像给"倾斜的桌面"先"校平"（差分），再在平桌上玩"台球"（ARMA建模）。原序列有趋势是因为桌面倾斜，差分就是把桌面弄平。

**解决什么问题**：对含有趋势的非平稳序列进行建模和预测。

## 2. 怎么用

### 完整步骤（ARIMA建模五步法）

1. **差分平稳化**：对非平稳序列做差分，直到差分后序列平稳
2. **模型定阶**：根据[[KP02_自协方差与ACF|ACF]]/[[KP04_PACF偏自相关|PACF]]或auto.arima()确定p和q
3. **参数估计**：用极大似然或最小二乘估计系数
4. **模型检验**：残差白噪声检验（Ljung-Box），若残差非白噪声则重定阶
5. **预测**：用通过检验的ARIMA模型做未来预测

### 关键公式

**差分算子**：
- 一阶差分：$\nabla x_t = x_t - x_{t-1} = (1-B)x_t$
- 二阶差分：$\nabla^2 x_t = \nabla x_t - \nabla x_{t-1} = x_t - 2x_{t-1} + x_{t-2}$

**ARIMA(p,d,q)展开**：
$$(1-\phi_1 B - \cdots - \phi_p B^p)(1-B)^d x_t = (1+\theta_1 B + \cdots + \theta_q B^q)\varepsilon_t$$

### R代码

```r
# ========== ARIMA完整建模流程 ==========
library(forecast)

# 目的：中国纱年产量序列ARIMA建模
x <- ts(c(97,130,156.5,135.2,137.7,180.5,205.2,190,188.6,196.7,
          180.3,210.8,196,223,238.2,263.5,292.6,317,335.4,327,
          321.9,353.5,397.8,436.8,465.7,476.7,462.6,460.8,501.8,501.5,
          489.5,542.3,512.2,559.8,542,567), start=1964)

# 第一步：看时序图判断是否非平稳
tsdisplay(x)  # 时序图+ACF+PACF三合一，有明显趋势→非平稳

# 第二步：差分并判断差分阶数
x.diff1 <- diff(x)   # 一阶差分
tsdisplay(x.diff1)   # 看一阶差分后是否平稳（ACF快速衰减到0）

# 第三步：自动定阶（最省事的方式）
x.fit <- auto.arima(x, trace=TRUE)  # trace=TRUE显示所有搜索过的模型
# 自动选择最佳p,d,q组合，基于AIC最小
summary(x.fit)

# 手动定阶方式（教学用）：
# 根据ACF截尾定q，PACF截尾定p
# 若ACF q阶截尾，PACF p阶截尾→ARMA(p,q)

# 第四步：残差白噪声检验
checkresiduals(x.fit)  # 自动画残差图+ACF+Ljung-Box检验
# p值>0.05→残差为白噪声→模型充分
# p值<0.05→残差还有信息→重定阶

# 第五步：预测
x.fore <- forecast(x.fit, h=10)  # 预测未来10期
plot(x.fore)
```

### 计算演示

**差分计算**：原序列$x_t = 10, 12, 15, 19, 24$（线性增长趋势）
- 一阶差分：$\nabla x_t = x_t - x_{t-1} = 2, 3, 4, 5$（仍有递增→不平稳）
- 二阶差分：$\nabla^2 x_t = \nabla x_t - \nabla x_{t-1} = 1, 1, 1$（常数→平稳！）

**ARIMA(0,1,1)预测**：$x_t = x_{t-1} + \varepsilon_t + \theta\varepsilon_{t-1}$
- 设$\theta=0.5$，当前$x_T=100$，$\varepsilon_T=2$
- 1期预测：$\hat{x}_{T+1} = x_T + \theta\varepsilon_T = 100 + 0.5\times2 = 101$
- 2期预测：$\hat{x}_{T+2} = \hat{x}_{T+1}$（因为更远期的不可观测）

## 3. 什么时候用

- **数据条件**：序列非平稳，但差分后平稳（即序列是d阶单整的）
- **典型场景**：
  - 有线性趋势的年销售额
  - 有增长趋势的宏观经济指标（GDP、CPI）
  - 带漂移的金融价格序列
- **前提假设**：
  - 差分后序列平稳
  - 残差$\varepsilon_t$为白噪声
  - 自回归特征根在单位圆外（[[02_平稳性|平稳性]]条件）

## 4. 什么时候不能用/易错点

- **过差分**：已经平稳的序列再差分，方差增大、模型变差
- **d太大**：实际中d通常≤2，d>2几乎不出现
- **把季节性当成普通趋势**：有季节效应的序列需要SARIMA，不能只用普通ARIMA
- **残差不白噪声就直接预测**：残差非白噪声说明模型不充分，预测不可靠
- **常见错误**：不看时序图就盲目auto.arima()，可能选错差分阶数

## 5. 与相似方法对比表

| 方法 | 适用序列 | 差分需求 | 核心结构 | 预测精度 |
|------|----------|----------|----------|----------|
| ARMA(p,q) | 平稳序列 | 不需要 | AR+MA | 中 |
| ARIMA(p,d,q) | 非平稳但差分后平稳 | d阶差分 | ARMA on diff | 高（趋势序列） |
| 趋势拟合 | 有确定性趋势 | 不需要 | 回归模型 | 高（线性趋势） |
| Holt指数平滑 | 有线性趋势 | 不需要 | 水平+趋势平滑 | 中 |
| SARIMA | 非平稳+季节 | d+D阶差分 | ARIMA+季节ARMA | 高（季节序列） |

## 6. 为什么用这个不用那个

- **为什么用差分而不是直接拟合趋势？** 差分不需要预先知道趋势的函数形式（线性/二次/指数），是"数据驱动"的平稳化方法。而趋势拟合需要指定函数形式。
- **为什么不用指数平滑？** 指数平滑是确定性方法，不能提取残差中的[[03_自相关|自相关]]结构。ARIMA能同时提取趋势和随机自相关信息。

## 7. 完整例子

**书中原例（5.2节）**：1962-1991年中国纱年产量
- 时序图：明显线性递增趋势 → 非平稳
- 一阶差分后：时序图在常数附近波动 → 平稳
- 定阶：ACF拖尾、PACF 1阶截尾 → AR(1)
- 模型：ARIMA(1,1,0)
- 预测：未来几年纱产量继续增长，但增速放缓

**生活实例**：奶茶店月销量（有增长趋势）
- 背景：奶茶店月销量逐年增长，但增长速度不固定
- 第一步：画时序图→看到明显上升趋势→非平稳
- 第二步：做一阶差分→差分后在0附近波动→平稳
- 第三步：auto.arima()自动定阶→假设选出ARIMA(1,1,0)
- 第四步：残差检验→p>0.05→白噪声→模型充分
- 第五步：预测下个月销量→在当前基础上加上趋势延续

## 答辩常问（带标准答案）

1. **问：ARIMA(p,d,q) 里 d 是什么？怎么定？为什么要差分？** 答：$d$ 是把原序列变成平稳序列所需的差分阶数，差分算子 $\nabla x_t=x_t-x_{t-1}$，二阶差分 $\nabla^2x_t=x_t-2x_{t-1}+x_{t-2}$。定 $d$ 的办法是逐阶差分后画时序图和 ACF：一阶差分后 ACF 快速衰减到 0、序列在常数附近波动就取 $d=1$；常见的趋势序列一阶差分即平稳，实际中 $d$ 一般不超过 2。差分的目的是把非平稳的趋势"消掉"，让序列满足 ARMA 建模要求的平稳性。注意不要过差分——已经平稳的序列再差分会人为放大方差、降低预测精度。
2. **问：为什么不直接用线性回归提趋势，而要用差分？** 答：线性趋势拟合必须事先指定函数形式（直线、抛物线还是指数曲线），形式选错就整个拟合错误；差分是数据驱动的，不需要事先知道趋势长什么样，一阶差分消线性趋势、二阶差分消二次趋势，自动把趋势去掉。代价是差分后趋势项的经济解释不如回归系数直观，所以要"可解释"用回归，要"稳健"用差分。
3. **问：ARIMA 建模完整步骤是什么？怎么判断模型合不合格？** 答：①差分平稳化（试 $d=0,1,2$ 直到平稳）；②对差分后序列按 ACF/PACF 截尾拖尾定 $p,q$，或用 `auto.arima()` 按 AIC 最小自动搜索；③极大似然估计参数；④检验——残差做 Ljung-Box 检验 p 值要 $>0.05$（残差白噪声、信息提干净了），且各参数 t 检验显著；⑤预测。残差 p 值 $<0.05$ 说明还有自相关没提完，要退回重新定阶；有季节效应的序列不能用普通 ARIMA，要上 SARIMA。

## 8. 速记卡

- ARIMA = AR + I + MA：自回归 + 差分积分 + 移动平均
- d = 需要几次差分才能平稳
- auto.arima()一键搞定：选d、选p、选q、验残差
- 残差必须是白噪声，否则模型不及格
- 一句话口诀：**先差分再建模，残差白噪声才算数**
