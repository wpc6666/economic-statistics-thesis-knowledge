## 1. 是什么

**残差自回归**：先用确定性方法（趋势拟合、季节调整）提取序列的确定性信息，再对残差序列做[[KP03_ARMA模型|ARMA]]建模，提取残差中残存的[[03_自相关|自相关]]信息。

**直觉类比**：先用橡皮擦把大的笔迹擦掉（确定性趋势），再用放大镜看纸上还残留什么笔迹（残差中的自相关）。

**解决什么问题**：确定性方法（如线性回归）的残差通常不是白噪声，还有自相关信息可以提取。

## 2. 怎么用

### 完整步骤

1. **确定性拟合**：用lm()或nls()提取趋势/季节
2. **残差检验**：画残差[[KP02_自协方差与ACF|ACF]]/[[KP04_PACF偏自相关|PACF]]，看是否自相关
3. **残差ARMA定阶**：对残差序列用ACF/PACF定阶
4. **残差建模**：对残差拟合ARMA(p,q)
5. **组合预测**：确定性预测 + 残差ARMA预测

### 关键公式

**残差自回归模型**：
$$x_t = f(t) + \varepsilon_t$$
$$\varepsilon_t = \phi_1 \varepsilon_{t-1} + \cdots + \phi_p \varepsilon_{t-p} + a_t$$

其中$f(t)$是确定性趋势函数，$a_t$是白噪声。

### R代码

```r
# ========== 残差自回归完整流程 ==========
# 目的：对有趋势的序列先回归再对残差建ARMA

# 第一步：读入数据并做确定性趋势拟合
t <- 1:100
x <- 2 + 0.5*t + arima.sim(n=100, list(ar=0.7), sd=1)  # 趋势+AR(1)残差

# 第二步：线性回归提取趋势
trend_fit <- lm(x ~ t)
summary(trend_fit)
resid <- residuals(trend_fit)  # 提取残差

# 第三步：检验残差是否自相关
tsdisplay(resid)  # ACF如果拖尾→残差有自相关
Box.test(resid, type="Ljung-Box", lag=10)  # p<0.05→显著自相关

# 第四步：对残差拟合ARMA模型
resid_fit <- auto.arima(resid)  # 自动定阶残差ARMA
summary(resid_fit)
checkresiduals(resid_fit)  # 检验残差的残差是否白噪声

# 第五步：组合预测
# 确定性部分预测：2 + 0.5 * (101:110)
# 残差部分预测：resid_fit预测值
combined_forecast <- predict(trend_fit, newdata=data.frame(t=101:110)) + 
                      forecast(resid_fit, h=10)$mean
```

### 计算演示

**简单例子**：
- 回归模型：$x_t = 10 + 0.5t + \varepsilon_t$
- 残差AR(1)：$\varepsilon_t = 0.8\varepsilon_{t-1} + a_t$
- 已知$\varepsilon_{100} = 2$
- 预测$x_{101}$：
  - 趋势预测：$10 + 0.5 \times 101 = 60.5$
  - 残差预测：$0.8 \times 2 = 1.6$
  - 总预测：$60.5 + 1.6 = 62.1$

## 3. 什么时候用

- **数据条件**：序列有明显确定性趋势，但回归残差不是白噪声
- **典型场景**：
  - 线性回归后残差ACF显著
  - 季节调整后残差仍有自相关
  - 需要提高预测精度的实际业务问题

## 4. 什么时候不能用/易错点

- **残差已经是白噪声**：如果Box检验p>0.05，残差没有自相关，不需要再建ARMA
- **过度拟合**：对残差过度定阶会引入噪声
- **常见错误**：不检验残差就直接建ARMA，浪费时间

## 5. 与相似方法对比表

| 方法 | 步骤 | 适用场景 | 优点 | 缺点 |
|------|------|----------|------|------|
| 纯回归 | 只拟合趋势 | 残差白噪声 | 简单 | 残差有信息时精度低 |
| 纯[[KP01_ARIMA模型|ARIMA]] | 差分+ARMA | 无明显确定性趋势 | 统计完整 | 趋势解释性差 |
| 残差自回归 | 回归+残差ARMA | 有趋势+残差自相关 | 结合两者优点 | 两步估计效率可能不最优 |

## 6. 为什么用这个不用那个

- **为什么不直接用ARIMA？** 残差自回归保留了趋势的解释性（"每年增长多少"），同时提取了残差的统计信息。
- **为什么不只用回归？** 回归残差如果自相关，预测精度会损失。

## 7. 完整例子

**书中原例（5.4节）**：社会消费品零售总额序列
- 第一步：拟合线性趋势 $\hat{x}_t = a + bt$
- 第二步：残差ACF显示1阶自相关显著
- 第三步：对残差拟合AR(1)：$\varepsilon_t = \phi_1 \varepsilon_{t-1} + a_t$
- 第四步：组合[[KP05_模型预测|模型预测]]精度显著提升

## 答辩常问（带标准答案）

1. **问：残差自回归模型的思路是什么？为什么回归之后还要对残差建模？** 答：这是一个"两步走"模型：先用确定性方法（线性/非线性趋势回归、季节调整）把序列写成 $x_t=f(t)+\varepsilon_t$，再检查回归残差 $\varepsilon_t$。如果残差不是白噪声（LB 检验 $p<0.05$、ACF 拖尾），说明回归只提取了趋势，残差里还残留自相关信息，于是对残差再拟合 ARMA $\varepsilon_t=\sum\phi_i\varepsilon_{t-i}+a_t$。最终预测 = 趋势部分预测 $f(t)$ + 残差 ARMA 预测。它的好处是既保留了回归系数的解释性（"每年增长多少"），又把残差里的预测信息榨干。
2. **问：怎么判断回归残差需不需要再建 ARMA？** 答：先对残差画 ACF/PACF 并做 Ljung-Box 检验。如果 LB 检验 p 值 $>0.05$，残差就是白噪声，回归已经足够，再建模就是画蛇添足、过拟合；如果 p 值 $<0.05$ 且 ACF 拖尾，说明残差有自相关，才需要对残差定阶拟合 ARMA。关键是不能跳过这个检验直接建模。
3. **问：残差自回归和直接用 ARIMA 有什么区别？** 答：ARIMA 用差分消趋势，差分后的模型里没有可解释的趋势系数；残差自回归用回归显式建趋势 $f(t)$，系数 $b$ 可以直接读成"每期增长多少"，解释性强。代价是两步估计（先回归再建残差 ARMA）不是联合极大似然，统计效率上不是最优；但实务上对"既要解释趋势、又要提高预测精度"的问题，这是很常用的折中方案。

## 8. 速记卡

- 先拆后建：趋势归回归，残差归ARMA
- Box检验p<0.05→残差有料→值得建ARMA
- 预测 = 趋势预测 + 残差ARMA预测
- 一句话口诀：**回归留趋势，残差补随机**
