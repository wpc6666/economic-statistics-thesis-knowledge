# KP04 ARCH模型

## 1. 是什么

**ARCH(q)**（自回归条件[[02_异方差|异方差]]模型）：模型化金融时间序列中常见的"波动率聚集"现象——大波动后跟着大波动，小波动后跟着小波动。

$$\varepsilon_t = \sqrt{h_t} e_t$$
$$h_t = \omega + \sum_{j=1}^{q}\lambda_j \varepsilon_{t-j}^2$$

其中$h_t$是条件方差（随时间变化的方差），$e_t$是独立同分布白噪声。

**直觉类比**：ARCH像金融市场的"情绪放大器"——昨天大跌2%，今天市场恐慌，波动加大；昨天平稳，今天市场淡定，波动收窄。波动率不是常数，而是"[[03_自相关|自相关]]"的。

**解决什么问题**：对具有集群波动特征的金融收益率序列建模，给出随时间变化的置信区间。

## 2. 怎么用

### 完整步骤

1. **拟合均值模型**：先用[[KP01_ARIMA模型|ARIMA]]或回归提取水平信息，得到残差$\varepsilon_t$
2. **ARCH效应检验**：
   - LM检验（拉格朗日乘子检验）
   - 残差平方的Q检验（Box-Ljung on $\varepsilon_t^2$）
3. **定阶q**：根据[[KP02_自协方差与ACF|ACF]]($\varepsilon_t^2$)截尾阶数或AIC
4. **估计参数**：用极大似然估计$\omega, \lambda_1, \cdots, \lambda_q$
5. **检验残差**：[[KP11_标准化_ZScore|标准化]]残差$e_t = \varepsilon_t/\sqrt{h_t}$应为白噪声

### 关键公式

**ARCH(q)条件方差**：
$$\text{Var}(\varepsilon_t | \varepsilon_{t-1}, \cdots) = h_t = \omega + \lambda_1 \varepsilon_{t-1}^2 + \cdots + \lambda_q \varepsilon_{t-q}^2$$

**参数约束**：
- $\omega > 0$（常数项非负）
- $\lambda_j \geq 0$（确保条件方差非负）
- $\sum \lambda_j < 1$（确保无条件方差有限）

### R代码

```r
# ========== ARCH模型完整流程 ==========
library(forecast)
library(rugarch)  # garchFit在fGarch包中

# 目的：价值加权月度收益率序列的ARCH建模

# 第一步：拟合均值模型（先提取水平信息）
x <- c(0.05, -0.03, 0.02, 0.08, -0.06, 0.01, -0.04, 0.03,
       -0.02, 0.06, -0.05, 0.04, 0.07, -0.08, 0.01, -0.03)
x.fit <- auto.arima(x)  # 先建均值模型
resid <- residuals(x.fit)

# 第二步：ARCH效应检验
# 方法1：残差平方的Ljung-Box检验
for(i in 1:6) print(Box.test(resid^2, type="Ljung-Box", lag=i))
# p<0.05→残差平方自相关→有ARCH效应

# 方法2：LM检验
library(FinTS)
ArchTest(resid, lag=6)  # p<0.05→显著ARCH效应

# 第三步：拟合ARCH(q)模型
spec <- ugarchspec(
  mean.model = list(armaOrder=c(0,0)),  # 均值部分
  variance.model = list(model="sGARCH", garchOrder=c(1,0))  # (p,q)，q=阶数
)
# garchOrder=c(1,0)表示ARCH(1)，c(2,0)表示ARCH(2)
fit <- ugarchfit(spec=spec, data=x)
show(fit)

# 第四步：查看条件波动率
vol <- sigma(fit)  # 提取条件波动率序列
plot(vol, main="条件波动率（ARCH拟合）")

# 第五步：预测
fore <- ugarchforecast(fit, n.ahead=10)
plot(fore)
```

### 计算演示

**ARCH(1)计算**：
- 设$h_t = 0.01 + 0.3\varepsilon_{t-1}^2$
- 已知$\varepsilon_{t-1} = 0.2$（大波动）
- 今天条件方差：$h_t = 0.01 + 0.3 \times 0.2^2 = 0.01 + 0.012 = 0.022$
- 今天条件标准差：$\sqrt{0.022} = 0.148$

对比：昨天$\varepsilon_{t-2}=0.05$（小波动）
- $h_{t-1} = 0.01 + 0.3 \times 0.05^2 = 0.01 + 0.00075 = 0.01075$
- 结论：大波动后今天的条件方差(0.022)是小波动后(0.01075)的2倍——波动率聚集！

## 3. 什么时候用

- **数据条件**：金融收益率序列，且残差平方显著自相关
- **典型场景**：
  - 股票日收益率
  - 汇率变动率
  - 加密货币价格波动
- **前提假设**：
  - 均值模型残差为零均值纯随机序列
  - 残差平方序列存在自相关（ARCH效应）

## 4. 什么时候不能用/易错点

- **没有ARCH效应**：如果LM检验p>0.05，不需要ARCH模型
- **q阶数太大**：ARCH(q)的q通常需要很大才能捕捉长期波动，参数估计困难
- **参数非负约束**：拟合时必须确保$\lambda_j \geq 0$
- **常见错误**：不先做ARCH效应检验就直接拟合模型，浪费计算

## 5. 与相似方法对比表

| 方法 | 波动率模型 | 适用场景 | 参数数 | 长期波动率 |
|------|-----------|----------|--------|-----------|
| 常数方差 | $\sigma^2 = \omega$ | 无ARCH效应 | 1 | 无记忆 |
| ARCH(q) | $h_t = \omega + \sum\lambda_j\varepsilon_{t-j}^2$ | 短期波动率聚集 | q+1 | 仅q期记忆 |
| [[KP05_GARCH模型|GARCH]](p,q) | $h_t = \omega + \sum\eta_i h_{t-i} + \sum\lambda_j\varepsilon_{t-j}^2$ | 长期波动率聚集 | p+q+1 | 长期记忆 |

## 6. 为什么用这个不用那个

- **为什么用ARCH而不只用常数方差？** 金融收益率的波动率不是常数，"平静期"和"动荡期"交替出现。常数方差会高估平静期、低估动荡期的风险。
- **ARCH的局限**：需要很大的q才能捕捉长期波动，参数太多。这就是GARCH被提出的原因。

## 7. 完整例子

**书中原例（例5-12）**：S&P500价值加权月度收益率
- LM检验显著→有ARCH效应
- 尝试ARCH(5)、ARCH(4)都有参数不显著
- 最终拟合ARCH(3)：
$$h_t = 0.001437 + 0.07954\varepsilon_{t-1}^2 + 0.2231\varepsilon_{t-2}^2 + 0.2732\varepsilon_{t-3}^2$$
- 条件异方差置信区间比无条件平行线更好地拟合了集群波动特征

**生活实例**：比特币日收益率
- 背景：比特币价格暴涨暴跌，波动率聚集明显
- 应用：用ARCH(1)模型估计今天的风险价值(VaR)
- 昨天跌了10%→今天条件方差增大→95%置信区间变宽→风险预警

## 答辩常问（带标准答案）

1. **问：ARCH 模型解决什么问题？它和 ARIMA 关心的东西有什么不同？** 答：ARIMA 建模的是序列的"水平"（条件均值），并且假设残差方差是常数。但金融收益率有典型的"波动率聚集"现象——大波动后面跟着大波动、小波动后面跟着小波动，方差随时间变化（条件异方差）。ARCH(q) 专门给条件方差 $h_t=\mathrm{Var}(\varepsilon_t|\text{历史})$ 建模：$h_t=\omega+\sum_{j=1}^{q}\lambda_j\varepsilon_{t-j}^2$。它不预测明天涨跌，而是预测明天的风险有多大、置信区间该多宽，是 VaR 和期权定价的基础。
2. **问：怎么判断一个序列需不需要 ARCH 模型？** 答：不能凭图感觉，要先检验 ARCH 效应。第一步先用 ARIMA/回归把均值模型建好，拿到残差 $\varepsilon_t$；第二步对残差平方 $\varepsilon_t^2$ 做 Ljung-Box 检验，或直接用 LM 检验（`ArchTest(resid, lag=6)`）。原假设是"残差平方没有自相关、即不存在 ARCH 效应"，p 值 $<0.05$ 拒绝原假设、说明有波动率聚集，才需要上 ARCH/GARCH；p 值 $>0.05$ 就用常数方差即可。
3. **问：ARCH(q) 的参数有什么约束？为什么 $\sum\lambda_j<1$？** 答：三个约束：$\omega>0$、各 $\lambda_j\ge 0$（保证条件方差 $h_t$ 永不为负）、$\sum_{j=1}^{q}\lambda_j<1$。最后一个是为了让无条件方差有限——$E(h_t)=\omega/(1-\sum\lambda_j)$，如果 $\sum\lambda_j\ge 1$，无条件方差无穷大，序列的波动没有回归中心，模型不平稳。

## 8. 速记卡

- ARCH = 波动率自相关 = 大波动跟着大波动
- $h_t$是条件方差，随昨天的残差平方变化
- 先检验ARCH效应（LM/Q检验），再定阶拟合
- 一句话口诀：**波动会传染，ARCH来建模**
