## 1. 是什么

**SARIMA$(p,d,q)(P,D,Q)_s$**（季节ARIMA模型）：在普通ARIMA基础上，增加季节周期长度$s$对应的季节自回归和季节移动平均结构。

$$\Phi_P(B^s)\phi_p(B)(1-B^s)^D(1-B)^d x_t = \Theta_Q(B^s)\theta_q(B)\varepsilon_t$$

- 小写$p,d,q$：普通差分和[[KP03_ARMA模型|ARMA]]阶数
- 大写$P,D,Q$：季节差分和季节ARMA阶数
- $s$：季节周期长度（月度=12，季度=4）

**直觉类比**：普通ARIMA处理"短期记忆"，季节SARIMA处理"每年同期的长期记忆"——今年7月的销量不仅和上个月有关，还和去年7月有关。

**解决什么问题**：同时提取趋势、短期[[03_自相关|自相关]]和季节周期效应。

## 2. 怎么用

### 完整步骤

1. **确定周期$ s $**：根据数据频率（月度=12，季度=4）
2. **普通差分$ d $**：提取非季节趋势
3. **季节差分$ D $**：$\nabla_s x_t = x_t - x_{t-s}$，提取季节趋势
4. **定阶普通$ p,q $**：看短期[[KP02_自协方差与ACF|ACF]]/[[KP04_PACF偏自相关|PACF]]
5. **定阶季节$ P,Q $**：看滞后$s, 2s, \cdots$处的ACF/PACF
6. **估计检验预测**：同普通ARIMA流程

### 关键公式

**季节差分**：
$$\nabla_s x_t = x_t - x_{t-s}$$
例如月度数据$s=12$：$\nabla_{12} x_t = x_t - x_{t-12}$

**季节ARMA**：
- 季节AR(P)：$\Phi_P(B^s) = 1 - \phi_1 B^s - \cdots - \phi_P B^{Ps}$
- 季节MA(Q)：$\Theta_Q(B^s) = 1 + \theta_1 B^s + \cdots + \theta_Q B^{Qs}$

### R代码

```r
# ========== SARIMA季节模型 ==========
library(forecast)

# 目的：澳大利亚葡萄酒月度销售数据
x <- wineind  # 月度数据，周期s=12

# 方法1：auto.arima自动选择季节阶数
x.fit <- auto.arima(x, seasonal=TRUE, trace=TRUE)
# seasonal=TRUE表示允许季节模型
# 自动选择最佳的(p,d,q)(P,D,Q)_12

# 方法2：手动指定SARIMA阶数
# 例如SARIMA(1,1,1)(1,1,1)_12
x.fit2 <- Arima(x, order=c(1,1,1), seasonal=c(1,1,1))
summary(x.fit2)

# 残差检验
checkresiduals(x.fit)

# 预测
x.fore <- forecast(x.fit, h=24)  # 预测未来24个月
plot(x.fore)
```

### 计算演示

**季节差分计算**：月度数据，去年7月销量=500，今年7月销量=600
- 季节差分：$\nabla_{12} x_{今年7月} = 600 - 500 = 100$
- 含义：今年7月比去年7月多卖100杯（同比增长）

**对比普通差分**：今年6月销量=550，今年7月=600
- 普通差分：$\nabla x = 600 - 550 = 50$（环比增长）

## 3. 什么时候用

- **数据条件**：有明显季节周期，且周期长度已知
- **典型场景**：
  - 月度销售额（周期12）
  - 季度GDP（周期4）
  - 周度客流量（周期7）
- **前提假设**：季节模式相对稳定，每年同期波动方向一致

## 4. 什么时候不能用/易错点

- **周期不确定**：如果季节效应不规律，SARIMA效果差
- **D太大**：通常D=1足够，D>1罕见
- **季节和普通差分混淆**：
  - 普通差分提取"短期趋势"
  - 季节差分提取"季节同比趋势"
  - 两者都需要时要同时做
- **样本量不足**：SARIMA参数多，至少需要2-3个完整周期的数据

## 5. 与相似方法对比表

| 方法 | 季节处理方式 | 适用场景 | 参数多少 | 预测精度 |
|------|-------------|----------|----------|----------|
| 普通ARIMA | 不处理季节 | 无季节效应 | 少 | 季节序列误差大 |
| Holt-Winters | 平滑提取季节 | 有趋势有季节 | 3个平滑系数 | 中等 |
| SARIMA | 统计建模季节 | 有趋势有季节 | p,d,q,P,D,Q | 高（统计结构） |
| 季节调整+ARIMA | 先去季节再建模 | 只关心趋势 | 两步法 | 中等 |

## 6. 为什么用这个不用那个

- **为什么不用Holt-Winters而用SARIMA？** SARIMA能提取季节滞后的自相关结构（如今年7月和去年7月的关系），而Holt-Winters只是平滑季节指数。
- **为什么不先做季节调整再用普通ARIMA？** 两步法会损失信息——季节调整后的残差可能仍然有季节自相关。

## 7. 完整例子

**生活实例**：空调月度销量预测
- 背景：某品牌空调2010-2023年月度销量，每年夏季旺季、冬季淡季，整体逐年增长
- 分析：
  1. 普通差分：提取逐年增长趋势
  2. 季节差分：消除"每年夏天都是旺季"的固定周期
  3. 短期ARMA：提取月度间的短期波动
- 最终模型：SARIMA(1,1,1)(1,1,1)_12
- 预测：明年每月销量，包含夏季旺季预测

## 答辩常问（带标准答案）

1. **问：SARIMA$(p,d,q)(P,D,Q)_s$ 中大小写参数各管什么？$s$ 怎么取？** 答：小写 $p,d,q$ 管"近邻"——普通 AR 阶数、普通差分阶数、普通 MA 阶数；大写 $P,D,Q$ 管"同期"——季节 AR 阶数、季节差分阶数、季节 MA 阶数；$s$ 是季节周期长度，月度数据取 12、季度取 4、周度取 7。季节差分是 $\nabla_s x_t=x_t-x_{t-s}$（月度数据就是今年同月减去年同月，即同比），它和普通差分 $\nabla x_t=x_t-x_{t-1}$（环比）是两回事，趋势和季节都有时要两个一起做。
2. **问：什么样的数据该上 SARIMA 而不是普通 ARIMA？** 答：只要序列有固定季节周期——月度数据看 ACF 在滞后 12、24 阶处有显著峰值，季度数据看滞后 4、8 阶——就说明"今年 7 月和去年 7 月相关"这种季节性自相关存在，普通 ARIMA 抓不到，必须用 SARIMA。判断标志：`auto.arima(x, seasonal=TRUE)` 自动选出的 $D$ 不为 0、或季节项 $(P,Q)$ 显著。样本上要求至少 2–3 个完整周期的数据，否则季节参数估不准。
3. **问：SARIMA 和 Holt-Winters 指数滑都能处理季节，选哪个？** 答：Holt-Winters 是确定性平滑，季节因子只是被平滑出来的一个常数倍数，不建模季节滞后之间的统计关系；SARIMA 是统计模型，能刻画"今年 7 月销量和去年 7 月销量之间的自相关结构"，并能给出 AIC 比较和残差检验，预测区间也更规范。事后做历史分解、看季节贡献用 Holt-Winters 或 `decompose`；要做严谨的统计预测建模就用 SARIMA。

## 8. 速记卡

- SARIMA = 普通ARIMA + 季节ARIMA
- 小写管"近邻"，大写管"同期"
- 月度s=12，季度s=4
- 一句话口诀：**短期趋势普通差，每年同期季节差**
