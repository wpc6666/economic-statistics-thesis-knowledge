# KP05 GARCH模型

## 1. 是什么

**GARCH(p,q)**（广义自回归条件[[02_异方差|异方差]]模型）：在ARCH(q)基础上，增加条件方差本身的自回归项，用更少参数捕捉长期波动率聚集。

$$\varepsilon_t = \sqrt{h_t} e_t$$
$$h_t = \omega + \sum_{i=1}^{p}\eta_i h_{t-i} + \sum_{j=1}^{q}\lambda_j \varepsilon_{t-j}^2$$

- 第一项$\omega$：常数基准方差
- 第二项$\sum\eta_i h_{t-i}$：条件方差的自回归（GARCH项）
- 第三项$\sum\lambda_j\varepsilon_{t-j}^2$：残差平方的移动平均（ARCH项）

**直觉类比**：ARCH只看"最近几天的残差"预测今天波动；GARCH像"最近几天的波动本身有惯性"——波动率有记忆，不会一夜突变。

**解决什么问题**：解决ARCH(q)需要很大q阶数才能拟合长期波动率的问题。

## 2. 怎么用

### 完整步骤

1. **拟合均值模型**：[[KP01_ARIMA模型|ARIMA]]/回归得到残差$\varepsilon_t$
2. **ARCH效应检验**：LM检验或Q检验
3. **选择GARCH阶数**：常用GARCH(1,1)（90%以上的金融数据用它就够了）
4. **估计参数**：极大似然估计
5. **诊断检验**：[[KP11_标准化_ZScore|标准化]]残差$e_t = \varepsilon_t/\sqrt{h_t}$应为白噪声，残差平方应为白噪声

### 关键公式

**GARCH(1,1)**（最常用）：
$$h_t = \omega + \eta_1 h_{t-1} + \lambda_1 \varepsilon_{t-1}^2$$

**平稳条件**：$\eta_1 + \lambda_1 < 1$（无条件方差有限）

**参数含义**：
- $\eta_1$：GARCH项系数——波动率的持续性
- $\lambda_1$：ARCH项系数——新冲击对波动率的影响
- $\eta_1 + \lambda_1$：接近1表示波动率冲击持续很久

#### 【三问】为什么 GARCH(1,1) 里要同时放 $h_{t-1}$ 和 $\varepsilon_{t-1}^2$ 两项？

- **怎么来的（直觉推导）**：ARCH(q) 模型 $h_t = \omega + \lambda_1 \varepsilon_{t-1}^2 + \cdots + \lambda_q \varepsilon_{t-q}^2$ 意思是"今天的方差由最近 q 天的残差平方决定"。但金融数据的波动率有**长期记忆**——一次大震荡会持续几十天。要捕捉这种长期记忆，ARCH 得取很大的 q（比如 q=20），参数太多、估计不稳。Bollerslev（1986）想到一个类比：既然水平值 $x_t$ 可以用 AR 模型（自身滞后）来描述，那条件方差 $h_t$ 为什么不能用 AR？于是他在 ARCH 基础上加一项"$h_{t-1}$ 自己的滞后"——这就是 GARCH。$\eta_1 h_{t-1}$ 是"波动率的惯性"，$\lambda_1 \varepsilon_{t-1}^2$ 是"新冲击对波动率的推一下"。两者合起来，GARCH(1,1) 只用 3 个参数就能拟合无限长的波动率记忆。
- **为什么用它**：解决"金融收益率的波动率会聚集"这个现实问题。打开任何股价图，你会看到"平稳期一大段 + 剧烈震荡一大段"交替出现——这叫波动率聚集。常数方差模型假设每天波动都一样，完全错了。GARCH 让 $h_t$（今天的波动）随昨天的波动和昨天的残差大小变化，能很好地刻画这种聚集现象，是计算 VaR（风险价值）、期权定价、投资组合优化的基础。
- **知识为什么存在**：1982 年 Engle 提出 ARCH 模型（拿诺贝尔奖的工作），但 ARCH(q) 在实际应用中 q 要取很大。1986 年 Bollerslev 把 AR 思想引入条件方差，提出 GARCH，只用 (1,1) 阶就搞定了 90% 以上的金融序列。GARCH 的出现让"波动率预测"从玄学变成可计算、可检验的统计模型，今天任何一家投行、基金公司的风险管理部门都在用 GARCH 族模型。

### R代码

```r
# ========== GARCH模型完整流程 ==========
library(rugarch)

# 目的：外币对美元日兑换率的GARCH建模

# 第一步：读入数据并做差分
x <- read.table("exchange_rates.csv", header=TRUE, sep=",")
x <- ts(x$rate, start=c(1979,12,31), frequency=365)

# 第二步：拟合ARIMA提取水平信息
x.fit <- arima(x, order=c(0,1,1))  # 兑换率序列是随机游走+MA(1)
resid <- residuals(x.fit)

# 第三步：ARCH效应检验
for(i in 1:6) print(Box.test(resid^2, type="Ljung-Box", lag=i))
# p<0.001→极强的ARCH效应

# 第四步：拟合GARCH(1,1)（最常用）
spec <- ugarchspec(
  mean.model = list(armaOrder=c(0,0)),  # 均值部分已是白噪声
  variance.model = list(model="sGARCH", garchOrder=c(1,1))  # GARCH(1,1)
)
fit <- ugarchfit(spec=spec, data=resid)
show(fit)
# 输出：omega, alpha1(ARCH项), beta1(GARCH项)

# 第五步：查看条件波动率
vol <- sigma(fit)
plot(vol, main="GARCH(1,1)条件波动率")

# 第六步：预测
fore <- ugarchforecast(fit, n.ahead=30)
plot(fore)
```

### 计算演示

**GARCH(1,1)计算**：
- 设$h_t = 0.01 + 0.8 h_{t-1} + 0.15 \varepsilon_{t-1}^2$
- 已知$h_{t-1} = 0.02$，$\varepsilon_{t-1} = 0.1$
- 今天条件方差：
  $$h_t = 0.01 + 0.8 \times 0.02 + 0.15 \times 0.1^2$$
  $$= 0.01 + 0.016 + 0.0015 = 0.0275$$

**对比ARCH(1)**：
- ARCH(1)：$h_t = 0.01 + 0.3 \times 0.1^2 = 0.013$
- GARCH(1,1)：$h_t = 0.0275$（因为波动率有惯性，昨天的$h_{t-1}=0.02$也贡献了）

**持续性**：$\eta_1 + \lambda_1 = 0.8 + 0.15 = 0.95$，接近1——波动率冲击会持续很久才衰减

## 3. 什么时候用

- **数据条件**：金融收益率序列，残差平方有长期[[03_自相关|自相关]]
- **典型场景**：
  - 股票/外汇/加密货币日收益率
  - 任何波动率聚集明显的金融时间序列
- **前提假设**：
  - 均值模型残差为零均值纯随机
  - $\eta_i \geq 0, \lambda_j \geq 0$（条件方差非负）
  - $\sum\eta_i + \sum\lambda_j < 1$（无条件方差有限）

## 4. 什么时候不能用/易错点

- **无ARCH效应**：不需要GARCH，用常数方差即可
- **过度复杂**：GARCH(1,1)通常足够，(p,q)大于(1,1)罕见
- **参数和>1**：若$\eta_1 + \lambda_1 \geq 1$，为IGARCH（积分GARCH），波动率不衰减
- **常见错误**：不先拟合均值模型就直接对原序列建GARCH

## 5. 与相似方法对比表

| 模型 | 条件方差公式 | 参数数 | 波动率记忆 | 适用场景 |
|------|-------------|--------|-----------|----------|
| ARCH(q) | $h_t = \omega + \sum_{j=1}^{q}\lambda_j\varepsilon_{t-j}^2$ | q+1 | 短期（q期） | 短期波动率聚集 |
| GARCH(p,q) | $h_t = \omega + \sum_{i=1}^{p}\eta_i h_{t-i} + \sum_{j=1}^{q}\lambda_j\varepsilon_{t-j}^2$ | p+q+1 | 长期（无限） | 长期波动率聚集 |
| GARCH(1,1) | $h_t = \omega + \eta_1 h_{t-1} + \lambda_1\varepsilon_{t-1}^2$ | 3 | 长期 | 90%金融数据首选 |
| EGARCH | 非对称GARCH（正负冲击不对称） | 更多 | 长期+非对称 | 杠杆效应（下跌波动更大） |
| IGARCH | $\eta_1 + \lambda_1 = 1$ | 3 | 永久记忆 | 汇率等接近随机游走的波动率 |

## 6. 为什么用这个不用那个

- **为什么用GARCH而不用ARCH？** ARCH需要很大的q才能捕捉长期波动率，GARCH只用p=1,q=1就能达到类似效果，参数更少更稳定。
- **GARCH vs ARCH选择**：
  - 波动率聚集短期（q≤3）→ARCH(q)就够
  - 波动率聚集长期（q需要很大）→GARCH(p,q)
  - 实际中90%以上的金融序列→GARCH(1,1)

## 7. 完整例子

**书中原例（例5-13）**：1979-1991年外币对美元日兑换率
- 差分后拟合ARIMA(0,1,1)
- 残差平方Q检验p值<2.2e-16→极强ARCH效应
- 拟合GARCH(1,1)
- 结果：条件波动率准确刻画了汇率波动的集群特征

**生活实例**：沪深300指数日收益率
- 背景：2020年疫情期间A股波动率飙升，平时较低
- GARCH(1,1)拟合：
  - $\omega$（基准）较小
  - $\eta_1$（持续性）≈0.9——波动率冲击持续很久
  - $\lambda_1$（新冲击）≈0.05——单日暴跌影响有限
- 应用：计算风险价值VaR，设置止损线

## 答辩常问（带标准答案）

1. **问：GARCH 比 ARCH 好在哪？为什么实务中几乎都用 GARCH(1,1)？** 答：ARCH(q) 的 $h_t$ 只由最近 q 期残差平方决定，要刻画金融数据那种持续几十天的波动率记忆，q 必须取很大，参数又多又估不稳。GARCH 在 $h_t$ 方程右边加了条件方差自身的滞后项 $\eta_1 h_{t-1}$，相当于给方差也建了一个 AR：$h_t=\omega+\eta_1 h_{t-1}+\lambda_1\varepsilon_{t-1}^2$。这样 GARCH(1,1) 只用 3 个参数就能表示无限长的波动率记忆，AIC 更优、估计更稳，实务中 90% 以上的金融收益率序列用 GARCH(1,1) 就够了。
2. **问：GARCH(1,1) 的平稳条件是什么？$\eta_1+\lambda_1$ 接近 1 说明什么？** 答：要求参数非负（$\omega>0,\eta_1\ge0,\lambda_1\ge0$）且 $\eta_1+\lambda_1<1$，这是无条件方差 $\omega/(1-\eta_1-\lambda_1)$ 有限的条件。$\eta_1+\lambda_1$ 叫波动率持续性：越接近 1，一次大冲击引发的波动就衰减得越慢、持续越久（金融数据通常在 0.95 以上）；等于 1 时就是 IGARCH，波动率冲击永不衰减、无条件方差无穷。
3. **问：GARCH 里 $\eta_1$ 和 $\lambda_1$ 分别代表什么？** 答：$\lambda_1$（ARCH 项系数）是"新冲击"的权重——今天实际发生了一个多大的意外，会立刻把明天的波动推高多少；$\eta_1$（GARCH 项系数）是"波动率惯性"的权重——即使今天没有新冲击，昨天已经形成的高波动状态本身也会延续。$\eta_1$ 大说明波动有长期惯性，$\lambda_1$ 大说明新消息立刻被市场放大。

## 8. 速记卡

- GARCH(1,1) = 波动率的AR(1) + MA(1)
- $\eta_1 + \lambda_1$ 越接近1，波动冲击持续越久
- 90%金融数据用GARCH(1,1)就够了
- ARCH是GARCH的特例（p=0）
- 一句话口诀：**波动有惯性，GARCH最省心**
