# KP01 Wold与Cramer分解

## 1. 是什么

**Wold分解定理**（1938年）：任何离散平稳过程$\{x_t\}$都可以分解为两个不相关的平稳序列之和——一个确定性序列$\{V_t\}$，一个随机序列$\{\xi_t\}$，其中随机序列是白噪声的无穷线性组合。

$$x_t = V_t + \xi_t, \quad \xi_t = \sum_{j=0}^{\infty}\varphi_j \varepsilon_{t-j}$$

**Cramer分解定理**（1961年）：将Wold思想推广到非平稳序列——任意时间序列都可以分解为多项式决定的确定性趋势成分和平稳的零均值误差成分。

$$x_t = \mu_t + \varepsilon_t = \sum_{j=0}^{d}\beta_j t^j + \Psi(B)a_t$$

**直觉类比**：Wold分解像把一杯浑水静置后分成清水层和沉淀层；Cramer分解则更进一步——即使水本身在随时间变色（非平稳），也能把"变色趋势"和"随机浑浊"分开。

**解决什么问题**：从理论上保证了"先提取确定性趋势，再分析随机残差"这一分析思路的合理性。

## 2. 怎么用

### 完整步骤

1. **判断序列[[02_平稳性|平稳性]]**：平稳序列用Wold分解框架；非平稳序列用Cramer分解框架
2. **提取确定性部分**：趋势拟合、季节调整等
3. **分析随机残差**：对残差序列拟合[[KP03_ARMA模型|ARMA]]模型

### 关键公式

**Wold分解条件**：
- $\varphi_0 = 1$，$\sum_{j=0}^{\infty}\varphi_j^2 < \infty$（平方可和）
- $\{\varepsilon_t\} \sim WN(0, \sigma_\varepsilon^2)$（白噪声）
- $\text{Cov}(V_t, \varepsilon_s) = 0, \forall t \neq s$（两部分不相关）

**确定性 vs 随机性的判别**：
- $\lim_{q\to\infty}\tau_q^2 = 0$ → 确定性序列（历史可完美预测未来）
- $\lim_{q\to\infty}\tau_q^2 = \text{Var}(y_t)$ → 随机序列（历史无法预测未来）

其中$\tau_q^2$是用$q$期历史做线性回归的残差方差。

### R代码

```r
# 目的：验证Wold分解——平稳ARMA序列 = 确定性均值 + 随机波动
set.seed(123)
x <- arima.sim(n=200, list(ar=c(0.8, -0.2)), sd=1)  # 模拟AR(2)平稳序列

# 确定性部分：均值（平稳序列均值为常数）
mu <- mean(x)
cat("确定性均值部分:", round(mu, 4), "\n")

# 随机部分：中心化后的残差（即Wold分解中的xi_t）
xi <- x - mu
plot(x, main="平稳序列 = 确定性均值 + 随机波动")
abline(h=mu, col="red", lwd=2)  # 红线为确定性均值

# Cramer分解验证：对非平稳序列分解趋势+残差
t <- 1:200
y <- 0.05 * t + arima.sim(n=200, list(ar=0.5), sd=2)  # 趋势+ARMA残差
fit <- lm(y ~ t)  # 提取多项式趋势（确定性部分）
trend <- fitted(fit)
resid_eps <- residuals(fit)  # 平稳残差（随机部分）
```

### 计算演示

假设某平稳序列$\{x_t\}$的Wold分解为$x_t = 5 + \varepsilon_t + 0.5\varepsilon_{t-1}$：
- 确定性部分$V_t = 5$（常数均值）
- 随机部分$\xi_t = \varepsilon_t + 0.5\varepsilon_{t-1}$（MA(1)结构）
- 验证$\varphi_0 = 1, \varphi_1 = 0.5$，$\sum\varphi_j^2 = 1 + 0.25 = 1.25 < \infty$ ✓

## 3. 什么时候用

- **理论基础**：任何时间序列分析的第一步都是"分解思维"——把确定性和随机性分开
- **数据条件**：序列足够长（通常>50期），确保分解有意义
- **前提假设**：
  - Wold分解：序列必须平稳（均值、方差、自协方差不随时间变化）
  - Cramer分解：序列的确定性部分可以用多项式逼近

## 4. 什么时候不能用/易错点

- **Wold分解不适用**：非平稳序列不能直接用Wold分解，必须先差分或提取趋势
- **Cramer分解的局限**：多项式阶数$d$必须有限；若序列存在非线性趋势（如指数爆炸），多项式拟合会失败
- **常见错误**：把"确定性序列"理解为"完全没有随机波动"，实际上确定性序列是指历史信息可以完美预测未来

## 5. 与相似方法对比表

| 方法 | 适用序列 | 分解形式 | 核心思想 |
|------|----------|----------|----------|
| Wold分解 | 平稳序列 | 确定性 + 白噪声线性组合 | 平稳序列的随机部分总能表示为白噪声的ARMA形式 |
| Cramer分解 | 任意序列 | 多项式趋势 + 平稳残差 | 非平稳来自多项式趋势或不稳定的随机部分 |
| ARMA建模 | 平稳序列 | 直接拟合ARMA参数 | 不做显式分解，直接估计自回归/移动平均系数 |

## 6. 为什么用这个不用那个

- **为什么需要分解定理？** 因为时序分析的核心逻辑是"先去除确定性信息，再对残差做随机建模"。分解定理从数学上保证了这个流程的合理性。
- **被排除的方法会出什么问题？** 不对序列做分解直接建模，会把趋势误判为[[03_自相关|自相关]]，导致模型严重失拟。

## 7. 完整例子

**书中原例**：ARMA$(p,q)$模型$x_t = \mu + \frac{\Theta(B)}{\Phi(B)}\varepsilon_t$就是Wold分解的具体形式——$\mu$是确定性平稳序列，$\frac{\Theta(B)}{\Phi(B)}\varepsilon_t$是随机平稳序列。

**生活实例**：奶茶店每日销量。假设一年365天数据：
- Wold分解视角：如果销量在均值附近随机波动（平稳），则"日均销量"是确定性部分，"每日偏离"是随机部分
- Cramer分解视角：如果销量逐年增长（非平稳），则"增长趋势"是确定性多项式部分，"逐年波动"是平稳随机残差

计算简单演示：
```
第1天销量 = 100杯，趋势部分 = 95 + 0.1×1 = 95.1，随机残差 = 4.9
第2天销量 = 105杯，趋势部分 = 95 + 0.1×2 = 95.2，随机残差 = 9.8
```
趋势项每期增长0.1杯，残差在0附近随机波动。

## 答辩常问（带标准答案）

1. **问：Wold 分解和 Cramer 分解分别说什么？两者什么关系？** 答：Wold 分解针对平稳序列，证明任何平稳过程都能写成一个确定性成分 $V_t$ 加上一个由白噪声无穷线性组合构成的随机成分 $\xi_t=\sum_{j=0}^{\infty}\varphi_j\varepsilon_{t-j}$（要求 $\sum\varphi_j^2<\infty$，两部分不相关）。Cramer 分解把它推广到非平稳序列：任意序列可分解成一个多项式趋势 $\sum_{j=0}^{d}\beta_jt^j$ 加一个平稳零均值残差。关系上 Cramer 是 Wold 的推广——平稳是 $d=0$ 的特例。这两个定理从理论上保证了"先提取趋势/季节等确定性成分，再对残差拟合 ARMA"这条分析路线是合理的。
2. **问：为什么时序分析要"先去确定性、再建随机模型"，不能直接对原序列拟合 ARMA？** 答：如果序列里有趋势或季节，这些确定性成分会让 [[KP02_自协方差与ACF|ACF]] 缓慢衰减、看起来像极强的自相关。直接对原序列拟合 ARMA，模型会把趋势误当成长期记忆，拟合出来的系数虚假显著、$R^2$ 很高但外推预测一塌糊涂，这就是伪回归。正确做法是先按 Cramer 分解把多项式趋势（和季节）剥离，让残差平稳，再对残差做 ARMA 建模。
3. **问："确定性序列"是不是就是"没有随机波动的序列"？** 答：不是。确定性成分指的是"用历史信息做线性预测时，长期预测残差方差趋于 0"——也就是未来可由历史完美预测，而不是说序列一点波动都没有。反过来，随机成分的长期预测残差方差会趋于序列自身方差，即历史对未来没有长期预测力。判断标准是看 $\tau_q^2$（用 q 期历史回归的残差方差）当 $q\to\infty$ 时趋于 0 还是趋于 $\mathrm{Var}(y_t)$。

## 8. 速记卡

- Wold = 平稳序列的"基因测序"：确定性 + 白噪声ARMA
- Cramer = 非平稳序列的"基因测序"：多项式趋势 + 平稳残差
- 确定性序列 = 历史能完美预测未来；随机序列 = 历史预测不了未来
- 一句话口诀：**先拆后建，确定性归趋势，随机性归ARMA**
