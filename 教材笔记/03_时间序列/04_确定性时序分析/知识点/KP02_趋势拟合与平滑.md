## 1. 是什么

**趋势拟合法**：把时间作为自变量，序列观察值作为因变量，建立回归模型提取长期趋势。

**平滑法**：利用修匀技术削弱短期随机波动，使序列平滑化以显示变化规律。分为移动平均法和指数平滑法两大类。

**直觉类比**：趋势拟合像用直尺或曲线板直接画一条最贴合数据的线；移动平均像给数据"美颜"——取附近几期的平均值磨掉尖刺；指数平滑像给近期数据更高权重的"加权美颜"。

**解决什么问题**：从含噪声的非平稳序列中提取清晰的长期趋势，并用于预测。

## 2. 怎么用

### 完整步骤

1. **画时序图**：观察趋势是线性、曲线、还是只有随机波动
2. **选择方法**：根据趋势形态选择拟合或平滑方法
3. **估计参数**：拟合模型确定系数
4. **检验效果**：检查残差是否随机
5. **预测**：用拟合/平滑模型做短期预测

### 关键公式

**线性趋势拟合**：
$$x_t = a + bt + I_t, \quad E(I_t)=0, \text{Var}(I_t)=\sigma^2$$

**n期移动平均**：
$$\tilde{x}_t = \frac{1}{n}(x_t + x_{t-1} + \cdots + x_{t-n+1})$$

**一次指数平滑**：
$$\tilde{x}_t = \alpha x_t + (1-\alpha)\tilde{x}_{t-1}, \quad 0 < \alpha < 1$$

**Holt两参数指数平滑**（有线性趋势）：
$$\tilde{x}_t = \alpha x_t + (1-\alpha)(\tilde{x}_{t-1} + r_{t-1})$$
$$r_t = \beta(\tilde{x}_t - \tilde{x}_{t-1}) + (1-\beta)r_{t-1}$$
预测：$\hat{x}_T(l) = \tilde{x}_T + l \cdot r_T$

**Holt-Winters三参数指数平滑**（有趋势+季节）：
加法模型：
$$a_t = \alpha(x_t - s_{t-\pi}) + (1-\alpha)(a_{t-1}+b_{t-1})$$
$$b_t = \beta(a_t - a_{t-1}) + (1-\beta)b_{t-1}$$
$$s_t = \gamma(x_t - a_t) + (1-\gamma)s_{t-\pi}$$

### R代码

```r
# ========== 1. 线性趋势拟合 ==========
# 目的：澳大利亚政府季度消费支出线性递增趋势
x <- ts(c(8444,9215,8879,8990,8115,9457,8590,9294,8997,9574,
          9051,9724,9120,10143,9746,10074,9578,10817,10116,10779), 
        start=1981, frequency=4)
t <- c(1:length(x))
x.fit <- lm(x ~ t)  # 线性回归拟合趋势
summary(x.fit)       # 查看系数：a=8498.688, b=89.123
# 结果：x_t = 8498.688 + 89.123t
abline(lm(x~t), col=2)

# ========== 2. 移动平均 ==========
# 目的：5期移动平均平滑北京最高气温序列
library(TTR)
x.ma <- SMA(x, n=5)  # n=5表示取5期移动平均
# 期数选择：有周期→取周期长度；要长期趋势→期数多；要短期敏感→期数少
plot(x, type="o")
lines(x.ma, col=2, lwd=2)

# ========== 3. Holt两参数指数平滑 ==========
# 目的：中国纱年产量有线性递增趋势，无季节效应
x <- ts(c(97,130,156.5,135.2,137.7,180.5,205.2,190,188.6,196.7,
          180.3,210.8,196,223,238.2,263.5,292.6,317,335.4,327,
          321.9,353.5,397.8,436.8,465.7,476.7,462.6,460.8,501.8,501.5,
          489.5,542.3,512.2,559.8,542,567), start=1964)
x.fit <- HoltWinters(x, gamma=FALSE)  # gamma=FALSE表示不用季节参数
# 输出：alpha=0.8556（水平平滑系数），beta=0.1585（趋势平滑系数）
library(forecast)
x.fore <- forecast(x.fit, h=10)  # 预测未来10年
plot(x.fore)

# ========== 4. Holt-Winters三参数指数平滑 ==========
# 目的：奶牛月度产奶量——既有趋势又有12个月周期
x <- ts(c(589,561,640,656,727,697,640,599,568,577,553,582,
          600,566,653,673,742,716,660,617,583,587,565,598), 
        start=c(1962,1), frequency=12)
x.fit <- HoltWinters(x)  # 三参数都不指定=三参数模型
# 输出：alpha控制水平，beta控制趋势，gamma控制季节
x.fore <- forecast(x.fit, h=24)  # 预测未来24个月
plot(x.fore)
```

### 计算演示

**移动平均计算**：最后4期观察值为5, 5.4, 5.8, 6.2
- $\hat{x}_T(1) = (5+5.4+5.8+6.2)/4 = 5.6$
- $\hat{x}_T(2) = (\hat{x}_T(1)+6.2+5.8+5.4)/4 = (5.6+6.2+5.8+5.4)/4 = 5.75$

**一次指数平滑计算**：设$\alpha=0.3$，$\tilde{x}_0=x_1=10$，观察值序列为10, 12, 11
- $\tilde{x}_1 = 0.3 \times 10 + 0.7 \times 10 = 10$
- $\tilde{x}_2 = 0.3 \times 12 + 0.7 \times 10 = 10.6$
- $\tilde{x}_3 = 0.3 \times 11 + 0.7 \times 10.6 = 10.72$

## 3. 什么时候用

| 方法 | 适用场景 | 数据条件 |
|------|----------|----------|
| 线性拟合 | 时序图显示直线趋势 | 趋势稳定、无突变 |
| 曲线拟合 | 时序图显示抛物线/指数趋势 | 趋势可识别为已知函数形式 |
| 移动平均 | 有周期波动要消除、或只需粗平滑 | 序列有周期性，周期长度已知 |
| 一次指数平滑 | 无趋势无季节，围绕常数均值波动 | 变化缓慢或迅速可通过调α控制 |
| Holt双参数 | 有线性趋势，无季节 | 趋势稳定递增/递减 |
| Holt-Winters三参数 | 既有趋势又有季节周期 | 月/季度数据最常见 |

**前提假设**：
- 趋势拟合：残差$I_t$零均值、方差齐性、无[[03_自相关|自相关]]
- 指数平滑：平滑系数$0 < \alpha, \beta, \gamma < 1$

## 4. 什么时候不能用/易错点

- **过平滑**：移动平均期数太大，会把真正的趋势也磨掉，且滞后性增强
- **α选错**：变化迅速的序列用小α→反应迟钝；变化缓慢的序列用大α→噪声放大
- **一次指数平滑做多期预测**：多期预测值恒等于$\tilde{x}_t$（水平线），无意义
- **Holt-Winters缺数据**：季节参数需要至少一个完整周期的数据才能初始化
- **常见错误**：对有季节效应的序列用一次指数平滑，导致季节波动被误判为噪声

## 5. 与相似方法对比表

| 方法 | 原理 | 适用数据 | 优点 | 缺点 | 什么时候选它 |
|------|------|----------|------|------|-------------|
| 线性趋势拟合 | 最小二乘回归 | 有明显直线趋势 | 解释性强、系数可检验 | 只能线性、对异常值敏感 | 趋势稳定且近似直线 |
| 曲线拟合 | nls非线性回归 | 有已知函数形式曲线趋势 | 可拟合复杂趋势 | 需要指定函数形式、迭代初值 | 趋势为二次型/指数型 |
| 移动平均 | 近n期简单平均 | 有周期波动要消除 | 简单直观 | 等权重不合理、滞后性 | 消除季节/周期影响 |
| 一次指数平滑 | 指数衰减加权平均 | 无趋势无季节 | 计算简单、近期权重高 | 不能预测趋势变化 | 平稳随机波动序列 |
| Holt双参数 | 水平+趋势双平滑 | 有线性趋势 | 可预测趋势延伸 | 不能处理季节 | 有稳定线性趋势的年数据 |
| Holt-Winters三参数 | 水平+趋势+季节三平滑 | 有趋势+季节 | 完整捕捉三要素 | 参数多、需完整周期数据 | 月度/季度有季节趋势数据 |

## 6. 为什么用这个不用那个

**决策逻辑**：
1. 先看时序图有没有趋势→没有趋势则用一次指数平滑
2. 有趋势但无季节→Holt双参数或趋势拟合
3. 有趋势又有季节→Holt-Winters三参数或decompose分解
4. 要消除周期影响看长期趋势→移动平均（期数=周期长度）

**被排除的方法会出什么问题**：
- 对有趋势序列用一次指数平滑→预测值是常数水平线，完全错过趋势
- 对有季节序列用Holt双参数→季节波动全部落入残差，残差严重自相关
- 用大期数移动平均提取短期趋势→过度滞后，反应迟钝

## 7. 完整例子

**书中原例（例4-5）**：中国纱年产量1964-1999年，Holt双参数指数平滑
- 拟合结果：$\alpha=0.8556, \beta=0.1585$
- 水平项$a=565.553$，趋势项$b=12.291$
- 预测公式：$\hat{x}_{2000+l} = 565.553 + 12.291 \times l$
- 即每年纱产量预测增长约12.3万吨

**生活实例**：奶茶店月销量预测
- 背景：某奶茶店2019-2023年逐月销量，每年夏季(6-8月)是旺季，冬季是淡季，整体逐年增长
- 选择方法：Holt-Winters三参数（有趋势+季节）
- R代码：
```r
sales <- ts(monthly_sales, start=c(2019,1), frequency=12)
fit <- HoltWinters(sales, seasonal="multiplicative")  # 乘法季节
forecast(fit, h=12)  # 预测下一年12个月
```
- 直觉：趋势水平项反映门店长期增长，季节因子反映夏季旺季冬季淡季

## 答辩常问（带标准答案）

1. **问：一次指数平滑、Holt 双参数、Holt-Winters 三参数分别在什么情况下用？** 答：按序列"有没有趋势、有没有季节"来选。一次指数平滑 $\tilde x_t=\alpha x_t+(1-\alpha)\tilde x_{t-1}$ 只适合无趋势、无季节、围绕常数均值波动的序列，而且多步预测就是一条水平线，没有趋势外推能力；Holt 双参数在一次平滑基础上加了趋势项 $r_t$，预测公式是 $\hat x_T(l)=\tilde x_T+l\cdot r_T$，呈斜线外推，适合有稳定线性趋势但无季节的年数据；Holt-Winters 三参数再加一个季节项 $s_t$，适合既有趋势又有季节周期的月/季度数据，预测呈带斜率的波浪线。口诀：无趋势用一次平滑，有趋势用 Holt，加季节用 Winters。
2. **问：平滑系数 $\alpha$ 大小怎么取舍？移动平均期数怎么选？** 答：$\alpha\in(0,1)$ 越接近 1 给近期数据权重越大、对变化越敏感但也越容易被噪声带偏；越接近 0 越平滑但反应越迟钝。经验上：变化快的序列用大 $\alpha$，平稳序列用小 $\alpha$，实际更常见的做法是让 R 的 `HoltWinters()` 自动按最小预测误差去估计 $\alpha,\beta,\gamma$。移动平均期数 $n$ [[KP05_评价标准值xi0的选择|的选择]]原则：要消除周期就取周期长度（月度数据 $n=12$、季度 $n=4$），要长期趋势就期数大、要短期敏感就期数小；期数太大会过度平滑、把真趋势磨掉并产生滞后。
3. **问：趋势拟合法（回归）和指数平滑法的本质区别是什么？** 答：趋势拟合是"全局一次性"估计——用全部数据最小二乘求出一条固定直线/曲线 $x_t=a+bt$，系数不随新数据变化，优点是解释性强、系数可做 t 检验，缺点是趋势一旦有转折或突变就整段失真。指数平滑是"递推自适应"——每个新数据到来都按 $\alpha$ 更新一次水平和趋势估计，权重随时间指数衰减，自动给近期更高权重，能跟上缓慢变化，但没有可解释的回归系数。实务中解释原因用拟合，做滚动预测用平滑。

## 8. 速记卡

- 移动平均：等权重磨皮，期数=周期长度
- 一次指数平滑：近期权重高，只适合平稳序列
- Holt：加趋势项，预测是斜线
- Holt-Winters：加季节项，预测是波浪线
- 一句话口诀：**有趋势用Holt，加季节用Winters，无趋势用一次平滑，消周期用移动平均**
