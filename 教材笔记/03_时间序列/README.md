## 使用路径

### 小白入门
1. 先读 [01_时序分析简介](01_时序分析简介/01_什么是时间序列.md)
2. 读 [02_平稳时间序列](02_平稳时间序列/00_章节总结.md) 掌握[[02_平稳性|平稳性]]和[[KP02_自协方差与ACF|ACF]]/[[KP04_PACF偏自相关|PACF]]
3. 读 [03_ARMA模型](03_ARMA模型/00_章节总结.md) 掌握[[KP04_建模六步法|建模六步法]]
4. 每章先看框架图，再读知识点卡片

### 复习备考
- 重点背 AR/MA/[[KP03_ARMA模型|ARMA]] 的 ACF/PACF 截尾拖尾模式表
- 每章 00_章节总结.md 的自测题
- 速记卡

### 实战预测
- 按建模六步法走：平稳性检验 → 识别(p,q) → 估计 → 检验 → 预测
- R代码直接复制改数据即可

## 模型识别速查表

| 模型 | ACF | PACF | 例子 |
|------|-----|------|------|
| AR(p) | 拖尾 | p阶截尾 | 本月销量与上月相关 |
| MA(q) | q阶截尾 | 拖尾 | 只受近期冲击影响 |
| ARMA(p,q) | 拖尾 | 拖尾 | 两者兼有 |
| [[KP01_ARIMA模型|ARIMA]](p,d,q) | 差分后同上 | 差分后同上 | 有趋势的序列 |
