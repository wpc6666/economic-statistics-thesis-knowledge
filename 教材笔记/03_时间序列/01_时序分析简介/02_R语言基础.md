# 02 R语言基础

## 一、概述

本节掌握R语言时间序列分析的最小工具箱：生成ts对象、读入外部数据、基本变换与绘图。

## 二、要点梳理

### 1. R基本规则

- 赋值符号：标准写法为 `<-`（方向箭头），也支持 `=`
- 注释：`#` 开头到行末
- 区分大小写：`X` 与 `x` 是不同对象
- 最小输出模式：赋值后不自动显示结果，需输入对象名查看
- 程序包：先 `install.packages()` 安装，再 `library()` 加载

### 2. 生成时间序列数据

**直接录入（小样本）：**
- 行输入：`c()` 函数
- 列输入：`scan()` 函数

**外部文件转换（大样本）：**
- `read.table()` 读入txt/csv文件
- 多变量数据读入后称为**数据框**（data.frame）
- 访问变量用 `数据框$变量名`

### 3. 时间序列处理

- **变换**：如对数变换 `y <- log(x$yield)`
- **子集**：`subset(x, year > 1925, select=yield)`
- **缺失值插值**：zoo包的 `na.approx()`（线性插值）和 `na.spline()`（样条插值）
- **导出**：`write.table()` 写回csv文件

### 4. 绘图基础

```r
plot(ts对象)                    # 默认时序图
plot(ts对象, type="p")          # 散点图
plot(ts对象, type="l")          # 线图
plot(ts对象, type="b")          # 点连线
plot(ts对象, type="o")          # 线穿过点
```

常用图形参数：

| 参数 | 作用 | 示例 |
|------|------|------|
| `type` | 点线结构 | `"p"`, `"l"`, `"b"`, `"o"`, `"h"`, `"s"` |
| `pch` | 点符号 | `pch=16` 实心圆 |
| `lty` | 线类型 | `lty=2` 虚线 |
| `lwd` | 线宽 | `lwd=2` 两倍宽 |
| `col` | 颜色 | `col="red"` 或 `col=2` |
| `main` | 标题 | `main="小麦产量时序图"` |
| `xlab/ylab` | 坐标轴名 | `xlab="年份"` |
| `xlim/ylim` | 坐标范围 | `ylim=c(15, 16)` |
| `abline` | 添加参照线 | `abline(v=1887, lty=2)` |

## 三、公式详解

### `ts()` 函数语法

```r
ts(data, start, end, frequency)
```

| 参数 | 含义 | 常用值 |
|------|------|--------|
| `data` | 数值向量 | c(101, 82, ...) |
| `start` | 起始时间 | `c(2005,1)` 表示2005年1月 |
| `frequency` | 每年数据频率 | 1=年度, 2=半年度, 4=季度, 12=月度, 52=周度, 365=日度 |

## 四、R实例与代码

```r
# ============================================
# 完整示例：小麦平均亩产序列（教材例1-1）
# ============================================

# 第一步：从CSV读入数据
x <- read.table("E:/R/data/file1.csv", sep=",", header=TRUE)
# sep=","  → 文件以逗号分隔
# header=T → 第一行包含变量名 year 和 yield

# 第二步：查看数据框结构
x            # 显示全部数据
x$year       # 访问year列
x$yield      # 访问yield列

# 第三步：对数变换
ln_yield <- log(x$yield)   # 对yield取自然对数

# 第四步：子集筛选（保留1925年之后的数据）
z <- subset(x, year > 1925, select=yield)

# 第五步：将yield转为时间序列并绘图
yield_ts <- ts(x$yield, start=1884)     # 年度数据，起始1884年
plot(yield_ts,
     main="1884-1939年英格兰和威尔士小麦平均亩产",
     xlab="年份", ylab="亩产量",
     col="blue", lwd=2)

# 第六步：导出处理后的数据
x_new <- data.frame(x, ln_yield)
write.table(x_new, file="E:/R/data/yield.csv", sep=",", row.names=FALSE)
# row.names=FALSE → 不保存行号列
```

```r
# ============================================
# 缺失值插值示例（zoo包）
# ============================================

install.packages("zoo")    # 首次使用需安装
library(zoo)               # 加载zoo包

a <- c(1:7)               # 1,2,3,4,5,6,7
a[4] <- NA               # 第4个值设为缺失
a                        # 1 2 3 NA 5 6 7

y1 <- na.approx(a)       # 线性插值 → 1 2 3 4 5 6 7
y2 <- na.spline(a)       # 样条插值 → 1 2 3 4 5 6 7
```

## 答辩常问（带标准答案）

1. **问：为什么一定要用 `ts()` 把向量转成时间序列对象？直接对普通向量做 `acf()` 不行吗？** 答：普通数值向量只有大小、没有时间刻度，R 的时序函数（`acf()`、`pacf()`、`arima()`、`forecast()`）虽然能跑，但它们不知道数据是月度还是年度、从哪一年开始，画出来的图和[[KP02_季节模型|季节模型]]都会错位。`ts(data, start=c(2005,1), frequency=12)` 同时告诉 R：起始时间、以及一年有多少个观测（frequency=12 是月度、4 是季度、1 是年度），这是后续季节识别、周期分解的前提。
2. **问：`frequency` 参数怎么取？取错了会怎样？** 答：按一年的观测频率取：年度数据 `frequency=1`、半年度 `=2`、季度 `=4`、月度 `=12`、周度 `=52`、日度 `=365`。它不是随便设的——后面 `decompose()` 做季节分解、S[[KP01_ARIMA模型|ARIMA]] 设周期 $s$、Holt-Winters 提取季节项，全部依赖这个 frequency。把月度数据错设成 `frequency=1`，季节模型就找不到 12 个月的周期，季节效应完全提不出来。
3. **问：程序包为什么要先 `install.packages()` 再 `library()`？两者区别？** 答：`install.packages()` 是把包从网上下载安装到本地硬盘，只需做一次；`library()` 是把已安装的包加载进当前 R 会话，每次新开 R 都要重新加载一次。答辩时如果被问"为什么你的代码报 there is no package called"，答案就是只 install 了没 library，或者压根没 install。

## 五、小结

1. R中所有时间序列分析的前提是把向量转为 `ts()` 对象。
2. 外部数据用 `read.table()` 读入，通过 `$` 符号访问数据框中的变量。
3. 绘图用 `plot()`，常用 `type`、`col`、`lwd`、`main` 等参数自定义。
4. 缺失值用zoo包的 `na.approx()` 或 `na.spline()` 插值。
5. 程序包必须先安装（`install.packages`）再加载（`library`）。
