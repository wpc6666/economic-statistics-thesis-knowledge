# 01 什么是时间序列

## 一、概述

本节讲清楚三件事：时间序列的严格定义、描述性分析与统计分析的分野、时域与频域两条技术路线。

## 二、要点梳理

### 1. 时间序列的定义

按时间顺序排列的一组随机变量构成时间序列：

$$X_1, X_2, \dots, X_t, \dots \quad \text{简记为} \quad \{X_t, t \in T\}$$

对应的 $n$ 个观察值：

$$x_1, x_2, \dots, x_n \quad \text{简记为} \quad \{x_t, t=1,2,\dots,n\}$$

- $\{X_t\}$ 称为**随机时序**（总体）
- $\{x_t\}$ 称为**观察值序列**，是 $\{X_t\}$ 的一个**实现**（样本）
- 研究目的：由观察值序列 $\{x_t\}$ 的性质推断随机时序 $\{X_t\}$ 的性质

### 2. 描述性时序分析

早期方法：通过直观的数据比较或绘图观测寻找序列中的发展规律。

- 典型案例：古埃及人观察尼罗河泛滥规律、范蠡总结"六岁穰，六岁旱"、太阳黑子11年周期
- 优点：操作简单、直观有效
- 局限：主观性强，难以准确预测随机序列的未来走势
- 定位：通常是统计时序分析的第一步

### 3. 统计时序分析

20世纪20年代起，利用数理统计学原理分析时间序列，重心从表面现象转移到内在相关关系。

**两大类方法：**

| 维度 | 频域分析（谱分析） | 时域分析 |
|------|-------------------|----------|
| 核心思想 | 将序列分解为不同频率的周期波动 | 从[[03_自相关|自相关]]角度揭示序列发展规律 |
| 数学工具 | 傅里叶变换、正弦余弦逼近 | 自相关函数、[[KP03_ARMA模型|ARMA]]模型 |
| 应用领域 | 电力工程、信息工程、物理、天文 | 自然科学与社会科学各领域（主流） |
| 优点 | 适合周期信号分析 | 理论扎实、步骤规范、结果易解释 |
| 缺点 | 数学复杂、结果抽象 | 主要处理线性、同方差单变量序列 |

### 4. 时域分析五步法

1. **考察观察值序列的特征**（[[02_平稳性|平稳性]]、纯随机性检验）
2. **根据序列特征选择适当的拟合模型**
3. **根据观察数据确定模型口径**（参数估计）
4. **检验模型、优化模型**
5. **利用拟合模型推断统计性质或预测未来**

### 5. 时域分析发展脉络

- 1927年 Yule 提出 AR 模型
- 1931年 Walker 提出 MA 模型和 ARMA 模型
- 1970年 Box & Jenkins 系统提出 [[KP01_ARIMA模型|ARIMA]] 模型（Box-Jenkins方法）
- 后续拓展：[[KP04_ARCH模型|ARCH]]/[[KP05_GARCH模型|GARCH]]（[[02_异方差|异方差]]）、协整（多变量）、非线性模型

## 三、公式详解

### 公式1：随机时序定义

$$\{X_t, t \in T\}$$

- $X_t$：$t$ 时刻的随机变量
- $T$：时间指标集合
- 符号含义：序列在每个时刻都是随机的，而非确定的数

### 公式2：观察值序列

$$\{x_t, t=1,2,\dots,n\}$$

- $x_t$：$t$ 时刻的具体观察值（实数）
- $n$：序列长度（样本量）
- 这是我们实际能拿到的数据

## 四、R实例与代码

```r
# 目的：用行输入方式创建一个简单的时间序列
# 案例：2005年1-6月某商品价格（教材表1-3）

price <- c(101, 82, 66, 35, 31, 7)  # 行输入6个月度数据
price <- ts(price, start=c(2005, 1), frequency=12)  # 转为ts对象：起始2005年1月，月度数据
price  # 查看时间序列对象
# 输出格式：
#     Jan Feb Mar Apr May Jun
# 2005 101 82  66  35  31  7
```

```r
# 目的：用列输入方式（scan）创建时间序列
price <- scan()        # 列输入，逐行回车，空行结束
# 1: 101
# 2: 82
# ...
# 7: （空行结束）
price <- ts(price, start=c(2005,1), frequency=12)
```

## 答辩常问（带标准答案）

1. **问：时间序列里的随机时序 $\{X_t\}$ 和观察值序列 $\{x_t\}$ 有什么区别？为什么要强调"一次实现"？** 答：$\{X_t,t\in T\}$ 是总体——每个时刻 $t$ 都是一个随机变量，服从某种概率分布；我们实际记录下来的 $x_1,x_2,\dots,x_n$ 是这个随机过程的一次"实现"（样本），它本身不是随机变量。强调"一次实现"是因为：时间序列每个时刻只观测一次，我们无法对同一时刻重复抽样，只能用这一条序列去推断背后的随机过程，这也是为什么平稳性假设如此重要——它让我们能把不同时刻的观测当成同一个总体的样本来用。
2. **问：时域分析和频域分析有什么区别？本课程走哪条路线？** 答：频域（谱分析）把序列分解成不同频率的正弦周期叠加，用傅里叶变换处理，适合电力、天文这种强周期信号；时域分析从自相关函数出发，认为序列现在的值和过去的值有线性依赖，用 ARMA/ARIMA 建模，优点是理论扎实、步骤规范、结果容易解释，是经济、管理等社会科学领域的主流。本课程主线是时域分析。
3. **问：描述性时序分析为什么不能算"真正的"时序分析？** 答：描述性分析靠画折线图、做直观对比找规律（如古埃及人看尼罗河泛滥、太阳黑子 11 年周期），简单直观但主观性强、无法量化不确定性，也难以预测带随机波动的序列。它只能作为统计建模的第一步——真正的统计时序分析要先做平稳性和纯随机性检验，再选模型、估参数、检验残差，最后才预测，也就是课程后面反复用的时域五步法。

## 五、小结

1. 时间序列 = 按时间排列的随机变量族；我们看到的只是它的一次实现。
2. 描述性分析是入门手段，统计时序分析才是本书主体。
3. 时域分析从自相关出发建模，是社会科学领域的主流方法。
4. R语言中用 `ts()` 函数将普通向量转为时间序列对象，这是一切分析的起点。
