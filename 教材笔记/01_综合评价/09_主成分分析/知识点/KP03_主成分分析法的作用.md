# KP03 · 主成分分析法的作用

## 一、是什么

主成分分析法在多元统计中具有五项作用：降维、揭示变量关系、多维数据可视化、构造回归模型、筛选回归变量。

**直观直觉**：[[KP04_PCA与FA对比|PCA]] 不只是"压缩指标"，它还是一个多面工具——既能瘦身（降维）、又能透视（看变量关系）、还能画图（二维投影）、更能辅助回归（做主成分回归、选变量）。

## 二、怎么用

| 作用 | 具体做法 |
|---|---|
| ①降维 | 用 $m$ 维 $Y$ 空间代替 $p$ 维 $X$ 空间（$m<p$），损失信息很少 |
| ②揭示变量关系 | 通过因子负荷 $a_{ij}$ 弄清 $X$ 变量间的关系 |
| ③多维可视化 | 取前两个主成分，按得分画 $n$ 个样品二维散点图，看分布、分类、找离群点 |
| ④构造回归模型 | 以各主成分作新自变量代替原 $x$ 做回归（主成分回归） |
| ⑤筛选回归变量 | 若某 $X_i$ 在前 $m$ 个主成分中系数都近似为零，可删除该变量 |

## 三、什么时候用

- 变量太多、维数太高无法画图或建模时 → 降维/可视化；
- 自变量间存在[[KP02_多重共线性|多重共线性]]时 → 主成分回归；
- 需要从大量候选自变量中选变量子集时 → 筛选变量。

## 四、什么时候不能用 / 易错点

- 降维后若某个主成分无法解释实际意义，不能强行用于回归或评价；
- 主成分回归虽解决共线性，但损失了参数的原始经济含义；
- 可视化只取前两维，可能丢失第三维以后的结构。

## 五、与相似方法的区别

| 用途 | PCA | 专门方法 |
|---|---|---|
| 降维 | PCA | [[KP03_PCA与因子分析对比|因子分析]][[KP01_对应分析|对应分析]]等 |
| 可视化 | PCA 二维投影 | 多维尺度 [[KP01_多维标度MDS|MDS]] |
| 回归 | 主成分回归 | 岭回归、逐步回归 |
| 筛选变量 | PCA 删近零系数变量 | 逐步回归、LASSO |

## 六、为什么用这个而不用那个

- **为什么用 PCA 处理多重共线性而不用逐步回归**：逐步回归按单变量贡献剔除，可能丢弃集体信息；PCA 用全部变量的线性组合做回归，保留信息更全。
- **为什么用 PCA 画图而不直接画前两个指标**：前两个指标不一定是方差最大方向，PCA 投影才是信息最丰富的二维视角。

## 七、完整例子

原书干部测评例 9.4 中，27 个指标经 PCA + 旋转后，前 4 个主成分（累计 85.42%）即可代表干部能力的主要方面，实现降维与可视化解释。

## 答辩常问（带标准答案）

1. **问：主成分回归能解决什么问题？为什么不用逐步回归？** 答：自变量间存在多重共线性时，回归系数方差膨胀、符号反常。PCA 把 $p$ 个相关自变量换成 $k$ 个互不相关的主成分再回归，从根本上消除共线性；逐步回归按单个变量贡献剔除，可能丢掉集体信息，PCA 用全部变量的线性组合保留信息更全。代价是主成分失去原始经济含义。
2. **问：怎么用 PCA 筛选回归变量？** 答：若某个原始变量 $x_i$ 在前 $m$ 个主成分上的系数都近似为 0，说明它对数据变异几乎无贡献，可删除该变量。
3. **问：PCA 二维散点图能看出什么？** 答：取前两个主成分按得分画 $n$ 个样品的二维点，可直观看样品分布、分类聚集、发现离群点——这是信息最丰富的二维视角，比直接画任意两个原始指标更全面。

## 八、速记卡

- 五作用：**降维、透视、画图、回归、选变量**。
- 前两主成分得分 → 二维散点图，可看分布、分类、找离群点。
- 某 $X_i$ 在所有主成分中系数≈0 → 可删。
