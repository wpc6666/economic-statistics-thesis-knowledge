# KP08 · 主成分含义的解释

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


## 一、是什么

主成分是原始指标的线性组合，比原始指标内容更复杂。解释主成分含义，就是根据各指标 $x_j$ 在主成分表达式中的系数 $a_{ij}$ 的**大小和符号**，结合指标本身的实际意义，给主成分起一个能反映其本质的名字。

## 二、怎么用

| 观察 | 判断 |
|---|---|
| 某指标 $x_j$ 的 $a_{ij}$ 明显偏大 | 该主成分主要反映 $x_j$ 的信息 |
| 各指标 $a_{ij}$ 大致相同 | 可能存在一个共性影响因素 |
| $a_{ij}>0$ | 该指标与主成分作用同向 |
| $a_{ij}<0$ | 该指标与主成分作用逆向 |

## 三、什么时候用

- 选定 $k$ 个主成分后、计算[[KP09_综合评价值F的构造|综合评价值]]之前；
- 对定量综合评价做进一步定性分析时。

## 四、什么时候不能用 / 易错点

- 系数大小相近、无法识别主导指标时，**不能强行解释**——应考虑旋转、增删指标、去奇异样本；
- 不看符号、只看绝对值，导致方向判断错误；
- 把主成分含义当成"因果关系"——它只是统计上的线性组合。

## 五、与相似方法的区别

| 方法 | 可解释性 |
|---|---|
| [[02_主成分分析PCA|主成分分析]]（未旋转） | 主成分系数常较平均，含义模糊 |
| 主成分旋转后 | 系数两极化，含义清晰 |
| [[KP03_PCA与因子分析对比|因子分析]]（旋转后） | 公因子含义最清晰（见第十章） |

## 六、为什么用这个而不用那个

- 若主成分系数已经明显两极分化（如例 9.1 的 $y_2$ 突出 $x_5,x_6$），直接解释即可；
- 若系数平均、无法解释，应先用最大方差旋转（KP12）再解释，而不是硬起名字。

## 七、完整例子

例 9.1：

- $y_1$：7 个系数都为正且相近 → "经济效益全面能力综合指标"；
- $y_2$：$x_5$（百元销售收入利润）、$x_6$（百元销售成本利润）系数明显大且为正 → "盈利能力"；
- $y_3$：$x_4$（产值利税率）系数最大 → "产值利税率决定的经济效益"。

## 答辩常问（带标准答案）

1. **问：怎么给一个主成分起名字？** 答：看该主成分表达式中各指标系数 $a_{ij}$ 的大小和符号——哪个指标系数明显偏大，主成分就主要反映它；系数都差不多大且同号，说明是"综合水平/共性因素"；系数一正一负则说明是两者之差（如续航减价格的"性价比"）。
2. **问：系数都差不多大、解释不出来怎么办？** 答：三种处理——①做最大方差旋转让系数两极化 ②检查并去掉奇异样本 ③增补或删除指标；绝不能强行起名，否则后面综合得分的意义都站不住。
3. **问：主成分系数的负号怎么理解？** 答：$a_{ij}<0$ 表示该指标与主成分作用方向相反（主成分得分高时该指标处于低位），不代表"坏"；解释时必须同时看符号，不能只看绝对值。

## 八、速记卡

- 解释依据：系数**大小**（谁主导）+ **符号**（同向/逆向）。
- 系数都相近 → 找共性因素。
- 解释不清 → 旋转 / 去奇异样本 / 增删指标。

## 九、小白生活实例（手把手算）

### 场景故事
小红已经算出两个主成分得分 $y_1,y_2$，但她不知道这两个"新分数"到底代表什么——是"手机档次"还是"性价比"？她得对着系数给每个主成分起个名字。

### 小数据表
（沿用 KP04 的结果）

| 主成分 | 系数 $u_{\text{价格}}$ | 系数 $u_{\text{续航}}$ | 得分 A | 得分 B | 得分 C |
|---|---|---|---|---|---|
| $y_1$ | 0.707 | 0.707 | -1.414 | 0.707 | 0.707 |
| $y_2$ | -0.707 | 0.707 | 0 | 0.707 | -0.707 |

### 数据为什么长这样
- 主成分表达式是 $y_1=0.707\,z_{\text{价格}}+0.707\,z_{\text{续航}}$，$y_2=-0.707\,z_{\text{价格}}+0.707\,z_{\text{续航}}$。
- 系数的**大小**告诉我们谁在主导这个主成分，**符号**告诉我们是同向还是反向。

### 从零开始逐步计算

**第一步：解释 $y_1$**

看系数：$u_{\text{价格}}=0.707$，$u_{\text{续航}}=0.707$。两个系数**都是正的、大小相等**，说明价格和续航在 $y_1$ 上是"一起涨"的。

大白话：$y_1$ 高 = 价格贵 + 续航长 = **"综合档次"主成分**。A 的 $y_1=-1.414$（最便宜、续航最短，最低档），B、C 的 $y_1=0.707$（中高端）。

**第二步：解释 $y_2$**

看系数：$u_{\text{价格}}=-0.707$，$u_{\text{续航}}=0.707$。两个系数**符号相反、大小相等**，说明价格和续航在 $y_2$ 上是"对冲"的。

大白话：$y_2$ 高 = 续航长但价格不贵 = **"性价比"主成分**（续航相对于价格的优势）。
- B 的 $y_2=0.707$：中等价格但续航最长，**性价比高**；
- C 的 $y_2=-0.707$：最贵但续航一般，**性价比差**；
- A 的 $y_2=0$：便宜也续航短，性价比中庸。

**第三步：对照得分验证**

| 手机 | $y_1$（档次） | $y_2$（性价比） |
|---|---|---|
| A | -1.414（最低档） | 0 |
| B | 0.707（中档） | 0.707（性价比高） |
| C | 0.707（中档） | -0.707（性价比差） |

解释和得分完全吻合。

### 最终结果排序
$y_1$ = "手机综合档次"（价格+续航同向）；$y_2$ = "性价比"（续航减价格）。B 手机档次中等但性价比最高，C 档次中等但性价比差，A 档次最低。

### 一句话感悟
主成分名字就是"**看系数谁大、符号同不同**"——系数都正且接近就是"综合水平"，一正一负就是"两者之差/性价比"。
