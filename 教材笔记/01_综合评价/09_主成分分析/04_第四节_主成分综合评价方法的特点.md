# 第九章 第四节 · 主成分综合评价方法的特点（小节笔记）

> 所属章节：第九章 [[02_主成分分析PCA|主成分分析]]（原书第 3841–3860 行）
> 本节归纳主成分综合评价方法的三大特点，是评价其优劣、决定是否选用的依据。

## 一、本节概述

通过前三节的过程分析可知，主成分综合评价方法有三个鲜明特点：**能消除指标间相关关系的影响、权数具有客观性、综合评价结果不稳定**。前两个是优点，第三个是局限，三者共同决定了该方法的适用边界。

## 二、知识要点逐条展开

### 1. 特点一：能消除评价指标间相关关系的影响

- 综合评价中各指标间往往存在一定相关关系，表明它们反映的信息有所重复；若不作变换直接合成，合成结果必然包含重复信息，有时会歪曲被评价对象间的相对地位。
- 主成分分析把原来相关的原始指标作数学变换，转化成**彼此独立的主成分**，再对所选主成分线性加权求和 → 消除了因相关造成的信息重复对[[KP09_综合评价值F的构造|综合评价值]]的影响，有助于正确认识被评价对象的相对位置。
- **这是主成分综合评价方法的最大特点**。正因如此，指标选择工作相对容易：用主成分分析做综合评价时，指标选择原则是**尽可能全面，而不必顾虑指标间的相关影响**。

### 2. 特点二：所得综合评价的权数具有客观性

- 主成分分析的权数是伴随数学变换自动生成的，具有客观性：各指标系数 $a_{ij}$ 和方差贡献率 $a_k$ 都从协方差矩阵获得。
- 数理统计中，指标方差表示指标数据的离散（差异）程度。即主成分分析**根据指标数值在被评价对象间的差异程度来确定权数**：
  - 指标数值差异越大 → 该指标区分各被评价对象的信息越丰富 → 给越大权数；
  - 指标数值在各对象间几乎无差异 → 无助于区分相对地位 → 权数应很小。
- **例 9.1 印证**：第一主成分中资金利税率权数 0.4831 高于产值利税率权数 0.3586，原因是资金利税率在 30 个省区的离散变异系数 0.4459 大于产值利税率的 0.3562，区分信息更丰富。
- 优点：比人为定权工作量小、不带主观随意性，较客观科学，提高结果可靠性。
- **局限**：
  1. 权数不具有稳定性——同一指标在不同被评价对象集合中有不同权数；
  2. 实际中数值差异大的指标，并不一定具有更重要的经济意义。

### 3. 特点三：综合评价结果不稳定

- 同一被评价对象在不同样本集合中的均值和[[03_离散程度|离散程度]]一般不同 → 协方差矩阵不同 → 主成分和方差贡献率不同 → 综合评价值变化。
- **含义**：减少或增加被评价对象，都可能改变原来对象的排列位次。不同样本集合算出的综合评价值**不可比**。
- 因此该方法**不便于评价资料的系列积累，更适宜于一次性综合评价**；做横向、纵向比较时需把被比较对象放在一起计算。
- **大样本缓解**：由大数定律，随着被评价对象增多，平均水平 $\bar{x}$ 和离散程度 $S$ 趋于稳定 → 协方差矩阵趋于稳定 → 结果不唯一性减弱。故主成分分析适宜大样本容量，一般要求**样本容量大于指标个数的两倍**。

本节无新公式。涉及的权数即方差贡献率 $\omega_i=\lambda_i/\sum_{j=1}^p\lambda_j$，详见 [第二节](./02_第二节_主成分分析综合评价步骤.md)。

## 五、本节小结

| 特点 | 性质 | 要点 |
|---|---|---|
| 消除指标相关影响 | 最大优点 | 主成分两两不相关，避免信息重复；指标可选得全面 |
| 权数客观 | 优点但有局限 | 由方差/变异自动生成；但权数不稳定、不必然等于经济重要性 |
| 结果不稳定 | 局限 | 样本集合变则位次变；适宜一次性评价；需 $n>2p$ 的大样本 |

## 答辩常问（带标准答案）

1. **问：主成分综合评价的三大特点是什么？** 答：①消除指标间相关影响（最大优点，故选指标可尽量全面）②权数客观（由方差/变异自动生成，但不稳定、不等于经济重要性）③结果不稳定（样本集合变则位次变，只宜一次性评价，要求 $n>2p$）。
2. **问：权数客观体现在哪？** 答：指标在样本间差异越大、区分信息越多，权数自动越大——例 9.1 资金利税率变异系数 0.4459 大于产值利税率 0.3562，前者权数 0.4831 大于后者 0.3586；但权数随样本变，数值差异大不等于经济意义重要。
3. **问：为什么 [[KP04_PCA与FA对比|PCA]] 不适合跨年追踪评价？** 答：换样本集合 → 协方差矩阵变 → 主成分方向和贡献率变 → $F$ 不可比、位次重排；长期评价要用权数固定的[[KP11_主观赋权vs客观赋权|主观赋权]]或[[KP09_熵值法|熵值法]]，横向比较时所有对象必须放在一起算。
