## 三、通用写作规范

- **正式学术笔记风格**：客观、严谨、术语统一；禁止"喵/主人/颜文字/撒娇"等角色扮演语气；不写与本书无关的内容。
- 中文正文；公式保留 **LaTeX**（行内 `$...$`，独立公式 `$$...$$`），符号用原书符号。
- 每个公式必须配：**符号含义逐项说明 → 公式直观含义 → 来源/理论依据 → 适用条件与限制**。
- 方法对比一律用 **Markdown 表格**成表；[[KP02_指标体系|指标体系]]、阈值、因子载荷等一律转成 Markdown 表格。
- 每个文件末尾给出"关联知识点"相对链接，织成知识网。
- 交叉链接用相对路径，例如 `[熵值法](04_赋权方法/知识点/KP09_熵值法.md)`。
- 合理使用标题层级、表格、有序列表、引用块、`mermaid` 图；避免大段无分隔文字。

## 四、四类笔记的固定结构

### 1. 小节笔记（每个小节一份）

1. **本节概述**（1 段，说明本节在全章中的位置与要解决的问题）
2. **知识要点逐条展开**（覆盖原文每个小标题/要点，不得遗漏）
3. **公式详解**（LaTeX + 符号含义 + 直观含义 + 适用条件）
4. **书中例题/数据的完整演算**（保留中间步骤；无例题则注明）
5. **本节小结**（要点列表）
6. **关联知识点**（链接到本章知识点文件）

### 2. 知识点笔记（最关键，每个方法/概念必须包含全部 8 块）

1. **是什么**：严格定义 + **直观直觉/生活化类比**（类比要准确，不得误导）
2. **怎么用**：完整操作步骤 + 公式 + 计算示例，**保留中间过程**
3. **什么时候用**：适用场景、数据条件、前提假设
4. **什么时候不能用 / 易错点**：违反假设的后果、常见误用、原书提醒
5. **与相似方法的区别**：**Markdown 对比表**（维度至少含：核心思想、输入数据、权数来源、前提假设、优点、缺点、适用场景）
6. **为什么用这个方法而不用那个方法**：决策逻辑——给定具体场景，说明选择理由与排除理由（这是用户反复强调的重点，必须写实、写细）
7. **完整例子**：优先用书中原例，数据可追溯；无原例时用极简自拟数据并标注"自拟演示"
8. **速记卡 + 关联知识点**：3–6 条最易考/最易忘的结论 + 链接

### 3. 章节总结（每章一份）

1. **知识框架图**：优先 `mermaid graph TD`（节点文字简短），并附**文字缩进树**兜底
2. **核心公式清单**（表格：公式名 / 表达式 / 用途 / 适用条件）
3. **[[01_方法选择决策树|方法选择决策树]]（文字版）**：用"若……则……；否则……"的判别链，覆盖本章全部方法
4. **与前后章节的联系**
5. **高频考点/自测题**：8–15 题，含**答案要点**
6. **本章知识点索引**（表格：KP 编号 / 名称 / 一句话用途）

### 4. 案例笔记（每个[[案例一_企业入驻条件综合评价|案例一]]份）

1. **研究背景与问题**
2. **指标体系如何构建**（完整指标 Markdown 表，注明正/逆/适度指标）
3. **方法选择决策链**：为什么选这些方法、为什么不用其他方法（重点）
4. **关键计算过程**（无量纲化、赋权、合成、检验的中间结果）
5. **结果与结论**（排序、评价结论、政策含义）
6. **可复用的分析模板**（抽象成可迁移的步骤清单）
7. **与本书方法/章节的对应表**
