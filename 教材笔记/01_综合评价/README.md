## 一、本书讲什么

综合评价要解决的问题是：**用多个指标、对多个参评单位同时评价**。其基本思想是把多个量纲不同、方向可能不一致的指标，经过"**[[KP02_指标体系|指标体系]] → 无量纲化 → 赋权 → 合成**"，转化为一个能反映综合情况的**综合分值**，再据此排序。

全书分两部分：

- **基本理论（绪论 + 第 1–10 章）**：一般问题、指标体系、无量纲化、赋权、数值合成、常规成套方法（评分/指数/[[KP06_秩和比RSR评价法|RSR]]/功效系数）、灰色关联、模糊综合、主成分、[[KP03_PCA与因子分析对比|因子分析]]；
- **典型案例（3 个）**：企业入驻条件、[[案例二_城市竞争力与房地产价格|城市竞争力与房地产价格]]、社会发展水平。

## 四、方法选择速查（核心决策表）

| 你的数据/场景特征 | 首选方法 | 一句话理由 |
|---|---|---|
| 信息不完全、贫信息、小样本 | **[[KP10_灰色关联度vs模糊综合评价|灰色关联度]]** | 只看曲线形状相似，不需大样本 |
| 概念边界模糊、有评语等级 | **[[KP10_灰色关联度vs模糊综合评价|模糊综合评价]]** | 用隶属度刻画"亦此亦彼" |
| 指标众多、高度相关、需降维 | **主成分 / 因子** | 重客观排序用主成分，重结构解释用因子 |
| 多投入、多产出、评相对效率 | **[[KP09_数据包络分析DEA|DEA]]** | 线性规划给出相对效率，无需预设生产函数 |
| 指标可线性补偿、可替代 | **线性综合** | 加权求和，一项短板可由其他项弥补 |
| 要求各指标均衡、不可偏废 | **几何综合** | 连乘，任一指标极低即"一票否决" |
| 部分补偿、部分均衡 | **混合综合** | 加 + 乘叠加 |
| 有明确机制/函数关系 | **模型综合** | 用 Z=F(X) 表达真实机制 |
| 有标准、易打分 | **综合评分法** | 实际值转分数后加权 |
| 有基期/计划标准 | **综合指数法** | 个体指数加权 |
| 仅知位次、数据异常分布不明 | **秩和比 RSR** | 按位次加权，抗异常值 |
| 有满意值与不允许值 | **功效系数法** | 双边界映射 60~100 分 |
| 自变量高度共线、又要保留全部变量 | **主成分回归** | 先降维消共线，再回归还原 |

> 完整判别逻辑见 [方法选择决策树](./assets/方法选择决策树.svg)；各方法的关键特征与适用标签见 [方法对比总览](./assets/方法对比总览.svg)。

## 七、笔记体例说明

- **小节笔记**：本节概述 → 知识要点 → 公式详解（符号/含义/适用条件）→ 例题演算 → 小结 → 关联知识点；
- **知识点（KP）**：是什么（含直觉类比）→ 怎么用（步骤+公式+演算）→ 什么时候用 → 什么时候不能用/易错 → 与相似方法的区别（对比表）→ 为什么用这个而不用那个 → 完整例子 → 速记卡 → **九、小白生活实例（手把手算，仅方法类）**；
- **章节总结**：知识框架图（mermaid+文字树）→ 核心公式清单 → 方法选择决策树 → 章节联系 → 自测题（含答案要点）→ 知识点索引；
- **案例笔记**：研究背景 → 指标体系 → 方法选择决策链 → 关键计算 → 结果结论 → 可复用模板 → 与章节对应。

> 小白增补的统一要求见 `小白增补规范.md`。所有公式、数字、结论均来自原书或经 Python 复算，演算保留中间步骤；原书排版/笔误处以"⚠️ 校注"照录说明，未作擅改。
