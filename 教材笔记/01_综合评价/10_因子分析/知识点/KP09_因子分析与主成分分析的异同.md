# KP09 · 因子分析与主成分分析的异同

## 一、是什么

因子分析（FA）与主成分分析（[[KP04_PCA与FA对比|PCA]]）在综合评价中看似相似，但本质是两种不同的多元统计方法。本知识点系统对比二者的相同点与差异点，并给出方法选择决策逻辑。

## 二、怎么用（对比分析方法）

对比两法时，依次从以下维度展开：数学模型与变换方向、是否需模型假定、研究重点、载荷/系数形式、旋转、可解释性、得分精确性、计算量、权数来源。先列相同点，再列差异表，最后落到"什么场景选哪个"。

## 三、什么时候用

- **选 PCA**：只要求排序、要求得分精确、计算简便；
- **选 FA**：既排序又要清晰解释潜在因子结构、做深入定性分析；
- 样本量大、指标相关强、只需客观降维排序时两者均可。

## 四、什么时候不能用 / 易错点

- 指标不相关、样本极小、需跨年纵向可比时，**两者都不适用**——应改用固定权数[[KP11_主观赋权vs客观赋权|主观赋权]]或[[KP09_熵值法|熵值法]]；
- 把两法不加区别混用（原书批评的常见错误）；
- 认为因子分析[[KP09_综合评价值F的构造|综合评价值]]像 PCA 一样精确——FA 得分带估计误差；
- 主成分含义模糊时强行解释而不旋转。

## 五、与相似方法的区别（详细对比表）

| 对比维度 | 主成分分析 PCA | 因子分析 FA |
|---|---|---|
| **核心思想** | 方差最大方向上的线性变换降维 | 找公共因子解释变量间相关 |
| **数学模型** | $Y=U'X$（主成分是 $X$ 的线性组合） | $X=AF+\varepsilon$（$X$ 是公因子线性组合） |
| **变换方向** | 从原始指标→主成分（合成/投影） | 从公因子→原始指标（分解/生成） |
| **是否需模型假定** | 不需要概率分布假定 | 需要[[KP02_因子模型|因子模型]]及公因子条件假定 |
| **研究重点** | 主成分方差贡献大小 | 因子分解的具体形式 |
| **载荷/系数** | $a_{ij}=u_{ij}$（特征向量分量） | $a_{ij}=u_{ij}\sqrt{\lambda_j}$（需估计） |
| **旋转** | 形式上可借用 FA 旋转 | 方差最大旋转是标准步骤 |
| **可解释性** | 主成分含义常模糊，需旋转改进 | 旋转后公因子含义清晰（**更优**） |
| **得分精确性** | 主成分得分**精确** | [[KP06_因子得分Thomson法|因子得分]]需 Thomson 估计（**带误差**） |
| **计算量** | 较小 | 较大（载荷估计+旋转+得分估计） |
| **权数** | 方差贡献率 $\lambda_i/\sum\lambda$ | 方差贡献率 $\lambda_i/\sum\lambda$（相同） |
| **共同度概念** | 无 | 有（$h_i^2$） |
| **最大优点** | 结果精确、计算简单 | 因子含义清晰、便于定性解释 |
| **最大缺点** | 主成分含义常模糊 | 结果带估计成分、计算量大 |

**相同点**：①都对原始数据 z-score [[KP11_标准化_ZScore|标准化]]；②都消除原始指标相关的信息重复；③权数都客观、由数学变换伴随生成；④都降维；⑤都以相关矩阵 $R$ 为出发点，综合指标与原始指标关系都是线性。

## 六、为什么用这个而不用那个

- **为什么 FA 因子更易解释而 PCA 不易**：FA 模型 $X=AF+\varepsilon$ 本身就是"指标由少数公因子生成"，旋转后每个公因子只主导少数指标；PCA 是"找方差最大方向"，每个主成分天然是所有指标的平均，系数平铺。
- **为什么 PCA 结果更准确**：PCA 主成分是 $Y=U'X$ 的精确投影；FA 因子得分因 $m<p$ 只能 Thomson 估计，带误差。
- **为什么 PCA 是 FA 的特例**：FA 主成分法估计中 $F_i=y_i/\sqrt{\lambda_i}$、$a_{ij}=u_{ij}\sqrt{\lambda_j}$，即从 PCA 主成分变换而来，故 FA 的旋转技术可移植到 PCA。

**方法选择决策表**：

| 场景 | 选择 | 理由 |
|---|---|---|
| 只要求排序、得分精确、计算简便 | PCA | 主成分得分精确、步骤少 |
| 既排序又要清晰解释潜在因子 | FA | 旋转后公因子含义明确 |
| 样本量大、指标相关强 | 均可 | 按是否需解释选 |
| 主成分含义模糊但想保留精确性 | PCA+旋转 | PCA 是 FA 特例 |
| 指标不相关、样本极小、跨年可比 | 都不用 | 改用固定权数法 |

## 答辩常问（带标准答案）

1. **问：因子分析比主成分分析好在哪、差在哪？** 答：好在旋转后公因子含义清晰、能命名做定性解释（FA 的最大优点）；差在因子得分只能 Thomson 估计、带误差，评价结果不如 PCA 精确，且计算量大（多了载荷估计、旋转、得分估计三步）。
2. **问：两者最根本的差异是哪一条？** 答：模型方向相反——PCA 是变换 $Y=U'X$（指标到主成分的合成投影，不需概率模型假定）；FA 是分解模型 $X=AF+\varepsilon$（公因子生成指标，需假定因子结构）。正因为 PCA 是 FA 的特例，FA 的旋转技术才能移植到 PCA。
3. **问：答辩时怎么快速选方法？** 答：只要排序、要得分精确、图简单 → PCA；既要排序又要解释背后的潜在因素、做定性归因 → FA；指标不相关、样本极小、要跨年纵向可比 → 两个都别用，改用固定权数法或熵值法。

## 八、速记卡

- 相同：标准化、消相关、权数客观、降维、以 $R$ 为出发点。
- FA 优：因子可解释；FA 劣：得分带估计误差、计算量大。
- 根本差异：PCA 是变换 $Y=U'X$；FA 是分解模型 $X=AF+\varepsilon$。
- PCA 是 FA 的特例。
