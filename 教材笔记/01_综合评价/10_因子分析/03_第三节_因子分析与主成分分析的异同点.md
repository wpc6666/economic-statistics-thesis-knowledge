## 一、本节概述

因子分析与主成分分析在综合评价中看似相似（都要合成[[KP09_综合评价值F的构造|综合评价值]]排序、都消除指标信息重复、权数都客观、都降维），但二者本质是不同的多元统计方法。本节从相同点与差异两方面系统对比，并回答第九章遗留问题"能否把[[KP05_因子旋转|因子旋转]]用于主成分"。

## 二、知识要点逐条展开

### （一）相同点

在综合评价应用上，两者基本思想一致：

1. **都对原始数据作 z-score [[KP11_标准化_ZScore|标准化]]**，消除量纲数量级影响，解决指标可综合性问题；
2. **都消除原始指标相关性的信息重复影响**：[[KP04_PCA与FA对比|PCA]] 把 $p$ 个指标转化为少数彼此独立的主成分再合成；FA 把 $p$ 个指标分解为少数彼此不相关的公因子再合成；
3. **权数都客观、伴随数学变换生成**：PCA 权数 $\omega_i=\lambda_i/\sum\lambda_j$ 及系数 $a_{ij}$ 来自 $R$ 的变换；FA 合成总[[KP06_因子得分Thomson法|因子得分]]时，公因子权数也是贡献率 $\lambda_i/\sum\lambda_j$，每个公因子中指标系数由 $A'R^{-1}$ 获得，与指标变差信息有关；
4. **都有降维特点**：在信息损失不大前提下用少数综合指标化简较多原始指标，减少评价工作量。

此外，两者都以[[01_相关系数|相关系数]]矩阵为出发点，适用范围相同；综合指标与原始指标关系都是线性的。

### （二）差异点

**1. 公共因子比主成分更容易被解释**

因子分析中即使初始因子含义不明，也可通过方差最大正交旋转使旋转后公因子有更鲜明实际意义。这不影响评价值计算，但因子含义明确更有助于评判和指标分类，有利于深入定性分析。**这是 FA 优于 PCA 之处**。

**回答第九章遗留问题**：能否把因子旋转用于 PCA？在 FA 用主成分法估计载荷时，通过 $F_i=y_i/\sqrt{\lambda_i}$ 把主成分 $y_i$ 变换为公因子 $F_i$，通过 $a_{ij}=\sqrt{\lambda_j}u_{ij}$ 把主成分系数 $u_{ji}$ 转换为因子载荷 $a_{ij}$。因此**从形式上看 PCA 可看成 FA 的特例**，FA 的方差最大旋转也就可用于 PCA。

**2. 因子分析的评价结果没有主成分分析准确**

FA 中综合评价值是少数公因子的线性加权，但公因子得分只能用回归方法估计，故综合评价值**带有估计成分**；PCA 中综合评价值虽是少数主成分线性加权，但主成分数值是**精确**的、不是估计的。因此在同样原始变差信息条件下，PCA 综合评价值比总因子得分更准确。**这是 FA 不及 PCA 之处**。

**3. 因子分析比主成分分析计算工作量大**

FA 特有的[[KP03_因子载荷矩阵A的统计意义|因子载荷矩阵]]估计、初始因子方差最大正交旋转、因子得分估计三项计算量较大；PCA 相对简单。

**4. 模型假定差异（根本性差异）**

- FA 要假定原始指标有特定模型（$X=AF+\varepsilon$），公因子要满足一定条件，重点放在**从公因子、特殊因子到原始指标的变换**上，注重因子分解的具体形式，而不注意各因子的变差信息贡献大小；
- PCA 仅仅是一种指标变换，**不需要任何概率分布和基本统计模型假定**，只以代数或几何最优化技术简化原始指标结构，重点放在**从原始指标到主成分的变换**上，注重主成分的方差贡献大小。

## 三、详细对比表

| 对比维度 | 主成分分析 PCA | 因子分析 FA |
|---|---|---|
| 核心思想 | 方差最大方向上的线性变换降维 | 找公共因子解释变量间相关 |
| 数学模型 | $Y=U'X$（主成分是 $X$ 的线性组合） | $X=AF+\varepsilon$（$X$ 是公因子的线性组合） |
| 变换方向 | 从原始指标→主成分（合成/投影） | 从公因子→原始指标（分解/生成） |
| 是否需模型假定 | 不需要概率分布假定 | 需要[[KP02_因子模型|因子模型]]及公因子条件假定 |
| 重点 | 主成分方差贡献大小 | 因子分解的具体形式 |
| 出发点 | 相关矩阵 $R$ | 相关矩阵 $R$（相同） |
| 与原始指标关系 | 线性 | 线性（相同） |
| 载荷/系数 | $a_{ij}=u_{ij}$（特征向量分量） | $a_{ij}=u_{ij}\sqrt{\lambda_j}$（需估计） |
| 旋转 | 形式上可借用 FA 旋转 | 方差最大旋转是标准步骤 |
| 可解释性 | 主成分含义常模糊，需旋转改进 | 旋转后公因子含义清晰（**更优**） |
| 得分精确性 | 主成分得分**精确** | 因子得分需 Thomson 估计（**带估计误差**） |
| 计算量 | 较小 | 较大（载荷估计+旋转+得分） |
| 权数 | 方差贡献率 $\lambda_i/\sum\lambda$ | 方差贡献率 $\lambda_i/\sum\lambda$（相同） |
| 标准化 | z-score | z-score（相同） |
| 降维 | 是 | 是（相同） |
| 适用范围 | 相关矩阵出发的降维评价 | 与 PCA 相同 |
| 最大优点 | 结果精确、计算简单 | 因子含义清晰、便于定性解释 |
| 最大缺点 | 主成分含义常不清晰 | 结果带估计成分、计算量大 |

## 四、什么时候用哪个方法（决策逻辑）

| 场景 | 选择 | 理由 |
|---|---|---|
| 只要求排序、要求得分精确、计算简便 | **PCA** | 主成分得分精确、步骤少 |
| 既排序又要清晰解释潜在因子结构、做深入定性分析 | **FA** | 旋转后公因子含义明确 |
| 样本量大、指标相关强、只需客观降维排序 | PCA 或 FA 均可 | 二者相似，按是否需解释选 |
| 主成分含义模糊但又想保留 PCA 精确性 | **PCA + 旋转** | PCA 是 FA 特例，可借用旋转 |
| 指标不相关、样本极小、需跨年纵向可比 | **两者都不用** | 改用固定权数主观赋权/熵值法 |

## 六、本节小结

- **相同**：都标准化、都消相关、权数都客观、都降维、都以 $R$ 为出发点。
- **差异**：FA 因子更易解释（旋转）但结果带估计成分、计算量大；PCA 结果精确计算简单但因子含义模糊。
- **根本差异**：FA 是分解模型（$X=AF+\varepsilon$），PCA 是变换（$Y=U'X$）。
- PCA 是 FA 的特例，故 FA 的旋转技术可移植到 PCA。

## 答辩常问（带标准答案）

1. **问：FA 和 PCA 有哪四点相同？** 答：都 z-score 标准化、都消除指标相关的信息重复、权数都客观伴随变换生成（都是 $\lambda_i/\sum\lambda$）、都降维；且都以相关矩阵 $R$ 为出发点，综合指标与原指标都是线性关系。
2. **问：差异在哪？最根本的一条是什么？** 答：①FA 因子旋转后更易解释，PCA 主成分含义常模糊 ②PCA 得分精确，FA 得分带估计误差 ③FA 计算量大。根本差异：FA 是分解模型 $X=AF+\varepsilon$ 需模型假定，PCA 只是数学变换 $Y=U'X$ 不需分布假定。
3. **问：为什么 PCA 是 FA 的特例？** 答：主成分法估计载荷时令 $F_i=y_i/\sqrt{\lambda_i}$、$a_{ij}=u_{ij}\sqrt{\lambda_j}$，就从 PCA 主成分变换出了 FA 的公因子和载荷；正因如此，FA 的方差最大旋转才能移植到 PCA 上。
