## 第一章 绪论

**1.** （概念题）某地区2024年GDP为5000亿元，2023年为4500亿元，全国平均GDP为6000亿元。请分别用时间标准和空间标准对该地区GDP水平作评价。

**解：**

- **时间标准（同比）：**
  $增速 = \dfrac{5000-4500}{4500}\times100\% = 11.11\%$
  说明该地区经济同比增长11.11%，发展态势良好。

- **空间标准（与全国平均比）：**
  $相对水平 = \dfrac{5000}{6000}\times100\% = 83.33\%$
  说明该地区GDP仅为全国平均水平的83.33%，在全国处于中等偏下位置。

- **结论：** 该地区经济增长较快（时间标准好），但绝对水平仍低于全国平均（空间标准偏弱），需多标准交叉评价。

## 第二章 综合评价的一般问题

**1.** 某企业综合评分 $I_0=80$ 分，因获国家级名牌产品，按规定加5分；同年发生一次安全事故，按规定乘修正系数 $k_1=0.8$。求最终得分。

**解：**

- 第一步：常数修正（名牌加分）：
  $I_1 = I_0 + K = 80 + 5 = 85$ 分

- 第二步：乘数修正（安全事故）：
  $I_{\text{最终}} = I_1 \times k_1 = 85 \times 0.8 = 68$ 分

- **结论：** 该企业最终得68分。名牌加分被安全事故的乘数修正大幅抵消。

**2.** 某指标体系由3个指标组成，其协方差（相关）矩阵行列式（广义方差）如下：
- 含全部3指标：$f_3=0.50$
- 去掉指标1后：$f_{2}^{(1)}=0.40$
- 去掉指标2后：$f_{2}^{(2)}=0.10$
- 去掉指标3后：$f_{2}^{(3)}=0.45$

问：按极小广义方差法，哪个指标最具代表性、应优先选入？

**解：**

- 条件广义方差最小说明去掉该指标后剩余指标变动几乎不变，即该指标最能代表其余指标信息。
- 比较：$f_{2}^{(1)}=0.40$，$f_{2}^{(2)}=0.10$，$f_{2}^{(3)}=0.45$。
- 最小者为 $f_{2}^{(2)}=0.10$（去掉指标2后）。

- **结论：** 指标2最具代表性，应优先选入指标体系。

## 第三章 综合评价指标体系的建立

**1.** （概念题）某初选指标集有10个指标，经系统聚类法在相关系数0.8的阈值上聚成4类：
- 第1类：$x_1, x_2, x_3$
- 第2类：$x_4, x_5$
- 第3类：$x_6, x_7, x_8$
- 第4类：$x_9, x_{10}$

每类指标间相关系数均≥0.8，类间<0.8。若每类选1个代表，最终指标体系应有几个指标？选择的依据是什么？

**解：**

- 最终指标体系应有4个指标（每类选1个）。
- 选择依据：
  - 类内指标高度相关（≥0.8），信息重叠，只需选1个代表；
  - 代表指标应选**经济意义最清晰、数据最易获取**的那个（定性判断），而非仅按统计量；
  - 类间相关<0.8，信息互补，4类全部保留。

- **结论：** 最终指标体系为4个指标，既消除了类内冗余，又保留了类间信息。

## 第四章 指标无量纲化方法

**1.** 某企业3项指标数据如下：

| 企业 | 销量（杯，正指标） | 差评率（%，逆指标） | 价格（元，适度指标，最优值15） |
|---|---|---|---|
| A | 100 | 2 | 14 |
| B | 80 | 5 | 18 |
| C | 60 | 8 | 12 |

请分别对三项指标同向化。

**解：**

- **销量（正指标）：** 不需同向化。

- **差评率（逆指标，用最小阈值法）：** $y_i = x_{\min}/x_i = 2/x_i$
  - A：$2/2 = 1.00$
  - B：$2/5 = 0.40$
  - C：$2/8 = 0.25$

- **价格（适度指标，最优值 $x_0=15$，用绝对值倒数法）：** $y_i = 1/|x_i-15|$
  - A：$1/|14-15| = 1/1 = 1.00$
  - B：$1/|18-15| = 1/3 = 0.333$
  - C：$1/|12-15| = 1/3 = 0.333$

- **结论：** A企业三项指标同向化后均最优（差评率=1、价格=1），综合表现最好。

**2.** 对5个学生的数学成绩（满分100）：85、70、90、60、75。
（1）用规格化法无量纲化；
（2）用标准化法（设均值 $\bar x=76$，标准差 $S=11.4$）无量纲化。

**解：**

- **（1）规格化：** $y_i = (x_i-\min)/(\max-\min)$，$\min=60$，$\max=90$，极差=30
  - 85：$(85-60)/30 = 0.833$
  - 70：$(70-60)/30 = 0.333$
  - 90：$(90-60)/30 = 1.000$
  - 60：$(60-60)/30 = 0.000$
  - 75：$(75-60)/30 = 0.500$

- **（2）标准化：** $z_i = (x_i-\bar x)/S = (x_i-76)/11.4$
  - 85：$(85-76)/11.4 = 0.79$
  - 70：$(70-76)/11.4 = -0.53$
  - 90：$(90-76)/11.4 = 1.23$
  - 60：$(60-76)/11.4 = -1.40$
  - 75：$(75-76)/11.4 = -0.09$

- **结论：** 规格化把成绩压到[0,1]；标准化以0为均值、1为标准差，保留了离差方向与大小。

## 第五章 指标重要性赋权方法

**1.** （AHP方根法）某评价问题的判断矩阵如下（3个指标）：

|  | $B_1$ | $B_2$ | $B_3$ |
|---|---|---|---|
| $B_1$ | 1 | 3 | 5 |
| $B_2$ | 1/3 | 1 | 3 |
| $B_3$ | 1/5 | 1/3 | 1 |

试用方根法求权重向量，并做一致性检验（已知 $RI=0.58$）。

**解：**

- **第一步：每行元素乘积 $M_i$：**
  - $M_1 = 1\times3\times5 = 15$
  - $M_2 = \frac13\times1\times3 = 1$
  - $M_3 = \frac15\times\frac13\times1 = \frac1{15} \approx 0.0667$

- **第二步：开 $p=3$ 次方根 $\omega_i'=\sqrt[3]{M_i}$：**
  - $\omega_1' = \sqrt[3]{15} \approx 2.466$
  - $\omega_2' = \sqrt[3]{1} = 1.000$
  - $\omega_3' = \sqrt[3]{0.0667} \approx 0.405$

- **第三步：归一化 $\omega_i = \omega_i'/\sum\omega_j'$：**
  $\sum = 2.466+1.000+0.405 = 3.871$
  - $\omega_1 = 2.466/3.871 = 0.637$
  - $\omega_2 = 1.000/3.871 = 0.258$
  - $\omega_3 = 0.405/3.871 = 0.105$

- **第四步：求 $BW$ 与 $\lambda_{\max}$：**
  - $(BW)_1 = 1\times0.637+3\times0.258+5\times0.105 = 0.637+0.774+0.525 = 1.936$
  - $(BW)_2 = \frac13\times0.637+1\times0.258+3\times0.105 = 0.212+0.258+0.315 = 0.785$
  - $(BW)_3 = \frac15\times0.637+\frac13\times0.258+1\times0.105 = 0.127+0.086+0.105 = 0.319$

  $\lambda_{\max} = \frac1p\sum_i \frac{(BW)_i}{\omega_i} = \frac13\left(\frac{1.936}{0.637}+\frac{0.785}{0.258}+\frac{0.319}{0.105}\right)$
  $= \frac13(3.040+3.043+3.038) = \frac13\times9.121 = 3.040$

- **第五步：一致性检验：**
  $CI = \dfrac{\lambda_{\max}-p}{p-1} = \dfrac{3.040-3}{2} = 0.020$

  $CR = CI/RI = 0.020/0.58 = 0.0345 < 0.10$

- **结论：** 权重向量为 $W=(0.637,\ 0.258,\ 0.105)$，一致性比率 $CR=0.0345<0.10$，通过一致性检验，判断矩阵可信。

**2.** （熵值法）有3个对象、2个指标，同向化后比重矩阵 $B=(b_{ij})$ 如下：

| 对象 | 指标1 | 指标2 |
|---|---|---|
| A | 0.5 | 0.2 |
| B | 0.3 | 0.3 |
| C | 0.2 | 0.5 |

已知 $K=1/\ln 3=0.9102$。试求两指标的权重。

**解：**

- **第一步：计算各指标熵值 $e_j = -K\sum_i b_{ij}\ln b_{ij}$：**

  指标1：$b=(0.5, 0.3, 0.2)$
  $0.5\ln0.5 = 0.5\times(-0.6931) = -0.3466$
  $0.3\ln0.3 = 0.3\times(-1.2040) = -0.3612$
  $0.2\ln0.2 = 0.2\times(-1.6094) = -0.3219$
  求和 = $-1.0297$
  $e_1 = -0.9102\times(-1.0297) = 0.937$

  指标2：$b=(0.2, 0.3, 0.5)$
  与指标1对称，求和 = $-1.0297$
  $e_2 = 0.937$

- **第二步：差异系数 $d_j = 1-e_j$：**
  $d_1 = 1-0.937 = 0.063$
  $d_2 = 1-0.937 = 0.063$

- **第三步：归一化得权数：**
  $\omega_1 = d_1/(d_1+d_2) = 0.063/0.126 = 0.5$
  $\omega_2 = 0.5$

- **结论：** 两指标离散程度相同，权重相等（均为0.5）。若实际数据某指标分布更分散（如 $b=(0.8,0.1,0.1)$），则其熵值更小、差异系数更大、权重更高。

## 第六章 综合评价数值的综合方法

**1.** 某3个学生3门课成绩（已无量纲化，0~1）如下：

| 学生 | 语文 $x_1$ | 数学 $x_2$ | 英语 $x_3$ |
|---|---|---|---|
| A | 0.8 | 0.6 | 0.9 |
| B | 0.6 | 0.9 | 0.5 |
| C | 0.5 | 0.5 | 0.5 |

权数 $w=(0.3,\ 0.4,\ 0.3)$。
（1）用线性综合法求综合得分；
（2）用几何综合法求综合得分（设权数即指数）。

**解：**

- **（1）线性综合 $z=\sum w_i x_i$：**
  - A：$0.3\times0.8+0.4\times0.6+0.3\times0.9 = 0.24+0.24+0.27 = 0.75$
  - B：$0.3\times0.6+0.4\times0.9+0.3\times0.5 = 0.18+0.36+0.15 = 0.69$
  - C：$0.3\times0.5+0.4\times0.5+0.3\times0.5 = 0.15+0.20+0.15 = 0.50$

  排序：A > B > C

- **（2）几何综合 $z=\prod x_i^{w_i}$：**
  - A：$0.8^{0.3}\times0.6^{0.4}\times0.9^{0.3}$
    $\ln z_A = 0.3\ln0.8+0.4\ln0.6+0.3\ln0.9$
    $= 0.3\times(-0.223)+0.4\times(-0.511)+0.3\times(-0.105)$
    $= -0.067-0.204-0.032 = -0.303$
    $z_A = e^{-0.303} = 0.738$

  - B：$\ln z_B = 0.3\ln0.6+0.4\ln0.9+0.3\ln0.5$
    $= 0.3\times(-0.511)+0.4\times(-0.105)+0.3\times(-0.693)$
    $= -0.153-0.042-0.208 = -0.403$
    $z_B = e^{-0.403} = 0.668$

  - C：$z_C = 0.5^{0.3+0.4+0.3} = 0.5^1 = 0.500$

  排序：A > B > C

- **结论：** 两种方法排序一致（A最优）；但几何法对低分更敏感（B的数学高分被英语0.5拖累更明显）。

## 第七章 几种常规综合评价方法

**1.** （功效系数法）某企业正向指标 $x=80$，不允许值 $x^{(s)}=60$，满意值 $x^{(h)}=100$。求功效系数 $d$。

**解：**

- 公式：$d = \dfrac{x-x^{(s)}}{x^{(h)}-x^{(s)}}\times40+60$

- 代入：$d = \dfrac{80-60}{100-60}\times40+60 = \dfrac{20}{40}\times40+60 = 20+60 = 80$

- **结论：** 该企业功效系数为80分（介于不允许值60与满意值100中间）。

**2.** （RSR法）3个企业2项指标，数值越大越好，已排秩如下（1为最优）：

| 企业 | 指标1位次 $r_{i1}$ | 指标2位次 $r_{i2}$ |
|---|---|---|
| 甲 | 1 | 3 |
| 乙 | 2 | 1 |
| 丙 | 3 | 2 |

设权数 $w=(0.5,\ 0.5)$，$n=3$，$p=2$。求RSR并排序。

**解：**

- 公式：$z_i = \dfrac{100}{np}\sum_j w_j r_{ij}$

- 甲：$\sum w_j r_{ij} = 0.5\times1+0.5\times3 = 0.5+1.5 = 2.0$
  $z_{\text{甲}} = \dfrac{100}{3\times2}\times2.0 = \dfrac{100}{6}\times2.0 = 33.33$

- 乙：$0.5\times2+0.5\times1 = 1.0+0.5 = 1.5$
  $z_{\text{乙}} = \dfrac{100}{6}\times1.5 = 25.00$

- 丙：$0.5\times3+0.5\times2 = 1.5+1.0 = 2.5$
  $z_{\text{丙}} = \dfrac{100}{6}\times2.5 = 41.67$

- **结论：** RSR越小越好，排序为 **乙(25.00) < 甲(33.33) < 丙(41.67)**，乙最优。

## 第八章 灰色关联度评价法

**1.** 某地区3年GDP（参考序列 $x_0$，亿元）与3个产业产值（比较序列 $x_1, x_2, x_3$）数据如下（已初值化）：

| 年份 | $x_0$（GDP） | $x_1$（一产） | $x_2$（二产） | $x_3$（三产） |
|---|---|---|---|---|
| 1 | 1.00 | 1.00 | 1.00 | 1.00 |
| 2 | 1.20 | 1.10 | 1.15 | 1.30 |
| 3 | 1.50 | 1.20 | 1.30 | 1.70 |

取分辨系数 $\rho=0.5$，求各产业与GDP的关联度，并排序。

**解：**

- **第一步：求绝对差 $\Delta_{0k}(t)=|x_0(t)-x_k(t)|$：**

  | 年份 | $\Delta_{01}$ | $\Delta_{02}$ | $\Delta_{03}$ |
  |---|---|---|---|
  | 1 | 0 | 0 | 0 |
  | 2 | $|1.20-1.10|=0.10$ | $|1.20-1.15|=0.05$ | $|1.20-1.30|=0.10$ |
  | 3 | $|1.50-1.20|=0.30$ | $|1.50-1.30|=0.20$ | $|1.50-1.70|=0.20$ |

- **第二步：两级最大差、最小差：**
  $\Delta(\min) = 0$（第1年所有序列差值为0）
  $\Delta(\max) = 0.30$（第3年一产差值）

- **第三步：关联系数 $\xi_{0k}(t)=\dfrac{\Delta(\min)+\rho\Delta(\max)}{\Delta_{0k}(t)+\rho\Delta(\max)}=\dfrac{0+0.5\times0.30}{\Delta+0.5\times0.30}=\dfrac{0.15}{\Delta+0.15}$：**

  | 年份 | $\xi_{01}$ | $\xi_{02}$ | $\xi_{03}$ |
  |---|---|---|---|
  | 1 | $0.15/0.15=1.000$ | 1.000 | 1.000 |
  | 2 | $0.15/0.25=0.600$ | $0.15/0.20=0.750$ | $0.15/0.25=0.600$ |
  | 3 | $0.15/0.45=0.333$ | $0.15/0.35=0.429$ | $0.15/0.35=0.429$ |

- **第四步：关联度 $r_{0k}=\frac1n\sum_t\xi_{0k}(t)$：**
  - $r_{01} = (1.000+0.600+0.333)/3 = 1.933/3 = 0.644$
  - $r_{02} = (1.000+0.750+0.429)/3 = 2.179/3 = 0.726$
  - $r_{03} = (1.000+0.600+0.429)/3 = 2.029/3 = 0.676$

- **结论：** 关联序为 $r_{02}(0.726) > r_{03}(0.676) > r_{01}(0.644)$，第二产业与GDP关联最密切，是主导产业。

## 第九章 模糊综合评价方法

**1.** 评价某餐厅，因素集 $U=\{口味,\ 价格,\ 服务\}$，评语集 $V=\{好,\ 中,\ 差\}$。权向量 $A=(0.5,\ 0.3,\ 0.2)$。模糊关系矩阵：

$$R=\begin{pmatrix}0.6&0.3&0.1\\0.2&0.5&0.3\\0.4&0.4&0.2\end{pmatrix}$$

用"乘与有界和"算子求评价向量 $B$，并按最大隶属原则判级。

**解：**

- **算子：** $b_j = \sum_i a_i r_{ij}$（因加权和远小于1，$\min\{1,\cdot\}$ 不触发）

- **"好"列：** $b_1 = 0.5\times0.6+0.3\times0.2+0.2\times0.4 = 0.30+0.06+0.08 = 0.44$

- **"中"列：** $b_2 = 0.5\times0.3+0.3\times0.5+0.2\times0.4 = 0.15+0.15+0.08 = 0.38$

- **"差"列：** $b_3 = 0.5\times0.1+0.3\times0.3+0.2\times0.2 = 0.05+0.09+0.04 = 0.18$

- **评价向量：** $B=(0.44,\ 0.38,\ 0.18)$，和为1.00。

- **最大隶属原则：** $\max(0.44, 0.38, 0.18)=0.44$，对应"好"。

- **结论：** 该餐厅综合评价为"好"（好的隶属度0.44最高）。

## 第十章 主成分分析

**1.** 某问题相关矩阵的特征根为 $\lambda_1=3.5,\ \lambda_2=1.5,\ \lambda_3=0.6,\ \lambda_4=0.3,\ \lambda_5=0.1$（共5个指标）。
（1）求各主成分方差贡献率与累计贡献率；
（2）按累计贡献率≥85%原则，应取几个主成分？
（3）若前 $k$ 个主成分得分 $y_1, y_2$ 已知，如何构造综合评价值 $F$？

**解：**

- **（1）方差贡献率 $a_k=\lambda_k/\sum\lambda_i$：**
  $\sum\lambda_i = 3.5+1.5+0.6+0.3+0.1 = 6.0$

  | 主成分 | $\lambda$ | 贡献率 $a_k$ | 累计 $a(k)$ |
  |---|---|---|---|
  | $y_1$ | 3.5 | 58.33% | 58.33% |
  | $y_2$ | 1.5 | 25.00% | 83.33% |
  | $y_3$ | 0.6 | 10.00% | 93.33% |
  | $y_4$ | 0.3 | 5.00% | 98.33% |
  | $y_5$ | 0.1 | 1.67% | 100% |

- **（2）按累计贡献率≥85%：**
  - 取2个：累计83.33% < 85%，不够
  - 取3个：累计93.33% ≥ 85%，应取3个主成分

- **（3）综合评价值构造：**
  $F = \dfrac{\lambda_1 y_1+\lambda_2 y_2+\lambda_3 y_3}{\lambda_1+\lambda_2+\lambda_3} = \dfrac{3.5 y_1+1.5 y_2+0.6 y_3}{5.6}$

  即按方差贡献率加权求和前3个主成分得分。

- **结论：** 应取3个主成分（累计93.33%），综合评价值按方差贡献率加权。

## 第十一章 因子分析

**1.** 某因子分析问题，3个公因子的载荷矩阵（已旋转）如下：

| 指标 | $F_1$ | $F_2$ | $F_3$ |
|---|---|---|---|
| $x_1$ | 0.85 | 0.10 | 0.05 |
| $x_2$ | 0.80 | 0.15 | 0.10 |

（1）求各指标共同度 $h_i^2$；
（2）求各公因子方差贡献 $g_j$ 与方差贡献率；
（3）试命名3个公因子。

**解：**

- **（1）共同度 $h_i^2=\sum_j a_{ij}^2$：**
  - $h_1^2 = 0.85^2+0.10^2+0.05^2 = 0.7225+0.01+0.0025 = 0.735$
  - $h_2^2 = 0.80^2+0.15^2+0.10^2 = 0.64+0.0225+0.01 = 0.673$

  - $h_4^2 = 0.10^2+0.80^2+0.15^2 = 0.01+0.64+0.0225 = 0.673$
  - $h_5^2 = 0.05^2+0.10^2+0.90^2 = 0.0025+0.01+0.81 = 0.823$

- **（2）公因子方差贡献 $g_j=\sum_i a_{ij}^2$，方差贡献率 $a_j=g_j/p$（$p=5$）：**

  $g_1 = 0.85^2+0.80^2+0.20^2+0.10^2+0.05^2 = 0.7225+0.64+0.04+0.01+0.0025 = 1.415$
  $g_2 = 0.10^2+0.15^2+0.85^2+0.80^2+0.10^2 = 0.01+0.0225+0.7225+0.64+0.01 = 1.405$
  $g_3 = 0.05^2+0.10^2+0.10^2+0.15^2+0.90^2 = 0.0025+0.01+0.01+0.0225+0.81 = 0.855$

  总贡献 = $1.415+1.405+0.855 = 3.675$

  方差贡献率：
  - $a_1 = 1.415/5 = 28.3\%$
  - $a_2 = 1.405/5 = 28.1\%$
  - $a_3 = 0.855/5 = 17.1\%$
  - 累计 = 73.5%

- **（3）公因子命名：**
  - $F_1$：在 $x_1, x_2$ 上载荷高（0.85、0.80），若 $x_1, x_2$ 为经济类指标，则 $F_1$ = "经济因子"
  - $F_2$：在 $x_3, x_4$ 上载荷高，若为社会类指标，则 $F_2$ = "社会因子"
  - $F_3$：在 $x_5$ 上载荷0.90，独占，若为环境类指标，则 $F_3$ = "环境因子"

- **结论：** 旋转后载荷两极化，3个公因子含义清晰，累计解释73.5%方差。

## 第十二章 案例

**1.** （综合应用）某企业综合评价，3个指标权重 $w=(0.5,\ 0.3,\ 0.2)$，A、B两企业无量纲化后得分如下：

| 企业 | 指标1 | 指标2 | 指标3 |
|---|---|---|---|
| A | 0.9 | 0.6 | 0.7 |
| B | 0.7 | 0.9 | 0.5 |

（1）用线性综合法求两企业综合得分；
（2）若指标3为安全底线，采用几何综合法（一票否决）重新评价，设A的指标3=0.7、B的指标3=0.4，结果有何变化？

**解：**

- **（1）线性综合法：**
  - A：$0.5\times0.9+0.3\times0.6+0.2\times0.7 = 0.45+0.18+0.14 = 0.77$
  - B：$0.5\times0.7+0.3\times0.9+0.2\times0.5 = 0.35+0.27+0.10 = 0.72$

  排序：A(0.77) > B(0.72)

- **（2）几何综合法 $z=\prod x_i^{w_i}$：**
  - A：$\ln z_A = 0.5\ln0.9+0.3\ln0.6+0.2\ln0.7$
    $= 0.5\times(-0.105)+0.3\times(-0.511)+0.2\times(-0.357)$
    $= -0.053-0.153-0.071 = -0.277$
    $z_A = e^{-0.277} = 0.758$

  - B：$\ln z_B = 0.5\ln0.7+0.3\ln0.9+0.2\ln0.4$
    $= 0.5\times(-0.357)+0.3\times(-0.105)+0.2\times(-0.916)$
    $= -0.179-0.032-0.183 = -0.394$
    $z_B = e^{-0.394} = 0.674$

  排序：A(0.758) > B(0.674)

- **结论：** 两种方法都是A最优；但几何法下B被安全指标3=0.4拖累更严重（差距从0.05扩大到0.084），体现了几何法"强调均衡、惩罚短板"的特点。若B的指标3=0，则几何法直接判定B为0分（一票否决）。
