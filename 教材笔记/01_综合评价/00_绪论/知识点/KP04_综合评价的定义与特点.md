# KP04 · 综合评价的定义与特点

## 一、是什么

**综合评价（多变量综合评价方法，Comprehensive Evaluation Method）**：使用比较系统的、规范的方法，对**多个指标、多个单位同时进行评价**的方法。其基本思想是把反映被评价对象的各个指标的信息**综合起来，变换成一个综合指标**，凭此反映被评价事物的整体状况。

**直观直觉**：综合评价像"高考总分"——语文、数学、外语各科满分不同、内容不同（量纲不同），经过[[KP11_标准化_ZScore|标准化]]处理与加权，合成一个总分，再对所有考生排序。它既解决了"各科成绩此高彼低、无法整体比较"的难题，又保留了各科信息。

## 二、怎么用（综合评价的三个特点，即其运作机制）

1. **多指标同时完成**：评价过程不是一个指标接一个指标顺次完成，而是通过特殊方法将多个指标的评价**同时完成**；
2. **按重要性加权**：根据指标重要性进行**加权处理**，使评价结果更科学；
3. **综合分值排序**：结果为根据**综合分值大小**对单位排序，并据此得到结论。

整体流程（详见第一章一般步骤）：建立[[KP02_指标体系|指标体系]] → [[02_指标无量纲化|指标无量纲化]]（同质化）→ 确定权数 → 合成综合值 → 排序与分析。

## 三、什么时候用

- 需要对事物作**整体性评价**，而单个指标无法代表整体时；
- 存在**多个指标、多个参评单位**，且指标方向、程度可能不一致时；
- 典型应用：工业经济效益综合评价、小康生活水平综合评价、科技进步综合评价、国家（地区）综合实力评价等。

## 四、什么时候不能用 / 易错点

- 指标随意拼凑、不做论证就汇总（原书前言批评的第一类缺陷）；
- 不加分析地使用算术平均或简单代数和（第二类缺陷）；
- 过分相信数学方法的计算结果，不对研究目的和数据特征做分析（第三类缺陷）；
- 指标未做同向化、无量纲化就直接加权合成，结果不可比；
- 综合评价方法尚未进入规范性理论阶段，**不能把综合分值当作绝对真理**，应结合定性分析。

## 五、与单指标评价的区别

| 维度 | 单指标评价 | 综合评价 |
|---|---|---|
| 指标 | 单个/少量 | 多指标体系 |
| 评价方式 | 顺次比较 | 多指标同时 |
| 权数 | 无 | 按重要性加权 |
| 结果 | 相对指标，易矛盾 | 综合分值，可排序 |
| 特征 | 简单、灵活但片面 | **综合性、系统性** |
| 计算复杂度 | 低 | 较高（计算机可解决） |

## 六、为什么用综合评价而不用单指标评价

- 当评价目标是**整体优劣/整体排序**，且指标间出现"此高彼低"矛盾时，单指标评价无法回答，必须用综合评价；
- 综合评价把**高维（多指标）信息压缩为一维（综合分值）**，使多单位整体比较成为可能；
- 反之，若问题只涉及**单一侧面**（如"谁产量高"），则不必动用综合评价，单指标比较更简单直接。

## 七、完整例子

- **高考总分类比（自拟演示）**：不同科目（量纲不同、分值不同）→ 按规定权重（或等权）合成总分 → 按总分排序录取。
- **原书应用**：工业经济效益综合评价、小康生活水平综合评价、科技进步综合评价、国家与地区综合实力评价——均用多指标合成综合分值后排序。

## 答辩常问（带标准答案）

1. **问：综合评价的三个特点（运作机制）是什么？** 答：一是**多指标同时完成**，不是一个指标接一个指标顺次比较，而是通过特殊方法把多个指标的评价同时做完；二是**按重要性加权**，根据各指标的重要程度赋权，使结果更科学；三是**依据综合分值排序**，最后把被评价单位按综合分值大小排队得出结论。
2. **问：为什么综合评价能解决单指标评价解决不了的矛盾？** 答：单指标评价在各指标"此高彼低"时会给出互相矛盾的结论。综合评价把反映对象各侧面的多指标信息，经过同向化、无量纲化和加权，变换成一个综合指标（相当于高考把各科成绩合成总分），把高维信息压缩为一维，使多单位的整体排序成为可能，既解决整体性问题又克服单项指标的片面性。
3. **问：做综合评价时常见的三类错误是什么？** 答：一是指标随意拼凑、不做论证就汇总；二是不加分析地使用算术平均或简单代数和合成；三是过分相信数学方法的计算结果，不对研究目的和数据特征做定性分析。另外还要注意指标必须先同向化、无量纲化再加权，否则结果不可比；综合评价方法尚未完全规范化，综合分值不能当作绝对真理。

## 八、速记卡

- 定义：系统、规范地对**多指标、多单位同时**评价。
- 三特点：**同时、加权、排序**。
- 两大优势：**综合性、系统性**。
- 方法论还未规范化，结果须结合定性分析，不可盲信。
