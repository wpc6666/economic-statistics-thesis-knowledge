# KP03 · 单指标评价及其局限

## 一、是什么

**单指标评价（传统评价）**：对总体某一方面特征的**单个指标**，在不同时间、不同空间上进行对比，通过相对指标说明分析对象在一定时间、地点、条件下状况的评价方法。它是一种**简单数量比较**。

**直观直觉**：单指标评价像"盲人摸象"——摸到腿的说大象像柱子，摸到尾巴的说像绳子。每个指标都真实反映了一个侧面，但谁也代表不了整体。

## 二、怎么用

1. 选取反映某一侧面的单项[[KP01_统计指标|统计指标]]（如资金产值率、劳动生产率）；
2. 选定[[KP02_评价标准|评价标准]]（时间/空间等，见 [KP02](./KP02_评价标准.md)）；
3. 计算相对指标（如发展速度、对比比值）；
4. 据此判断该侧面的优劣。

优点：**灵活、简单、约束条件少、适用范围广泛**。

## 三、什么时候用

- 只关心事物的**某一个侧面**，且该侧面有明确指标可代表时；
- 比较单位少（两个或三个）、指标少的简单情形；
- 需要快速了解情况、发现问题、揭示矛盾时。

## 四、什么时候不能用 / 两大局限（原书）

1. **指标间相互矛盾**：各指标的变动方向和变动程度不同，常出现不同指标说明的状态相互矛盾的情况。例如两地区经济效益比较，劳动生产率甲优于乙，增加值率却乙优于甲，此时很难判断孰优孰劣；
2. **无法处理多指标、多单位**：传统评价只限于两三个单位、较少指标；进行多指标、多单位相互评价时难度极大、几乎不可能，往往出现"判断不清谁好谁差"的混乱局面。

## 五、与综合评价的区别

| 维度 | 单指标评价 | 综合评价 |
|---|---|---|
| 指标数量 | 单个（或少量）指标 | 多个指标构成体系 |
| 评价方式 | 一个指标顺次比较 | 多指标同时完成 |
| 单位数量 | 限于两三个单位 | 多个单位同时 |
| 权数 | 不涉及 | 按重要性加权 |
| 结果 | 相对指标，易相互矛盾 | 综合分值，可整体排序 |
| 优点 | 灵活、简单、约束少 | 综合性、系统性、整体性 |
| 局限 | 片面、多单位时失效 | 计算与考虑因素较复杂 |

## 六、为什么从单指标走向综合评价

- 当只需判断**单一侧面**（如"谁的劳动生产率高"），单指标评价简单有效，无需综合；
- 当需要判断**整体优劣**且出现"此指标甲好、彼指标乙好"的矛盾时，单指标评价无法给出整体结论，**必须把多个指标的信息综合为一个综合指标**，即升级为综合评价（[KP04](./KP04_综合评价的定义与特点.md)）；
- 原书指出：综合指标**既解决了评价的整体性问题，又克服了单项指标的片面性**。

## 七、完整例子（原书）

两地区经济效益比较：

- 从**劳动生产率**看：甲地区 > 乙地区；
- 从**增加值率**看：乙地区 > 甲地区。

单指标评价给出两个方向相反的结论，无法判断两地区整体经济效益孰优孰劣。要解决这一矛盾，需建立[[KP02_指标体系|指标体系]]并综合成一个综合分值，再据此排序。

## 答辩常问（带标准答案）

1. **问：单指标评价的两大局限是什么？请举例说明。** 答：第一，**指标间相互矛盾**——各指标变动方向和程度不同，常出现互相打架的结论。例如比较两地区经济效益，从劳动生产率看甲优于乙，从增加值率看却乙优于甲，无法判断整体优劣。第二，**无法处理多指标、多单位**——传统单指标比较只限于两三个单位、少量指标，参评单位一多就出现"判断不清谁好谁差"的混乱局面。
2. **问：既然单指标评价简单灵活，为什么不能一直用下去？** 答：单指标评价只反映事物的一个侧面，相当于"盲人摸象"。当评价目标是整体优劣、且不同指标给出相反方向结论时，单指标既解决不了整体性问题，也克服不了片面性。出路是把多个指标的信息综合成一个综合指标，即升级为综合评价。
3. **问：单指标评价适合用在什么场合？** 答：只关心事物某一个侧面、且该侧面有明确指标代表时；参评单位只有两三个、指标较少的简单情形；以及需要快速发现问题、揭示矛盾的初步分析阶段。这些场合用单指标比较灵活、约束少，不必动用综合评价。

## 八、速记卡

- 单指标评价 = 简单数量比较，优点是**简单灵活**，本质是"盲人摸象"。
- 两大局限：**指标互相矛盾**、**多单位多指标失效**。
- 出路：多指标 → 综合指标 → 综合评价。
