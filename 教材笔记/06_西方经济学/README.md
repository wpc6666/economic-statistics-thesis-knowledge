> 笔记风格：0 基础小白友好——先大白话，后公式；符号第一次出现必解释；每个知识点都有手把手算的生活例子。

## 一、这门课到底在学什么

一句话：**微观经济学研究"单个的人（消费者、企业）"和"单个市场"怎么通过价格做选择，以及这些选择拼起来会不会让整个社会过得更好。**

它和"宏观经济学"的分工：
- **微观**：盯树叶——你买不买奶茶、奶茶店定什么价、工人拿多少工资。
- **宏观**：盯森林——全国 GDP、通胀、失业率。

上册是微观，下册是宏观。本笔记只覆盖上册。

## 三、推荐学习路线

**第一遍（建立直觉，2 周）**：按顺序读每章的"00_章节总结"，不纠结公式，先搞懂"这章在回答什么问题"。

**第二遍（啃公式，4 周）**：按顺序读每个 KP，重点跟着"手把手算"走一遍。经济学的公式少，关键是**每个符号都要能说出它在图上是哪一段**。

**第三遍（串联，2 周）**：
- 把第 1 章（供求）和第 4、5 章（厂商）连起来看——需求曲线从消费者最优化推出来，供给曲线从厂商最优化推出来。
- 把第 6 章（要素市场）和第 3 章（成本）连起来——工资上涨 → 成本曲线移动。
- 把第 8 章（市场失灵）和第 4、5 章（市场结构）连起来——完全竞争是理想基准，现实都在偏离它。

## 四、怎么用这份笔记

- 每个知识点独立成文件，文件名格式 `KPxx_关键词.md`。
- 遇到不懂的符号，先翻到那个 KP 的"严格定义"段。
- 学完一章，画一遍 mermaid 框架图（章节总结里有），能画出来才算懂。
- 所有 KP 末尾都有"🔗 相关知识点"，看不懂就顺着链接回溯。

## 五、跨课关联

- 与 [[../02_计量经济学/README|02 计量经济学]]：微观经济学是计量经济学的"理论母体"——供给弹性、需求弹性、生产函数都是实证估计的对象。
- 与 [[../05_统计学原理/README|05 统计学原理]]：弹性、均值、方差这些概念两边都用，但经济学关心"为什么是这个数"，统计学关心"怎么从样本估这个数"。
- 与 [[../01_综合评价/README|01 综合评价]]：要素分配、效率评价背后都是微观经济学的帕累托标准。

## 宏观学习路线

1. **先学衡量**（第9章）：GDP、CPI、失业率是什么。
2. **再学短期模型**（10-12章）：收入-支出 → IS-LM → AD-AS，一步一步加变量。
3. **然后学问题和政策**（13-15章）：失业通胀、开放经济、财政货币政策。
4. **最后学长期**（第16章）：经济增长。
