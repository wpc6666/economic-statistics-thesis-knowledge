# KP01 GDP的含义与核算

> 所属：[[00_章节总结|第九章 宏观经济基本指标]]

## 1. 一句话先懂（小白版）

GDP 就是"一年里，咱们国家地盘上一共生产了多少东西，折算成钱是多少"。你可以把它想成全国人民一年的"家庭账本"——不管东西是谁造的，只要是在中国境内造的，就算中国的 GDP。

**关键直觉**：一件 10 块钱的面包，面粉厂把 3 块钱的面粉卖给面包店，面包店做成面包卖 10 块。GDP 只算最终那 10 块，**不能**把 3 块面粉 + 10 块面包 = 13 块重复算。这就是"最终产品"四个字的意思。

## 2. 严格定义

**国内生产总值（GDP）**：一定时期内（通常一年或一季度），在一国（或地区）**境内**生产的所有**最终产品与服务**的**市场价值**总和。

四个关键词一个都不能少：

| 关键词 | 含义 | 反例 |
|---|---|---|
| 市场价值 | 用货币加总，不然苹果和橘子没法加 | 你在家自己给自己做的饭不算 |
| 最终产品 | 直接卖给消费者的，不是当原料的 | 面包店买的面粉不算 GDP |
| 境内 | 按地盘算，不按国籍算 | 苹果公司在上海造的手机算中国 GDP |
| 一定时期 | 流量（一年新生产的），不是存量 | 你去年买的二手车今年转手不算今年 GDP |

## 3. 为什么三种方法算出来一样？（原理）

宏观经济里有个"循环流程图"的直觉：企业生产东西卖出去收到钱（支出），这笔钱又以工资、利息、租金、利润的形式发给家庭（收入），家庭再拿去买东西（支出）。**买者花出去的每一分钱，都是卖者收到的收入**，所以：

$$\text{产出} = \text{支出} = \text{收入}$$

这就是为什么 GDP 可以从三个角度算：生产法（增值法）、支出法、收入法。理论上三个数应该一模一样。

## 4. 支出法核算 GDP（最常用）

把全国所有人的购买加起来，按买家身份分成四块：

$$Y = C + I + G + NX$$

| 符号 | 名字 | 谁花的 | 例子 |
|---|---|---|---|
| $C$ | 消费 | 家庭 | 你买奶茶、看电影、买手机 |
| $I$ | 投资 | 企业 | 建厂房、买设备、存货变动、盖住宅 |
| $G$ | 政府购买 | 政府 | 修高铁、发公务员工资、办学校 |
| $NX$ | 净出口 | 国外 | 出口 $X$ − 进口 $M$ |

**几个新手最容易搞错的点**：

1. **投资 $I$ 不是你炒股**。宏观里的"投资"只指买实物资本（厂房、设备、住宅、存货）。你买股票只是把钱从左口袋换到右口袋，没有新生产东西，不算 GDP。
2. **政府转移支付不算 $G$**。政府发养老金、低保，只是把钱从纳税人手里转到老人手里，没换任何产品服务，所以不计入 GDP。
3. **进口要减掉**。因为你买的耐克鞋是进口的，这笔钱已经算在 $C$ 里了，但它不是中国生产的，所以要减掉 $M$。
4. **住宅不管谁买都算投资 $I$**，这是唯一例外——你自己买的自住婚房，在宏观里也算"住宅投资"。

## 5. 收入法核算 GDP

把所有人赚到的钱加起来：

$$GDP = \underbrace{工资 + 利息 + 租金 + 利润}_{要素收入} + 折旧 + 间接税 - 补助金$$

- **折旧**：机器用旧了值减少的那部分，要加回去（因为支出法里的投资是"总投资"，没扣折旧）。
- **间接税（如销售税）**：市场价比要素成本高一块税钱，加回去；政府给企业的补助金则反过来减。

## 6. 手算例子

**题目**：某小国某年数据如下（单位：亿元），用支出法算 GDP。

| 项目 | 金额 |
|---|---|
| 居民消费 | 600 |
| 企业建厂房买设备 | 150 |
| 企业存货增加 | 20 |
| 政府公务员工资 | 100 |
| 政府发养老金 | 30 |
| 出口 | 80 |
| 进口 | 50 |
| 居民买二手车 | 10（去年造的） |

**第一步：挑出计入的项目**

- $C = 600$（居民消费）
- $I = 150 + 20 = 170$（厂房设备 + 存货增加；二手车是去年造的，不计）
- $G = 100$（公务员工资是政府购买服务；养老金是转移支付，不计）
- $NX = 80 - 50 = 30$

**第二步：代入公式**

$$Y = C + I + G + NX = 600 + 170 + 100 + 30 = \mathbf{900 \text{ 亿元}}$$

**解读**：这个国家一年新生产了 900 亿元的产品和服务。

## 7. 什么时候不能用 / 容易混淆

- **GDP 不等于幸福感**：它不反映收入分配（贫富差距）、不反映家务劳动、不反映环境代价（污染了但 GDP 照样涨）。
- **GDP 不等于 GNP**：GDP 按"地盘"算，GNP 按"国籍"算。苹果公司在上海的工厂利润算中国 GDP、美国 GNP；中国海尔在美国工厂利润算美国 GDP、中国 GNP。
- **二手车、二手房、股票债券**都不计入当期 GDP——它们只是产权转移，没有新生产。
- **自己在家带孩子、自己做饭**不计入 GDP，但请保姆、下馆子就计入。这叫"市场性"原则。

## 8. 现实意义

新闻里说"2024 年中国 GDP 增长 5%"，意思就是这一年全国新生产的产品服务比去年多了 5%。GDP 是政府决定发多少钱、央行加不加息的核心依据。但越来越多人提"绿色 GDP"——把污染、资源消耗扣掉，因为 GDP 高不代表百姓真的过得好。
