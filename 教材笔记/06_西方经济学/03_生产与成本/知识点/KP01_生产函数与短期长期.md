# KP01 生产函数与短期长期

> 所属：[[00_章节总结|第3章 企业的生产和成本]]

## 1. 一句话先懂（小白版）

投入多少工人、多少设备，能产出多少杯奶茶？这个"投入 → 最大产出"的关系就是生产函数。**短期**就是店面租约还没到期（设备动不了），只能加人；**长期**就是店面能换大、设备能加。

## 2. 严格定义

**生产函数（Production Function）**：在技术既定下，一定时期内各种生产要素投入组合与最大产出之间的关系。

$$Q = f(L, K)$$

其中：
- $Q$：最大产量
- $L$：劳动投入（人时）
- $K$：资本投入（机器、店面）

**短期（Short Run）**：至少有一种生产要素数量不能调整的时期。通常假设 $K$ 固定，只有 $L$ 可变。

**长期（Long Run）**：所有生产要素都能调整的时期。

## 3. 常见生产函数

**柯布-道格拉斯生产函数（C-D 函数）**：
$$Q = A L^\alpha K^\beta$$

其中：
- $A$：技术水平
- $\alpha$：劳动产出弹性（0 < α < 1）
- $\beta$：资本产出弹性

例子：$Q = L^{0.5} K^{0.5}$，投入 4 个工人、9 台机器，$Q = \sqrt{4}\times\sqrt{9} = 2 \times 3 = 6$。

## 4. 怎么用（手把手算）

**场景**：奶茶店短期，$K=4$（4 个工位）固定，$Q = \sqrt{L} \cdot \sqrt{K} = 2\sqrt{L}$。

- $L=1$：$Q = 2\sqrt{1} = 2$ 杯
- $L=4$：$Q = 2\sqrt{4} = 4$ 杯
- $L=9$：$Q = 2\sqrt{9} = 6$ 杯

**长期**：$K$ 也能调，比如 $L=9, K=16$：
$$Q = \sqrt{9} \times \sqrt{16} = 3 \times 4 = 12 \text{ 杯}$$

## 5. 短期 vs 长期的区别

| | 短期 | 长期 |
|---|---|---|
| 固定要素 | 有（如 $K$） | 无 |
| 决策 | 雇多少工人 | 开多大店面、买多少机器 |
| 成本 | 有固定成本 FC | 全是可变成本 |
| 例子 | 租约期内的奶茶店 | 可以重新选址时 |

## 6. 容易混淆什么

| 概念 | 区别 |
|---|---|
| 短期 vs 长期 | 不是日历时间长短，而是"要素能不能调"。小工厂短期可能 1 个月，大钢厂短期可能 3 年。 |
| 生产函数 vs 成本函数 | 前者看投入产出；后者看成本产量。两者对偶。 |

## 7. 现实意义

- 为啥奶茶店生意好时先加人不加店面？店面是短期固定要素，人是可变要素。
- 为啥开分公司是长期决策？要重新租店面、办证照。
- 为啥大厂裁员是短期行为？裁人快，关产线慢。
