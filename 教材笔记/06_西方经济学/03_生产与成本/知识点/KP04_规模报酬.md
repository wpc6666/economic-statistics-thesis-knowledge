# KP04 规模报酬

## 1. 一句话先懂（小白版）

工人和机器**同时翻倍**，产量会变成原来的几倍？
- 变成 3 倍 → 规模报酬递增（越大越划算）。
- 变成 2 倍 → 规模报酬不变。
- 变成 1.5 倍 → 规模报酬递减（大而无当）。

## 2. 严格定义

**规模报酬（Returns to Scale）**：所有生产要素**同比例**增加时，产出变化的比例。

设 $Q = f(L, K)$，要素都乘 $\lambda$：
$$Q' = f(\lambda L, \lambda K)$$

三种情况：
- **规模报酬递增**：$Q' > \lambda Q$（产出增长 > 要素增长）
- **规模报酬不变**：$Q' = \lambda Q$
- **规模报酬递减**：$Q' < \lambda Q$

## 3. 怎么用（手把手算，C-D 函数）

**场景**：$Q = L^{0.6} K^{0.6}$。

**第一步**：要素乘 $\lambda = 2$：
$$Q' = (2L)^{0.6} (2K)^{0.6} = 2^{0.6+0.6} L^{0.6} K^{0.6} = 2^{1.2} Q$$

**第二步**：判断。
- $2^{1.2} \approx 2.297 > 2$ → **规模报酬递增**。

**一般规则**：C-D 函数 $Q = L^\alpha K^\beta$，$\alpha + \beta > 1$ 递增，$=1$ 不变，$<1$ 递减。

## 4. 为什么会有规模报酬变化

**递增的原因**：
- 分工专业化（人多了可以专做一件事）。
- 技术不可分割（流水线必须够大才划算）。
- 批量采购折扣。

**递减的原因**：
- 管理协调困难（公司大了层级多）。
- 决策变慢。
- 要素价格上涨（大量招人推高工资）。

## 5. 现实例子

| 行业 | 规模报酬特点 |
|---|---|
| 芯片制造 | 极强递增（一条产线百亿投资，量越大单位成本越低） |
| 农业 | 接近不变（农场翻倍，产量翻倍） |
| 手工创作 | 递减（作家再雇人也写不出更多书） |
| 互联网平台 | 先递增后不变（用户多了边际成本趋零） |

## 6. 容易混淆什么

| 概念 | 区别 |
|---|---|
| 规模报酬 vs 边际报酬递减 | 前者是所有要素同比例变（长期）；后者是其他要素固定只加一种（短期）。 |
| 规模经济 vs 规模报酬 | 规模经济是"长期平均成本随产量下降"；规模报酬是"产出与投入的比例关系"。前者含价格效应。 |

## 7. 现实意义

- 为啥芯片厂越建越大？规模报酬递增，单位成本递减。
- 为啥小餐馆能活下去？规模报酬接近不变，不需要大投入。
- 为啥微软要做云计算？数据中心规模报酬递增。
