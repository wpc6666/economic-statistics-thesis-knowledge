# KP05 需求收入弹性与交叉弹性

> 所属：[[00_章节总结|第1章 需求、供给和均衡价格]]

## 1. 一句话先懂（小白版）

- **收入弹性**：你工资涨 10%，奶茶买多了百分之几？
- **交叉弹性**：咖啡涨 10%，奶茶买多了百分之几？（咖啡和奶茶是替代关系还是互补关系？）

## 2. 严格定义

### 需求收入弹性

$$e_I = \frac{\Delta Q / Q}{\Delta I / I}$$

其中 $I$ 是消费者收入。

- $e_I > 0$：**正常品**——收入涨，需求涨。
  - $0 < e_I < 1$：**必需品**（粮食、自来水）。
  - $e_I > 1$：**奢侈品**（旅游、名牌包）。
- $e_I < 0$：**低档品**——收入涨，需求反而降（如地摊货、公交）。

### 需求交叉价格弹性

$$e_{xy} = \frac{\Delta Q_x / Q_x}{\Delta P_y / P_y}$$

其中 $x$、$y$ 是两种商品。

- $e_{xy} > 0$：**替代品**（咖啡和奶茶，咖啡涨价→奶茶需求涨）。
- $e_{xy} < 0$：**互补品**（奶茶和珍珠，奶茶涨价→珍珠需求降）。
- $e_{xy} = 0$：**无关商品**。

## 3. 为什么（原理/机制）

- 收入变化改变了"预算约束线"位置，从而改变最优消费量。
- 相关商品价格变化改变了"相对价格"，从而引发替代。

## 4. 怎么用（手把手算）

**题目**：小王月收入从 5000 涨到 6000，奶茶月消费量从 10 杯涨到 15 杯；同期咖啡从 20 涨到 25 元，奶茶月消费量又多了 3 杯。

**第一步**：算收入弹性。
- $\Delta I / I = (6000-5000)/5000 = 0.2$
- $\Delta Q / Q = (15-10)/10 = 0.5$
- $e_I = 0.5 / 0.2 = 2.5$

**解读**：$e_I = 2.5 > 1$，奶茶在小王这里是**奢侈品**（收入涨 1%，奶茶消费涨 2.5%）。

**第二步**：算交叉弹性（咖啡价格变化引起的奶茶需求变化）。
- 咖啡 $\Delta P_y / P_y = (25-20)/20 = 0.25$
- 奶茶 $\Delta Q_x / Q_x = 3/15 = 0.2$
- $e_{xy} = 0.2 / 0.25 = 0.8$

**解读**：$e_{xy} = 0.8 > 0$，咖啡和奶茶是**替代品**——咖啡涨价，奶茶需求涨。

## 5. 怎么用（判断商品类型）

**场景**：某国数据显示，地铁出行的收入弹性为 -0.3。

- $e_I = -0.3 < 0$ → 地铁是**低档品**。
- 现实印证：收入高了买私家车，少坐地铁。

## 6. 什么时候不能用

- **收入变化范围太大**：从乞丐到富豪，商品类型会变（打车从奢侈品变必需品）。
- **短期 vs 长期**：交叉弹性在长期会因消费者形成习惯而变小。

## 7. 容易混淆什么

| 概念 | 区别 |
|---|---|
| 收入弹性 vs 价格弹性 | 前者看收入变化，后者看自身价格变化。 |
| 交叉弹性 vs 价格弹性 | 前者看别的商品价格，后者看自己价格。 |
| 替代品 vs 互补品 | 交叉弹性正负号一翻，关系完全相反。 |

## 8. 现实意义

- **恩格尔定律**：食品的收入弹性 < 1，越穷的国家食品支出占比越高。
- **企业并购**：两家交叉弹性大的公司（如可口可乐和百事）并购，政府会警惕垄断。
- **判断行业景气度**：奢侈品收入弹性 > 1，经济好时暴涨，经济差时暴跌。
