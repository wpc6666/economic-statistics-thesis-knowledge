# KP01 完全垄断市场

> 所属：[[00_章节总结|第5章 不完全竞争市场]]

## 1. 一句话先懂（小白版）

整个城市只有一家自来水公司，你不喝也得喝——它想定什么价就定什么价。这就是垄断：**唯一卖者，没有替代品，别人进不来。**

## 2. 严格定义

**完全垄断（Monopoly）**：整个行业只有一个厂商，产品没有相近替代品，其他厂商无法进入。

**形成原因**：
1. **资源垄断**：独家控制关键资源（如南非钻石公司 De Beers）。
2. **政府特许**：专利、牌照（烟草、食盐）。
3. **自然垄断**：规模经济极强（自来水、电网），一家生产最划算。
4. **成本优势**：先行者成本远低于新进入者。

## 3. 垄断厂商的需求与收益

垄断厂商面对**整个市场的需求曲线**——向右下倾斜。

**关键结论**：垄断厂商的 **MR < P**。

为什么？垄断厂商要多卖一件，必须给所有商品降价。所以：
- 多卖一件多收 P 元（新增收益）。
- 但之前所有商品都要降价（损失）。
- 净收益 MR = P - 降价损失 < P。

## 4. 怎么用（手把手算）

**场景**：市场需求 $P = 100 - Q$。

**第一步**：写总收益：
$$TR = P \cdot Q = (100 - Q) Q = 100Q - Q^2$$

**第二步**：求 MR：
$$MR = \frac{dTR}{dQ} = 100 - 2Q$$

**第三步**：对比 P 和 MR。

| Q | P = 100-Q | TR = P·Q | MR = ΔTR/ΔQ |
|---|---|---|---|
| 0 | 100 | 0 | — |
| 10 | 90 | 900 | 90 |
| 20 | 80 | 1600 | 70 |
| 30 | 70 | 2100 | 50 |
| 40 | 60 | 2400 | 30 |

观察：MR = 100 - 2Q，P = 100 - Q，MR 永远比 P 小 Q。

## 5. 与完全竞争对比

| | 完全竞争 | 垄断 |
|---|---|---|
| 厂商数量 | 无数 | 1 |
| 需求曲线 | 水平 | 向右下倾斜 |
| MR 与 P | MR = P | MR < P |
| 定价权 | 无 | 有 |
| 长期利润 | 0 | > 0 |

## 6. 现实例子

- 自来水、电力、天然气（自然垄断）。
- 专利药（专利期内独家）。
- 地方铁路（资源垄断）。

## 7. 容易混淆什么

| 概念 | 区别 |
|---|---|
| 垄断 vs 寡头 | 独家 vs 少数几家。 |
| 自然垄断 vs 行政垄断 | 前者因规模经济；后者因政府特许。 |
