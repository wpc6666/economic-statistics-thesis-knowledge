# KP03 蒙代尔-弗莱明模型

## 1. 一句话先懂（小白版）

蒙代尔-弗莱明模型就是**开放经济版的 IS-LM**：把 BP 曲线加进来，研究在开放经济下，财政政策和货币政策在不同汇率制度下效果如何。

核心结论：
- **固定汇率制**：财政政策有效，货币政策无效。
- **浮动汇率制**：货币政策有效，财政政策无效。

## 2. 模型假设

1. 资本完全流动（BP 水平，$r = r_f$）。
2. 小国经济（不影响世界利率）。
3. 价格短期不变。
4. 汇率制度分两种：固定或浮动。

## 3. 固定汇率制下的政策效果

### 财政政策（政府花钱）

- IS 右移 → $r$ 上升 → 资本大量流入 → 本币有升值压力。
- 央行为了维持固定汇率，必须买美元、卖本币 → 货币供给增加 → LM 右移。
- 结果：$Y$ 大幅增加，$r$ 回到 $r_f$。**财政政策非常有效**。

### 货币政策（央行放水）

- LM 右移 → $r$ 下降 → 资本流出 → 本币有贬值压力。
- 央行为了维持固定汇率，必须卖美元、买本币 → 货币供给减少 → LM 左移回原位。
- 结果：$Y$ 不变。**货币政策完全无效**。

## 4. 浮动汇率制下的政策效果

### 财政政策（政府花钱）

- IS 右移 → $r$ 上升 → 资本流入 → 本币升值。
- 本币升值 → 出口下降、进口上升 → $NX$ 下降 → IS 左移回原位。
- 结果：$Y$ 不变，只是本币升值、净出口下降。**财政政策完全无效（完全挤出）**。

### 货币政策（央行放水）

- LM 右移 → $r$ 下降 → 资本流出 → 本币贬值。
- 本币贬值 → 出口增加、进口下降 → $NX$ 增加 → IS 右移。
- 结果：$Y$ 大幅增加。**货币政策非常有效**。

## 5. 政策效果总结表

| 汇率制度 | 财政政策 | 货币政策 |
|---|---|---|
| **固定汇率** | 有效（$Y$ 大增） | 无效（回到原位） |
| **浮动汇率** | 无效（被本币升值挤出） | 有效（$Y$ 大增） |

## 6. 手算例子

**题目**：小国开放经济，$r_f = 5\%$，资本完全流动。初始均衡 $Y=1000$，$r=5\%$。

**情形1：固定汇率制下，政府购买增加 100**

- IS 右移 500（乘数 5）→ $Y$ 涨到 1500，$r$ 升到 7%。
- $r > r_f = 5\%$，资本大量流入。
- 央行买外汇、放本币，LM 右移，$r$ 回到 5%。
- 最终 $Y = 1500$，财政政策完全有效。

**情形2：浮动汇率制下，政府购买增加 100**

- IS 右移 → $r$ 上升 → 本币升值。
- 本币升值 10%，出口下降 500，IS 左移回原位。
- 最终 $Y = 1000$，只是 $NX$ 下降。财政政策无效。

## 7. 现实意义

- **香港**：联系汇率制（固定汇率），所以香港没有独立货币政策——美联储加息香港就得跟着加。
- **中国**：有管理的浮动汇率，资本账户不完全开放，所以还能保持一定的货币政策独立性。
- **欧元区**：统一货币（固定汇率的极致），各国失去独立货币政策，只能靠财政政策调节经济。
