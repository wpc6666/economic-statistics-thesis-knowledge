# KP04 三元悖论（不可能的三位一体）

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 所属：[[00_章节总结|第十四章 开放条件下的宏观经济]]

## 1. 一句话先懂（小白版）

一个国家在开放经济里，有三个好东西想要：
1. **固定汇率**（汇率稳定，外贸好做）
2. **独立货币政策**（能自己决定加息降息）
3. **资本自由流动**（钱随便进出国门）

**但这三个最多只能同时要两个**，第三个必须放弃。这就是**三元悖论**（不可能的三位一体）。

## 2. 三种组合

| 选择 | 放弃 | 例子 |
|---|---|---|
| 固定汇率 + 资本自由流动 | 独立货币政策 | 香港（联系汇率，跟美联储走） |
| 独立货币政策 + 资本自由流动 | 固定汇率 | 美国、欧元区、日本（浮动汇率） |
| 固定汇率 + 独立货币政策 | 资本自由流动 | 中国（资本账户管制） |

## 3. 为什么三者不可兼得？（原理）

- 要固定汇率 + 资本自由流动：资本流入时本币有升值压力，央行必须买外汇放本币，货币供给被动增加——货币政策不独立。
- 要独立货币政策 + 资本自由流动：加息会吸引资本流入，本币升值压力，央行如果不干预，汇率就变——保不住固定汇率。
- 要固定汇率 + 独立货币政策：想加息但资本会流入冲击汇率，只能用资本管制挡住。

## 4. 图形直觉

画个三角形，三个顶点分别是：固定汇率、独立货币政策、资本自由流动。你选两个顶点，就必须放弃第三个顶点。

```
        固定汇率
          /\
         /  \
        /    \
       /      \
货币政策——资本自由流动
```

## 5. 现实例子

| 国家/地区 | 选择了哪两个 | 放弃了什么 |
|---|---|---|
| 香港 | 固定汇率 + 资本自由流动 | 独立货币政策 |
| 美国 | 独立货币政策 + 资本自由流动 | 固定汇率 |
| 中国 | 固定汇率（管理浮动）+ 独立货币政策 | 资本自由流动（资本管制） |
| 欧元区 | 统一货币（固定汇率）+ 资本自由流动 | 各国独立货币政策 |
| 1997 亚洲金融危机 | 泰国等想三个都要，被资本攻击，崩盘 |

## 6. 手算例子

**题目**：某小国央行想把汇率钉在 7（本币/美元），同时想加息对抗通胀。但资本完全自由流动。会发生什么？

- 央行加息 → $r$ 高于世界利率 → 资本大量流入。
- 外汇市场上大家抢本币，本币有升值压力（汇率想从 7 降到 6.5）。
- 央行为了钉住 7，必须卖本币买美元 → 本币供给增加 → 加息效果被抵消。
- 结果：加息没压住通胀，只是外汇储备增加了。

**结论**：固定汇率 + 资本自由流动下，货币政策无效——这就是三元悖论。

## 7. 容易混淆

- **三元悖论不是说三个都要不行，是最多要两个**。
- **中国的"有管理的浮动汇率"是中间状态**，不是完全固定，也不是完全浮动，所以能保留一定的货币政策独立性，但代价是资本账户不能完全开放。
- **资本管制不是万灵药**：管制成本高，容易腐败，长期会扭曲经济。

## 8. 现实意义

中国一直在推进"人民币国际化"和"资本账户开放"，但这意味着要放弃固定汇率（走向浮动）或独立货币政策。这是中国金融改革的核心权衡。2015 年汇改就是向浮动汇率迈出的一步。
