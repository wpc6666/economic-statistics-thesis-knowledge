# KP04 资本的黄金律水平

## 1. 一句话先懂（小白版）

储蓄率高，人均产出高——但产出高不等于消费高。你省太多，钱都用来建工厂了，当前能吃的用的反而少。

**黄金律**就是找到一个最优储蓄率，让稳态下**人均消费 $c^*$ 最大**。

## 2. 黄金律条件

稳态人均消费：

$$c^* = y^* - i^* = f(k^*) - (n+\delta)k^*$$

要让 $c^*$ 最大，对 $k^*$ 求导并令导数为 0：

$$MPK = n + \delta$$

其中 $MPK = f'(k)$ 是资本的边际产量。

**直觉**：多存一块钱资本，边际产出是 $MPK$，但要消耗 $(n+\delta)k$ 来维持资本。当 $MPK = n+\delta$ 时，多一个人资本既不增消费也不减消费——这就是最优点。

## 3. 手算例子

**题目**：已知 $f(k) = k^{1/2}$，$n=0.02$，$\delta=0.08$。求黄金律资本 $k_gold$ 和对应储蓄率。

**第一步：算 MPK**

$$MPK = f'(k) = \frac{1}{2}k^{-1/2} = \frac{1}{2\sqrt{k}}$$

**第二步：黄金律条件**

$$\frac{1}{2\sqrt{k}} = n + \delta = 0.1$$

$$\sqrt{k} = \frac{1}{0.2} = 5$$

$$k_{gold} = \mathbf{25}$$

**第三步：算黄金律储蓄率**

稳态条件：$s \sqrt{k} = 0.1 k$

代入 $k=25$：

$$s \times 5 = 0.1 \times 25 = 2.5$$

$$s_{gold} = 0.5 = 50\%$$

**第四步：算黄金律消费**

$$c_{gold} = y - (n+\delta)k = \sqrt{25} - 0.1 \times 25 = 5 - 2.5 = 2.5$$

## 4. 与上一个 KP 对比

- 上一个例子 $s=0.3$ 时，$k^*=9$，$c^* = y - (n+\delta)k = 3 - 0.1 \times 9 = 2.1$。
- 黄金律 $s=0.5$ 时，$c = 2.5$。
- 现在 $s=0.3$ 比黄金律低，应该多储蓄；但如果 $s=0.7$，$k$ 会更高但 $c$ 反而更低。

## 5. 容易混淆

- **黄金律不是"储蓄率越高越好"**：太高的储蓄率会让消费下降。
- **现实中各国储蓄率不一定在黄金律上**：美国储蓄率低，可能低于黄金律；中国储蓄率 40%+，可能接近或略高于黄金律。
- **黄金律是长期最优**：过渡期间可能要忍受低消费。

## 6. 现实意义

中国过去靠高储蓄高投资增长，但消费率只有 38%（美国 70%）。按黄金律逻辑，中国应该从"投资驱动"转向"消费驱动"——不是不投资，而是把储蓄率降到让消费最大的水平。
