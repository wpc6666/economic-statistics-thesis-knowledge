# KP03 储蓄率与人口增长对稳态的影响

> 所属：[[00_章节总结|第十六章 经济增长]]

## 1. 一句话先懂（小白版）

**储蓄率高** → 投资多 → 稳态人均资本高 → 人均产出高。但储蓄率不是越高越好——省太多，当前消费太少。

**人口增长快** → 每个工人要分更多新工人配资本 → 稳态人均资本低 → 人均产出低。

## 2. 储蓄率变化的影响

$s$ 上升 → $s \cdot f(k)$ 曲线上移 → 新稳态 $k^*$ 更高。

**结论**：
- 储蓄率高的国家更富（人均产出高）。
- 但储蓄率提高只有**水平效应**（人均产出水平更高），没有**长期增长效应**（长期人均增长率还是 0，靠技术进步）。
- 过渡期间：经济从旧稳态到新稳态，会经历一段高速增长。

## 3. 人口增长的影响

$n$ 上升 → 持平投资线 $(n+\delta)k$ 更陡 → 稳态 $k^*$ 更低。

**结论**：
- 人口增长快的国家更穷（人均产出低）。
- 因为每个新工人都要配资本，储蓄被"摊薄"了。
- 这就是为什么非洲高人口增长国家长期穷。

## 4. 手算例子

**题目**：已知 $f(k) = k^{1/2}$，$n=0.02$，$\delta=0.08$。

**情形1：$s = 0.3$**

$$0.3 k^{1/2} = 0.1 k \Rightarrow k^* = 9, y^* = 3$$

**情形2：$s$ 提高到 0.4**

$$0.4 k^{1/2} = 0.1 k \Rightarrow k^{1/2} = 4 \Rightarrow k^* = 16, y^* = 4$$

储蓄率从 30% 提到 40%，人均产出从 3 涨到 4——富了 33%，但长期增长率还是 0（无技术进步）。

**情形3：$n$ 提高到 0.05**

$$0.3 k^{1/2} = (0.05+0.08)k = 0.13 k$$

$$k^{1/2} = 0.3/0.13 = 2.31$$

$$k^* = 5.33, y^* = 2.31$$

人口增长率从 2% 涨到 5%，人均产出从 3 降到 2.31——穷了 23%。

## 5. 条件收敛 vs 绝对收敛

- **绝对收敛**：所有国家不管参数如何，都收敛到同一稳态——不对。
- **条件收敛**：储蓄率、人口增长率相同的国家收敛到同一稳态——对。
- **穷国增长快**：只是因为它们离自己的稳态远，不是因为穷本身。

## 6. 现实意义

- 中国高储蓄率（40%+）是过去高增长的重要原因，但不能一直靠这个。
- 印度人口增长快，人均 GDP 上不去——需要提高储蓄率和教育。
- 欧洲、日本人口负增长，稳态人均资本高，但总产出增长慢。
