# KP03 长期总供给曲线

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 所属：[[00_章节总结|第十二章 AD-AS模型]]

## 1. 一句话先懂（小白版）

短期里工资是合同钉死的，物价涨了企业多生产。但**长期里**工资可以调整：物价涨了，工人发现实际工资降了，就要求涨工资；工资涨回去，企业成本回到原来水平，就不增产了。

所以长期里，不管物价是 100 还是 200，产出都固定在**潜在产出 $Y_f$**。长期 AS 是一条垂直线。

## 2. 严格定义

**长期总供给（LRAS）曲线**：长期中，价格和工资都充分灵活调整后，经济的产出水平。

$$Y = Y_f$$

$Y_f$ 是潜在产出（充分就业产出），由经济的资本、劳动、技术决定，**与物价水平无关**。图形上是垂直于横轴 $Y_f$ 的直线。

## 3. 为什么长期 AS 垂直？（原理）

长期里：
- 工资可以灵活调整（合同到期重签）。
- 物价和工资同比例上涨，实际工资不变。
- 企业没有动力多雇人或少雇人。
- 产出回到充分就业水平 $Y_f$。

这就是古典学派的"货币中性"：物价变了，所有实际变量（产出、就业、实际工资）都不变。

## 4. 长期 AS 怎么移动？

只有**潜在产出 $Y_f$ 变化**才会移动长期 AS：

| 变动 | LRAS 移动 |
|---|---|
| 劳动力增加 | 右移 |
| 资本存量增加 | 右移 |
| 技术进步 | 右移 |
| 制度改善 | 右移 |
| 疫情导致劳动力减少 | 左移 |

长期经济增长就是 LRAS 不断右移的过程——这是 [[../../16_经济增长/00_章节总结|经济增长理论]] 研究的事。

## 5. 短期 AS 和长期 AS 的关系

- 短期 AS 向右上倾斜，与 LRAS 相交于 $P = P^e$ 的点。
- 如果实际物价 $P > P^e$，短期均衡在 LRAS 右边（产出 > 潜在，过热）。
- 长期里工人会调整预期 $P^e$ 上升，短期 AS 左移，回到 LRAS。
- 如果 $P < P^e$，短期均衡在 LRAS 左边（产出 < 潜在，衰退），长期里工人接受降工资，$P^e$ 下降，短期 AS 右移，回到 LRAS。

**长期调整机制**：经济会自动回到 LRAS，只是需要时间（工资和价格调整的时间）。

## 6. 手算例子

已知 $Y_f = 1000$，短期 AS：$Y = 1000 + 100(P - P^e)$。

**情形1**：初始 $P^e = 100$，AD 决定 $P = 110$。

- 短期：$Y = 1000 + 100 \times 10 = 1100 > Y_f$（过热）
- 长期：工人发现物价涨了，要求涨工资，$P^e$ 上升到 110，短期 AS 左移
- 新短期 AS：$Y = 1000 + 100(P - 110)$，新均衡 $P = 110$，$Y = 1000$（回到 LRAS）

**情形2**：AD 决定 $P = 90$。

- 短期：$Y = 1000 + 100 \times (-10) = 900 < Y_f$（衰退）
- 长期：失业高，工人接受降工资，$P^e$ 降到 90
- 新均衡：$P = 90$，$Y = 1000$

## 7. 容易混淆

- **长期 AS 垂直，不是水平**——和凯恩斯短期极端完全相反。
- **长期 AS 的位置是潜在产出 $Y_f$**，由供给侧（资本、劳动、技术）决定，不是需求侧。
- **短期到长期的调整靠预期和工资调整**，不是靠 AD 移动。

## 8. 现实意义

为什么长期里扩张性货币政策只会导致通胀，不会让经济增长？因为长期 AS 垂直——你把 AD 推右，产出不变，只是物价涨。这就是"货币长期中性"。政府想长期提高生活水平，不能靠印钱，只能靠技术进步、增加资本、提高劳动生产率——即移动 LRAS 右移。
