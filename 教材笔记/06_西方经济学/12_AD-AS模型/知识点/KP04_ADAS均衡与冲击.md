# KP04 AD-AS均衡与经济冲击

## 1. 一句话先懂（小白版）

AD 是需求，AS 是供给，两条线的交点就是短期均衡。外来冲击分两种：
- **需求冲击**：大家突然爱花钱了（或不敢花钱了）→ AD 移动。
- **供给冲击**：石油突然涨价、技术突然进步 → AS 移动。

每种冲击下，短期产出和物价怎么变？长期又怎么调？这就是 AD-AS 模型要回答的。

## 2. 短期均衡与长期均衡

- **短期均衡**：AD 和 SRAS 的交点。此时 $Y$ 可能高于或低于 $Y_f$。
- **长期均衡**：AD、SRAS、LRAS 三条线交于同一点。此时 $Y = Y_f$，$P = P^e$。

## 3. 需求冲击（以扩张为例）

**场景**：央行降息、政府发钱，AD 右移。

- **短期**：AD 右移 → 新交点 $P$ 上升，$Y$ 上升（> $Y_f$，经济过热）。
- **长期**：工人发现物价涨了，要求涨工资，$P^e$ 上升，SRAS 左移 → $P$ 进一步上升，$Y$ 回到 $Y_f$。

**结论**：扩张性需求政策短期能增产，长期只涨价（货币中性）。

## 4. 供给冲击（以石油危机为例）

**场景**：1973 年石油涨价 4 倍，企业成本飙升。

- **短期**：SRAS 左移 → 新交点 $P$ 上升（通胀），$Y$ 下降（衰退）——这就是**滞胀**（stagflation）。
- **政策困境**：
  - 如果扩需求（AD 右移）：$Y$ 回到 $Y_f$，但 $P$ 更高（通胀加剧）。
  - 如果不干预：长期里高失业让工资下降，SRAS 右移回原位，但要经历长时间衰退。

这就是 1970 年代西方的"滞胀"困境——菲利普斯曲线失灵了。

## 5. 手算例子

已知 $Y_f = 1000$，初始 AD：$Y = 2000 - 10P$，SRAS：$Y = 1000 + 100(P - 100)$（$P^e = 100$）。

**第一步：短期均衡**

$$2000 - 10P = 1000 + 100(P - 100)$$

$$2000 - 10P = 1000 + 100P - 10000$$

$$2000 - 10P = 100P - 9000$$

$$11000 = 110P$$

$$P = 100$$

$$Y = 2000 - 10 \times 100 = 1000$$

正好在 $Y_f = 1000$，长期均衡。

**第二步：AD 右移到 $Y = 2500 - 10P$**

$$2500 - 10P = 1000 + 100(P - 100)$$

$$2500 - 10P = 100P - 9000$$

$$11500 = 110P$$

$$P = 104.55$$

$$Y = 2500 - 10 \times 104.55 = 1454.5$$

短期：$Y = 1454.5 > Y_f$（过热），$P = 104.55 > P^e = 100$。

**第三步：长期调整**

工人预期调整 $P^e = 104.55$，新 SRAS：$Y = 1000 + 100(P - 104.55)$。

$$2500 - 10P = 1000 + 100(P - 104.55)$$

$$2500 - 10P = 100P - 9455$$

$$11955 = 110P$$

$$P = 108.68$$

$$Y = 2500 - 10 \times 108.68 = 1413.2$$

（这里为了教学简化，实际调整会一直持续到 $Y = 1000$，$P = 150$。）

## 6. 政策含义

| 冲击类型 | 短期对策 | 长期结果 |
|---|---|---|
| 需求不足（衰退） | 扩 AD（财政/货币） | 短期 $Y$ 回 $Y_f$，长期通胀 |
| 供给冲击（滞胀） | 两难：扩需求则通胀，不干预则衰退 | 靠工资调整缓慢恢复 |
| 技术进步（有利供给） | 不用干预，AS 右移 | $Y$ 增、$P$ 降，黄金时代 |

## 7. 容易混淆

- **需求冲击：产出和物价同方向变**（AD 右移，$P$ 和 $Y$ 都涨）。
- **供给冲击：产出和物价反方向变**（AS 左移，$P$ 涨、$Y$ 降 = 滞胀）。
- **长期里经济自动回到 $Y_f$**，但可能要几年，社会代价大——这就是政府干预的理由。

## 8. 现实意义

2020 年疫情是典型的**双重冲击**：
- 需求侧：大家不敢出门消费，AD 左移。
- 供给侧：工厂停工、物流中断，AS 左移。
- 结果：美国靠大规模发钱扩 AD，短期恢复快，但 2022 年通胀冲到 9%——这就是长期里 AD 过度右移的代价。
