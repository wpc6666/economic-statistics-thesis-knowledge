# KP02 短期总供给曲线

> 所属：[[00_章节总结|第十二章 AD-AS模型]]

## 1. 一句话先懂（小白版）

总需求曲线讲"人们想买多少"，总供给曲线讲"企业愿意生产多少"。

**短期里**，物价上涨时企业愿意多生产——因为工资等成本是合同固定的，产品涨价了，利润就高了，所以多生产。短期 AS 曲线向右上方倾斜。

**极端凯恩斯情形**：经济极度萧条，有大量闲置工人和机器，物价完全不涨，企业愿意在现有价格下生产任何数量——短期 AS 是水平的。

## 2. 严格定义

**短期总供给（SRAS）曲线**：短期内，物价水平 $P$ 与企业愿意供给的产出 $Y$ 之间的关系。

一般形式：

$$Y = Y_f + \alpha(P - P^e)$$

其中：
- $Y_f$：潜在产出（充分就业产出）。
- $P^e$：预期价格水平。
- $\alpha$：价格超预期上涨时，企业增加产出的幅度。

**直觉**：如果实际物价 $P$ 比人们预期的 $P^e$ 高，企业发现产品卖得贵了，但工资（按预期定的）没涨，利润增加，就多生产。

## 3. 为什么短期 AS 向右上倾斜？（三个理论解释）

| 理论 | 谁提的 | 核心逻辑 |
|---|---|---|
| **工资刚性理论** | 凯恩斯 | 长期劳动合同把工资钉住了，物价涨了，实际工资下降，企业多雇人多生产 |
| **错觉理论** | 卢卡斯 | 企业只看到自己产品涨价，没意识到是整体物价涨，误以为自己产品相对涨价，多生产 |
| **粘性价格理论** | 新凯恩斯 | 有些企业调价慢（菜单成本），整体物价涨时它们没涨，相对便宜，卖得多，多生产 |

三个理论不同，但结论一样：**物价超预期上涨 → 短期产出增加**。

## 4. 短期 AS 的两个特殊形状

### 凯恩斯极端情形（水平 AS）

经济严重萧条，有大量失业和闲置产能：

$$P = \bar{P} \quad (\text{固定})$$

企业在这个价格下愿意生产任何数量。总需求增加只增加产出，不涨价。这就是大萧条时的情况。

### 常规情形（向右上倾斜）

正常经济里，物价温和上涨，企业温和增产。

## 5. 短期 AS 怎么移动？

| 变动 | SRAS 移动 |
|---|---|
| 名义工资上升（工人要求涨工资） | 左移（成本上升，供给减少） |
| 原材料涨价（石油危机） | 左移 |
| 技术进步 | 右移 |
| 预期物价 $P^e$ 上升 | 左移（工人要求涨工资） |
| 潜在产出 $Y_f$ 增加 | 右移 |

## 6. 手算例子

已知 $Y_f = 1000$，$\alpha = 100$，$P^e = 100$。求：
1. $P = 100$ 时的 $Y$
2. $P = 110$ 时的 $Y$
3. $P = 90$ 时的 $Y$

**公式**：$Y = Y_f + \alpha(P - P^e)$

1. $P = 100$：$Y = 1000 + 100 \times (100-100) = \mathbf{1000}$（正好潜在产出）
2. $P = 110$：$Y = 1000 + 100 \times 10 = \mathbf{1100}$（物价超预期涨 10%，产出高于潜在）
3. $P = 90$：$Y = 1000 + 100 \times (-10) = \mathbf{900}$（物价低于预期，产出低于潜在，衰退）

## 7. 容易混淆

- **短期 AS 和长期 AS 不一样**：短期向右上，长期垂直（下一个 KP）。
- **短期 AS 的位置由预期物价 $P^e$ 决定**：$P^e$ 上升，工人要求涨工资，整条 AS 左移。
- **沿 AS 移动 vs AS 移动**：物价变 → 沿 AS 移动；工资、技术、预期变 → AS 整条移动。

## 8. 现实意义

2022 年俄乌战争导致石油暴涨，企业成本飙升，短期 AS 左移——这就是"供给冲击"，结果是物价涨、产出降（滞胀）。政府没法用简单的扩需求解决，因为扩需求会让物价更涨。
