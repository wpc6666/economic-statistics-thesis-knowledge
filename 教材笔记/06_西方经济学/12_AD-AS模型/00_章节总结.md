# 第十二章 国民收入的决定：AD-AS模型 · 章节总结

> 本章引入价格水平：AD 讲需求侧，AS 讲供给侧。交点决定短期 $P$ 和 $Y$；长期里经济回到潜在产出 $Y_f$。

## 一、本章地图

```mermaid
graph TD
    A[AD-AS模型] --> B[总需求 AD]
    A --> C[总供给 AS]

    B --> B1[从IS-LM推出]
    B1 --> B2[物价升 实际货币余额降 利率升 投资降]
    B2 --> B3[AD向右下倾斜]
    B3 --> B4[财政货币政策移动AD]

    C --> C1[短期SRAS 向右上]
    C1 --> C2[工资粘性 错觉 粘性价格]
    C --> C3[长期LRAS 垂直于潜在产出]
    C3 --> C4[工资价格充分调整 货币中性]

    B4 --> D[AD与SRAS交点 短期均衡]
    C1 --> D
    D --> D1[可能高于或低于Yf]
    D1 --> D2[长期调整 回到LRAS]

    D --> E[冲击分析]
    E --> E1[需求冲击 AD移动 P与Y同向]
    E --> E2[供给冲击 AS移动 P与Y反向 滞胀]
```

## 二、核心公式速查

| 公式 | 含义 |
|---|---|
| AD：$Y = AD(P)$ 向右下 | 物价与总需求反向 |
| SRAS：$Y = Y_f + \alpha(P - P^e)$ | 短期总供给 |
| LRAS：$Y = Y_f$ 垂直 | 长期总供给 |
| 长期均衡 | AD=SRAS=LRAS，$Y=Y_f$ |

## 三、一句话记住每个 KP

- **KP01 AD 曲线**：物价高 → 实际货币余额少 → 利率高 → 投资低 → $Y$ 低，右下倾斜。
- **KP02 短期 AS**：工资粘性下，物价超预期涨 → 企业多生产，右上倾斜。
- **KP03 长期 AS**：工资充分调整后，产出固定在 $Y_f$，垂直。
- **KP04 AD-AS 均衡**：需求冲击 $P,Y$ 同动；供给冲击 $P,Y$ 反动（滞胀）。
