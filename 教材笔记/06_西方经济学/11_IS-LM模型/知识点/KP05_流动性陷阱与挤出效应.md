# KP05 流动性陷阱与挤出效应

> 所属：[[00_章节总结|第十一章 IS-LM模型]]

## 1. 一句话先懂（小白版）

两个极端情况决定了货币政策和财政政策什么时候管用、什么时候不管用：

- **流动性陷阱**：利率已经低到不能再低，央行再怎么印钱，老百姓都把现金拿在手里——**货币政策失效**。
- **挤出效应**：政府借钱搞投资，把利率抬上去了，私人企业本来想贷款投资的，现在觉得贵就不投了——**财政政策效果打折扣**。

## 2. 流动性陷阱（凯恩斯陷阱）

### 定义

当利率极低时，人们预期利率只会上升（债券价格只会下跌），因此愿意持有任何数量的货币。货币需求曲线变成水平。

### 政策含义

- **货币政策完全失效**：央行增发货币，全部被人们以现金持有，不买债券、不投资、不消费，利率也降不下去。
- **财政政策完全有效**：IS 右移，LM 水平，$Y$ 增加但 $r$ 不变，没有挤出效应。

### 现实例子

- 日本 1990 年代后利率长期接近 0，央行量化宽松几十年，经济还是低迷。
- 美国 2008 年后联邦基金利率降到 0-0.25%，美联储搞了三轮 QE，经济才慢慢恢复。

## 3. 古典极端情况

和流动性陷阱相反：

- 利率极高，人们不持有任何投机货币，货币需求只看收入 $Y$。
- LM 曲线垂直。
- **财政政策完全无效**：IS 右移只推高利率，$Y$ 不变（挤出 100%）。
- **货币政策完全有效**：LM 右移，$Y$ 大幅增加。

这是古典学派的世界——价格灵活、市场出清、货币中性。

## 4. 中间区域

大多数时候 IS-LM 在中间区域：
- LM 向右上倾斜。
- 财政政策有效但有挤出。
- 货币政策有效但不完全。
- **政策组合最有效**：财政 + 货币配合。

## 5. 挤出效应

### 定义

政府购买增加 → IS 右移 → $r$ 上升 → 私人投资 $I = e - dr$ 下降 → 抵消一部分财政扩张效果。

### 挤出大小的决定因素

| 因素 | 挤出大 | 挤出小 |
|---|---|---|
| LM 斜率 | 陡（古典） | 平（凯恩斯） |
| 货币需求对利率敏感度 $h$ | 小 | 大 |
| 投资对利率敏感度 $d$ | 大 | 小 |
| 经济是否充分就业 | 是（资源紧张） | 否（有闲置产能） |

### 手算例子

已知 $C = 100 + 0.8Y_d$，$I = 200 - 10r$，$G = 100$，$T = 50$，$L = 0.5Y - 20r$，$M/P = 500$。

**第一步：推 IS**

$$Y = C + I + G = 100 + 0.8(Y-50) + 200 - 10r + 100$$
$$Y = 100 + 0.8Y - 40 + 200 - 10r + 100$$
$$0.2Y = 360 - 10r$$
$$Y = 1800 - 50r$$

**第二步：推 LM**

$$0.5Y - 20r = 500$$
$$Y = 1000 + 40r$$

**第三步：均衡**

$$1800 - 50r = 1000 + 40r$$
$$800 = 90r$$
$$r = 8.89$$
$$Y = 1000 + 40 \times 8.89 = 1355.6$$

**第四步：政府购买增加到 $G=200$**

IS 变成：$Y = 100 + 0.8(Y-50) + 200 - 10r + 200 = 1900 - 50r$

$$1900 - 50r = 1000 + 40r$$
$$900 = 90r$$
$$r = 10$$
$$Y = 1000 + 40 \times 10 = 1400$$

$Y$ 只增加了 $1400 - 1355.6 = 44.4$。

**如果利率不变（无挤出）**：政府购买乘数 $k_G = 1/(1-0.8) = 5$，$\Delta G = 100$，应该 $\Delta Y = 500$。

**实际只增加 44.4**——大部分被利率上升挤出了。这就是为什么 IS-LM 模型下财政政策效果比简单乘数模型小得多。

## 6. 容易混淆

- **流动性陷阱是 LM 水平，不是 IS 水平**。
- **挤出效应是 IS 移动时沿 LM 移动导致的 $r$ 上升**，不是 LM 移动。
- **凯恩斯区域财政最有效，古典区域货币最有效，中间区域两者都有效但都打折扣**。

## 7. 现实意义

2008 年中国为什么敢搞四万亿？因为当时全球金融危机，中国出口暴跌，经济有大量闲置产能（不在古典区域），挤出效应小。2015 年中国想再搞大刺激，但经济已经接近充分就业（基建饱和），挤出效应变大，所以政府转向"供给侧改革"。
