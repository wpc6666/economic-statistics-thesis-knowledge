# KP06 替代效应与收入效应

> 所属：[[00_章节总结|第2章 消费者选择]]

## 1. 一句话先懂（小白版）

奶茶从 10 块降到 5 块，你多买了。为啥多买？两个原因：
1. 奶茶相对炸鸡便宜了 → 改买奶茶（**替代效应**）。
2. 你手里 30 块能买更多东西了，等于变富了 → 多买（**收入效应**）。

## 2. 严格定义

**价格变化的总效应 = 替代效应 + 收入效应**。

**替代效应（Substitution Effect）**：商品价格变化后，**剔除实际收入变化**（用补偿预算线让效用回到原来水平），仅由相对价格变化引起的需求量变化。

**收入效应（Income Effect）**：商品价格变化后，**实际收入变化**引起的需求量变化。

$$\text{总效应} = \text{替代效应} + \text{收入效应}$$

## 3. 三种商品的分解

| 商品类型 | 替代效应 | 收入效应 | 总效应 | 需求曲线 |
|---|---|---|---|---|
| 正常品 | 负（价降量升） | 正（价降→实际收入升→多买） | 价降量升 | 向右下倾斜 |
| 低档品 | 负 | 负（价降→实际收入升→少买低档品） | 替代 > 收入，价降量升 | 向右下倾斜 |
| 吉芬品 | 负 | 负 | 收入 > 替代，价降量降 | **向右上倾斜**（例外） |

## 4. 怎么用（手把手算，图示逻辑）

**场景**：奶茶价格从 10 降到 5。

**第一步**：画原均衡点 A（1.5 杯奶茶，1 份炸鸡）。

**第二步**：奶茶降价后，预算线绕纵轴外旋，新均衡点 C。A → C 是**总效应**。

**第三步**：画一条补偿预算线（与新预算线平行，切回原无差异曲线），切于 B 点。
- A → B 是**替代效应**（相对价格变化，效用不变）。
- B → C 是**收入效应**（实际收入上升，相对价格不变）。

**结论**：总效应 = AB + BC。

## 5. 现实例子

- **正常品（奶茶）**：降价 → 多买。替代效应让你改买奶茶；收入效应让你买更多奶茶。两者同向，总效应大。
- **低档品（地摊 T 恤）**：降价 → 多买，但收入效应反向。降价后你觉得自己富了，开始买优衣库，地摊 T 恤反而少买。但替代效应仍占上风，总效应还是多买。
- **吉芬品（灾年土豆）**：土豆涨价 → 穷人更穷 → 买不起肉 → 买更多土豆。收入效应超过替代效应，需求曲线反常。

## 6. 容易混淆什么

| 概念 | 区别 |
|---|---|
| 替代效应 vs 收入效应 | 相对价格变化 vs 实际收入变化。 |
| 正常品 vs 低档品 vs 吉芬品 | 收入效应方向和大小不同。 |

## 7. 现实意义

- 为啥双十一剁手？降价 = 替代效应（便宜了）+ 收入效应（感觉自己赚了）。
- 为啥经济差时口红销量涨？收入下降 → 高档品（包）需求降 → 口红这种小奢侈品替代效应上来。
- 为啥吉芬品罕见？需要"极低档 + 占支出比重大 + 无更好替代"，现实中几乎没有。
