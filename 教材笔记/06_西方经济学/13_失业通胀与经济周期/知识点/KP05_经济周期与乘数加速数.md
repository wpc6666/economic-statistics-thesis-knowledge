# KP05 经济周期与乘数-加速数模型

> 所属：[[00_章节总结|第十三章 失业、通胀与经济周期]]

## 1. 一句话先懂（小白版）

经济不是一直平稳增长的，它有"复苏-繁荣-衰退-萧条"的周期。为什么？萨缪尔森说：**乘数和加速数相互作用**。

- **乘数**：投资增加 → 收入成倍增加。
- **加速数**：收入增加 → 需要更多产能 → 投资成倍增加。

这俩互相放大，就形成了周期性波动。

## 2. 经济周期的阶段

| 阶段 | 特征 |
|---|---|
| 复苏 | $Y$ 上升，失业下降，乐观 |
| 繁荣 | $Y$ 达到顶峰，通胀上升，过热 |
| 衰退 | $Y$ 下降，失业上升，悲观 |
| 萧条 | $Y$ 触底，高失业，产能闲置 |

## 3. 乘数-加速数模型

**加速原理**：产出变动 $\Delta Y$ 引起投资 $I$ 变动：

$$I_t = v(Y_t - Y_{t-1})$$

$v$ 是加速数（资本-产出比，一般 2-4）。意思是：要多生产 1 块钱，需要多买 $v$ 块钱的机器。

**乘数原理**：$Y_t = C_t + I_t = \alpha + \beta Y_{t-1} + v(Y_t - Y_{t-1})$。

这是个二阶差分方程，会产生**周期性波动**：

- 经济复苏 → $Y$ 增加 → 按加速数，$I$ 大增 → 按乘数，$Y$ 更大增 → 繁荣。
- 但繁荣到顶后，$Y$ 增速放缓 → 按加速数，$I$ 反而下降 → 按乘数，$Y$ 下降 → 衰退。
- 衰退到底，设备需要更新，$I$ 又开始增加 → 复苏。

## 4. 其他经济周期理论

| 理论 | 核心观点 |
|---|---|
| **消费不足论** | 工人收入低，消费跟不上生产，过剩危机 |
| **投资过度论** | 利率低时投资过度，泡沫破裂 |
| **创新周期论**（熊彼特） | 重大创新（铁路、互联网）带来繁荣，扩散完后衰退 |
| **货币信用论** | 银行信贷扩张导致繁荣，收缩导致衰退 |
| **实际经济周期理论（RBC）** | 经济波动是技术冲击导致的，不是市场失灵 |

## 5. 手算例子

**题目**：已知 $v=2$，$\beta=0.8$，$\alpha=100$。第 0 年 $Y_0=1000$，第 1 年自发投资增加到 200。求前 5 年 $Y$。

**公式**：$Y_t = C_t + I_t = 100 + 0.8Y_{t-1} + 2(Y_t - Y_{t-1})$

这是差分方程，我们用简化思路：

- $Y_1 = 100 + 0.8 \times 1000 + 200 = 100 + 800 + 200 = 1100$
- $I_2 = 2 \times (1100 - 1000) = 200$
- $Y_2 = 100 + 0.8 \times 1100 + 200 = 100 + 880 + 200 = 1180$
- $I_3 = 2 \times (1180 - 1100) = 160$
- $Y_3 = 100 + 0.8 \times 1180 + 160 = 100 + 944 + 160 = 1204$
- $I_4 = 2 \times (1204 - 1180) = 48$
- $Y_4 = 100 + 0.8 \times 1204 + 48 = 100 + 963 + 48 = 1111$

看：$Y$ 从 1000 涨到 1204，又跌到 1111——周期出现了。

## 6. 容易混淆

- **经济周期不是"错误"**，是市场运行的固有特征。
- **长期增长趋势**和**短期周期波动**要分开：$Y_t = Y_{趋势} + Y_{周期}$。
- **政府反周期政策**：衰退时扩需求，过热时压需求，平抑波动。

## 7. 现实意义

中国 2001-2007 年繁荣（WTO 红利 + 房地产启动），2008 年危机后四万亿刺激再繁荣，2010 年后增速放缓——这就是典型的周期。理解周期才能理解为什么政府要"跨周期调节"。
