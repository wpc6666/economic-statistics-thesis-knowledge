# KP03 两部门均衡国民收入决定

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>

## 1. 一句话先懂（小白版）

把消费函数和投资函数拼起来，解一个方程，就能算出全国均衡产出是多少。公式长得很简单：

$$Y^* = \frac{\alpha + I}{1 - \beta}$$

其中 $\alpha$ 是自发消费，$I$ 是投资，$\beta$ 是边际消费倾向。这个公式是整个凯恩斯主义宏观经济学的"母公式"。

## 2. 严格定义

**两部门经济**：只有家庭和企业，没有政府、没有外贸。

**均衡条件**：$Y = C + I$

**代入线性消费函数** $C = \alpha + \beta Y$：

$$Y = \alpha + \beta Y + I$$

**解出均衡收入**：

$$Y^* = \frac{\alpha + I}{1 - \beta}$$

## 3. 公式怎么来的？（完整推导）

从均衡条件开始：

$$Y = C + I$$

把消费函数 $C = \alpha + \beta Y$ 代入：

$$Y = \alpha + \beta Y + I$$

把含 $Y$ 的项移到左边：

$$Y - \beta Y = \alpha + I$$

左边提取 $Y$：

$$Y(1 - \beta) = \alpha + I$$

两边除以 $(1-\beta)$：

$$Y^* = \frac{\alpha + I}{1 - \beta}$$

**关键观察**：分母 $1-\beta = MPS$（边际储蓄倾向）。所以均衡收入 = 自发支出 / MPS。

## 4. 手算例子

**题目**：已知 $\alpha = 200$，$\beta = 0.8$，$I = 300$。求均衡收入 $Y^*$。

**第一步：代入公式**

$$Y^* = \frac{200 + 300}{1 - 0.8} = \frac{500}{0.2} = \mathbf{2500}$$

**第二步：验证**

- $C = 200 + 0.8 \times 2500 = 200 + 2000 = 2200$
- $C + I = 2200 + 300 = 2500 = Y$ ✓
- $S = Y - C = 2500 - 2200 = 300 = I$ ✓

**第三步：如果投资增加 100（从 300 涨到 400）**

$$Y^{**} = \frac{200 + 400}{0.2} = \frac{600}{0.2} = 3000$$

投资只多了 100，但收入多了 500——这就是下一个 KP 要讲的**乘数效应**。

## 5. 图形直觉（凯恩斯交叉图）

画个图：横轴 $Y$（收入），纵轴 $E$（支出）。
- 画一条 45° 线（$E=Y$，所有收支相等的点）。
- 画总支出线 $E = C + I = \alpha + I + \beta Y$，斜率为 $\beta$，截距为 $\alpha+I$。
- 两线交点就是均衡点 $Y^*$。

如果总支出线上移（比如投资增加），交点沿 45° 线向右移动——收入增加。

## 6. 容易混淆

- **均衡收入 vs 潜在收入**：$Y^*$ 是由需求决定的均衡产出，不一定是充分就业产出。如果 $Y^* < Y_{\text{潜在}}$，就是萧条缺口；$Y^* > Y_{\text{潜在}}$，就是通胀缺口。
- **$\alpha$ 和 $I$ 都是"自发支出"**：不随收入变的支出。它们增加，收入成倍增加。
- **$\beta$ 越大，乘数越大**：因为钱流转得更快（每轮都花掉 80%）。

## 7. 现实意义

这个模型告诉政府：经济差的时候，只要增加一点自发支出（搞基建、发补贴），就能把 GDP 拉起来一大块。但前提是社会上有闲置产能——如果工厂都满负荷了，再增加需求只会涨价。
