# KP01 均衡国民收入与有效需求原理

> 所属：[[00_章节总结|第十章 收入-支出模型]]

## 1. 一句话先懂（小白版）

经济大萧条时，工厂里机器闲置、工人失业，东西卖不出去。这时候**问题不是生产得不够，而是没人买**。凯恩斯说：这时候全国"想买多少"决定了"能生产多少"——你需求 8000 亿，企业就只敢生产 8000 亿，多了卖不掉压仓库。

**均衡国民收入**就是"正好卖光、企业不扩产也不裁员"那个产出水平。它由**总需求**决定，不是由生产能力决定。

## 2. 严格定义

**均衡产出（均衡国民收入）**：与**计划总需求（意愿支出）**相等的产出。在这个产出水平上，企业生产的东西刚好被买光，**非计划存货投资 = 0**。

公式（两部门）：

$$Y = C + I$$

其中 $Y$ 是实际产出（收入），$C$ 是意愿消费，$I$ 是意愿投资。

**关键区分**：
- **意愿（计划）支出**：家庭和企业真正想买的量。
- **实际支出**：事后会计核算的量，包括卖不掉堆在仓库的"非计划存货投资"。

均衡时二者相等；不均衡时，企业通过调整产量向均衡靠拢。

## 3. 为什么需求决定产出？（原理）

凯恩斯模型有四个关键假设，少一个都不成立：

1. **短期、价格刚性**：经济萧条时价格不灵活，需求少了企业不降价，而是减产裁员。
2. **有闲置资源**：工厂有空机器、工人失业，增加需求能拉来闲置产能，不会涨价。
3. **两部门简化**：先不考虑政府和外贸，只有家庭（消费）和企业（投资）。
4. **投资外生**：暂时假设企业投资是固定的（不随利率、产量变），先看消费怎么决定。

**调整机制**：
- 如果企业生产了 10000 亿，但大家只想买 8000 亿 → 2000 亿压仓库（非计划存货 +2000）→ 企业下一年减产。
- 如果企业只生产 8000 亿，但大家想买 10000 亿 → 仓库被搬空（非计划存货 -2000）→ 企业下一年增产。
- 直到生产 = 意愿购买，存货不积压也不短缺，达到均衡。

**等价条件**：由 $Y = C + I$ 和 $Y = C + S$（收入要么消费要么储蓄），两边消去 $C$，得到：

$$I = S$$

**计划投资 = 计划储蓄**是两部门均衡的另一种说法。

## 4. 手算例子

**题目**：假设两部门经济，消费函数 $C = 1000 + 0.8Y$，企业意愿投资 $I = 600$。求均衡国民收入 $Y$。

**第一步：写出均衡条件**

$$Y = C + I$$

**第二步：代入 C 和 I**

$$Y = 1000 + 0.8Y + 600$$

**第三步：移项解 Y**

$$Y - 0.8Y = 1600$$
$$0.2Y = 1600$$
$$Y = \frac{1600}{0.2} = \mathbf{8000}$$

**第四步：验证 I = S**

储蓄函数 $S = Y - C = Y - (1000 + 0.8Y) = -1000 + 0.2Y$

代入 $Y=8000$：$S = -1000 + 0.2 \times 8000 = -1000 + 1600 = 600 = I$ ✓

**解读**：这个经济的均衡产出是 8000 亿。如果企业一开始生产 9000 亿，就会有 1000 亿压仓库，下一年减产到 8000。

## 5. 容易混淆

- **事前 vs 事后**：$I=S$ 在会计核算里永远成立（事后），但在均衡条件里要求的是**计划投资 = 计划储蓄**（事前）。计划投资 ≠ 计划储蓄时，经济就会调整。
- **均衡 ≠ 充分就业**：均衡产出 8000 亿可能远低于潜在产出（比如 10000 亿），这就是"萧条均衡"。凯恩斯的革命性就在于说：市场可以自己停在一个"有失业的均衡"上。
- **凯恩斯交叉图**：45° 线（$Y=E$）和总支出线 $E=C+I$ 的交点就是均衡点。

## 6. 什么时候不能用

- 这是**短期**模型，价格刚性。长期里价格灵活，产出由供给（资本、劳动、技术）决定，那是 [[../16_经济增长/00_章节总结|经济增长理论]] 的事。
- 经济过热（充分就业、资源紧张）时，需求增加只会涨价不会增产，这个模型就失效了。
- 假设投资外生是简化，真实投资随利率变——那是 [[../11_IS-LM模型/00_章节总结|IS-LM 模型]] 要解决的。

## 7. 现实意义

2008 年金融危机、2020 年疫情，都是"大家不敢花钱 → 企业减产裁员 → 大家更不敢花钱"的恶性循环。凯恩斯的药方就是：既然民间需求不足，政府直接花钱补缺口——这就是为什么危机时各国都搞"四万亿""财政刺激"。
