# KP02 消费函数与储蓄函数

## 1. 一句话先懂（小白版）

你这个月工资 1 万块，花掉 8000、存下 2000。**消费函数**就是描述"收入多少时花多少"的公式。

凯恩斯发现一条心理规律：**收入涨了，消费也涨，但不会涨那么多**。你从月薪 1 万涨到 1.5 万，多出来的 5000 块你可能只花 3500、存 1500——这就是"边际消费倾向递减"。

## 2. 严格定义

**消费函数**：消费 $C$ 随可支配收入 $Y$ 变化的关系：

$$C = \alpha + \beta Y$$

- $\alpha$：**自发消费**——就算收入为 0，你也得吃饭租房，靠存款或借钱也要花的钱。
- $\beta$：**边际消费倾向（MPC）**——每多赚 1 块钱，多花多少钱。$0 < \beta < 1$。
- $\beta Y$：**引致消费**——由收入引出来的消费。

**储蓄函数**：$S = Y - C$，代入得：

$$S = -\alpha + (1-\beta) Y$$

- $-\alpha$：收入为 0 时你得"负储蓄"（吃老本/借钱）。
- $1-\beta$：**边际储蓄倾向（MPS）**——每多赚 1 块钱，多存多少钱。

## 3. 四个关键比率

| 比率 | 公式 | 含义 |
|---|---|---|
| **APC** 平均消费倾向 | $APC = C/Y$ | 总收入里花掉的比例 |
| **MPC** 边际消费倾向 | $MPC = \Delta C/\Delta Y = \beta$ | 多赚 1 块里花掉的比例 |
| **APS** 平均储蓄倾向 | $APS = S/Y$ | 总收入里存下的比例 |
| **MPS** 边际储蓄倾向 | $MPS = \Delta S/\Delta Y = 1-\beta$ | 多赚 1 块里存下的比例 |

**两条铁律**：

$$APC + APS = 1 \quad (\text{因为 } C+S=Y)$$

$$MPC + MPS = 1 \quad (\text{因为 }\Delta C+\Delta S=\Delta Y)$$

**APC > MPC**：因为 $APC = C/Y = (\alpha+\beta Y)/Y = \alpha/Y + \beta$，多了个 $\alpha/Y > 0$。收入越低，$\alpha/Y$ 越大，APC 越超过 MPC——穷人几乎把全部收入都花掉。

## 4. 手算例子

**题目**：已知消费函数 $C = 300 + 0.75Y$。求 $Y=1000$ 和 $Y=2000$ 时的 $C$、$S$、APC、MPC、APS、MPS。

**当 $Y=1000$：**

- $C = 300 + 0.75 \times 1000 = 300 + 750 = \mathbf{1050}$
- $S = 1000 - 1050 = \mathbf{-50}$（负储蓄，吃老本）
- $APC = 1050/1000 = \mathbf{1.05}$（花的比赚的多！）
- $APS = -50/1000 = \mathbf{-0.05}$
- $MPC = 0.75$，$MPS = 0.25$

**当 $Y=2000$：**

- $C = 300 + 0.75 \times 2000 = 300 + 1500 = \mathbf{1800}$
- $S = 2000 - 1800 = \mathbf{200}$
- $APC = 1800/2000 = \mathbf{0.9}$
- $APS = 200/2000 = \mathbf{0.1}$
- $MPC = 0.75$，$MPS = 0.25$

**观察**：
- 收入从 1000 涨到 2000，多赚 1000，多花 750（MPC=0.75），多存 250（MPS=0.25）。
- APC 从 1.05 降到 0.9——收入越高，花掉的比例越小。
- MPC 始终是 0.75（线性消费函数的斜率不变）。

## 5. 其他消费理论（补充）

凯恩斯只看"现期收入"，后来的经济学家觉得太简单：

| 理论 | 谁提的 | 核心观点 |
|---|---|---|
| **相对收入假说** | 杜森贝里 | 消费看别人怎么花（示范效应）和自己过去的习惯（棘轮效应：由奢入俭难） |
| **恒久收入假说** | 弗里德曼 | 消费看**长期平均收入**，不是临时收入。一次性奖金不会全花掉 |
| **生命周期假说** | 莫迪利安尼 | 人一生平滑消费：年轻时借钱花、中年存钱、退休吃老本 |

**政策含义**：如果政府临时减税，按恒久收入假说，老百姓知道这是一次性的，不会多花——所以临时减税刺激消费效果差；永久性减税才管用。

## 6. 容易混淆

- **APC 可以大于 1**：低收入时花的比赚的多（刷信用卡），这是正常的。
- **MPC 是斜率，APC 是射线斜率**：在图上，MPC 是消费曲线切线的斜率，APC 是该点与原点连线的斜率。
- **储蓄函数和消费函数是镜像**：知道一个就能推出另一个。

## 7. 现实意义

为什么政府发消费券比发现金更能刺激消费？因为消费券"必须花掉"，相当于强制提高 MPC；发现金老百姓可能存起来。为什么疫情后中国消费恢复慢？因为老百姓对未来收入没信心，恒久收入预期下降，MPC 变低了。
