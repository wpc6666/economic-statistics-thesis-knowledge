# KP04 泰勒规则与动态不一致

> 所属：[[00_章节总结|第十五章 宏观经济政策]]

## 1. 一句话先懂（小白版）

央行应该怎么定利率？泰勒说有个简单规则：

$$r = \pi + 0.5 \times \text{GDP缺口} + 0.5 \times (\pi - 2\%) + 2\%$$

意思是：通胀比 2% 高多少，利率就加多少；经济比潜在产出高多少，利率再加一半。

**动态不一致**：政府嘴上说要抗通胀，但老百姓知道它事后会偷偷搞通胀来骗工人降失业——所以老百姓一开始就不信，直接要求涨工资，结果只剩通胀，失业没降。解决办法是给央行一个"抗通胀"的 mandates，让它独立。

## 2. 泰勒规则

$$i_t = \pi_t + r^* + 0.5(\pi_t - \pi^*) + 0.5 \times \frac{Y_t - Y_f}{Y_f}$$

- $i_t$：名义利率
- $\pi_t$：当前通胀
- $r^*$：均衡实际利率（一般 2%）
- $\pi^*$：目标通胀（一般 2%）
- $(Y_t - Y_f)/Y_f$：GDP 缺口

**直觉**：通胀超目标 1 个百分点，名义利率加 1.5 个百分点（实际利率上升 0.5）；产出缺口 1 个百分点，利率加 0.5。

## 3. 手算例子

**题目**：当前通胀 $\pi = 3\%$，目标 $\pi^* = 2\%$，GDP 缺口 = 1%（经济过热），$r^* = 2\%$。按泰勒规则，名义利率应该多少？

$$i = 3\% + 2\% + 0.5(3\% - 2\%) + 0.5 \times 1\%$$
$$i = 3\% + 2\% + 0.5\% + 0.5\% = \mathbf{6\%}$$

**解读**：通胀偏高 + 经济过热，利率要到 6%。

## 4. 动态不一致（时间不一致性）

### 问题

政府想低失业，但如果它宣布"要抗通胀"，老百姓半信半疑：
- 如果政府真的抗通胀，不搞扩张，失业在自然率 $u_n$。
- 如果政府偷偷扩需求，通胀超预期，失业降到 $u < u_n$——更好。
- 所以政府有"食言"的激励。

### 后果

老百姓猜到政府会食言，一开始就把通胀预期 $\pi^e$ 调高。结果政府真扩需求时，工人立刻要求涨工资，实际工资没变，失业还是 $u_n$，只剩高通胀。

**坏结果**：通胀高、失业没降——这就是 1970 年代。

### 解决办法

1. **央行独立**：不让政客管利率，央行只管抗通胀。
2. **通胀目标制**：公开宣布 2% 目标，建立信誉。
3. **规则优于相机抉择**：按规则来，不随机应变。

## 5. 现实意义

- 美联储 2% 通胀目标制就是这么来的。
- 欧央行的唯一使命就是物价稳定，就是为了避免动态不一致。
- 中国央行近年也在提"预期管理"，就是为了建立抗通胀信誉。

## 6. 容易混淆

- **泰勒规则不是法律**，是经验法则，央行会根据情况调整。
- **动态不一致是"事前最优 vs 事后最优"的冲突**：事前说抗通胀最优，事后偷偷扩需求最优。
- **央行独立不是绝对的**：美国美联储主席由总统任命，国会监督。
