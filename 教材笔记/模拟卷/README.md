## 四、使用建议

1. **第一遍（11 月上旬）**：按卷1→卷2→卷3→卷4→卷5 顺序，每周末限时 180 分钟手写一套，对照参考答案背框架。
2. **第二遍（11 月下旬）**：重点做卷5（拔高）+ 卷6（数字经济专题），训练跨章节综合题与前沿热点。
3. **第三遍（考前一周）**：只看每卷【考点对照表】和【解析·得分点】，默写答题框架与公式清单。
4. 计算题数字全部可心算（MPC=0.8、U=X1X2、古诺反应函数等），符合闭卷不能用计算器要求。
