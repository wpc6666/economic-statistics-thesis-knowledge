# 第5章 平均指标与变异指标

> 所属：[[00_绪论|第1章 绪论]] ｜ 前置：[[04_总量与相对指标|第4章 总量与相对指标]] ｜ 后续：[[06_抽样与参数估计|第6章 抽样与参数估计]]

## 本章一句话定位

一组数据摆在面前，你要回答两个问题：**它的"典型水平"是多少？**（集中趋势）**它内部"散不散"？**（离中趋势）平均指标回答前者，变异指标回答后者。两个指标合起来，才能完整描述一组数据的分布特征。这是描述统计的最高潮，也是后面抽样推断、假设检验的直接基础。

## 核心公式清单

| 公式 | 含义 | 符号要点 |
|---|---|---|
| $\bar{x}=\dfrac{\sum x_i}{n}$ | 简单算术平均数 | 未分组数据 |
| $\bar{x}=\dfrac{\sum x_i f_i}{\sum f_i}$ | 加权算术平均数 | $f_i$ 是频数（权数） |
| $H=\dfrac{n}{\sum \frac{1}{x_i}}$ | 简单调和平均数 | 已知标志总量 m=xf 时与加权算术等价 |
| $H=\dfrac{\sum m_i}{\sum \frac{m_i}{x_i}}$ | 加权调和平均数 | 已知每组金额 m_i、单价 x_i |
| $G=\sqrt[n]{\prod x_i}$ | 简单几何平均数 | 用于平均发展速度、平均增长率 |
| $M_0=L+\dfrac{\Delta_1}{\Delta_1+\Delta_2}\times i$ | 组距数列众数下限公式 | L 众数组下限，Δ 与邻组频数差 |
| $M_e=L+\dfrac{\frac{n}{2}-S_{m-1}}{f_m}\times i$ | 组距数列中位数下限公式 | S 为累计频数 |
| $R=x_{\max}-x_{\min}$ | 极差 | 最粗略，只受两端影响 |
| $A.D.=\dfrac{\sum\|x_i-\bar{x}\|}{n}$ | 平均差 | 用绝对值避免正负抵消 |
| $\sigma^2=\dfrac{\sum(x_i-\mu)^2}{N}$ | 总体方差 | 除以 N |
| $s^2=\dfrac{\sum(x_i-\bar{x})^2}{n-1}$ | 样本方差 | 除以 n-1（贝塞尔校正） |
| $CV=\dfrac{s}{\bar{x}}\times100\%$ | 标准差系数 | 无量纲，可跨组比较离散度 |

## 方法选择速查

| 你想知道 | 用哪个指标 |
|---|---|
| 一般水平、无极端值、数据对称 | 算术平均数 |
| 已知每组标志总量（金额），缺频数 | 调和平均数 |
| 平均增长率、平均收益率 | 几何平均数 |
| 收入这种右偏严重的数据，想反映"典型人" | 中位数 |
| 服装尺码、最常见的分数 | 众数 |
| 数据最大跨度 | 极差 R |
| 数据整体波动程度（最常用） | 标准差 s |
| 两组数据单位不同 / 均值悬殊，比谁更"散" | 离散系数 CV |
| 分布是否对称、是否尖峰 | 偏度、峰度 |

## 自测题

1. 为什么计算居民平均收入常用中位数而不是算术平均数？
2. 一组数据 4、8、8、8、10，算术平均数、中位数、众数各是多少？分布是左偏、对称还是右偏？
3. 样本方差为什么除以 n−1 而不是 n？
4. 甲商品价格标准差 5 元、均价 50 元；乙商品标准差 8 元、均价 160 元。哪个商品价格波动相对更大？
5. 轮船顺水 100 km/h、逆水 80 km/h，来回平均速度为什么不是 90 km/h？
