# KP02 调和平均数

> 所属：[[00_章节总结|第5章 平均指标与变异指标]] ｜ 节：[[01_第一节_平均指标]]

## 1. 一句话先懂（小白版）

调和平均数就是"倒数的平均数的倒数"。当你知道每组花了多少钱、不知道买了多少斤时，用它算平均价格。它和加权算术平均数其实是同一个东西的两面——只要把 m = x·f 代进去，两个公式完全等价。

## 2. 严格定义

调和平均数是各个参与平均的数据倒数的算术平均数的倒数，又称倒数平均数，一般用于计算强度相对指标（如平均价格、平均速度）的平均数。

## 3. 公式怎么来的、为什么是它

**简单调和平均数**：

$$H = \frac{n}{\sum_{i=1}^{n} \frac{1}{x_i}}$$

**加权调和平均数**（已知每组标志总量 $m_i$）：

$$H = \frac{\sum_{i=1}^{n} m_i}{\sum_{i=1}^{n} \frac{m_i}{x_i}}$$

符号解释：
- $x_i$：第 $i$ 组的变量值（如单价、速度）
- $m_i$：第 $i$ 组的标志总量（如总金额、总里程）
- $H$：调和平均数

**为什么要倒数？** 以"平均速度"为例：顺水 100 km/h、逆水 80 km/h，来回一样远。

- 你不能直接 (100+80)/2 = 90，因为来回距离相同但花的时间不同。
- 去时每公里花 1/100 小时，回时每公里花 1/80 小时。
- 每公里平均花 $\frac{1}{2}(\frac{1}{100}+\frac{1}{80})$ 小时。
- 平均速度 = 1 ÷ 每公里平均时间 = $\frac{2}{1/100 + 1/80}$。

这就是调和平均的直觉：**当权重藏在倒数里时，要用倒数平均。**

**和加权算术平均的关系（关键）**：

加权算术平均：$\bar{x} = \dfrac{\sum x_i f_i}{\sum f_i}$

如果令 $m_i = x_i f_i$（即每组标志总量 = 变量值 × 频数），则 $f_i = m_i / x_i$，代入：

$$\bar{x} = \frac{\sum m_i}{\sum m_i / x_i} = H$$

**结论**：当已知 $m_i = x_i f_i$ 时，加权调和平均和加权算术平均**结果完全一样**。区别只在于你手里拿到的是 $f_i$ 还是 $m_i$。

## 4. 什么时候用这个方法

- 已知每组标志总量（金额、总里程、总产量），缺频数（数量、时间）。
- 典型场景：平均价格（已知各批总金额、单价）、平均速度（已知各段距离、速度）。

## 5. 为什么不用别的方法（对比）

| 场景 | 用哪个 |
|---|---|
| 已知单价 $x_i$ 和购买数量 $f_i$ | 加权算术平均 $\sum x_i f_i/\sum f_i$ |
| 已知单价 $x_i$ 和购买金额 $m_i$ | 加权调和平均 $\sum m_i/\sum(m_i/x_i)$ |
| 求平均增长率 | 几何平均 [[KP03_几何平均数]] |
| 数据对称、一般水平 | 算术平均 [[KP01_算术平均数简单与加权]] |

## 6. 例子（手算全过程）

**例 1：轮船往返平均速度**

去时 100 km/h，回时 80 km/h，路程相同。

$$H = \frac{2}{1/100 + 1/80}$$

先算分母：
- 1/100 = 0.01
- 1/80 = 0.0125
- 和 = 0.0225

$$H = 2 / 0.0225 = 88.89 \text{ km/h}$$

**为什么不是 90？** 因为去时花的时间短（距离同、速度快），回时花的时间长，总时间里"慢速段"占比更大，所以平均速度偏向慢速那一侧（88.89 < 90）。这就是调和平均恒小于等于算术平均的原因。

**例 2：鸡蛋平均进货价格**

商人进三批鸡蛋：

| 批次 | 单价 $x_i$（元/公斤） | 金额 $m_i$（元） |
|---|---|---|
| 第一批 | 10 | 1000 |
| 第二批 | 8 | 1600 |
| 第三批 | 12 | 1200 |

**先算每批买了多少公斤**（= $m_i / x_i$）：
- 第一批：1000 / 10 = 100 公斤
- 第二批：1600 / 8 = 200 公斤
- 第三批：1200 / 12 = 100 公斤

**总金额**：1000 + 1600 + 1200 = 3800 元
**总数量**：100 + 200 + 100 = 400 公斤

$$H = \frac{\sum m_i}{\sum m_i/x_i} = \frac{3800}{400} = 9.5 \text{ 元/公斤}$$

**验算**：如果用加权算术平均（已知数量 100/200/100）：
$$\bar{x} = \frac{10\times100 + 8\times200 + 12\times100}{100+200+100} = \frac{1000+1600+1200}{400} = \frac{3800}{400} = 9.5$$

完全一致——这就验证了 $m_i = x_i f_i$ 时两者等价。

## 7. 易错点 & 关联

- **易错点 1**：平均价格用算术平均。给了金额就必须用调和平均，否则权重错了。
- **易错点 2**：往返速度用算术平均。距离相同用调和；时间相同才用算术。
- **易错点 3**：以为调和平均永远小于算术平均。对正数数据，$H \le G \le \bar{x}$（均值不等式链），调和最小。
