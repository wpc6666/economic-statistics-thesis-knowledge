## 1. 一句话先懂（小白版）

几何平均数是把 n 个数乘起来再开 n 次方。它专门用来算"平均增长率、平均发展速度"——因为增长率是连乘关系（复利），你不能把每年的增长率加起来除以年数，必须用几何平均。

## 2. 严格定义

几何平均数是 n 个数据连乘积的 n 次方根，通常用于计算动态相对数（发展速度）的平均值，如平均发展速度、平均收益率。

## 3. 公式怎么来的、为什么是它

**简单几何平均数**：

$$G = \sqrt[n]{x_1 \cdot x_2 \cdots x_n} = \sqrt[n]{\prod_{i=1}^{n} x_i}$$

**加权几何平均数**（不同发展速度持续年数不同）：

$$G = \sqrt[\sum f_i]{x_1^{f_1} \cdot x_2^{f_2} \cdots x_k^{f_k}} = \sqrt[\sum f_i]{\prod x_i^{f_i}}$$

符号解释：
- $x_i$：第 $i$ 期的发展速度（如 1.08 表示增长 8%）
- $f_i$：该发展速度持续的年数
- $\prod$：连乘符号

**为什么平均增长率必须用几何，不能用算术？**

举个最简单的例子：某股票第一年涨 100%（从 100 涨到 200），第二年跌 50%（从 200 跌回 100）。

- 算术平均增长率 = (100% + (−50%)) / 2 = 25%
- 但你两年后还是 100 块，实际增长率 = 0%！

算术平均严重高估。为什么？因为增长是**连乘**关系：

$$末值 = 初值 \times (1+g_1)\times(1+g_2)\times\cdots\times(1+g_n)$$

要找一个"平均发展速度 G"，使得：

$$末值 = 初值 \times G^n$$

解得：$G = \sqrt[n]{末值/初值} = \sqrt[n]{\prod x_i}$，这就是几何平均。

**直觉**：复利是利滚利，每年的增长都建立在上一年的本利和之上。把 n 年连乘后开 n 次方，就是"每年保持固定增长率 G"的那条等效曲线。

## 4. 什么时候用这个方法

- 平均发展速度、平均增长速度。
- 平均收益率（投资、GDP、人口增长率）。
- 比率类、连乘关系的数据。
- **不能用**于绝对量数据（产量、工资等）。

## 5. 为什么不用别的方法（对比）

| 数据类型 | 用哪个平均 |
|---|---|
| 绝对量（工资、身高、产量） | 算术平均 [[KP01_算术平均数简单与加权]] |
| 比率、速度、增长率 | 几何平均 |
| 已知标志总量缺频数 | 调和平均 [[KP02_调和平均数]] |

**均值不等式链**：对正数数据，$H \le G \le \bar{x}$。几何平均恰好夹在中间。

## 6. 例子（手算全过程）

**例 1：某地区 GDP 平均发展速度**

GDP：2008 年 1000 亿 → 2009 年 1100 亿 → 2010 年 1210 亿 → 2011 年 1360 亿。

三年的发展速度：
- 2009 年：1100/1000 = 1.10
- 2010 年：1210/1100 = 1.10
- 2011 年：1360/1210 = 1.1240

**简化计算**（中间项抵消）：

$$G = \sqrt[3]{\frac{1360}{1000}} = \sqrt[3]{1.36}$$

计算 1.36 的立方根：
- 1.1 的立方 = 1.331
- 1.11 的立方 = 1.3676
- 插值：$\sqrt[3]{1.36} \approx 1.1079$

**平均发展速度 G = 110.79%**，**平均增长速度 = G − 1 = 10.79%**。

**验算**：$1000 \times (1.1079)^3 = 1000 \times 1.36 = 1360$ ✓

**例 2：加权几何平均（20 年发展速度）**

| 发展速度 $x_i$ | 年数 $f_i$ | $x_i^{f_i}$ |
|---|---|---|
| 1.02 | 1 | 1.0200 |
| 1.05 | 5 | $1.05^5$ = 1.2763 |
| 1.07 | 10 | $1.07^{10}$ = 1.9672 |
| 1.10 | 4 | $1.10^4$ = 1.4641 |
| 合计 | 20 | 乘积 = 3.7493 |

$$G = \sqrt[20]{3.7493}$$

两边取对数：$\ln G = \frac{\ln 3.7493}{20} = \frac{1.3216}{20} = 0.06608$

$$G = e^{0.06608} = 1.0683 = 106.83\%$$

平均发展速度 106.83%，平均增长速度 6.83%。

## 7. 易错点 & 关联

- **易错点 1**：平均增长率用算术平均。见上面股票例子，会严重高估。
- **易错点 2**：把增长速度直接拿来连乘。几何平均的对象是**发展速度**（= 1 + 增长率），不是增长率本身。
- **易错点 3**：数据中有 0 或负数时不能用几何平均（开方无意义）。
- **易错点 4**：跨期数搞错。从 2008 到 2011 是 3 年增长，开 3 次方，不是 4 次方。
