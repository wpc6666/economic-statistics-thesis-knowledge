# 第十章 统计指数

> 教材：韩兆洲《统计学原理（第7版）》第 10 章

## 本章一句话定位
把一堆**单位不同、不能直接相加**的东西（猪肉、白菜、汽车、房租），通过**同度量因素**（销量或价格）转成可加的销售额，加权合成一个百分数，看它们整体涨了还是跌了；并把总变动**拆账**到各个因素头上。

## 核心公式清单

| 公式 | 含义 |
|---|---|
| $L_p = \sum p_1 q_0 / \sum p_0 q_0$ | 拉氏价格指数 |
| $L_q = \sum p_0 q_1 / \sum p_0 q_0$ | 拉氏物量指数 |
| $P_p = \sum p_1 q_1 / \sum p_0 q_1$ | 派氏价格指数 |
| $P_q = \sum p_1 q_1 / \sum p_1 q_0$ | 派氏物量指数 |
| $I_p = \sum K_p \cdot p_0 q_0 / \sum p_0 q_0$ | 加权算术平均价格指数（= $L_p$） |
| $I_p = \sum p_1 q_1 / \sum (1/K_p) p_1 q_1$ | 加权调和平均价格指数（= $P_p$） |
| $\frac{\sum p_1 q_1}{\sum p_0 q_0} = \frac{\sum p_0 q_1}{\sum p_0 q_0} \times \frac{\sum p_1 q_1}{\sum p_0 q_1}$ | 指数体系（拉氏量 × 派氏价） |
| $\Delta_{总} = \Delta_{量} + \Delta_{价}$ | 绝对数拆账 |

## 方法选择速查

| 你要做什么 | 用什么 |
|---|---|
| 算价格指数（看价变） | 派氏（销量固定在报告期） |
| 算销量/产量指数（看量变） | 拉氏（价格固定在基期） |
| 手里只有个体指数 + 基期权数 | 加权算术平均 |
| 手里只有个体指数 + 报告期权数 | 加权调和平均 |
| 拆销售额变动原因 | 指数体系：拉氏量 × 派氏价 |
| 长期对比 | 杨格固定权数 |
| 折中 | 费雪理想指数 $\sqrt{L \times P}$ |
