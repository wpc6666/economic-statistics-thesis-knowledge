## 本节内容

### 一、指数的概念
广义指数是一切相对数；狭义指数是反映**不同度量事物构成的复杂总体综合变动**的特殊相对数。本章讲狭义指数。

### 二、指数的分类

| 分类维度 | 类别 | 含义 |
|---|---|---|
| 研究范围 | 个体指数 | 一种商品（如猪肉价格指数） |
|  | 总指数 | 一篮子商品（如 CPI） |
| 指标性质 | 数量指标指数 | 产量、销量（反映规模） |
|  | 质量指标指数 | 价格、成本、劳动生产率（反映水平） |
| 时间状态 | 动态指数 | 不同时间对比 |
|  | 静态指数 | 空间、计划完成等非时间对比 |
| 编制方法 | 加权综合指数 | 先加总再对比 |
|  | 加权平均指数 | 先对比再平均 |

### 三、指数的作用
1. 反映复杂总体变动方向和程度；
2. 因素分析（指数体系）；
3. 空间差异比较；
4. 反映比例关系；
5. 长期趋势分析；
6. 多指标综合评价（人类发展指数、国家创新指数）。
