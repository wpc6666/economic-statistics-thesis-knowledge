# 第三章 统计数据的整理与显示

> 教材：韩兆洲《统计学原理（第7版）》第03章

## 本章一句话定位

本章把第 2 章采集回来的杂乱原始数据，变成一张看得懂规律的频数分布表和直方图。它对应统计研究四阶段中的"统计整理"阶段，是连接采集与分析的中间桥梁。

## 核心公式清单

| 公式 | 符号 | 用途 |
|---|---|---|
| $R = X_{\max} - X_{\min}$ | 全距=最大-最小 | 算组距的基础 |
| $n = 1 + 3.3\lg N$ | n 组数，N 数据个数 | 斯特吉斯经验公式定组数 |
| $d = R / n$ | d 组距 | 定组距 |
| $\text{组中值} = (\text{下限}+\text{上限})/2$ | 开口组借邻组组距 | 代表组内一般水平 |
| 开口组组中值 $= \text{上限} - d_{\text{邻}}/2$ 或 $= \text{下限} + d_{\text{邻}}/2$ | 首末开口组 | 开口组组中值 |
| $\text{频率} = f / \sum f \times 100\%$ | f 频数 | 算频率 |
| 频数密度 = 某组次数 / 某组组距 | 不等距换算 | 画不等距直方图 |

## 方法选择速查

| 你的问题 | 用哪个 |
|---|---|
| 数据收上来先做什么 | 审核（KP01） |
| 离散变量取值少怎么分 | 单项式分组（KP02） |
| 连续变量怎么分 | 组距式分组 + 斯特吉斯公式（KP02/KP04） |
| 怎么算一组的代表值 | 组中值（KP03） |
| 怎么呈现分布 | 频数分布表 + 直方图（KP05/KP08） |
| 怎么读"X 以下有多少户" | 以下累计（KP06） |
| 论文里放数据表 | 三线表（KP07） |
| 想快速出图 | Excel 数据分析-直方图（第七节） |
