# KP03 组限与组中值

## 1. 一句话先懂（小白版）

组限就是每组的"起点和终点"，比如"800–1000 元"这一组，下限是 800、上限是 1000。组中值就是这一组正中间那个数，比如 900——它代表这一组的"平均水平"。

## 2. 严格定义

- **下限**：每组的起点数值（最小值）。
- **上限**：每组的终点数值（最大值）。
- **组距** = 上限 - 下限。
- **组中值** = 上限和下限的中点，代表组内一般水平。

### 两种组限形式

| 形式 | 适用变量 | 例子 | 处理规则 |
|---|---|---|---|
| 重合式 | 连续变量 | 不满1岁 / 1–3岁 / 3–7岁 | "含下限不含上限"，3–7 岁 = 满 3 岁不满 7 岁 |
| 不重合式 | 离散变量 | 99 人以下 / 100–499 人 / 500–999 人 | 上下限紧密相连不重叠 |

### 组中值公式

**相邻组限重合时**：

$$\text{组中值} = \frac{\text{下限} + \text{上限}}{2}$$

**开口组**（首组"多少以下"、末组"多少以上"）：

$$\text{缺下限开口组组中值} = \text{上限} - \frac{\text{邻组组距}}{2}$$

$$\text{缺上限开口组组中值} = \text{下限} + \frac{\text{邻组组距}}{2}$$

## 3. 公式怎么来的

组中值就是把下限和上限加起来除以 2，就是求中点。

例：800–1000 元这一组：
- 下限 = 800，上限 = 1000。
- 组中值 = (800 + 1000) ÷ 2 = 900。

开口组例子：
- 首组"800 以下"，邻组是 800–1000，组距 = 200。
- 组中值 = 800 - 200/2 = 800 - 100 = 700。
- 末组"2200 以上"，邻组是 2000–2200，组距 = 200。
- 组中值 = 2200 + 200/2 = 2200 + 100 = 2300。

## 4. 什么时候用

- 做组距式分组时，必须写清上下限，并算出组中值。
- 后续算加权平均数时，就用组中值代表每组的取值（见第 5 章平均指标）。
- 画直方图时，横轴用组限位置。

## 5. 为什么不用别的方式

| 做法 | 问题 |
|---|---|
| 不写组中值，只用区间 | 后续无法算平均数 |
| 开口组硬算组中值 | 没有另一边界，必须借邻组组距推算 |
| 重合式组限不声明"含下限不含上限" | 3 岁的人不知道归 1–3 还是 3–7 |

## 6. 例子

**生活实例**：某班同学月支出分组。

| 月支出（元） | 组距 | 组中值 |
|---|---|---|
| 500 以下 | 100（借邻组） | 500 - 100/2 = 450 |
| 500–600 | 100 | (500+600)/2 = 550 |
| 600–700 | 100 | 650 |
| 700–800 | 100 | 750 |
| 800 以上 | 100（借邻组） | 800 + 100/2 = 850 |

- 手算验证：相邻组中值差 100，正好等于组距。

**经济实例**：原书表 3-8 某市居民月人均可支配收入。

| 收入组（元） | 组中值（元） | 户数 |
|---|---|---|
| 800–1000 | 900 | 5 |
| 1000–1200 | 1100 | 7 |
| 1200–1400 | 1300 | 10 |
| 1400–1600 | 1500 | 13 |
| 1600–1800 | 1700 | 8 |
| 1800–2000 | 1900 | 6 |
| 2000–2200 | 2100 | 3 |
| 2200–2400 | 2300 | 2 |

- 手算加权平均收入 ≈ (900×5 + 1100×7 + 1300×10 + 1500×13 + 1700×8 + 1900×6 + 2100×3 + 2300×2) ÷ 54
  - 分子 = 4500 + 7700 + 13000 + 19500 + 13600 + 11400 + 6300 + 4600 = 80600
  - 平均 = 80600 ÷ 54 ≈ 1492.6 元

## 7. 易错点 & 关联

- **易错点 1**：组中值 ≠ 平均数。它是假设组内均匀分布时的代表值，实际不一定正好等于组内真实平均。
- **易错点 2**：开口组不借邻组组距，瞎猜组中值。
- **易错点 3**：连续变量分组时上下限重叠却不声明规则，导致数据归属混乱。
