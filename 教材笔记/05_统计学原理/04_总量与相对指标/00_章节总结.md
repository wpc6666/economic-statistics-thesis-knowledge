# 第4章 总量指标与相对指标

> 所属：[[00_绪论|第1章 绪论]] ｜ 前置：[[03_统计数据整理|第3章 统计数据整理]] ｜ 后续：[[05_平均与变异指标|第5章 平均指标与变异指标]]

## 本章一句话定位

统计学要"用数字说话"，第一步就是把现象的规模和对比关系算出来。**总量指标**回答"有多大、有多少"，是所有统计指标的地基；**相对指标**回答"谁比谁、占多少、差多远"，把两个绝对数抽象成可比的比值。本章是描述统计的两块基石，第5章的平均指标、第6章的抽样推断，全部建立在这两类指标之上。

## 核心公式清单

| 公式 | 含义 | 符号要点 |
|---|---|---|
| $计划完成相对数=\dfrac{实际完成数}{计划任务数}\times100\%$ | 检查计划执行情况 | 分子分母不能互换 |
| $计划完成相对数=\dfrac{1\pm实际提高\%}{1\pm计划提高\%}\times100\%$ | 计划任务本身是"提高/降低百分之几"时用 | 不要和"百分点之差"混淆 |
| $结构相对数=\dfrac{总体某部分数值}{总体全部数值}\times100\%$ | 内部构成，各组之和=100% | 分子分母不能互换 |
| $比例相对数=\dfrac{总体某一部分}{总体另一部分}$ | 部分与部分之比，常写为 A∶B | 分子分母可互换 |
| $比较相对数=\dfrac{某空间指标}{另一空间同类指标}$ | 同一时间不同空间对比 | 分子分母可互换 |
| $动态相对数=\dfrac{报告期水平}{基期水平}\times100\%$ | 发展速度，不同时间对比 | 分子分母不能互换 |
| $强度相对数=\dfrac{某指标数值}{另一有联系的不同指标数值}$ | 密度、强度、普及度 | 常为复名数 |

## 方法选择速查

| 你想知道什么 | 用哪个指标 |
|---|---|
| 这个国家今年 GDP 是多少、人口多少 | 总量指标（时期 / 时点） |
| 产量有没有完成计划、完成了多少 | 计划完成相对数 |
| 三次产业占 GDP 的比重 | 结构相对数 |
| 轻重工业、积累与消费的比例 | 比例相对数 |
| 甲乙两省人均 GDP 谁高谁低 | 比较相对数 |
| 今年比去年增长了百分之几 | 动态相对数（发展速度） |
| 每万人拥有多少张病床、人口密度 | 强度相对数 |

## 自测题

1. 年末银行存款余额是时期指标还是时点指标？为什么不能把 12 个月的月末存款余额加总？
2. 某厂计划单位成本降低 6%，实际只降低了 3%，计划完成相对数是多少？这是超额完成还是没完成？
3. 结构相对数和比例相对数都在"部分与部分"之间做文章，二者本质区别是什么？
4. 强度相对数为什么常常带"人/平方公里""个/万人"这种复名数？它和平均指标怎么区分？
5. 某地区 GDP 2023 年为 1000 亿，2024 年为 1100 亿。动态相对数是多少？增长了百分之几？
