# KP05 结构相对数与比例相对数

> 所属：[[00_章节总结|第4章 总量指标与相对指标]] ｜ 节：[[02_第二节_相对指标]]

## 1. 一句话先懂（小白版）

结构相对数问的是"这个篮子里苹果占了百分之几"——部分占全体的比例；比例相对数问的是"苹果和梨的数量比是几比几"——部分和部分的对比。一个分母是全体，一个分母是另一部分。

## 2. 严格定义

- **结构相对数**：总体中某部分数值与该总体全部数值对比的比值，反映总体内部构成，一般用百分数表示，同一总体各部分结构相对数之和 = 100%。
- **比例相对数**：同一总体内某一部分数值与另一部分数值对比的比值，反映总体各部分之间的内在联系和比例关系，一般用 A∶B 形式表示。

## 3. 公式怎么来的、为什么是它

**结构相对数**：

$$结构相对数 = \frac{总体中某部分数值}{总体全部数值} \times 100\%$$

**直觉**：把一个蛋糕切成几块，每块占整个蛋糕的百分之几。所有块加起来一定是 100%。这就是研究"构成"——三次产业占 GDP 的比重、支出法 GDP 中消费/投资/净出口的比重、人口的城乡构成。

**比例相对数**：

$$比例相对数 = \frac{总体中某一部分数值}{总体中另一部分数值}$$

**直觉**：不看整个蛋糕，只看两块蛋糕之间谁大谁小、大几倍。比如轻重工业比 1.97∶1、积累与消费比、男女性别比。

**为什么这两个容易混？** 它们都在"同一总体内部"做文章。区别在分母：

| 对比项 | 结构相对数 | 比例相对数 |
|---|---|---|
| 分子 | 某一部分 | 某一部分 |
| 分母 | **总体全部** | **总体另一部分** |
| 结果形式 | 百分数，各组之和=100% | 比数，如 A∶B |
| 分子分母能否互换 | 不能 | 能（1.97∶1 和 1∶0.51 都说得通） |

## 4. 什么时候用这个方法

- **结构相对数**：分析产业结构、消费结构、人口年龄结构、支出构成。
- **比例相对数**：分析轻重工业比、积累消费比、男女比、师生比。

## 5. 为什么不用别的方法（对比）

| 问题 | 用哪个 |
|---|---|
| 第三产业占 GDP 的百分之几？ | 结构相对数 |
| 第三产业产值是第二产业的几倍？ | 比例相对数 |
| 甲乙两省第三产业占比谁高？ | 比较相对数（[[KP06_比较相对数与动态相对数]]） |
| 今年第三产业占比比去年高了几个百分点？ | 动态相对数（[[KP06_比较相对数与动态相对数]]） |

## 6. 例子

**经济实例（结构）**：某地区 GDP 1800 亿元，第一产业 90 亿、第二产业 720 亿、第三产业 990 亿。

- 第一产业比重 = 90 / 1800 × 100% = **5%**
- 第二产业比重 = 720 / 1800 × 100% = **40%**
- 第三产业比重 = 990 / 1800 × 100% = **55%**
- 检验：5% + 40% + 55% = 100% ✓

第三产业占 55%，说明该地区经济发展水平较高（发达国家一般 70% 以上）。

**经济实例（比例）**：某地区工业总产值 2110 亿，其中轻工业 1400 亿、重工业 710 亿。

$$轻重工业比例 = \frac{1400}{710} = 1.97∶1$$

意思是：以重工业为 100，轻工业就是 197。也可以写成 1400∶710 ≈ 1.97∶1。

## 7. 易错点 & 关联

- **易错点 1**：把结构相对数和比例相对数混用。结构的分母是全体，比例的分母是另一部分。
- **易错点 2**：认为结构相对数各组之和不一定是 100%。如果加起来不是 100%，一定是哪里算错了或者漏了组。
- **易错点 3**：比例相对数分子分母强行加起来等于 1。1.97∶1 不意味着重工业占 50%，它只是两个部分的比。
- **易错点 4**：结构相对数分子分母互换。第三产业占 55% 不能说"GDP 占第三产业 1818%"，这毫无意义。
