## 核心公式清单

本章以概念为主，没有需要计算的核心公式。唯一需要记住的"公式性"关系是：

- **统计指标 = 各总体单位数量标志值汇总而来**（例如全国职工总数 = 每家企业职工数相加）。
- **大数定理的直观表达**：样本量 n 越大，样本平均数 $\bar{x}$ 围绕总体平均数 $\mu$ 的波动越小。

## 方法选择速查

| 你遇到的问题 | 用本章哪个概念/方法 |
|---|---|
| 不知道"统计"到底指什么 | 统计三含义 |
| 不知道一次研究该圈定谁 | 总体与总体单位 |
| 不知道问卷题目是"什么" | 标志（数量/品质） |
| 不知道报告里的数字是"什么" | 统计指标 |
| 只看一两个样本就想下结论 | 大数定理提醒你要"大量观察" |
| 写论文不知道该看哪些指标 | 指标体系（少而精、需要与可能结合） |

## 自测题

1. "统计"一词有哪三种含义？它们之间是什么关系？
2. 统计最基本的特点是什么？为什么？
3. 什么是总体？什么是总体单位？举一个你自己生活中的例子说明两者如何随研究目的互换。
4. 品质标志和数量标志有什么区别？各举一例。
5. 离散变量和连续变量各举一例，并说明为什么它们的分组方式不同。
6. 为什么说"没有变异就没有统计"？
7. 统计指标和标志有哪两条区别、两条联系？
8. 大数定理的三条方法论意义是什么？为什么抛 1 次硬币和抛 24000 次硬币，结论可靠程度不同？
9. 统计研究的四个阶段是什么？为什么不能跳过"整理"直接做"分析"？
