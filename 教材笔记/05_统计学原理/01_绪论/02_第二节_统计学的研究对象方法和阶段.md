# 第二节 统计学的研究对象、方法和阶段

> 所属：[[00_章节总结|第一章 绪论]]

本节讲了哪几件事：
- 统计学的研究对象：客观事物的总体数量特征和数量关系
- 大数定理的方法论意义
- 五种基本研究方法
- 四个研究阶段

## 本节内容

### 一、研究对象

统计学的研究对象是**客观事物的总体数量特征和数量关系**，目的是反映其发展过程及规律性。

### 二、大数定理

个别单位的表现受偶然因素影响，会有波动；但对大量单位汇总后，偶然因素互相抵消，总体的稳定规律就显现出来。详见 [[KP05_统计研究方法与大数定理]]。

### 三、五种基本方法

| 方法 | 核心 |
|---|---|
| 大量观察法 | 对全部或足够多单位调查，依据大数定理 |
| 统计分组法 | 按标志把总体分成不同性质的组 |
| 统计指标法 | 用总量、相对、平均、动态、指数等指标描述总体 |
| 统计模型法 | 用数学方程模拟变量间关系（如回归） |
| 统计推断法 | 由样本推断总体（参数估计、假设检验） |

### 四、四个研究阶段

| 阶段 | 产出 |
|---|---|
| 统计设计 | 调查方案、指标体系 |
| 统计调查（数据采集） | 第一手原始资料 |
| 统计整理 | 分组、汇总、表格 |
| 统计分析 | 结论、报告、预测 |

详见 [[KP06_统计研究环节]]。
