# 第二节 统计调查方案的设计

> 所属：[[00_章节总结|第二章 统计数据的采集]]

本节讲了哪几件事：
- 调查方案的六要素
- 调查对象、调查单位、报告单位的辨析
- 调查表的两种形式（单一表/一览表）
- 调查标准时间与调查期限

## 本节内容

### 一、为什么要先写方案

调查方案是整个调查工作的指导纲领。目的是灵魂——目的变了，对象、项目、方法全跟着变。

### 二、六要素

| 要素 | 关键问题 |
|---|---|
| 主题和目的 | 为什么做？ |
| 对象/单位/报告单位 | 查谁？谁交表？ |
| 项目和调查表 | 查什么？ |
| 时间和地点 | 数据是哪一刻/在哪登记？ |
| 方式和方法 | 怎么查？ |
| 组织实施 | 谁来做、钱哪来？ |

详见 [[KP02_调查方案六要素]]。

### 三、关键辨析

**调查单位 vs 报告单位**：

| 调查任务 | 调查单位 | 报告单位 |
|---|---|---|
| 工业企业生产情况 | 每家企业 | 每家企业（一致） |
| 职工收入调查 | 每位职工 | 每家企业（不一致） |
| 生产设备调查 | 每台设备 | 每家企业（不一致） |

**单一表 vs 一览表**：

- 单一表：一张表登一个单位，项目多、单位分散时用。
- 一览表：一张表登多个单位，项目少、单位集中时用。

**标准时间 vs 调查期限**：

- 标准时间 = 数据所属的时点/时期（如 2010-11-01 零时）。
- 调查期限 = 干活用的时间（如 11 月 1 日至 10 日）。
