本节讲了哪几件事：

- 问卷设计注意事项

## 本节内容

### 一、问卷三部分

```
说明语 → 正文（被调查者信息 + 调查项目 + 调查信息）→ 结束语
```

详见 [[KP06_问卷结构与问题措辞]]。

### 二、六种题型

| 题型 | 适用 |
|---|---|
| 两项选择 | 是/否类简单问题 |
| 单选/多选 | 给定选项 |
| 程度性问题（李克特量表） | 满意度、态度 |
| 评分题（5/10/百分制） | 标准化主观度量 |
| 集中排列题 | 多个问题共用一套选项 |
| 开放式问题 | 收集意外想法，放最后 |

### 三、设计注意事项

1. 方便后续统计整理，紧扣目的。
2. 先易后难、先封闭后开放、先一般后敏感。
3. 大型调查前先做预调查。

详见 [[KP05_问卷设计原则]]。
