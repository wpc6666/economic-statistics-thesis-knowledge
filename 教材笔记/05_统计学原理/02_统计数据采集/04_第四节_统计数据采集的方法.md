本节讲了哪几件事：
- 直接观察法
- 采访法
- 电话调查法（含 CATI）
- 邮寄调查法
- 网络调查法
- 实验调查法

## 本节内容

六种方法各有适用场景：

| 方法 | 一句话 |
|---|---|
| 直接观察法 | 在现场看行为，不能看动机 |
| 采访法 | 面对面聊，可深入但贵 |
| 电话调查法 | 快、便宜、短，适合简单问题 |
| 邮寄调查法 | 范围广但回收率低 |
| 网络调查法 | 最便宜最快，但样本不随机 |
| 实验调查法 | 小范围试点，验证因果 |

详见 [[KP04_数据采集方法]]。

选方法时问三个问题：要多深入？要多快？预算多少？
