## 1. 一句话先懂（小白版）

问卷不是想到啥问啥，要让被访者愿意填、能看懂、好回答、收上来好统计。设计问卷的过程就是在给"陌生人"写一份既礼貌又高效的对话脚本。

## 2. 严格定义

**调查问卷**（调查表）：以书面形式了解被调查者的反应和看法，并据此获得资料的载体。

### 问卷设计的三条核心原则

1. **方便后续统计整理和数据分析**：每个问题都要能编码、能汇总、紧扣研究目的。
2. **问题排列有内在逻辑**：
   - 先易后难；
   - 先一般后敏感；
   - 先封闭式后开放式；
   - 按时间或类别顺序排列。
3. **大型调查前先做预调查**：小范围试发，发现歧义、修正措辞。

### 问题类型选择

| 题型 | 适用 | 优点 | 缺点 |
|---|---|---|---|
| 两项选择（是/否） | 互斥的二择一 | 易问易答易统计 | 不能讲原因、深度浅 |
| 单选/多选 | 给定若干选项 | 明确、易分类 | 可能漏了被访者真实想法（加"其他"补救） |
| 程度性问题（李克特量表） | 满意度、态度 | 可量化主观感受 | 不同人对"比较满意"理解不一 |
| 评分题（5分/10分/百分制） | 主观感受度量 | 标准化、可比 | 需要解释评分含义 |
| 集中排列题 | 多个问题共用一套选项 | 问卷紧凑、便于回答 | 占用篇幅大 |
| 开放式问题 | 想收集意外想法 | 自由、能发现新信息 | 难统计、易主观；不宜多，放最后 |

## 3. 问题排列的黄金顺序

```
开场（有趣、易答）
  ↓
一般事实问题（人口学：性别、年龄、职业）
  ↓
需要思考的核心问题（封闭式为主）
  ↓
敏感问题（收入、隐私）
  ↓
开放式问题（自由表达）
  ↓
致谢
```

## 4. 什么时候用

- 做问卷调查类论文/项目时，先按本原则列问题大纲，再写具体措辞。
- 收到别人的问卷做评审时，用这三条原则挑错。

## 5. 为什么不用别的方式

| 做法 | 后果 |
|---|---|
| 一上来就问收入 | 被访者警惕，拒答率飙升 |
| 全是开放式问题 | 回收后无法统计，整理成本极高 |
| 问题顺序混乱 | 被访者跳答、漏答 |
| 不做预调查 | 正式发放后才发现题目有歧义 |
| 选项不互斥 | 被访者不知道选哪个，数据混乱 |

## 6. 例子

**生活实例**：班长设计一份"食堂满意度"问卷。

- **错误示范**：第一题就问"你父母月收入多少？"——被访者立刻警惕。
- **正确顺序**：
  1. 你本周在食堂吃几次？（封闭式，易答）
  2. 你对食堂饭菜口味满意度？（非常满意/比较满意/一般/不太满意/不满意）
  3. 你对价格满意度？（同上量表）
  4. 你每月在食堂大概花多少钱？（敏感，放后面）
  5. 你对食堂还有什么建议？（开放式，最后）

- 手算：回收 45 份，口味"非常满意"5 人、"比较满意"18 人、"一般"15 人、"不太满意"5 人、"不满意"2 人。满意率（前两项）= (5+18) ÷ 45 = 51.1%。

**经济实例**：某电商公司设计"用户复购意愿"问卷。
- 封闭式为主：最近一次购买时间、购买品类、满意度（5 级量表）、是否愿意推荐（NPS 0–10 分）。
- 人口学信息（性别、年龄、城市）放最后。
- 结尾一道开放题："您希望我们改进什么？"
- 预调查 30 人，发现"最近一次购买时间"选项没写"超过一年"，正式版补上。

## 7. 易错点 & 关联

- **易错点 1**：诱导性提问。如"你难道不认为我们产品很好用吗？"——答案被扭曲。
- **易错点 2**：一题两问。如"你是否满意食堂的价格和口味？"——被访者想分开答。
- **易错点 3**：选项不穷尽也不互斥。如问年龄给"18–30 / 30–50 / 50 以上"，30 岁不知道算哪组。
- **易错点 4**：跳过预调查直接大投放。
