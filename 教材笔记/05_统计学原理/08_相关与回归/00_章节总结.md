## 一、本章一句话定位

前面几章讲的都是"一个变量自己怎么样"（均值、方差、抽样、检验），从这一章开始，统计学开始回答一个更现实的问题：**两个或多个变量之间有没有关系？关系有多强？能不能用一个变量去预测另一个变量？**

相关与回归分析就是把这种"变量之间的联动"量化下来的整套工具：先用**相关系数 r** 回答"两个变量是不是同涨同落、关系有多紧"，再用**回归方程**画一条最贴数据的直线，用来做预测。

## 三、核心公式清单

| 公式 | 含义 | 符号解释 |
|---|---|---|
| $r = \dfrac{\sum (x-\bar x)(y-\bar y)}{\sqrt{\sum (x-\bar x)^2}\sqrt{\sum (y-\bar y)^2}}$ | 皮尔逊相关系数 | $\bar x,\bar y$ 为均值；分子是协方差的 n 倍，分母是两边标准差的 n 倍 |
| $\hat y = b_0 + b_1 x$ | 一元线性回归方程 | $b_0$ 截距，$b_1$ 斜率 |
| $b_1 = \dfrac{\sum (x-\bar x)(y-\bar y)}{\sum (x-\bar x)^2}$ | OLS 斜率 | x 偏离均值时 y 平均偏离多少 |
| $b_0 = \bar y - b_1 \bar x$ | OLS 截距 | 直线必过 $(\bar x,\bar y)$ |
| $R^2 = 1 - \dfrac{\sum (y-\hat y)^2}{\sum (y-\bar y)^2}$ | 可决系数 | y 的总变动中被 x 解释掉的比例 |
| $s_y = \sqrt{\dfrac{\sum (y-\hat y)^2}{n-2}}$ | 估计标准误差 | 回归线上下的"平均波动幅度" |
| $\hat y = b_0 + b_1 x_1 + b_2 x_2 + \dots + b_m x_m$ | 多元线性回归 | 每个 $b_j$ 是偏回归系数 |
| $t_j = \dfrac{b_j}{s_{b_j}}$ | 回归系数 t 检验 | 检验 $x_j$ 对 y 是否有显著影响 |
| $F = \dfrac{R^2}{1-R^2}\cdot\dfrac{n-m}{m-1}$ | F 检验 | 检验"整组自变量有没有用" |

## 四、方法选择速查

| 你想干什么 | 用什么 |
|---|---|
| 只想知道两个变量关系紧不紧、是正还是负 | 相关系数 r（[[KP03_相关系数r的直觉]]） |
| 想画一条直线、用 x 预测 y | 一元线性回归 OLS（[[KP08_最小二乘法OLS]]） |
| 想知道这条直线拟合得好不好 | $R^2$（[[KP09_拟合优度R2]]） |
| 有两个以上自变量一起预测 y | 多元线性回归（[[KP10_多元线性回归与偏回归系数]]） |
| 散点图明显是弯的 | 曲线回归 + 换元线性化（[[KP11_曲线回归与线性化]]） |
| 想判断"算出来的关系是不是真的、还是抽样凑巧" | 显著性检验（[[KP05_相关系数显著性检验]]） |
