# KP02 相关方向（正/负/不相关）与相关形式（线性/非线性）

## 1. 一句话先懂（小白版）

看散点图就能一眼判断：

- **正相关**：点从左下往右上斜——x 越大，y 也越大（身高越高，体重越重）。
- **负相关**：点从左上往右下斜——x 越大，y 反而越小（商品越贵，销量越低）。
- **不相关**：点像撒胡椒面，看不出任何方向（身高和考试分数）。
- **线性**：点绕着一条**直线**抖。
- **非线性（曲线）**：点绕着一条**弯线**抖（施肥量和亩产量：施太少不长，施太多烧苗，中间最优）。

## 2. 严格定义

| 分类维度 | 类别 | 定义 |
|---|---|---|
| 相关方向 | 正相关 | x 与 y 同方向变动：x 增 y 也增，x 减 y 也减 |
|  | 负相关 | x 与 y 反方向变动：x 增 y 减，x 减 y 增 |
|  | 不相关 | x 变动时 y 没有任何系统性反应 |
| 相关形式 | 线性相关（直线相关） | 散点围绕一条直线波动 |
|  | 非线性相关（曲线相关） | 散点围绕一条曲线波动 |
| 相关程度 | 完全相关 | 散点严格落在一条线上（= 函数关系） |
|  | 不完全相关 | 散点绕线波动，但趋势明显（社会经济现象多属此类） |
|  | 不相关 | 散点无规律 |

## 3. 公式怎么来的、为什么是它

这一节的"公式"就是**相关图（散点图）**本身，没有新公式。判断流程：

1. 把每一对 $(x_i, y_i)$ 画成直角坐标系上的一个点。
2. 看这些点整体往哪个方向倾斜 → 决定正/负/不相关。
3. 看这些点绕的是直线还是弯线 → 决定线性/非线性。

真正把这些"看出来的直觉"量化的，是后面 [[KP03_相关系数r的直觉]] 里的 $r$：

- $r > 0$ → 正相关
- $r < 0$ → 负相关
- $r \approx 0$ → 不相关（线性意义上）
- 注意：$r \approx 0$ 只代表**线性**不相关，可能存在很强的**非线性**关系（比如 U 形）。

## 4. 什么时候用这个方法

- 拿到数据第一步：**先画散点图**，再决定后面用什么模型。
- 散点图是"模型选择的体检表"：
  - 直线斜着走 → 一元线性回归
  - 弯的（抛物线、指数、双曲线）→ [[KP11_曲线回归与线性化]]
  - 完全撒胡椒面 → 别费劲做回归了
  - 一个极端点把所有点带偏 → 警惕异常值，[[KP12_相关不等于因果与应用注意]]

## 5. 为什么不用别的方法（对比）

| 现象 | 选线性回归 | 选曲线回归 |
|---|---|---|
| 散点绕直线 | ✅ | ❌（会扭曲直线趋势） |
| 散点绕弯线 | ❌（拟合效果差） | ✅ |
| U 形 / 倒 U 形 | ❌ | ✅（二次曲线） |
| 饱和增长（越涨越慢） | ❌ | ✅（指数 / 对数） |

## 6. 例子

**生活实例**：
- 正相关：气温升高 → 冰淇淋销量上升
- 负相关：商品价格升高 → 需求量下降
- 不相关：鞋码大小 → 智商高低
- 非线性：年龄 vs 跑步速度（儿童期随年龄加快，老了又变慢，倒 U 形）

**经济实例**：
- 正相关：居民可支配收入 → 耐用消费品销售量
- 负相关：商品流通费用率 → 商品零售额（规模越大费用率越低）
- 非线性：施肥量 → 农作物亩产量

**关键提醒**：相关方向和相关形式是**两个独立维度**。你可以有"正的非线性相关"（如 $y = x^2$ 在 $x>0$ 段），也可以有"负的线性相关"（如商品价格 vs 需求量）。

## 7. 易错点 & 关联

- **易错 1**：相关系数 $r=0$ 就以为"两变量没关系"。错！$r=0$ 只表示**没有线性关系**，可能有强非线性关系（典型：$y = x^2$，对称分布时 $r=0$ 但关系极强）。
- **易错 2**：把"负相关"当成"没关系"。负相关也是相关，只是方向相反。
- **易错 3**：不画散点图直接算回归。散点图会告诉你模型选得对不对。
