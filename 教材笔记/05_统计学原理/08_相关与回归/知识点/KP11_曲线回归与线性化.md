## 1. 一句话先懂（小白版）

散点图明显是弯的（比如施肥量和亩产量：施太少不长，施太多烧苗），硬套直线会很丑。但很多"弯的方程"通过**换元**可以变回"直线方程"，然后照样用 OLS 解。

核心技巧：**把 x 或 y 做个数学变换（取倒数、取对数、平方），让变换后的变量之间是直线关系。**

## 2. 严格定义

常见的可线性化曲线：

| 曲线类型 | 原方程 | 换元 | 变换后（直线） |
|---|---|---|---|
| 双曲线 | $\hat y = b_0 + b_1 \frac{1}{x}$ | $x' = 1/x$ | $\hat y = b_0 + b_1 x'$ |
| 对数曲线 | $\hat y = b_0 + b_1 \ln x$ | $x' = \ln x$ | $\hat y = b_0 + b_1 x'$ |
| 二次曲线 | $\hat y = b_0 + b_1 x + b_2 x^2$ | $x' = x^2$ | $\hat y = b_0 + b_1 x + b_2 x'$ |
| 指数曲线 | $\hat y = b_0 b_1^x$ | 取对数：$\ln \hat y = \ln b_0 + x \ln b_1$，令 $y' = \ln y$ | $y' = A + Bx$ |

## 3. 公式怎么来的、为什么是它

### 为什么要换元？

OLS 只能解"参数线性"的方程。$\hat y = b_0 + b_1 \frac{1}{x}$ 对 $b_0, b_1$ 是线性的，只是 x 本身是 $1/x$。所以只要定义一个新变量 $x' = 1/x$，问题就变成 $\hat y = b_0 + b_1 x'$，直接套一元 OLS 公式（[[KP08_最小二乘法OLS]]）。

### 指数曲线要小心

$\hat y = b_0 b_1^x$ 看起来对 $b_0, b_1$ 不是线性的，但两边取自然对数：

$$
\ln \hat y = \ln b_0 + x \ln b_1
$$

令 $y' = \ln y$、$A = \ln b_0$、$B = \ln b_1$，就变成：

$$
y' = A + B x
$$

**注意**：这时候 OLS 最小化的是 $\sum (\ln y - \ln \hat y)^2$，不是原来的 $\sum (y - \hat y)^2$——和直接最小化原方程残差有微小差异。这是对数线性化的代价。

## 4. 什么时候用这个方法

- 散点图明显弯曲（[[KP02_相关方向与相关形式]]）。
- 经济理论提示非线性关系（规模报酬递减、饱和效应、S 形增长）。
- 曲线形状能对上常见类型（双曲线、指数、二次）。

## 5. 为什么不用别的方法（对比）

| 曲线类型 | 典型场景 |
|---|---|
| 双曲线 $\hat y = b_0 + b_1/x$ | 商品流通费用率 vs 零售额（规模越大费用率越低，趋近常数） |
| 对数 $\hat y = b_0 + b_1 \ln x$ | 边际效用递减：x 增长带来的 y 增长越来越慢 |
| 二次 $\hat y = b_0 + b_1 x + b_2 x^2$ | 倒 U 形（施肥量 vs 产量、年龄 vs 收入） |
| 指数 $\hat y = b_0 b_1^x$ | 复利增长、人口增长 |

**怎么选**：先画散点图，看形状最像哪条，试一下，比较 $R^2$ 或残差。

## 6. 例子

**原书例 8-5**（商品流通费用率 y vs 商品零售额 x）：

散点图显示 x 越大 y 越小，但下降越来越慢，像双曲线 $\hat y = b_0 + b_1 / x$。

令 $x' = 1/x$，用 10 组数据算得：

- $b_1 = 42.73$
- $b_0 = 2.57$

**双曲线回归方程**：

$$
\hat y = 2.57 + 42.73 \cdot \frac{1}{x}
$$

- 经济解释：零售额越大，流通费用率越低；当 x → ∞，费用率趋近 2.57%（这是"规模不变"的下限）。
- 相关指数 $R = -0.9887$（负号因为 x 越大 y 越小），高度相关。

**预测**：x = 41.25 百万元时：

$$
\hat y = 2.57 + \frac{42.73}{41.25} = 2.57 + 1.04 = 3.61\%
$$

## 7. 易错点 & 关联

- **易错 1**：换元后忘把 x 换回原尺度。预测时一定要用 $\hat y = b_0 + b_1 \cdot (1/x)$ 代入原 x，不是代入 $x'$。
- **易错 2**：指数曲线对数变换后，最小化的是 log 残差，不是原残差。预测值在 y 较大时可能有偏。
- **易错 3**：二次曲线当线性用。U 形关系硬套直线会得到 b₁≈0，错误结论"没关系"。
