# KP06 相关分析 vs 回归分析

> 所属：[[00_章节总结|第8章 相关与回归]] ｜ 节：[[01_第一节_相关与回归基本概念]]

## 1. 一句话先懂（小白版）

- **相关分析**：只回答"x 和 y 关系紧不紧、是正还是负"。x 和 y **地位平等**，交换一下答案不变。
- **回归分析**：要回答"x 变一点，y 平均会变多少？能不能用 x 预测 y？"。x 和 y **地位不对等**，必须指定谁是自变量、谁是因变量。

## 2. 严格定义

- **相关分析**：研究两个或多个随机变量之间相互依存关系的**方向和密切程度**的统计方法。直线相关用相关系数 $r$ 表示，曲线相关用相关指数表示，多元相关用复相关系数 $R$ 表示。
- **回归分析**：研究某一因变量与一个或几个自变量之间**数量关系变动趋势**的方法，求出的关系叫回归方程 $\hat y = b_0 + b_1 x + \dots$。

## 3. 公式怎么来的、为什么是它

相关分析的核心数字是 $r$（见 [[KP03_相关系数r的直觉]]），它**没有预测功能**，只给一个 $[-1,1]$ 的数。

回归分析的核心数字是回归方程 $\hat y = b_0 + b_1 x$，它**能预测**：给个 $x_0$，代进去就有 $\hat y_0$。

为什么需要两套？因为：
- 你想知道"关系有多紧" → 用 r，简单。
- 你还想"用 x 预测 y" → 必须画一条线，就需要回归。

## 4. 什么时候用这个方法

实际工作中的**标准流程**：

1. 先画散点图（[[KP02_相关方向与相关形式]]）。
2. 算 r，看方向和强度（[[KP03_相关系数r的直觉]]）。
3. 做显著性检验（[[KP05_相关系数显著性检验]]）。
4. 检验通过 → 配回归方程（[[KP08_最小二乘法OLS]]）。
5. 用回归方程做预测。

相关分析是"体检"，回归分析是"开药方"。

## 5. 为什么不用别的方法（对比）

| 对比项 | 相关分析 | 回归分析 |
|---|---|---|
| 变量地位 | 平等（不分自变量/因变量） | 不平等（必须定谁是因谁是果） |
| 变量性质 | 两个都是随机变量 | 自变量非随机（可控制），因变量随机 |
| 产出 | 一个数 r ∈ [-1,1] | 一个方程 $\hat y = b_0 + b_1 x$ |
| 能否预测 | 不能 | 能 |
| 交换 x 和 y | r 不变 | 方程变（$y$ 对 $x$ 回归 ≠ $x$ 对 $y$ 回归） |
| 回答的问题 | "关系有多紧？" | "x 变一点，y 变多少？" |

**关键联系**：在一元线性回归里，$r^2 = R^2$（[[KP09_拟合优度R2]]），所以相关系数和回归方程是同一枚硬币的两面。

## 6. 例子

**生活实例**：
- 相关分析：身高和体重的 r 是多少？（不分谁影响谁）
- 回归分析：用身高预测体重，$\hat w = b_0 + b_1 h$。

**经济实例**：
- 相关分析：固定资产投资和 GDP 的 r = 0.9932（本教材例 8-2）。
- 回归分析：$\hat{\text{GDP}} = 24.10 + 2.84 \times \text{投资}$——投资每多 1 百亿元，GDP 平均多 2.84 百亿元。

**注意**：相关分析里你把"投资 vs GDP"换成"GDP vs 投资"，r 还是 0.9932；但回归方程 $\hat{\text{投资}} = \dots$ 就完全是另一条线了。

## 7. 易错点 & 关联

- **易错 1**：把 r 当成回归斜率。错——r 是无量纲的，$b_1$ 有量纲（y 的单位 / x 的单位）。
- **易错 2**：相关显著 = 回归显著。一元回归里两者 t 检验等价，但多元里不一样（[[KP10_多元线性回归与偏回归系数]]）。
- **易错 3**：相关分析不区分因果就直接上回归。先有定性判断（经济理论），再定量。
