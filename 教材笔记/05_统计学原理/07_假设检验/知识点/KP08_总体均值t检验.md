# KP08 总体均值 t 检验

## 1. 一句话先懂（小白版）

**t 检验**和 Z 检验几乎一样，只是当总体 σ 未知、样本又小（n<30）时，用样本 s 代替 σ，分布从标准正态变成 t 分布。t 分布尾巴更厚，小样本更保守——因为 s 本身也有误差，不能太自信。

## 2. 严格定义

**t 检验统计量**：

$$t=\frac{\bar{x}-\mu_0}{s/\sqrt{n}}\sim t(n-1)$$

其中 $s$ 是样本标准差，自由度 $df=n-1$。

**适用条件**：
- 总体正态。
- σ 未知。
- 小样本（n<30）。

## 3. t 分布 vs Z 分布

| | Z 分布 | t 分布 |
|---|---|---|
| 形状 | 标准正态 | 对称，但尾巴更厚 |
| 均值 | 0 | 0 |
| 方差 | 1 | >1（取决于自由度） |
| 自由度 | 无 | n-1 |
| n→∞ 时 | — | 趋近 Z |

**为什么 t 尾巴厚？**——因为 t 统计量里有两个随机变量：$\bar{x}$ 和 $s$。小样本时 $s$ 波动大，有时偏小有时偏大，导致 t 比 Z 更分散。n 大了 $s$ 稳定了，t 就趋近 Z。

## 4. 常用 t 临界值（双尾 α=0.05）

| df=n-1 | t 临界值 | 对比 Z=1.96 |
|---|---|---|
| 5 | 2.571 | 大很多 |
| 10 | 2.228 | 大一些 |
| 20 | 2.086 | 接近 |
| 30 | 2.042 | 很接近 |
| ∞ | 1.96 | 等于 Z |

## 5. 对比：Z 检验 vs t 检验

| | Z 检验 | t 检验 |
|---|---|---|
| σ | 已知 | 未知 |
| 样本量 | 大样本（或正态总体） | 小样本 |
| 分布 | N(0,1) | t(n-1) |
| 临界值 | 1.96 | 比 1.96 大 |
| 保守程度 | 一般 | 更保守 |

## 6. 手算例子（完整）

**题目**：某牛奶厂盒装牛奶标准净重 1000 克。抽 10 盒，测得：1010、1024、994、986、1016、1030、1004、990、980、1020。α=0.01，问生产是否正常？

**解**：
1. H0: μ=1000；H1: μ≠1000（双尾）。
2. n=10<30，σ 未知，用 t 检验。df=9。
3. α=0.01 双尾，查 t 表 t0.005(9)=3.250。
4. 样本均值 $\bar{x}=1005.4$。
5. 样本标准差 $s=17.28$。
6. 标准误 = $s/\sqrt{n}=17.28/3.162=5.47$。
7. t = (1005.4-1000)/5.47 = 0.987。
8. |0.987| < 3.250，不拒绝 H0。

**结论**：没有足够证据说生产不正常，盒装牛奶净重符合标准。

## 7. 易错点 & 关联

- **易错1**：小样本 σ 未知还用 Z。n=10 时 t0.025(9)=2.262，比 1.96 大不少，用 Z 会低估误差。
- **易错2**：忘记自由度。t 临界值和 df 有关，不能直接用 1.96。
- **易错3**：n≥30 还纠结用 t 还是 Z。n=30 时 t 和 Z 几乎一样，随便用哪个。
