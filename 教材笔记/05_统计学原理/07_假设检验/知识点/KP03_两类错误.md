# KP03 两类错误（α 与 β）

> 所属：[[00_章节总结|第七章 假设检验]] ｜ 节：[[02_第二节_假设检验的基本思路与方法]]

## 1. 一句话先懂（小白版）

**α 错误（第一类）= 冤枉好人**：H0 明明是对的，你却拒绝了。
**β 错误（第二类）= 放走坏人**：H0 明明是错的，你却没拒绝。
法庭上：α 是无罪判有罪，β 是有罪判无罪。样本量固定时，想少冤枉就容易放走，想少放走就容易冤枉——两者此消彼长。

## 2. 严格定义

| | H0 真实 | H0 不真实 |
|---|---|---|
| **接受 H0** | 正确（概率 1-α） | **第二类错误 β**（纳伪） |
| **拒绝 H0** | **第一类错误 α**（拒真） | 正确（概率 1-β，检验功效） |

- **α（拒真概率）**：H0 为真时被错误拒绝的概率。就是显著性水平。
- **β（纳伪概率）**：H0 为假时被错误接受的概率。
- **1-β（检验功效）**：H0 为假时被正确拒绝的概率。

## 3. 为什么此消彼长

想象一个"拒绝门槛"：门槛设得高（α 小），就不容易拒绝 H0——冤枉好人少了，但坏人也容易溜过去（β 大）。门槛设得低（α 大），容易拒绝 H0——坏人跑不掉，但好人也可能被误杀（α 大）。

**怎么同时降低？**——增大样本量 n。n 越大，标准误越小，样本均值越靠近真值，两类错误都能降下来。但现实中 n 不能无限大，所以通常**控制 α**（比如固定 0.05），接受 β 作为代价。

## 4. 什么时候要特别注意哪类错误

| 场景 | 最怕哪类错误 | 为什么 |
|---|---|---|
| 药品试验 | **α 错误**（假药当真药） | 吃坏人，人命关天 |
| 质量检测 | **β 错误**（次品当正品） | 卖出去召回，损失大 |
| 法庭审判 | **α 错误**（无罪判有罪） | 冤枉好人，司法公正 |
| 产品验收 | **β 错误**（次品放过） | 客户投诉，品牌受损 |

## 5. 对比

| | 第一类错误 α | 第二类错误 β |
|---|---|---|
| 别名 | 拒真、冤枉好人 | 纳伪、放走坏人 |
| 什么时候犯 | H0 真但拒绝了 | H0 假但接受了 |
| 概率 | 就是显著性水平 | 取决于 H1 离 H0 多远 |
| 怎么控制 | 直接设 α | 增大 n 降低 |

## 6. 手算例子

**题目**：某厂规定零件直径标准 μ=10mm，σ=0.5mm。抽 n=25 个，α=0.05 双尾检验。

- 拒绝域：Z<-1.96 或 Z>1.96。
- 即 $\bar{x}<10-1.96\times 0.5/5=9.804$，或 $\bar{x}>10.196$。

**如果实际 μ 真的变成了 10.2（偏移了 0.2）**，β 是多少？
- 在 μ=10.2 下，$\bar{x}\sim N(10.2, 0.1^2)$。
- 不拒绝 H0 的区域是 [9.804, 10.196]。
- 求 $P(9.804<\bar{x}<10.196)$ 在 μ=10.2 下：
  - Z1 = (9.804-10.2)/0.1 = -3.96
  - Z2 = (10.196-10.2)/0.1 = -0.04
  - P(-3.96<Z<-0.04) = Φ(-0.04)-Φ(-3.96) ≈ 0.484-0 ≈ 0.484

**β≈0.484**——也就是说，即使真偏移了 0.2mm，你也有 48.4% 的概率检测不出来！要提高检出率（减小 β），就得增大样本量。

## 7. 易错点 & 关联

- **易错1**：以为 α 是"H0 为真的概率"。不对，α 是"H0 为真时被拒绝的概率"——是条件概率。
- **易错2**：α 越小越好。α=0.001 很保守，但 β 会很大，什么变化都检测不出来。
- **易错3**：样本量固定时想同时降 α 和 β。不可能，只能增大 n。
