# KP01 假设检验的逻辑（无罪推定）

> 所属：[[00_章节总结|第七章 假设检验]] ｜ 节：[[01_第一节_假设检验概述]]

## 1. 一句话先懂（小白版）

**法庭上先假定被告无罪，看证据是否极端到"在无罪情况下几乎不可能发生"。如果是，才判有罪。** 统计检验一模一样：先假定原假设 H0 成立，看样本数据是否极端到在 H0 下几乎不可能——如果是，才拒绝 H0。

## 2. 严格定义

**假设检验**：先对总体参数提出一个假设（H0），然后在 H0 成立的前提下计算样本统计量出现的概率。如果这个概率小于事先规定的显著性水平 α，就拒绝 H0；否则不拒绝 H0。

**核心原理**：小概率事件在一次试验中几乎不会发生。如果在 H0 下应该几乎不发生的事居然发生了，就有理由怀疑 H0 不对。

## 3. 用无罪推定理解四步

| 法庭 | 统计检验 |
|---|---|
| 假定被告无罪 | 假定 H0 成立（比如"新配方没提高寿命"） |
| 证据摆出来 | 样本算出来了，$\bar{x}=25300$ |
| 在无罪前提下，这证据可能吗？ | 在 H0（μ=25000）下，$\bar{x}$ 离 25000 这么远的概率多大？ |
| 证据太极端 → 判有罪 | 概率 < α → 拒绝 H0，接受 H1 |
| 证据不够极端 → 无罪释放 | 概率 ≥ α → 不拒绝 H0 |

**注意**：统计检验里"不拒绝 H0"不等于"H0 是对的"——就像法庭上"无罪释放"不等于"被告真的没干"，只是证据不够而已。

## 4. 什么时候用

- 判断新工艺有没有效果。
- 判断新产品质量是否达标。
- 判断两个总体是否有差异。
- 论文里检验回归系数是否显著（第8章）。

## 5. 对比

| | 区间估计 | 假设检验 |
|---|---|---|
| 目的 | 猜参数在哪 | 判断参数是否等于某值 |
| 逻辑 | 直接构造区间 | 反证法（无罪推定） |
| 结果 | 一个区间 | 拒绝/不拒绝 H0 |
| 关系 | 区间包含 μ0 ↔ 不拒绝 H0 | 区间不包含 μ0 ↔ 拒绝 H0 |

## 6. 手算例子

**题目**：某厂灯泡平均寿命历史 μ=1000 小时，σ=80。新生产抽 100 个，$\bar{x}=990$。问新灯泡寿命是否显著降低？（α=0.05）

**无罪推定过程**：
1. H0：μ=1000（新灯泡寿命没变）。
2. 在 H0 下，$\bar{x}\sim N(1000, 80^2/100)$，标准误 = 8。
3. 实际 $\bar{x}=990$，离 1000 差 10，即 $Z=(990-1000)/8=-1.25$。
4. 在 H0 下，Z<-1.25 的概率是多少？查标准正态表，P(Z<-1.25)=0.1056。
5. 0.1056 > 0.05（α），不算小概率事件。
6. **不拒绝 H0**——没有足够证据说新灯泡寿命降低了。

## 7. 易错点 & 关联

- **易错1**：把"不拒绝 H0"当成"接受 H0"。不拒绝只是证据不够，不是证明了 H0。
- **易错2**：以为假设检验能证明 H0 正确。不能，它只能"拒绝"或"不拒绝"。
- **易错3**：先看数据再决定 H0。H0 必须在看数据之前定好，否则就是"事后找理由"。
