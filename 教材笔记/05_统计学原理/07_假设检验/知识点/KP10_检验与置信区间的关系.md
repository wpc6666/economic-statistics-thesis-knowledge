# KP10 检验与置信区间的关系

> 所属：[[00_章节总结|第七章 假设检验]] ｜ 节：[[04_第四节_Excel假设检验]]

## 1. 一句话先懂（小白版）

**置信区间和假设检验是同一枚硬币的两面。** 如果 μ0 落在 95% 置信区间里，那 α=0.05 的双尾检验就不拒绝 H0；如果 μ0 落在区间外面，就拒绝 H0。

## 2. 严格定义

**关系**：在 $1-\alpha$ 置信水平下，总体参数 μ 的置信区间为 $[\bar{x}-z_{\alpha/2}\sigma/\sqrt{n},\ \bar{x}+z_{\alpha/2}\sigma/\sqrt{n}]$。

- 如果 $\mu_0$ **在区间内** → 不拒绝 H0: μ=μ0。
- 如果 $\mu_0$ **在区间外** → 拒绝 H0: μ=μ0。

## 3. 为什么等价

置信区间是"所有可能被接受的 μ 值的集合"。
- 区间内的 μ 值，和样本数据不矛盾，所以不拒绝。
- 区间外的 μ 值，和样本数据矛盾，所以拒绝。

## 4. 对比

| | 置信区间 | 假设检验 |
|---|---|---|
| 目的 | 估计参数在哪 | 判断参数是否等于某值 |
| 结果 | 一个区间 | 拒绝/不拒绝 |
| 信息 | 还告诉你精度 | 只说过没过线 |
| 关系 | 区间包含 μ0 ↔ 不拒绝 H0 | 区间不包含 μ0 ↔ 拒绝 H0 |

## 5. 手算例子

**题目**：某厂袋装食品抽 28 袋，$\bar{x}=500.21$，σ=5。α=0.05，问 μ=500 是否合理？

**用置信区间做**：
- 95% 置信区间 = $500.21\pm 1.96\times 5/\sqrt{28}=500.21\pm 1.85=[498.36, 502.06]$。
- μ0=500 在区间内 → 不拒绝 H0。

**用假设检验做**：
- Z = (500.21-500)/(5/√28) = 0.21/0.945 = 0.222。
- |0.222| < 1.96 → 不拒绝 H0。

**结果完全一致。**

## 6. 什么时候用哪个

| 你的目的 | 用什么 |
|---|---|
| 想知道参数大概在哪 | 置信区间 |
| 想判断参数是否等于某值 | 假设检验 |
| 论文里报告结果 | **两个都给**——区间给精度，检验给显著性 |

## 7. 易错点 & 关联

- **易错1**：以为置信区间和假设检验是两回事。它们数学上完全等价。
- **易错2**：单尾检验和双尾置信区间对应不上。双尾检验对应双尾置信区间；单尾检验对应单侧置信限。
- **易错3**：区间包含 μ0 就说"μ=μ0 是对的"。不拒绝不等于证明，只是证据不够。
