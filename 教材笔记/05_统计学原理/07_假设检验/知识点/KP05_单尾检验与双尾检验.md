# KP05 单尾检验与双尾检验

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 所属：[[00_章节总结|第七章 假设检验]] ｜ 节：[[02_第二节_假设检验的基本思路与方法]]

## 1. 一句话先懂（小白版）

- **双尾检验**：只问"有没有差异"，不管方向。比如"这批牛奶重量准不准"——重了不行轻了也不行。
- **单尾检验**：关心某个方向。比如"新轮胎寿命是不是提高了"——只关心有没有变长，变短了不算新闻。

## 2. 严格定义

| 类型 | H0 | H1 | 拒绝域 | 临界值 |
|---|---|---|---|---|
| **双尾** | μ=μ0 | μ≠μ0 | 左右两端各 α/2 | ±zα/2 |
| **右尾** | μ≤μ0 | μ>μ0 | 右端 α | zα |
| **左尾** | μ≥μ0 | μ<μ0 | 左端 α | -zα |

## 3. 怎么选

| 你的问题 | 选什么 |
|---|---|
| 零件直径是否等于标准值？ | 双尾 |
| 新配方是否提高了寿命？ | 右尾 |
| 电池是否缩短了发光时间？ | 左尾 |
| 产品合格率是否达到 95%？ | 右尾（P≥0.95） |
| 收视率是否发生了变化？ | 双尾 |

**判断口诀**：你关心"是大是小"就单尾，只关心"是不是"就双尾。

## 4. 为什么单尾更容易拒绝 H0

同样 α=0.05：
- 双尾：拒绝域在两端各 2.5%，临界值 ±1.96。
- 右尾：拒绝域全在右端 5%，临界值 1.645。

**同样的数据，单尾检验的临界值更小，更容易显著。** 所以不能为了"凑显著"而事后选单尾——必须在看数据前根据研究问题定好。

## 5. 对比

| | 双尾 | 单尾 |
|---|---|---|
| 拒绝域 | 两端 | 一端 |
| α 分配 | 各 α/2 | 全在一端 |
| 临界值（α=0.05） | ±1.96 | 1.645 或 -1.645 |
| 敏感度 | 低 | 高（对指定方向） |
| 什么时候用 | 只问差异 | 关心方向 |

## 6. 手算例子

**题目**：某厂电风扇历史平均寿命 25000 小时，σ=1900。新生产抽 400 台，$\bar{x}=25300$。问新电风扇寿命是否有显著差异？（α=0.05）

**分析**：题目问"有没有差异"，不问方向，用双尾。

1. H0: μ=25000；H1: μ≠25000。
2. 临界值 ±1.96。
3. Z = (25300-25000)/(1900/20) = 300/95 = 3.16。
4. |3.16| > 1.96，拒绝 H0。

**如果题目改成"新电风扇寿命是否提高了"**（右尾）：
- 临界值 1.645。
- Z=3.16 > 1.645，还是拒绝。
- 但单尾更"容易"显著——因为临界值从 1.96 降到 1.645。

## 7. 易错点 & 关联

- **易错1**：先看数据偏大，再改成单尾检验。这是"事后选择性报告"，学术不端。
- **易错2**：双尾和单尾的 α 搞混。双尾 α=0.05 是两端各 0.025；单尾 α=0.05 是一端 0.05。
- **易错3**：什么问题都用双尾。如果你研究的是"新药是否比老药好"，单尾更有功效。
