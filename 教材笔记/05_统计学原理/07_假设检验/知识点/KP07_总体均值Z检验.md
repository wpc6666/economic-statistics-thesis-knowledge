# KP07 总体均值 Z 检验

> 所属：[[00_章节总结|第七章 假设检验]] ｜ 节：[[03_第三节_总体参数检验]]

## 1. 一句话先懂（小白版）

**Z 检验**就是用标准正态分布来判断样本均值和假设值差得远不远。什么时候用 Z？——总体 σ 已知，或者样本量够大（n≥30）。

## 2. 严格定义

**Z 检验统计量**：

$$Z=\frac{\bar{x}-\mu_0}{\sigma/\sqrt{n}}$$

其中 $\mu_0$ 是 H0 假设的总体均值。

**适用条件**：
- 总体正态，σ 已知（不管 n 大小）。
- 总体非正态，但 n≥30（CLT 近似）。
- σ 未知但 n≥30，用 s 代替 σ。

## 3. 检验步骤

1. 建 H0: μ=μ0，H1: μ≠μ0（或 >、<）。
2. 定 α，查临界值（双尾 ±zα/2，单尾 ±zα）。
3. 算 Z = $(\bar{x}-\mu_0)/(\sigma/\sqrt{n})$。
4. 比较：|Z|>临界值 → 拒绝 H0。

## 4. 什么时候用 Z vs t

| 条件 | 用什么 |
|---|---|
| σ 已知，任何 n | Z |
| σ 未知，n≥30 | Z（用 s 代替） |
| σ 未知，n<30 | **t**（[[KP08_总体均值t检验]]） |

## 5. 对比

| | Z 检验 | t 检验 |
|---|---|---|
| 分布 | 标准正态 | t(n-1) |
| σ | 已知（或大样本 s 代替） | 未知小样本 |
| 临界值 | 1.96（95%双尾） | 比 1.96 大，查 t 表 |
| 小样本 | 不能用 | 用 |

## 6. 手算例子（完整）

**题目**：某电风扇厂历史平均寿命 25000 小时，σ=1900。新生产抽 400 台，$\bar{x}=25300$。α=0.05，问新产品寿命是否有显著差异？

**解**：
1. H0: μ=25000；H1: μ≠25000（双尾）。
2. α=0.05，临界值 ±1.96。
3. Z = (25300-25000)/(1900/√400) = 300/95 = 3.16。
4. |3.16| > 1.96，拒绝 H0。

**结论**：新电风扇平均寿命与历史水平有显著差异，确实提高了。

**右尾例子**：
某电池厂历史 μ=1000 小时，σ=80。抽 100 个，$\bar{x}=990$。α=0.05，问是否显著降低？

1. H0: μ≥1000；H1: μ<1000（左尾）。
2. 临界值 -1.645。
3. Z = (990-1000)/(80/10) = -1.25。
4. -1.25 > -1.645，不拒绝 H0。

**结论**：没有足够证据说电池寿命降低了。

## 7. 易错点 & 关联

- **易错1**：小样本 σ 未知也用 Z。n=10 时必须用 t。
- **易错2**：Z 的分母写错。是 σ/√n，不是 σ/n，也不是 σ。
- **易错3**：双尾单尾临界值搞混。双尾 α=0.05 用 1.96，单尾用 1.645。
