## 一、本章一句话定位

**区间估计是猜"参数大概在哪"，假设检验是判断"参数是不是等于某个值"。** 它用的是"无罪推定"逻辑：先假设原假设成立，看样本证据是否极端到在原假设下几乎不可能发生——如果是，就拒绝原假设。本章是统计推断的另一根支柱，也是论文实证部分最常用的方法。

## 三、核心公式清单

| 公式 | 含义 |
|---|---|
| $Z=\dfrac{\bar{x}-\mu_0}{\sigma/\sqrt{n}}$ | 总体均值 Z 检验统计量（σ已知/大样本） |
| $t=\dfrac{\bar{x}-\mu_0}{s/\sqrt{n}}$ | 总体均值 t 检验统计量（σ未知小样本） |
| $Z=\dfrac{p-P_0}{\sqrt{P_0(1-P_0)/n}}$ | 总体比例 Z 检验统计量 |
| 拒绝规则（双尾） | $\|Z\|>z_{\alpha/2}$ 则拒绝 H0 |
| 拒绝规则（右尾） | $Z>z_\alpha$ 则拒绝 H0 |
| 拒绝规则（左尾） | $Z<-z_\alpha$ 则拒绝 H0 |

## 四、方法选择速查

| 你要检验什么 | 用什么 |
|---|---|
| σ已知，检验均值是否等于 μ0 | **Z 检验** |
| σ未知，小样本，检验均值 | **t 检验**（自由度 n-1） |
| 大样本，不管 σ | **Z 检验**（t≈Z） |
| 检验比例是否等于 P0 | **Z 检验**（大样本） |
| 只关心"有没有差异"不管方向 | **双尾检验** |
| 关心"是否大于"或"是否小于" | **单尾检验** |
