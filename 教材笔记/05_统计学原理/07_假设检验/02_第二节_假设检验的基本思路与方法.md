## 本节内容

### 一、假设检验的四步流程

1. **建假设**：写出 H0 和 H1。
2. **定 α**：选显著性水平（通常 0.05），查临界值。
3. **算统计量**：根据样本算 Z 或 t。
4. **做判断**：统计量落在拒绝域就拒绝 H0，否则不拒绝。

### 二、双尾检验 vs 单尾检验

| | 双尾检验 | 右尾检验 | 左尾检验 |
|---|---|---|---|
| H0 | μ=μ0 | μ≤μ0 | μ≥μ0 |
| H1 | μ≠μ0 | μ>μ0 | μ<μ0 |
| 拒绝域 | 两端各 α/2 | 右端 α | 左端 α |
| 临界值 | ±zα/2 | zα | -zα |
| 什么时候用 | 只问"有没有差异" | 问"是否提高了" | 问"是否降低了" |

### 三、两类错误

| | H0 真实 | H0 不真实 |
|---|---|---|
| 接受 H0 | 正确（1-α） | **第二类错误 β**（放走坏人） |
| 拒绝 H0 | **第一类错误 α**（冤枉好人） | 正确（1-β，检验功效） |

**样本量固定时，α 和 β 此消彼长**：要少冤枉好人（α 小），就容易放走坏人（β 大）。要同时降低两类错误，只能增大样本量。

### 四、P 值法

P 值 = "在 H0 成立的前提下，观察到当前样本（或更极端）的概率"。
- P < α → 拒绝 H0。
- P ≥ α → 不拒绝 H0。

P 值比临界值法更精确——它告诉你"如果拒绝 H0，实际冒了多大风险"，而不是只说"过没过线"。
