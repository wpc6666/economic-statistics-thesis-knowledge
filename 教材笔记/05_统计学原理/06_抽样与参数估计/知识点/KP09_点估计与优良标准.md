# KP09 点估计与优良标准

> 所属：[[00_章节总结|第六章 抽样与参数估计]] ｜ 节：[[04_第四节_参数估计]]

## 1. 一句话先懂（小白版）

**点估计**就是用一个具体的数去猜总体参数——"我猜全市平均工资是 6500 元"。但不是随便一个数都能猜得好，好的估计量要满足三条：**无偏**（平均不偏）、**有效**（方差小）、**一致**（样本越大越准）。

## 2. 严格定义

**点估计**：用样本统计量的某个具体取值，直接作为总体参数的估计值。例如用 $\bar{x}$ 估计 $\mu$，用 $p$ 估计 $P$，用 $s^2$ 估计 $\sigma^2$。

**估计量的三条优良标准**：

| 标准 | 数学表达 | 直觉 |
|---|---|---|
| **无偏性** | $E(\hat{\theta})=\theta$ | 反复抽样，估计值平均等于真值 |
| **有效性** | $V(\hat{\theta}_1)<V(\hat{\theta}_2)$ | 同样无偏，方差更小的更有效 |
| **一致性** | $n\to\infty$ 时 $\hat{\theta}\to\theta$ | 样本越大，估计越准 |

## 3. 为什么样本均值是好的估计量

- **无偏**：$E(\bar{x})=\mu$（已证明）。
- **有效**：$V(\bar{x})=\sigma^2/n<\sigma^2=V(X)$，即样本均值比抽一个人准。
- **一致**：由大数定律，$n$ 越大 $\bar{x}$ 越靠近 $\mu$。

**样本方差为什么除以 n-1 而不是 n？**——就是为了无偏。如果除以 n，$E(s_n^2)=\frac{n-1}{n}\sigma^2<\sigma^2$，是有偏的。除以 n-1 才能让 $E(s_{n-1}^2)=\sigma^2$。

## 4. 什么时候用

- 任何参数估计的第一步。
- 评价不同估计方法哪个好。

## 5. 对比

| 估计量 | 无偏吗 | 有效吗 | 一致吗 |
|---|---|---|---|
| $\bar{x}$ 估计 $\mu$ | 是 | 是（比单个X准） | 是 |
| 样本中位数估计 $\mu$ | 是 | 否（比方差大） | 是 |
| 抽一个人估计 $\mu$ | 是 | 否（方差=σ²） | 否 |
| $s_n^2=\frac{\sum(x_i-\bar{x})^2}{n}$ | **否**（偏小） | — | 是 |
| $s_{n-1}^2=\frac{\sum(x_i-\bar{x})^2}{n-1}$ | 是 | — | 是 |

## 6. 例子

**生活实例**：
想估计全班平均身高。你有几种办法：
- 抽 1 个人的身高当估计——无偏（因为 $E(X)=\mu$），但太散，无效。
- 抽 30 个人算平均——无偏，而且方差是 $\sigma^2/30$，有效。
- 抽全班最高的那个人——有偏（他肯定偏高），直接排除。

**经济实例**：
估计某厂灯泡平均寿命。用 100 只灯泡的样本平均寿命 $\bar{x}=1500$ 小时作为点估计。这个估计是无偏的——反复抽样，1500 上下波动，平均正好是真均值。

## 7. 易错点 & 关联

- **易错1**：以为点估计就是猜一个数完事。点估计没说准不准，要配区间估计（[[KP10_区间估计与置信区间]]）。
- **易错2**：以为无偏就够了。无偏但方差极大的估计量（比如抽一个人），实际没法用。
- **易错3**：样本方差除以 n。必须除以 n-1 才无偏（小样本时尤其重要）。
