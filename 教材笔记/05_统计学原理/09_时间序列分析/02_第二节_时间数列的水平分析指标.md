## 本节内容

### 一、发展水平与序时平均数
发展水平就是数列里每一个具体数。序时平均数是把不同时间的发展水平平均一下，反映一段时间内的"一般水平"。

**和第 5 章一般平均数的关键区别**：
- 一般平均 = 同一时期、不同个体之间拉平（静态）；
- 序时平均 = 同一个体、不同时间之间拉平（动态）。

### 二、序时平均数的算法选择（本节核心）

| 数列类型 | 数据特点 | 公式 |
|---|---|---|
| 时期数列 | 各期长度相等 | $\bar{a} = \sum a_i / n$ |
| 时点数列（连续登记） | 每天都有 | $\bar{a} = \sum a_i / n$ |
| 时点数列（变动登记） | 知道变动脉搏 | $\bar{a} = \sum a_i f_i / \sum f_i$ |
| 时点数列（间隔相等） | 月末、季末 | **首末折半法**：$(\frac{a_1}{2} + a_2 + \cdots + \frac{a_n}{2})/(n-1)$ |
| 时点数列（间隔不等） | 时点不齐 | 加权首末折半 |
| 相对数/平均数数列 | $c_i = a_i/b_i$ | $\bar{c} = \bar{a}/\bar{b}$ |

**首末折半法的直觉**：时点是"照片"，相邻两张之间假设线性变化，所以这段时间的平均是 $(a_i + a_{i+1})/2$。首尾两张照片各自只贡献半段，中间每张照片都在相邻两段里各贡献一半，合计 1 份。

### 三、增长量
- 逐期：$a_i - a_{i-1}$
- 累计：$a_i - a_0$
- 关系：累计 = 各逐期之和（中间项全抵消）
- 平均增长量 = $(a_n - a_0) / n$

## 本节与其他节/章的联系
水平指标是后续速度指标（第三节）的计算基础——发展速度就是两个发展水平之比，增长 1% 绝对值就是前期水平除以 100。序时平均数本身又和第 5 章算术平均、加权平均、几何平均思想一脉相承。
