# KP17 循环波动与不规则波动

## 1. 一句话先懂（小白版）
- **循环波动 $C$**：几年一轮的经济周期（繁荣→衰退→萧条→复苏），不像季节那样固定一年，长短不一但周而复始。
- **不规则波动 $I$**：天灾、战争、突发疫情这种没法预测的偶然扰动。

测完趋势 $T$ 和季节 $S$ 后，剩下的 $CI$ 再做一次移动平均，平滑掉随机项，剩下的就是 $C$；$CI / C = I$。

## 2. 严格定义
乘法模型：$Y = T \times S \times C \times I$。

分解顺序：
1. 算 $S$（季节指数）；
2. $Y/S$ 剔除季节，做回归得 $T$；
3. $CI = (Y/S) / T$；
4. 对 $CI$ 做移动平均得 $C$；
5. $I = CI / C$。

## 3. 公式怎么来的、为什么是它
每一步除法都是"剔除"：除以 $T$ 去掉趋势，除以 $S$ 去掉季节，最后用移动平均去掉不规则。剩下的就是可识别的周期。

## 4. 什么时候用这个方法
- 判断经济周期位置（繁荣/衰退）；
- 识别异常年份（$I$ 偏离 1 很远）；
- 做完整四因素分解预测。

## 5. 为什么不用别的方法
| 因素 | 测定难度 |
|---|---|
| $T$ 趋势 | 易，回归即可 |
| $S$ 季节 | 较易，季节指数 |
| $C$ 循环 | 难，周期长度不定 |
| $I$ 不规则 | 不可预测，预测时取 1 |

## 6. 例子
**经济实例**（教材图 9-3）：啤酒例中，2008Q3 的 $CI = 1.0594$，移动平均后 $C = 1.0442$，$I = 1.0594/1.0442 \approx 1.01$——这一期几乎没有不规则扰动。

预测 2012—2013 时，未来的 $I$ 取 1.0000（不能预知），$C$ 取最后一个周期的值。

## 7. 易错点 & 关联
- **易错 1**：把 $I$ 当可预测项。预测时 $I=1$。
- **易错 2**：$C$ 和 $S$ 混淆。$S$ 周期固定（一年），$C$ 周期不固定（3—10 年）。
- **易错 3**：以年为单位的数列没有季节因素（$S$ 不存在），模型退化为 $Y = T \times C \times I$。
