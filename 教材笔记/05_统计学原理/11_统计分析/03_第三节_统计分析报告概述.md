## 本节内容

### 一、什么是统计分析报告

统计分析报告，是以统计资料为事实依据、以统计方法为技术手段，**定量分析与定性分析相结合**，去认识和揭示事物的一种分析研究活动。它是统计工作的最后成果——前面收集数据、整理数据、计算指标、做模型，最后都要落成一份报告，这才叫"出活"。

一句话：**统计报告不是数字罗列，是用数据论证一个观点。**

### 二、统计分析报告的三个根本特点

1. **以统计资料为依据**：用数字说话，不是拍脑袋。
2. **以统计方法为手段**：分组、对比、平均、指数、回归、时间序列……该用就用。
3. **定量与定性相结合**：数字是血肉，观点是灵魂。光有数字没有观点，是流水账；光有观点没有数字，是空谈。

研究路径是"**质 → 量 → 质**"：先从业务里提出问题（质），再用数据去测量（量），最后回到对业务规律的认识（新的质）。

### 三、统计分析报告的分类

| 分类标准 | 类别 | 典型场景 |
|---|---|---|
| 按报告对象与目的 | 统计**工作报告** | 向上级汇报、年度总结、进度分析 |
|  | 统计**研究报告** | 学术论文、学位论文、课题研究报告 |
| 按呈现形式 | **书面报告** | 提交、归档、发表 |
|  | **口头陈述报告** | 答辩、汇报会、发布会 |

### 四、统计分析报告的一般结构（四段式）

不管是工作报告还是研究报告，骨架大体是：

```
基本情况  →  成绩/问题  →  原因分析  →  对策建议
   ↑            ↑             ↑              ↑
 用数据打底   用对比找差距   用方法挖根源   用结论指方向
```

- **基本情况**：本期/本地区的总量、速度、结构，和历史比、和计划比、和先进比。
- **成绩与问题**：哪些指标好于预期、哪些掉队、哪些异常。
- **原因分析**：为什么会这样？是外部环境、是政策、是结构、是管理？
- **对策建议**：下一步怎么办？要具体、可操作，不能喊口号。

### 五、写报告要守的四条原则

1. **实事求是**：数字不能造，结论不能编。统计造假是统计工作的第一大忌。
2. **遵纪守法**：以方针政策、法律法规为准绳。
3. **以唯物辩证法为指导**：一分为二，既看成绩也看问题，不搞唯心臆测。
4. **规程严谨又生动具体**：图表要配文，文字要通俗，标题要醒目。

### 六、常见毛病（新手最容易犯的错）

详见 [[KP09_统计分析报告常见毛病]]。最典型的三种：

- **流水账**：从 1 月写到 12 月，每月干了啥列一遍，读完不知道你想说啥。
- **数字堆砌**：整页整页的表格和数字，没有提炼、没有观点。
- **缺乏结论**：分析了半天，最后"特此报告"，没有对策、没有判断。
