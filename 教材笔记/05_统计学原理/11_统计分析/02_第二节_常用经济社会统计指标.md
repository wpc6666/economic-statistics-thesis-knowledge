## 本节内容

这一节是"常识性+工具性"的指标集合。国家统计局每年发的统计公报、新闻联播里播的"GDP 增长 X%"、"CPI 上涨 Y%"、"失业率 Z%"——背后全是这一节的东西。学统计不是为了做数学题，而是为了**看得懂新闻、读得懂公报、写得出有数据支撑的判断**。

### 一、衡量经济总量：GDP 与 GNP

GDP（国内生产总值）是一个国家**领土范围内**常住单位在一定时期内生产的最终成果；GNP（国民生产总值，现称 GNI）是一个国家**国民**无论身在何处赚的总收入。两者差一个"国外净要素收入"。

GDP 有三种算法，理论上应当相等，叫"三面等值"：

- **生产法**：各部门总产出 − 中间投入 = 增加值，全部加总。
- **收入法**：劳动者报酬 + 固定资产折旧 + 生产税净额 + 营业盈余。
- **支出法**：最终消费 + 资本形成总额 + 货物和服务净出口。

详见 [[KP02_GDP与GNP]]。

### 二、衡量产业结构：三次产业

按生产活动的历史顺序，把整个国民经济切成三块：

- **第一产业**：农、林、牧、渔业（直接取自自然界）。
- **第二产业**：采矿业、制造业、电力燃气水生产供应业、建筑业（对初级产品再加工）。
- **第三产业**：除一、二产以外的所有服务业。

第三产业占 GDP 比重越高，通常被认为产业结构越高级——小康水平约 40%，富裕水平约 61%。详见 [[KP03_三次产业划分]]。

### 三、衡量居民生活水平：恩格尔系数

恩格尔系数 = 食品消费支出 ÷ 全部生活消费支出。

直觉：吃饱是刚需，穷人收入几乎全用来吃饭；富人吃饱以后，剩下的钱可以用于教育、旅游、娱乐。所以**恩格尔系数越高，日子越紧巴**。

联合国划分标准：

| 恩格尔系数 | 生活水平 |
|---|---|
| < 30% | 最富裕 |
| 30%–40% | 富裕 |
| 40%–50% | 小康 |
| 50%–60% | 勉强度日 |
| > 60% | 绝对贫困 |

详见 [[KP04_恩格尔系数]]。

### 四、衡量收入分配公平：基尼系数与洛伦兹曲线

洛伦兹曲线把人口按收入从低到高排队，横轴是人口累计比例，纵轴是收入累计比例。如果所有人收入一样，曲线就是 45° 对角线（绝对平均）；如果所有收入都被一个人拿走，曲线就贴在横坐标轴上（绝对不平均）。

基尼系数 = 对角线和洛伦兹曲线围成的面积 a ÷ 对角线与坐标轴围成的三角形面积 A。

- G = 0：绝对平均。
- G = 1：绝对不平均。
- 0.2 以下高度平均；0.2–0.3 相对平均；0.3–0.4 比较合理；**0.4 是国际警戒线**；0.4 以上差距偏大。

详见 [[KP05_基尼系数与洛伦兹曲线]]。

### 五、衡量物价：通货膨胀率与 CPI

CPI（居民消费价格指数）是一篮子消费品和服务的价格报告期比基期的相对数。CPI 的同比涨幅，就是大家口中的"通货膨胀率"。

按严重程度分三档：

- **温和通胀**：百分之几，低而稳，经济能正常运转。
- **奔腾通胀**：两位数且加速，货币开始紊乱。
- **恶性通胀**：月通胀率 50% 以上，货币体系濒临崩溃。

详见 [[KP06_通货膨胀率与CPI]]。

### 六、衡量劳动力闲置：失业率

失业率 = 失业人数 ÷ 经济活动人口（就业+失业）。

我国官方公布的是**城镇登记失业率**：只算在就业服务机构登过记的城镇户口失业者，不含进城农民工、不含农村剩余劳动力。口径偏窄，国际可比性差。近年来国家统计局也发布**城镇调查失业率**，口径更接近国际劳工组织标准。

详见 [[KP07_失业率]]。

### 七、其他常用指标速览

| 指标 | 一句话 |
|---|---|
| 城镇化率 | 城镇人口 ÷ 总人口，反映人口集聚程度 |
| 居民消费率 | 居民消费 ÷ GDP，反映内需强弱 |
| R&D 经费投入强度 | 研发经费 ÷ GDP，衡量创新努力程度 |
| 人口自然增长率 |（出生−死亡）÷ 平均人口，千分数 |
| 外贸依存度 | 进出口总额 ÷ GDP，小国通常高于大国 |
| 区位商 | 某地区某产业占比 ÷ 全国该产业占比，>1 说明专业化 |
| HDI 人类发展指数 | 预期寿命 + 教育 + 人均 GDP 三维度综合，联合国发布 |
