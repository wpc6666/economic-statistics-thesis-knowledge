### 二、综合评价法一句话是什么

综合评价法，就是**用一套统计指标体系，把多个方面、多个量纲的指标，通过加权打分，合成一个综合得分，用来给评价对象排名次、分等级**。

它和"单项评价"相对：单项评价只用一个指标（比如用人均 GDP 排城市座次），综合评价同时用好几个指标（经济、社会、环境、创新……），最后算一个总分。

### 三、常用方法一句话清单

| 方法 | 一句话是干嘛的 |
|---|---|
| **德尔菲法（Delphi）** | 找一群专家匿名多轮打分，反复反馈直到达成共识，用来主观定权重。 |
| **层次分析法（AHP）** | 把决策问题拆成目标层–准则层–方案层，专家两两比较打 1–9 分，算出权重向量并做一致性检验。 |
| **熵值法** | 看每个指标在样本间的差异大小，差异越大、信息量越大、权重越高——纯客观赋权。 |
| **变异系数法** | 用标准差除以均值，衡量各指标的相对变异程度，变异越大权重越高。 |
| **TOPSIS 法** | 找"最优点"和"最劣点"，算每个样本到这两个端点的距离，距离最优点越近越好。 |
| **模糊综合评价** | 当指标是"好/中/差"这种模糊语言时，用隶属度矩阵和模糊算子做综合判断。 |
| **灰色关联分析** | 样本少、信息不全时，算各比较序列与理想序列的曲线几何相似程度，相似度高者优。 |
| **主成分/因子分析** | 把高度相关的多个指标压缩成少数几个不相关的综合因子，顺带由因子载荷定权重。 |

### 四、综合评价的七步流程（记住骨架即可）

1. **明确目的**：为什么评、评谁、评哪几个方面。
2. **建指标体系**：选哪些指标（整体性、可比性、可操作性、相互独立性）。
3. **定权重**：主观法（德尔菲、AHP）或客观法（熵值、变异系数、主成分）。
4. **无量纲化**：把"元、%、人、平方米"这些不同量纲拉到同一把尺子上（标准化、规格化、功效系数法）。
5. **定评价标准**：和历史比、和计划比、和先进比、和经验值比。
6. **合成总分**：加权算术平均、加权几何平均、或 TOPSIS 距离。
7. **分析结果**：排名、找差距、提建议。
