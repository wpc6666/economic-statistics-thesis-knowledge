# KP01 · 固定效应模型（FE）

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


## 1. 是什么

**一句话直觉**：每个个体都有自己的"底色"（固定效应 $u_i$）——有的人天生能力强、有的省天生资源多。固定效应模型把每个个体的底色控制住，只看**同一个体内部随时间的变化**。

面板回归方程：

$$y_{it} = \beta_0 + \beta_1 x_{it} + u_i + \varepsilon_{it}$$

各符号含义：
- $i$ = 个体（省、企业、个人，$i=1,\dots,n$）
- $t$ = 时间（年、月，$t=1,\dots,T$）
- $u_i$ = 个体固定效应（不随时间变化的个体特征）
- $\varepsilon_{it}$ = 随机扰动项

**关键假设**：FE 允许 $u_i$ 与解释变量 $x_{it}$ 相关，即 $\text{Cov}(u_i, x_{it}) \neq 0$。这是 FE 比[[07_随机效应RE与Hausman检验|随机效应]]（RE）更一般的地方——不要求个体异质性与解释变量无关。

---

## 2. 怎么用

固定效应有三种等价的估计方法。

**方法一：LSDV（最小二乘[[KP03_虚拟变量|虚拟变量]]法）**

给每个个体加一个虚拟变量：

$$y_{it} = \beta_0 + \beta_1 x_{it} + \gamma_2 D_{2i} + \dots + \gamma_n D_{ni} + \varepsilon_{it}$$

其中 $D_{ki}=1$ 当观测来自第 $k$ 个个体。每个虚拟变量系数 $\gamma_k$ 就是该个体的"底色"。个体很多时（如1000家企业）虚拟变量过多，不方便。

**方法二：组内估计量（Within Estimator，最常用）**

对每个个体做去均值变换：

$$y_{it} - \bar{y}_i = \beta_1 (x_{it} - \bar{x}_i) + (\varepsilon_{it} - \bar{\varepsilon}_i)$$

其中 $\bar{y}_i = \frac{1}{T}\sum_{t=1}^T y_{it}$。关键是 $u_i$ 被减掉了（它不随时间变，$\bar{u}_i = u_i$），对变换后数据做 [[KP02_OLS正交性|OLS]] 即可。

**方法三：一阶差分法（FD）**

$$y_{it} - y_{i,t-1} = \beta_1 (x_{it} - x_{i,t-1}) + (\varepsilon_{it} - \varepsilon_{i,t-1})$$

$u_i$ 同样被减掉。$T=2$ 时 FD 与组内估计完全相同；$T>2$ 时两者不同但都一致。

**Stata 代码**：

```stata
xtset id year                       // 设定面板
xtreg lnwage educ exper, fe         // 固定效应回归
reg lnwage educ exper i.id          // LSDV，系数与FE等价
xtreg lnwage educ exper i.year, fe  // 双向固定效应（个体+时间）
```

输出中 `F test that all u_i=0` 若显著，说明个体效应确实存在、用 FE 比混合 OLS 合适。

## 3. 什么时候用

- 数据是**面板结构**（多个个体 × 多个时间点）
- 怀疑存在**不随时间变化的遗漏变量**（地理、文化、能力、资源禀赋），且这些变量与解释变量相关
- 关注的核心变量**随时间有变化**（FE 靠组内变化识别）
- 想控制所有"个体层面说不清楚的固定差异"

---

## 4. 什么时候不能用 / 易错点

**不能用的情况**：
- 核心解释变量**不随时间变化**（性别、种族、地理位置），FE 会把它连同 $u_i$ 一起消掉，无法估计
- 核心变量随时间变化极小，FE 估计很不准（标准误大）
- 时间序列很短（$T=2$ 且变量几乎不变）

**易错点**：

| 误区 | 正确理解 |
|------|----------|
| FE 控制了所有遗漏变量 | 只控制了**不随时间变化**的遗漏变量，随时间变的遗漏变量仍在 |
| FE 一定比 OLS 好 | 若个体效应与 x 无关，RE 更有效 |
| FE 与 OLS 系数差很多说明有偏 | 可能只是 FE 只用了组内变异 |
| LSDV 和 FE 不一样 | 二者在数学上完全等价 |

---

## 5. 与相似方法对比

| 方法 | 是否允许 $u_i$ 与 x 相关 | 利用的信息 | 能否估计不变变量 |
|------|------------------------|-----------|----------------|
| 混合 OLS | —（忽略 $u_i$） | 组内+组间 | 能 |
| 固定效应 FE | 允许 | 只用组内 | 不能 |
| 随机效应 RE | 不允许 | 组内+组间 | 能 |

---

## 6. 为什么用 FE 不用别的

- **为什么不用混合 OLS？** 混合 OLS 忽略 $u_i$，若 $u_i$ 与 x 相关（如能力强的人受教育更多），系数有[[02_遗漏变量偏误|遗漏变量偏误]]。
- **为什么不用随机效应 RE？** RE 要求 $u_i$ 与 x 不相关，这个假设往往不成立。用 Hausman 检验，若拒绝原假设则应选 FE。
- **为什么不用一阶差分？** $T>2$ 时组内估计量通常更有效（在误差无[[03_自相关|自相关]]时），FE 是更常用[[KP05_评价标准值xi0的选择|的选择]]。

## 7. 完整例子：教育对工资的影响

模型：$\ln(wage_{it}) = \beta_0 + \beta_1 educ_{it} + u_i + \varepsilon_{it}$

能力是 $u_i$ 的一部分，不随时间变但与教育相关。FE 估计的是"同一个人多上几年学后工资涨多少"，而不是"能力强 vs 能力弱的人工资差"。

**手算（n=2，T=2）**：

| 个体 | 年 | ln(wage) | educ | 去均值 ln(wage) | 去均值 educ |
|------|-----|----------|------|----------------|------------|
| A | 2010 | 2.0 | 12 | −0.5 | −1 |
| A | 2012 | 3.0 | 14 | 0.5 | 1 |
| B | 2010 | 1.5 | 10 | −0.5 | −1 |
| B | 2012 | 2.5 | 12 | 0.5 | 1 |

$$\hat{\beta}_{FE} = \frac{\sum \widetilde{y}_{it}\widetilde{x}_{it}}{\sum \widetilde{x}_{it}^2}$$

- 分子：$(-0.5)(-1)+(0.5)(1)+(-0.5)(-1)+(0.5)(1) = 2.0$
- 分母：$1+1+1+1 = 4$
- $\hat{\beta}_{FE} = 2.0/4 = 0.5$

**解读**：同一个人多上 1 年学，工资约提高 50%。

## 答辩常问（带标准答案）

1. **问：固定效应模型是怎么把"不随时间变化的遗漏变量（如个人能力、地区资源）"消掉的？** 答：靠组内去均值。对每个个体 i，把模型两边减去该个体在所有时点的均值：$u_i$ 不随时间变，所以 $\bar u_i=u_i$，一减就被消掉了，剩下的方程是 $(y_{it}-\bar y_i)=\beta_1(x_{it}-\bar x_i)+(\varepsilon_{it}-\bar\varepsilon_i)$。这个变换后做 OLS，系数只靠"同一个体自己前后变化"的变异识别，个体之间的固有差异（不管有没有观测到）全部被控制住——这就是 FE 能解决"不可观测但不随时间变"的遗漏变量的原理。
2. **问：固定效应模型是不是把所有遗漏变量都控制住了？它有什么致命局限？** 答：不是。FE 只消掉**不随时间变化**的遗漏变量；随时间变化的混淆因素（如个人健康状况逐年变化、地区当年的政策冲击）仍然留在扰动项里。它的局限有两个：一是**不随时间变化的核心解释变量无法估计**（性别、种族、地理位置会和 $u_i$ 一起被减掉）；二是核心变量随时间变化很小时，组内变异少，标准误会很大、估计不准。所以选 FE 前要先看核心变量在样本期内到底变不变。
3. **问：LSDV（个体虚拟变量法）、组内估计量、一阶差分法这三种做法是什么关系？** 答：数学上等价——LSDV 给每个个体加虚拟变量，组内估计量去均值后 OLS，一阶差分对相邻两年做差，三者得到的 $\hat\beta_1$ 在 $T=2$ 时完全相同，$T>2$ 时都一致、数值略有差异。Stata 里 `xtreg y x, fe` 是组内估计量的快捷写法，`reg y x i.id` 是 LSDV 写法，系数完全一样。

## 8. 速记卡

- FE = 给每个个体去均值，消掉不随时间变的"底色"
- 三种估计：LSDV、组内、一阶差分（T=2 时等价）
- FE 允许 $u_i$ 与 x 相关；不能估计不变变量
- 选 FE 还是 RE：Hausman 检验，拒绝则用 FE
- 双向固定效应：加 `i.year` 同时控制时间冲击
