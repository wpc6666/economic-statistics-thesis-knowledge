## 1. 是什么

在Stata中用 `regress`（缩写 `reg`）命令进行[[05_多元线性回归|多元线性回归]]，用 `predict` 进行预测。本章聚焦：如何跑多元回归、如何解读输出表、如何做预测。

**直觉类比**：`reg` 就是告诉Stata"把左边的y用右边的一堆x拟合成一条线/超平面"，然后Stata吐出系数、标准误、t值、p值、R²等一整张表。

**解决什么问题**：把[[KP02_OLS正交性|OLS]]估计从手算变成一键执行，并系统读出每个统计量的含义。

## 2. 怎么用

### 完整步骤

1. 打开数据：`use filename.dta, clear`
2. 跑回归：`reg y x1 x2 x3`
3. 解读输出表的每个数字
4. 用 `predict` 算拟合值
5. 用 `predict, residual` 算残差
6. 用 `test x1 x2` 做联合显著性检验

### Stata命令语法

```stata
regress 被解释变量 解释变量1 解释变量2 ... 解释变量K
```

- `regress` 可缩写为 `reg`
- 第一个变量是y，后面的都是x（自动包含常数项 `_cons`）

### Stata代码（逐行注释）

```stata
* ============================================
* 目的：工资方程多元回归完整流程
* 数据：grilic.dta（NLS年轻男子工资数据，n=758）
* ============================================

* 第一步：打开数据
use grilic.dta, clear

* 第二步：描述数据，看看有哪些变量
describe

* 第三步：跑多元回归
* 被解释变量：lnw（工资对数）
* 解释变量：s(教育年限) iq(智商) expr(工龄) tenure(现任工龄)
*           smsa(是否大城市) south(是否南部) black(是否黑人)
reg lnw s iq expr tenure smsa south black

* 第四步：计算拟合值（即y的预测值），记为lnw1
predict lnw1

* 第五步：计算残差，记为e
predict e, residual

* 第六步：查看前几个观测的实际值、拟合值、残差
list lnw lnw1 e in 1/10

* 第七步：检验"教育年限s的系数=0"——其实输出表里的t值已经做了
* 再做一次F检验：s和iq联合不显著
test s iq

* 第八步：检验s的系数是否等于0.1
* （原假设 H0: s=0.1）
reg lnw s iq expr tenure smsa south black
test s = 0.1
```

### 输出表逐列解读

以原书grilic回归输出为例：

|-----|-------|-----------|---|---------|----------------------|
| s | .0610184 | .0068025 | 8.97 | 0.000 | .04765 .07439 |
| iq | .003117 | .0016658 | 1.87 | 0.062 | -.00015 .00638 |
| expr | .0387198 | .0066141 | 5.85 | 0.000 | .02573 .05170 |
| tenure | .0493802 | .0081996 | 6.02 | 0.000 | .03329 .06547 |
| smsa | .139842 | .0280335 | 4.99 | 0.000 | .08479 .19489 |
| south | -.1167824 | .0262168 | -4.45 | 0.000 | -.16824 -.06533 |
| black | -.1014673 | .036097 | -2.81 | 0.005 | -.17233 -.03060 |
| _cons | 4.986242 | .1391288 | 35.84 | 0.000 | 4.71306 5.25942 |

**逐列解释**：

| 列名 | 含义 | 怎么读 |
|------|------|--------|
| Coef. | OLS估计的系数 $\hat\beta_k$ | 每个解释变量对y的偏效应 |
| Std. Err. | 标准误 $SE(\hat\beta_k)$ | 系数估计的抽样波动大小 |
| t | t统计量 = Coef./Std.Err. | 检验H0: β=0的t值 |
| P>\|t\| | p值 | p<0.05则拒绝H0，变量显著 |
| [95% Conf. Interval] | 95%置信区间 | 不跨0则在5%水平显著 |

**上半部分**：

| 项目 | 数值 | 含义 |
|------|------|------|
| Number of obs | 758 | 样本量 |
| F(7,750) | 118.69 | 整个方程F统计量 |
| Prob > F | 0.0000 | 整个方程联合显著 |
| R-squared | 0.5126 | 模型解释了y变异的51.26% |
| Adj R-squared | 0.5081 | 校正自由度后的R² |
| Root MSE | .34338 | 扰动项标准差的估计s |

### test命令的用法

```stata
* 检验多个变量联合不显著
reg lnw s iq expr tenure smsa south black
test iq expr tenure        * H0: iq=expr=tenure=0

* 检验系数相等
test s = expr               * H0: β_s = β_expr

* 检验线性组合
test s - iq = 0.1           * H0: β_s - β_iq = 0.1
```

### predict预测

```stata
* 点预测：对样本内每个观测计算拟合值
predict yhat
* （无选项时默认算拟合值 y̅ = x'β̂）

* 残差
predict e, residual
* （加 residual 选项才算残差 e = y - ŷ）
```

## 3. 什么时候用

**适用场景**：
- 任何需要估计多元回归方程的实证研究
- 报告回归结果（系数、标准误、p值、R²）
- 检验单个或多个系数的显著性

**数据要求**：
- .dta格式，无缺失值（或已处理缺失值）
- 解释变量间无完全共线性

## 4. 什么时候不能用/易错点

- **忘记 `, clear`**：打开新数据时如果不加clear，Stata会报错"no; data in memory would be lost"
- **predict不加选项**：默认算拟合值，不是残差！要算残差必须写 `predict e, residual`
- **把p值当效应大小**：p值小只说明显著，不说明效应大。大样本下很小的效应也能显著
- **R²高就认为模型好**：R²高可能是因为样本趋势一致，不一定因果正确
- **不看"Number of obs"**：缺失值会自动被删掉，样本量可能比预期小

## 5. 与相似方法对比表

| 命令 | 功能 | 什么时候用 | 输出重点 |
|------|------|-----------|----------|
| reg | OLS多元回归 | 标准横截面/时间序列回归 | Coef./t/p值 |
| reg, robust | OLS+[[KP03_稳健标准误|稳健标准误]] | 怀疑[[02_异方差|异方差]]时（第7章） | Coef.不变，Std.Err.变大 |
| newey | Newey-West [[KP03_NeweyWest_HAC|HAC]] | 怀疑[[03_自相关|自相关]]时（第8章） | Coef.不变，Std.Err.调整 |
| test | 联合[[KP02_假设检验|假设检验]] | 检验多个系数=0或系数相等 | F统计量和p值 |
| predict | 预测/残差 | 算拟合值或残差 | 新变量 |

## 6. 为什么用这个不用那个

- **为什么用reg而不是手算？** $K>2$时矩阵求逆手算不现实，Stata一键完成。
- **为什么要看Std. Err.？** 只有点估计不够，必须知道估计的精度。标准误大意味着系数不可靠。
- **为什么用test而不是看单个t值？** 单个t值只能检验一个系数；多个系数联合为0必须用F检验（test命令）。
- **被排除的做法（只看R²）会出什么问题？** R²=0.99的模型如果遗漏关键变量，系数仍然有偏；R²=0.3的模型如果控制得当，可能更可信。

## 7. 完整例子

### 书中原例：Cobb-Douglas生产函数回归

```stata
* 打开数据
use cobb_douglas.dta, clear

* 跑二元对数回归
reg lny lnk lnl
```

输出：

| lny | Coef. | Std. Err. | t | P>\|t\| |
|-----|-------|-----------|---|---------|
| lnk | .2330537 | .0635298 | 3.67 | 0.001 |
| lnl | .807278 | .1450762 | 5.56 | 0.000 |
| _cons | -.1773099 | .4342933 | -0.41 | 0.687 |

解读：
- lnk的p值=0.001<0.01，在1%水平显著
- lnl的p值=0.000<0.01，在1%水平显著
- _cons的p值=0.687，不显著（截距项不显著是常见的，不影响）
- R²=0.9574，模型拟合很好

```stata
* 算拟合值
predict lny1

* 算残差
predict e, residual

* 看数据
list lny lny1 e
```

### 小白生活实例：开奶茶店要预测月销量

假设已经回归好：$\widehat{\text{销量}} = 500 + 20\times\text{广告费} + 25\times\text{人流量}$。

某月：广告费=5（百元），人流量=20（百人）。

预测销量 = 500 + 20×5 + 25×20 = 500 + 100 + 500 = 1100杯。

如果这个月实际卖了1200杯，残差 = 1200 - 1100 = +100杯（比预测多卖100杯）。

## 答辩常问（带标准答案）

1. **问：回归后 `predict yhat` 和 `predict e, residual` 有什么区别？能不能随便用？** 答：不能。`predict` 不带选项时默认计算的是拟合值 $\hat y = x'\hat\beta$（即回归线上的预测值）；要算残差必须显式写 `predict e, residual`，残差 $e = y - \hat y$。两者一个是"[[KP05_模型预测|模型预测]]的 y"，一个是"实际 y 减去预测 y"，符号方向完全相反，搞混会让后续的异方差检验、残差图全部做错。
2. **问：想检验"教育年限和智商两个系数联合为零"，为什么不能分别看它们两个的 t 值，而要用 `test s iq`？** 答：两个单独的 t 检验各自在 5% 水平上控制第一类错误，但"两个同时为零"是一个联合约束。如果分别看，两个 t 统计量在原假设下不独立，联合拒绝概率会超过 5%，容易把"其实联合不显著"误判成显著。`test s iq` 计算的是 F 统计量，把约束作为一个整体检验，这才是正确做法。
3. **问：回归输出的 Number of obs 比原始样本量小，是怎么回事？** 答：Stata 默认按"完整观测"原则删除任何一个变量上有缺失值的样本（listwise deletion）。比如原始 800 人，但 iq 有缺失，回归就自动只用所有变量都齐全的 758 人。跑回归前应该用 `misstable` 或各变量的 `summarize` 对比样本量，确认缺失不是系统性的，否则估计的子样本可能不代表总体。

## 8. 速记卡

- `reg y x1 x2 x3`：一键OLS，自动加常数项
- 输出表五列：Coef. / Std.Err. / t / P>\|t\| / 置信区间
- p<0.05 = 显著；R² = 模型解释力；Number of obs = 实际样本量
- `predict yhat` 算拟合值；`predict e, residual` 才算残差
- `test x1 x2` 做联合F检验

**口诀**：reg跑表五列看，系数标准t和p；predict拟合和残差，test联合F检验。
