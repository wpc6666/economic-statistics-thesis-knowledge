# 计量经济学学习笔记

> 基于陈强《计量经济学及Stata应用》的小白向学习笔记库。

## 使用路径

### 小白入门（从零开始）
1. 先读 [00_导论/01_什么是计量经济学](00_导论/01_什么是计量经济学.md)
2. 读 [01_Stata入门](01_Stata入门/00_章节总结.md) 学会[[01_Stata基本操作|基本操作]]
3. 按顺序读 03→04→05 章，掌握 [[KP02_OLS正交性|OLS]] 回归的核心逻辑
4. 每章先看 00_章节总结.md 的框架图，再读知识点卡片

### 复习备考
- 直接看每章 00_章节总结.md 的核心公式清单和自测题
- 重点看知识点卡片的"速记卡"部分
- 对比表是考试重点（[[KP02_异方差处理|异方差处理]]、FE vs RE、OLS vs IV）

### 实战写论文
- 从 [14_实证研究指南](14_实证研究指南/00_实证研究流程.md) 开始
- 按方法选择决策链：OLS → [[KP01_异方差检验|异方差检验]] → [[03_自相关|自相关]]检验 → 内生性判断 → 面板/IV/Logit

## 方法选择决策速查

| 你的数据/问题 | 用什么方法 | 去哪个文件 |
|-------------|-----------|-----------|
| 截面数据，X外生 | OLS + [[KP03_稳健标准误|稳健标准误]] | 03/06章 |
| 截面数据，有遗漏变量 | [[03_工具变量IV|工具变量]] 2[[KP02_两阶段最小二乘2SLS|SLS]] | 09章 |
| 面板数据，有个体效应 | 固定效应 FE | 11章 |
| 因变量是0/1 | Logit/Probit | 10章 |
| 时间序列预测 | ARMA/VAR | 12章 |
| 非平稳序列 | ADF+协整+ECM | 13章 |
| 异方差 | OLS+稳健标准误（首选） | 06章 |
| 自相关 | Newey-West HAC | 07章 |
