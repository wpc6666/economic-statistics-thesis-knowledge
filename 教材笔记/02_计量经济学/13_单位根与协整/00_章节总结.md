# 第14章 单位根与协整 · 章节总结

## 核心问题：非平稳时间序列怎么办

**非平稳时间序列处理流程：**

1. **平稳序列**
   - 直接用ARMA/VAR模型

2. **非平稳序列**
   - **有单位根**：
     - 伪回归风险！
     - 一阶差分→I(1)
     - 多个I(1)变量：
       - 有协整关系→ECM/VECM模型
       - 无协整关系→差分后做VAR
   - **趋势平稳**：
     - 去趋势即可

## 伪回归是什么

两个完全独立的随机游走，回归出来R²很高、t统计量很大——全是假的！

**避免方法**：先做[[KP01_单位根检验ADF|单位根检验]]，再决定怎么处理。

## [[KP01_单位根检验ADF|ADF]]检验三种形式

| 类型 | Stata选项 | 适用情形 |
|------|-----------|----------|
| 无常数无趋势 | `noconstant` | 序列无均值无趋势 |
| 有常数无趋势 | 默认值 | 序列有均值但无趋势 |
| 有常数有趋势 | `trend` | 序列有明显时间趋势 |

## 协整的直觉

> 两个喝醉的人手拉手走路——各自摇摇晃晃（随机游走），但两人之间的距离始终稳定（协整关系）。

## Stata 命令速查

```stata
* ADF单位根检验
dfuller y, lags(p) trend regress

* 协整秩检验
vecrank y1 y2 y3, lags(#)

* VECM估计
vec y1 y2 y3, lags(#) rank(#)
```

## 本章方法答辩速查

1. **问：拿到几个宏观非平稳变量（如 GDP、消费、投资），从单位根检验到建模的完整决策树怎么走？** 答：三步：① **ADF 检验**判[[02_平稳性|平稳性]]——原假设"有单位根"，p<0.05 拒绝才是平稳；水平值不拒绝、一阶差分拒绝（`dfuller D.y`）→ 判定 I(1)；② **查协整**——多个 I(1) 变量直接水平回归有伪回归风险，用 Engle-Granger（双变量，残差 ADF）或 Johansen（多变量，`vecrank` 定协整秩）；③ 协整存在 → 用 **V[[KP02_协整与ECM|ECM]]/ECM** 同时刻画长期均衡（协整方程）和短期调整（误差修正系数必须为负）；协整不存在 → 全部差分后做 [[KP01_VAR模型|VAR]]。这棵树就是时间序列实证的标准报告路径。
2. **问：ADF 检验的原假设是什么？p 值解读最容易犯什么错误？** 答：原假设是"序列**有**单位根（非平稳）"。判断规则：**p<0.05 拒绝原假设 → 平稳；p>0.05 不拒绝 → 认为有单位根**。最常见错误是把 p>0.05 读成"证明了平稳"——恰恰相反，不拒绝"有单位根"等于默认它有单位根。另外注意 ADF 统计量不服从[[07_正态分布|正态分布]]，临界值要用 MacKinnon 表、左单侧检验，不能套 1.96。
