# KP01 单位根检验 ADF

## 一句话直觉

> **随机游走就是"喝醉的人走路"——每一步都是随机的，走得越远越不知道自己在哪。ADF检验就是判断这个序列到底是"喝醉了"还是"清醒的"。**

---

## 一、什么是单位根

### 随机游走模型

$$y_t = y_{t-1} + \varepsilon_t$$

- $\varepsilon_t$ 是白噪声
- $y_t$ 的方差随时间发散：$\text{Var}(y_t) = t\sigma_\varepsilon^2$
- 冲击有永久效应（不会衰减）

### 与平稳AR(1)的对比

$$y_t = \beta_1 y_{t-1} + \varepsilon_t$$

| $\beta_1$ 值 | 类型 | 冲击效应 |
|-------------|------|----------|
| $|\beta_1| < 1$ | 平稳 | 冲击逐渐衰减 |
| $\beta_1 = 1$ | 单位根（随机游走） | 冲击永久持续 |
| $|\beta_1| > 1$ | 爆炸式增长 | 冲击无限放大（现实中少见） |

---

## 二、伪回归（Spurious Regression）

### 问题

两个完全独立的随机游走：

$$y_t = y_{t-1} + u_t, \quad x_t = x_{t-1} + v_t$$

其中 $u_t$ 和 $v_t$ 完全独立。

**回归结果**：$y_t$ 对 $x_t$ 回归，R²可能高达0.4，t统计量高达94——但两者完全无关！

### 为什么会这样

两个随机游走都有"共同的时间趋势"，回归会把这个假趋势当成真实关系。

### 解决方法

1. 先差分，变成平稳序列再回归
2. 检验是否存在协整关系（见KP02）

---

## 三、DF检验

### 检验方程

$$\Delta y_t = \beta_0 + \delta y_{t-1} + \gamma t + \varepsilon_t$$

其中 $\delta = \beta_1 - 1$。

### 假设

- $H_0$：$\delta = 0$（有单位根，非平稳）
- $H_1$：$\delta < 0$（无单位根，平稳）

### 关键

DF统计量（t统计量）**不服从[[07_正态分布|正态分布]]**，临界值要查表（MacKinnon临界值）。

**左边单侧检验**：DF统计量越小（负得越多），越拒绝原假设。

---

## 四、ADF检验（增广DF检验）

### 为什么要增广

DF检验假设扰动项无[[03_自相关|自相关]]。如果有自相关，检验结果不可靠。

### ADF方程

$$\Delta y_t = \beta_0 + \delta y_{t-1} + \gamma_1 \Delta y_{t-1} + \gamma_2 \Delta y_{t-2} + \dots + \gamma_p \Delta y_{t-p} + \gamma t + \varepsilon_t$$

加入滞后差分项，保证扰动项无自相关。

#### 【三问】为什么要把模型改写成 $\Delta y_t$ 对 $y_{t-1}$ 的回归？为什么还要加滞后差分？

- **怎么来的（直觉推导）**：原 AR(1) 模型是 $y_t = \beta_1 y_{t-1} + \varepsilon_t$。两边减 $y_{t-1}$，得到 $\Delta y_t = (\beta_1 - 1) y_{t-1} + \varepsilon_t = \delta y_{t-1} + \varepsilon_t$。这个改写的妙处在于：**[[02_平稳性|平稳性]]判断从"$\beta_1$ 是否等于1"变成了"$\delta$ 是否等于0"**。如果 $\delta=0$（即 $\beta_1=1$），就是随机游走（有单位根）；如果 $\delta<0$（即 $\beta_1<1$），就是平稳 AR(1)。检验 $\delta=0$ 比检验 $\beta_1=1$ 方便得多。DF 假设扰动项 $\varepsilon_t$ 无自相关，但现实中经济数据的扰动项通常自相关，所以 Dickey-Fuller 加了 $\gamma_1 \Delta y_{t-1} + \cdots$ 这些滞后差分项——它们的作用是"把自相关吸收掉"，让新的扰动项 $\varepsilon_t$ 变成白噪声，从而保证检验统计量分布正确。
- **为什么用它**：解决"宏观时间序列（GDP、消费、股价）到底是平稳的还是随机游走"这个根本问题。如果直接对非平稳序列回归，会出现"伪回归"——两个完全无关的随机游走回归出 R²=0.9、t 值=94 的假结果。ADF 是进入时间序列分析的第一道关卡：**先判断序列是否平稳，再决定用什么模型**。不做单位根检验就做回归，是时间序列研究的头号错误。
- **知识为什么存在**：1970 年代之前，计量经济学家默认经济时间序列是平稳的，直接回归。直到 Grange 和 Newbold（1974）著名的"伪回归实验"——用两个独立的随机游走回归，发现 99% 的情况 t 值显著——整个计量经济学界才意识到问题有多严重。Dickey 和 Fuller（1979, 1981）提出这个检验方法（拿诺贝尔奖级别的贡献），MacKinnon（1991）给出精确临界值表。ADF 从此成为时间序列论文的标配步骤，也是协整分析（Engle-Granger 两步法）的第一步。

### 三种检验类型

| 类型 | 方程形式 | Stata选项 | 适用 |
|------|----------|-----------|------|
| 无常数无趋势 | $\Delta y_t = \delta y_{t-1} + \dots$ | `noconstant` | 序列无均值 |
| 有常数无趋势 | $\Delta y_t = \beta_0 + \delta y_{t-1} + \dots$ | 默认 | 序列有均值 |
| 有常数有趋势 | $\Delta y_t = \beta_0 + \delta y_{t-1} + \gamma t + \dots$ | `trend` | 序列有趋势 |

## 五、滞后阶数[[KP05_评价标准值xi0的选择|的选择]]

### Schwert法则

最大滞后阶数：

$$p_{\max} = [12 \cdot (T/100)^{1/4}]$$

其中T是样本容量。

### 序贯t规则

从大到小试：看最后一阶滞后差分项是否显著，不显著就减少一阶。

## 六、生活实例：检验GDP对数是否有单位根

### 数据

美国实际GNP对数，1890-1970年，共81个观测。

### Step 1：画时间趋势图

- 明显上升趋势 → 应该带趋势项检验

### Step 2：计算最大滞后阶数

$$p_{\max} = [12 \times (62/100)^{1/4}] = [10.65] = 10$$

### Step 3：ADF检验

```stata
dfuller lrgnp, lags(9) trend reg
```

**输出结果**：

| 统计量 | 值 |
|--------|-----|
| Z(t) | -2.308 |
| 1%临界值 | -4.146 |
| 5%临界值 | -3.498 |
| p值 | 0.4296 |

**判断**：Z(t) = -2.308 > -3.498（5%临界值）→ 不拒绝原假设 → **有单位根**。

### Step 4：检验一阶差分

```stata
dfuller D.lrgnp, lags(1) reg
```

**输出**：Z(t) = -5.322 < -3.566（1%临界值）→ 拒绝原假设 → **差分后平稳**。

**结论**：lrgnp是I(1)过程。

## 七、Stata 完整代码

```stata
* 设定时间序列
tsset year

* ===== ADF检验 =====
* 基本形式
dfuller y, lags(3)

* 带趋势项
dfuller y, lags(3) trend

* 显示回归结果（看滞后差分项是否显著）
dfuller y, lags(3) trend reg

* ===== 判断流程 =====
* 1. 先检验水平值
dfuller y, lags(p) trend reg
* 如果p值>0.05 → 有单位根，继续检验差分

* 2. 检验一阶差分
dfuller D.y, lags(q) reg
* 如果p值<0.05 → 差分后平稳，原序列是I(1)

* 3. 如果还不平稳，检验二阶差分
dfuller D2.y, lags(r) reg
* 一般经济变量最多I(2)
```

## 八、常见误区

| 误区 | 正确理解 |
|------|----------|
| "ADF用普通t检验的临界值" | ADF统计量不服从正态分布，要用MacKinnon临界值 |
| "p>0.05就说明序列是平稳的" | 不对！p>0.05是不拒绝"有单位根"，即认为有单位根 |
| "ADF滞后阶数无所谓" | 阶数太少有偏误，太多检验功效低 |
| "有单位根就不能做任何回归" | 可以做差分回归，或者检验协整关系 |
| "所有宏观变量都有单位根" | 不是，失业率等变量通常是平稳的 |

## 答辩常问（带标准答案）

1. **问：ADF 检验的原假设是什么？p > 0.05 到底该怎么解读？** 答：原假设是"序列**有**单位根（非平稳）"，备择假设是平稳。判断规则必须背准：**p < 0.05 拒绝原假设 → 认为序列平稳；p > 0.05 不拒绝原假设 → 认为有单位根（非平稳）**。最常见的错误就是把 p > 0.05 解读成"证明了平稳"——恰恰相反，不拒绝"有单位根"等于默认它有单位根。另外 ADF 的 t 统计量不服从正态分布，临界值要用 MacKinnon 表（左单侧检验，统计量负得越多越拒绝），不能套 1.96。
2. **问：什么是"伪回归"？为什么要先做 ADF 再回归？** 答：Granger 和 Newbold 的著名实验：拿两个完全独立的随机游走（$y_t=y_{t-1}+u_t$，$x_t=x_{t-1}+v_t$，u 和 v 毫无关系）直接回归，结果 R² 经常超过 0.4、t 值高达十几甚至几十，"高度显著"——但两者本质上毫不相干，只是共享了"时间趋势"。这就是伪回归。所以时间序列分析的第一步永远是单位根检验：非平稳序列要么差分后回归（I(1) 差分一次平稳），要么检验协整关系，绝不能直接回归。
3. **问：ADF 相比 DF 检验多加的那些滞后差分项（$\Delta y_{t-1}, \Delta y_{t-2}\dots$）是干什么用的？** 答：DF 检验假设扰动项没有自相关，但现实经济数据的扰动项几乎总有自相关，直接用 DF 统计量的分布就不对了。加入 $\Delta y$ 的滞后差分项，是为了把残差里残留的自相关"吸收掉"，保证新的扰动项是白噪声，从而 ADF 统计量的分布仍然服从 Dickey-Fuller 分布。滞后阶数不能乱设：太少吸收不干净（检验有偏），太多浪费自由度（检验功效下降），经验上用 Schwert 法则定上限、再用序贯 t 规则从大到小删减。
