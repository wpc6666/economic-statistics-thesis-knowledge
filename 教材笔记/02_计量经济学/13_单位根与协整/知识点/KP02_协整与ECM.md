# KP02 [[07_协整与误差修正ECM|协整与误差修正]]模型 ECM

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


## 一句话直觉

> **两个喝醉的人手拉手走路——各自摇摇晃晃（随机游走），但两人之间的距离始终稳定（协整关系）。误差修正模型就是描述"偏离均衡后多快拉回来"。**

---

## 一、什么是协整

### 定义

如果多个I(1)变量的某种线性组合是I(0)（平稳的），则称它们是协整的。

### 直觉

- 短期利率和长期利率都是随机游走（I(1)）
- 但两者的利差（长期利率 - 短期利率）是平稳的（I(0)）
- 说明它们有长期均衡关系

---

## 二、为什么需要协整

### 差分的代价

直接差分：$\Delta y_t$ 对 $\Delta x_t$ 回归

**问题**：
- 丢失了长期信息（经济含义改变了）
- 只能研究短期关系

### 协整的好处

如果变量间有协整关系，可以同时研究：
- **长期均衡关系**：$y_t = \beta_0 + \beta_1 x_t + \varepsilon_t$
- **短期调整过程**：误差修正模型

---

## 三、Engle-Granger 两步法

### 第一步：估计长期关系

用[[KP02_OLS正交性|OLS]]估计协整回归：

$$y_t = \phi + \theta x_t + z_t$$

如果协整关系存在，OLS估计量是超一致的（收敛速度比通常更快）。

### 第二步：检验残差是否平稳

对残差 $\hat{z}_t = y_t - \hat{\phi} - \hat{\theta} x_t$ 做[[KP01_单位根检验ADF|ADF]]检验。

- 如果残差平稳 → 存在协整关系 ✓
- 如果残差不平稳 → 不存在协整关系 ✗

**注意**：EG-ADF的临界值与普通ADF不同（更严格）。

---

## 四、误差修正模型（ECM）

### 双变量ECM

$$\Delta y_t = \alpha_0 + \alpha_1 (\hat{y}_{t-1} - \hat{\phi} - \hat{\theta} x_{t-1}) + \gamma_1 \Delta x_t + \varepsilon_t$$

其中 $(\hat{y}_{t-1} - \hat{\phi} - \hat{\theta} x_{t-1}) = \hat{z}_{t-1}$ 是上一期的"非均衡误差"。

### 系数解读

- $\alpha_1$：误差修正速度（必须为负）
- $|\alpha_1|$ 越大，偏离均衡后调整越快
- $\alpha_1 = -0.2$：每期修正20%的偏离

### 生活实例：货币需求函数

长期均衡关系：

$$\ln M_t = \beta_0 + \beta_1 \ln Y_t + \beta_2 r_t + \varepsilon_t$$

短期误差修正：

$$\Delta \ln M_t = \alpha_0 + \alpha_1 \hat{\varepsilon}_{t-1} + \gamma_1 \Delta \ln Y_t + \gamma_2 \Delta r_t + u_t$$

**解读**：
- 如果上期货币持有过多（$\hat{\varepsilon}_{t-1} > 0$），本期会减少货币持有（$\alpha_1 < 0$）
- 调整速度 $\alpha_1 = -0.3$：每年修正30%的偏离

---

## 五、Johansen协整检验（多变量）

### 什么时候用

- 变量个数 > 2
- 可能有多个协整关系

### 协整秩（Cointegration Rank）

n个I(1)变量最多有(n-1)个协整关系。

### 两种检验统计量

| 检验 | 原假设 | 特点 |
|------|--------|------|
| 迹检验（Trace） | 协整秩 = h | 更常用，Stata默认 |
| 最大特征值检验 | 协整秩 = h vs h+1 | 较少用 |

---

## 六、VECM模型（向量误差修正模型）

### 模型形式

$$\Delta \mathbf{y}_t = \boldsymbol{\alpha} + \Gamma_0 \mathbf{y}_{t-1} + \Gamma_1 \Delta \mathbf{y}_{t-1} + \dots + \Gamma_{p-1} \Delta \mathbf{y}_{t-p+1} + \boldsymbol{\varepsilon}_t$$

其中 $\Gamma_0 \mathbf{y}_{t-1}$ 是误差修正项。

### 协整秩

$\text{rank}(\Gamma_0)$ = 协整秩 = 线性无关的协整向量个数。

---

## 七、Stata 完整代码

```stata
* 设定时间序列
tsset year

* ===== 第一步：检验所有变量是否都是I(1) =====
dfuller y, lags(p) trend reg
dfuller x, lags(q) trend reg
* 都有单位根 → 可以做协整检验

* ===== Engle-Granger两步法 =====
* 第一步：OLS估计长期关系
reg y x
predict resid, resid

* 第二步：检验残差是否平稳
dfuller resid, noconstant reg
* 注意：EG-ADF临界值比普通ADF更严格

* ===== Johansen协整检验（多变量） =====
* 先选择VAR滞后阶数
varsoc y1 y2 y3

* 检验协整秩
vecrank y1 y2 y3, lags(2) trend(trend)

* 输出解读：
* rank=0: trace统计量 = 46.37 > 临界值34.55 → 拒绝无协整
* rank=1: trace统计量 = 16.18 < 临界值18.17 → 接受协整秩=1
* 结论：有1个协整关系

* ===== 估计VECM =====
vec y1 y2 y3, lags(2) rank(1)

* 输出解读：
* 长期协整方程：y1 = 0.98*y2 - 0.11*y3 + 常数项
* 误差修正项系数：调整速度

* ===== 诊断检验 =====
veclmar        // 残差自相关检验
vecstable, graph  // 系统稳定性检验
```

## 八、对比表：EG两步法 vs Johansen MLE

| 维度 | Engle-Granger | Johansen |
|------|---------------|----------|
| 变量个数 | 适合2个 | 适合多个 |
| 协整关系个数 | 只能1个 | 可以多个 |
| 估计方法 | 两步OLS | MLE |
| 效率 | 较低（两步误差传递） | 较高（同时估计） |
| 软件实现 | 简单 | Stata `vecrank` + `vec` |
| 适用场景 | 双变量、简单关系 | 多变量、复杂系统 |

## 九、常见误区

| 误区 | 正确理解 |
|------|----------|
| "协整就是相关" | 协整是长期均衡关系，不是简单相关 |
| "所有I(1)变量都协整" | 不一定，需要检验 |
| "协整回归的标准误是对的" | EG两步法的标准误有偏，要用MLE |
| "VECM和[[KP01_VAR模型|VAR]]差不多" | VECM包含误差修正项，捕捉长期均衡 |
| "协整秩越大越好" | 协整秩要经济理论支持，不是越大越好 |

## 答辩常问（带标准答案）

1. **问：到底什么是协整？为什么说两个 I(1) 变量"协整"了就不怕伪回归？** 答：定义是：如果几个 I(1) 变量的某个**线性组合**是 I(0)（平稳的），它们之间就是协整的。直觉是两个各自摇摇晃晃的随机游走，手拉手走路、彼此距离始终稳定——短期利率和长期利率都随机游走，但利差（长-短）是平稳的，说明二者有长期均衡关系。协整成立时，直接回归水平值得到的不是伪回归，而是有经济意义的长期均衡方程；只有不协整的 I(1) 变量直接回归才是伪回归。
2. **问：Engle-Granger 两步法具体[[08_答辩PPT怎么做|怎么做]]？检验残差时有什么要注意的？** 答：第一步用 OLS 估计长期关系 $y_t=\phi+\theta x_t+z_t$（协整成立时这个 OLS 是"超一致"的，收敛比普通回归快）；第二步把残差 $\hat z_t=y_t-\hat\phi-\hat\theta x_t$ 拿出来做 ADF 检验——**残差平稳（拒绝单位根）就说明存在协整，残差不平稳就说明不协整**。注意两个细节：残差检验要用 `noconstant`（残差均值已被吸收），而且 EG-ADF 的临界值比普通 ADF **更严格**（因为残差是估计出来的），不能直接套普通 MacKinnon 表。
3. **问：误差修正模型里误差修正系数 $\alpha_1$ 的符号有什么讲究？它的大小代表什么？** 答：$\alpha_1$ 必须为**负**：如果上期偏离均衡（$\hat z_{t-1}>0$，即 y 偏高），本期就要反向修正、把 y 拉回均衡，所以 $\Delta y_t$ 与 $\hat z_{t-1}$ 负相关。$\alpha_1=-0.2$ 的含义是：每期修正掉上一期偏离的 20%，系数绝对值越大，向长期均衡调整得越快。这正是 ECM 同时描述"短期动态 + 长期均衡"的核心——偏离是暂时的，系统会自己拽回来。
