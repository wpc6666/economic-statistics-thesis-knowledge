# 2. Stata基本操作

## 概述

本章通过 grilic_small.xls 数据集（30名美国年轻男子的教育投资回报率数据），手把手教你 Stata 的核心操作：导入数据、审视数据、画图、统计分析、生成变量、日志管理。

## 一、导入数据

### 方法1：Excel 复制粘贴（最常用）

```stata
* 目的：从Excel导入数据到Stata
* 步骤：
* 1. 点击 Data Editor(Edit) 图标打开数据编辑器
* 2. 在Excel中全选数据（Ctrl+C）
* 3. 粘贴到Data Editor中（Ctrl+V）
* 4. 弹窗选择"Treat first row as variable names"（第一行是变量名）
* 5. 关闭Data Editor，点击Save存为 .dta 文件
```

### 方法2：命令打开已有 dta 文件

```stata
* 目的：用命令打开Stata格式数据文件
* 假设文件在E盘根目录
use E:\grilic_small.dta, clear
* clear：表示替换内存中已有的数据（选择项option）
```

```stata
* 目的：清空内存中的数据
clear
```

## 二、变量标签

```stata
* 目的：查看数据集中有哪些变量及其属性
describe
* 简写：d
* 输出：obs（观测数）、vars（变量数）、变量名、存储类型、变量标签
```

```stata
* 目的：修改变量标签
* 操作：点击 Variables Manager 图标 → 编辑变量标签 → Apply
* 注意：Stata严格区分大小写，建议变量名用小写字母
```

## 三、审视数据

### 3.1 列出具体数据

```stata
* 目的：列出所有观测值的 s 和 lnw 变量
list s lnw
```

```stata
* 目的：只看前5个观测值
list s lnw in 1/5
* in 1/5：第1到第5个观测值
```

```stata
* 目的：列出满足条件的观测值
list s lnw if s >= 16
* if：条件筛选
* 逻辑符号：==（等于）、>（大于）、<（小于）、>=（大于等于）、<=（小于等于）、~=或!=（不等于）
```

### 3.2 连续滚屏显示

```stata
* 目的：取消分页显示，连续滚屏
set more off

* 目的：恢复分页显示
set more on
```

### 3.3 删除与保留

```stata
* 目的：删除满足条件的观测值（不可撤销！）
drop if s >= 16

* 目的：只保留满足条件的观测值
keep if s >= 16
```

### 3.4 排序

```stata
* 目的：按变量 s 升序排列
sort s

* 目的：按变量 s 降序排列
gsort -s
* 注意：sort 只能升序，降序要用 gsort -变量名
```

## 四、画图

### 4.1 直方图（看分布）

```stata
* 目的：画教育年限的直方图
histogram s, width(1) frequency
* histogram：直方图命令
* width(1)：组宽设为1（默认Stata自动分组）
* frequency：纵坐标显示频数（默认显示密度）
```

**输出解读**：教育年限呈双峰分布——12年（高中毕业）最多，其次16年（大学毕业）。

### 4.2 散点图（看两变量关系）

```stata
* 目的：画教育年限与工资对数的散点图
scatter lnw s
* 从图可直观看出：工资对数与教育年限似乎正相关
```

```stata
* 目的：在散点图上标注每个点的观测值编号
gen n = _n
* _n：自动变量，表示第n个观测值
scatter lnw s, mlabel(n)
* mlabel(n)：用变量 n 作为每个点的标签
```

## 五、统计分析

### 5.1 描述统计

```stata
* 目的：看变量 s 的基本统计量
summarize s
* 简写：sum s
* 输出：Obs（样本量）、Mean（均值）、Std.Dev.（标准差）、Min（最小值）、Max（最大值）
```

**输出结果（grilic_small 数据）**：
| 变量 | Obs | Mean | Std.Dev. | Min | Max |
|------|-----|------|----------|-----|-----|
| s | 30 | 13.8 | 2.14 | 11 | 18 |
| expr | 30 | 1.66 | 2.45 | 0 | 10.08 |
| lnw | 30 | 5.79 | 0.37 | 4.87 | 6.36 |

```stata
* 目的：不加变量名，显示所有变量的统计量
sum
```

### 5.2 频数表

```stata
* 目的：看变量 s 的频数分布
tabulate s
* 简写：tab s
* 输出：Freq.（频数）、Percent（百分比）、Cum.（累积百分比）
```

### 5.3 [[01_相关系数|相关系数]]

```stata
* 目的：计算三个变量两两相关系数，带显著性
pwcorr lnw s expr, sig star(.05)
* pwcorr：pairwise correlation（两两相关）
* sig：显示p值（显著性水平）
* star(.05)：给p<0.05的相关系数打星号
```

**输出结果解读**：
- lnw 与 s：相关系数 0.5368*，p=0.0022 → 在1%水平显著正相关
- lnw 与 expr：相关系数 0.2029，p=0.2823 → 不显著（样本量小）
- s 与 expr：相关系数 -0.1132，p=0.5514 → 不显著

## 六、生成新变量

```stata
* 目的：生成教育年限的对数
gen lns = log(s)
* gen：generate 简写
```

```stata
* 目的：生成教育年限的平方项
gen s2 = s^2
```

```stata
* 目的：生成交互项（教育×工龄）
gen exprs = s * expr
```

```stata
* 目的：从工资对数反算工资水平
gen w = exp(lnw)
* 因为 lnw = ln(w)，所以 w = exp(lnw)
```

### [[KP03_虚拟变量|虚拟变量]]（哑变量）

```stata
* 目的：定义"受过高等教育"虚拟变量（s>=16 取1，否则取0）
gen college = (s >= 16)
* 括号内是逻辑表达式：为真取1，为假取0
```

```stata
* 目的：修改变量定义（如把阈值从16改成15）
replace college = (s >= 15)
* replace：直接覆盖原有变量
```

```stata
* 目的：变量重命名
rename colleg college
* 比如刚才打错了变量名
```

## 七、Stata 的计算器功能

```stata
* 目的：计算 ln2
display log(2)
* 输出：.69314718
* 简写：dis
```

```stata
* 目的：计算 √2
dis 2^0.5
* 输出：1.4142136
```

## 八、日志管理

```stata
* 目的：开始记录日志（保存所有输出结果）
log using today
* 生成 today.smcl 文件，在当前路径
* 所有后续操作和输出都会记录在日志中
```

```stata
* 目的：暂时关闭日志（不记录输出）
log off

* 目的：恢复日志记录
log on

* 目的：彻底关闭日志
log close
```

## 小结

1. Stata 的核心工作流：**导入数据 → 审视数据 → 画图看分布 → 统计分析 → 回归**。
2. 命令窗口直接输入命令比菜单操作快得多，要养成用命令的习惯。
3. `help` 命令是最好的老师——任何命令不懂就 `help 命令名`。
4. 日志文件（.smcl）能保存所有输出，写论文时非常有用。

## 答辩常问（带标准答案）

1. **问：`use grilic.dta, clear` 里的 `clear` 是干什么的？不加会怎样？** 答：Stata 同一时刻内存里只放得下一份数据。如果内存里已经有数据，再 `use` 新文件时 Stata 会报错"no; data in memory would be lost"，拒绝覆盖——这是防止你不小心丢掉正在处理的数据。加 `, clear` 表示"确认清空内存、载入新数据"，是切换数据集时的固定搭配。
2. **问：`gen` 和 `replace` 有什么区别？生成虚拟变量为什么可以直接写 `gen college=(s>=16)`？** 答：`gen` 是**创建一个原来不存在的新变量**；`replace` 是**修改已存在变量的观测值**（如阈值从 16 改成 15 时用 `replace college=(s>=15)`）。虚拟变量那行能直接工作，是因为括号里是逻辑表达式：s≥16 为真时 Stata 返回 1、为假返回 0，一行就生成了 0/1 虚拟变量，不需要写 if 判断。
3. **问：`drop if s>=16` 和 `keep if s>=16` 的后果分别是什么？操作时要注意什么？** 答：`drop if s>=16` 是**删掉**教育年限大于等于 16 的观测；`keep if s>=16` 是反过来，**只保留**这些观测、删掉其余。两者都是对数据集的永久性修改，**不可撤销**——一旦回车就没有"撤销键"。稳妥做法是先 `list s if s>=16` 看一眼要删/留的是哪些，确认无误再执行，重要数据先另存备份。
