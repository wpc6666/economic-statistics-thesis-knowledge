# KP01 异方差检验

## 1. 是什么

异方差检验是判断"扰动项方差是否随观测变化"的统计方法。最常用的两种：
- **BP检验（Breusch-Pagan test）**：检验 $e_i^2$ 是否与解释变量系统相关
- **White检验**：BP的升级版，加入平方项和交叉项，捕捉非线性异方差

**直觉类比**：同方差像投篮命中率——不管你站在哪条线，命中率波动都差不多。异方差像预测营业额——大店的营业额波动天然比小店大。检验就是看：把残差平方画出来，它是不是"有的地方高、有的地方低"。

**解决什么问题**：回归完先做检验，确认有没有异方差。如果有，再决定怎么处理（见KP02）。

## 2. 怎么用

### BP检验步骤

1. 先做[[KP02_OLS正交性|OLS]]回归，得到残差 $e_i$
2. 用 $e_i^2$ 对所有解释变量回归（或对拟合值 $\hat y_i$ 回归）
3. 看这个辅助回归的 $R^2$
4. 构造LM统计量：$LM = n \cdot R^2 \sim \chi^2(K-1)$
5. 原假设 $H_0$：同方差（即 $e_i^2$ 与X无关）

### White检验步骤

1. 先做OLS回归
2. 用 $e_i^2$ 对所有解释变量、解释变量的平方项、解释变量的交叉项回归
3. 看辅助回归的 $R^2$
4. White统计量 $= n \cdot R^2 \sim \chi^2(p)$，p为辅助回归参数个数

### 公式

$$\text{BP LM} = n \cdot R^2_{e^2 \sim X} \sim \chi^2(K-1)$$

$$\text{White} = n \cdot R^2_{e^2 \sim X, X^2, X\cdot X'} \sim \chi^2(p)$$

- 原假设 $H_0$：$\sigma_i^2$ 为常数（同方差）
- p值 < 0.05：拒绝同方差，即存在异方差

#### 【三问】为什么要搞 BP/White 这种"对 e² 再回归"的检验？

- **怎么来的（直觉推导）**：如果同方差成立，那残差的平方 $e_i^2$（它是 $\sigma_i^2$ 的样本估计）应该是"乱撒的"——和解释变量 X 没什么关系。反过来，如果异方差存在，$\sigma_i^2$ 会随 X 变大或变小，那 $e_i^2$ 就会和 X 系统相关。所以 Breusch 和 Pagan 想到一个直接的办法：**拿 e² 当被解释变量，再对 X 做一次回归**。如果这次辅助回归的 $R^2$ 显著大于0，说明 e² 不是乱撒的，异方差存在。LM 统计量 $n \cdot R^2$ 在大样本下服从卡方分布——这是拉格朗日乘数检验的标准套路。
- **为什么用它**：解决"OLS 跑完之后，标准误到底可不可信"这个问题。OLS 在异方差下**系数估计仍然无偏**（β̂ 还是对的），但**标准误算错了**——可能高估、可能低估。标准误错了，t 检验、p 值、置信区间全部失灵。所以必须先检验，再决定要不要用[[KP03_稳健标准误|稳健标准误]]或加权最小二乘。
- **知识为什么存在**：经典 OLS 理论（高斯-马尔可夫定理）的成立前提之一就是同方差。但现实数据（收入、消费、营业额、企业规模）几乎都是异方差的——大店的营业额波动天然比小店大。如果没有 BP/White 这种检验，研究者只能靠画残差图"凭感觉"，无法给出客观的 p 值和拒绝规则。BP（1979）和 White（1980）的发明，让异方差诊断从"看图说话"升级为"[[KP02_假设检验|假设检验]]"。

### Stata代码

```stata
* ============================================
* 异方差检验完整流程
* ============================================

* 第一步：打开数据
use mus04data.dta, clear

* 第二步：先做OLS回归
reg food_exp income

* 第三步：BP检验（默认对拟合值回归）
estat hettest
* （等价于：estat hettest, iid）

* 第四步：BP检验——指定对所有解释变量回归
estat hettest income

* 第五步：White检验（最严格，包含平方和交叉项）
estat imtest, white
```

**输出解读（原书mus04data例）**：

```
. estat hettest
Breusch-Pagan / Cook-Weisberg test for heteroskedasticity
         Ho: Constant variance
         Variables: fitted values of food_exp

         chi2(1) = 5.38
         Prob > chi2 = 0.0204
```

- chi2(1)=5.38，p=0.0204<0.05
- 拒绝同方差原假设，即存在异方差

```
. estat imtest, white
White's test for Ho: homoskedasticity
    against Ha: unrestricted heteroskedasticity
    chi2(2) = 6.31
    Prob > chi2 = 0.0427
```

- White检验p=0.0427<0.05，同样拒绝同方差

## 3. 什么时候用

**适用场景**：
- 任何横截面回归做完后
- 数据有明显规模差异（大企业vs小企业、高收入vs低收入）
- 残差图看起来"漏斗形"（一端宽一端窄）

**检验顺序**：
1. 先画残差图（rvfplot）
2. 再做BP检验（简单快速）
3. 再做White检验（更全面）

## 4. 什么时候不能用/易错点

- **p值接近0.05时的决策**：统计显著≠实际重要。即使p=0.04，如果异方差很轻微，稳健标准误和普通标准误差别不大，OLS也能凑合
- **BP检验只检验线性形式**：如果异方差是U型的（中间小两边大），BP可能检验不出来，要用White
- **样本量太大时什么都显著**：n=10000时p<0.001不代表异方差严重，要看实际差异
- **检验后忘记处理**：检验出异方差后必须改标准误或加权，不能装作没看见

## 5. 与相似方法对比表

| 检验方法 | 检验对象 | 优点 | 缺点 | Stata命令 |
|----------|----------|------|------|-----------|
| BP检验 | e²对X的线性回归 | 简单直观，计算快 | 只能检验线性形式 | estat hettest |
| White检验 | e²对X、X²、交叉项 | 能捕捉非线性异方差 | 辅助回归参数多，自由度消耗大 | estat imtest, white |
| 残差图 | 可视化 | 直观，能看出异方差形状 | 主观，不能精确判断 | rvfplot |

## 6. 为什么用这个不用那个

- **为什么先做BP再做White？** BP简单快速，如果BP显著就基本确认异方差；BP不显著但怀疑非线性，再用White。
- **为什么不只看残差图？** 画图是探索性的，不能给出精确的p值和拒绝规则。检验提供客观决策标准。
- **被排除的做法（直接用OLS不检验）会出什么问题？** 如果存在异方差但用普通标准误，标准误会被高估或低估，t[[08_t检验和F检验|检验和]]置信区间都不可靠。

## 7. 完整例子

### 书中原例：food_exp（食品支出 vs 收入）

```stata
use mus04data.dta, clear
reg food_exp income
```

回归结果：$\widehat{food\_exp} = -137.83 + 10.21 \cdot income$

画残差图：
```stata
rvfplot
* （残差e对拟合值yhat画散点图）
```

直观看到：收入高时残差散得更开（漏斗形），说明高收入家庭食品支出的波动更大。

```stata
estat hettest
* chi2(1)=5.38, p=0.0204 < 0.05
* → 存在异方差
```

```stata
estat imtest, white
* chi2(2)=6.31, p=0.0427 < 0.05
* → White检验也确认存在异方差
```

结论：食品支出回归存在异方差。下一步应该用稳健标准误（见KP03）或WLS（见KP02）。

### 小白生活实例：预测餐厅营业额

10家餐厅，规模从小到大：

| 餐厅 | 月营业额（万） | 误差（预测偏差，万） |
|------|---------------|---------------------|
| 小店1 | 5 | 0.3 |
| 小店2 | 8 | 0.5 |
| 中店1 | 20 | 1.2 |
| 中店2 | 35 | 2.0 |
| 大店1 | 80 | 4.5 |
| 大店2 | 120 | 7.0 |

直观：大店误差绝对量天然大。BP检验就是看"误差的平方"是否和"营业额大小"系统相关——小店铺残差仅 0.3~0.5、大店残差达 4.5~7.0，残差随营业额同步放大，呈正相关。

简单计算：把 $e_i^2$ 对规模回归，如果斜率显著>0，就确认异方差。

## 答辩常问（带标准答案）

1. **问：BP 检验和 White 检验有什么区别？答辩时老师追问"你为什么用 White"怎么答？** 答：BP 检验是把残差平方 $e_i^2$ 对解释变量（或拟合值）做**线性**回归，只能检验"方差是否随 X 线性变大/变小"这一种形式；White 检验在辅助回归里加入解释变量的**平方项和交叉项**，能捕捉 U 型（中间方差小、两头大）等非线性异方差，覆盖面更广。代价是 White 的辅助回归参数个数多、消耗自由度。实务中 BP 先做，若不显著但理论怀疑非线性形式，再补 White。
2. **问：检测出异方差之后，原来的 OLS 系数 $\hat\beta$ 是不是就作废了？** 答：不作废。只要严格外生性 $E(\varepsilon|X)=0$ 成立，异方差下 OLS 系数仍然无偏、大样本下一致——系数估计本身没有问题。出问题的是**普通标准误**：它是按同方差公式算的，异方差下会系统性地偏高或偏低，导致 t 值、p 值、置信区间全部失真。所以处理异方差主要是修标准误（稳健标准误）或修估计方式（WLS），不是重算系数。
3. **问：样本量很大（n=1 万）时 BP 检验 p<0.001，是不是说明异方差很严重、必须用 WLS？** 答：不是。大样本下任何轻微的偏离同方差都会在统计上显著，p 值小不等于异方差在经济上重要。正确做法是对比普通标准误和稳健标准误的实际大小：如果两者相差不到 10%~20%，异方差影响有限，报告稳健标准误即可；只有两者差异很大、且能说清方差函数形式时，才值得考虑 WLS/FWLS。

## 8. 速记卡

- 原假设：同方差；p<0.05拒绝=存在异方差
- BP检验：`estat hettest`，简单快速，只检验线性
- White检验：`estat imtest, white`，全面，含平方和交叉项
- 漏斗形残差图 = 异方差的典型视觉信号
- 检验出异方差后，必须改标准误或加权

**口诀**：残差画个图，漏斗就是异方差；BP简单White全，p小拒绝同方差。
