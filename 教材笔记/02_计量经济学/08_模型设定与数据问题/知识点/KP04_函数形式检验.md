# KP04 函数形式检验

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


## 一、是什么

函数形式检验用来判断：我们假设的回归函数形式（线性？对数？二次？）是否正确？如果模型设定的函数形式有误，[[KP02_OLS正交性|OLS]]估计量是不一致的。

**直觉类比**：你以为两个变量是直线关系，实际是曲线关系——硬画一条直线当然拟合不好，但问题不在斜率，在于你选错了函数形状。

## 二、怎么用

### 2.1 RESET 检验（Regression Specification Error Test）

Ramsey (1969) 提出的RESET检验是最常用的函数形式检验。

**步骤**：
1. 先跑原模型 $y = \beta_0 + \beta_1 x + \varepsilon$，得到拟合值 $\hat y$
2. 构造 $\hat y^2, \hat y^3, \hat y^4$ 作为辅助回归量
3. 跑辅助回归：$y = \beta_0 + \beta_1 x + \delta_2 \hat y^2 + \delta_3 \hat y^3 + u$
4. 用 F 检验联合检验 $\delta_2 = \delta_3 = 0$

- 原假设：模型函数形式正确
- 若 F 统计量 > 临界值（p<0.05），拒绝原假设——函数形式有误

**Stata**：
```stata
reg y x          // 先跑原模型
estat ovtest     // Ramsey RESET检验，用拟合值的幂次
```

### 2.2 Box-Cox 变换

Box-Cox 检验比较线性模型 vs 对数模型哪个更好。

$$y^{(\lambda)} = \frac{y^\lambda - 1}{\lambda}$$

- $\lambda = 1$：线性模型
- $\lambda = 0$：对数模型
- 用极大似然法估计 $\lambda$，看它更接近1还是0

### 2.3 对数模型

常见函数形式：
- **线性模型**：$y = \beta_0 + \beta_1 x + \varepsilon$，$\beta_1$ 是绝对变化
- **双对数模型**：$\ln y = \beta_0 + \beta_1 \ln x + \varepsilon$，$\beta_1$ 是弹性
- **半对数模型**：$\ln y = \beta_0 + \beta_1 x + \varepsilon$，$x$ 变化1单位导致 $y$ 变化 $100\beta_1\%$

## 三、什么时候用

- 跑完回归后做诊断，怀疑模型函数形式不对
- 残差图呈现系统性弯曲（不是随机散布在0周围）
- 理论上变量关系可能非线性（如收入与消费可能边际递减）

## 四、什么时候不能用 / 易错点

### RESET 检验的局限
- RESET 只能告诉你"函数形式有误"，**不能告诉你正确的形式是什么**
- 显著不代表一定需要加 $\hat y^2$，可能是遗漏了其他变量
- 不显著也不代表模型一定正确（检验功效有限）

### 常见错误
- 看到RESET显著就盲目加二次项——应该先排查是否遗漏了关键变量
- 对数模型要求 $y > 0$，有0值时不能直接取对数

## 五、对比表：常见函数形式

| 函数形式 | 方程 | $\beta_1$ 含义 | 适用场景 |
|---------|------|---------------|---------|
| 线性 | $y=\beta_0+\beta_1 x$ | x变1单位，y变$\beta_1$绝对量 | 比例关系 |
| 双对数 | $\ln y=\beta_0+\beta_1 \ln x$ | x变1%，y变$\beta_1\%$（弹性） | 价格弹性、收入弹性 |
| 半对数 | $\ln y=\beta_0+\beta_1 x$ | x变1单位，y变$100\beta_1\%$ | 增长率模型 |
| 二次 | $y=\beta_0+\beta_1 x+\beta_2 x^2$ | 有最优值（抛物线） | 边际递减/递增 |

## 六、为什么用这个不用那个

RESET检验是最便宜的函数形式诊断——跑个回归加一条 `estat ovtest` 就知道函数形式有没有问题。它不要求你预先知道正确形式，纯粹是数据驱动的诊断工具。

## 七、完整例子

研究消费函数 $C = \beta_0 + \beta_1 Y + \varepsilon$（消费 vs 收入）。

1. 跑线性回归，得到 $R^2 = 0.98$
2. 画残差图：低收入和高收入处残差为正，中间为负——呈U形弯曲
3. 跑 RESET 检验：F = 8.45, p = 0.002 < 0.05
4. 结论：线性模型函数形式有误
5. 尝试加入收入二次项 $Y^2$：RESET 不再显著，二次项系数显著为负（边际消费倾向递减）

## 答辩常问（带标准答案）

1. **问：RESET 检验是怎么判断"函数形式不对"的？它的原假设是什么？** 答：步骤是：先跑原模型拿到拟合值 $\hat y$，再在辅助回归 $y=\beta_0+\beta_1x+\delta_2\hat y^2+\delta_3\hat y^3+u$ 里，用 F 检验联合检验 $\delta_2=\delta_3=0$。逻辑是：如果真实关系是线性的，拟合值的高次幂就不该对 y 还有解释力；一旦显著，说明原模型的残差里还残留着系统性的曲线形状。**原假设是"函数形式正确"**，p<0.05 才拒绝，即判定形式有误。Stata 命令是 `estat ovtest`。
2. **问：RESET 检验显著，是不是就该往模型里加二次项？** 答：不一定。RESET 只回答"现形式不对"，不回答"正确形式是什么"。显著的可能原因有两类：一是函数形式真的非线性（如消费的边际递减），加 $\hat y^2$ 或 $x^2$ 能解决；二是根本就是**遗漏了某个关键变量**，拟合值的幂次只是把那个变量的效应"代理"了出来。正确顺序是先排查遗漏变量，再考虑换函数形式。
3. **问：回归系数里双对数、半对数、线性三种形式的系数分别怎么读？** 答：线性模型 $\beta_1$ 是绝对量：x 每变 1 单位，y 变 $\beta_1$ 个单位；双对数 $\ln y=\beta_1\ln x$ 中 $\beta_1$ 是**弹性**：x 变 1%，y 变 $\beta_1\%$（常用于价格弹性、生产函数）；半对数 $\ln y=\beta_1 x$ 中 $\beta_1$ 表示 x 每变 1 单位，y 变化 $100\beta_1\%$（常用于教育回报率、增长率模型）。被问"为什么 lnw 对 s 的系数 0.061 解释成 6.1%"，用的就是半对数规则。

## 八、速记卡

- RESET检验 = 函数形式诊断，`estat ovtest`
- 原假设：函数形式正确；p<0.05 = 形式有误
- RESET只告诉你"不对"，不告诉你"怎样才对"
- 双对数=弹性，半对数=增长率，二次=有最优值
- 残差图弯曲是函数形式有误的直观信号
