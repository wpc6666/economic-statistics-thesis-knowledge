# KP01 遗漏变量偏差

## 1. 是什么

遗漏变量偏差是指：真实模型中包含某变量 $x_3$，但回归时漏掉了它，且 $x_3$ 与已包含的解释变量 $x_2$ 相关，导致 $\hat\beta_2$ 有偏且不一致。

**直觉类比**：研究"教育年限→收入"，但漏掉了"能力"。能力强的人既多读了书（$x_2$高），又天生工资高（$y$高）。不控制能力，估出来的"教育回报率"其实混入了"能力回报率"，严重高估。

**解决什么问题**：解释为什么回归系数可能"看起来显著但其实不对"。是因果推断中最重要的偏差来源。

## 2. 怎么用

### 偏差公式

真实模型：
$$y_i = \beta_1 + \beta_2 x_{i2} + \beta_3 x_{i3} + \varepsilon_i$$

误设模型（漏掉 $x_3$）：
$$y_i = \beta_1 + \beta_2 x_{i2} + u_i$$

其中 $u_i = \beta_3 x_{i3} + \varepsilon_i$。

$\hat\beta_2$ 的概率极限：
$$plim(\hat\beta_2) = \beta_2 + \beta_3 \cdot \delta$$

其中 $\delta$ 是 $x_3$ 对 $x_2$ 回归的斜率（即 $x_3 = \alpha + \delta x_2 + \nu$ 中的 $\delta$）。

### 偏差方向判断表

| β₃符号（漏掉变量的真实效应） | x₂与x₃相关方向 | 偏差方向（β̂₂ vs β₂） |
|---------------------------|---------------|---------------------|
| + | 正相关 | 高估（β̂₂ > β₂） |
| + | 负相关 | 低估（β̂₂ < β₂） |
| - | 正相关 | 低估（β̂₂ < β₂） |
| - | 负相关 | 高估（β̂₂ > β₂） |

### Stata代码（演示用）

```stata
* ============================================
* 遗漏变量偏差演示
* ============================================

* 真实模型：lnw = β1 + β2*educ + β3*ability + ε
* 误设模型：lnw = β1 + β2*educ + u（漏掉ability）

use grilic.dta, clear

* 正确模型（控制能力iq）
reg lnw educ iq expr tenure smsa south black
* β_educ ≈ 0.061

* 错误模型（漏掉iq）
reg lnw educ expr tenure smsa south black
* β_educ ≈ 0.103
* 差异=0.042，就是遗漏变量偏差
```

### 计算演示

假设真实关系：
- 教育年限 $x_2$，能力 $x_3$，工资 $y$
- $\beta_2=0.06$（每多受一年教育，工资涨6%）
- $\beta_3=0.01$（能力每高1分，工资涨1%）
- $x_2$ 和 $x_3$ 正相关：能力高的人平均多上2年学，即 $\delta=2$

漏掉 $x_3$ 时：
$$plim(\hat\beta_2) = 0.06 + 0.01\times 2 = 0.08$$

即估计出的"教育回报率"=8%，比真实的6%高估了2个百分点。这2个百分点其实是"能力高的人天生工资高"被错算到了"教育"头上。

## 3. 什么时候用

**适用场景**：
- 解释回归结果"为什么符号不对"
- 判断研究结论是否可信
- 设计实证研究：选择控制变量

**判断步骤**：
1. 找出被漏掉的关键变量 $x_3$
2. 判断 $\beta_3$ 的符号（$x_3$ 对 $y$ 的效应方向）
3. 判断 $x_2$ 与 $x_3$ 的相关方向
4. 推出偏差方向

## 4. 什么时候不能用/易错点

- **只有相关不够，要判断因果方向**：$x_2$ 影响 $x_3$ 还是 $x_3$ 影响 $x_2$？这决定偏差的性质
- **"控制太多"也有问题**：控制了中介变量（受 $x_2$ 影响的变量）反而会低估 $x_2$ 的总效应
- **遗漏变量偏差无法通过增加样本量解决**：$n\to\infty$ 时偏差仍然存在（不一致）
- **不是所有漏掉的变量都有偏**：只有与已包含变量相关的遗漏变量才有偏；与所有x都不相关的遗漏变量不影响 $\hat\beta_2$

## 5. 与相似问题对比表

| 问题类型 | 偏差? | 不一致? | 后果 | 解决方法 |
|----------|-------|---------|------|----------|
| 遗漏变量（与x相关） | 是 | 是 | 系数有偏且n→∞不消失 | 加入该变量或找[[03_工具变量IV|工具变量]] |
| 遗漏变量（与x不相关） | 否 | 否 | 只增大方差 | 无所谓 |
| 加入无关变量 | 否 | 否 | 增大方差，效率损失 | 删掉无关变量 |
| 函数形式错误 | 是 | 是 | 系数偏 | RESET检验、变换形式 |

## 6. 为什么用这个不用那个

- **为什么要加入控制变量？** 为了消除遗漏变量偏差。控制住混淆变量后，$\hat\beta_2$ 才接近真实因果效应。
- **为什么不能无控制变量就做回归？** 因为简单相关不等于因果。
- **被排除的做法（裸回归）会出什么问题？** 如工资-教育裸回归，回报率10.3%；控制能力后降到6.1%。裸回归高估了68%。

## 7. 完整例子

### 书中原例：grilic工资回归

```stata
use grilic.dta, clear

* 裸回归（只看教育）
reg lnw educ
* β_educ = 0.1027

* 控制所有变量
reg lnw educ iq expr tenure smsa south black
* β_educ = 0.0610
```

差异：0.1027 - 0.0610 = 0.0417个百分点。

解读：不控制智商(iq)、工龄、地区等变量时，教育回报率被高估了4.17个百分点。原因：智商高的人既受教育更多，工资也更高，不控制iq就把iq的功劳算到了教育头上。

### 小白生活实例：研究运动对体重的影响

真实模型：体重 = β₁ + β₂×运动 + β₃×肌肉量 + ε
- β₂<0（运动减脂，体重降）
- β₃>0（肌肉重，体重增）
- 运动多的人肌肉量也大（正相关）

漏掉肌肉量时：
$$plim(\hat\beta_2) = \beta_2 + \beta_3 \times \delta$$
- β₂=-0.3（每多运动1小时减0.3斤）
- β₃=+0.5（每多1公斤肌肉重0.5斤）
- δ=2（每多运动1小时多长2公斤肌肉）

$$plim(\hat\beta_2) = -0.3 + 0.5\times 2 = +0.7$$

结果：估计出"运动让人长胖"（β̂=+0.7）！完全错误。原因：运动多的人肌肉重，体重当然高——但这不代表运动本身让人胖，只是没控制肌肉量。

## 答辩常问（带标准答案）

1. **问：是不是只要漏掉一个变量，系数就一定有偏？** 答：不一定。漏掉的变量 $x_3$ 必须同时满足两个条件才会让 $\hat\beta_2$ 有偏：一是它本身对 y 有真实效应（$\beta_3 \neq 0$），二是它与已包含的解释变量 $x_2$ 相关。如果 $x_3$ 对 y 有影响、但与所有已包含 x 都不相关（如研究教育回报时漏掉"左利手还是右利手"），它只增大扰动项方差、不产生偏差。所以口诀是"相关才会偏"。
2. **问：漏掉变量后，系数是被高估还是低估？怎么快速判断方向？** 答：用概率极限公式 $plim(\hat\beta_2)=\beta_2+\beta_3\cdot\delta$，其中 $\delta$ 是 $x_3$ 对 $x_2$ 回归的斜率。判断规则：$\beta_3$ 与 $\delta$ **同号**则高估（偏误为正），**异号**则低估。例：能力（$x_3$）对工资为正（$\beta_3>0$）、能力与教育正相关（$\delta>0$），同号 → 教育回报率被高估，这和"裸回归 10.3% vs 控制能力后 6.1%"的事实一致。
3. **问：遗漏变量偏差能不能靠"把样本量加大"来解决？** 答：不能。这是它与[[02_异方差|异方差]]、[[03_自相关|自相关]]最关键的区别：后两者只是推断问题，加大样本标准误会自己修正；而遗漏变量偏差是**不一致**的——$n\to\infty$ 时 $plim(\hat\beta_2)$ 仍停留在 $\beta_2+\beta_3\delta$，不收敛到真值。解决办法只有识别策略：把可观测的混淆变量显式控制进来、找工具变量、用面板[[06_固定效应FE|固定效应]]消掉不随时间变化的遗漏变量、或利用自然实验。

## 8. 速记卡

- 偏差公式：$plim(\hat\beta_2)=\beta_2+\beta_3\cdot\delta$
- 偏差方向 = β₃符号 × x₂与x₃相关方向
- 遗漏变量偏差 n→∞ 不消失（不一致）
- 只有与x相关的遗漏变量才有偏
- 控制变量的目的：消除混淆

**口诀**：遗漏变量最致命，相关才会偏系数；正正偏正负偏负，方向判断两符号；样本再多也没用，因果识别靠设计。
