# KP03 虚拟变量

## 一、是什么

虚拟变量（Dummy Variable）是取值为 0 或 1 的变量，用来表示定性因素（性别、城乡、政策前后、季节等）对因变量的影响。

**直觉类比**：回归方程像一条直线，虚拟变量就是在这条直线上"插入一个台阶"——台阶上下截距不同，但斜率可以相同也可以不同。

## 二、怎么用

### 2.1 截距虚拟变量（改变截距）

$$y_i = \beta_0 + \beta_1 x_i + \beta_2 D_i + \varepsilon_i$$

其中 $D_i = 1$ 表示某组（如女性），$D_i = 0$ 表示另一组（如男性）。

- 男性：$y = \beta_0 + \beta_1 x + \varepsilon$
- 女性：$y = (\beta_0 + \beta_2) + \beta_1 x + \varepsilon$

$\beta_2$ 就是两组截距之差。

### 2.2 斜率虚拟变量（改变斜率）

$$y_i = \beta_0 + \beta_1 x_i + \beta_2 D_i \cdot x_i + \varepsilon_i$$

$\beta_2$ 表示两组斜率之差。

### 2.3 Stata 实现

```stata
* 方法1：直接生成虚拟变量
gen female = (gender == "女")    // 女性=1，男性=0
reg wage edu female               // 截距虚拟变量

* 方法2：xi: 自动生成
xi: reg wage i.gender             // Stata自动生成I.gender_1

* 方法3：同时改变截距和斜率
gen female_edu = female * edu     // 交互项
reg wage edu female female_edu   // 截距+斜率都不同
```

### 2.4 Chow 检验（结构变动检验）

检验两组回归是否存在显著的结构差异（截距和斜率是否都相同）。

- 原假设：两组回归系数完全相同
- F 统计量 = $\frac{(RSS_p - RSS_1 - RSS_2)/k}{(RSS_1 + RSS_2)/(n_1 + n_2 - 2k)}$
- 若 F > 临界值，拒绝原假设，说明存在结构变动

## 三、什么时候用

- 需要在回归中纳入定性变量（性别、地域、政策时期）
- 需要比较两组回归结果是否有显著差异
- 需要控制时间[[06_固定效应FE|固定效应]]（年度虚拟变量）

## 四、什么时候不能用 / 易错点

### 虚拟变量陷阱
如果有 $n$ 组，只能放 $n-1$ 个虚拟变量，否则会与常数项完全共线（完全[[KP02_多重共线性|多重共线性]]）。

**错误示例**：3个季节放3个虚拟变量——$D_春 + D_夏 + D_秋 = 1$（因为 $D_冬 = 1 - D_春 - D_夏 - D_秋$），与常数项完全共线。

**正确做法**：放 $n-1$ 个虚拟变量，省略一组作为基准组。

### 常见错误
- 把虚拟变量当连续变量解释（$\beta_2$ 不是"每增加一单位"，而是"从0到1的跳变"）
- 忘记省略基准组导致虚拟变量陷阱

## 五、对比表：虚拟变量回归 vs 分组回归

| 方面 | 虚拟变量回归 | 分组回归 |
|------|-------------|---------|
| 模型数量 | 1个 | 2个（每组各跑一个） |
| 统计检验 | 可直接检验组间差异（t/F检验） | 需要手动比较系数 |
| 自由度 | 更多（合并估计） | 较少（每组样本量小） |
| 适用场景 | 组间差异不大、想检验差异 | 组间关系完全不同 |

## 六、为什么用这个不用那个

一个回归搞定组间差异，不用跑两个回归，而且可以直接用 t 检验看 $\beta_2$ 是否显著——p<0.05 就说明两组确实有差异。

## 七、完整例子

研究城乡消费差异：$C = \beta_0 + \beta_1 Y + \beta_2 D + \varepsilon$，$D=1$ 城镇，$D=0$ 农村。

- $\hat\beta_1 = 0.72$：边际消费倾向，城乡相同
- $\hat\beta_2 = 153.9$（显著）：城镇居民自发消费比农村高153.9元
- Chow 检验 F = 15.39 > 临界值，拒绝"城乡消费函数相同"的原假设

## 答辩常问（带标准答案）

1. **问：什么是"虚拟变量陷阱"？怎么避免？** 答：如果定性变量有 n 组，却把 n 个虚拟变量全部放进带常数项的回归，那么 $D_1+D_2+\cdots+D_n=1$ 对所有观测恒成立，这个和就与常数项（全 1 向量）完全共线，$(X'X)$ 不可逆，回归无法估计——这就是虚拟变量陷阱。避免方法：有 n 组只放 **n-1 个**虚拟变量，省略的那一组作为基准组，它的截距被 $\beta_0$ 吸收，每个虚拟变量的系数都解释为"相对基准组的截距差"。Stata 中用 `xi: reg y i.group` 或 `reg y i.group` 会自动处理这个问题。
2. **问：虚拟变量的系数 $\beta_2$ 能不能像普通变量那样解释成"每增加一单位，y 变化多少"？** 答：不能。虚拟变量只有 0 和 1 两个取值，$\beta_2$ 的含义是"从基准组（D=0）跳到 D=1 组时，y 的截距跳变了多少"——本例中即"城镇居民比农村居民自发消费高 153.9 元"。如果模型里还有交互项 $D\cdot x$，交互项的系数才是两组**斜率**之差。把台阶当连续量解释是答辩中最容易被抓的错误。
3. **问：Chow 检验检验的到底是什么？它和单个虚拟变量的 t 检验有什么区别？** 答：Chow 检验的原假设是"两组回归的截距**和**所有斜率全部相同"，即用一个回归拟合两组数据与分别跑两个回归的残差平方和没有显著差异，公式为 $F=\frac{(RSS_p-RSS_1-RSS_2)/k}{(RSS_1+RSS_2)/(n_1+n_2-2k)}$。单个虚拟变量的 t 检验只比较截距差；Chow 检验是对整个结构（截距+斜率）的联合检验，p<0.05 说明两组回归不能共用一条线，存在结构变动。

## 八、速记卡

- 虚拟变量 = 0/1 台阶，截距台阶或斜率台阶
- n组放n-1个虚拟变量，省略一组做基准
- $\beta_2$ 是组间差异，不是"每增加一单位"
- Chow 检验看两组回归是否有结构变动
- Stata: `xi: reg y i.group` 或手动 gen
