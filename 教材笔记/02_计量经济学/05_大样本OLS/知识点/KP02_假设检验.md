## 1. 是什么

假设检验是利用样本数据判断"关于总体参数的某个命题是否成立"的统计方法。计量经济学中最常用的是：
- **t检验**：检验单个系数是否等于某常数
- **F检验**：检验多个系数的联合约束
- **p值**：在原假设成立下，观测到当前或更极端统计量的概率
- **置信区间**：对参数取值范围的区间估计

**直觉类比**：法庭判案。原假设="被告无罪"，我们默认无罪，除非证据（样本数据）足够有力地证明有罪。p值就是"如果被告真的无罪，证据竟如此不利的概率"——这个概率越小，越倾向于拒绝"无罪"。

**解决什么问题**：样本估计值永远带有抽样波动，我们需要判断"估计出这个效应"是真有其事还是纯属巧合。

## 2. 怎么用

### t检验完整流程

1. 设立原假设 $H_0: \beta_k = c$（通常c=0）
2. 计算t统计量：$t = \frac{\hat\beta_k - c}{SE(\hat\beta_k)}$
3. 确定显著性水平 $\alpha$（常用0.05）
4. 查临界值：大样本下用 $z_{1-\alpha/2}=1.96$
5. 判断：$|t|>1.96$ 则拒绝 $H_0$

### 公式

**t统计量**：
$$t_k = \frac{\hat\beta_k - c}{SE(\hat\beta_k)} \xrightarrow{d} N(0,1) \quad (\text{大样本})$$

**p值**：
$$p = P_{H_0}(|T| > |t_{obs}|)$$
- p<0.01：在1%水平显著（***）
- 0.01<p<0.05：在5%水平显著（**）
- 0.05<p<0.10：在10%水平显著（*）
- p>0.10：不显著

**置信区间**：
$$\hat\beta_k \pm 1.96 \times SE(\hat\beta_k) \quad (95\% \text{置信区间})$$

**F统计量（检验m个线性约束）**：
$$F = \frac{(SSR^* - SSR)/m}{SSR/(n-K)} \xrightarrow{d} \chi^2_m/m$$

### Stata代码

```stata
* ============================================
* 假设检验完整流程示例
* ============================================

use grilic.dta, clear

* 第一步：回归
reg lnw s iq expr tenure smsa south black

* 第二步：t检验——每个变量的t值已在输出表里
* 看P>|t|列，p<0.05就显著

* 第三步：检验s的系数是否等于0.1
* H0: β_s = 0.1
test s = 0.1

* 第四步：检验多个变量联合不显著
* H0: β_iq = β_expr = β_tenure = 0
test iq expr tenure

* 第五步：检验系数相等
* H0: β_s = β_iq
test s = iq

* 第六步：置信区间——输出表已自动给出[95% Conf. Interval]
```

### 计算演示

假设回归结果：$\hat\beta_s = 0.061$，$SE(\hat\beta_s) = 0.0068$。

**检验H0: β_s=0**：
- t = 0.061/0.0068 = 8.97
- |t|=8.97 > 1.96，拒绝H0
- p值≈0.000，高度显著

**95%置信区间**：
- 0.061 ± 1.96×0.0068 = 0.061 ± 0.0133
- = [0.0477, 0.0743]
- 区间不跨0，与t检验结论一致

**检验H0: β_s=0.1**：
- t = (0.061-0.1)/0.0068 = -5.74
- |t|=5.74 > 1.96，拒绝H0
- 即教育回报率不是10%

## 3. 什么时候用

**t检验**：
- 检验单个系数是否为0（变量是否显著）
- 检验单个系数是否等于某具体值

**F检验**：
- 多个系数联合为0（整个方程显著性、一组变量是否该保留）
- 多个线性约束同时检验
- 比较嵌套模型（有约束vs无约束）

**置信区间**：
- 想报告效应大小的可能范围，而不只是"显著/不显著"

## 4. 什么时候不能用/易错点

- **p值小≠效应大**：大样本下很小的效应也能显著。要同时看系数大小和经济意义
- **p值大≠没效应**：可能是样本量不够，检验功效不足
- **双侧检验vs单侧检验**：默认Stata做双侧检验。如果理论上效应方向明确，可做单侧检验（p值减半）
- **F检验自由度**：F(m, n-K)，m是约束个数，K是参数个数
- **多重检验问题**：同时检验很多系数，总有几个"碰巧"显著。需要Bonferroni校正等

## 5. 与相似方法对比表

| 方法 | 检验对象 | 统计量分布 | 什么时候用 | Stata命令 |
|------|----------|-----------|-----------|-----------|
| t检验 | 单个系数=常数 | t(n-K)≈N(0,1) | 检验单个变量显著性 | 输出表自动给出 |
| F检验 | 多个系数联合约束 | F(m,n-K)≈χ²(m)/m | 检验一组变量联合显著 | test命令 |
| p值 | 观测到当前统计量的概率 | — | 衡量证据强弱 | 输出表P>\|t\|列 |
| 置信区间 | 参数的可能范围 | — | 报告效应大小的不确定性 | 输出表自动给出 |

## 6. 为什么用这个不用那个

- **为什么用t检验而不是直接看系数大小？** 因为系数大小可能是抽样波动造成的。t检验把系数除以标准误，[[KP11_标准化_ZScore|标准化]]后才能判断"这个效应相对于它的波动够不够大"。
- **为什么多个变量联合显著要用F检验而不是一个个看t？** 因为一个个看t会遇到"多重比较问题"：即使这些变量联合起来没效应，随机波动也会让其中个别变量t值显著。F检验整体把控一类错误概率。
- **被排除的做法（只看R²高不高）会出什么问题？** R²高不告诉我们哪个变量显著。R²=0.9可能是因为整体趋势，不代表每个变量都显著。

## 7. 完整例子

### 书中原例：grilic工资回归

```stata
use grilic.dta, clear
reg lnw s iq expr tenure smsa south black
```

输出：

| lnw | Coef. | Std.Err. | t | P>\|t\| |
|-----|-------|----------|---|---------|
| s | .0610 | .0068 | 8.97 | 0.000 |
| iq | .0031 | .0017 | 1.87 | 0.062 |
| expr | .0387 | .0066 | 5.85 | 0.000 |
| tenure | .0494 | .0082 | 6.02 | 0.000 |
| smsa | .1398 | .0280 | 4.99 | 0.000 |
| south | -.1168 | .0262 | -4.45 | 0.000 |
| black | -.1015 | .0361 | -2.81 | 0.005 |
| _cons | 4.986 | .1391 | 35.84 | 0.000 |

解读：
- s的p=0.000：教育年限在1%水平显著
- iq的p=0.062：智商在5%水平不显著，在10%水平显著
- expr, tenure, smsa, south, black都在1%水平显著
- F(7,750)=118.69，p=0.0000：整个方程高度显著

```stata
* 检验IQ和工龄类变量联合显著
test iq expr tenure
```

如果F统计量对应的p<0.05，拒绝"这三个变量联合不显著"，说明这一组变量整体有解释力。

### 小白生活实例：新药有没有效

假设测试一种减肥药，实验组平均减重5斤（SE=2斤）。
- t = 5/2 = 2.5
- |t|=2.5 > 1.96，在5%水平显著
- p值≈0.012，药确实有效
- 95%置信区间：5 ± 1.96×2 = [1.08, 8.92]斤
- 含义：我们有95%把握，这种药平均能让人减1-9斤

如果另一款药宣称减重10斤但SE=6斤：
- t = 10/6 = 1.67
- |t|=1.67 < 1.96，不显著
- 虽然点估计更大，但因为波动太大，不能确定真有效

## 答辩常问（带标准答案）

1. **问：p 值到底是什么？能不能说"p<0.05 意味着原假设有 5% 的概率成立"？** 答：不能，这是最常见的倒置错误。p 值的正确定义是：在**原假设成立**的前提下，观测到当前统计量或更极端结果的概率——它是"给定无罪，证据如此不利的概率"，不是"给定证据，无罪的概率"。原假设要么真要么假，没有概率可言；p 值小只说明"如果原假设为真，数据不该长这样"，据此拒绝原假设。
2. **问：要检验"教育、智商、工龄三个系数联合为零"，为什么不能分别看三个 t 值是否显著，而要用 F 检验？** 答：因为存在多重比较问题。三个 t 检验各自在 5% 水平控制第一类错误，但联合来看，即使三个系数真的都为零，随机波动也有相当概率让其中至少一个 t 值超过 1.96（检验个数越多，"碰巧显著"越多）。F 检验把"三个系数同时为零"作为一个整体约束来检验，正确控制了联合第一类错误概率，Stata 中对应 `test iq expr tenure`。
3. **问：95% 置信区间和 t 检验是什么关系？报告区间有什么好处？** 答：二者等价：95% 置信区间不跨零，就等价于在 5% 水平拒绝 $H_0:\beta=0$；区间跨零则不显著。报告置信区间比只报"显著/不显著"好在两个方面：一是能直接看出效应大小的可能范围（如 [0.048, 0.074]，而不是干巴巴一个星号）；二是能区分"样本量太小导致的不显著"和"效应本身接近零"——很宽的不显著区间说明检验功效不足，很窄且贴零的区间才说明效应确实接近零。

## 8. 速记卡

- t检验：$t=\hat\beta/SE$，|t|>1.96则5%显著
- p值：p<0.01***, 0.01<p<0.05**, 0.05<p<0.10*, p>0.10不显著
- F检验：多个变量联合约束，用test命令
- 置信区间：$\hat\beta \pm 1.96\times SE$，不跨0则显著
- 显著≠效应大，还要看经济意义

**口诀**：t值系数除标准误，一点九六是门槛；p小拒绝原假设，区间跨零就不显著；多变量联合检验，F统计来把关。
