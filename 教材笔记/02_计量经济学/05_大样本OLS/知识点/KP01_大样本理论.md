# KP01 大样本理论

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


## 1. 是什么

大样本理论研究：当样本量 $n$ 趋于无穷大时，估计量 $\hat\theta_n$ 的行为。核心回答两个问题：
1. **一致性**：$n$ 很大时，$\hat\theta_n$ 是否收敛到真实值 $\theta$？
2. **渐近分布**：$\hat\theta_n$ 围绕 $\theta$ 波动的分布是什么形状？

**直觉类比（掷骰子）**：
- 掷1次骰子，结果可能1-6任何数，完全不可预测。
- 掷100次骰子，算平均值——很可能接近3.5（理论期望），但还可能有小波动。
- 掷100万次骰子，平均值几乎一定就是3.5。这就是大数定律。
- 更神奇的是：掷n次算平均值，把平均值减去3.5再除以标准误，这个"[[KP11_标准化_ZScore|标准化]]的平均值"的分布，无论骰子是不是均匀的，都越来越像标准正态——这就是中心极限定理。

**解决什么问题**：现实数据不满足[[07_正态分布|正态分布]]（工资偏右、疾病计数离散），小样本t检验不精确。大样本理论说：别怕，样本够大时，一切渐近正态，直接用正态近似就行。

## 2. 怎么用

### 三个核心概念

1. **依概率收敛**：$\hat\theta_n \xrightarrow{p} \theta$
   - 含义：n越大，$\hat\theta_n$ 落在 $\theta$ 附近一个小邻域内的概率越接近1
   - 直观：样本量增加，估计值越来越稳定在真值周围

2. **大数定律（LLN）**：$\bar X = \frac{1}{n}\sum_{i=1}^n X_i \xrightarrow{p} E(X_i) = \mu$
   - 条件：独立同分布、$E|X_i|<\infty$
   - 结论：样本均值收敛到总体均值

3. **中心极限定理（CLT）**：$\sqrt{n}\frac{\bar X - \mu}{\sigma} \xrightarrow{d} N(0,1)$
   - 条件：独立同分布、$0<Var(X_i)=\sigma^2<\infty$
   - 结论：标准化样本均值渐近标准正态

### 公式

$$\hat\theta_n \xrightarrow{p} \theta \quad \Longleftrightarrow \quad \lim_{n\to\infty} P(|\hat\theta_n-\theta|>\varepsilon)=0, \forall \varepsilon>0$$

$$\text{LLN:} \quad \bar X_n \xrightarrow{p} \mu$$

$$\text{CLT:} \quad \sqrt{n}\frac{\bar X_n-\mu}{\sigma} \xrightarrow{d} N(0,1)$$

### [[KP02_OLS正交性|OLS]]的大样本性质

在严格外生性 $E(\varepsilon|X)=0$ 和渐近满秩下：

1. **一致性**：$plim(\hat\beta) = \beta$
2. **渐近正态**：$\sqrt{n}(\hat\beta-\beta) \xrightarrow{d} N(0, \sigma^2 Q^{-1})$，其中 $Q=plim(X'X/n)$
3. **渐近有效**：在大样本同类估计量中方差最小

### Stata中的对应

```stata
* 目的：模拟演示大数定律——抛硬币10000次，看正面比例收敛到0.5
* 用Stata的随机数生成
set seed 12345
clear
set obs 10000

* 生成每次抛硬币结果（0或1）
gen toss = runiform() < 0.5

* 计算前n次的累计正面比例
gen cum_pct = sum(toss)/_n

* 看前10、前100、前1000、前10000次的比例
list cum_pct if _n==10
list cum_pct if _n==100
list cum_pct if _n==1000
list cum_pct if _n==10000
```

## 3. 什么时候用

**适用场景**：
- 样本量足够大（通常n>30，实证研究几百上千更稳）
- 扰动项分布未知或明显非正态
- 需要做[[KP02_假设检验|假设检验]]、构造置信区间

**判断标准**：
- n=几十：小样本理论可能更精确（如果正态假定可信）
- n=几百上千：大样本理论几乎一定适用

## 4. 什么时候不能用/易错点

- **样本量太小就用大样本近似**：n=10时CLT根本不成立，渐近正态只是空中楼阁
- **混淆"一致性"和"无偏性"**：无偏≠一致，一致≠无偏。大样本下我们优先保证一致性
- **忘记CLT的条件**：必须独立同分布+有限方差。如果数据有强烈[[03_自相关|自相关]]或重尾分布，CLT结论可能失效
- **把渐近分布当成精确分布**：大样本结论只是n→∞时的极限，n有限时有近似误差

## 5. 与相似方法对比表

| 性质 | 无偏性 | 一致性 | 渐近正态性 |
|------|--------|--------|-----------|
| 定义 | $E(\hat\theta)=\theta$ | $plim(\hat\theta)=\theta$ | $\sqrt{n}(\hat\theta-\theta)\to N(0,V)$ |
| 关注 | 估计量的期望是否对 | n→∞时是否收敛到真值 | 估计量的渐近分布形状 |
| 小样本 | 精确 | 不适用 | 不适用 |
| 大样本 | 仍有意义但弱 | 核心要求 | 统计推断的基础 |
| 哪个更基本 | 小样本概念 | 大样本概念 | 大样本概念 |

## 6. 为什么用这个不用那个

- **为什么不用小样本t检验？** 因为要求扰动项严格正态，现实中很少满足。
- **为什么相信大样本理论？** 因为中心极限定理是数学定理，只要数据满足i.i.d.+有限方差，结论严格成立。
- **被排除的方法（假设正态然后做精确t检验）会出什么问题？** 如果实际扰动项是厚尾分布，小样本t统计量的分布不是t分布，临界值选错，检验结论可能完全错误。

## 7. 完整例子

### 掷骰子模拟（CLT直觉）

掷骰子，点数 $X$ 的总体分布：$P(X=1)=P(X=2)=\cdots=P(X=6)=1/6$。
- 均值 $\mu = 3.5$
- 方差 $\sigma^2 = \frac{1}{6}(2.5^2+1.5^2+0.5^2+0.5^2+1.5^2+2.5^2) = 2.92$
- 标准差 $\sigma \approx 1.71$

**n=1**：样本均值就是单次点数，分布在1-6离散点上，完全不是正态。

**n=10**：样本均值的分布开始集中在3.5附近，形状有点像钟形但还不标准。

**n=100**：标准化变量 $\sqrt{100}(\bar X - 3.5)/1.71$ 的分布几乎就是标准正态。

这就是为什么大样本下我们敢用正态分布做推断——CLT自动帮你把乱七八糟的总体分布"洗"成正态。

### 工资数据实例

工资对数lnw通常近似正态，但工资本身明显右偏（少数人工资极高）。
- 如果直接对工资w做回归，扰动项不正态，小样本t检验不精确
- 对lnw做回归，扰动项近似正态，小样本和大样本结论接近
- 即使n很大不做对数变换，CLT也能保证大样本推断有效

### 小白生活实例：考试平均分

一个班30人，每人考试成绩分布很怪（有人满分有人零分）。
- 算全班平均分：无论成绩分布多怪，平均分本身的抽样分布近似正态（CLT）
- 这就是为什么教育统计里可以用z检验比较两个班平均分——不需要假设成绩正态

## 答辩常问（带标准答案）

1. **问：无偏性和一致性有什么区别？为什么说大样本下一致性是最基本的要求？** 答：无偏性是 $E(\hat\theta)=\theta$，意思是反复抽样时估计量的期望等于真值，是小样本概念；一致性是 $plim(\hat\theta)=\theta$，意思是 n 趋于无穷时估计量依概率收敛到真值，是大样本概念。二者互不蕴含：一个估计量可以有偏但 n 增大后收敛到真值（有偏但一致），也可以无偏但 n 增大时发散（无偏但不一致）。实证研究样本量再大也有限，我们首先要求"样本越大数据越靠谱"，所以一致性是底线要求；无偏性只在小样本、正态假定下才有精确意义。
2. **问：现实数据扰动项明显不正态（如工资右偏），为什么还敢用 t [[08_t检验和F检验|检验和]]正态临界值 1.96？** 答：靠中心极限定理。只要样本独立同分布、方差有限，$\sqrt n(\hat\beta-\beta)$ 的抽样分布就渐近正态，t 统计量渐近服从标准正态。工资本身偏态没关系，CLT 会把"乱七八糟的总体分布"在大样本下"洗成"钟形——这也是为什么实证研究 n 达到几百个时，不管扰动项形状如何，直接用 1.96 做临界值是标准做法。
3. **问：中心极限定理在什么情况下会失效？大样本近似就不可靠了？** 答：两类情况最常见：一是样本不满足独立同分布——强自相关的时间序列、整群抽样的集群数据，观测间不独立，CLT 直接套正态会低估标准误（后面章节的 [[KP03_NeweyWest_HAC|HAC]]、聚类标准误就是补救）；二是方差无限或极重尾（如收入最高 0.1% 的极端值主导样本），平均值本身收敛很慢。所以"n 大就行"是有前提的，前提是数据满足 CLT 的条件。

## 8. 速记卡

- 大样本理论 = n→∞时估计量的极限行为
- 一致性：$plim(\hat\theta)=\theta$（大样本下估计量收敛到真值）
- LLN：样本均值→总体均值（掷骰子掷多了平均就是3.5）
- CLT：标准化样本均值→标准正态（不管原始分布多怪）
- 大样本下t统计量≈标准正态，直接用1.96

**口诀**：大样本，靠极限；大数定律收均值，中心极限正态现；无偏一致两概念，一致更基本是关键。
