# KP01 Logit与Probit

## 一句话直觉

> **人做选择不是"全有或全无"的开关，而是"概率随条件平滑变化"——Logit/Probit就是用S型曲线把解释变量映射到0到1之间的概率。**

---

## 一、为什么需要二值选择模型

### 被解释变量是0或1

例子：
- 是否上大学（是=1，否=0）
- 是否买房（是=1，否=0）
- 是否违约（是=1，否=0）

### 线性概率模型（LPM）的问题

直接用[[KP02_OLS正交性|OLS]]：$y = \beta_0 + \beta_1 x + \varepsilon$

**问题1**：预测概率 $E(y|x) = \beta_0 + \beta_1 x$ 可能 < 0 或 > 1

**问题2**：扰动项必然[[02_异方差|异方差]]（因为 $y$ 只能取0或1）

**问题3**：边际效应 $\beta_1$ 是常数，不现实（x很小和x很大时，x对概率的影响应该不同）

---

## 二、Probit模型

### 模型设定

假设存在潜变量（latent variable）：

$$y^* = \beta_0 + \beta_1 x + \varepsilon, \quad \varepsilon \sim N(0,1)$$

观测规则：

$$y = \begin{cases} 1, & \text{如果 } y^* > 0 \\ 0, & \text{如果 } y^* \leq 0 \end{cases}$$

### 预测概率

$$P(y=1|x) = P(y^* > 0|x) = P(\varepsilon > -(\beta_0 + \beta_1 x)) = \Phi(\beta_0 + \beta_1 x)$$

其中 $\Phi(\cdot)$ 是标准正态累积分布函数（CDF）。

### 直觉

$\beta_0 + \beta_1 x$ 越大 → $\Phi(\cdot)$ 越接近1 → 越可能选择y=1。

---

## 三、Logit模型

### 模型设定

同样假设潜变量，但扰动项服从逻辑分布：

$$y^* = \beta_0 + \beta_1 x + \varepsilon, \quad \varepsilon \sim \text{Logistic}(0, \pi/\sqrt{3})$$

### 预测概率

$$P(y=1|x) = \Lambda(\beta_0 + \beta_1 x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x)}}$$

其中 $\Lambda(\cdot)$ 是逻辑分布CDF。

### 对数几率形式（Logit独有的优势）

$$\ln\left(\frac{P(y=1|x)}{P(y=0|x)}\right) = \beta_0 + \beta_1 x$$

**解读**：x增加1单位，对数几率 $\ln(P/(1-P))$ 增加 $\beta_1$。

**几率比（Odds Ratio）**：$e^{\beta_1}$ 表示x增加1单位，几率变为原来的 $e^{\beta_1}$ 倍。

---

## 四、Logit vs Probit 对比

| 维度 | Logit | Probit |
|------|-------|--------|
| 扰动项分布 | 逻辑分布 | 标准[[07_正态分布|正态分布]] |
| CDF形式 | $\Lambda(z) = 1/(1+e^{-z})$ | $\Phi(z)$ |
| 尾部厚度 | 更厚（极端值影响更大） | 较薄 |
| 系数尺度 | 约为Probit的1.6倍 | 约为Logit的0.6倍 |
| 边际效应 | 几乎相同 | 几乎相同 |
| 预测概率 | 几乎相同 | 几乎相同 |
| 对数几率解释 | 有（几率比） | 无直接解释 |
| 计算复杂度 | 简单 | 稍复杂 |
| 大样本表现 | 几乎一样 | 几乎一样 |

**关键结论**：在大样本下，Logit和Probit的边际效应、预测概率几乎没有差别。选择哪个更多是习惯问题。

---

## 五、边际效应怎么读

### 为什么不能直接读系数

$\beta_1$ 不是边际效应！因为：

$$\frac{\partial P(y=1|x)}{\partial x} = \phi(\beta_0 + \beta_1 x) \cdot \beta_1 \quad \text{（Probit）}$$

边际效应取决于x的取值，不是常数。

### 三种边际效应

1. **平均边际效应（AME）**：对每个观测计算边际效应，然后取平均 → 最常用
2. **代表值处的边际效应（MEM）**：在均值处计算
3. **样本比例处的边际效应**：在 $P(y=1) = \bar{y}$ 处计算

### 生活实例：教育对买房概率的影响

假设Probit估计结果：

$$P(\text{买房}=1|\text{教育}) = \Phi(-2 + 0.3 \times \text{教育})$$

**计算不同教育年限的边际效应**：

| 教育年限 | $\beta_0+\beta_1 x$ | $\phi(\cdot)$ | 边际效应 = $\phi(\cdot) \times 0.3$ |
|----------|---------------------|---------------|-------------------------------------|
| 6年 | -2+1.8 = -0.2 | 0.391 | 0.391×0.3 = 0.117 |
| 12年 | -2+3.6 = 1.6 | 0.110 | 0.110×0.3 = 0.033 |
| 16年 | -2+4.8 = 2.8 | 0.008 | 0.008×0.3 = 0.002 |

**解读**：
- 教育6年的人，多上1年学，买房概率提高约11.7个百分点
- 教育12年的人，多上1年学，买房概率提高约3.3个百分点
- 教育16年的人，多上1年学，买房概率几乎不变（已经很高了）

**直觉**：S型曲线的中间最陡（边际效应最大），两端平缓（边际效应小）。

## 六、Stata 完整代码

```stata
* ===== Probit模型 =====
probit buy education income age

* 输出解读：
* education系数 = 0.3（不是边际效应！）
* income系数 = 0.05

* 计算平均边际效应（推荐）
margins, dydx(education income age)

* 输出解读：
* education: dy/dx = 0.089 → 多上1年学，买房概率平均提高8.9个百分点

* 计算在特定教育年限处的预测概率
margins, at(education=(6 12 16))

* ===== Logit模型 =====
logit buy education income age

* 几率比解读
logit, or  // 输出几率比 exp(β)

* 边际效应
margins, dydx(education income age)

* ===== 拟合优度 =====
estat classify  // 分类准确率
* 或者看伪R²（Pseudo R²）
* 输出中有Pseudo R²，一般0.2-0.4就算不错了
```

## 七、常见误区

| 误区 | 正确理解 |
|------|----------|
| "系数就是边际效应" | 系数不是边际效应！要用 `margins` 计算 |
| "Logit和Probit结果差很多" | 大样本下几乎一样，系数尺度不同而已 |
| "伪R²和OLS的R²一样解释" | 伪R²不能直接解释为"解释了多少变异" |
| "预测概率超过0.5就判为1" | 阈值可以调整，不一定是0.5 |
| "Logit的几率比就是边际效应" | 几率比是乘法关系，不是加法 |

## 答辩常问（带标准答案）

1. **问：被解释变量是 0/1 时，直接用 OLS（线性概率模型 LPM）有什么问题？为什么要换 Logit/Probit？** 答：三个问题。一是 OLS 预测值 $\hat y=\beta_0+\beta_1x$ 可能小于 0 或大于 1，不像个概率；二是 y 只能取 0/1，扰动项必然异方差（方差 $p(1-p)$ 随 x 变化），普通标准误失效；三是 LPM 假设 x 对概率的边际效应是常数，但现实中概率接近 0.5 时 x 的作用最大、接近 0 或 1 时作用很小——Logit/Probit 用 S 型 CDF（逻辑分布或正态分布）把线性指数 $x'\beta$ 压缩到 0~1 之间，天然解决了这三点。
2. **问：Logit/Probit 输出的系数 β₁ 能不能直接读成"x 增加一单位，y=1 的概率变化多少"？** 答：不能，这是最常见的解读错误。系数 β₁ 只是潜变量指数上的斜率，真正的边际效应是 $\partial P(y=1|x)/\partial x = \phi(\beta_0+\beta_1x)\cdot\beta_1$（Probit），它随 x 的取值变化——S 曲线中间最陡、两端平缓（本例中教育 6 年的边际效应 0.117，教育 16 年只剩 0.002）。规范做法是用 `margins, dydx(...)` 算**平均边际效应（AME）**后再报告。
3. **问：Logit 和 Probit 的系数差了近 1.6 倍，是不是说明两个模型结论不一致？** 答：不是。系数尺度不同是因为两个分布的方差设定不同（逻辑分布方差约为标准正态的 $\pi^2/3$ 倍），换算后大样本下**边际效应和预测概率几乎完全相同**。被问"该选哪个"时，标准答案是：二者在实证上结论一致，选择主要看习惯和有没有"几率比"的解释需求（Logit 能直接报 $e^{\beta_1}$，Probit 不行）。
