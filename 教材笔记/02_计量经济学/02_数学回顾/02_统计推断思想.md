# 3.9 统计推断的思想

## 概述

统计推断就是：根据样本数据，推断总体的性质。核心问题是——怎么从部分信息（样本）推知整体（总体）？推断出来的结论有多可靠？

## 一、总体与样本

- **总体（population）**：研究对象全体
- **个体（individual）**：总体中的每个研究对象
- **样本（sample）**：从总体中抽取的部分个体
- **样本容量（sample size）**：样本包含的个体数 n

**理想抽样**：随机样本（random sample）——总体中每个个体被抽中的概率相同，且相互独立（独立同分布，iid）。

## 二、点估计

### 1. 估计量 vs 估计值

- **估计量（estimator）**：统计量 $\hat\theta(X_1, \cdots, X_n)$，是样本数据的函数，是随机变量
- **估计值（estimate）**：给定样本后估计量的具体取值，是一个数字

例：估计总体均值 $\theta = E(X)$，可用：
- 样本均值 $\bar{X} = \frac{1}{n}\sum X_i$
- 第一个观测值 $X_1$
- 中位数
- 最大值/最小值

估计量很多，需要评判标准。

### 2. 无偏性

**偏差**：$Bias(\hat\theta) = E(\hat\theta) - \theta$

**无偏估计量**：$Bias(\hat\theta) = 0$，即 $E(\hat\theta) = \theta$

**直觉**：无偏 = 估计量不会系统性地高估或低估。多次抽样平均下来正好等于真值。

```mermaid
graph TD
    A[估计量好坏标准] --> B[无偏性]
    A --> C[有效性/MSE]
    B --> B1[E(θ̂)=θ<br>不系统偏差]
    C --> C1[MSE越小越好<br>估计量离真值越近]
```

### 3. 均方误差（MSE）

$$MSE(\hat\theta) = E[(\hat\theta - \theta)^2]$$

**MSE 分解**：
$$MSE(\hat\theta) = Var(\hat\theta) + [Bias(\hat\theta)]^2$$

**证明思路**：
$$\hat\theta - \theta = [\hat\theta - E(\hat\theta)] + [E(\hat\theta) - \theta]$$

平方后展开：
- 第一项平方：$Var(\hat\theta)$（方差）
- 交叉项：$2E\{[\hat\theta - E(\hat\theta)][E(\hat\theta) - \theta]\} = 0$（因为 $E(\hat\theta) - \theta$ 是常数，可以提出来，而 $E[\hat\theta - E(\hat\theta)] = 0$）
- 第二项平方：$[Bias(\hat\theta)]^2$（偏差平方）

**意义**：最优估计量不是只追求无偏——如果一个有偏估计量的方差特别小，它的 MSE 可能反而比无偏估计量更小。这就是**偏差-方差权衡（trade-off）**。

## 三、区间估计与[[KP02_假设检验|假设检验]]（预告）

> 本节原书只讲了点估计和 MSE，区间估计和假设检验在后续章节展开。这里先建立概念框架。

### 1. 区间估计

点估计只给一个数，区间估计给一个范围，并告诉我们这个范围包含真值的概率有多高。

例：教育投资回报率的点估计是 9.7%，95% 置信区间是 [8.5%, 10.8%]——意味着如果重复抽样100次，大约95个区间会包含真实的 β。

### 2. 假设检验

**核心逻辑**：先假设原假设 $H_0$ 成立，然后看样本数据在 $H_0$ 下出现的概率有多小。如果概率太小（小于显著性水平 α），就拒绝 $H_0$。

**第I类错误与第II类错误**：

|  | $H_0$ 为真 | $H_0$ 为假 |
|--|-----------|-----------|
| 拒绝 $H_0$ | **第I类错误**（弃真）α | 正确 |
| 不拒绝 $H_0$ | 正确 | **第II类错误**（取伪）β |

- **第I类错误（弃真）**：原假设是对的，但你拒绝了它。概率 = α（显著性水平，通常取5%）。
- **第II类错误（取伪）**：原假设是错的，但你没拒绝它。概率 = β。
- **检验功效** = 1 - β = 正确拒绝错误原假设的概率。

**直觉**：就像法庭审判——
- 第I类错误 = 冤枉好人（被告无罪但被判有罪）
- 第II类错误 = 放走坏人（被告有罪但被判无罪）
- 社会通常宁可放走坏人（第II类），也不愿冤枉好人（第I类）——所以 α 定得很小（5%）。

## 小结

1. 统计推断 = 从样本推总体，核心是估计量的好坏标准。
2. 无偏性：$E(\hat\theta) = \theta$，不系统偏差。
3. MSE 分解：方差 + 偏差平方，说明估计量选择是偏差和方差的权衡。
4. 假设检验有两类错误：弃真（第I类）和取伪（第II类），二者此消彼长。

## 答辩常问（带标准答案）

1. **问：估计量（estimator）和估计值（estimate）是一回事吗？** 答：不是。估计量是样本数据的函数 $\hat\theta(X_1,\dots,X_n)$，比如样本均值 $\bar X$——它是随机变量，换一批样本就变一次；估计值是**某一次具体抽样后**算出来的那个数字（如 $\bar x=13.8$）。答辩时被问"[[KP02_OLS正交性|OLS]] 估计量是随机的吗"，答案是：是估计量（随机），只有跑完一次回归得到的 $\hat\beta$ 数字才是估计值。
2. **问：MSE 分解是什么意思？为什么"最优估计量"不一定是无偏估计量？** 答：$MSE(\hat\theta)=E[(\hat\theta-\theta)^2]=Var(\hat\theta)+[Bias(\hat\theta)]^2$——总误差等于方差加偏差平方。所以评判估计量不能只盯无偏性：如果一个**有偏**估计量的方差特别小，它离真值的平均距离（MSE）反而可能比"无偏但方差大"的估计量更小。这就是偏差-方差权衡，也是岭回归、模型设定中"适度牺牲无偏性换稳定性"的理论依据。
3. **问：假设检验的两类错误是什么？为什么显著性水平 α 通常定 5%？** 答：第I类错误是"弃真"——原假设明明为真却拒绝了，概率为 α；第II类错误是"取伪"——原假设明明为假却没拒绝，概率为 β，检验功效 = 1−β。两者此消彼长，α 定得越小，越不容易拒绝原假设，β 就越大。α 取 5% 沿用了法庭逻辑：宁可放走坏人（第II类），也不愿冤枉好人（第I类）——先假定被告无罪（原假设），证据必须足够硬才能推翻。
