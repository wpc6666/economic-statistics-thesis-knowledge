## 概述

本节回顾计量经济学的概率统计基础：条件概率、常见分布、数字特征（期望、方差、协方差、[[01_相关系数|相关系数]]），以及迭代期望定律和均值独立——这些是理解回归扰动项性质的关键。

## 一、概率与条件概率

### 1. 概率的直观理解

概率 = 大量重复实验下事件发生频率趋向的稳定值。

例：天气预报说明天70%概率下雨 = 如果有100天预报了70%降雨概率，大约70天会下雨。

### 2. 条件概率

$$P(A|B) = \frac{P(AB)}{P(B)}$$

- $P(A|B)$：在 B 发生的条件下 A 发生的概率
- $P(AB)$：A 和 B 同时发生的概率（交集）
- 分母 $P(B)$：条件 B 发生的概率（归一化）

**直觉**：条件概率就是把"世界"缩小到 B 发生的范围内，再看 A 在这个小世界里占多少比例。

### 3. 独立事件

如果 $P(A|B) = P(A)$（B 是否发生不影响 A），则 A、B 相互独立，此时：
$$P(AB) = P(A)P(B)$$

### 4. 全概率公式

如果 $\{B_1, B_2, \cdots, B_n\}$ 两两互斥且必有一个发生，则：
$$P(A) = \sum_{i=1}^n P(B_i) P(A|B_i)$$

**直觉**：把世界分成 n 种情形，每种情形下的条件概率按权重加权平均。

## 二、常见分布

### 1. [[07_正态分布|正态分布]]

$$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left\{-\frac{(x-\mu)^2}{2\sigma^2}\right\}$$

记为 $X \sim N(\mu, \sigma^2)$。[[KP11_标准化_ZScore|标准化]]后 $Z = (X-\mu)/\sigma \sim N(0,1)$。

**Stata 命令**：
```stata
* 目的：计算标准正态小于1.96的概率
display normal(1.96)
* 输出：.9750021（即P(Z<1.96)=0.975）

* 目的：画标准正态密度函数
twoway function y = normalden(x), range(-5 5) xline(0) ytitle(概率密度)
```

### 2. 卡方分布（χ²）

如果 $Z_1, \cdots, Z_k$ 独立同分布 $N(0,1)$，则：
$$\sum_{i=1}^k Z_i^2 \sim \chi^2(k)$$

- 取值为正（平方和）
- 期望 = k，方差 = 2k
- 形状：右偏，k 越大越对称

### 3. t分布

如果 $Z \sim N(0,1)$，$Y \sim \chi^2(k)$，且二者独立，则：
$$\frac{Z}{\sqrt{Y/k}} \sim t(k)$$

- 以原点对称，比正态分布厚尾
- k→∞ 时收敛于标准正态

### 4. F分布

如果 $Y_1 \sim \chi^2(k_1)$，$Y_2 \sim \chi^2(k_2)$，且二者独立，则：
$$\frac{Y_1/k_1}{Y_2/k_2} \sim F(k_1, k_2)$$

- 取值为正，右偏
- $X \sim t(k) \Rightarrow X^2 \sim F(1,k)$

## 三、数字特征

### 1. 期望（均值）

**离散型**：$E(X) = \sum_k x_k p_k$

**连续型**：$E(X) = \int_{-\infty}^{+\infty} x f(x) dx$

**直觉**：对 x 按概率加权平均。

**期望算子性质**：线性性
$$E(X+Y) = E(X) + E(Y), \quad E(kX) = kE(X)$$

### 2. 方差

$$Var(X) = E[(X-E(X))^2] = E(X^2) - [E(X)]^2$$

- 方差越大，波动越大
- 标准差 $\sigma = \sqrt{Var(X)}$

### 3. 协方差

$$Cov(X,Y) = E[(X-E(X))(Y-E(Y))] = E(XY) - E(X)E(Y)$$

- Cov > 0：正相关（X大Y也大）
- Cov < 0：负相关（X大Y反而小）
- Cov = 0：线性不相关（但不一定独立！可能有非线性关系）

### 4. 相关系数

$$\rho = Corr(X,Y) = \frac{Cov(X,Y)}{\sqrt{Var(X)Var(Y)}}$$

- 标准化后的协方差，消除了计量单位影响
- $-1 \le \rho \le 1$

### 5. 条件期望与条件方差

**条件期望**：
$$E(Y|X=x) = \int_{-\infty}^{+\infty} y f(y|x) dy$$

- 是 x 的函数（y 已被积分积掉）
- 直觉：固定 X=x 后，Y 的平均值

**条件方差**：
$$Var(Y|X=x) = \int_{-\infty}^{+\infty} [y - E(Y|x)]^2 f(y|x) dy$$

- 也是 x 的函数

## 四、迭代期望定律

$$E(Y) = E_X[E(Y|x)]$$

**一句话**：无条件期望 = 条件期望的加权平均（权重为 X 的分布）。

**直觉**：想算全班的平均身高，可以先算每个班的平均身高，再按各班人数加权平均。

**离散情形**：
$$E(Y) = \sum_i P(X=x_i) E(Y|x_i)$$

**Stata 验证（grilic 数据）**：
```stata
* 目的：用 rns（南方虚拟变量）验证迭代期望定律
use grilic.dta, clear

* 北方居民的工资对数均值
sum lnw if rns == 0
* 结果：Obs=554, Mean=5.725644

* 南方居民的工资对数均值
sum lnw if rns == 1
* 结果：Obs=204, Mean=5.581083

* 加权平均验证
display 5.725644*(554/758) + 5.581083*(204/758)
* 结果：5.6867384

* 直接算无条件均值
sum lnw
* 结果：Mean=5.686739
* 两者几乎相等 → 验证迭代期望定律
```

## 五、无关性三层次

| 层次 | 定义 | 强度 | 含义 |
|------|------|------|------|
| 相互独立 | $f(x,y) = f_x(x)f_y(y)$ | 最强 | X 和 Y 没有任何关系 |
| 均值独立 | $E(Y|x) = E(Y)$ | 中等 | X 不影响 Y 的均值 |
| 线性不相关 | $Cov(X,Y) = 0$ | 最弱 | X 和 Y 无线性关系（可能有非线性） |

**逻辑链**：相互独立 ⇒ 均值独立 ⇒ 线性不相关；反之不然。

## 小结

1. 条件概率和条件分布是计量经济学的核心概念——回归本质上就是条件期望。
2. 四大分布（正态、χ²、t、F）是后续[[KP02_假设检验|假设检验]]的数学工具。
3. 迭代期望定律 $E(Y) = E[E(Y|X)]$ 是推导 [[KP02_OLS正交性|OLS]] 性质的关键定理。
4. 无关性有三个层次，要注意区分"不相关"和"独立"——不相关只是没有线性关系。

## 答辩常问（带标准答案）

1. **问：什么是迭代期望定律（Law of Iterated Expectations）？为什么说它在回归推导中反复用到？** 答：公式是 $E(Y)=E_X[E(Y|X)]$——无条件期望等于"先按 X 取条件期望、再对 X 的分布取期望"。直觉是算全班平均身高：先算每个班的平均身高，再按各班人数加权平均。它在计量中反复出现：推导 $E(\varepsilon|X)=0$ 为何能推出 $E(\varepsilon)=0$、证明 OLS 的无偏性、分解方差（方差分解 $Var(Y)=E[Var(Y|X)]+Var[E(Y|X)]$）都要靠它。
2. **问：相互独立、均值独立、线性不相关，这三个概念谁强谁弱？能不能举一个"不相关但不独立"的例子？** 答：强度依次递减：**相互独立 ⇒ 均值独立 ⇒ 线性不相关**，反过来都不成立。Cov(X,Y)=0 只表示没有直线关系，不代表没有任何关系：经典例子是 $Y=X^2$（X 对称分布时 Cov=0），X 变化时 Y 明显变化（非线性），但二者线性相关系数为零。所以"相关系数为 0"绝不能说成"X 和 Y 没关系"。
3. **问：为什么说"回归本质上就是条件期望"？** 答：回归方程 $E(Y|X=x)=\beta_0+\beta_1x$ 刻画的就是"给定 X=x 时 Y 的平均水平"——条件期望函数。散点图里每个 x 处那簇 y 值的重心连线，就是回归线。理解了"回归=条件期望"，就理解了为什么 $E(\varepsilon|X)=0$（扰动项条件均值为零）是核心假设：它保证回归线就是 Y 的条件均值线，系数才有"控制其他变量后净效应"的含义。
