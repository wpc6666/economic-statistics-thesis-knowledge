## [[KP01_VAR模型|VAR]]模型核心

- 每个变量都是所有变量滞后值的函数
- 脉冲响应：一个变量的冲击对其他变量的动态影响
- 格兰杰因果：x的滞后值是否有助于预测y（注意：不是真正的因果！）

## Stata 命令速查

```stata
* 设定时间序列
tsset year

* ARMA模型估计
arima y, ar(1) ma(1)

* VAR模型
varsoc y1 y2 y3  // 选择滞后阶数
var y1 y2 y3, lag(1/2)

* 脉冲响应
irf create model1, set(myirf)
irf graph oirf, impulse(y1) response(y2 y3)

* 格兰杰因果检验
vargranger
```

## 本章方法答辩速查

1. **问：拿到一个平稳时间序列，单变量和多变量的完整[[05_ARIMA建模流程|建模流程]]分别是什么？** 答：单变量（ARMA）：先确认序列平稳（这是本章前提，非平稳要下一章先处理）→ 画 ACF/PACF 按口诀识别阶数（AR：PACF 截尾；MA：ACF 截尾）→ `arima y, ar(p) ma(q)` 估计 → Ljung-Box 检验残差必须是白噪声（p>0.05 才算模型设定干净）→ 用 AIC/BIC 在候选模型里选最简洁的。多变量（VAR）：`varsoc` 选滞后阶数 → `var` 估计 → 残差诊断（`varlmar` 无[[03_自相关|自相关]]、`varstable` 平稳）→ 脉冲响应函数（IRF）展示动态影响 → `vargranger` 看格兰杰意义上的预测方向。
2. **问：VAR 做完脉冲响应和格兰杰因果，能不能直接下"货币政策导致产出变化"的结论？** 答：不能。格兰杰因果只是"x 的滞后值在控制 y 自身滞后后还有预测力"，不是经济因果（公鸡打鸣格兰杰引起太阳升起）；脉冲响应的形状还依赖 Cholesky 变量排序——排前面的变量冲击可以影响后面的，反过来不行，排序必须靠经济理论。严谨表述是"利率的冲击在 2 个季度后使产出下降约 0.5%，且利率具有格兰杰意义上的预测力"。
