# KP02 ARMA模型

## 一句话直觉

> **AR是"自己跟自己玩"（用过去的自己预测现在的自己），MA是"跟噪声玩"（用过去的干扰预测现在的自己），ARMA就是两者都玩。**

---

## 一、AR(p) 自回归模型

### 模型设定

$$y_t = \beta_0 + \beta_1 y_{t-1} + \beta_2 y_{t-2} + \dots + \beta_p y_{t-p} + \varepsilon_t$$

其中 $\varepsilon_t$ 是白噪声。

### AR(1) 的直觉

$$y_t = \beta_0 + \beta_1 y_{t-1} + \varepsilon_t$$

- $\beta_1$ 越大，当前值越依赖过去值
- $\beta_1 = 0$：就是白噪声（没有记忆）
- $|\beta_1| < 1$：平稳（冲击随时间衰减）
- $\beta_1 = 1$：单位根（冲击永久持续）

### [[02_平稳性|平稳性]]条件

AR(1)：$|\beta_1| < 1$

AR(p)：特征方程的所有根都在单位圆外

---

## 二、MA(q) 移动平均模型

### 模型设定

$$y_t = \mu + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + \dots + \theta_q \varepsilon_{t-q}$$

### MA(1) 的直觉

$$y_t = \mu + \varepsilon_t + \theta_1 \varepsilon_{t-1}$$

- 当前值 = 当期噪声 + 过去噪声的加权
- MA模型永远平稳（因为是白噪声的有限线性组合）

---

## 三、ARMA(p,q) 混合模型

$$y_t = \beta_0 + \beta_1 y_{t-1} + \dots + \beta_p y_{t-p} + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \dots + \theta_q \varepsilon_{t-q}$$

---

## 四、[[KP02_自协方差与ACF|ACF]]和[[KP04_PACF偏自相关|PACF]]：识别模型阶数

### ACF（[[03_自相关|自相关]]函数）

$$\rho_k = \frac{\text{Cov}(y_t, y_{t-k})}{\text{Var}(y_t)}$$

衡量相隔k期的观测值之间的相关性。

### PACF（[[KP04_PACF偏自相关|偏自相关]]函数）

控制中间各期之后，$y_t$ 与 $y_{t-k}$ 的直接相关性。

### 识别口诀

| 模型 | ACF | PACF |
|------|-----|------|
| AR(p) | 拖尾（逐渐衰减） | p阶截尾（p阶后突然变0） |
| MA(q) | q阶截尾（q阶后突然变0） | 拖尾（逐渐衰减） |
| ARMA(p,q) | 拖尾 | 拖尾 |

### 图形判断

```
AR(1)的ACF：  ●
              ●
              ●
              ●  （指数衰减，拖尾）
              ●
              ●

AR(1)的PACF： ●
              ○○○○○ （1阶截尾）

MA(1)的ACF：  ●
              ●
              ○○○○○ （1阶截尾）

MA(1)的PACF： ●
              ●
              ●
              ●  （指数衰减，拖尾）
```

## 五、生活实例：GDP增长率建模

### 数据

GDP增长率 $y_t$，共100个季度观测。

### 步骤1：画ACF和PACF

```stata
ac y       // 自相关图
pac y      // 偏自相关图
```

### 观察结果

- ACF：1阶后突然不显著 → MA(1)？
- PACF：逐渐衰减 → AR(p)？

### 尝试不同模型

| 模型 | AIC | BIC |
|------|-----|-----|
| AR(1) | -234.5 | -229.3 |
| MA(1) | -236.8 | -231.6 |
| ARMA(1,1) | -240.2 | -232.5 |
| ARMA(2,1) | -240.5 | -230.2 |

**选择**：ARMA(1,1)，因为AIC最小且参数不多。

## 六、Stata 完整代码

```stata
* 设定时间序列
tsset quarter

* ===== 画ACF和PACF =====
ac gdp_growth
pac gdp_growth

* ===== 估计ARMA模型 =====
* AR(1)
arima gdp_growth, ar(1)

* MA(1)
arima gdp_growth, ma(1)

* ARMA(1,1)
arima gdp_growth, ar(1) ma(1)

* 输出解读：
* AR系数 = 0.35
* MA系数 = -0.20
* Log likelihood = -118.5
* AIC = 243.0
* BIC = 250.8

* ===== 预测 =====
* 动态预测（用预测值代替滞后值）
predict y_hat, dynamic

* 静态预测（用真实滞后值）
predict y_hat_static

* ===== 诊断检验 =====
* 残差白噪声检验（Box-Pierch/Ljung-Box）
predict residuals, resid
wntestq residuals
* 如果p>0.05 → 残差是白噪声，模型设定正确
```

## 七、信息准则选阶数

| 准则 | 公式 | 特点 |
|------|------|------|
| AIC | $-2\ln L + 2k$ | 倾向选较复杂模型 |
| BIC | $-2\ln L + k\ln n$ | 更严格，倾向选简洁模型 |

**实践建议**：
- 小样本用AIC
- 大样本用BIC（一致性更好）
- 两者都看，选折中的模型

---

## 八、常见误区

| 误区 | 正确理解 |
|------|----------|
| "ARMA可以用于任何时间序列" | 必须先检验平稳性；非平稳要用[[KP01_ARIMA模型|ARIMA]] |
| "ACF截尾就一定是MA" | 样本ACF有误差，可能是近似截尾 |
| "滞后阶数越多拟合越好" | 过拟合损失预测能力 |
| "ARMA模型不需要经济理论" | 变量选择和阶数选择都依赖理论 |
| "残差自相关说明模型不好" | 是的！残差应该是白噪声 |

## 答辩常问（带标准答案）

1. **问：拿到一个平稳序列，怎么用 ACF 和 PACF 的图形判断它是 AR(p) 还是 MA(q)？** 答：背口诀"AR 截尾在 PACF，MA 截尾在 ACF"：AR(p) 的自相关函数 ACF 呈拖尾（指数/正弦逐渐衰减），偏自相关函数 PACF 在 p 阶后突然截尾（变零）；MA(q) 正好反过来——ACF 在 q 阶后突然截尾，PACF 拖尾。如果两者都拖尾，就是 ARMA(p,q) 混合模型。注意样本图形总有抽样误差，"截尾"指落在置信带内不显著，不是数学上精确为零。
2. **问：AR(1) 模型 $y_t=\beta_0+\beta_1 y_{t-1}+\varepsilon_t$ 的平稳条件是什么？$\beta_1=1$ 会发生什么？** 答：平稳条件是 $|\beta_1|<1$——此时一个冲击随时间按 $\beta_1^k$ 衰减，序列围绕均值波动。如果 $\beta_1=1$，就是单位根过程（随机游走）：冲击永久留在系统里，本期等于上期加噪声，序列没有均值、不会回——这正是下一章 [[KP01_单位根检验ADF|ADF]] 检验要识别的对象，对单位根序列直接做 ARMA 会得到伪回归。
3. **问：选 ARMA 阶数时，为什么不能只看对数似然越大越好，而要用 AIC/BIC？** 答：因为模型每多加一个参数，对数似然必然只增不减，照这个逻辑阶数越多越好，纯粹过拟合。AIC（$-2\ln L+2k$）和 BIC（$-2\ln L+k\ln n$）对参数个数 k 加惩罚项，BIC 的惩罚更重、大样本下倾向于选简洁模型。实践中二者都看、选折中点，并且最后要用 Ljung-Box 检验确认残差是白噪声——残差里还有自相关，说明阶数没选够。
