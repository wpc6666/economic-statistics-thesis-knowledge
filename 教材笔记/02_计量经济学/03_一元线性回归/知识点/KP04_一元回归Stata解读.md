# KP04 一元回归 Stata 输出解读

## 1. 是什么

**读懂 Stata 的 `reg` 命令输出**：把回归输出表里的每个数字都对应到一个概念，知道它是什么意思、怎么读、怎么解释。

**直觉类比**：回归输出表就像体检报告——上面一堆数字，每个数字都有特定含义。你得知道哪个指标看什么病，否则一堆数字摆在眼前等于白看。

**解决什么问题**：跑了 `reg lnw s`，输出一大堆东西，每个数字分别代表什么？哪些重要哪些次要？

## 2. 怎么用

### Stata 输出全貌

```
. reg lnw s

      Source |       SS       df       MS
-------------+------------------------------
       Model |   35.2039946     1   35.2039946
    Residual |   104.082155   756   .137674809
-------------+------------------------------
       Total |   139.28615    757   .183997556

Number of obs =       758
F(1, 756)     =    255.70
Prob > F      =    0.0000
R-squared     =    0.2527
Adj R-squared =    0.2518
Root MSE      =    .37105

------------------------------------------------------------------------------
        lnw |      Coef.   Std. Err.      t    P>|t|     [95% Conf. Interval]
-------------+----------------------------------------------------------------
          s |   .0966245   .0060425    15.99   0.000     .0847624    .1084866
      _cons |   4.391486   .0821136    53.48   0.000     4.230288    4.552684
------------------------------------------------------------------------------
```

### 分区解读

**左上角（方差分析表）**：

| 区域 | 含义 | 本例数值 |
|------|------|----------|
| Model SS | ESS（解释平方和） | 35.204 |
| Residual SS | RSS（残差平方和） | 104.082 |
| Total SS | TSS（总平方和） | 139.286 |
| df | 自由度 | Model df=1, Residual df=756, Total df=757 |

**右上角（模型整体统计量）**：

| 指标 | 含义 | 怎么读 |
|------|------|--------|
| Number of obs | 样本量 | 758个观测值 |
| F(1, 756) | F统计量 | 255.70，检验整个方程是否显著 |
| Prob > F | F检验的p值 | 0.0000 < 0.05，方程整体显著 |
| R-squared | R² | 0.2527，解释了25.3%的变动 |
| Adj R-squared | 调整R² | 0.2518，惩罚变量个数后的R² |
| Root MSE | 回归标准误 | 0.371，残差的标准差 |

**右下角（系数表）——最重要**：

| 列名 | 含义 | 怎么读 |
|------|------|--------|
| Coef. | 回归系数 | s的系数=0.0966，即β̂=0.097 |
| Std. Err. | 系数标准误 | 0.006，系数估计的抽样波动大小 |
| t | t统计量 | Coef./Std.Err. = 0.0966/0.006 = 15.99 |
| P>\|t\| | p值 | 0.000 < 0.05，系数显著不为零 |
| [95% Conf. Interval] | 95%置信区间 | [0.085, 0.108]，真值有95%概率落在此区间 |

### 系数的经济解释

**s（教育年限）的系数 = 0.0966**：
- 因为 y 是 ln(wage)，x 是 schooling
- β ≈ Δlnw/Δs = Δw/w / Δs
- 每多上一年学，工资平均增加 0.0966 ≈ 9.7%

**_cons（常数项）的系数 = 4.391**：
- 教育年限为0时，工资对数的预测值
- exp(4.391) ≈ 80.7（美元/小时之类的）
- 实际意义不大，主要是数学上需要它来保证回归线过均值点

## 3. 什么时候用

- 每次跑完回归都要会读输出
- 写论文报告结果时，知道哪些数字该放进正文

## 4. 什么时候不能用/易错点

- **只看 Coef. 不看 Std.Err. 和 p 值**：系数再大，如果标准误也大、p值不显著，就是没统计证据。
- **把 p 值=0.000 当精确值**：实际是 p < 0.001，Stata 只显示三位小数。
- **混淆统计显著和经济显著**：系数显著只说明"有效果"，效果有多大要看系数本身的大小。
- **看到 R² 高就觉得模型好**：R² 只说明拟合好，不说明因果对。

|--------|---------|-----------------|--------|
| Coef. | 每个x一个系数 | 每个x一个系数 | x增加1单位，y平均变多少 |

## 6. 为什么选这个

reg 是 Stata 最核心的命令，输出格式是固定的——学会读一次，终身受用。

## 7. 完整例子

**书中原例（grilic）**：
```stata
reg lnw s
```

**报告写法**（论文风格）：

> 利用 758 名美国年轻男子的数据，将工资对数（lnw）对教育年限（s）进行 [[KP02_OLS正交性|OLS]] 回归。结果显示，教育年限的系数为 0.097（标准误 0.006），在 1% 水平上显著为正。这意味着每多接受一年教育，工资平均提高约 9.7%。模型的 R² 为 0.253，即教育年限约解释了工资对数变动的 25%。

## 答辩常问（带标准答案）

1. **问：Stata 输出里 p 值显示 0.000，是不是说 p 精确等于零？** 答：不是。Stata 的 p 值只显示三位小数，0.000 的真实含义是 p < 0.001，即原假设（系数为零）在 0.1% 的水平上就被拒绝。写报告时规范表述是"在 1%（或 0.1%）水平上显著"，不能写成"p=0"。
2. **问：系数 p < 0.05 高度显著，能不能说明这个经济效应很重要、值得投入政策资源？** 答：不能。显著性只回答"这个效应在统计上是不是零"，不回答"效应有多大"。两个常被混淆的情形：样本量很大时，一个经济意义很小的系数也能显著（n=10 万时系数 0.001 都显著）；样本量很小时，很大的系数可能因为标准误太大而不显著。判断经济重要性要看 Coef. 的绝对大小乘以实际变化量，再对照成本。
3. **问：回归表里的截距 _cons（本例 4.391）需要认真解释经济含义吗？** 答：一般不需要。截距是"教育年限 s=0 时工资对数的预测值"，但现实中几乎没有人教育年限为 0，这种解释属于把直线外推到数据范围之外，意义有限。截距存在的主要作用是数学上保证样本回归线经过均值点 $(\bar x, \bar y)$，报告时点一句即可，论文篇幅要留给核心解释变量。

## 8. 速记卡

- Coef. = 系数（效应有多大）
- Std.Err. = 标准误（估计有多不准）
- t = Coef./Std.Err.（大于2就显著）
- P>\|t\| = p值（<0.05显著，越小越显著）
- R² = 解释了多少比例的变动
- F = 整个方程是否显著
- 口诀：**"系数看大小，标准误看粗细，t值除以二就是线，p值越小越争气，R方看拟合，F值看整体"**
