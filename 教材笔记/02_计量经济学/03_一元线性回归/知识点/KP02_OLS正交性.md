# KP02 OLS正交性

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


## 1. 是什么

**OLS 正交性**：OLS 估计出来的残差向量 e，与解释变量向量 x、常数向量 l（全1向量）、拟合值向量 ŷ 都正交（内积为零）。

**直觉类比**：就像拼图——OLS 自动把 y 中能被 x 解释的部分全部"抽走"了，剩下的残差里一丁点 x 的信息都不剩。残差和 x 是彻底"垂直"的，互相不包含对方的信息。

**解决什么问题**：为什么 $\sum e_i = 0$？为什么 $\sum x_i e_i = 0$？这些不是巧合，是 OLS 最小化的必然结果。

## 2. 怎么用

### 核心结论

$$\sum_{i=1}^n e_i = 0 \quad \text{（残差和为零）}$$

$$\sum_{i=1}^n x_i e_i = 0 \quad \text{（残差与 X 正交）}$$

$$\sum_{i=1}^n \hat{y}_i e_i = 0 \quad \text{（残差与拟合值正交）}$$

### 为什么 $\sum e_i = 0$？

从 OLS 一阶条件第一个方程直接来的：
$$\sum (y_i - \hat\alpha - \hat\beta x_i) = 0$$

左边就是 $\sum e_i$，所以 $\sum e_i = 0$。

**推论**：因为 $\sum e_i = 0$，两边除以 n：
$$\bar{e} = 0$$
即残差的均值恒为零。

**进一步推论**：因为 $e_i = y_i - \hat{y}_i$，两边求和取均值：
$$0 = \bar{y} - \bar{\hat{y}} \quad \Rightarrow \quad \bar{y} = \bar{\hat{y}}$$
即被解释变量的均值 = 拟合值的均值。

### 为什么 $\sum x_i e_i = 0$？

从 OLS 一阶条件第二个方程直接来的：
$$\sum (y_i - \hat\alpha - \hat\beta x_i) x_i = 0$$
左边就是 $\sum x_i e_i$。

**向量形式**：
$$l'e = 0, \quad x'e = 0$$
其中 l 是全1列向量，x 是解释变量列向量，e 是残差列向量。

### 为什么 $\sum \hat{y}_i e_i = 0$？

因为 $\hat{y}_i = \hat\alpha + \hat\beta x_i$，所以：
$$\sum \hat{y}_i e_i = \hat\alpha \underbrace{\sum e_i}_{=0} + \hat\beta \underbrace{\sum x_i e_i}_{=0} = 0$$

### Stata 验证

```stata
* 目的：验证OLS正交性
use grilic.dta, clear
reg lnw s
* 计算残差
predict e, residual
* 验证1：残差均值是否为0
sum e
* 结果：Mean 应该约等于 0
* 验证2：残差与x的内积
gen xe = s * e
sum xe
* 结果：求和应该约等于 0
```

## 3. 什么时候用

- 推导 OLS 性质时（第5章无偏性证明）
- 推导平方和分解公式时
- 理解为什么 R² 能等于[[01_相关系数|相关系数]]平方

## 4. 什么时候不能用/易错点

- **无常数项回归**：$\sum e_i = 0$ 不再成立！因为没有 α，就没有第一个一阶条件。但 $\sum x_i e_i = 0$ 仍然成立。
- **正交 ≠ 独立**：正交只是线性不相关，残差和 X 正交不代表残差和 X 独立（可能有非线性关系）。
- **混淆残差和扰动项**：$\sum e_i = 0$ 是样本残差的性质；总体扰动项 $\varepsilon_i$ 的性质是 $E(\varepsilon_i | x_i) = 0$，不要搞混。

## 5. 与相似概念对比表

| 概念 | 含义 | 层次 | 说明 |
|------|------|------|------|
| 样本残差和为零 | $\sum e_i = 0$ | 样本层面 | OLS 有常数项时自动成立 |
| 样本残差与X正交 | $\sum x_i e_i = 0$ | 样本层面 | OLS 一阶条件，有/无常数项都成立 |
| 扰动项条件均值为零 | $E(\varepsilon|x) = 0$ | 总体层面 | 外生性假设，需要假设，不是自动成立 |

## 6. 为什么选这个

正交性是 OLS 最小化的数学必然结果——不是额外假设，是推导出来的性质。正因为有这个性质，才能推出平方和分解、R² 等一系列漂亮结论。

## 7. 完整例子

**奶茶店例子验证**：
回归方程 $\hat{y} = 15 + 5x$

| x | y | ŷ = 15+5x | e = y-ŷ | x·e |
|---|---|-----------|---------|-----|
| 1 | 20 | 20 | 0 | 0 |
| 2 | 25 | 25 | 0 | 0 |
| 3 | 30 | 30 | 0 | 0 |
| 4 | 35 | 35 | 0 | 0 |
| 5 | 40 | 40 | 0 | 0 |

完美拟合时每个残差 $e_i=0$，于是每个 $x_i e_i=0$，求和 $\sum x_i e_i=0$ 自然成立（零向量与任何向量都正交）。

**真实数据（grilic）**：残差均值约等于0，残差与 s 的样本协方差约等于0——这不是巧合，是 OLS 的必然。

## 答辩常问（带标准答案）

1. **问：为什么无常数项回归时 $\sum e_i = 0$ 不再成立，而 $\sum x_i e_i = 0$ 仍然成立？** 答：OLS 有两个一阶条件：对截距 $\hat\alpha$ 求偏导给出 $\sum e_i = 0$，对斜率 $\hat\beta$ 求偏导给出 $\sum x_i e_i = 0$。无常数项回归时模型里根本没有 $\hat\alpha$，第一个一阶条件就不存在，所以残差和不再被强制为零；但对 $\hat\beta$ 的一阶条件仍然保留，所以 $\sum x_i e_i = 0$ 照样成立。
2. **问：样本残差满足 $\sum x_i e_i = 0$，是不是就说明扰动项外生、X 与扰动项不相关？** 答：不是，这是两个层次的事情。$\sum x_i e_i = 0$ 是样本残差的代数性质，只要用 OLS 有常数项估计就必然成立，不管数据真实关系对不对；外生性是总体假设 $E(\varepsilon_i | x_i) = 0$，它是我们对数据生成过程的信念，无法由样本正交性自动推出。样本正交永远成立，外生却可能不成立。
3. **问："残差与 X 正交"是不是等于"残差与 X 独立"？** 答：不等于。正交只表示二者线性不相关（样本协方差为零），但残差里仍可能残留 X 的非线性信息——例如真实关系是 U 型而你拟合了直线，残差与 x² 就明显相关。正交是线性层面的性质，独立是分布层面的性质，独立一定正交，正交不一定独立。

## 8. 速记卡

- 两个正交：$\sum e_i = 0$，$\sum x_i e_i = 0$
- 推论：$\bar{y} = \bar{\hat{y}}$（y的均值=拟合值均值）
- 推论：残差也和拟合值正交 $\sum \hat{y}_i e_i = 0$
- 无常数项回归时，$\sum e_i = 0$ 不再成立！
- 口诀：**"OLS 残差有脾气，跟谁都不搭茬——和常数正交，和X正交，和拟合值也正交"**
