## 1. 是什么

Newey-West HAC（Heteroskedasticity and Autocorrelation Consistent）标准误是时间序列回归中最常用的[[KP03_稳健标准误|稳健标准误]]，同时修正[[02_异方差|异方差]]和[[03_自相关|自相关]]两种问题。

**HAC拆解**：
- **H**eteroskedasticity consistent：像White标准误一样，允许异方差
- **A**utocorrelation consistent：同时允许扰动项自相关
- **C**onsistent：大样本下一致估计

**直觉类比**：White标准误只修正"每个观测方差不一样"；Newey-West额外修正"相邻观测不独立"。它把最近L期的信息加权合并，相当于把"L+1个相关观测"当成"1个独立观测"来算标准误。

**解决什么问题**：时间序列回归中，异方差和自相关经常同时存在，需要一个标准误同时修正两者。

## 2. 怎么用

### 滞后阶数选择

经验法则（Newey-West提出）：

$$L \approx n^{1/4}$$

- n=36：$36^{1/4}\approx 2.45$，取L=3
- n=100：$100^{1/4}=3.16$，取L=4
- n=200：$200^{1/4}\approx 3.76$，取L=4

### 公式直觉

Newey-West估计量：

$$\hat V_{NW} = (X'X)^{-1}\hat S(X'X)^{-1}$$

其中 $\hat S$ 是对长期方差 $S=\sum_{s=-\infty}^{\infty} E(x_t x_{t-s}' \varepsilon_t \varepsilon_{t-s})$ 的估计：

$$\hat S = \hat S_0 + \sum_{j=1}^{L}\left(1-\frac{j}{L+1}\right)(\hat S_j + \hat S_j')$$

- $\hat S_0 = \sum_t e_t^2 x_t x_t'$（同期项，和White一样）
- $\hat S_j = \sum_{t=j+1}^n e_t e_{t-j} x_t x_{t-j}'$（j阶滞后项）
- 权重 $(1-j/(L+1))$：越远的滞后权重越小

### Stata代码

```stata
* ============================================
* Newey-West HAC完整流程
* ============================================

use consumption.dta, clear
tsset year

* 第一步：先算滞后阶数 L ≈ n^(1/4)
display 36^(1/4)
* 输出约2.45，取L=3

* 第二步：Newey-West回归
newey c y d yd, lag(3)
* lag(3) = 截断参数L=3

* 第三步：看输出
* Coef.与普通OLS一样
* Std.Err.是HAC修正后的
* t和P>|t|用新的标准误算

* 第四步：联合检验
test d yd
```

**输出解读（原书consumption例）**：

| c | Coef. | NW Std.Err. | t | P>\|t\| |
|---|-------|-------------|---|---------|
| y | .4996 | .0099 | 50.35 | 0.000 |
| d | 645.22 | 139.94 | 4.61 | 0.000 |
| yd | -.1552 | .0138 | -11.27 | 0.000 |
| _cons | 12.89 | 10.17 | 1.27 | 0.214 |

```
. test d yd
(1) d = 0
(2) yd = 0
F(2, 32) = 73.05
Prob > F = 0.0000
```

## 3. 什么时候用

**必用场景**：
- 时间序列回归（几乎一定有自相关）
- 同时怀疑异方差+自相关
- 做结构变动检验、政策效应估计
- 实证论文时间序列部分标配

**滞后阶数选择**：
- 默认用 $n^{1/4}$
- 经济数据通常L=2–5

## 4. 什么时候不能用/易错点

- **滞后阶数设太大**：L太大时估计量方差膨胀，标准误虚高
- **滞后阶数设太小**：修正不够，标准误仍然不准
- **样本量太小时不可靠**：n<30时Newey-West可能严重不准
- **Newey-West不改变系数**：系数还是[[KP02_OLS正交性|OLS]]那一套，只改标准误
- **面板数据不要用newey**：面板要用cluster稳健标准误

## 5. 与相似方法对比表

| 标准误类型 | 修正异方差 | 修正自相关 | 适用数据 | Stata命令 |
|-----------|-----------|-----------|----------|-----------|
| 普通OLS | 否 | 否 | 同方差+无自相关 | reg y x |
| White稳健 | 是 | 否 | 横截面 | reg y x, robust |
| Newey-West HAC | 是 | 是 | 时间序列 | newey y x, lag(L) |
| 聚类稳健 | 是 | 组内相关 | 面板 | reg y x, cluster(id) |

## 6. 为什么用这个不用那个

- **为什么时间序列用Newey-West而不是White？** White只修正异方差，不修正自相关。时间序列几乎一定有自相关，所以必须用Newey-West同时修正。
- **为什么不直接FGLS？** FGLS需要正确设定自相关结构（如AR(1)）。Newey-West不假设任何具体结构，只要n够大就对，更稳健。
- **被排除的做法（普通OLS）会出什么问题？** 同时有自相关+异方差时，普通标准误双重错误，t检验完全不可信。

## 7. 完整例子

### 书中原例：consumption消费函数结构变动检验

数据：1978–2013年中国居民人均消费(c)与人均GDP(y)，n=36。

```stata
use consumption.dta, clear
tsset year

* 生成结构变动虚拟变量
gen d = (year > 1991)
gen yd = y*d

* 第一步：普通OLS
reg c y d yd
* F(2,32)=15.39, p=0.0000

* 第二步：检验异方差
estat imtest, white
* chi2(2)=6.31, p=0.0427 < 0.05 → 有异方差

* 第三步：检验自相关
estat bgodfrey
* chi2(1)=28.109, p=0.0000 → 有自相关

* 第四步：既然两者都有，用HAC
display 36^(1/4)
* = 2.449，取L=3

newey c y d yd, lag(3)

* 第五步：检验结构变动
test d yd
* F(2,32)=73.05, p=0.0000
```

结论：即使同时修正异方差和自相关，仍在1%水平拒绝"无结构变动"，即中国消费函数在1992年确实发生了结构变化。

### 小白生活实例：预测月销量

奶茶店48个月的销量数据，回归"广告投入→销量"。
- 普通OLS：标准误=0.5，t=4.0
- Newey-West（L=3）：标准误=0.8，t=2.5

差异原因：这个月销量和上个月、上上个月、上上个月都相关，Newey-West把这层相关性"折现"后，标准误变大了。结论仍然显著，但不确定性比原来认为的大。

## 答辩常问（带标准答案）

1. **问：HAC 三个字母分别代表什么含义？** 答：Heteroskedasticity consistent（异方差一致——像 White 标准误一样，不假设同方差）、Autocorrelation consistent（自相关一致——同时不假设相邻观测独立）、Consistent（大样本下一致估计，n 越大越接近真实标准误）。合起来就是：不管扰动方差异方差还是自相关，只要样本够大，它给出的标准误都是对的。
2. **问：时间序列回归为什么不能只用 White 稳健标准误（`, robust`）？** 答：White 只修正了异方差这一个问题。时间序列数据中相邻期的扰动项天然相关（本月销量的误差会影响下月），观测不独立，普通的"每个观测独立贡献方差"的标准误公式仍然系统性地错。Newey-West 在方差估计中把最近 L 阶的自协方差也加权加进来（越远的滞后权重越小，权重为 $1-j/(L+1)$），相当于把"L+1 个相关观测折合成约 1 个有效观测"来算标准误，这才把自相关修正掉。
3. **问：既然 HAC 这么通用，面板数据为什么不直接用 `newey`？** 答：因为两种数据的相关结构不一样。面板数据的相关性是**同一公司（个体）跨时间**的组内相关，时间方向上的观测数 T 通常很小（五到十年），`newey` 那种"按时间排序、算相邻期自协方差"的做法用不上；正确工具是聚类稳健标准误 `reg y x, cluster(id)`，它把每个个体当成一个聚类，允许同一聚类内任意形式的相关。

## 8. 速记卡

- HAC = Heteroskedasticity and Autocorrelation Consistent
- 同时修正异方差+自相关
- 滞后阶数 L ≈ n^{1/4}
- Stata：`newey y x, lag(L)`
- 系数不变，只改标准误
- 时间序列回归标配

**口诀**：HAC两修方差自相关，滞后阶数n开四；newey命令lag(L)，时间序列必备它。
