# KP01 相似性度量

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 直觉：聚类的第一步是回答"两个样品有多像"。像不像用距离衡量——距离近就像，距离远就不像。但选哪种距离大有讲究。

## 1. 是什么

### 定义
- **样品间距离**：d(i,j) 度量两个样品在 p 维空间中的远近。
- **变量间相似系数**：r_ij 度量两个变量的相似程度。

### 直觉类比
给奶茶店分组，先得定义"两家店像不像"。是按距离（客单价差多少）还是按趋势（口碑和销量是否同涨同跌）？这就是选度量的问题。

### 解决什么问题
- [[04_聚类分析|聚类分析]]的前置步骤。
- 不同度量会导致完全不同的聚类结果。

## 2. 怎么用

### 核心公式

**明氏距离：**
$$d_q(x,y) = \left[\sum_{k=1}^{p}|x_k-y_k|^q\right]^{1/q}$$
- q=1：曼哈顿距离（L₁）
- q=2：欧氏距离（L₂）
- q→∞：切比雪夫距离

**马氏距离：**
$$d_M^2(x,y) = (x-y)'\Sigma^{-1}(x-y)$$

**兰氏距离（适合正数变量）：**
$$d_{LW}(x,y) = \frac{1}{p}\sum_{k=1}^{p}\frac{|x_k-y_k|}{x_k+y_k}$$

**夹角余弦：**
$$\cos\alpha = \frac{x'y}{|x||y|}$$

**皮尔逊[[01_相关系数|相关系数]]：**
$$r_{xy} = \frac{\sum(x_k-\bar{x})(y_k-\bar{y})}{\sqrt{\sum(x_k-\bar{x})^2\sum(y_k-\bar{y})^2}}$$

### R 代码

```r
# 目的：计算各种距离并做层次聚类
# (1) 数据标准化（关键！量纲不同时必须做）
df_scaled <- scale(df)  # 每列 (x-mean)/sd

# (2) 计算距离矩阵
# dist(x, method=) 可选 "euclidean", "manhattan", "minkowski"
d_euc <- dist(df_scaled, method = "euclidean")
d_man <- dist(df_scaled, method = "manhattan")

# (3) 计算变量间相关系数矩阵
cor_mat <- cor(df_scaled)  # 变量间相似系数

# (4) 聚类（见 KP02）
hc <- hclust(d_euc, method = "ward.D2")
plot(hc)
```

### 计算演示
两个样品：A=(1,2), B=(4,6)。
- 曼哈顿距离 = |1-4|+|2-6| = 3+4 = 7
- 欧氏距离 = √(9+16) = 5
- 切比雪夫距离 = max(3,4) = 4

## 3. 什么时候用

### 适用场景
- 所有聚类分析的第一步。
- 变量间相关结构分析。

### 数据条件
- 量纲不同先[[KP11_标准化_ZScore|标准化]]。
- 变量全为正时可选兰氏距离。

### 前提假设
- 样品独立。

## 4. 什么时候不能用 / 易错点

- **量纲不同不标准化**：大方差变量主导距离。
- **聚类中慎用马氏距离**：类结构未知，用全部样本算的 Σ 不合理。
- **相关系数只刻画线性关系**：r=0 不代表独立。

## 5. 与相似方法对比表

| 度量 | 类型 | 公式特点 | 适用变量 | 优缺点 |
|------|------|----------|----------|--------|
| 欧氏距离 | 样品距离 | q=2 | 连续变量 | 最常用，量纲敏感 |
| 曼哈顿距离 | 样品距离 | q=1 | 连续变量 | 对异常值稳健 |
| 切比雪夫距离 | 样品距离 | q→∞ | 连续变量 | 只看最大维差 |
| 马氏距离 | 样品距离 | 乘 Σ⁻¹ | 连续变量 | 考虑相关，小样本不稳 |
| 兰氏距离 | 样品距离 | 除以和 | 正数变量 | 适合比例数据 |
| 夹角余弦 | 变量相似 | 方向相似 | 任意 | 忽略绝对值 |
| 相关系数 | 变量相似 | 标准化后余弦 | 连续变量 | 线性相关度量 |

## 6. 为什么用这个不用那个

- **量纲相同、近似独立** → 欧氏距离。
- **量纲不同** → 先标准化再欧氏距离。
- **变量有强相关** → 马氏距离（但聚类中少用）。
- **变量间看相似性** → 相关系数或夹角余弦。

## 7. 完整例子

### 书中原例（3-1节）
5 个地区、3 个指标，先标准化再用欧氏距离做系统聚类。

### 小白生活实例
3 家奶茶店，2 个指标（甜度 0-10, 价格 元）：
- A=(8, 15), B=(6, 12), C=(9, 18)

不标准化：
- d(A,B) = √(4+9) = 3.61
- d(A,C) = √(1+9) = 3.16

标准化（甜度 sd=1.5，价格 sd=3）：
- A*=(0.67, 0)
- B*=(-0.67, -1)
- C*=(1.33, 1)
- d*(A,B) = √(1.34²+1²) = 1.67
- d*(A,C) = √(0.66²+1²) = 1.20

结论：标准化后关系不变，但数值更合理。

## 答辩常问（带标准答案）

1. **问：聚类前为什么必须标准化？不标准化会怎样？** 答：变量量纲不同时（如身高 cm 方差=29、体重 kg 方差=9），大方差变量完全主导欧氏距离，聚类结果只反映体重差异，身高被忽略。标准化后各变量方差=1，距离公平。R 中先 scale(df) 再 dist()。
2. **问：为什么聚类中少用马氏距离，而[[05_判别分析|判别分析]]中常用？** 答：马氏距离需要 Σ⁻¹。判别分析中类别已知，用各类的协差阵（或合并协差阵）合理；聚类分析中类结构未知，用全部样本算的 Σ 把不同类混在一起，不代表任何一类的离散模式，算出的距离反而扭曲。
3. **问：相关系数和夹角余弦有什么区别？什么时候用哪个？** 答：夹角余弦 cosα=x'y/(||x||||y||) 只看方向相似性，忽略绝对值大小；相关系数 r 是去均值后的夹角余弦，看的是"同涨同跌的趋势"。比较变量间关系用相关系数，比较样品轮廓形状（忽略大小）用夹角余弦。

## 8. 速记卡

- 样品间距离：明氏家族（欧氏最常用）。
- 变量间相似：相关系数。
- 量纲不同先标准化。
- 聚类中少用马氏距离。
- **一句话口诀**：先标准化，再量距离，距离近就像，距离远就分。
