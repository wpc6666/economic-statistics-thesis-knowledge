# KP03 K-means 聚类

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 直觉：先猜 K 个中心，把每个点划给最近中心；再把中心挪到组内均值处；重复直到稳定。像磁铁吸铁屑——磁铁位置一变，铁屑重新分组。

## 1. 是什么

### 定义
预先指定 K 个类，通过迭代把样品分配到最近类中心，并更新中心，直到收敛。

### 直觉类比
在城市里选 K 个商圈中心。开始随便猜 K 个点，让每家店归到最近商圈；然后把商圈中心挪到所有店的几何中心；再重新分配；重复。

### 解决什么问题
- 大样本快速聚类。
- 当系统聚类太慢时的替代方案。

## 2. 怎么用

### 完整步骤
1. 预先指定 K。
2. 随机选 K 个初始中心。
3. 每个样品归到最近中心。
4. 更新每个类的中心为类内均值。
5. 重复 3-4，直到中心不再变化。

### 核心公式

**分配步：**
$$c(i) = \arg\min_k \|x_i - \mu_k\|^2$$

**更新步：**
$$\mu_k = \frac{1}{|C_k|}\sum_{i \in C_k} x_i$$

**目标函数：**
$$J = \sum_{k=1}^{K}\sum_{i \in C_k}\|x_i - \mu_k\|^2$$

#### 【三问】为什么 K-means 要"分配—更新"反复迭代？它到底在优化什么？

- **怎么来的（直觉推导）**：目标函数 $J$ 是"所有点到它所属类中心的距离平方和"——越小说明类内越紧凑。问题：如果中心 $\mu_k$ 固定，最优分配就是把每个点划给最近的中心（分配步）；如果分配 $c(i)$ 固定，最优中心就是类内均值（更新步，因为 $\sum (x_i - \mu)^2$ 对 $\mu$ 求导得 $\mu = \bar x$）。这是一个"两头都能解，但合起来是个难题"的经典结构。Lloyd（1957）提出的算法就是：**先固定一头解另一头，交替迭代**——这叫坐标下降法。每一步 $J$ 都不会增加，所以最终一定收敛到某个局部最优解（但不一定是全局最优，这就是为什么要多次随机初值 nstart=25）。
- **为什么用它**：解决"大样本快速无监督分组"的问题。系统聚类（层次聚类）要算所有点两两距离，复杂度 $O(n^2)$，n=10000 就跑不动了。K-means 每轮只需 O(nK)，n=10万、K=10 也能秒出。在没有标签的情况下（客户分群、图像压缩、异常检测），K-means 是工业界使用最广的聚类算法。
- **知识为什么存在**：1957 年 Bell 实验室的 Lloyd 在研究脉冲编码调制（PCM，早期语音压缩）时提出这个算法。1967 年 MacQueen 正式命名 K-means。它的威力在于**简单、快速、可扩展**——今天的推荐系统用户分群、图像 K-means 颜色压缩、特征学习初始化，都是它的后代。它也催生了"EM 算法""GMM 聚类""向量量化"等一大类无监督学习方法。

### R 代码

```r
# 目的：K-means 聚类
# (1) 标准化
df_scaled <- scale(df)

# (2) 碎石图选 K
# 对 k=1..10 分别做 kmeans，看组内平方和下降幅度
wss <- numeric(10)
for (k in 1:10) {
  km <- kmeans(df_scaled, centers = k, nstart = 25)
  wss[k] <- km$tot.withinss
}
plot(1:10, wss, type = "b",
     xlab = "类别数 K", ylab = "组内平方和")
# 找"肘部"位置，即下降突然变缓的点

# (3) 正式 K-means
# centers=K 类别数, nstart=25 随机初值次数（避免局部最优）
km_result <- kmeans(df_scaled, centers = 3, nstart = 25)
print(km_result$size)     # 各类样品数
print(km_result$centers)  # 各类中心（标准化空间）

# (4) 轮廓系数评估
# install.packages("cluster")
library(cluster)
d <- dist(df_scaled)
sil <- silhouette(km_result$cluster, d)
plot(sil)
# 平均轮廓系数 > 0.5 聚类效果较好
```

### 计算演示
4 个点 (1,1),(1,2),(8,8),(9,9)，K=2。
- 初始中心 μ₁=(1,1), μ₂=(8,8)
- 分配：(1,1)→C₁, (1,2)→C₁, (8,8)→C₂, (9,9)→C₂
- 更新：μ₁=(1,1.5), μ₂=(8.5,8.5)
- 再分配：所有点不变，收敛。
- 结果：C₁={(1,1),(1,2)}, C₂={(8,8),(9,9)}。

## 3. 什么时候用

### 适用场景
- n 大（>1000）。
- 类近似球形。
- 需要快速聚类结果。

### 数据条件
- 连续变量。
- 量纲不同先[[KP11_标准化_ZScore|标准化]]。

### 前提假设
- 类近似球形、大小相近。
- 预先能估计 K。

## 4. 什么时候不能用 / 易错点

- **K 必须预先指定**：不知道分几类时先用系统聚类探索。
- **对初值敏感**：用 nstart=25 多次随机起始取最优。
- **只能发现球形类**：月牙形、环形类分不出来。
- **对异常值敏感**：一个离群点会拉偏中心。
- **类大小差异大时表现差**。

## 5. 与系统聚类对比表

| 维度 | 系统聚类 | K-means |
|------|----------|---------|
| 是否预设 K | 否 | 是 |
| 计算复杂度 | O(n²) | O(nK 迭代次数) |
| 大样本适用 | 慢 | 快 |
| 结果是否唯一 | 是 | 依赖初值 |
| 树状图 | 有 | 无 |
| 类形状 | 任意 | 球形 |
| 小样本推荐 | 是 | 一般 |
| 大样本推荐 | 否 | 是 |

## 6. 为什么用这个不用那个

- **n 小、要过程** → 系统聚类。
- **n 大、只要结果** → K-means。
- **类是球形** → K-means。
- **类形状不规则** → 系统聚类（类平均法）。

## 7. 完整例子

### 书中原例（3.5节）
2016 年各省消费支出数据，K-means 分 3 类：
- 第1类：北京、上海（高消费）
- 第2类：天津、浙江、广东等（中高）
- 第3类：其余省区（中等）

### 小白生活实例
100 家奶茶店，K-means 分 3 类：
- 碎石图：K=3 时肘部明显。
- C₁ 高端：客单价 30+，口碑 9+
- C₂ 社区：客单价 15-25，口碑 7-8
- C₃ 学生：客单价 <15，口碑 7
- 轮廓系数 0.6，聚类效果良好。

## 答辩常问（带标准答案）

1. **问：K-means 为什么要用 nstart=25 多次随机初始中心？** 答：K-means 是坐标下降法，每次迭代目标函数 J 不增，但可能收敛到局部最优而非全局最优。不同初始中心会收敛到不同局部解。nstart=25 表示随机选 25 组初始中心各跑一遍，取 J 最小的那个结果，显著降低落入坏局部最优的概率。
2. **问：K 值怎么选？肘部法则怎么用？** 答：对 k=1..10 分别跑 K-means，画组内平方和 WSS 随 k 变化的碎石图，找下降突然变缓的"肘部"位置。辅助判断：轮廓系数>0.5 聚类效果较好，>0.7 很好。肘部处的 k 就是推荐类别数。
3. **问：K-means 和系统聚类怎么选？各自适用什么场景？** 答：n>1000 且类近似球形→K-means（快，O(nK)）；n<200 且想看完整分类过程→系统聚类（O(n²) 距离矩阵，结果唯一有树状图）。K-means 需预设 K 且对初值敏感，系统聚类不需预设 K 但 n 大时慢。

## 8. 速记卡

- 步骤：定 K → 随机中心 → 分配 → 更新 → 收敛。
- K 怎么选：碎石图肘部 + 轮廓系数。
- nstart=25 避免局部最优。
- 适合大样本、球形类。
- R: kmeans(df, centers=K, nstart=25)。
- **一句话口诀**：先猜 K 个中心，店归最近中心，中心挪到组均值，重复到不动。
