# KP02 系统聚类法

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 直觉：把奶茶店按口味自动分组。一开始每家店自成一类，然后把最像的两家合并，越合越大，最后变成一棵"家谱树"（树状图）。

## 1. 是什么

### 定义
系统聚类法（hierarchical clustering）：一开始每个样品自成一类，然后逐步合并距离最近的两类，直到所有样品归为一类。

### 直觉类比
像家谱树：最开始是一个个独立的人，然后亲兄弟合并成一家，堂兄弟合并成一房，最后全族合一。树状图的横轴是样品，纵轴是合并高度。

### 解决什么问题
- 无预先类别数，自动探索数据的分组结构。
- 树状图直观展示"谁和谁像、在哪一层像"。

## 2. 怎么用

### 完整步骤
1. 数据[[KP11_标准化_ZScore|标准化]]。
2. 计算样品间距离矩阵 D。
3. 每个样品自成一类。
4. 找 D 中最小距离，合并两类。
5. 按所选方法重新计算新类与其他类的距离。
6. 重复 4-5，直到所有样品成一类。
7. 画树状图，在合适高度截断得到分类。

### 五种方法对比

| 方法 | 类间距离定义 | 递推公式 | 特点 |
|------|-------------|----------|------|
| 最短距离法 | min{d(i,j)} | D_new = min(D_Gk, D_Hk) | 链式效应 |
| 最长距离法 | max{d(i,j)} | D_new = max(D_Gk, D_Hk) | 避免链式 |
| 重心法 | 两类重心距离 | 加权重心距离 | 有物理意义 |
| 类平均法 | 所有样品对距离平均 | 加权平均 | 常用 |
| Ward 法 | 离差平方和增量 | 类内 SSE 增量 | 类内紧凑 |

### R 代码

```r
# 目的：系统聚类并画树状图
# (1) 数据标准化
df_scaled <- scale(df)

# (2) 计算欧氏距离矩阵
d <- dist(df_scaled, method = "euclidean")

# (3) 系统聚类
# hclust(d, method=) 可选：
# "single" 最短距离法
# "complete" 最长距离法
# "average" 类平均法
# "centroid" 重心法
# "ward.D2" Ward 法（推荐）
hc <- hclust(d, method = "ward.D2")

# (4) 画树状图
plot(hc, hang = -1, main = "Ward 法系统聚类树状图")

# (5) 截取 K 类
# cutree(hc, k=) 返回每个样品所属类
cluster_result <- cutree(hc, k = 3)
print(table(cluster_result))  # 各类样品数

# (6) 在树状图上画分类框
rect.hclust(hc, k = 3, border = "red")
```

### 计算演示（最短距离法）
4 个样品距离矩阵：

| | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 1 | 0 | 1.5 | 3.2 | 4.1 |
| 2 | 1.5 | 0 | 2.8 | 3.5 |
| 3 | 3.2 | 2.8 | 0 | 1.2 |
| 4 | 4.1 | 3.5 | 1.2 | 0 |

- 第1步：最小距离 = d(3,4)=1.2，合并 {3,4}
- 新类 {3,4} 与 {1} 的最短距离 = min(3.2,4.1)=3.2
- 新类 {3,4} 与 {2} 的最短距离 = min(2.8,3.5)=2.8
- 第2步：最小距离 = d(1,2)=1.5，合并 {1,2}
- 第3步：合并 {1,2} 和 {3,4}，距离 = min(3.2, 2.8) = 2.8
- 树状图：在高度 1.2 分 {3,4}，在 1.5 分 {1,2}，在 2.8 分两大类。

## 3. 什么时候用

### 适用场景
- 样品数 n 较小（< 200）。
- 想看完整分类过程。
- 需要确定分类数。

### 数据条件
- 量纲不同先标准化。
- n 不太大（n>1000 时计算量大）。

### 前提假设
- 距离度量合理。

## 4. 什么时候不能用 / 易错点

- **n 很大时慢**：O(n²) 距离矩阵，n>1000 建议 K-means。
- **树状图"逆转"**：重心法可能出现合并高度递减，需注意。
- **截断高度主观**：建议结合统计量（半偏 R²、伪 F）确定 K。
- **标准化问题**：不标准化会被大方差变量主导。

## 5. 与相似方法对比表

| 方法 | 类间距离 | 优点 | 缺点 | 适用 |
|------|----------|------|------|------|
| 最短距离 | 最近点 | 简单 | 链式效应 | 连通类 |
| 最长距离 | 最远点 | 紧凑 | 受极值影响 | 球形类 |
| 重心法 | 重心 | 物理意义 | 距离逆转 | — |
| 类平均法 | 平均距离 | 利用信息多 | 计算量大 | 通用 |
| Ward 法 | SSE 增量 | 类内紧凑 | 倾向小类 | 球形紧凑类 |

## 6. 为什么用这个不用那个

- **类是球形紧凑的** → Ward 法。
- **类形状不规则** → 类平均法。
- **防止链式效应** → 最长距离法。
- **n 很大** → K-means。

## 7. 完整例子

### 书中原例（3.3节）
2016 年全国 31 个省区城镇居民人均消费支出，8 个指标。
- 标准化后用 Ward 法聚类。
- 树状图显示分 2 类时：北京上海为一类，其余为一类。
- 分 3 类时：再分离出天津、浙江、广东等。

### 小白生活实例
10 家奶茶店，3 个指标（甜度、价格、口碑）。
- 标准化后 Ward 法聚类。
- 树状图在高度 5 处截断，得到 3 类：
  - 第1类（高端）：A、E、H（客单价高、口碑好）
  - 第2类（社区）：B、D、G、J（中等价位）
  - 第3类（学生）：C、F、I（低价、甜度高）

## 答辩常问（带标准答案）

1. **问：Ward 离差平方和法为什么最常用？它的原理是什么？** 答：每次合并使类内离差平方和（SSE）增量最小的两类，倾向于产生类内紧凑、大小相近的球形类，和 K-means 的目标函数一致，结果容易解释。R 中用 hclust(d, method="ward.D2")。缺点是倾向产生小类，且要求基于欧氏距离。
2. **问：最短距离法为什么会有"链式效应"？怎么避免？** 答：最短距离法只看两类最近的一个点，只要各有一个点靠近就合并，容易把细长的一串点连成一类，类形状被拉得很长。要避免链式效应用最长距离法或 Ward 法，但最长距离法受极值影响大。
3. **问：系统聚类的分类数 K 怎么确定？光看树状图够吗？** 答：(1)看树状图合并高度的跳跃，跳跃大的位置截断；(2)统计量辅助：半偏 R² 骤增说明不该再合并、伪 F 统计量越大越好；(3)结合实际业务意义。n 小时用系统聚类，n>1000 建议 K-means。

## 8. 速记卡

- 步骤：各自成类 → 合并最近 → 更新距离 → 直到一类。
- 五种方法：最短/最长/重心/类平均/Ward。
- Ward 法最常用，类内最紧凑。
- 树状图截断定 K。
- R: hclust(d, method="ward.D2")，cutree(hc, k=3)。
- **一句话口诀**：每家店自成一族，越合越大，树状图上看家谱。
