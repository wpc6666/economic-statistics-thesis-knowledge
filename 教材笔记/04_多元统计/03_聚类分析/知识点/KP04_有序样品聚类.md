# KP04 有序样品聚类

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 直觉：时间序列不能打乱顺序。比如一年 12 个月的气温，要分成"春夏秋冬"——只能切几刀，不能把 1 月和 7 月放一组。这就是有序样品聚类。

## 1. 是什么

### 定义
样品本身有顺序（时间、地质年代、地理位置），聚类时不能打乱顺序，只能在相邻样品之间切分。

### 直觉类比
把一根香肠切成几段。刀只能切在相邻两段之间，不能把香肠打乱重排。每一段就是一类。

### 解决什么问题
- 时间序列分段：把一年分成四季。
- 地质剖面分层：按深度分层。
- 学生成长阶段划分。

## 2. 怎么用

### 核心思想：最优分割法
- 目标：分 K 段后，段内离差平方和最小。
- Fisher 算法：动态规划，找到最优切分点。
- 段直径 D(i,j) = 样品 i 到 j 的离差平方和。

### 损失函数
$$e[P(n,K)] = \min_{\text{切分点}} \sum_{k=1}^{K} D(i_k, i_{k+1}-1)$$

### R 代码

```r
# 目的：有序样品聚类（最优分割法）
# 可用包 optpart 或编程实现 Fisher 算法

# (1) 假设有序数据 df，n 个样品按顺序排列
# 这里示意一维时间序列的分段
x <- c(1, 2, 3, 10, 11, 12, 30, 31, 32)  # 明显三段

# (2) 计算段直径矩阵 D(i,j)
# D(i,j) = sum_{t=i}^{j}(x[t] - mean(x[i:j]))^2
n <- length(x)
D <- matrix(0, n, n)
for (i in 1:n) {
  for (j in i:n) {
    D[i, j] <- sum((x[i:j] - mean(x[i:j]))^2)
  }
}

# (3) Fisher 算法求最优 K 段分割
# 这里 K=3
K <- 3
# 动态规划：p[m][k] = 前 m 个样品分 k 段的最小损失
p <- matrix(Inf, n, K)
cuts <- matrix(0, n, K)
for (m in 1:n) p[m, 1] <- D[1, m]

for (k in 2:K) {
  for (m in k:n) {
    for (i in (k-1):(m-1)) {
      val <- p[i, k-1] + D[i+1, m]
      if (val < p[m, k]) {
        p[m, k] <- val
        cuts[m, k] <- i
      }
    }
  }
}

# (4) 回溯找切分点
print(p[n, K])  # 最小损失
```

### 计算演示
时间序列 x = (1, 2, 3, 10, 11, 12, 30, 31, 32)，分 3 段。
- 自然分段：[1,2,3] | [10,11,12] | [30,31,32]
- 各段直径：
  - D(1,3) = (1-2)²+(2-2)²+(3-2)² = 2
  - D(4,6) = (10-11)²+(11-11)²+(12-11)² = 2
  - D(7,9) = (30-31)²+(31-31)²+(32-31)² = 2
- 总损失 = 6
- 其他切法（如 [1,2]|[3,4,5,6]|[7,8,9]）损失更大。

## 3. 什么时候用

### 适用场景
- 时间序列分段。
- 地质剖面分层。
- 有天然顺序的样品。

### 数据条件
- 样品顺序有实际意义。
- 指标为连续变量。

### 前提假设
- 相邻样品应在同一类或自然过渡。

## 4. 什么时候不能用 / 易错点

- **样品无顺序时不能用**：强行使用会损失信息。
- **切分段数 K 需预先指定**。
- **Fisher 算法计算量大**：n 很大时需优化。

## 5. 与相似方法对比表

| 方法 | 可否打乱顺序 | 适用 | 优点 | 缺点 |
|------|-------------|------|------|------|
| 系统聚类 | 可以 | 任意样品 | 通用 | 忽略顺序 |
| K-means | 可以 | 大样本 | 快速 | 忽略顺序 |
| 有序样品聚类 | 不可以 | 有顺序数据 | 尊重顺序 | 不通用 |

## 6. 为什么用这个不用那个

- **时间序列/地质剖面** → 必须用有序样品聚类。
- **样品无顺序** → 系统聚类或 K-means。

## 7. 完整例子

### 书中原例（3.6节）
某地区 21 个深度的地层数据，分 4 段。
- 用 Fisher 最优分割法。
- 得到 4 个地质层位，对应不同地质年代。

### 小白生活实例
一年 12 个月平均气温，分 4 季：
- 数据：1月3°, 2月5°, 3月10°, 4月16°, 5月21°, 6月25°, 7月28°, 8月27°, 9月23°, 10月17°, 11月10°, 12月5°
- 最优分割 4 段：
  - 冬：12,1,2月
  - 春：3,4,5月
  - 夏：6,7,8月
  - 秋：9,10,11月
- 段内气温差异小，段间差异大。

## 答辩常问（带标准答案）

1. **问：有序样品聚类和普通系统聚类最本质的区别是什么？** 答：普通聚类可以任意合并两类，打乱样品顺序无所谓；有序样品聚类只能在相邻样品之间切分，不能把不相邻的样品归为一类。因为样品本身有时间或空间顺序（月份、地质深度），打乱顺序就失去意义。
2. **问：Fisher 最优分割法在优化什么？和 K-means 的目标有什么联系？** 答：优化目标是把 n 个有序样品切 K 段，使段内离差平方和之和最小。用动态规划求解。思想和 K-means 的"类内 SSE 最小"一致，但多了一个约束：不能打乱样品顺序。
3. **问：什么数据必须用有序样品聚类？举两个例子。** 答：时间序列分段（一年 12 个月气温分四季）、地质剖面按深度分层。这些场景下 1 月和 7 月不能放一类，普通 K-means 会给出荒谬结果。

## 8. 速记卡

- 样品有顺序，不能打乱。
- Fisher 最优分割法。
- 目标：段内离差平方和最小。
- 适用：时间序列、地质剖面。
- **一句话口诀**：香肠切段，只能切在相邻处，段内越紧凑越好。
