# 多元统计分析学习笔记

> 基于何晓群《多元统计分析》第五版的小白向学习笔记库，R 语言实操。

## 使用路径

### 小白入门
1. 先读 [01_多元正态分布](01_多元正态分布/00_章节总结.md)
2. 读 [03_聚类分析](03_聚类分析/00_章节总结.md)（直觉最强）
3. 读 [05_主成分分析](05_主成分分析/00_章节总结.md)（最常用）
4. 每章先看框架图，再读知识点卡片

### 复习备考
- 重点对比表：[[KP04_PCA与FA对比|PCA]] vs [[KP03_PCA与因子分析对比|因子分析]]、聚类 vs 判别、Fisher判别 vs PCA
- 每章自测题
- 速记卡

### 实战分析
- 按方法选择决策：分组→聚类；已知分组→判别；降维→PCA/因子；看列联表→[[KP01_对应分析|对应分析]]

## 方法选择速查表

| 你的需求 | 用什么方法 | 章节 |
|---------|-----------|------|
| 无标签，自动分组 | 系统聚类/K-means | 03 |
| 有标签，预测新样本归类 | Fisher/Bayes/[[KP01_距离判别|距离判别]] | 04 |
| 多变量降维，保留最大方差 | [[02_主成分分析PCA|主成分分析]] PCA | 05 |
| 找隐藏因子，可旋转解释 | 因子分析 FA | 06 |
| 列联表行列关系可视化 | 对应分析 | 07 |
| 两组变量间最大相关 | 典型相关 CCA | 08 |
| 因变量是0/1 | Logistic回归 | 09 |
| 只有距离矩阵，反推坐标 | [[KP01_多维标度MDS|MDS]] [[KP01_多维标度MDS|多维标度]] | 11 |
