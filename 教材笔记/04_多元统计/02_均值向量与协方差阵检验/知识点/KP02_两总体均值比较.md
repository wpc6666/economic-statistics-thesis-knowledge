# KP02 两总体均值比较

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 直觉：一元两样本 t 检验比较两组均值；多元版本问"两组的整条均值向量是否不同"。关键是先确认两组协方差阵是否相等——相等就合并估计一个 S，不等就得分别估计。

## 1. 是什么

### 定义
有两个 p 维总体 G₁ ~ N_p(μ₁, Σ₁) 和 G₂ ~ N_p(μ₂, Σ₂)，分别抽样 n₁、n₂ 个样品，检验 H₀: μ₁ = μ₂。

### 直觉类比
比较"高端商圈奶茶店"和"社区商圈奶茶店"的客单价、销量、好评率是否整体不同——不是单独比每一项，而是把三项打包比。

### 解决什么问题
- 两总体多指标均值的整体差异检验。
- 为[[KP01_距离判别|距离判别]]分析提供"两类是否真的分得开"的统计依据。

## 2. 怎么用

### 完整步骤
1. 提出 H₀: μ₁ = μ₂。
2. 先用 Box's M 检验判断 Σ₁ 是否等于 Σ₂。
3. 若相等：合并协差阵 Ŝ = [(n₁-1)S₁ + (n₂-1)S₂]/(n₁+n₂-2)。
4. 算 T² = [n₁n₂/(n₁+n₂)] (X̄₁-X̄₂)'Ŝ⁻¹(X̄₁-X̄₂)。
5. 化 F 与临界值比较。
6. 若不等：Behrens-Fisher 近似，用 S* = S₁/n₁ + S₂/n₂。

### 核心公式

**协差阵相等时：**
$$T^2 = \frac{n_1 n_2}{n_1+n_2}(\bar{X}_1-\bar{X}_2)'\hat{\Sigma}^{-1}(\bar{X}_1-\bar{X}_2)$$

**合并协差阵：**
$$\hat{\Sigma} = \frac{(n_1-1)S_1 + (n_2-1)S_2}{n_1+n_2-2}$$

**自由度：** T² ~ T²(p, n₁+n₂-2)，化 F：
$$\frac{n_1+n_2-p-1}{(n_1+n_2-2)p}T^2 \sim F(p, n_1+n_2-p-1)$$

### R 代码

```r
# 目的：两样本 Hotelling T² 检验
# df1: 第一组 n1×p 数据框, df2: 第二组 n2×p 数据框

n1 <- nrow(df1); n2 <- nrow(df2); p <- ncol(df1)

# (1) 两组均值向量
xbar1 <- colMeans(df1)
xbar2 <- colMeans(df2)

# (2) 两组样本协方差阵
S1 <- cov(df1); S2 <- cov(df2)

# (3) 合并协方差阵（假设 Σ1=Σ2）
S_pooled <- ((n1-1)*S1 + (n2-1)*S2) / (n1 + n2 - 2)

# (4) 计算 T²
diff <- xbar1 - xbar2
T2 <- (n1*n2/(n1+n2)) * t(diff) %*% solve(S_pooled) %*% diff
print(T2)

# (5) 化 F
F_stat <- (n1+n2-p-1)/((n1+n2-2)*p) * T2
p_value <- 1 - pf(F_stat, df1=p, df2=n1+n2-p-1)
print(p_value)
```

### 计算演示
设 n₁=10, n₂=12, p=2，X̄₁-X̄₂ = (2, 1)'，合并 Ŝ = [[4, 1],[1, 2]]。

- |Ŝ| = 8-1 = 7，Ŝ⁻¹ = (1/7)[[2,-1],[-1,4]]
- T² = (10×12/22) × (2,1) Ŝ⁻¹ (2,1)'
- = 5.45 × (1/7) × (2×2×2 + 2×1×(-1) + 2×2×(-1) + 1×1×4)
- = 5.45 × (1/7) × (8-2-4+4) = 5.45 × 6/7 = 4.67
- F = (22-2-1)/((22-2)×2) × 4.67 = 19/40 × 4.67 = 2.22
- F(2,19) α=0.05 = 3.52，2.22 < 3.52，不拒绝 H₀。

## 3. 什么时候用

### 适用场景
- 两组样品的多指标均值比较。
- [[05_判别分析|判别分析]]建模前的可行性检验。

### 数据条件
- n₁+n₂ > p+1。
- 各组样品独立、组内正态。

### 前提假设
- 各组多元正态。
- 协差阵相等（Behrens-Fisher 情形除外）。

## 4. 什么时候不能用 / 易错点

- **协差阵不等时强行合并**：会扭曲 T²。先做 Box's M 检验。
- **n₁ 或 n₂ 太小**：协差阵估计不准。
- **T² 显著后要做一元检验**：定位具体哪个指标有差异。

## 5. 与相似方法对比表

| 情形 | 方法 | 统计量 | 自由度 |
|------|------|--------|--------|
| Σ₁=Σ₂ | 合并 T² | T² | p, n₁+n₂-2 |
| Σ₁≠Σ₂ | Behrens-Fisher | 近似 F | f 由公式近似 |
| 单总体 | 单样本 T² | T² | p, n-1 |
| [[KP03_多总体MANOVA|多总体]] | Wilks Λ | Λ | p, r-1, n-r |

## 6. 为什么用这个不用那个

- **Σ₁=Σ₂ 且正态** → 合并 T²。
- **Σ₁≠Σ₂** → Behrens-Fisher 近似，或直接用二次判别。
- **两组样本量极不平衡** → 合并估计会偏向大样本那组。

## 7. 完整例子

### 书中原例（例2-1）
比较河北、江苏、浙江三省经济发展水平。实际是 3 组，用 [[KP03_多总体MANOVA|MANOVA]]。两省比较时用两样本 T²。

### 小白生活实例
比较"高端商圈"10 家奶茶店和"社区商圈"12 家奶茶店的客单价、销量、好评率。
- X̄_高端 = (35, 200, 92%)'
- X̄_社区 = (18, 80, 85%)'
- 合并 S = [[100, 500, 0.1],[500, 5000, 0.5],[0.1, 0.5, 0.01]]
- 算 T²，若 p<0.05，则两类商圈的经营指标整体有显著差异，适合做判别分析。

## 答辩常问（带标准答案）

1. **问：两样本 T² 检验前为什么必须先做 Box's M 检验？** 答：T² 公式里要用合并协差阵 Ŝ=[(n₁-1)S₁+(n₂-1)S₂]/(n₁+n₂-2)，这个合并只有在 Σ₁=Σ₂ 时才合理。若协差阵不等还强行合并，会扭曲 T² 值。判断标准：Box's M 的 p>0.05→协差阵相等→合并 T²；p<0.05→Behrens-Fisher 近似。
2. **问：Behrens-Fisher 问题到底是什么？** 答：两总体均值检验但 Σ₁≠Σ₂ 时，没有精确的 T² 分布。用 S*=S₁/n₁+S₂/n₂ 代替合并协差阵，自由度 f 由近似公式确定，用 F 分布近似检验。这是一元统计中 Behrens-Fisher 问题的多元版本。
3. **问：两组样本量极不平衡时合并协差阵有什么问题？** 答：Ŝ 会偏向大样本那组的 S，小样本组的协方差结构被淹没，导致判别和检验都偏向大样本组。此时应谨慎解读，或直接用二次判别 QDA 分别估计各组协差阵。

## 8. 速记卡

- H₀: μ₁=μ₂，用 T² 检验。
- 协差阵相等 → 合并 Ŝ；不等 → Behrens-Fisher。
- T² 化 F 后查临界值。
- 显著后做一元 t 检验定位差异指标。
- **一句话口诀**：两组比向量，先看协方差阵，相等就合并，不等就近似。
