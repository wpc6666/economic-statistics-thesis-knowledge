# KP03 多总体均值检验（MANOVA）

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 直觉：单因素方差分析 ANOVA 问"三组的一个均值是否相等"；MANOVA 问"三组的整条均值向量是否相等"。把 p 个指标打包成一个整体，看组间差异是否足够大。

## 1. 是什么

### 定义
有 r 个 p 维总体 Gᵢ ~ N_p(μᵢ, Σ)，各抽 nᵢ 个样品，检验 H₀: μ₁ = μ₂ = … = μ_r。

### 直觉类比
ANOVA：三个班的数学平均分是否相等？
MANOVA：三个班的"数学、语文、英语"三科平均分向量是否整体相等？

### 解决什么问题
- 多组多指标均值的整体差异检验。
- 是[[05_判别分析|判别分析]]、方差分析的多维推广。

## 2. 怎么用

### 完整步骤
1. 提出 H₀: 所有 μᵢ 相等。
2. 计算组间离差阵 B 和组内离差阵 E。
3. 总离差阵 W = B + E。
4. 算 Wilks Λ = |E|/|W| = |E|/|B+E|。
5. Λ 越小越拒绝 H₀（组间差异大）。
6. 用 Bartlett 近似 V = -(n-r-(p-r+1)/2)lnΛ ~ χ²(p(r-1))。

### 核心公式

**组间离差阵：**
$$B = \sum_{i=1}^{r} n_i(\bar{X}_i - \bar{X})(\bar{X}_i - \bar{X})'$$

**组内离差阵：**
$$E = \sum_{i=1}^{r}\sum_{j=1}^{n_i}(X_{ij}-\bar{X}_i)(X_{ij}-\bar{X}_i)'$$

**Wilks Λ：**
$$\Lambda = \frac{|E|}{|B+E|} = \frac{|E|}{|W|}$$

**Bartlett 近似：**
$$V = -(n-r-\frac{p-r+1}{2})\ln\Lambda \sim \chi^2(p(r-1))$$

### R 代码

```r
# 目的：单因素 MANOVA
# df: n×p+1 数据框，最后一列 group 是分组因子

# (1) 构造多变量响应矩阵（所有数值列）
Y <- as.matrix(df[, 1:p])

# (2) 用 manova() 做单因素多元方差分析
# 语法：manova(cbind(y1,y2,...,yp) ~ group)
manova_result <- manova(Y ~ df$group)

# (3) 查看 Wilks Λ 和 F 近似
summary(manova_result, test = "Wilks")
# 其他可选检验："Pillai", "Hotelling-Lawley", "Roy"

# (4) 若 Wilks Λ 显著，再做单变量 ANOVA 看哪个指标有差异
for (j in 1:p) {
  aov_result <- aov(df[, j] ~ df$group)
  cat("变量", j, "的 ANOVA p 值：",
      summary(aov_result)1[1, 5], "\n")
}
```

### 计算演示
设 r=3, p=2, n₁=n₂=n₃=10。算得 |E|=100，|W|=150。
- Λ = 100/150 = 0.667
- V = -(30-3-(2-3+1)/2) × ln(0.667)
- = -(27) × (-0.405) = 10.94
- χ²(p(r-1)) = χ²(4)，α=0.05 临界值 9.49
- 10.94 > 9.49，拒绝 H₀。

## 3. 什么时候用

### 适用场景
- ≥3 组样品，每组多指标，想看组间是否整体有差异。
- 判别分析前的可行性检验。

### 数据条件
- 各组样本量之和 n > p+r。
- 各组协差阵相等。

### 前提假设
- 各组多元正态。
- 各组协差阵相同。
- 样品独立。

## 4. 什么时候不能用 / 易错点

- **协差阵不等时 MANOVA 不准**：先做 Box's M 检验。
- **严重不平衡设计**：大样本组会主导 E 阵。
- **Λ 显著后要做一元 ANOVA**：定位具体哪个指标、哪两组之间有差异。
- **Wilks Λ 不是越小越好**：Λ→1 说明组间无差异；Λ→0 说明组间差异大。

## 5. 与相似方法对比表

| 方法 | 检验对象 | 统计量 | 组数 | 指标数 |
|------|----------|--------|------|--------|
| 一元 ANOVA | 一个均值向量 | F | ≥2 | 1 |
| MANOVA (Wilks) | 均值向量 | Λ | ≥2 | ≥2 |
| Hotelling T² | 均值向量 | T² | 2 | ≥2 |
| Kruskal-Wallis | 分布位置 | H | ≥2 | 1（非参数） |

## 6. 为什么用这个不用那个

- **≥3 组、多指标、正态、协差阵齐** → MANOVA (Wilks Λ)。
- **2 组** → 两样本 T²（MANOVA 是 T² 的推广）。
- **数据非正态** → 考虑非参数 MANOVA。

## 7. 完整例子

### 书中原例（例2-1）
河北、江苏、浙江三省，p=4（人均 GDP、三产比重、人均消费、人均发电量）。
- 用 [[05_SPSS操作指引|SPSS]]: Analyze → General Linear Model → Multivariate
- 因变量选 4 个指标，固定因子选"省份"
- 看 Wilks Λ 的 Sig.
- 结果：三省在 4 个指标上整体差异显著。

### 小白生活实例
比较三类商圈（高端/社区/校园）各 10 家奶茶店的客单价、销量、好评率。
- 三组各 10 家，p=3。
- 算 Wilks Λ。
- 若 Λ 的 p<0.05，三类商圈整体不同。
- 再做一元 ANOVA，发现客单价差异最大，好评率差异不显著。

## 答辩常问（带标准答案）

1. **问：Wilks Λ 是越小越好还是越大越好？和 F 统计量方向相反吗？** 答：Λ=|E|/|B+E|=组内离差/总离差。Λ→0 说明组间差异大（组内占比小），拒绝 H₀；Λ→1 说明组间无差异。和一元 F"越大越拒绝"方向相反，Λ 是"越小越拒绝"。直觉：Λ=组内方差占比，占比小=组间分得开。
2. **问：MANOVA 和一元 ANOVA 是什么关系？p=1 时会怎样？** 答：ANOVA 检验多组间一个指标的均值差异；MANOVA 检验多组间多指标均值向量的整体差异。当 p=1 时 MANOVA 退化为 ANOVA。MANOVA 显著后，还要对每个指标做一元 ANOVA，定位哪个指标、哪两组之间有差异。
3. **问：做 MANOVA 需要哪些前提条件？** 答：(1)各组多元正态；(2)各组协差阵相等（先做 Box's M 检验）；(3)样品相互独立；(4)总样本量 n>p+r。违反时检验 p 值不准。严重不平衡设计中大样本组会主导 E 阵。

## 8. 速记卡

- H₀: 所有 μᵢ 相等。
- Λ = |E|/|W|，越小越拒绝。
- Bartlett 近似 V ~ χ²(p(r-1))。
- 显著后做一元 ANOVA 定位。
- **一句话口诀**：多组多指标，打包比差异，Wilks 一把尺，小了就拒绝。
