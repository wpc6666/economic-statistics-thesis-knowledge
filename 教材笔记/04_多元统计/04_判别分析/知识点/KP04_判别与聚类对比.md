# KP04 判别与聚类对比

> 直觉：聚类是"把陌生人按长相自动分组"，判别是"已知有学生和老师，给新来的人分类"。一个无标签，一个有标签。

## 1. 是什么

### 定义
- **[[04_聚类分析|聚类分析]]**：无标签，样品无事先类别，按相似性自动分组。
- **[[05_判别分析|判别分析]]**：有标签，已知类别样品训练规则，给新样品分类。

### 直觉类比
- 聚类：奶茶店老板不知道周边有几种商圈，把所有店按口味价格自动分组。
- 判别：老板已经知道哪些店是高端、哪些是社区，新店来了直接判断属于哪类。

### 解决什么问题
- 理清两种多元统计方法的本质区别。
- 实际问题中判断该用哪个。

## 2. 怎么用

### 对比表

| 维度 | 聚类分析 | 判别分析 |
|------|----------|----------|
| 类别标签 | 无 | 有 |
| 数据类型 | n×p 无标签 | n×p+1（最后一列类别） |
| 目标 | 发现内在结构 | 预测新样品类别 |
| 方法 | 系统聚类、K-means、有序样品 | 距离、Bayes、Fisher |
| 阶段 | 探索性分析 | 验证/预测分析 |
| 输出 | 类别归属 | 判别函数 + 新样品分类 |
| 事前知道类数 | 否 | 是（k 已知） |
| 典型算法 | hclust, kmeans | lda, qda |

### 实际应用流程
1. 先聚类探索数据结构（不知道有几类）。
2. 确定类别数 K。
3. 给样品贴上类标签。
4. 用这些标签训练判别函数。
5. 新样品用判别函数分类。

### R 代码

```r
# (1) 先聚类（无标签）
hc <- hclust(dist(df), method = "ward.D2")
labels <- cutree(hc, k = 3)  # 得到临时标签

# (2) 把聚类结果当标签，训练判别函数
df_labeled <- data.frame(df, group = as.factor(labels))
lda_model <- lda(group ~ ., data = df_labeled)

# (3) 新样品判别
pred <- predict(lda_model, newdata = newdata)
print(pred$class)
```

## 3. 什么时候用

### 什么时候用聚类
- 不知道样品分几类。
- 探索性分析。
- 客户分群、市场细分。

### 什么时候用判别
- 已知类别，要给新样品分类。
- 垃圾邮件识别、信用评级、疾病诊断。

## 4. 什么时候不能用 / 易错点

- **有标签却用聚类**：浪费已知信息。
- **无标签却用判别**：没有训练集。
- **聚类标签当真值**：聚类结果本身可能不准，判别时要注意。
- **先聚类后判别要交叉验证**：否则误判率偏乐观。

## 5. 与相似方法对比表

| 任务 | 有无标签 | 典型方法 | 例子 |
|------|----------|----------|------|
| 聚类 | 无 | K-means | 客户分群 |
| 判别 | 有 | lda/qda | 垃圾邮件分类 |
| 回归 | 有（连续） | lm | 房价预测 |
| 关联规则 | 无 | Apriori | 购物篮分析 |

## 6. 为什么用这个不用那个

- **有标签、要分类** → 判别。
- **无标签、要探索** → 聚类。
- **无标签但想分类** → 先聚类探索，再判别。

## 7. 完整例子

### 书中原例
第3章用系统聚类把 31 个省区按消费支出分 2 类（北京上海 vs 其他）。
第4章例4-3 用这个分类结果训练 Fisher 判别函数，再给广东、西藏归类。
- 流程：聚类（探索）→ 贴标签 → 判别（预测）。

### 小白生活实例
奶茶连锁：
- 阶段1：不知道商圈类型，把 50 家店按口味价格聚类成 3 类。
- 阶段2：给 3 类命名为高端/社区/学生。
- 阶段3：新店开业，用判别函数直接判断属于哪类商圈。

## 答辩常问（带标准答案）

1. **问：聚类和判别最本质的区别是什么？各回答什么问题？** 答：聚类无标签，事先不知道有几类、哪类是哪类，是无监督探索，回答"数据里有什么结构"；判别已知类别标签，训练判别函数给新样品归类，是有监督预测，回答"新样品属于哪类"。一个物以类聚，一个对号入座。
2. **问：为什么实践中常"先聚类后判别"？有什么风险？** 答：当只有一堆样品、不知道分几类时，先用系统聚类或 K-means 探索出 K 类并贴临时标签，再用这些标签训练判别函数。风险：聚类标签本身可能不准，判别误判率要用交叉验证估计，不能用回判率。
3. **问：有标签为什么还要聚类？无标签能不能直接用判别？** 答：标签可能太粗（如只知道高消费/低消费），聚类能发现更细的结构（高消费里还分奢侈型和品质型）。但无标签绝不能用判别——判别需要已知类别作为训练集，没有训练集无从谈起。

## 8. 速记卡

- 聚类：无标签，物以类聚。
- 判别：有标签，对号入座。
- 常组合用：先聚类探索，再判别预测。
- 聚类结果可能不准，判别需交叉验证。
- **一句话口诀**：不知道几类就聚类，知道几类就判别，先聚后判一条龙。
