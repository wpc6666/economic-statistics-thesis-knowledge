# KP02 Bayes 判别

> 直觉：[[KP01_距离判别|距离判别]]只看"离谁近"；Bayes 判别还看"哪类本来就多、错判谁代价大"。比如罕见病，即使检查结果像罕见病，也得先怀疑常见病。

## 1. 是什么

### 定义
基于 Bayes 公式，计算新样品 x 属于各类的后验概率 P(G_i|x)，归后验概率最大的类。同时考虑错判损失 L(j|i)。

### 直觉类比
医生看病：发烧可能是感冒（常见病，先验概率大）也可能是白血病（罕见病）。即使症状像白血病，也先考虑感冒——因为感冒先验概率大。这就是 Bayes 判别。

### 解决什么问题
- 各类大小悬殊时，距离判别会偏向大类。
- 错判代价不同时（如癌症漏诊代价大），需要调整。

## 2. 怎么用

### 核心公式

**后验概率：**
$$P(G_i|x) = \frac{q_i f_i(x)}{\sum_j q_j f_j(x)}$$

**期望错判损失最小：**
$$R(i|x) = \sum_{j \neq i} L(j|i) P(G_j|x)$$
归 R(i|x) 最小的类。

**[[05_SPSS操作指引|SPSS]] 中 Fisher's 系数就是 Bayes 判别系数。**

### R 代码

```r
# 目的：Bayes 判别
# (1) 加载 MASS 包
library(MASS)

# (2) lda() 默认假定协差阵相等，做 Bayes 线性判别
# prior 可设先验概率，默认按样本比例
lda_model <- lda(group ~ ., data = train,
                 prior = c(0.3, 0.5, 0.2))  # 先验概率
print(lda_model)

# (3) 预测新样品
pred <- predict(lda_model, newdata = newdata)
print(pred$class)       # 预测类别
print(pred$posterior)   # 后验概率

# (4) qda() 协差阵不等时的二次判别
qda_model <- qda(group ~ ., data = train)
pred_qda <- predict(qda_model, newdata = newdata)
```

### 计算演示
两类：
- G₁ 先验 q₁=0.1（罕见病），G₂ 先验 q₂=0.9（常见病）
- 某症状 x 在 G₁ 下概率 f₁(x)=0.8，在 G₂ 下概率 f₂(x)=0.2

后验概率：
- P(G₁|x) = 0.1×0.8 / (0.1×0.8+0.9×0.2) = 0.08/0.26 = 0.308
- P(G₂|x) = 0.9×0.2 / 0.26 = 0.692
- 即使症状像 G₁，后验概率 G₂ 更大，判 G₂。

## 3. 什么时候用

### 适用场景
- 各类先验概率已知。
- 错判代价不等。
- 各类大小悬殊。

### 数据条件
- 各类多元正态。
- 先验概率可估计或已知。

### 前提假设
- 多元正态。
- 先验概率准确。

## 4. 什么时候不能用 / 易错点

- **先验概率估计不准会误导**：q_i 错了后验就错。
- **错判损失难量化**：实际中 L(j|i) 常主观设定。
- **协差阵不等时用 qda()**：不要用 lda()。

## 5. 与相似方法对比表

| 方法 | 先验概率 | 错判损失 | 协差阵 | 适用 |
|------|----------|----------|--------|------|
| 距离判别 | 默认 1/k | 不考虑 | 相等 | 各类均衡 |
| Bayes (lda) | 可设 | 等损失 | 相等 | 有先验信息 |
| Bayes (qda) | 可设 | 可设 | 不等 | 协差阵不同 |
| Fisher | 不涉及 | 不涉及 | 相等 | 投影可视化 |

## 6. 为什么用这个不用那个

- **各类均衡、错判代价相同** → 距离判别或 Fisher。
- **各类悬殊或错判代价不同** → Bayes。
- **协差阵不等** → qda()。

## 7. 完整例子

### 书中原例（例4-3）
SPSS 中做 Fisher 判别时，Statistics → Function Coefficients → Fisher's 选项输出的就是 Bayes 判别系数。Save → Probabilities of group membership 输出后验概率。

### 小白生活实例
判断新店是否属于高端商圈：
- G₁ 高端先验 q₁=0.2（市场上高端店少）
- G₂ 社区先验 q₂=0.8
- 新店特征 x 在 G₁ 下概率 f₁(x)=0.7，在 G₂ 下 f₂(x)=0.3
- P(G₁|x) = 0.2×0.7/(0.14+0.24) = 0.368
- P(G₂|x) = 0.8×0.3/0.38 = 0.632
- 判社区店（尽管特征像高端，但高端店本来就少）。

## 答辩常问（带标准答案）

1. **问：Bayes 判别比距离判别多考虑了什么？举个直觉例子。** 答：距离判别默认各类先验概率相等、错判代价相同。Bayes 判别引入先验概率 q_i 和错判损失 L(j|i)。例如罕见病（先验 0.1）vs 常见病（先验 0.9），即使症状像罕见病，后验概率常见病更大，判常见病——这就是 Bayes 调整。
2. **问：后验概率公式怎么写？归哪类怎么定？** 答：P(G_i|x)=q_i f_i(x)/Σ_j q_j f_j(x)，即"该类先验×该类下观测到 x 的概率"做归一化。归后验概率最大的类。某类先验概率小，要离它更远才判它。
3. **问：lda() 和 qda() 怎么选？先验概率怎么设？** 答：都做 Bayes 判别。lda() 假定协差阵相等，边界线性；qda() 允许协差阵不等，边界二次。先做 Box's M，p>0.05 用 lda，p<0.05 用 qda。先验概率可用 prior=参数指定，默认按样本比例估计。

## 8. 速记卡

- 后验概率 P(G_i|x) ∝ q_i f_i(x)。
- 归后验概率最大的类。
- 先验概率小的类更难被判中。
- R: lda() 线性，qda() 二次。
- **一句话口诀**：离得近不算数，先验概率和错判代价一起算，后验最大才归它。
