# KP01 距离判别

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 直觉：新奶茶店离哪类商圈的"马氏距离"最近，就归哪类。比的不是直线距离，而是"在概率空间里离哪个类中心最近"。

## 1. 是什么

### 定义
设有 k 个已知类 G₁,…,G_k，各类均值向量 μ_i、协差阵 Σ_i。新样品 x 归 d²_M(x, G_i) 最小的那一类。

### 直觉类比
就像找"最近邻居"：来了一家新店，分别算它到高端商圈中心、社区商圈中心、校园商圈中心的距离，最近的就是它的类。

### 解决什么问题
- 有已知类别标签，给新样品分类。
- 最简单直观的判别方法。

## 2. 怎么用

### 完整步骤
1. 各类训练样品，算均值 x̄_i 和协差阵 S_i。
2. 若 Σ₁=…=Σ_k，合并 S_p。
3. 对新样品 x，算到各类的马氏距离 d²_M(x, G_i)。
4. 归距离最小的类。

### 核心公式

**两总体（Σ₁=Σ₂）：**
$$W(x) = (x-\frac{\bar{x}_1+\bar{x}_2}{2})'S_p^{-1}(\bar{x}_1-\bar{x}_2)$$
- W(x) ≥ 0 判 G₁，W(x) < 0 判 G₂

**[[KP03_多总体MANOVA|多总体]]：**
$$x \in G_i \iff d_M^2(x, G_i) = \min_j d_M^2(x, G_j)$$

### R 代码

```r
# 目的：距离判别
# train: 训练数据框，最后一列 group 是类别
# newdata: 待判样品

# (1) 按类分组算均值和协差阵
groups <- unique(train$group)
k <- length(groups)
p <- ncol(train) - 1

# (2) 合并协差阵（假设各类协差阵相等）
n <- nrow(train)
S_list <- lapply(groups, function(g) cov(train[train$group == g, 1:p]))
n_list <- as.numeric(table(train$group))
S_pooled <- Reduce("+", lapply(1:k, function(i) (n_list[i]-1)*S_listi)) / (n - k)

# (3) 各类均值
means_list <- lapply(groups, function(g) colMeans(train[train$group == g, 1:p]))

# (4) 对新样品算马氏距离并归类
d2 <- sapply(1:k, function(i) {
  mahalanobis(newdata, center = means_listi, cov = S_pooled)
})
new_class <- groups[which.min(d2)]
print(new_class)
```

### 计算演示
两类：G₁ 均值 (0,0)'，G₂ 均值 (2,2)'，合并 S = [[1,0],[0,1]]。
新样品 x = (1,1)'。

- d²(x,G₁) = (1,1)(1,1)' = 2
- d²(x,G₂) = (-1,-1)(-1,-1)' = 2
- 距离相等，恰好在分界线上。

若 x = (0.5, 0.5)'：
- d²(x,G₁) = 0.5
- d²(x,G₂) = 4.5
- 判 G₁。

## 3. 什么时候用

### 适用场景
- 已知类别，新样品分类。
- 各类多元正态。

### 数据条件
- n_i > p。
- 各类独立。

### 前提假设
- 多元正态。
- 协差阵相等（合并估计时）。

## 4. 什么时候不能用 / 易错点

- **协差阵不等时强行合并**：判别不准，应用二次判别。
- **n_i 太小**：协差阵估计不准。
- **回判误判率偏小**：用训练集自评，需交叉验证。

## 5. 与相似方法对比表

| 方法 | 类别数 | 协差阵 | 考虑先验 |
|------|--------|--------|----------|
| 距离判别 | ≥2 | 相等合并 | 否 |
| 距离判别（不等） | ≥2 | 不等分别 | 否 |
| Bayes 判别 | ≥2 | 任意 | 是 |
| Fisher 判别 | 2 | 相等 | 否 |

## 6. 为什么用这个不用那个

- **类别先验概率已知且错判代价不同** → Bayes。
- **协差阵不等** → 二次判别。
- **需要可视化判别方向** → Fisher。

## 7. 完整例子

### 书中原例（例4-2）
20 个国家人类发展水平分 3 类，待判中国内地和中国香港。
- 算各类马氏距离。
- 中国香港 d²=3.075 最小到 G₁（极高发展）。
- 中国内地 d²=0.793 最小到 G₂（高发展）。
- 回判误判率 0。

### 小白生活实例
两类商圈奶茶店，新到一家店 (客单价 25, 销量 150)。
- G₁ 高端中心 (35, 200)，G₂ 社区中心 (15, 80)。
- S = [[100,500],[500,5000]]。
- 算马氏距离，归最近类（见 KP02 [[KP02_统计距离|统计距离]]例题）。

## 答辩常问（带标准答案）

1. **问：距离判别什么时候用线性边界、什么时候用二次边界？** 答：各类协差阵相等（Box's M 检验 p>0.05）→合并协差阵 Ŝ，判别边界是直线（线性判别）；各类协差阵不等（p<0.05）→各类分别用自己的 S_i 算马氏距离，判别边界是二次曲线（二次判别 qda）。
2. **问：为什么回判误判率通常偏小？真实误判率怎么估计？** 答：回判是用训练集自己评估自己——判别函数就是从这些样品学的，对训练样品当然"熟悉"。真实误判率要用留出测试集或留一交叉验证（LOO）估计，通常比回判率高几个百分点。
3. **问：距离判别和 Fisher 判别是什么关系？什么时候等价？** 答：两总体协差阵相等时，距离判别推导出的判别函数 W(x)=(x-(x̄₁+x̄₂)/2)'S_p⁻¹(x̄₁-x̄₂)，其投影方向 a=S_p⁻¹(x̄₁-x̄₂) 正是 Fisher 方向。所以两总体、等协差阵时两者完全等价。

## 8. 速记卡

- 算新样品到各类的马氏距离。
- 归距离最小的类。
- 协差阵相等合并 S_p，不等分别算。
- 回判率偏乐观，需交叉验证。
- **一句话口诀**：新店离哪类中心最近，就归哪类。
