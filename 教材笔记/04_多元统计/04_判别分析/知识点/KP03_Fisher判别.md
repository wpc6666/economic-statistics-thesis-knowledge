# KP03 Fisher 判别

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 直觉：把多维数据投影到一条直线上，让两类投影后的中心距离最大、各自内部最紧凑。投影方向就是"最好的判别方向"。

## 1. 是什么

### 定义
找一个投影方向 a，把 p 维样品投影成一维 y = a'x，使投影后"类间距离 / 类内距离"最大。

### 直觉类比
在墙上投影两个班级的学生散点。找一个投影角度，让投影后两个班的点堆分得最开——这就是 Fisher 方向。

### 解决什么问题
- 高维数据可视化：投影到 1-2 维看类是否分得开。
- 降维判别：p 维变量压缩成 1-2 个判别函数。

## 2. 怎么用

### 完整步骤
1. 计算两类均值 x̄₁, x̄₂ 和合并协差阵 S_p。
2. 求判别方向 a = S_p⁻¹(x̄₁ - x̄₂)。
3. 判别函数 y = a'x。
4. 求分界点 m = ½(x̄₁+x̄₂)'a。
5. y ≥ m 判一类，y < m 判另一类。

### 核心公式

**判别方向：**
$$a = S_p^{-1}(\bar{x}_1 - \bar{x}_2)$$

**两总体分界点：**
$$m = \frac{1}{2}(\bar{x}_1 + \bar{x}_2)' S_p^{-1}(\bar{x}_1 - \bar{x}_2)$$

**[[KP03_多总体MANOVA|多总体]]：** 最多 min(p, k-1) 个判别函数，解广义特征值问题 S_p⁻¹B 的特征向量。

### R 代码

```r
# 目的：Fisher 线性判别
library(MASS)

# (1) lda() 做 Fisher 线性判别
lda_model <- lda(group ~ ., data = train)
print(lda_model)

# (2) 查看判别系数（标准化后）
# scaling 列就是投影方向 a
print(lda_model$scaling)

# (3) 预测
pred <- predict(lda_model, newdata = newdata)
print(pred$class)        # 分类结果
print(pred$x)            # 投影后的判别函数值

# (4) 画投影散点图（2个判别函数时）
plot(lda_model)
```

### 计算演示（书中原例 4-3）
北京上海 vs 其余省区，8 个消费指标。
- S_p⁻¹ 已知（书中原例）。
- a = S_p⁻¹(x̄₁-x̄₂) = (-0.008, -0.017, 0.020, 0.025, -0.019, 0.004, 0.015, 0.026)'
- 判别函数 y = -0.008x₁ - 0.017x₂ + 0.020x₃ + ...
- 分界点 m = 109.171
- 广东 y=40.929 < 109.171 → 第二类
- 西藏 y=-19.406 < 109.171 → 第二类

## 3. 什么时候用

### 适用场景
- 两类或多类判别。
- 需要可视化分类效果。
- 协差阵相等。

### 数据条件
- 各类多元正态。
- 协差阵相等。

### 前提假设
- 线性可分或近似线性可分。

## 4. 什么时候不能用 / 易错点

- **协差阵不等时用 Fisher 线性判别效果差**：应用 qda()。
- **投影方向不是方差最大方向**：Fisher 方向是类间最大，[[KP04_PCA与FA对比|PCA]] 方向是总方差最大。
- **多类时判别函数个数有限**：k 类最多 min(p, k-1) 个。

## 5. 与[[02_主成分分析PCA|主成分分析]]对比表

| 维度 | Fisher 判别 | 主成分分析 PCA |
|------|-------------|---------------|
| 目标 | 类间距离/类内距离最大 | 总方差最大 |
| 是否用类别信息 | 是（监督） | 否（无监督） |
| 方向 | S_p⁻¹B 的特征向量 | Σ 的特征向量 |
| 个数 | min(p, k-1) | p |
| 用途 | 分类 | 降维 |

## 6. 为什么用这个不用那个

- **有类别标签，要分类** → Fisher。
- **无标签，要降维看结构** → PCA。
- **协差阵不等** → 二次判别 qda()。

## 7. 完整例子

### 书中原例（例4-1 鸢尾花）
150 个鸢尾花，3 类（Setosa/Versicolor/Virginica），4 个指标。
- Fisher 判别 2 个线性判别函数。
- Setosa 与另两类完全分开。
- Versicolor 和 Virginica 有重叠。
- 回判准确率 97.3%。

### 小白生活实例
两类商圈奶茶店，8 个指标。
- Fisher 判别方向 a = S_p⁻¹(x̄₁-x̄₂)。
- 投影后 y 值：高端店 y>m，社区店 y<m。
- 新投影值 y_new 与 m 比较归类。

## 答辩常问（带标准答案）

1. **问：Fisher 判别方向和 PCA 方向有什么本质不同？** 答：Fisher 方向 a=S_p⁻¹(x̄₁-x̄₂)，最大化"类间距离/类内距离"比（判别导向，监督学习）；PCA 方向是 Σ 的最大特征值对应特征向量，最大化总方差（方差导向，无监督）。Fisher 用类别信息，PCA 不用。
2. **问：k 类问题最多能有几个判别函数？为什么？** 答：最多 min(p, k-1) 个。因为类间离差阵 B 的秩≤k-1（k 个均值向量之间只有 k-1 个线性独立方向）。例如 3 类鸢尾花只有 2 个判别函数，正好可以画二维投影散点图。
3. **问：两类问题的分界点怎么定？为什么是中点？** 答：投影后 y=a'x，分界点 m=½(x̄₁+x̄₂)'a，即两类均值投影的中点。y≥m 判 G₁，y<m 判 G₂。这个中点分界只在两类协差阵相等时是贝叶斯最优分界。

## 8. 速记卡

- 投影方向 a = S_p⁻¹(x̄₁-x̄₂)。
- 分界点 m = ½(x̄₁+x̄₂)'a。
- y≥m 判一类，y<m 判另一类。
- 与 PCA 区别：Fisher 看类间距离，PCA 看总方差。
- R: lda()。
- **一句话口诀**：找个方向投影，让两类分得最开，投影值和中点比大小。
