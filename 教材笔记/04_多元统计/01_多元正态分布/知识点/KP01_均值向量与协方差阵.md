# KP01 均值向量与协方差阵

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 直觉：把一元统计中的"均值"和"方差"推广到多维——均值变成一列向量，方差变成一张方阵，这个方阵还额外记录了变量之间的相关性。

## 1. 是什么

### 定义
- **均值向量** μ = E(X) = [E(X₁), E(X₂), …, E(Xₚ)]'，把 p 个变量各自的期望排成一列。
- **协方差阵** Σ = cov(X,X) = E[(X-μ)(X-μ)']，主对角元是各变量方差 σ_ii = D(X_i)，非对角元是两两协方差 σ_ij = cov(X_i,X_j)。
- **相关阵** R = (r_ij)，其中 r_ij = σ_ij / (√σ_ii √σ_jj)，是[[KP11_标准化_ZScore|标准化]]后的协方差阵。

### 直觉类比
想象你给一家奶茶店打分，打了"甜度、奶味、茶味"三个维度。一元统计只看甜度的平均分；多元统计要看三个维度各自的平均分（均值向量），还要看甜度和奶味是不是同时升高（协方差阵的非对角元）。

### 解决什么问题
- 多指标问题中，不能割裂地单独看每个指标，必须整体把握变量间的联合波动与关联结构。
- 协方差阵 Σ 是后续所有多元方法（距离、检验、判别、聚类、主成分）的核心输入。

## 2. 怎么用

### 完整步骤
1. 收集 n 个样品、p 个指标的数据，排成 n×p 矩阵 X。
2. 计算每个变量的样本均值 X̄_j = (1/n)Σ_i x_ij，排成样本均值向量 X̄。
3. 计算离差阵 L = Σ_i (X_(i) - X̄)(X_(i) - X̄)'。
4. 无偏样本协方差阵 S = L/(n-1)。
5. 若需要相关阵，用 R = D⁻¹/² S D⁻¹/²，其中 D = diag(S)。

### 核心公式

**均值向量：**
$$\bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_{(i)} = \begin{pmatrix}\bar{X}_1 \\ \vdots \\ \bar{X}_p\end{pmatrix}$$

**协方差阵：**
$$\Sigma = (\sigma_{ij}),\quad \sigma_{ij} = E[(X_i - \mu_i)(X_j - \mu_j)]$$

**相关阵：**
$$r_{ij} = \frac{\sigma_{ij}}{\sqrt{\sigma_{ii}}\sqrt{\sigma_{jj}}}$$

**重要性质：**
- E(AX) = A·E(X)
- D(AX) = AΣA'
- E(X'AX) = tr(AΣ) + μ'Aμ
- 标准化后 X* = (X-μ)/√σ，其协方差阵正好等于相关阵 R

### R 代码

```r
# 目的：用 R 计算样本均值向量、协方差阵、相关阵
# 数据：假设 df 是一个 n×p 的数据框，每列是一个变量

# (1) 计算样本均值向量
# colMeans() 对每一列求均值，返回一个长度为 p 的向量
mean_vec <- colMeans(df)
print(mean_vec)

# (2) 计算样本协方差阵
# cov() 默认使用 n-1 作为分母（无偏估计）
cov_mat <- cov(df)
print(cov_mat)

# (3) 计算样本相关阵
# cor() 等价于标准化后再求协方差阵
cor_mat <- cor(df)
print(cor_mat)

# (4) 验证：标准化数据的协方差阵 = 原数据相关阵
# scale() 对每列做 (x-mean)/sd，默认 center=TRUE, scale=TRUE
df_std <- scale(df)
cov_std <- cov(df_std)
# cov_std 应该与 cor_mat 数值上完全相等
print(round(cov_std - cor_mat, 10))  # 输出应全为 0
```

### 计算演示

设 3 个样品、2 个变量：

| 样品 | X₁ | X₂ |
|------|----|----|
| 1 | 1 | 2 |
| 2 | 2 | 1 |
| 3 | 3 | 4 |

**第1步：算均值**
- X̄₁ = (1+2+3)/3 = 2
- X̄₂ = (2+1+4)/3 = 7/3 ≈ 2.333
- 均值向量 X̄ = (2, 2.333)'

**第2步：算离差积**
- 样品1离差：(-1, -0.333)'，外积 = [[1, 0.333],[0.333, 0.111]]
- 样品2离差：(0, -1.333)'，外积 = [[0, 0],[0, 1.778]]
- 样品3离差：(1, 1.667)'，外积 = [[1, 1.667],[1.667, 2.778]]
- L = [[2, 2.0],[2.0, 4.667]]

**第3步：无偏协方差阵 S = L/(n-1) = L/2**
- S = [[1, 1.0],[1.0, 2.333]]

**第4步：相关阵**
- r₁₂ = 1.0 / √(1 × 2.333) = 1/1.528 = 0.655

## 3. 什么时候用

### 适用场景
- 任何多指标统计分析的第一步：描述数据的[[02_集中趋势|集中趋势]]与波动结构。
- 后续方法（[[KP01_距离判别|距离判别]]、聚类、主成分）的前置计算。

### 数据条件
- 每个变量至少有 n > p 个观测（否则协方差阵不可逆）。
- 各变量方差大于 0（否则相关阵无法定义）。

### 前提假设
- 样品之间相互独立。
- 各分量的期望与方差存在。
- 若要进一步做检验，需假定总体服从[[KP03_多元正态分布|多元正态分布]]。

## 4. 什么时候不能用 / 易错点

- **不要把协方差阵和相关阵混用**：量纲不同的变量直接算协方差阵会被大方差变量主导，必须先标准化。
- **n 必须大于 p**：n < p 时协方差阵奇异（不可逆），马氏距离等方法失效。
- **L/n 是有偏的**：小样本时务必用 L/(n-1)。
- **相关阵只刻画线性关系**：r=0 不代表独立，只代表无线性相关。
- **Σ 必须正定**：若两个变量完全线性相关，|Σ|=0，多元正态密度不存在。

## 5. 与相似方法对比表

| 方法 | 原理 | 适用数据 | 优点 | 缺点 | 什么时候选它 |
|------|------|----------|------|------|-------------|
| 协方差阵 Σ | 度量联合波动 | 原始量纲数据 | 保留量纲信息 | 受量纲影响大 | 同一量纲下比较波动 |
| 相关阵 R | 标准化后的协方差 | 不同量纲数据 | 消除量纲影响，可比 | 丢失方差大小信息 | 变量量纲不同时 |
| 广义方差 \|Σ\| | 协方差阵行列式 | 多元数据 | 一个数概括整体波动 | 解释不直观 | Wilks Λ 的构成 |
| 迹 tr(Σ) | 对角元和 | 多元数据 | 简单 | 忽略变量间相关性 | 粗估总方差 |

## 6. 为什么用这个不用那个

- **量纲一致** → 用协方差阵 S。
- **量纲不一致**（如身高 cm 与体重 kg） → 先标准化，用相关阵 R。
- **需要一个数概括整体[[03_离散程度|离散程度]]** → 用广义方差 |S|（Wilks Λ 用的就是它）或迹 tr(S)。
- **被排除的做法**：直接用欧氏距离处理不同量纲数据——大方差变量会完全主导距离结果。

## 7. 完整例子

### 书中原例：服装标准制定（1.3.3节）
对某年龄段女性测量 5 项指标：身高 X₁、胸围 X₂、腰围 X₃、上体长 X₄、臀围 X₅。

μ = (154.98, 83.39, 70.26, 61.32, 91.52)'

Σ = 
```
29.66
 6.51  30.53
 1.85  25.54  39.86
 9.36   3.54   2.23   7.03
10.34  19.53  20.70   5.21  27.36
```

解读：
- 身高方差 29.66 最大，腰围方差 39.86 最大。
- 胸围与腰围协方差 25.54 最大，说明胸围大的女性腰围也倾向于大。
- 上体长与身高协方差 9.36，正相关。

### 小白生活实例：奶茶店三维打分
3 家奶茶店，每人打"甜度(0-10)、价格(元)、口碑(0-10)"：

| 店 | 甜度 X₁ | 价格 X₂ | 口碑 X₃ |
|----|---------|---------|---------|
| A | 8 | 15 | 9 |
| B | 6 | 12 | 7 |
| C | 9 | 18 | 8 |

均值向量：X̄ = (7.67, 15.0, 8.0)'

协方差阵（n-1=2）：
- s₁₁ = [(8-7.67)²+(6-7.67)²+(9-7.67)²]/2 = 2.33
- s₂₂ = [(15-15)²+(12-15)²+(18-15)²]/2 = 9.0
- s₃₃ = [(9-8)²+(7-8)²+(8-8)²]/2 = 1.0
- s₁₂ = [(0.33)(0)+(-1.67)(-3)+(1.33)(3)]/2 = 5.0
- s₁₃ = [(0.33)(1)+(-1.67)(-1)+(1.33)(0)]/2 = 1.0
- s₂₃ = [(0)(1)+(-3)(-1)+(3)(0)]/2 = 1.5

S = [[2.33, 5.0, 1.0],[5.0, 9.0, 1.5],[1.0, 1.5, 1.0]]

解读：甜度和价格正相关（s₁₂=5.0），越甜的店越贵。

## 答辩常问（带标准答案）

1. **问：量纲不同的变量为什么不能直接算协方差阵，必须先标准化？** 答：协方差阵对角元是各变量方差，量纲大的变量（如体重 kg，方差可能达几百）会在后续距离计算、[[KP04_PCA与FA对比|PCA]] 中完全主导结果，把量纲小的变量（如比率 0.05）淹没。标准化后各变量方差=1，得到相关阵 R，各变量在距离中权重相等。判断标准：量纲一致且同方差用 S，量纲不同用 R。
2. **问：n<p 时为什么协方差阵不可逆？实际中怎么避免？** 答：n 个样品 p 个变量，离差阵 L=Σ(x_i-x̄)(x_i-x̄)' 的秩最多为 min(n-1, p)，当 n-1<p 时 |L|=0，S 奇异，马氏距离、T² 检验全部失效。经验法则要求 n>p，做 PCA 或回归时最好 n≥5p。
3. **问：[[01_相关系数|相关系数]] r=0 为什么不等于两变量独立？** 答：r 只刻画线性关系。若两变量呈完美 U 型关系，r=0 但完全不独立。只有对正态总体，"不相关"才等价于"独立"——因为多元正态密度完全由 μ 和 Σ 决定，Σ 对角意味着密度可拆成 p 个一元正态的乘积。

## 8. 速记卡

- 均值向量 μ：p 个变量的期望排成一列。
- 协方差阵 Σ：对角=方差，非对角=协方差，对称半正定。
- 相关阵 R：标准化后的 Σ，消除量纲影响。
- 样本估计：X̄ 估计 μ，L/(n-1) 估计 Σ。
- **一句话口诀**：均值向量管"中心在哪"，协方差阵管"怎么散开、谁跟谁联动"。
