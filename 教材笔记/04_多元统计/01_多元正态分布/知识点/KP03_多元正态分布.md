# KP03 多元正态分布

<div style="text-align:right;margin:10px 0;"><a href="../../../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


> 直觉：一元正态分布是一口"钟形钟"，多元正态分布就是把钟拉成 p 维空间里的"钟形山丘"——山丘的中心是 μ，山丘的形状由 Σ 决定（圆的=独立同方差，椭圆的=有相关性）。

## 1. 是什么

### 定义
若 p 维随机向量 X 的密度函数为：
$$f(x) = \frac{1}{(2\pi)^{p/2}|\Sigma|^{1/2}} \exp\left[-\frac{1}{2}(x-\mu)'\Sigma^{-1}(x-\mu)\right],\quad \Sigma>0$$
则称 X 服从 p 元正态分布，记 X ~ N_p(μ, Σ)。

### 直觉类比
想象二维数据（身高、体重）的散点图。如果身高和体重不相关，散点云是圆形的；如果正相关，散点云是斜着拉长的椭圆。这个椭圆山丘就是二元正态分布。山丘最高点在均值(μ₁, μ₂)处，沿着椭圆长轴方向散布大、短轴方向散布小。

### 解决什么问题
- 多元统计的绝大多数理论（估计、检验、判别、聚类）都建立在多元正态假定上。
- 它是一元正态分布的自然推广，且保持了"线性变换仍正态""边缘/条件分布仍正态"等优良性质。

## 2. 怎么用

### 核心性质

**性质1：参数含义明确**
- E(X) = μ，D(X) = Σ

**性质2：线性变换仍正态**
- 若 X ~ N_p(μ, Σ)，则 Z = AX + b ~ N_m(Aμ+b, AΣA')

**性质3：边缘分布仍正态**
- X 的任何分量子集仍服从正态分布。反之不真（边缘都正态不代表联合正态）。

**性质4：协方差对角 ⇒ 分量独立**
- 若 Σ 是对角阵，则 X₁,…,Xₚ 相互独立。
- 对正态总体而言，"不相关"等价于"独立"。

**性质5：马氏距离平方服从 χ²**
- d² = (X-μ)'Σ⁻¹(X-μ) ~ χ²(p)

**性质6：条件分布仍正态**
将 X 剖分为 X = [X⁽¹⁾; X⁽²⁾]，给定 X⁽²⁾=x⁽²⁾ 时：
$$X^{(1)}|X^{(2)} \sim N_q(\mu_{1\cdot2}, \Sigma_{11\cdot2})$$
$$\mu_{1\cdot2} = \mu^{(1)} + \Sigma_{12}\Sigma_{22}^{-1}(x^{(2)}-\mu^{(2)})$$
$$\Sigma_{11\cdot2} = \Sigma_{11} - \Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}$$

### R 代码

```r
# 目的：模拟多元正态数据并可视化
# (1) 加载 MASS 包，其中 mvrnorm() 用于生成多元正态随机数
library(MASS)

# (2) 设定均值向量和协方差阵
mu <- c(0, 0)
Sigma <- matrix(c(1, 0.8, 0.8, 1), nrow = 2)  # 正相关协方差阵

# (3) 生成 500 个服从 N_2(mu, Sigma) 的随机样品
# n=500 样品数, mu 均值向量, Sigma 协方差阵
set.seed(123)  # 固定随机种子，保证可重复
data <- mvrnorm(n = 500, mu = mu, Sigma = Sigma)

# (4) 画散点图，直观看到椭圆形散点云
plot(data[,1], data[,2],
     xlab = "X1", ylab = "X2",
     main = "二元正态分布散点图（相关系数 r=0.8）")
abline(v = 0, h = 0, lty = 2, col = "gray")

# (5) 验证：样本均值和样本协方差阵应接近设定值
print(colMeans(data))       # 应接近 (0, 0)
print(cov(data))            # 应接近 [[1, 0.8],[0.8, 1]]

# (6) 验证马氏距离平方 ~ chi-square(p=2)
# mahalanobis(x, center, cov) 计算每个样品到中心的马氏距离平方
d2 <- mahalanobis(data, center = mu, cov = Sigma)
# 画直方图，与 chi-square(2) 密度对比
hist(d2, breaks = 30, freq = FALSE,
     main = "马氏距离平方的分布 vs χ²(2)")
curve(dchisq(x, df = 2), add = TRUE, col = "red", lwd = 2)
```

### 计算演示：条件分布（书中原例）

已知女性体型数据 μ 和 Σ（见 KP01）。给定臀围 X₅=91.52（即均值），求胸围 X₂ 的条件分布。

- X⁽¹⁾ = (X₁,X₂,X₃,X₄)'，X⁽²⁾ = X₅
- μ⁽¹⁾ = (154.98, 83.39, 70.26, 61.32)'
- μ⁽²⁾ = 91.52
- Σ₁₂ = (10.34, 19.53, 20.70, 5.21)'
- Σ₂₂ = 27.36

条件均值：
- μ_{1·2} = μ⁽¹⁾ + Σ₁₂/Σ₂₂ × (X₅ - 91.52)
- 当 X₅ = 91.52 时，第二项为 0，条件均值 = μ⁽¹⁾ = (154.98, 83.39, 70.26, 61.32)'

条件方差（以胸围 X₂ 为例）：
- Σ_{11·2} 的第(2,2)元 = 30.53 - (19.53)²/27.36 = 30.53 - 13.94 = 16.59
- 结论：已知臀围后，胸围的方差从 30.53 降到 16.59，不确定性减小。

## 3. 什么时候用

### 适用场景
- 绝大多数多元统计方法的基础假定。
- 需要精确计算置信区间、[[KP02_假设检验|假设检验]] p 值时。

### 数据条件
- n > p，样品相互独立。
- 各变量近似正态（可通过 Q-Q 图、Shapiro-Wilk 检验逐一验证单变量正态性）。

### 前提假设
- 多元正态分布。实际中常先验证每个边缘变量的正态性，再假定联合多元正态。
- 若严重违反正态假定，检验统计量的 p 值会不准，但大样本下中心极限定理可补救。

## 4. 什么时候不能用 / 易错点

- **"边缘正态 ⇒ 联合正态"是错的**：书中反例 f(x₁,x₂) = (1/2π)exp[-(x₁²+x₂²)/2][1+x₁x₂exp(-(x₁²+x₂²)/2)]，两个边缘都是 N(0,1)，但联合不是二元正态。
- **不相关 ≠ 独立（非正态情形）**：只有正态总体下不相关才等价于独立。
- **Σ 必须正定**：若 |Σ|=0，密度函数不存在（退化正态）。
- **样本量不能太小**：n 接近 p 时，协方差阵估计极不稳定。
- **条件分布的协方差阵 Σ₁₁·₂ 一定 ≤ Σ₁₁**：知道更多变量只会减少不确定性，不会增加。

## 5. 与相似方法对比表

| 方法 | 类型 | 密度 | 用途 | 优点 | 缺点 |
|------|------|------|------|------|------|
| 多元正态分布 | 连续分布 | 指数型椭圆 | 理论基础、检验 | 性质优良（线性变换、条件分布仍正态） | 要求对称、单峰 |
| 多元 t 分布 | 连续分布 | 重尾 | 稳健统计 | 容忍异常值 | 计算复杂 |
| 多元二项/泊松 | 离散分布 | — | 计数数据 | 适合分类/计数 | 不能用于连续变量 |

## 6. 为什么用这个不用那个

- **理论推导与检验** → 用多元正态，因为所有抽样分布（Wishart、T²、Wilks Λ）都从它推出。
- **数据明显有重尾或异常值** → 考虑多元 t 分布或稳健方法。
- **被排除的做法**：在严重非正态数据上直接套用 T² 检验——p 值会不可靠。

## 7. 完整例子

### 书中原例：服装标准（1.3.3节）
已知 5 维女性体型数据 N₅(μ, Σ)。给定上体长 X₄ 和臀围 X₅，求身高 X₁ 的条件分布。

计算结果：
- D(X₁|X₄,X₅) = 16.72 < D(X₁) = 29.66
- D(X₂|X₄,X₅) = 16.58 < D(X₂) = 30.53
- D(X₃|X₄,X₅) = 23.71 < D(X₃) = 39.86

**解读**：知道一个人的上体长和臀围后，身高、胸围、腰围的预测精度大幅提高（方差减小约 40%）。这就是条件分布的实际应用——制定服装号型时，只需测量少数几个关键尺寸就能推断其他尺寸。

### 小白生活实例：奶茶店评分的二元正态
假设奶茶店的"甜度"X₁ 和"口碑"X₂ 服从二元正态：
- μ = (7, 8)'（甜度均值 7，口碑均值 8）
- Σ = [[1, 0.6],[0.6, 1]]（甜度和口碑正相关 r=0.6）

问：已知某店甜度特别高（X₁=9，比均值高 2 个标准差），它的口碑期望是多少？

条件均值：
- E(X₂|X₁=9) = μ₂ + σ₁₂/σ₁₁ × (9-μ₁)
- = 8 + 0.6/1 × (9-7) = 8 + 1.2 = 9.2

**解读**：甜度很高的店，口碑期望从 8 升到 9.2——因为两者正相关。这就是条件分布的直觉：顺着相关方向推。

## 答辩常问（带标准答案）

1. **问：为什么"每个边缘变量都正态"不能推出"联合多元正态"？** 答：书中反例 f(x₁,x₂)=(1/2π)exp[-(x₁²+x₂²)/2][1+x₁x₂exp(-(x₁²+x₂²)/2)]，两个边缘都是 N(0,1)，但联合密度不是椭圆对称的，不是二元正态。所以实际中不能靠逐个画单变量 Q-Q 图就假定多元正态，严格做法是检验联合正态性（如 Mardia 检验）。
2. **问：条件分布中为什么 Σ₁₁·₂ ≤ Σ₁₁？** 答：Σ₁₁·₂=Σ₁₁-Σ₁₂Σ₂₂⁻¹Σ₂₁，后一项 Σ₁₂Σ₂₂⁻¹Σ₂₁ 是半正定矩阵，减去后方差阵只会减小。物理含义：已知 X⁽²⁾ 后，X⁽¹⁾ 的不确定性降低了。书中服装例子：知道臀围后胸围方差从 30.53 降到 16.59。
3. **问：多元正态下"不相关"为什么等价于"独立"？非正态呢？** 答：多元正态密度完全由 μ 和 Σ 决定。若 Σ 是对角阵（不相关），密度可拆成 p 个一元正态密度的乘积，联合分布=边缘分布乘积，即独立。非正态分布没有这个性质——不相关只代表没有线性关系，可能存在非线性关系。

## 8. 速记卡

- 密度核心：指数里是马氏距离平方的一半。
- 四大性质：线性变换仍正态、边缘仍正态、条件仍正态、不相关=独立。
- 条件均值公式：μ₁·₂ = μ₁ + Σ₁₂Σ₂₂⁻¹(x₂-μ₂)。
- 条件方差公式：Σ₁₁·₂ = Σ₁₁ - Σ₁₂Σ₂₂⁻¹Σ₂₁ ≤ Σ₁₁。
- **一句话口诀**：多元正态就是"椭圆山丘"，切一刀（条件化）还是正态，拉直线性变换还是正态。
