# KP02 统计距离

> 直觉：欧氏距离用"直线长度"度量远近，但现实中变量有大有小、有相关性——就像用步长量路，大长腿和小短腿走同样步数距离却不同。马氏距离就是"按每个人的步长归一化后再量距离"。

## 1. 是什么

### 定义
- **欧氏距离**：d(P,Q) = √[Σ(x_i - y_i)²]，勾股定理的直接推广。
- **统计距离（[[KP11_标准化_ZScore|标准化]]距离）**：d(P,Q) = √[Σ(x_i-y_i)²/S_ii]，每个维度按样本方差加权。
- **马氏距离**：d²_M(X,Y) = (X-Y)'Σ⁻¹(X-Y)，用协方差阵的逆加权，同时消除量纲与相关性影响。

### 直觉类比
假设你要比较两个学生的"成绩远近"。甲语文 90、数学 60；乙语文 60、数学 90。欧氏距离认为两人一样远（√900+900）。但如果数学全班差距很大（方差大）、语文全班差距很小（方差小），那甲和乙其实差不多——因为数学差30分在班里不算什么，语文差30分才是大事。马氏距离就是"按每科的方差归一化后再比"。

### 解决什么问题
- 欧氏距离对每个坐标一视同仁，不合理。
- 需要一种与量纲无关、且考虑变量间相关性的距离度量。
- 马氏距离是后续[[KP01_距离判别|距离判别]]、T²检验的基础。

## 2. 怎么用

### 完整步骤
1. 判断变量是否同量纲、同方差、不相关。
2. 若不满足，计算样本协方差阵 S。
3. 求 S 的逆 S⁻¹。
4. 对任意两点 X、Y，计算 d²_M = (X-Y)'S⁻¹(X-Y)。
5. 比较 d²_M 的大小，越小越接近。

### 核心公式

**欧氏距离：**
$$d(P,Q) = \sqrt{\sum_{k=1}^{p}(x_k - y_k)^2}$$

**统计距离（对角加权）：**
$$d(P,Q) = \sqrt{\sum_{k=1}^{p}\frac{(x_k - y_k)^2}{S_{kk}}}$$

**马氏距离：**
$$d_M^2(X,Y) = (X-Y)'\Sigma^{-1}(X-Y)$$

**点 X 到总体 G 的马氏距离：**
$$d_M^2(X,G) = (X-\mu)'\Sigma^{-1}(X-\mu)$$

### R 代码

```r
# 目的：计算两个样品之间的马氏距离
# 数据：df 是 n×p 数据框，x1 和 x2 是两个待比样品（p维向量）

# (1) 计算样本协方差阵
cov_mat <- cov(df)

# (2) 求协方差阵的逆
# solve() 对矩阵求逆，要求矩阵可逆（正定）
cov_inv <- solve(cov_mat)

# (3) 计算马氏距离平方
# t(x1 - x2) %*% cov_inv %*% (x1 - x2)
diff <- x1 - x2
mahal_dist_sq <- t(diff) %*% cov_inv %*% diff
print(mahal_dist_sq)

# (4) R 也有内置函数 mahalanobis()
# mahalanobis(x, center, cov) 计算 x 到 center 的马氏距离平方
# center 是均值向量，cov 是协方差阵
mahal_dist_sq2 <- mahalanobis(x1, colMeans(df), cov_mat)
print(mahal_dist_sq2)
```

### 计算演示（书中原例 3-2）

设二维正态总体 G ~ N₂(0, Σ)，其中 Σ = [[1, 0.9],[0.9, 1]]。

求点 A=(1,1)' 和点 B=(1,-1)' 到均值 μ=(0,0)' 的距离。

**第1步：求 Σ⁻¹**
- |Σ| = 1×1 - 0.9×0.9 = 1 - 0.81 = 0.19
- Σ⁻¹ = (1/0.19) × [[1, -0.9],[-0.9, 1]]

**第2步：算 A 点马氏距离**
- d²_M(A,μ) = (1,1) Σ⁻¹ (1,1)'
- = (1/0.19) × [1×1 + 1×1 - 0.9×1×1 - 0.9×1×1]
- = (1/0.19) × (2 - 1.8) = 0.2/0.19 ≈ 1.053

**第3步：算 B 点马氏距离**
- d²_M(B,μ) = (1,-1) Σ⁻¹ (1,-1)'
- = (1/0.19) × [1×1 + (-1)×(-1) - 0.9×1×(-1) - 0.9×(-1)×1]
- = (1/0.19) × (2 + 1.8) = 3.8/0.19 = 20

**对比欧氏距离：**
- d²_E(A,μ) = 1+1 = 2
- d²_E(B,μ) = 1+1 = 2
- 欧氏距离认为 A、B 一样远；马氏距离认为 B 比 A 远约 19 倍。

**为什么？** 因为 X₁ 和 X₂ 高度正相关（r=0.9），点 A=(1,1) 顺着相关方向偏移，概率密度高（f=0.2157）；点 B=(1,-1) 逆着相关方向偏移，概率密度极低（f=0.00001658）。马氏距离正确反映了这一点。

## 3. 什么时候用

### 适用场景
- 变量量纲不同（如身高 cm 与体重 kg）。
- 变量间存在显著相关性。
- 需要做距离判别、T² 检验时。

### 数据条件
- 协方差阵 Σ 正定（可逆）。
- 样本量 n > p（否则 S 奇异）。

### 前提假设
- 马氏距离本身不要求正态，但配合 T² 检验时需要多元正态假定。

## 4. 什么时候不能用 / 易错点

- **[[04_聚类分析|聚类分析]]中慎用马氏距离**：聚类前不知道类结构，用全部样本算的 Σ 往往不合理，实践中常用标准化后的欧氏距离。
- **Σ 不可逆时无法计算**：n < p 或变量间完全共线性时，马氏距离失效。
- **马氏距离对小样本不稳定**：n 很小时 S 估计不准。
- **不要混淆"距离"和"概率"**：马氏距离大不代表概率低，但对正态总体两者一致。

## 5. 与相似方法对比表

| 方法 | 公式 | 考虑量纲 | 考虑相关性 | 优点 | 缺点 | 什么时候选它 |
|------|------|----------|------------|------|------|-------------|
| 欧氏距离 | √Σ(x-y)² | 否 | 否 | 简单直观 | 量纲敏感、忽略相关 | 同量纲独立变量 |
| 统计距离 | √Σ(x-y)²/S_ii | 是 | 否（仅对角） | 消除量纲 | 不考虑变量相关 | 变量独立但量纲不同 |
| 马氏距离 | (x-y)'Σ⁻¹(x-y) | 是 | 是 | 最合理，对线性变换不变 | 需估计 Σ，小样本不稳 | [[05_判别分析|判别分析]]、T² 检验 |
| 兰氏距离 | (1/p)Σ\|x-y\|/(x+y) | 是 | 否 | 适合正数变量 | 不考虑相关 | 变量全为正时 |
| 切比雪夫距离 | max\|x_k-y_k\| | 否 | 否 | 只看最大维度差 | 信息利用少 | 只关心最坏维度 |

## 6. 为什么用这个不用那个

- **变量量纲相同且相互独立** → 欧氏距离即可。
- **变量量纲不同但相互独立** → 先标准化，再用欧氏距离（等价于统计距离）。
- **变量间有相关性** → 必须用马氏距离，否则会误判"顺着相关方向"的点很近。
- **被排除的做法**：直接用欧氏距离处理身高(cm)和体重(kg)——体重数值大，完全主导距离结果。

## 7. 完整例子

### 书中原例：量纲反转实验（1.2节）
横轴 x₁ = 重量(kg)，纵轴 x₂ = 长度(cm)。
- A=(0,0), B=(5,10), C=(0,0), D=(10,1)
- 欧氏距离：AB = √(25+100) = √125 ≈ 11.18；CD = √(100+1) = √101 ≈ 10.05
- 结论：AB > CD

现在把 x₂ 单位从 cm 换成 mm（×10）：
- A=(0,0), B=(5,100), C=(0,0), D=(10,10)
- 欧氏距离：AB = √(25+10000) = √10025 ≈ 100.1；CD = √(100+100) = √200 ≈ 14.14
- 结论：AB >> CD，结论完全反转！

这说明欧氏距离与量纲有关，不合理。马氏距离通过除以方差，对单位变换不变。

### 小白生活实例：判断新奶茶店属于哪类商圈
已知两类商圈：
- 高端商圈 G₁：均值 μ₁ = (客单价 35 元, 日均销量 200 杯)'
- 社区商圈 G₂：均值 μ₂ = (客单价 15 元, 日均销量 80 杯)'
- 合并协方差阵估计 S = [[100, 500],[500, 5000]]

新店 X = (25 元, 150 杯)'。

计算马氏距离：
- X-μ₁ = (-10, -50)'
- X-μ₂ = (10, 70)'
- S⁻¹ = (1/(100×5000-500²)) × [[5000, -500],[-500, 100]] = (1/250000) × [[5000, -500],[-500, 100]]

d²(X,G₁) = (-10,-50) S⁻¹ (-10,-50)'
= (1/250000) × [(-10)²×5000 + (-50)²×100 + 2×(-10)×(-50)×(-500)]
= (1/250000) × [500000 + 250000 - 500000]
= 250000/250000 = 1

d²(X,G₂) = (10,70) S⁻¹ (10,70)'
= (1/250000) × [100×5000 + 4900×100 + 2×10×70×(-500)]
= (1/250000) × [500000 + 490000 - 700000]
= 290000/250000 = 1.16

d²(X,G₁) = 1 < d²(X,G₂) = 1.16，新店判为高端商圈。

## 答辩常问（带标准答案）

1. **问：马氏距离为什么能同时消除量纲和变量相关性的影响？** 答：d²_M=(x-y)'Σ⁻¹(x-y)。乘上 Σ⁻¹ 相当于两步：先按各变量方差归一（消除量纲），再用逆矩阵的非对角项消去变量间协方差（消除相关性）。正因如此，马氏距离对一切线性变换不变——把身高从 cm 换成 mm，距离结果不变，这是欧氏距离做不到的。
2. **问：聚类分析中为什么慎用马氏距离？** 答：马氏距离需要 Σ⁻¹，但聚类前不知道类结构，用全部样本算的 Σ 把不同类混在一起，这个"总协方差阵"不代表任何一类的离散模式，算出的距离反而扭曲。判别分析中类已知，用马氏距离合理；聚类中类未知，实践中通常用标准化后的欧氏距离。
3. **问：书中原例中 A=(1,1) 和 B=(1,-1) 欧氏距离相同，为什么马氏距离差近 19 倍？** 答：因为 X₁ 与 X₂ 高度正相关（r=0.9）。A 顺着相关方向偏移，落在概率密度高的区域，马氏距离小（1.05）；B 逆着相关方向偏移，落在概率极低的区域，马氏距离大（20）。这说明欧氏距离只看几何位置，马氏距离看的是"在概率云里离中心有多远"。

## 8. 速记卡

- 欧氏距离：勾股定理，量纲敏感。
- 统计距离：除以方差，消除量纲。
- 马氏距离：乘 Σ⁻¹，消除量纲 + 相关性。
- 关键性质：对一切线性变换不变；等值面是椭球面。
- **一句话口诀**：欧氏距离量直线，统计距离量标准差，马氏距离量"在概率空间里离中心有多远"。
