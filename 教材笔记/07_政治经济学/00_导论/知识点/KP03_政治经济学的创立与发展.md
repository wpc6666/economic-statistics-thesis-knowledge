# KP03 · 政治经济学的创立与发展

> 所属：[[../00_章节总结|导论]] ｜ 节：原书第四、五节

## 1. 一句话先懂（小白版）

马克思不是凭空发明了一套理论。他是把**英国古典政治经济学**（斯密、李嘉图的劳动价值论）拿过来，**砍断它和资产阶级的联系**，再用**唯物史观**给它装了新骨架，最后在这个骨架上发现了"剩余价值"——这就是马克思主义政治经济学。

简单说：**斯密李嘉图给了他"劳动创造价值"的种子，马克思给它浇了"剥削"的水，长出了一棵大树。**

## 2. 严格定义

**马克思主义政治经济学创立的两个直接理论来源：**

1. **德国古典哲学**（黑格尔辩证法 + 费尔巴哈唯物主义）→ 改造成唯物辩证法；
2. **英国古典政治经济学**（配第、斯密、李嘉图的劳动价值论）→ 改造成剩余价值论。

**马克思的两大发现：**
- **唯物史观**：生产力决定生产关系、经济基础决定上层建筑；
- **剩余价值学说**：利润来自工人剩余劳动。

恩格斯说，这两大发现使社会主义从空想变成科学。

## 3. 为什么（原理/机制）

### 为什么古典政治经济学走不下去？

斯密、李嘉图已经提出了"劳动创造价值"，但他们卡在两个地方：

1. **解释不了利润**：既然劳动创造价值，那资本家的利润从哪来？如果商品按价值交换，工人工资 = 劳动创造的价值，那资本家就没利润。古典派绕不出来，最后干脆说"资本也创造价值"（即后来的三位一体公式：劳动-工资、资本-利润、土地-地租）。
2. **把资本主义当成永恒**：斯密说这是"人的交换、倾向、物物交换的天性"，是自然秩序。

**马克思怎么突破的？**

他区分了**劳动**和**劳动力**（这是关键突破，详见 [[../../02_资本主义经济制度与生产/知识点/KP04_劳动力商品]]）：

- 工人出卖的不是"劳动"，而是"劳动力"（一个月的干活能力）；
- 劳动力的价值 = 养活工人及其家庭的费用（工资 5000）；
- 但劳动力的**使用**（劳动）能创造出比 5000 更多的价值（比如 8000）；
- 中间 3000 的差额就是**剩余价值**，被资本家拿走。

这一下既坚持了"劳动创造价值"，又解释了利润来源，还说明了剥削——一举三得。

## 4. 来源（理论怎么来的）

时间线：

| 时间 | 事件 |
|---|---|
| 1843-1844 | 马克思在巴黎开始研究政治经济学，写《1844 年经济学哲学手稿》 |
| 1848 | 《共产党宣言》发表，和恩格斯一起把唯物史观系统表达 |
| 1859 | 《政治经济学批判》出版，首次系统表述剩余价值理论雏形 |
| 1867 | 《资本论》第一卷出版（第二、三卷由恩格斯整理遗稿后出版） |
| 19 世纪末-20 世纪初 | 列宁研究垄断资本主义（《帝国主义是资本主义的最高阶段》） |
| 20 世纪 | 斯大林时期苏联政治经济学教科书；毛泽东《论十大关系》《关于正确处理人民内部矛盾的问题》 |
| 改革开放后 | 中国特色社会主义政治经济学：社会主义市场经济、社会主义初级阶段基本经济制度 |
| 新时代 | 习近平新时代中国特色社会主义经济思想（新发展理念、新发展格局、高质量发展） |

## 5. 怎么用（现实例子）

**用奶茶店对照：**

- **斯密会怎么说**："王老板拿利润是因为他提供了资本、承担了风险，这是自然秩序。"
- **李嘉图卡在哪里**：他承认劳动创造价值，但解释不清"既然等价交换，利润从哪来"，最后只能含糊说"工资和利润此消彼长"。
- **马克思怎么说**："王老板买到的不是工人的'劳动'，而是工人的'劳动力'。劳动力一个月值 5000，但让他干活，一个月能做出 8000 的奶茶价值。差的 3000 就是剩余价值。这不是天经地义，这是**资本主义生产关系特有的**——因为王老板占有了店面、机器、原料，工人不把劳动力卖给他就活不下去。"

## 6. 什么时候不能用（边界条件）

- 马克思研究的是**19 世纪英国自由竞争资本主义**。到了 20 世纪，资本主义出现了很多新现象（垄断、金融化、跨国公司、数字平台），需要列宁之后的理论发展来补充，不能直接拿 1867 年的原话套今天的平台经济。
- 剩余价值论揭示的是**资本主义生产关系的本质**，不是说"所有利润都绝对来自剥削、企业家的管理劳动一分钱都不算"。马克思自己也承认管理劳动是生产劳动——区别在于**占有剩余价值的那部分**是无偿的。
- 中国特色社会主义政治经济学不是把《资本论》照搬到中国，而是**结合中国实际**（社会主义初级阶段、公有制为主体、市场经济）发展出来的。

## 7. 容易混淆什么

| 容易混 | 区别 |
|---|---|
| 马克思政治经济学 vs 古典政治经济学 | 都讲劳动价值论，但后者把资本主义当永恒，前者把它当历史的、必然灭亡的阶段。 |
| 马克思政治经济学 vs 空想社会主义 | 空想社会主义（圣西门、傅立叶）凭道德愤怒骂资本主义；马克思用经济规律说明它必然灭亡、必然被社会主义代替。 |
| 剩余价值论 vs 劳动价值论 | 劳动价值论是"劳动创造价值"（古典派也讲）；剩余价值论是"工人创造的价值大于劳动力价值，差额被资本家占有"（马克思独创）。 |
| 马克思政治经济学 vs 西方新古典 | 前者从生产关系看；后者从资源配置看。 |

## 8. 现实意义

今天讨论"996 是不是剥削""外卖骑手社保""字节跳动的利润来自哪"——这些问题，政治经济学给你的答案和西方经济学不一样。它不让你停在"供需决定工资"的表象，而是追问：**这份工资对应的劳动力价值是多少？劳动者实际创造了多少价值？中间差额去哪了？**

这是这门课最大的现实意义——给你一双看穿"谁在创造、谁在占有"的眼睛。
