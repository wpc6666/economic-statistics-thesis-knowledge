# KP03 · 新发展格局

> 所属：[[00_章节总结|第六章 社会主义市场经济与发展]]

## 1. 一句话先懂（小白版）

以前我们是"世界工厂"——生产东西卖给全世界（国际大循环）。现在要变成"以内为主、内外联动"——自己内部的循环当主力，同时不放弃国际循环。这就是"以国内大循环为主体、国内国际双循环相互促进"的新发展格局。

**为什么要变？**——就像一个人，以前靠出门打工赚钱（出口导向），现在自己家里的生意做起来了，消费能力也强了，就应该主要靠自家生意吃饭，出门打工变成补充。

## 2. 严格定义

**新发展格局**：以国内大循环为主体、国内国际双循环相互促进的新发展格局。

- **国内大循环为主体**：让生产、分配、流通、消费更多依托国内市场，提升供给体系对国内需求的适配性，形成需求牵引供给、供给创造需求的更高水平动态平衡。
- **国内国际双循环相互促进**：在以国内大循环为主体的同时，继续充分利用国际市场和国际资源，通过对外开放提升国内大循环的效率和水平。

## 3. 为什么要提出新发展格局

### 3.1 外部环境变化

| 因素 | 具体表现 |
|---|---|
| 逆全球化抬头 | 贸易保护主义、单边主义盛行，美国对中国打贸易战 |
| 全球需求疲软 | 2008年金融危机后，世界经济长期低迷，外需增长有限 |
| 产业链重构 | 疫情后各国重新考虑供应链安全，产业链"中国+1"趋势 |

**大白话**：以前我们靠外国人买东西赚钱，现在外国人买得少了、还加关税，那我们就得自己想办法——自己人买自己人生产的东西。

### 3.2 国内条件成熟

| 条件 | 数据/事实 |
|---|---|
| 超大规模市场 | 14亿人口，4亿中等收入群体，全球最有潜力的消费市场 |
| 完整工业体系 | 联合国产业分类中全部工业门类都有，独立完整 |
| 内需潜力大 | 最终消费支出对GDP增长贡献率已达50%以上 |

**大白话**：以前是"没钱所以要出口赚外汇"，现在是"有钱了、市场大了，可以自己玩得转了"。

## 4. 新发展格局不是什么（容易混淆）

### 误区1：关起门来搞建设

**错！** 新发展格局不是封闭的国内循环，而是更加开放的国内国际双循环。

打个比方：不是"我以后不出去打工了，在家闭门造车"，而是"我主要靠自家生意，但我也会和外人做生意，而且做得更好"。

### 误区2：只是扩大出口

**错！** 重点是"内循环"，不是"外循环"。而且不只是多生产东西，而是生产和消费要匹配——以前是生产什么卖什么，现在是需要什么生产什么。

### 误区3：和改革开放矛盾

**错！** 新发展格局是更高水平的开放。以前是"利用外资、出口创汇"的开放，现在是"内需为主、双向开放"的开放——别人也可以来中国市场卖东西、投资。

## 5. 新发展格局怎么运转（手算例子）

**场景**：王老板的奶茶店以前是"出口导向型"——主要卖给来旅游的外国人。

| 项目 | 旧模式（国际大循环为主） | 新模式（国内大循环为主体） |
|---|---|---|
| 原料 | 从国外进口茶叶、奶源 | 用云南茶叶、内蒙古奶源（国内供应链） |
| 生产 | 按照外国游客口味调整配方 | 按照国内年轻人喜好做新品（芝士葡萄、芋泥波波） |
| 销售 | 主要卖给外国游客 | 外卖、小程序、周边城市加盟店 |
| 收入 | 主要靠外汇 | 人民币收入为主 |
| 供应链 | 依赖国际物流 | 国内冷链、本地配送 |

**算一笔账**：
- 旧模式：月营业额10万，其中7万来自外国游客，3万来自本地
- 新模式：月营业额15万，其中11万来自本地居民和外卖，4万来自外国游客

**变化**：
- 总营业额：10万 → 15万（增长50%）
- 本地消费占比：30% → 73%（国内大循环为主体）
- 外国游客占比：70% → 27%（国际循环是补充）

**这就是"国内大循环为主体、国内国际双循环相互促进"。**

## 6. 关键抓手

### 6.1 扩大内需（战略基点）

- **消费**：提升收入、完善社保、让老百姓敢花钱
- **投资**：新型基础设施（5G、数据中心）、城镇化、补短板

### 6.2 科技自立自强（战略支撑）

- 解决"卡脖子"问题（芯片、操作系统、高端机床）
- 把科技命脉掌握在自己手里

### 6.3 深化供给侧结构性改革

- 不是生产什么卖什么，而是需要什么生产什么
- 让供给更好地匹配需求

## 7. 现实意义

1. **应对外部风险**：减少对国际市场的依赖，不怕别人"脱钩断链"
2. **发挥大国优势**：14亿人的大市场是我们最大的底牌
3. **提升人民生活**：发展的目的是让老百姓过得更好，不是为了出口而出口
4. **引领全球经济**：中国大市场成为世界吸引力，别人离不开我们

## 8. 一句话感悟

新发展格局就像一个人长大成人：小时候靠爸妈养（出口赚外汇），长大了自己赚钱养家（国内大循环），同时也和朋友做生意（双循环）——不是不和外人来往，而是自己站得住了。
