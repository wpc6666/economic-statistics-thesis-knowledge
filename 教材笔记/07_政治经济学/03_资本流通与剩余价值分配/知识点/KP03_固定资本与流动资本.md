# KP03 · 固定资本与流动资本

> 所属：[[../00_章节总结|第6章 资本主义流通]] ｜ 节：原书第六章第二节

## 1. 一句话先懂（小白版）

王老板开店的钱分两种：

- **机器、装修**：能用 3 年，价值一点点分摊到每杯奶茶里。这叫**固定资本**——它不离开老板，只是慢慢转移价值。
- **茶叶、牛奶、工资**：买进来一次用完，下个月再买。这叫**流动资本**——一次周转就回来。

**为什么要这么分？** 因为它影响周转速度。固定资本占比大的店（如船厂、重工厂），一年转不了几圈；流动资本占比大的店（如奶茶店、外卖），一年转很多圈。

## 2. 严格定义

| 分类 | 含义 | 价值周转方式 |
|---|---|---|
| **固定资本** | 以厂房、机器、设备、工具等劳动资料形式存在的生产资本 | 价值在多次生产过程中逐步转移，实物形态长期不变 |
| **流动资本** | 以原料、燃料、辅助材料形式存在的资本 + 用于购买劳动力的可变资本 | 价值在一次生产过程中全部周转回来 |

**固定资本折旧**：固定资本按磨损程度逐步转移到产品中去的价值。

$$\text{折旧费} = \frac{\text{固定资本原始价值}}{\text{使用年限}}$$

**折旧率**：

$$\text{折旧率} = \frac{\text{年折旧费}}{\text{固定资本原始价值}} \times 100\%$$

**固定资本的两种磨损：**
- **有形磨损（物质磨损）**：机器使用磨损、自然腐蚀；
- **无形磨损（精神磨损）**：新机器出现，旧机器贬值（哪怕它还能用）。

## 3. 为什么（原理/机制）——完整推导

### 两种划分的交叉关系

很多人搞混"不变资本/可变资本"和"固定资本/流动资本"。其实它们是**按不同标准划分的**：

| | 属于不变资本 c | 属于可变资本 v |
|---|---|---|
| **固定资本** | 机器、厂房、设备 | （无） |
| **流动资本** | 原料、燃料、辅助材料 | 工资 |

- 机器：是 c，也是固定资本；
- 原料：是 c，但是流动资本；
- 工资：是 v，也是流动资本。

**为什么要做这两种划分？**
- c/v 划分：揭示剩余价值的真正来源（v 才创造 m）；
- 固定/流动划分：揭示周转速度的差异（固定资本慢、流动资本快）。

### 折旧怎么计算？

王老板买封口机 6000 元，能用 3 年：

- 每年折旧费 = 6000/3 = 2000 元；
- 每月折旧费 = 2000/12 ≈ 167 元；
- 每杯奶茶分摊的机器折旧 = 167/1100 ≈ 0.15 元。

这 0.15 元加到每杯奶茶成本里，是 c 的一部分。3 年后机器报废，王老板账上已经攒了 6000 元折旧基金，可以买新机器。

### 无形磨损为什么重要？

你 2020 年花 1 万买了一台奶茶封口机，预计用 5 年。2023 年新出了自动封口机，效率是你那台的 3 倍——你的机器虽然还能用，但已经"过时"了。资本家必须尽快把折旧提完，否则新技术一来，旧机器直接贬值。

这就是为什么企业拼命"加速折旧"——不是因为物理磨损快，而是怕精神磨损。

## 4. 来源（理论怎么来的）

古典政治经济学（斯密、李嘉图）已经区分了固定资本和流动资本，但他们把"可变资本"混在流动资本里，看不见剩余价值来源。马克思的贡献是：**保留固定/流动划分（用于分析周转），同时坚持 c/v 划分（用于揭示剥削）**。

## 5. 怎么用（现实例子）——手把手算

**题目**：王老板奶茶店：
- 封口机 6000 元，用 3 年；
- 店面装修 60000 元，用 5 年；
- 每月茶叶牛奶 4400 元；
- 月工资 5000 元。

求：
① 固定资本总额；
② 每月折旧；
③ 流动资本月周转额；
④ 如果一年 12 个月，固定资本和流动资本各自的年周转额。

**第一步：固定资本总额。**

$$\text{固定资本} = 6000 + 60000 = 66000 \text{ 元}$$

**第二步：月折旧。**

- 封口机年折旧 = 6000/3 = 2000，月折旧 = 167；
- 装修年折旧 = 60000/5 = 12000，月折旧 = 1000；
- 月折旧合计 = 167 + 1000 = **1167 元**。

**第三步：流动资本月周转额。**

$$\text{流动资本月周转} = 4400 + 5000 = 9400 \text{ 元}$$

**第四步：年周转额。**

- 固定资本年周转额 = 年折旧 = 2000 + 12000 = **14000 元**（注意：不是 66000 全转，只转折旧部分）；
- 流动资本年周转额 = 9400 × 12 = **112800 元**。

**结论**：虽然固定资本一次性投了 6.6 万，但一年只周转 1.4 万；流动资本每月 9400，一年周转 11.28 万。固定资本占压了大量资金，但周转很慢。

## 6. 什么时候不能用（边界条件）

- **固定资本 vs 流动资本的划分是生产资本内部的划分**。货币资本和商品资本（流通资本）不参与这个划分——它们是流通领域的，不是生产领域的。
- **当代新情况**：数据中心、服务器、算法投入是新型固定资本；云服务是租赁，不形成固定资本。
- **社会主义企业也要折旧管理**，但折旧基金用于更新改造，不是为私人增殖。

## 7. 容易混淆什么

| 容易混 | 区别 |
|---|---|
| 固定资本 vs 不变资本 | 固定资本只是 c 的一部分（机器厂房）；c 还包括原料（流动）。 |
| 流动资本 vs 可变资本 | 流动资本 = 原料 + 工资；v 只是工资部分。原料是 c 但属于流动资本。 |
| 有形磨损 vs 无形磨损 | 有形 = 用坏、生锈；无形 = 新技术让旧机器贬值。 |
| 折旧 vs 成本 | 折旧是固定资本价值转移到产品；成本包括折旧 + 原料 + 工资。 |

## 8. 现实意义

- **为什么重资产行业（钢铁、造船）进入门槛高？** 固定资本投几亿，一年周转不了几次。
- **为什么互联网公司是"轻资产"？** 它们不建工厂，服务器是租的，流动资本占比高，周转快。
- **为什么设备更新政策刺激经济？** 因为无形磨损让旧设备效率低，更新设备能提高劳动生产率。
- **为什么奶茶店加盟费里有"设备费"？** 那是品牌方卖固定资本给你，赚一道钱。
