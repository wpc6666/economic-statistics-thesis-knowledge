# KP04 · 共同富裕

## 1. 一句话先懂（小白版）

共同富裕不是"杀富济贫"，不是大家一样富，而是：
- **全体人民**都富裕（不是少数人）；
- **全面富裕**（物质 + 精神 + 公共服务）；
- **共建共富**（靠劳动，不是躺平）；
- **逐步共富**（不是一夜之间，是分阶段）。

## 2. 严格定义

**共同富裕**：全体人民通过辛勤劳动和相互帮助，普遍达到生活富裕富足、精神自信自强、环境宜居宜业、社会和谐和睦、公共服务普及普惠，实现人的全面发展和社会全面进步。

**阶段性目标**：
- 2025 年：居民收入增长和经济增长基本同步；
- 2035 年：全体人民共同富裕取得更为明显的实质性进展；
- 本世纪中叶：全体人民共同富裕基本实现。

## 3. 为什么

- 资本主义按价值规律自发作用必然两极分化；
- 社会主义要在尊重效率的同时，用制度安排遏制分化；
- 共同富裕是社会主义本质要求。

## 4. 怎么用

- 脱贫攻坚（消除绝对贫困）；
- 浙江共同富裕示范区；
- 三次分配（慈善）；
- 反垄断、规范资本无序扩张。

## 5. 容易混淆什么

| 容易混 | 区别 |
|---|---|
| 共同富裕 vs 平均主义 | 共同富裕不是平均，允许合理差距。 |
| 共同富裕 vs 同时富裕 | 不是所有人同时富，有先富带后富。 |
| 三次分配 vs 强制转移 | 三次分配靠慈善自愿，不是强制。 |
