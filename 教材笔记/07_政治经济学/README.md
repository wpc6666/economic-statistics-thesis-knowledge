## 这门课在讲什么（一句话）

政治经济学不是"政治 + 经济学"，而是**研究"生产关系"的学问**——简单说就是：**东西是谁生产的、生产出来归谁分、钱和资本在谁手里转、老板凭什么拿走一大块、打工人创造的价值去哪了**。

它和你以后会学的《西方经济学》（微观/宏观）是**两套完全不同的世界观**：

| 问题 | 西方经济学（新古典） | 马克思主义政治经济学 |
|---|---|---|
| 价值从哪来 | 效用（东西让我爽不爽） | 劳动（人花了多少社会必要劳动时间） |
| 利润是什么 | 资本、土地、劳动各自的"边际贡献" | 工人创造的、被资本家无偿占有的**剩余价值** |
| 工资是什么 | 劳动的价格（供需决定） | 劳动力商品的价格（≠劳动创造的价值） |
| 为什么会有经济危机 | 市场失灵、外部冲击 | 生产社会化 vs 生产资料私人占有的**必然矛盾** |
| 研究对象 | 资源如何配置 | 生产关系如何演变 |

> 跨课程对照：[[../06_西方经济学/README|06 西方经济学]]（效用价值论 vs 劳动价值论）。

## 学习路线（小白顺序）

1. **先读 [[00_导论/00_章节总结]]**：搞清楚这门课"研究谁、为什么、怎么研究"，不然后面全是名词对名词。
2. **死磕 01 商品与货币**：劳动二重性是"政治经济学的枢纽"，不懂这个后面全崩。重点啃：[[01_商品与货币/知识点/KP02_劳动二重性]]。
3. **再啃 02 剩余价值生产**：这是马克思的"两大发现"之一（另一个是唯物史观）。核心链条：劳动力商品 → 劳动过程 → 价值增殖过程 → $m'=m/v$。
4. **然后 03 资本流通与分配**：把"剩余价值"这条线走完——它怎么在产业资本家、商业资本家、银行家、地主之间瓜分。
5. **最后看 04-07**：前面是"解剖麻雀"，后面是"历史趋势 + 中国现实"。

## 学习建议

- **别背定义，要推链条**。比如"剩余价值"不是背下来的，是从"劳动力商品的使用价值是劳动、劳动能创造比自身价值更大的价值"这一步一步推出来的。
- **所有抽象概念都套"奶茶店"**：本笔记大量用"老板开奶茶店雇你做奶茶"做例子。遇到不懂的，先想"换成奶茶店会怎样"。
- **和西方经济学对照着学**：同一现象两套解释，对照一次胜过背十次。
- **符号第一次出现必须搞懂**：$W$ 商品、$G$ 货币、$c$ 不变资本、$v$ 可变资本、$m$ 剩余价值、$m'$ 剩余价值率、$p'$ 利润率……本笔记每个符号第一次出现都会解释。
