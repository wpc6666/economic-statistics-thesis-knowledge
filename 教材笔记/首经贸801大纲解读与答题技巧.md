# 首经贸 801 经济学 · 大纲解读与答题技巧

> 适用科目：首都经济贸易大学 801 经济学（政治经济学 + 西方经济学各 50%）
> 参考书目：马工程《西方经济学》（第二版）、《马克思主义政治经济学概论》（第二版）
> 配套真题：每章文件夹下的「考研真题集.md」（简答+论述）和「选择题集.md」（单选巩固）

## 一、试卷结构（先搞清楚"考什么、怎么给分"）

| 题型 | 题量 | 单题分值 | 总分 | 建议字数 | 建议用时 |
|---|---|---|---|---|---|
| 简答与计算题 | 6 题 | 15 分 | 90 分 | 450–700 字 | 15 分钟/题 |
| 论述题 | 2 题 | 30 分 | 60 分 | 900–1200 字 | 30 分钟/题 |
| **合计** | **8 题** | — | **150 分** | — | **180 分钟** |

**几个关键事实：**

1. **政经、西经各占 50%**：6 道简答计算里，通常 3 道西经 + 3 道政经；2 道论述里，1 道西经 + 1 道政经。
2. **不能用计算器**：计算题只考简单数（弹性、乘数、剩余价值率、消费者均衡），数字设计成整数或简单分数。
3. **论述题跨章节**：不考单一知识点，往往是"用 IS-LM/AD-AS 分析当前某政策""用马克思主义政治经济学分析某现象"。
4. **必须关注宏观经济形势**：大纲明确要求"关注中国宏观经济形势、近两年国内外重要经济事件、当年中央政府文件"。

## 三、答题模板（直接套用）

### 3.1 名词解释（5 分题，150–200 字）

**通用模板：**
> 定义 + 公式/图示 + 条件/特征 + 原因 + 分类 + 影响/意义 + 举例

**三类变体：**
- 定义类（含公式）：定义 + 公式 + 拓展（如需求交叉弹性）
- 定义类（含图示）：定义 + 图示 + 拓展（如需求价格弧弹性）
- 定理类：定理内容 + 拓展（如福利经济学第一定理）
- 现象类：现象解释 + 拓展（如"薄利多销"）

### 3.2 简答题（15 分，450–700 字）

**九大题型对应模板：**

| 题型 | 答题骨架 |
|---|---|
| 概念简答 | 定义 → 公式/图形 → 特征/条件 → 举例 |
| 关系对比 | A 是什么 → B 是什么 → 相同点 → 不同点（表格）→ 联系 |
| 原因分析 | 现象 → 原因 ①②③ → 总结 |
| 因素影响 | 概念 → 影响因素 ①②③ → 每因素怎么作用 → 现实意义 |
| 影响结果 | 概念 → 传导机制（第一步…第二步…）→ 经济后果 → 政策含义 |
| 解决对策 | 问题表现 → 原因 → 对策 ①②③（对应原因）→ 评价 |
| 经济现象 | 现象描述 → 用哪个理论解释 → 理论展开 → 结论 |
| 模型分析 | 模型假设 → 图形/公式 → 均衡解 → 比较静态 → 政策含义 |
| 分析推导 | 已知条件 → 第一步推… → 第二步推… → 结论（不跳步） |

**数字序号踩分（阅卷老师一眼看踩分点）：**
> 一、（一级标题）
> （一）（二级）
> 1.（三级）
> （1）（四级）
> ①（五级）

### 3.3 论述题（30 分，900–1200 字）

**三大类型：**

#### 类型一：理论类（"试述 XX 理论及其现实意义"）

骨架：
1. **破题定义**（4 分）：这个理论是什么、解决什么问题
2. **理论展开**（8 分）：假设 → 模型 → 结论，分 2–3 段
3. **图形/公式**（6 分）：画出来、标坐标轴、说明线怎么移
4. **现实意义**（8 分）：用中国实际经济现象佐证
5. **评价/局限**（4 分）：理论边界、哪些假设不现实、后来怎么发展的

#### 类型二：政策效应类（"用 XX 模型分析 YY 政策对 ZZ 的影响"）

骨架：
1. **政策是什么**（3 分）
2. **用什么模型**（3 分）：明确写出 IS-LM / AD-AS / 蒙代尔-弗莱明 / 劳动价值论
3. **传导机制**（10 分）：政策工具 → 曲线怎么移 → 新均衡 → 各变量怎么变
4. **政策效果评价**（8 分）：在什么条件下有效、什么条件下失效（如流动性陷阱）
5. **中国实际**（6 分）：结合 2024–2026 年中国政策（积极财政+适度宽松货币、房地产、地方债、双循环）

#### 类型三：现象类（"如何看待 XX 经济现象"）

骨架：
1. **现象描述**（3 分）：这是什么、数据/事实
2. **用哪个理论解释**（5 分）：选 1–2 个理论工具
3. **理论分析**（10 分）：机制传导
4. **多维度展开**（8 分）：对消费者/企业/政府/对外的影响
5. **对策/展望**（4 分）：应该怎么办
6. **站位升华**（4 分）：马克思主义视角或中国式现代化视角（政经题必写）

## 四、字数与时间控制

**铁律：1 分 ≈ 30–40 字。**

- 15 分简答：450–700 字，15 分钟写完（约 40 字/分钟手速）
- 30 分论述：900–1200 字，30 分钟写完

**不要犯的错：**
- 看到一道简答会写就使劲写，挤占论述时间 → **先在草稿纸列框架，再动笔**
- 论述只写理论不结合中国实际 → 直接扣 5–8 分
- 简答只写定义不展开 → 撑死拿 5 分

## 五、卷面与排版技巧（阅卷人视角）

1. **一页纸写 2 道简答或 1 道论述**：不要一道题写满两页，让老师来回翻。
2. **页边距**：四周留一指宽，不要顶格写。
3. **题目间隔**：题与题之间空 1–2 行；同一题多小问之间空 2–3 行。
4. **踩分点单独成行**：核心定义、公式、结论**单独占一行加粗或下划线**，让老师一眼扫到。
5. **写错字**：划一道斜线继续写，不要涂黑疙瘩，不要整行划掉。
6. **答卷下方标页码**：第 X 页 / 共 Y 页。

## 六、计算题高频公式清单（必背）

### 西经

| 公式 | 用于 |
|---|---|
| 需求价格弹性 $e_d = \frac{\Delta Q}{\Delta P}\cdot\frac{P}{Q}$ | 弹性计算 |
| 弧弹性中点法 $\frac{Q_2-Q_1}{(Q_1+Q_2)/2} \div \frac{P_2-P_1}{(P_1+P_2)/2}$ | 一段区间弹性 |
| 消费者均衡 $\frac{MU_1}{P_1} = \frac{MU_2}{P_2} = \lambda$ | 最优购买量 |
| 厂商均衡 $MR = MC$ | 利润最大化 |
| 完全竞争 $P = MC$（长期） | 长期均衡 |
| 投资乘数 $k = \frac{1}{1-MPC} = \frac{1}{MPS}$ | 国民收入决定 |
| 政府购买乘数 $k_g = \frac{1}{1-MPC}$ | 三部门 |
| 税收乘数 $k_t = \frac{-MPC}{1-MPC}$ | 三部门 |
| 平衡预算乘数 $k_b = 1$ | 三部门 |
| 货币乘数 $m = \frac{1+cr}{rr+cr}$ | 货币供给 |
| 索洛稳态 $s\cdot f(k) = (n+\delta)k$ | 增长 |
| 黄金律 $MPK = n+\delta$ | 消费最大化 |

### 政经

| 公式 | 用于 |
|---|---|
| 剩余价值率 $m' = \frac{m}{v} = \frac{\text{剩余劳动时间}}{\text{必要劳动时间}}$ | 剥削程度 |
| 年剩余价值率 $M' = m' \cdot n$（n 为年周转次数） | 年剥削程度 |
| 生产价格 = 成本价格 $(c+v)$ + 平均利润 | 利润转化 |
| 简单再生产实现条件 Ⅰ$(v+m)$ = Ⅱ$c$ | 两大部类交换 |
| 扩大再生产实现条件 Ⅰ$(v+\Delta v + \frac{m}{x})$ = Ⅱ$(c+\Delta c)$ | 扩大再生产 |

## 七、复习节奏建议
