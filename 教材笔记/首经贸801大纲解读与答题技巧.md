## 二、名词解释答题模板（3 类）

**通用骨架**：定义/定理/现象解释 + 公式/图示 + 条件/特征 + 原因 + 分类 + 影响/意义 + 举例。

| 类型 | 骨架 | 举例 |
|---|---|---|
| **定义类（含公式）** | 定义 + 公式 + 拓展 | 需求交叉价格弹性 |
| **定义类（含图示）** | 定义 + 图示 + 拓展 | 需求价格弧弹性 |
| **定义类（纯文字）** | 定义 + 拓展 | 供给 |
| **定理类** | 定理内容 + 拓展 | 福利经济学第一定理 |
| **现象类** | 现象解释 + 拓展 | 薄利多销、谷贱伤农 |

## 三、简答题 9 大题型 + 答题模板

每道简答题属于以下 9 类之一，套用对应骨架：

| # | 题型 | 答题骨架 |
|---|---|---|
| 1 | **概念简答** | 定义 → 公式/图形 → 特征/条件 → 举例 |
| 2 | **关系对比** | A 是什么 → B 是什么 → 相同点 → 不同点（表格）→ 联系 |
| 3 | **原因分析** | 现象 → 原因 ①②③ → 总结 |
| 4 | **因素影响** | 概念 → 影响因素 ①②③ → 每因素怎么作用 → 现实意义 |
| 5 | **影响结果** | 概念 → 传导机制（第一步…第二步…）→ 经济后果 → 政策含义 |
| 6 | **解决对策** | 问题表现 → 原因 → 对策 ①②③（对应原因）→ 评价 |
| 7 | **经济现象** | 现象描述 → 用哪个理论解释 → 理论展开 → 结论 |
| 8 | **模型分析** | 模型假设 → 图形/公式 → 均衡解 → 比较静态 → 政策含义 |
| 9 | **分析推导** | 已知条件 → 第一步推… → 第二步推… → 结论（不跳步） |

**首经贸真题风格示例**：
- "运用基尼系数和库兹涅茨曲线说明一国收入分配不平等的状况和变化趋势"（模型分析 + 现象）
- "用马克思主义政治经济学阐述资本主义扩大再生产的实现条件及其在现实经济中经常遭到破坏的原因"（分析推导 + 原因）
- "已知消费者效用函数 U=3X₁X₂²，求最优购买量"（分析推导/计算）

## 四、论述题 3 大类型 + 答题模板

论述题跨章节考，30 分/900–1200 字/30 分钟。

### 类型一：理论类（单一理论、理论及结论分析、对比分析）

骨架：
1. **破题定义**（4 分）：这个理论是什么、解决什么问题
2. **理论展开**（8 分）：假设 → 模型 → 结论，分 2–3 段
3. **图形/公式**（6 分）：画出来、标坐标轴、说明线怎么移
4. **现实意义**（8 分）：用中国实际经济现象佐证
5. **评价/局限**（4 分）：理论边界、哪些假设不现实、后来怎么发展的

### 类型二：政策效应类（政策及组合效果、政策比较）—— 主要在宏观章

骨架：
1. **政策是什么**（3 分）：政策工具、力度、出台背景
2. **用什么模型**（3 分）：明确写出 IS-LM / AD-AS / 蒙代尔-弗莱明 / 劳动价值论
3. **传导机制**（10 分）：政策工具 → 曲线怎么移 → 新均衡 → 各变量怎么变
4. **政策效果评价**（8 分）：在什么条件下有效、什么条件下失效（如流动性陷阱）
5. **中国实际**（6 分）：结合 2024–2026 年中国政策（积极财政+适度宽松货币、房地产、地方债、双循环）

### 类型三：现象类（理论明确、理论不明确）

骨架：
1. **现象描述**（3 分）：这是什么、数据/事实
2. **用哪个理论解释**（5 分）：选 1–2 个理论工具
3. **理论分析**（10 分）：机制传导
4. **多维度展开**（8 分）：对消费者/企业/政府/对外的影响
5. **对策/展望**（4 分）：应该怎么办
6. **站位升华**（4 分）：马克思主义视角或中国式现代化视角（政经题必写）

## 五、答题序号规范（让老师一眼看到踩分点）

```
一级：一、二、三
二级：（一）（二）（三）
三级：1. 2. 3.
四级：(1) (2) (3)
五级：① ② ③
```

**规则**：如果题目给的序号是"1."，答案从"（1）"开始，再下一级到"①"。

**踩分突出技巧**：
- 核心定义、公式、结论**单独占一行**
- 用冒号引出："**需求定律：**其他条件不变时……"
- 首行缩进，让老师一眼看到层级
- 数字序号本身就是踩分点标记

## 六、卷面注意事项

### 6.1 整体卷面

1. **分正反面**：除答题纸第一页自带内容，其余空白页自己规划位置
2. **一页纸写 2 道简答或 1 道论述**：避免老师来回翻
3. **页边距**：上下左右各留一指宽，美观 + 防扫描遗漏
4. **题目间隔**：题与题之间空 1–2 行；同一题多小问之间空 2–3 行
5. **行间距**：不要挤在一起，平时用白纸练习

### 6.2 书写

- 尽量工整、平行书写
- 写错字用 `/` 划掉继续写，**不要涂黑疙瘩、不要整行划掉**
- **答卷下方标页码**：第 X 页 / 共 Y 页（自命题答题卡必写）

### 6.3 踩分点位置

老师不逐字读，直接找踩分点。答案结构必须是：
> **先定义阐释 → 再加图形/公式说明 → 最后拓展/总结**

## 七、高频公式清单（必背）

### 西经

| 公式 | 用于 |
|---|---|
| 需求价格弹性 $e_d = \frac{\Delta Q}{\Delta P}\cdot\frac{P}{Q}$ | 弹性计算 |
| 弧弹性中点法 $\frac{Q_2-Q_1}{(Q_1+Q_2)/2} \div \frac{P_2-P_1}{(P_1+P_2)/2}$ | 一段区间弹性 |
| 消费者均衡 $\frac{MU_1}{P_1} = \frac{MU_2}{P_2} = \lambda$ | 最优购买量 |
| 厂商均衡 $MR = MC$ | 利润最大化 |
| 完全竞争长期均衡 $P = MC = \min AC$ | 长期均衡 |
| 投资乘数 $k = \frac{1}{1-MPC} = \frac{1}{MPS}$ | 国民收入决定 |
| 政府购买乘数 $k_g = \frac{1}{1-MPC}$ | 三部门 |
| 税收乘数 $k_t = \frac{-MPC}{1-MPC}$ | 三部门 |
| 平衡预算乘数 $k_b = 1$ | 三部门 |
| 货币乘数 $m = \frac{1+cr}{rr+cr}$ | 货币供给 |
| 索洛稳态 $s\cdot f(k) = (n+\delta)k$ | 增长 |
| 黄金律 $MPK = n+\delta$ | 消费最大化 |

### 政经

| 公式 | 用于 |
|---|---|
| 剩余价值率 $m' = \frac{m}{v} = \frac{\text{剩余劳动时间}}{\text{必要劳动时间}}$ | 剥削程度 |
| 年剩余价值率 $M' = m' \cdot n$（n 为年周转次数） | 年剥削程度 |
| 生产价格 = 成本价格 $(c+v)$ + 平均利润 | 利润转化 |
| 简单再生产实现条件 Ⅰ$(v+m)$ = Ⅱ$c$ | 两大部类交换 |
| 扩大再生产实现条件 Ⅰ$(v+\Delta v + \frac{m}{x})$ = Ⅱ$(c+\Delta c)$ | 扩大再生产 |
