## 二、名词解释答题模板（3 类）

**通用骨架**：定义/定理/现象解释 + 公式/图示 + 条件/特征 + 原因 + 分类 + 影响/意义 + 举例。

| 类型 | 骨架 | 举例 |
|---|---|---|
| **定义类（含公式）** | 定义 + 公式 + 拓展 | 需求交叉价格弹性 |
| **定义类（含图示）** | 定义 + 图示 + 拓展 | 需求价格弧弹性 |
| **定义类（纯文字）** | 定义 + 拓展 | 供给 |
| **定理类** | 定理内容 + 拓展 | 福利经济学第一定理 |
| **现象类** | 现象解释 + 拓展 | 薄利多销、谷贱伤农 |

**政经名词解释特殊模板**：
- 概念定义 → 体现的生产关系 → 历史进步性/局限性 → 现实意义
- 例：「剩余价值」——定义（m 是雇佣工人创造的被资本家无偿占有的超过劳动力价值的价值）→ 体现的剥削关系 → 剩余价值规律是资本主义基本经济规律

## 三、简答题 9 大题型 + 答题模板

每道简答题属于以下 9 类之一，套用对应骨架：

| # | 题型 | 答题骨架 |
|---|---|---|
| 1 | **概念简答** | 定义 → 公式/图形 → 特征/条件 → 举例 |
| 2 | **关系对比** | A 是什么 → B 是什么 → 相同点 → 不同点（表格）→ 联系 |
| 3 | **原因分析** | 现象 → 原因 ①②③ → 总结 |
| 4 | **因素影响** | 概念 → 影响因素 ①②③ → 每因素怎么作用 → 现实意义 |
| 5 | **影响结果** | 概念 → 传导机制（第一步…第二步…）→ 经济后果 → 政策含义 |
| 6 | **解决对策** | 问题表现 → 原因 → 对策 ①②③（对应原因）→ 评价 |
| 7 | **经济现象** | 现象描述 → 用哪个理论解释 → 理论展开 → 结论 |
| 8 | **模型分析** | 模型假设 → 图形/公式 → 均衡解 → 比较静态 → 政策含义 |
| 9 | **分析推导** | 已知条件 → 第一步推… → 第二步推… → 结论（不跳步） |

**首经贸真题风格示例**：
- "运用基尼系数和库兹涅茨曲线说明一国收入分配不平等的状况和变化趋势"（模型分析 + 现象）
- "用马克思主义政治经济学阐述资本主义扩大再生产的实现条件及其在现实经济中经常遭到破坏的原因"（分析推导 + 原因）
- "已知消费者效用函数 U=3X₁X₂²，求最优购买量"（分析推导/计算）

### 3.1 政经简答 vs 西经简答的侧重差异

| 维度 | 政治经济学简答 | 西方经济学简答 |
|---|---|---|
| 核心 | 生产关系、剥削、制度分析 | 资源配置、行为主体、市场均衡 |
| 答题重点 | 概念内涵 → 体现的生产关系 → 历史作用/局限 → 现实意义 | 假设 → 模型/图形 → 结论 → 政策含义 |
| 必须有 | 马克思主义立场、阶级分析 | 数学推导、图形移动方向 |
| 常见题型 | 概念简答、原因分析、现象解释 | 模型分析、因素影响、计算推导 |
| 易丢分 | 只背定义不分析生产关系 | 只背结论不推导、不画图形 |

## 四、论述题 3 大类型 + 答题模板

论述题跨章节考，30 分/900–1200 字/30 分钟。

### 类型一：理论类（单一理论、理论及结论分析、对比分析）

骨架：
1. **破题定义**（4 分）：这个理论是什么、解决什么问题
2. **理论展开**（8 分）：假设 → 模型 → 结论，分 2–3 段
3. **图形/公式**（6 分）：画出来、标坐标轴、说明线怎么移
4. **现实意义**（8 分）：用中国实际经济现象佐证
5. **评价/局限**（4 分）：理论边界、哪些假设不现实、后来怎么发展的

**适用场景**：政经（劳动价值论、剩余价值论、资本积累）；西经（消费者行为、市场失灵、经济增长）。

### 类型二：政策效应类（政策及组合效果、政策比较）—— 主要在宏观章

骨架：
1. **政策是什么**（3 分）：政策工具、力度、出台背景
2. **用什么模型**（3 分）：明确写出 IS-LM / AD-AS / 蒙代尔-弗莱明 / 劳动价值论
3. **传导机制**（10 分）：政策工具 → 曲线怎么移 → 新均衡 → 各变量怎么变
4. **政策效果评价**（8 分）：在什么条件下有效、什么条件下失效（如流动性陷阱）
5. **中国实际**（6 分）：结合 2024–2026 年中国政策（积极财政+适度宽松货币、房地产、地方债、双循环）

**首经贸高频政策类论述考点**：
- 财政政策与货币政策组合（IS-LM）
- 供给侧结构性改革（AD-AS、增长模型）
- 收入分配政策（生产要素分配、劳动价值论）
- 对外开放与人民币汇率（蒙代尔-弗莱明模型）

### 类型三：现象类（理论明确、理论不明确）

骨架：
1. **现象描述**（3 分）：这是什么、数据/事实
2. **用哪个理论解释**（5 分）：选 1–2 个理论工具
3. **理论分析**（10 分）：机制传导
4. **多维度展开**（8 分）：对消费者/企业/政府/对外的影响
5. **对策/展望**（4 分）：应该怎么办
6. **站位升华**（4 分）：马克思主义视角或中国式现代化视角（政经题必写）

**政经现象题站位升华模板**：
> "当代资本主义的新变化没有改变资本主义的根本性质，生产社会化与生产资料资本主义私人占有之间的矛盾仍然是基本矛盾。我国坚持以人民为中心的发展思想，推动共同富裕，是社会主义制度优越性的体现。"

**西经现象题对策模板**：
> "市场失灵需要政府干预，但政府干预也可能失灵。应当在让市场在资源配置中起决定性作用的前提下，更好发挥政府作用，实现有效市场与有为政府的结合。"

## 五、答题序号规范（让老师一眼看到踩分点）

```
一级：一、二、三
二级：（一）（二）（三）
三级：1. 2. 3.
四级：(1) (2) (3)
五级：① ② ③
```

**规则**：如果题目给的序号是"1."，答案从"（1）"开始，再下一级到"①"。

**踩分突出技巧**：
- 核心定义、公式、结论**单独占一行**
- 用冒号引出："**需求定律：**其他条件不变时……"
- 首行缩进，让老师一眼看到层级
- 数字序号本身就是踩分点标记

## 六、卷面注意事项

### 6.1 整体卷面

1. **分正反面**：除答题纸第一页自带内容，其余空白页自己规划位置
2. **一页纸写 2 道简答或 1 道论述**：避免老师来回翻
3. **页边距**：上下左右各留一指宽，美观 + 防扫描遗漏
4. **题目间隔**：题与题之间空 1–2 行；同一题多小问之间空 2–3 行
5. **行间距**：不要挤在一起，平时用白纸练习

### 6.2 书写

- 尽量工整、平行书写
- 写错字用 `/` 划掉继续写，**不要涂黑疙瘩、不要整行划掉**
- **答卷下方标页码**：第 X 页 / 共 Y 页（自命题答题卡必写）

### 6.3 踩分点位置

老师不逐字读，直接找踩分点。答案结构必须是：
> **先定义阐释 → 再加图形/公式说明 → 最后拓展/总结**

## 九、数字经济专题答题框架（首经贸新热点）

### 9.1 数据要素×政治经济学

**核心逻辑**：数据不是"无中生有"，其价值源泉仍然是活劳动。

答题骨架：
1. **数据要素的地位**：2020年中央列为第七大生产要素
2. **劳动二重性分析**：
   - 具体劳动：数据采集、标注、RLHF排序 → 转移旧价值、创造使用价值
   - 抽象劳动：标注员、算法工程师的脑力耗费 → 形成新价值
3. **用户免费劳动**：浏览、点赞、评论 → 产消合一 → 未付酬活劳动被平台无偿占有
4. **结论**：数据要素不违背劳动价值论，"AI自动创造价值"是拜物教翻版

### 9.2 平台经济×西方经济学

**核心逻辑**：平台是双边市场，有网络效应、规模经济、数据垄断特征。

答题骨架：
1. **平台市场结构**：双边市场、网络效应、自然垄断倾向
2. **市场失灵表现**：垄断定价、算法合谋、大数据杀熟、隐私侵犯
3. **政府监管**：反垄断、数据安全、劳动者权益保护
4. **中国实际**：平台经济常态化监管，促进健康发展

### 9.3 AI就业×宏观经济学

**核心逻辑**：AI是技能偏向型技术进步（SBTC），替代低技能、补充高技能，加剧收入分化。

答题骨架：
1. **SBTC理论**：AI提高高技能劳动需求，压低低技能工资
2. **结构性失业 vs 摩擦性失业**：哪些岗位被替代、哪些新岗位产生
3. **收入分配影响**：劳动份额下降、资本份额上升、技能溢价扩大
4. **政策应对**：终身学习、社会保障、再分配调节

## 十、答题常见错误与避坑指南

### 10.1 十大常见丢分点

| 错误 | 后果 | 正确做法 |
|---|---|---|
| ① 只写定义不展开 | 得3-4分，丢一半 | 定义后接公式/图形/原因/举例 |
| ② 不画图形 | 模型题丢6-8分 | 文字描述坐标轴、曲线位置、移动方向 |
| ③ 推导跳步 | 计算题丢步骤分 | 每步写清：已知→用什么公式→代入→结果 |
| ④ 序号混乱 | 老师找不到踩分点 | 严格按一、（一）、1、(1)、①层级 |
| ⑤ 只写理论不联系实际 | 论述题丢"现实意义"分 | 每道论述至少结合1个中国经济现象 |
| ⑥ 政经题不站马克思主义立场 | 政经论述丢4分 | 结尾升华：资本主义矛盾/社会主义优越性 |
| ⑦ 西经题不写假设条件 | 模型题丢"前提"分 | 先写：在XX假设下，模型结论成立 |
| ⑧ 字数不够 | 简答<300字、论述<600字 | 简答450-700字，论述900-1200字 |
| ⑨ 时间分配失衡 | 简答写太久，论述没写完 | 简答15分钟、论述30分钟严格计时 |
| ⑩ 不标页码 | 自命题答题卡漏页扣分 | 每题写完标：第X页/共Y页 |

### 10.2 计算题避坑

- 所有计算都是整数或简单分数（闭卷不让用计算器）
- 必须写公式、代入过程、单位
- 结果保留2位小数即可
- 最后用一句话解释经济含义

### 10.3 政经题特殊避坑

- 不要用西经的"效用""理性人"框架分析政经题
- 必须用"生产关系""剥削""剩余价值"这些马克思主义范畴
- 评价资本主义制度时要辩证：历史进步性 + 历史局限性

## 十一、复习节奏

1. **第一轮（–10 月底）**：过 KP 知识点 + 做每章「选择题集」巩固概念
2. **第二轮（11 月）**：做每章「考研真题集」的简答题，对照参考答案背框架
3. **第三轮（12 月上旬）**：专攻论述题，练跨章节组合、结合当年热点
4. **考前一周**：默写本文档模板和公式清单，限时手写 2 套模拟卷

## 十二、配套真题索引

每章文件夹下都有：
- **考研真题集.md**：8–12 道简答 + 3–5 道论述，每题七要素（考什么/答题框架/参考答案/解析/生活实例/双链接），并标注【建议字数】【建议时间】【题型分类】
- **选择题集.md**：每个知识点 8–10 道单选，用于快速巩固

6套完整模拟卷在「教材笔记/模拟卷/」目录下。

从每个 KP 文件末尾的「📝 考研真题」板块可以直达对应题目。
