## 🎯 这是什么？

这是一个**完全自包含**的经济统计学论文写作知识库，包含：

- 📖 **5门核心课程**：综合评价、计量经济学、时间序列分析、多元统计分析、统计学原理
- 📝 **637个详细笔记**：每个知识点都有概念解释、公式推导、生活实例、什么时候用、为什么不用其他
- 🗺️ **67个SVG思维导图**：每章一张知识树，一眼掌握全章结构
- 🔗 **6230个双向链接**：从任意知识点出发，能跳到相关知识点、相关章节、相关模块
- 📊 **完整论文写作指南**：从选题到答辩，全套流程

## 🚀 快速开始

### 如果你是小白（从没学过统计）
1. 从 [[经济统计学论文从0基础到精通/00_学前准备/README|00_学前准备]] 开始
2. 按顺序学：01_基础数学 → 02_描述统计 → 03_相关与回归
3. 每章先看SVG思维导图，再看详细笔记

### 如果你要写论文
1. 看 [[经济统计学论文从0基础到精通/11_方法选择决策/01_方法选择决策树|方法选择决策树]]
2. 找到你的题目类型，直接抄框架
3. 看 [[经济统计学论文从0基础到精通/12_毕业论文实战/|12_毕业论文实战]] 的答辩问答

### 如果你想查知识点
1. 在搜索框输入关键词（如"熵值法"、"固定效应"、"ARIMA"）
2. 点击任意笔记，顺着链接跳到相关知识点

### 如果你想写科研论文
2. 涵盖：选题、论文写作、绘图、Vibe Research、案例剖析

### 1. 小白友好
- 每个概念都有**生活比喻**（如"贝塞尔修正=打95折"）
- 每个公式都有**为什么用这个**的解释

- 每种套路都有**答辩常问**（直接背）

### 3. 双向链接
- 6230个wikilink，从任意知识点跳到相关知识点

- 涵盖：选题、论文写作、绘图、Vibe Research、案例剖析
