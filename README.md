## 这是什么

一个**完全自包含**的经济统计学论文写作知识库。不依赖外部链接，不要求任何前置基础，打开就能学。

每个知识点都按同一个套路写：**概念定义 → 原理推导 → 公式 → 图形直觉 → 生活实例 → 常见误区 → 可迁移模型**。不堆术语，每一步都讲"为什么是这样、什么时候能用、什么时候不能用"。

它同时是三样东西：

1. **一门从零开始的论文写作课**——16 个模块，从微积分基础一路讲到答辩问答；
2. **一套七门课的教材笔记**——按教材章节整理，400+ 个知识点（KP）；
3. **一个在线题库**——选择题、简答题、论述题、6 套模拟卷，带错题本和云端同步。

## 本地使用（Obsidian，推荐）

在线版够用，但双向链接的完整威力在 Obsidian 里才能发挥。

```bash
git clone https://github.com/wpc6666/economic-statistics-thesis-knowledge.git
```

1. 下载 [Obsidian](https://obsidian.md/)（免费）。
2. 选「Open folder as vault」，指向刚 clone 下来的目录。
3. 享受：关系图谱、反向链接、画布、全局搜索。

不需要任何插件，开箱即用。

## 题库系统说明

题库不是简单的"题目堆"，它解决两个真实问题：**记不住**和**不知道自己会不会**。

| 功能 | 说明 |
|---|---|
| 选择题 | 自动判分，当场看解析 |
| 简答 / 论述题 | 对照参考答案自己打分，练框架感 |
| 6 套模拟卷 | 成套计时训练，含一套数字经济专题 |
| **错题本** | 做错的题自动进错题本 |
| **过关规则** | 同一道题**连续答对 3 次**才算掌握，否则打回重练 |
| **随机练习** | 从错题本随机抽题，避免按顺序背答案 |
| **云端同步** | 注册账号后进度存 Supabase，手机 / 电脑多端通用 |

做题建议：先按章节刷选择题找手感，再用简答论述搭框架，最后两周掐时间做模拟卷。

## 怎么用最省事

- **从没学过统计**：从 `00_学前准备` 开始，按顺序读到 `03_相关与回归`，别急。
- **要写毕业论文**：直接跳到 `11_方法选择决策`，对号入座找套路，再去 `12_毕业论文实战` 看答辩问答。
- **考研复习**：打开在线答题，章节题 → 错题本 → 模拟卷。
- **只想查一个词**：网页右上角搜索框输关键词（如"熵值法""固定效应""ARIMA"），点进去顺着链接跳。
