## 🚀 快速开始

### 从没学过统计 —— 按顺序学

1. 从 [00_学前准备](经济统计学论文从0基础到精通/00_学前准备/) 开始
2. 按顺序：`01_基础数学` → `02_描述统计` → `03_相关与回归`
3. 每章先看 SVG 思维导图，再看详细笔记

### 要写论文 —— 直接抄框架

1. 打开 [11_方法选择决策](经济统计学论文从0基础到精通/11_方法选择决策/)
2. 找到你的题目类型，套对应框架
3. 到 [12_毕业论文实战](经济统计学论文从0基础到精通/12_毕业论文实战/) 看答辩问答

### 只想查知识点

在网页右上角搜索框输入关键词（如「熵值法」「固定效应」「ARIMA」），
点进任意笔记后顺着链接跳转。

## 🛠 使用方式

### 用 Obsidian 打开（推荐）

1. 下载 [Obsidian](https://obsidian.md/)
2. 把本仓库文件夹作为 Vault 打开
3. 享受双向链接、关系图谱、SVG 导图

```bash
git clone https://github.com/wpc6666/economic-statistics-thesis-knowledge.git
# Obsidian → Open folder as vault → 选择该目录
```

### 用网页阅读

👉 <https://wpc6666.github.io/economic-statistics-thesis-knowledge/>

支持目录跳转、wikilink 跳转、公式渲染、**手机竖屏适配**。
