## 本章学习心法

### 第一，只补用得到的

上一章（03_[[03_数学要补到什么程度|数学要补到什么程度]]）已经划好了边界：
- **要会算**：初中代数、[[03_求和号Σ是什么|求和号]]、均值方差、代入求导结果、简单概率；
- **要会认**：函数图像、矩阵向量、希腊字母；
- **完全不用**：ε-δ 极限、特征值推导、测度论、各种证明。

**遇到定理证明直接跳过，只记结论。**

### 第二，每个数字都亲手算一遍

这一章每节都有"完整数字例子"。别光看，拿纸笔跟着算。看懂和会算，差着十万八千里。

### 第三，建立"生活比喻库"

- 函数 = 售货机；
- 导数 = 开车瞬时速度；
- 矩阵 = 一张 Excel 表；
- 期望 = 赌场长期平均输赢；
- 方差 = 波动大小；
- [[07_正态分布|正态分布]] = 钟形曲线。

**以后看到公式，先想比喻，再看符号。**

## 本章总图：这些数学怎么串起来

```mermaid
graph TD
    F["函数 y=f(x)<br>输入→输出"] --> D["导数<br>函数在某点的变化率"]
    F --> SUM["求和号 Σ<br>把一堆数加起来"]
    SUM --> MV["均值 x̄=Σx/n<br>方差=Σ(x-x̄)²/n"]
    F --> MAT["矩阵/向量<br>把多个函数打包"]
    MAT --> REG["回归 OLS<br>β̂=(X'X)⁻¹X'y"]
    D --> MARG["经济学边际<br>边际成本=C'(x)"]
    MV --> P["概率/期望/方差"]
    P --> N["正态分布<br>68-95-99.7"]
    N --> Z["z 分数<br>(x-μ)/σ"]
    P --> REG
    Z --> REG
    REG --> PAPER["毕业论文实证"]
```

**怎么读这张图**：从最左上角"函数"出发，往右/往下看。
- 函数加个"变化率"就成了导数；
- 函数加个"求和"就成了均值方差；
- 函数打包成矩阵，再和概率、正态分布结合，就凑齐了回归 [[04_OLS截距和拟合值|OLS]] 的全部零件；
- 这些零件最后拼起来，就是你论文里的实证模型。

## 学完本章你应该达到的水平

看到下面这行公式，你不应该害怕：

$$\hat{\beta}_1 = \frac{\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y})}{\sum_{i=1}^{n}(x_i-\bar{x})^2}$$

你应该能说出：
- $\sum$ 是求和号；
- $\bar{x}$ 是 x 的均值；
- $\hat{\beta}_1$ 是斜率的估计值；
- 整个公式在算"x 和 y 的协方差除以 x 的方差"；
- 你不需要手推这个公式，但你知道每个符号在干嘛。

达到这个水平，本章就过关了。
