# 05 概率是什么？（抛硬币版）

## 一、为什么要学这个？

**生活里的真实痛点：**

天气预报说："明天降水概率 70%。"

你带不带伞？

- 70% 听起来很高，带吧；
- 但 30% 不下雨，白带了也烦；
- 到底"70%"是什么意思？是 100 个明天里有 70 个会下雨？还是气象学家有 70% 把握？

这就是概率。

经济统计里到处是概率：
- "这个回归系数在 5% 水平上显著"——5% 是概率；
- "p 值 = 0.02"——p 值是概率；
- "95% [[../../教材笔记/05_统计学原理/06_抽样与参数估计/知识点/KP10_区间估计与置信区间|置信区间]]"——95% 是概率；
- "违约概率"——风控里天天用。

**不懂概率，你就看不懂后面所有的[[KP02_假设检验|假设检验]]。**

**不学会怎样？**
- 看到 p 值就知道"小于 0.05 就是好"，但不知道为什么；
- 论文里写不出"在 5% 显著性水平下拒绝原假设"这种话；
- 被导师问"你这个 p 值 0.06 为什么不显著"，你答不上。

## 二、是什么？

### 生活比喻：概率就是"长期频率"

抛一次硬币，你不知道正面还是反面。但抛 10000 次，大概有 5000 次正面——正面出现的"频率"约 0.5。

> **概率** = 当试验次数无穷多时，某个结果出现的频率。
>
> （这种"反复试验、结果排成一个分布"的思路，正是后面 [[../../教材笔记/05_统计学原理/06_抽样与参数估计/知识点/KP05_抽样分布|抽样分布]] 的起点。）

| 试验 | 可能结果 | 概率 |
|------|----------|------|
| 抛硬币 | 正面 / 反面 | 各 0.5 |
| 掷骰子 | 1~6 点 | 各 1/6 |
| 抽牌 | 52 张 | 每张 1/52 |
| 明天天气 | 下雨 / 不下雨 | 0.7 / 0.3 |

### 严格定义

> **概率** $P(A)$：事件 A 发生的可能性大小，取值在 0 到 1 之间。
> - $P(A)=0$：不可能发生；
> - $P(A)=1$：必然发生；
> - $P(A)=0.5$：一半一半。

**两个基本规则**：
1. 所有可能事件概率加起来 = 1（比如硬币正面 0.5 + 反面 0.5 = 1）；
2. $P(\text{不发生 A}) = 1 - P(A)$。

## 三、条件概率 $P(A|B)$ 是什么？（全班考试版）

**这是全章最重要的一个概念。**

想象一个班 100 人：
- 男生 60 人，女生 40 人；
- 考试及格共 74 人，其中男生及格 48 人，女生及格 26 人。

画成一张表：

| | 及格 | 不及格 | 合计 |
|---|---|---|---|
| 男生 | 48 | 12 | 60 |
| 女生 | 26 | 14 | 40 |
| 合计 | 74 | 26 | 100 |

**问题 1：随便抽一个人，及格的概率？**
$$P(\text{及格}) = 74/100 = 0.74$$

**问题 2：已知这个人是男生，他及格的概率？**

注意，"已知是男生"——范围缩小到男生那 60 人，不再是全班 100 人。
$$P(\text{及格}|\text{男}) = 48/60 = 0.80$$

**问题 3：已知这个人是女生，她及格的概率？**
$$P(\text{及格}|\text{女}) = 26/40 = 0.65$$

**符号 $P(A|B)$ 读成"A 在 B 条件下的概率"**，意思是：已经知道 B 发生了，A 发生的概率是多少。

**公式**：
$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

套进例子：
$$P(\text{及格}|\text{男}) = \frac{P(\text{及格且男})}{P(\text{男})} = \frac{48/100}{60/100} = \frac{48}{60} = 0.80$$

**为什么经济学关心条件概率？**

因为回归分析本质上就是在问："已知受教育年限是 X，工资 Y 的条件分布是什么？"——这就是 $E(Y|X)$。

## 四、频率派 vs 贝叶斯派（一句话区别）

| 派别 | 概率是什么 | 代表人物 | 你写论文用哪个 |
|------|-----------|----------|----------------|
| 频率派 | 长期频率（抛 10000 次硬币正面占比） | 奈曼、皮尔逊 | ✅ 默认这个 |
| 贝叶斯派 | 你对事件的"信念强度"（看到新证据后更新） | 贝叶斯、拉普拉斯 | 选学 |

**一句话区别**：
- 频率派：概率 = 客观频率，硬币正面概率就是 0.5，跟你信不信无关；
- 贝叶斯派：概率 = 主观信念，"明天下雨概率 70%"是你根据气象数据更新后的信心。

**本科论文默认用频率派**（p 值、置信区间都是频率派框架下的）。贝叶斯那套是研究生以后的事。

## 五、每个符号是什么？

| 符号 | 怎么读 | 是什么 | 例子 |
|------|--------|--------|------|
| $P(A)$ | "P A" | 事件 A 发生的概率 | P(抛硬币正面)=0.5 |
| $P(A \cap B)$ | "P A 交 B" | A 和 B 同时发生 | P(及格且男)=0.48 |
| $P(A \cup B)$ | "P A 并 B" | A 或 B 发生 | P(男或女)=1 |
| $P(A\|B)$ | "P A 在 B 条件下" | 已知 B 发生，A 的概率 | P(及格\|男)=0.8 |
| $P(\neg A)$ | "P 非 A" | A 不发生 | P(不及格)=0.26 |
| $\Omega$ | "Omega" | 所有可能结果的集合 | {正, 反} |

## 六、一个完整的数字例子

**题目**：一个袋子里有 3 个红球、2 个白球。不放回抽两次。

**(1) 第一次抽到红球的概率？**
$$P(R_1) = 3/5 = 0.6$$

**(2) 已知第一次抽到红球，第二次还是红球的概率？**

第一次抽走一个红球后，袋里剩 2 红 2 白，共 4 个球。
$$P(R_2|R_1) = 2/4 = 0.5$$

**(3) 两次都抽到红球的概率？**

$$P(R_1 \cap R_2) = P(R_1) \times P(R_2|R_1) = 0.6 \times 0.5 = 0.3$$

**(4) 两次抽到不同颜色的概率？**

两种情况：先红后白 + 先白后红。
$$P(\text{不同色}) = P(R_1 W_2) + P(W_1 R_2)$$
$$= (3/5)(2/4) + (2/5)(3/4) = 6/20 + 6/20 = 12/20 = 0.6$$

**验证**：两次同色概率 = 0.3（红红）+ 0.2（白白，即 (2/5)(1/4)=0.1）= 0.4；不同色 0.6，加起来 = 1。✅

## 七、什么时候用概率？

| 场景 | 用什么概率 |
|------|-----------|
| 假设检验 | p 值 = 在原假设成立下，看到当前或更极端数据的概率 |
| [[../../教材笔记/05_统计学原理/06_抽样与参数估计/知识点/KP10_区间估计与置信区间|置信区间]] | 95% 置信区间 = 重复抽样 100 次，95 次会覆盖真实参数 |
| 回归系数显著性 | 系数 t 值对应的 p 值，小于 0.05 就显著 |
| 风控/信用评分 | 客户违约概率 P(违约|收入、年龄、贷款记录) |
| Logit 模型 | 预测 P(买车|年龄、收入、性别) |

**最后一个 Logit 模型，第 6 章会专门讲。**

---

## 八、什么时候不能用？（易错点）

1. **别赌徒谬误**。连续抛 5 次正面，第 6 次正面概率还是 0.5——硬币没有记忆。
2. **$P(A|B) \neq P(B|A)$**。P(及格|男)=0.8，但 P(男|及格)=48/74=0.65，完全不同。这叫"条件概率倒置"，新闻里经常犯。
3. **独立事件才可以乘**。抛两次硬币独立，P(正正)=0.5×0.5=0.25；但不放回抽牌不独立，第二次概率会变。
4. **别把"概率 0.5"理解成"下一次一定一半一半"**。概率是长期频率，单次试验该是啥还是啥。
5. **相关不等于独立**。两个事件相关（比如身高和体重），就不能直接用 $P(A\cap B)=P(A)P(B)$。

## 九、Python 代码（模拟抛硬币）

```python
import numpy as np

# 设随机种子，让结果可复现
np.random.seed(42)

# 抛 10000 次硬币
n = 10000
coins = np.random.choice(['正', '反'], size=n)

# 统计正面频率
p_heads = (coins == '正').mean()
print(f"抛 {n} 次硬币，正面频率 = {p_heads:.4f}")

# 模拟全班考试例子
# 男生 60 人：48 及格 12 不及格
# 女生 40 人：26 及格 14 不及格
boys_pass = 48
boys_fail = 12
girls_pass = 26
girls_fail = 14

p_pass_given_boy = boys_pass / (boys_pass + boys_fail)
p_pass_given_girl = girls_pass / (girls_pass + girls_fail)

print(f"P(及格|男) = {p_pass_given_boy:.2f}")   # 0.80
print(f"P(及格|女) = {p_pass_given_girl:.2f}")   # 0.65
```

**输出怎么读**：抛 10000 次硬币，正面频率约 0.5——这就是"概率=长期频率"。条件概率算出来 0.80 和 0.65，和手算一致。

## 十、和别的概念对比

| 概念 | 是什么 | 例子 |
|------|--------|------|
| 概率 | 事件发生可能性 | P(下雨)=0.7 |
| 频率 | 历史出现次数占比 | 过去 100 天有 70 天下雨 |
| 似然 | 反过来：已知结果，参数多可能 | 看到 70 天下雨，"真概率是 0.7"的可能性 |
| 胜率 | $P(A)/(1-P(A))$ | Logit 模型里用 |

---

## 十一、速记卡

> **概率 = 长期频率，取值 0 到 1。**
> $P(A|B)$ = 已知 B 发生时 A 的概率，别和 $P(B|A)$ 搞混。
> $P(A|B) = P(A\cap B)/P(B)$，就这一个公式。
> 本科论文用频率派（p 值、置信区间），贝叶斯以后再说。
> 回归本质是在研究 $E(Y|X)$——给定 X，Y 的条件期望。
