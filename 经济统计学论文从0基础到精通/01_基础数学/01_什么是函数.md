# 01 什么是函数？（数学白痴版）

## 一、为什么要学这个？

**你这辈子已经用过函数无数次了，只是不知道它叫"函数"。**

- 打车：输入"距离 10 公里"，输出"28 元"——这就是函数；
- 点奶茶：输入"中杯 + 珍珠 + 三分糖"，输出"18 元"——这就是函数；
- 工资：输入"工作年限 5 年"，输出"月工资 1 万"——这就是函数；

**整个经济学和统计学，本质上就是在找各种各样的"输入→输出"关系。**

- 输入：教育年限 → 输出：工资（这就是后面的回归）；
- 输入：利率 → 输出：投资量（这就是 IS-LM 模型）；
- 输入：广告投入 → 输出：销量（这就是市场营销要建的模型）。

**不学会怎样？**
后面每一章都会出现 $y = f(x)$ 这种写法，你会以为是天书。
其实它就是"输入 x，输出 y"的另一种写法，跟你打车计价没区别。

---

## 二、是什么？

### 生活比喻：函数就是一台自动售货机

想象一台售货机：

```
你投进硬币（输入 x）
        ↓
   [售货机内部规则 f]
        ↓
掉出一瓶可乐（输出 y）
```

**函数 f** = 这台售货机内部的规则。
**输入 x** = 你投的东西。
**输出 y = f(x)** = 掉出来的东西。

**关键性质**：**同一个输入，永远对应同一个输出。**
（你投 5 块钱，它不可能今天掉可乐明天掉汉堡——那才叫函数；如果它心情好掉可乐、心情不好掉矿泉水，那不是函数，是抽奖。）

### 严格定义

> **函数** $y = f(x)$：对于每一个输入值 $x$（在允许的范围内），都有**唯一确定**的输出值 $y$ 与之对应。

- $x$ 叫**自变量**（你可以调的那个）；
- $y$ 叫**因变量**（被 x 决定的那个）；
- $f$ 叫**对应法则**（售货机内部的规则）。

### 经济学里最常见的几种函数

| 函数名 | 长什么样 | 生活例子 |
|--------|----------|----------|
| 线性函数 | $y = a + b x$ | 打车费 = 起步价 + 里程 × 每公里价 |
| 二次函数 | $y = a + b x + c x^2$ | 倒 U 形：年龄对生产率的影响（太年轻/太老都不行） |
| 对数函数 | $y = \ln x$ | 工资对数、GDP 对数（边际效用递减） |
| 指数函数 | $y = e^{r t}$ | 复利：本金按年息 r 利滚利 |
| 常数函数 | $y = c$ | 不管 x 怎么变，y 都不变（如最低工资标准） |

## 三、公式怎么来的？（从直觉到符号）

我们以"打车费"为例：

- 起步价：3 公里以内都是 10 元；
- 超过 3 公里：每公里 2 元。

**把它写成函数：**

当 $x \le 3$：
$$y = 10$$

当 $x > 3$：
$$y = 10 + 2(x - 3)$$

化简第二个式子：
$$y = 10 + 2x - 6 = 4 + 2x$$

**所以最终的打车函数是分段的：**

$$
y =
\begin{cases}
10, & x \le 3 \\
4 + 2x, & x > 3
\end{cases}
$$

**每一步在干嘛？**
- 第一步：把"超过 3 公里的部分"算出来：$(x - 3)$ 公里；
- 第二步：这部分每公里 2 元，所以加价 $2(x-3)$；
- 第三步：加上起步价 10 元；
- 第四步：去括号、合并常数项，得到 $4 + 2x$。

**检验一下**：x = 5 公里时，y = 4 + 2×5 = 14 元。
实际算：起步 10 元 + 超出 2 公里 × 2 元 = 14 元。✅ 对上了。

## 四、每个符号是什么？

拿最常见的 $y = \beta_0 + \beta_1 x$ 举例（这就是第 3 章的回归方程）：

| 符号 | 怎么读 | 是什么 | 生活类比 |
|------|--------|--------|----------|
| $y$ | "y" | 因变量（被解释的） | 打车费 |
| $x$ | "x" | 自变量（解释的） | 里程 |
| $\beta_0$ | "beta 零" | 截距：x=0 时的 y | 起步价（严格说是 x=0 时的费用，这里数学上外推） |
| $\beta_1$ | "beta 一" | 斜率：x 每加 1，y 变多少 | 每公里 2 元 |
| $\beta$ | "beta" | 希腊字母，读作"贝塔" | —— |
| $\alpha$ | "alpha" | 希腊字母，读作"阿尔法" | 也常用来表示截距 |
| $\epsilon$ / $\varepsilon$ | "epsilon" | 扰动项：你没考虑到的其他因素 | 堵车、红灯绕路 |

**希腊字母不要怕，就是名字。** 常见的就这几个：
$\alpha$ 阿尔法、$\beta$ 贝塔、$\varepsilon$ 艾普西龙、$\mu$ 缪（均值）、$\sigma$ 西格玛（标准差）、$\sum$ 西格玛大写（[[03_求和号Σ是什么|求和号]]）。

## 五、一个完整的数字例子

**问题**：已知函数 $y = 100 + 50 x$（x 是工龄，y 是月工资），求：

**(1) 刚入职（x=0）时工资多少？**

代入：
$$y = 100 + 50 \times 0 = 100$$

哎，100 元？这不对——说明我们这个函数是从 x=1 开始才靠谱的，x=0 是外推。这就是为什么截距 $\beta_0$ 在经济学里常常没意义。

**(2) 工作 5 年时工资多少？**

$$y = 100 + 50 \times 5 = 100 + 250 = 350 \text{（百元）} = 3500 \text{ 元}$$

**(3) 工资从 100 涨到 200 需要几年？**

列方程：
$$200 = 100 + 50 x$$
两边减 100：
$$100 = 50 x$$
两边除以 50：
$$x = 2$$

答：2 年。

**(4) 这个函数的斜率是多少？代表什么？**

斜率 = $\beta_1 = 50$（百元/年）。
意思：**工龄每多 1 年，月工资涨 500 元。**

## 六、什么时候用函数？

当你要把"两个量之间的关系"写成数学式子时，就用函数。
统计学里尤其关心：
- **线性函数**（最常用）：两个量成比例变化；
- **对数函数**（也很常用）：当数据跨度很大（如 GDP 从几万到几十万亿），取对数让它好看；
- **二次函数**：当关系是"先升后降"或"先降后升"（倒 U 形、U 形）。

---

## 七、什么时候不能用？（易错点）

1. **不是所有关系都是线性的**。人的身高和年龄：0~18 岁线性增长，18~60 岁不变，60 岁后略微变矮——硬套直线会错得离谱。
2. **函数只能描述"确定"的关系**。现实经济关系都带随机性：同样工龄 5 年的人，工资有高有低。所以统计学家在线性函数后面**加一个扰动项 $\varepsilon$**：
   $$y = \beta_0 + \beta_1 x + \varepsilon$$
   这个 $\varepsilon$ 就是"同样 x 但 y 不一样"的那部分波动。
3. **别乱外推**。你用 0~18 岁身高数据拟合的直线，推到 30 岁会说你身高 2 米，荒谬。

## 八、Python 代码（画个图看看函数长啥样）

```python
# 导入画图工具
import matplotlib.pyplot as plt
import numpy as np

# 设中文字体（macOS）
plt.rcParams['font.sans-serif'] = ['Hiragino Sans GB', 'PingFang SC']
plt.rcParams['axes.unicode_minus'] = False

# 生成 x：从 0 到 10，每隔 0.1 一个点
x = np.arange(0, 10, 0.1)

# 三个常见函数
y1 = 100 + 50 * x              # 线性
y2 = 100 + 50*x - 3*x**2       # 二次（倒U）
y3 = 100 + 50 * np.log(x+1)    # 对数（边际递减）

# 画图
plt.figure(figsize=(8, 5))
plt.plot(x, y1, label='线性 y=100+50x', linewidth=2)
plt.plot(x, y2, label='二次 y=100+50x-3x²', linewidth=2)
plt.plot(x, y3, label='对数 y=100+50ln(x+1)', linewidth=2)
plt.xlabel('工龄 x（年）')
plt.ylabel('工资 y（百元）')
plt.title('三种函数形状对比')
plt.legend()
plt.grid(alpha=0.3)
plt.savefig('function_shapes.png', dpi=150, bbox_inches='tight')
plt.show()
```

**输出怎么读**：
- 直线：工资随工龄匀速涨；
- 倒 U 形：工龄对工资的影响先正后负（干太久反而涨不动甚至被淘汰）；
- 对数形：刚开始涨得快，后来涨不动（边际递减）。

## 九、和别的数学概念对比

| 概念 | 一句话 | 和函数的关系 |
|------|--------|-------------|
| 函数 | 输入→输出的规则 | 本体 |
| 方程 | 让函数等于某个数，求 x | 函数的一个"切片" |
| 导数 | 函数在某点的斜率 | 函数的"变化速度" |
| 矩阵 | 一堆函数打包 | 多个 x 同时影响多个 y |
| 概率分布 | 输入随机时，输出的分布 | 带随机性的函数 |

## 十、速记卡

> **函数 = 售货机 = 输入 x → 输出 y = f(x)。**
> 整个回归分析，就是拿数据去猜这台售货机内部的规则 $f$ 长什么样。
> 最常用的就是线性函数 $y = \beta_0 + \beta_1 x$：$\beta_1$ 是斜率（x 加 1，y 变多少）。
> 看到希腊字母别慌，就是名字。

## 💡 经济学视角：函数这个工具，在经济学里拿来干嘛？

**这个方法是为了解决什么经济学问题？**
1838 年经济学家古诺第一次把"价格涨了，需求量降多少"写成 $Q = f(P)$ 的样子，经济学从此从"讲道理"变成"算关系"。你学的每一个函数，背后都是一个经济学家在追问：**"一个量变了，另一个量会跟着怎么变？"**

**经济学里哪些经典模型正好就是函数？**
| 经济学模型 | 函数长什么样 | 在问什么 |
|---|---|---|
| 需求函数 | $Q_d = a - bP$ | 价格涨 1 块，少买几件？ |
| 生产函数 | $Q = f(K, L)$ | 多雇一个工人、多买一台机器，多生产多少？ |
| 消费函数 | $C = a + bY$ | 收入多 100 块，拿多少出来花？ |
| 效用函数 | $U = U(x_1, x_2)$ | 奶茶和炸鸡怎么搭配，你最爽？ |

**举个实证论文的例子：**
《中国农村居民消费函数实证研究（1995—2020）》拿 28 个省的年度数据跑 $C = \alpha + \beta Y + \varepsilon$，估出来 $\beta = 0.62$——意思是农村居民收入每多 1 元，平均拿出 6 毛 2 来消费，这就是**边际消费倾向**，后面乘数理论的命根子。
