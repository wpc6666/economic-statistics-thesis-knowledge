# 02 什么是导数和斜率？（开车速度版）

## 一、为什么要学这个？

**生活里的真实痛点：**

你打车去机场，司机开了 60 公里，用了 1 小时。

你低头看手机导航，上面显示：
- 全程平均速度 = 60 公里/小时；
- 但你经过学校门口时，导航显示"当前速度 20 公里/小时"；
- 上了高速，导航显示"当前速度 100 公里/小时"。

**"平均速度"和"当前速度"有什么区别？**

- 平均速度 = 总路程 ÷ 总时间（这是"一段路"的速度）；
- 当前速度 = 仪表盘上那个数字（这是"一瞬间"的速度）。

**"一瞬间的速度"，数学上就叫导数。**

经济学里天天说"边际成本""边际收益""边际效用"——这些"边际"，翻译成数学语言就是导数。你不懂导数，就看不懂"边际成本是 5 元"这句话到底在说啥。

**不学会怎样？**
- 看到"边际"两个字就发懵；
- 论文里写不出"边际效应"的解释；
- 被导师问"你这个系数代表边际效应吗"，你答不上。

---

## 二、是什么？

### 生活比喻：导数 = 仪表盘上的瞬时速度

想象位移函数 $s(t)$：t 时刻你在哪。

- $s(0)=0$：起点；
- $s(1)=60$：1 小时后在 60 公里处；
- $s(2)=140$：2 小时后在 140 公里处。

**平均速度**（第 1 小时到第 2 小时之间）：
$$\frac{s(2)-s(1)}{2-1} = \frac{140-60}{1} = 80 \text{ 公里/小时}$$

这是"这一小时"的平均速度。

**瞬时速度**（第 1 小时那一刻的速度）：
你不能用"第 1 小时到第 2 小时"来算——那是一小时的平均。你要把时间间隔缩到极小：

$$v(1) = \lim_{\Delta t \to 0} \frac{s(1+\Delta t)-s(1)}{\Delta t}$$

**这个极限，就是位移函数 $s(t)$ 在 t=1 处的导数**，记作 $s'(1)$ 或 $\frac{ds}{dt}|_{t=1}$。

### 严格定义

> **导数** $f'(x)$：函数 $f(x)$ 在点 x 处，"x 变化一点点时，y 跟着变化多少"的比率。
>
> $$f'(x) = \lim_{\Delta x \to 0} \frac{f(x+\Delta x)-f(x)}{\Delta x}$$

**几何意义**：导数 = 函数图像在那一点的**切线斜率**。

- 直线 $y = a+bx$ 的斜率是 b，所以它的导数是常数 b；
- 曲线的斜率每点都不一样，所以导数也是一个函数。

---

## 三、公式怎么来的？（不跳步）

我们以最简单的二次函数 $y = ax^2$ 为例，看看导数怎么推出来。

**第一步**：写出差商：
$$\frac{\Delta y}{\Delta x} = \frac{a(x+\Delta x)^2 - ax^2}{\Delta x}$$

**第二步**：展开 $(x+\Delta x)^2$：
$$(x+\Delta x)^2 = x^2 + 2x\Delta x + (\Delta x)^2$$
这一步是因为：$(A+B)^2 = A^2 + 2AB + B^2$，初中公式。

**第三步**：代回去：
$$\frac{\Delta y}{\Delta x} = \frac{a[x^2 + 2x\Delta x + (\Delta x)^2] - ax^2}{\Delta x}$$

**第四步**：分子里 $ax^2$ 和 $-ax^2$ 抵消：
$$\frac{\Delta y}{\Delta x} = \frac{a[2x\Delta x + (\Delta x)^2]}{\Delta x}$$

**第五步**：分子分母约掉 $\Delta x$：
$$\frac{\Delta y}{\Delta x} = a[2x + \Delta x] = 2ax + a\Delta x$$

**第六步**：让 $\Delta x \to 0$，$a\Delta x$ 这一项趋近于 0：
$$y' = 2ax$$

**结论**：$(ax^2)' = 2ax$。

**同样的方法**可以推出常用结果（你不用自己推，记住就行）：

| 函数 | 导数 |
|------|------|
| $y = c$（常数） | $y' = 0$ |
| $y = x$ | $y' = 1$ |
| $y = x^2$ | $y' = 2x$ |
| $y = x^3$ | $y' = 3x^2$ |
| $y = ax^2+bx+c$ | $y' = 2ax+b$ |
| $y = \ln x$ | $y' = 1/x$ |
| $y = e^x$ | $y' = e^x$ |

## 四、每个符号是什么？

| 符号 | 怎么读 | 是什么 | 生活类比 |
|------|--------|--------|----------|
| $f'(x)$ | "f 撇 x" | 函数 f 在 x 处的导数 | 仪表盘速度 |
| $\frac{dy}{dx}$ | "dy dx"（整体读） | y 对 x 的导数 | y 随 x 的变化率 |
| $\Delta x$ | "delta x" | x 的一小段变化 | 时间间隔 |
| $\Delta y$ | "delta y" | 对应的 y 变化 | 这段时间走的路程 |
| $y''$ | "y 两撇" | 二阶导数（导数的导数） | 加速度（速度的变化率） |

## 五、一个完整的数字例子

**题目**：已知成本函数 $C(x) = 100 + 20x + 0.5x^2$（x 是产量，单位百件；C 是成本，单位元）。

**(1) 总成本函数的导数是什么？**

用公式 $(ax^2+bx+c)' = 2ax+b$：
这里 $a=0.5, b=20, c=100$，所以：
$$C'(x) = 2\times 0.5 x + 20 = x + 20$$

**(2) 生产 100 件（x=1）时，边际成本是多少？**

代入 x=1：
$$C'(1) = 1 + 20 = 21 \text{ 元/百件}$$

意思：**产量从 100 件增加到 101 件时，成本大约增加 21 元。**

**(3) 数值验证一下**：算 C(2) - C(1)：
$$C(1) = 100 + 20 + 0.5 = 120.5$$
$$C(2) = 100 + 40 + 2 = 142$$
$$C(2) - C(1) = 21.5 \text{ 元}$$

和导数 21 元非常接近（差 0.5 是因为"从 1 到 2"不是"微小变化"，是一大步）。

**(4) 生产 1000 件（x=10）时，边际成本是多少？**

$$C'(10) = 10 + 20 = 30 \text{ 元/百件}$$

意思：产量越大，再生产一件的边际成本越高（这就是经济学里的"边际成本递增"）。

## 六、什么时候用导数？

经济学里凡是说"边际"，就是导数：

| 经济学名词 | 数学表达 | 意思 |
|------------|----------|------|
| 边际成本 MC | $C'(x)$ | 多生产一件，成本加多少 |
| 边际收益 MR | $R'(x)$ | 多卖一件，收入加多少 |
| 边际效用 MU | $U'(x)$ | 多吃一个包子，满足感加多少 |
| 边际消费倾向 MPC | $C'(Y)$ | 收入多 1 元，消费加多少 |
| 回归系数 $\hat{\beta}_1$ | $\partial y/\partial x$ | x 多 1 单位，y 平均变多少 |

**最后一行是论文里最常用的**：你跑回归得到的系数 $\hat{\beta}_1$，本质上就是"y 对 x 的导数"——它就是边际效应。

---

## 七、什么时候不能用？（易错点）

1. **导数是"瞬时"变化率，不是"一段"平均变化率**。别用 $(f(2)-f(1))/(2-1)$ 去冒充 f'(1)，那是平均斜率。
2. **导数为 0 不代表函数为 0**。$y=x^2$ 在 x=0 处导数是 0，但 y=0；在 x=1 处 y=1，导数是 2。导数是变化率，不是函数值本身。
3. **导数为正不代表 y 在增加到无穷**。比如 $y=\ln x$，导数 $1/x$ 永远为正，但 y 增长越来越慢。
4. **离散数据没有真正的导数**。你手里是"2015 年 GDP、2016 年 GDP……"这种离散点，没有"瞬间"可言。经济学里说"边际"时，其实是把离散数据当连续函数处理的近似——论文里这么写没问题，但心里要知道这是近似。
5. **别把"斜率"和"[[01_相关系数|相关系数]]"搞混**。斜率是回归直线的倾斜程度（有单位），相关系数是两个变量线性相关的强度（-1 到 1，无单位）。

## 八、Python 代码（画函数和它的切线）

```python
import numpy as np
import matplotlib.pyplot as plt

# 设中文字体
plt.rcParams['font.sans-serif'] = ['Hiragino Sans GB', 'PingFang SC']
plt.rcParams['axes.unicode_minus'] = False

# 成本函数
def C(x):
    return 100 + 20*x + 0.5*x**2

# 导数（边际成本）
def Cprime(x):
    return x + 20

# 画曲线
x = np.linspace(0, 10, 100)
y = C(x)

plt.figure(figsize=(8, 5))
plt.plot(x, y, label='成本函数 C(x)', linewidth=2)

# 在 x=1 处画切线：y = C(1) + C'(1)*(x-1)
x0 = 1
tangent = C(x0) + Cprime(x0)*(x - x0)
plt.plot(x, tangent, '--', label=f'x=1 处切线，斜率=C\'(1)={Cprime(1)}', linewidth=2)

# 标记切点
plt.scatter([x0], [C(x0)], color='red', zorder=5)

plt.xlabel('产量 x（百件）')
plt.ylabel('成本 C(x)（元）')
plt.title('成本函数与 x=1 处的切线（导数=切线斜率）')
plt.legend()
plt.grid(alpha=0.3)
plt.savefig('derivative_tangent.png', dpi=150, bbox_inches='tight')
plt.show()
```

**输出怎么读**：虚线在 x=1 那一点刚好"贴"在曲线上——它的倾斜程度就是导数。虚线越陡，说明那一点成本涨得越快。

## 九、和别的概念对比

| 概念 | 是什么 | 和导数的关系 |
|------|--------|--------------|
| 斜率 | 直线的倾斜程度 | 直线的导数就是斜率（常数） |
| 平均变化率 | 一段区间的 Δy/Δx | 导数是区间缩到无穷小时的极限 |
| 二阶导数 | 导数的导数 | 加速度（速度的变化率） |
| 偏导数 $\partial y/\partial x$ | 多变量时，只对一个变量求导 | 回归系数就是偏导数 |
| 积分 | 导数的逆运算 | 从边际成本反推总成本 |

---

## 十、速记卡

> **导数 = 仪表盘瞬时速度 = 函数在某点切线的斜率。**
> 公式 $(ax^2+bx+c)' = 2ax+b$，记住就行，不用会推。
> 经济学里"边际"= 导数：边际成本 = 成本函数的导数。
> 回归系数 $\hat{\beta}_1$ 就是 y 对 x 的边际效应。
> 导数是"一瞬间"的变化率，不是"一段路"的平均速度。
