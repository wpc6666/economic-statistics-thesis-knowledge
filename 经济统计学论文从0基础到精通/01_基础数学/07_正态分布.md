# 07 正态分布（钟形曲线与 68-95-99.7 法则）

## 一、为什么要学这个？

**生活里的真实痛点：**

你高考数学考了 120 分，不知道自己是啥水平。

老师告诉你："全省均分 100，标准差 15。"

你算一下：(120-100)/15 = 1.33。

这个 1.33 是啥？老师说："你比平均水平高 1.33 个标准差，大概超过全省 90% 的人。"

**这个"90%"就是从正态分布表查出来的。**

经济统计里到处是正态分布：
- 考试成绩、身高、智商——天生近似正态；
- 回归系数 $\hat{\beta}$ 在大样本下近似正态（[[../../教材笔记/05_统计学原理/06_抽样与参数估计/知识点/KP07_中心极限定理|中心极限定理]]）；
- t 检验、F 检验、p 值——全部建立在正态假设上；
- [[../../教材笔记/05_统计学原理/06_抽样与参数估计/知识点/KP10_区间估计与置信区间|置信区间]] $\hat{\beta} \pm 1.96 \times \mathrm{SE}$——1.96 就是正态分布 97.5% 分位数，SE 是[[../../教材笔记/05_统计学原理/06_抽样与参数估计/知识点/KP06_样本均值的抽样分布与标准误|标准误]]。

**不懂正态分布，第 3 章 t 检验你就看不懂。**

**不学会怎样？**
- 看到"95% 置信区间"不知道 1.96 哪来的；
- 论文里写不出"假设扰动项服从正态分布"；
- 被问"为什么用 t 检验"，答"教科书这么写的"。

---

## 二、是什么？

### 生活比喻：正态分布就是一口钟

把全班 100 人的考试成绩画成直方图：
- 大部分人集中在平均分附近（中间鼓起）；
- 很少人考特别高或特别低（两边下降）；
- 左右大致对称。

把直方图的顶部连成线，就是一口**钟形曲线**：

```
        ╱╲
       ╱  ╲
      ╱    ╲
     ╱      ╲
    ╱        ╲
___╱          ╲___
```

这就是正态分布。

### 严格定义

> **正态分布** $N(\mu, \sigma^2)$：一个连续概率分布，形状由两个参数决定：
> - $\mu$（均值）：钟形的中心位置；
> - $\sigma$（标准差）：钟形的胖瘦。$\sigma$ 越小越瘦高，越大越矮胖。
>
> 标准正态分布 $N(0, 1)$：均值 0、标准差 1 的正态分布，记作 $Z$。

**概率密度函数**（不用背，知道长这样就行）：
$$f(x) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

**你不需要记住这个公式**。你只需要知道：
- 中间最高（最可能出现）；
- 两边对称下降；
- 几乎不超过 $\mu \pm 3\sigma$。

---

## 三、68-95-99.7 经验法则

这是正态分布最有用的一个性质，**背下来**：

| 区间 | 包含的数据比例 |
|------|---------------|
| $\mu \pm 1\sigma$ | 约 68% |
| $\mu \pm 2\sigma$ | 约 95% |
| $\mu \pm 3\sigma$ | 约 99.7% |

**意思**：
- 68% 的人成绩在均分 ±15 分以内；
- 95% 的人成绩在均分 ±30 分以内；
- 99.7% 的人成绩在均分 ±45 分以内。

**超出 $\mu \pm 3\sigma$ 的概率只有 0.3%**——这就是质量管理里"3σ 原则"的来源：超出 3 个标准差就算异常。

**95% 对应的精确倍数是 1.96**（不是 2）。论文里写置信区间用 1.96，不用 2：
$$\hat{\beta} \pm 1.96 \times \mathrm{SE}$$

---

## 四、z 分数：把任何正态分布变成标准正态

**问题**：你的成绩 120，均分 100，标准差 15——你排第几？

**第一步：算 z 分数**

$$z = \frac{x - \mu}{\sigma} = \frac{120 - 100}{15} = 1.33$$

z = 1.33 意思：你的成绩比平均分高 1.33 个标准差。

**第二步：查标准正态分布表**

z = 1.33 对应的累积概率约 0.908——意思是你超过了 90.8% 的人。

**z 分数的本质**：把任何正态分布"[[KP11_标准化_ZScore|标准化]]"成 $N(0,1)$。不管原来 μ 和 σ 是多少，一减一除，就变成标准正态，查表就行。

---

## 五、为什么现实中那么多东西服从正态分布？（中心极限定理，一句话）

> **[[../../教材笔记/05_统计学原理/06_抽样与参数估计/知识点/KP07_中心极限定理|中心极限定理]]**：不管原始数据是什么分布，只要样本量 n 足够大，样本均值 $\bar{x}$ 的分布就近似正态。

**直觉解释**：人的身高 = 基因 + 营养 + 运动 + 睡眠 + 许多微小因素的总和。每个因素单独看可能不是正态，但**加在一起**就趋近正态。

这就是为什么：
- 测量误差 = 无数小误差叠加 → 正态；
- 回归系数 = 无数个体扰动的平均 → 大样本下正态；
- 考试成绩 = 无数题目得分加总 → 近似正态。

**本科论文里你不需要证明中心极限定理，知道"大样本下估计量近似正态"就够了。**

## 六、每个符号是什么？

| 符号 | 怎么读 | 是什么 |
|------|--------|--------|
| $N(\mu, \sigma^2)$ | "正态分布 缪 西格玛平方" | 均值 μ、方差 σ² 的正态分布 |
| $Z$ | "Z" | 标准正态分布 $N(0,1)$ |
| $z = (x-\mu)/\sigma$ | "z 分数" | 标准化后的值 |
| $\Phi(z)$ | "Phi z" | 标准正态累积分布函数（查概率） |
| 1.96 | —— | $N(0,1)$ 的 97.5% 分位数（95% 置信区间用） |
| 1.645 | —— | 95% 单侧分位数 |
| 2.576 | —— | 99% 双侧分位数 |

## 七、一个完整的数字例子

**题目**：某班考试成绩服从 $N(70, 10^2)$，即均分 70、标准差 10。

**(1) 你考了 85 分，z 分数多少？**

$$z = \frac{85-70}{10} = 1.5$$

你比平均分高 1.5 个标准差。

**(2) 你超过百分之多少的同学？**

查标准正态表，Φ(1.5) ≈ 0.933——超过 93.3% 的人。

**(3) 中间 95% 的人成绩在什么范围？**

$$\mu \pm 1.96\sigma = 70 \pm 1.96 \times 10 = 70 \pm 19.6$$

即 [50.4, 89.6]。95% 的人成绩在 50 到 90 分之间。

**(4) 考多少分才算前 2.5%？**

前 2.5% = 上尾 2.5%，对应 z = 1.96：
$$x = 70 + 1.96 \times 10 = 89.6$$

即考到 90 分以上就是前 2.5%。

---

## 八、什么时候用正态分布？

| 场景 | 怎么用 |
|------|--------|
| 大样本回归 | 假设 $\hat{\beta} \sim N(\beta, \mathrm{SE}^2)$，做 t 检验 |
| 置信区间 | $\hat{\beta} \pm 1.96 \times \mathrm{SE}$ |
| 异常值检测 | 超出 μ±3σ 算异常 |
| 标准化打分 | 把不同考试成绩换成 z 分数再比较 |

---

## 九、什么时候不能用？（易错点）

1. **小样本别乱用正态**。n<30 时，用 t 分布而不是正态分布（t 分布尾部更厚，更保守）。
2. **收入、GDP、股价这种偏斜数据不是正态**。它们右偏（少数极大值），通常取对数后才近似正态。
3. **正态分布是连续分布，别拿它算离散概率**。比如"恰好考 85 分"在连续分布里概率是 0，要算"84.5~85.5"这一小段。
4. **别把 68-95-99.7 当成精确值**。它是经验法则，精确值是 68.27%、95.45%、99.73%。论文里用 1.96，别用 2。
5. **中心极限定理不是万能的**。样本量要足够大（一般 n≥30 起步），而且原始分布不能极端偏斜。
6. **别把"正态"等同于"对称"**。正态一定对称，但对称的分布不一定正态（比如均匀分布）。

## 十、Python 代码（画正态曲线 + 验证法则）

```python
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['Hiragino Sans GB', 'PingFang SC']
plt.rcParams['axes.unicode_minus'] = False

# 生成标准正态的密度曲线
from scipy.stats import norm
x = np.linspace(-4, 4, 200)
y = norm.pdf(x)

plt.figure(figsize=(9, 5))
plt.plot(x, y, linewidth=2)

# 填不同区间颜色
plt.fill_between(x, y, where=(x>=-1)&(x<=1), alpha=0.4, label='68% (μ±1σ)')
plt.fill_between(x, y, where=(x>=-2)&(x<=2), alpha=0.3, label='95% (μ±2σ)')
plt.fill_between(x, y, where=(x>=-3)&(x<=3), alpha=0.2, label='99.7% (μ±3σ)')

plt.axvline(0, color='red', linestyle='--', label='μ=0')
plt.title('正态分布与 68-95-99.7 法则')
plt.legend()
plt.grid(alpha=0.3)
plt.savefig('normal_distribution.png', dpi=150, bbox_inches='tight')
plt.show()

# 验证 68-95-99.7
print(f"P(|Z|<1) = {norm.cdf(1)-norm.cdf(-1):.4f}")   # 0.6827
print(f"P(|Z|<2) = {norm.cdf(2)-norm.cdf(-2):.4f}")   # 0.9545
print(f"P(|Z|<3) = {norm.cdf(3)-norm.cdf(-3):.4f}")   # 0.9973

# 算 z=1.5 对应的累积概率
print(f"Φ(1.5) = {norm.cdf(1.5):.4f}")                # 0.9332
```

**输出怎么读**：68.27%、95.45%、99.73%——和经验法则的 68、95、99.7 对上。z=1.5 时累积概率 0.9332，即超过 93.3% 的人。

## 十一、和别的分布对比

| 分布 | 形状 | 什么时候用 |
|------|------|-----------|
| 正态 | 钟形对称 | 连续变量、大样本估计量 |
| t 分布 | 类似钟形但尾部更厚 | 小样本（n<30）回归系数 |
| 卡方分布 | 右偏、只取正值 | 方差检验、独立性检验 |
| F 分布 | 右偏 | 多系数联合检验（F 检验） |
| 二项分布 | 离散 | 是/否事件的次数 |

## 十二、从单变量到多变量（一句话版）

本科论文你只需要单变量正态就够了。但读硕士论文、读多元统计文献时会碰到"多元正态""协方差阵""马氏距离"这些词，先有个直觉，不要求会算。

### 12.1 均值向量与协方差阵（把一元推广到 p 维）

单变量正态只有一个 μ（均值）和一个 σ²（方差）。多元正态同时看 p 个变量，μ 变成了一列**均值向量**（p 个变量各自的均值排成一列），σ² 变成了一张 **p×p 协方差阵 Σ**——对角元是各变量自己的方差，非对角元是两个变量之间的协方差（也就是它们是否一起涨跌）。

> 打个比方：你给奶茶店打"甜度、奶味、茶味"三个分。一元统计只看甜度的平均分；多元统计要看三个维度各自的平均分（均值向量），还要看"甜度高的店是不是奶味也高"（协方差阵非对角元）。

（详见 [[../../教材笔记/04_多元统计/01_多元正态分布/知识点/KP01_均值向量与协方差阵|多元统计·均值向量与协方差阵]]）

### 12.2 马氏距离（按"概率云的形状"量距离）

欧氏距离就是勾股定理——两点之间直线多长。但如果两个变量高度相关（比如身高和体重），"顺着相关方向偏移一点"其实不算远（概率密度本来就高），"逆着相关方向偏移"才是真的远（概率密度极低）。

**马氏距离就是"在概率云里离中心有多远"**——先按各变量方差归一（消除量纲），再用协方差阵的逆消除变量间的相关性。它是判别分析、T²检验的基础。

> 一句话：欧氏距离量直线长度，马氏距离量"在这个分布里，你这个点有多罕见"。

（详见 [[../../教材笔记/04_多元统计/01_多元正态分布/知识点/KP02_统计距离|多元统计·统计距离与马氏距离]]）

**本科论文用到这两个概念吗？**——99% 用不到。你只要知道：做聚类、判别、PCA 时，软件内部其实就是在用协方差阵和马氏距离。你会用 R 的 `cov()`、`mahalanobis()` 就行，公式不用手推。

## 十三、速记卡

> **正态分布 = 钟形曲线，由 μ（中心）和 σ（胖瘦）决定。**
> **68-95-99.7 法则**：μ±1σ 含 68%，μ±2σ 含 95%，μ±3σ 含 99.7%。
> 95% 置信区间用 1.96 不是 2。
> z 分数 = (x-μ)/σ，标准化后查表知排名。
> 中心极限定理：大样本下样本均值/回归系数近似正态——这是整个[[KP02_假设检验|假设检验]]的基石。

## 💡 经济学视角：工资和收入，凭什么也画成钟形曲线？

**这个方法是为了解决什么经济学问题？**
1835 年凯特勒第一次发现：法国士兵的身高、胸围画出来都是钟形曲线——"误差规律"居然能描述人。高尔顿把这个发现用到人的智商、身世上，提出"回归到均值"。后来经济学家发现：去掉富豪和赤贫之后，大多数普通人的工资分布、能力分布确实近似钟形——这就是为什么用正态分布去建模工资是合理的。更重要的是中心极限定理：不管原始分布多歪，只要把无数个独立小因素加起来（工龄、学历、能力、运气、人脉……），总结果就趋近正态。这就是为什么回归系数天然就是正态的，假设检验才有依据。

**经济学里哪些变量的分布长得像钟形？**

| 经济学变量 | 分布形状 | 备注 |
|---|---|---|
| 工资（取对数后） | 近似正态 | 原始工资右偏，取对数才钟形 |
| 智商/能力 | 正态 | 设计时就被画成 μ=100，σ=15 |
| 回归系数 $\hat{\beta}$ | 渐近正态 | 大样本下自动成立 |
| 家庭消费（剔除极端） | 近似正态 | 中间大多数家庭集中在均值附近 |

**举个实证论文的例子：**
《中国城镇工资分布的演变——基于 CGSS 2003—2021》把对数工资画成直方图，发现 2003 年钟形中心在 9.5（约 1.3 万元），2021 年移到 10.3（约 3 万元），但 σ 从 0.6 扩大到 0.8——意思是"平均工资涨了，但人和人之间的差距也拉大了"。这是判断"共同富裕"进展最直观的一张图。
