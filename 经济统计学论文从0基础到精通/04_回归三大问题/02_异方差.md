## 一、为什么要学这个？

**生活场景**：你研究"收入对消费的影响"。

- 月收入 3000 的人：消费基本固定在 2500 左右，波动 ±200。
- 月收入 10 万的人：这个月买房花 50 万，下个月可能只花 5000，波动 ±20 万。

**这就是异方差**：误差项的方差，随着 X 变大而变大（或变小）。

**不学会怎样？** 你跑完回归，t 值算错了。本来不显著的系数，被你误判为显著；本来显著的，被你误判为不显著。论文投稿时审稿人第一句话就是："你用[[KP03_稳健标准误|稳健标准误]]了吗？"——没用的话，直接拒。

---

## 二、是什么？（比喻 + 定义）

### 比喻：吹气球

同方差 = 吹气球。你吹一口气，气球均匀变大——每个位置的"膨胀程度"都一样。

异方差 = 吹一个歪气球。某个地方特别薄，一吹就鼓包；其他地方纹丝不动——误差的"波动"不均匀。

### 严格定义

经典假设 MLR.5 说：
$$\mathrm{Var}(\varepsilon | X) = \sigma^2 \quad \text{（常数，和 X 无关）}$$

异方差就是：
$$\mathrm{Var}(\varepsilon | X) = \sigma_i^2 \quad \text{（每个观测 i 的方差不一样）}$$

**关键理解**：异方差**不影响系数的无偏性**——$\hat{\beta}_1$ 还是对的。它只让**标准误算错了**，于是 t 检验、F 检验、置信区间全错。

---

## 三、公式怎么来的？

### 普通标准误公式（同方差时才对）

在同方差假设下：
$$\mathrm{Var}(\hat{\beta}_1) = \frac{\sigma^2}{\sum (X_i - \bar{X})^2}$$

这里 $\sigma^2$ 是"平均的误差方差"。这个公式背后的假设是：每个观测的误差方差都等于 $\sigma^2$。

### 异方差时，普通公式为什么错了？

当第 i 个观测的误差方差是 $\sigma_i^2$（各不相同）时，正确的方差应该是：

$$\mathrm{Var}(\hat{\beta}_1) = \frac{\sum (X_i - \bar{X})^2 \sigma_i^2}{\left[\sum (X_i - \bar{X})^2\right]^2}$$

**这一步怎么来的？** 因为 $\hat{\beta}_1 = \sum w_i Y_i$，其中权重 $w_i = (X_i-\bar{X})/\sum(X_i-\bar{X})^2$。当每个 $Y_i$ 的方差是 $\sigma_i^2$ 且互相独立时：

$$\mathrm{Var}(\hat{\beta}_1) = \sum w_i^2 \sigma_i^2 = \sum \frac{(X_i-\bar{X})^2}{\left[\sum(X_i-\bar{X})^2\right]^2} \sigma_i^2$$

把 $\sigma_i^2$ 用残差 $e_i^2$ 估计，就得到**怀特稳健标准误**：

$$\mathrm{SE}_{robust}(\hat{\beta}_1) = \sqrt{\frac{\sum (X_i - \bar{X})^2 e_i^2}{\left[\sum (X_i - \bar{X})^2\right]^2}}$$

**对比普通公式**：
- 普通公式：分子是 $\sigma^2 \cdot \sum(X_i-\bar{X})^2$（把所有观测的方差都当成同一个 $\sigma^2$）。
- 稳健公式：分子是 $\sum (X_i-\bar{X})^2 e_i^2$（每个观测用自己的残差平方）。

## 四、符号表

| 符号 | 含义 |
|------|------|
| $\sigma^2$ | 同方差假设下的误差方差（常数） |
| $\sigma_i^2$ | 异方差下第 i 个观测的误差方差 |
| $e_i$ | 第 i 个观测的回归残差 |
| $\bar{X}$ | X 的样本均值 |
| $\sum (X_i-\bar{X})^2$ | X 的总变异（SST 的一部分） |
| $\mathrm{SE}_{robust}$ | 怀特稳健标准误 |

## 五、一个完整的数字例子（手算）

**数据**：5 户家庭，X=年收入（万元），Y=年消费（千元）。

| 户 | X | Y |
|----|---|---|
| 1 | 1 | 15.5 |
| 2 | 2 | 19.0 |
| 3 | 3 | 28.0 |
| 4 | 4 | 24.0 |
| 5 | 5 | 45.0 |

**第一步：算 [[04_OLS截距和拟合值|OLS]] 系数。**

$\bar{X} = 3$，$\bar{Y} = 26.3$。

| 户 | $X_i-\bar{X}$ | $Y_i-\bar{Y}$ | $(X_i-\bar{X})(Y_i-\bar{Y})$ | $(X_i-\bar{X})^2$ |
|----|------|------|------|------|
| 1 | -2 | -10.8 | 21.6 | 4 |
| 2 | -1 | -7.3 | 7.3 | 1 |
| 3 | 0 | 1.7 | 0 | 0 |
| 4 | 1 | -2.3 | -2.3 | 1 |
| 5 | 2 | 18.7 | 37.4 | 4 |
| 合计 | 0 | 0 | 64.0 | 10 |

$$\hat{\beta}_1 = \frac{64.0}{10} = 6.4$$
$$\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X} = 26.3 - 6.4 \times 3 = 7.1$$

回归方程：$\hat{Y} = 7.1 + 6.4 X$。

**第二步：算残差。**

拟合值 $\hat{Y}_i = 7.1 + 6.4 X_i$：

| 户 | $X_i$ | $Y_i$ | $\hat{Y}_i$ | 残差 $e_i$ | $e_i^2$ |
|----|---|---|---|---|---|
| 1 | 1 | 15.5 | 13.5 | 2.0 | 4.0 |
| 2 | 2 | 19.0 | 19.9 | -0.9 | 0.81 |
| 3 | 3 | 28.0 | 26.3 | 1.7 | 2.89 |
| 4 | 4 | 24.0 | 32.7 | -8.7 | 75.69 |
| 5 | 5 | 45.0 | 39.1 | 5.9 | 34.81 |

SSE = 4.0 + 0.81 + 2.89 + 75.69 + 34.81 = 118.2。

**第三步：算普通标准误（错误的）。**

$$\hat{\sigma}^2 = \frac{\mathrm{SSE}}{n-2} = \frac{118.2}{3} = 39.4$$

$$\mathrm{SE}_{普通}(\hat{\beta}_1) = \sqrt{\frac{39.4}{10}} = \sqrt{3.94} = 1.98$$

**第四步：算稳健标准误（正确的）。**

$$\sum (X_i-\bar{X})^2 e_i^2 = 4 \times 4.0 + 1 \times 0.81 + 0 \times 2.89 + 1 \times 75.69 + 4 \times 34.81$$
$$= 16.0 + 0.81 + 0 + 75.69 + 139.24 = 231.74$$

$$\mathrm{SE}_{稳健}(\hat{\beta}_1) = \sqrt{\frac{231.74}{10^2}} = \sqrt{2.3174} = 1.52$$

**第五步：对比。**

| 指标 | 普通标准误 | 稳健标准误 |
|------|-----------|-----------|
| SE($\hat{\beta}_1$) | 1.98 | 1.52 |
| t 值 = 6.4/SE | 3.23 | 4.21 |

这个小例子里稳健 se 反而小一点——但重点不是谁大谁小，而是**两个数不一样**。这说明普通 se 在异方差下算错了。在大样本、且高 X 对应大方差时，普通 se 通常会**低估**真实不确定性，导致你把不显著的东西误判为显著。

Python 验证：

```python
import numpy as np
x = np.array([1,2,3,4,5.])
y = np.array([15.5,19.0,28.0,24.0,45.0])
# 手算结果：b1=6.4, b0=7.1, 普通se=1.98, 稳健se=1.52
# 用 statsmodels 跑一下确认
import statsmodels.api as sm
X = sm.add_constant(x)
m = sm.OLS(y, X).fit()
m_robust = m.get_robustcov_results(cov_type='HC1')
print("普通 se:", m.bse[1])       # ≈1.98
print("稳健 se:", m_robust.bse[1]) # ≈1.52
```

## 六、什么时候用？

**什么时候会有异方差？**
- 截面数据：收入、消费、利润——大公司和小公司波动不一样。
- 调查数据：富人回答问题的偏差比穷人大。
- 只要数据的"规模"差异大，几乎一定有异方差。

**怎么检验？**

1. **画图**：画残差 vs 拟合值的散点图。如果残差越变越宽（喇叭形），就是异方差。
2. **BP 检验（Breusch-Pagan）**：把残差平方 $e_i^2$ 对所有解释变量（或拟合值 $\hat Y_i$）回归，看这个辅助回归的 $R^2$。
3. **怀特检验（White）**：BP 的升级版——辅助回归里加入 X 的平方项和交叉项，能抓"U 型异方差"（中间方差小、两头大）。

检验原假设 $H_0$：同方差（$\sigma_i^2$ 是常数）。p < 0.05 拒绝 $H_0$，说明有异方差。

### BP / White 检验到底在做什么？（[[../../教材笔记/02_计量经济学/06_异方差/知识点/KP01_异方差检验|KP01 异方差检验]]）

**直觉**：如果同方差成立，残差平方 $e_i^2$（它是 $\sigma_i^2$ 的样本估计）应该是"乱撒的"——和 X 没关系。如果异方差存在，$\sigma_i^2$ 随 X 变大，那 $e_i^2$ 就会和 X 系统相关。

**BP 检验的统计量**：$LM = n \cdot R^2_{e^2 \sim X} \sim \chi^2(K-1)$。其中 $R^2$ 是"把 $e^2$ 对 X 回归"得到的。n 是样本量。

**Stata 输出怎么读**（原书 mus04data 例）：

```
. estat hettest
Breusch-Pagan / Cook-Weisberg test for heteroskedasticity
         Ho: Constant variance
         Variables: fitted values of food_exp
         chi2(1) = 5.38
         Prob > chi2 = 0.0204
```

- chi2(1)=5.38，p=0.0204 < 0.05 → 拒绝同方差，**存在异方差**。

```
. estat imtest, white
White's test:  chi2(2) = 6.31   Prob > chi2 = 0.0427
```

- White 检验 p=0.0427 < 0.05 → 同样确认异方差。

**BP vs White 怎么选？** BP 只检验"方差随 X 线性变化"这一种形式；White 加入平方项和交叉项，能抓非线性异方差，但消耗更多自由度。论文里两个都报、或只报 White 即可。

> **大样本陷阱**：n=10000 时 BP 检验 p<0.001 不代表异方差严重——大样本下任何轻微偏离都显著。正确做法是对比普通标准误和稳健标准误的实际大小：如果两者差不到 10%~20%，异方差影响有限，报 robust 即可。

## 七、易错点

1. **异方差不影响系数**。$\hat{\beta}_1$ 还是无偏的，别换模型。只换标准误。
2. **不要一有异方差就用 WLS（加权最小二乘）**。WLS 需要你知道方差函数长什么样，现实中你不知道。**默认用 robust**，它不需要知道方差形式。
3. **robust 不是万能药**。它在大样本下才靠谱，n<30 时效果不好。
4. **别把异方差和内生性搞混**。异方差 = 标准误错；内生性 = 系数错。修法完全不同。
5. **Stata 里 `reg y x, robust` 就够了**。不需要手动加权。

## 八、Stata 代码

```stata
-- 异方差完整诊断流程
sysuse auto, clear          -- 用 Stata 自带示例数据
reg price weight length      -- 第一步：普通 OLS
predict resid, residuals     -- 保存残差
rvfplot                      -- 画残差vs拟合值图：看是不是喇叭形
estat hettest                -- BP检验：p<0.05 说明有异方差
estat imtest, white          -- 怀特检验：更严格的版本

-- 修法：加 robust
reg price weight length, robust   -- 就加一个词 robust
                                  -- 系数不变，标准误换成怀特稳健的
```

**输出怎么读**：
- `reg` 普通输出里的 Std. Err. 是错的；
- `reg, robust` 输出里的 Std. Err. 才是对的；
- 系数 Coef. 两版完全一样。

## 九、和别的方法对比

| 方法 | 什么时候用 | 优点 | 缺点 |
|------|-----------|------|------|
| 普通 OLS | 确认同方差 | 简单 | 异方差下 se 错 |
| **稳健标准误 robust** | **默认都加** | **不需要知道方差形式** | **小样本下不够准** |
| WLS 加权最小二乘 | 明确知道方差函数（如 Var 正比于 X²） | 最有效 | 现实中方差函数几乎不可能知道 |
| FWLS 可行 WLS | 先估方差函数再加权 | 不用事先知道形式 | 两步估计，标准误要修正 |
| 取对数 | 被解释变量方差随水平增大 | 简单有效 | 解释变成弹性，系数要重解 |

**论文建议**：所有回归表都汇报 robust 标准误。审稿人已经把"用 robust"当成默认要求了。

### WLS 到底怎么做？（[[../../教材笔记/02_计量经济学/06_异方差/知识点/KP02_异方差处理|KP02 异方差处理]]）

WLS 的思路：给每个观测一个权重 $w_i = 1/\sigma_i$，让方差大的观测权重小、方差小的观测权重大。加权后的回归变成：

$$\min \sum w_i^2 e_i^2 = \min \sum (e_i/\sigma_i)^2$$

加权后扰动项 $\varepsilon_i/\sigma_i$ 的方差 = 1（同方差了），OLS 又 BLUE 了。

**Stata 写法**（假设方差正比于 income）：

```stata
gen w = 1/income                    // 权重 = 1/σ
reg food_exp income [aweight=w]     // aweight 就是 WLS
```

**FWLS（两步 WLS）**：不知道 $\sigma_i^2$ 长什么样时，先 OLS 拿残差 $e_i$，再用 $e_i^2$ 对 X 回归估出 $\hat\sigma_i^2$，最后用 $1/\hat\sigma_i^2$ 加权。代价：第二步权重是估出来的，标准误会偏，需要修正。

### 一眼分清：系数动没动？（[[../../教材笔记/02_计量经济学/06_异方差/知识点/KP03_稳健标准误|KP03 稳健标准误]]）

| 做法 | 系数 Coef. | 标准误 Std.Err. |
|------|-----------|-----------------|
| `reg y x`（普通 OLS） | 基准 | 基准 |
| `reg y x, robust` | **和 OLS 完全一样** | 变了（White 修正） |
| `reg y x [aweight=w]`（WLS） | **和 OLS 不一样** | 变了（加权后同方差） |

**答辩一眼识别**：系数没变只有标准误变 = 只修推断（稳健标准误）；系数和标准误都变 = 换了估计方法（WLS/FWLS）。

### 真实数值对比（原书 food_exp 例）

```stata
reg food_exp income          // 普通 OLS
reg food_exp income, robust  // 稳健标准误
```

| food_exp | Coef. | 普通 Std.Err. | 稳健 Std.Err. |
|----------|-------|---------------|---------------|
| income | 10.21 | 2.09 | 2.64 |
| _cons | -137.83 | 79.43 | 94.77 |

- 系数**完全一样**（10.21）——robust 不动系数；
- income 的标准误从 2.09 涨到 2.64（变大 26%）——异方差使普通标准误**低估**了真实波动；
- t 值从 4.88 降到 3.86——仍然显著，但没那么"铁板钉钉"了。

### 四种标准误怎么选？

| 标准误类型 | 修异方差 | 修自相关 | 适用数据 | Stata 命令 |
|-----------|---------|---------|----------|-----------|
| 普通 OLS | 否 | 否 | 确认同方差+无自相关 | `reg y x` |
| White 稳健 | 是 | 否 | **横截面数据** | `reg y x, robust` |
| Newey-West HAC | 是 | 是 | **时间序列数据** | `newey y x, lag(L)` |
| 聚类稳健 | 是 | 组内相关 | **面板数据** | `reg y x, cluster(id)` |

## 十、为什么不用别的方法？

- **为什么不用 WLS（加权最小二乘）？** WLS 效率最高，但它要求你事先知道每个观测的方差函数长什么样（比如 Var(ε) 正比于 X²）。现实中你不知道，只能瞎猜权重——权重猜错了，WLS 系数照样有偏、标准误照样错，还不如什么都不做；robust 对方差形式零假设，大样本下稳。
- **为什么不用 GLS 代替 robust？** GLS 是 WLS 的推广，连"误差之间是否相关"都要事先假设结构（对角阵、AR(1) 之类），假设错了后果比异方差本身还严重；稳健标准误只修正标准误、不碰系数，对数据结构假设最少。
- **为什么不用对 Y 取对数代替 robust？** 取自然对数确实能压平"富人波动大"的喇叭形，但它把系数从"边际效应"（1 单位）变成"弹性"（1%），解释口径全变了；而且只压方差随水平增大的那一类异方差，检验显示异方差还在的话，对数之后照样要加 robust。

## 十一、答辩常问（直接背）

1. **问：异方差下 OLS 系数还能用吗？** 答：能，系数依然无偏——异方差只破坏标准误公式，不碰 $\hat{\beta}$。所以修法是加 robust 换标准误，系数一个数都不用改，绝不要换模型或删数据。
2. **问：BP [[08_t检验和F检验|检验和]]怀特检验怎么选？** 答：BP 检验假设方差只随 X 线性变化（把 $e^2$ 对 X 回归），简单但会漏；怀特检验加入 X 的平方项和交互项，能抓非线性的异方差形式，更保险。两者原假设都是同方差，p<0.05 即有异方差；论文里报怀特、或两个都报。
3. **问：稳健标准误是不是万能药，n=20 也能用？** 答：不是。HC 稳健标准误是大样本性质，n<30 时估出来的方差本身就很噪，置信区间覆盖率很差。小样本要么用 HC3 调整，要么增大样本；答辩时别吹 robust 包治百病。
4. **问：普通标准误和稳健标准误差多少算异常？** 答：差一倍以上就要警惕——比如普通 se=0.5、稳健 se=1.2，说明高 X 组的大方差被普通公式漏掉了，t 值从 4 跌到 1.7，显著性直接翻盘，论文回归表必须汇报稳健那一列。

## 十二、速记卡

> **异方差 = 误差波动不均匀（穷人波动小，富人波动大）。**
> - 后果：系数 $\hat{\beta}$ 还无偏，但标准误算错，t 检验不准。
> - 检验：BP 检验 / 怀特检验，p<0.05 就是有异方差。
> - 修法：`reg y x, robust`——加一个词，标准误换成怀特稳健的。
> - 不要用 WLS，除非你知道方差函数长什么样（你几乎不知道）。
> - 记住：**异方差打补丁（robust），内生性动手术（IV/FE）。**

## 💡 经济学视角：收入和消费数据，为什么天生就是"歪"的

**这个方法是为了解决什么经济学问题？**
打开任何一个收入数据集你就会发现：月入 3000 的人，每个月消费都在 2500 上下晃 200 块；月入 30 万的人，这个月花 5 万、下个月可能花 50 万——**富人的"波动"天然比穷人高一个数量级**。这就是异方差：误差方差不是常数，是跟着 X（收入）一起变大的。经济学数据里，凡是涉及收入、消费、企业利润、城市 GDP 的变量，几乎都长这副样子。

**经济学里哪些经典模型正好对应这个方法？**
| 模型 | 为什么异方差天生存在 |
|---|---|
| 消费函数 $C=a+bY$ | 高收入家庭储蓄空间大，可支配消费波动剧烈 |
| 生产函数 $Q=F(K,L)$ | 大企业产量波动远大于小作坊 |
| 收入分配理论 | 引致需求 + 边际生产力决定工资，工资方差随行业、随企业规模急剧拉大 |

**举个实证论文的例子：**
《中国城镇居民消费行为研究》跑 $\ln C=\alpha+\beta\ln Y+\varepsilon$，普通 reg 出来 t 值 8.5，加 robust 后 t 值掉到 3.2——结论方向没变，但显著性被"挤水分"了。审稿人最反感的就是不打 robust 的消费函数回归，因为那等于默认穷人和富人的消费波动一样大，违反直觉。
