# 04 多重共线性：身高和体重同时放进去会怎样？

<div style="text-align:right;margin:10px 0;"><a href="../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


## 一、为什么要学这个？

**生活场景**：你研究"体重 Y 由什么决定"，放了两个解释变量：身高 X₁ 和臂展 X₂。

问题来了：**高个子臂展一般也长**，这俩变量几乎说的是同一件事。

- 你加 1cm 身高，体重涨多少？
- 你加 1cm 臂展，体重涨多少？

Stata 会告诉你：系数标准误巨大，t 值不显著，甚至系数符号是反的（身高系数变负）。但你去掉臂展，身高系数立刻变回显著为正。

**这就是多重共线性**：两个或多个 X 之间高度相关，Stata 分不清谁是谁的贡献。

**不学会怎样？** 你看到一个系数不显著，以为是"经济上没影响"，其实是共线性把系数"淹没"了。论文里被导师问"你这两个 X 是不是太像了"，你答不上来。

---

## 二、是什么？（比喻 + 定义）

### 比喻：两个合唱队员

你想研究"每个队员对歌曲音量的贡献"。

- 如果队员 A 和队员 B 总是**同时开口、同时闭嘴**（完全同步），你根本分不清音量变化是谁造成的。
- 如果 A 和 B 经常错开唱，你就能听出各自的贡献。

多重共线性 = 两个 X 像两个完全同步的合唱队员，回归模型分不清谁是谁。

### 严格定义

**完全共线性**：某个 X 可以由其他 X 线性表出。比如 X₂ = 2×X₁。这种情况 Stata 会直接报错，估不出系数。

**近似共线性**（现实中常见的）：X 之间高度相关，但不是完全线性关系。比如身高和体重的[[01_相关系数|相关系数]] r=0.99。

后果：
- 系数估计 $\hat{\beta}$ 还是无偏的；
- 但**标准误很大**，t 值不显著；
- 样本稍微变一点，系数就大幅跳动（不稳定）；
- 符号甚至可能翻转。

## 三、公式怎么来的？VIF

> 详细推导与手算示例见 [[../../教材笔记/02_计量经济学/08_模型设定与数据问题/知识点/KP02_多重共线性|KP02 多重共线性]]。

### VIF（方差膨胀因子）

VIF 的思路：把第 j 个 X 对其他所有 X 回归，看 R² 有多大。

$$X_j = \alpha_0 + \alpha_1 X_1 + \cdots + \alpha_{j-1} X_{j-1} + \alpha_{j+1} X_{j+1} + \cdots + v_j$$

得到 $R_j^2$（X_j 被其他 X 解释的比例）。

然后：
$$\mathrm{VIF}_j = \frac{1}{1 - R_j^2}$$

**这个公式怎么来的？**

[[KP03_多元回归Stata|多元回归]]中，$\hat{\beta}_j$ 的方差是：
$$\mathrm{Var}(\hat{\beta}_j) = \frac{\sigma^2}{(n-1)\mathrm{Var}(X_j)} \cdot \frac{1}{1-R_j^2}$$

- 第一项：如果没有其他 X，方差就是这个。
- 第二项：$1/(1-R_j^2)$ 就是 VIF——它把方差"膨胀"了多少倍。

**直觉**：
- $R_j^2 = 0$（X_j 和其他 X 无关）：VIF = 1，没膨胀。
- $R_j^2 = 0.9$：VIF = 10，标准误膨胀 $\sqrt{10} \approx 3.16$ 倍。
- $R_j^2 = 0.99$：VIF = 100，标准误膨胀 10 倍。

**经验法则**：
- VIF < 5：安全；
- 5 < VIF < 10：要警惕；
- VIF > 10：严重共线性，必须处理。

## 四、符号表

| 符号 | 含义 |
|------|------|
| $X_j$ | 第 j 个解释变量 |
| $R_j^2$ | 把 X_j 对其他所有 X 回归得到的 R² |
| $\mathrm{VIF}_j$ | 第 j 个变量的方差膨胀因子 |
| $r_{12}$ | X₁ 和 X₂ 的相关系数 |

**二元情形简化公式**：只有两个 X 时，$R_j^2 = r_{12}^2$，所以：
$$\mathrm{VIF} = \frac{1}{1 - r_{12}^2}$$

## 五、一个完整的数字例子（手算 VIF）

**数据**：6 个人，X₁=身高（cm），X₂=体重（kg）。

| 人 | X₁ 身高 | X₂ 体重 |
|----|---------|---------|
| A | 160 | 55 |
| B | 165 | 60 |
| C | 170 | 65 |
| D | 175 | 72 |
| E | 180 | 80 |
| F | 185 | 88 |

**第一步：把 X₂ 对 X₁ 回归。**

$\bar{X}_1 = 172.5$，$\bar{X}_2 = 70.0$。

| 人 | $X_1-\bar{X}_1$ | $X_2-\bar{X}_2$ | 乘积 | $(X_1-\bar{X}_1)^2$ |
|----|------|------|------|------|
| A | -12.5 | -15 | 187.5 | 156.25 |
| B | -7.5 | -10 | 75.0 | 56.25 |
| C | -2.5 | -5 | 12.5 | 6.25 |
| D | 2.5 | 2 | 5.0 | 6.25 |
| E | 7.5 | 10 | 75.0 | 56.25 |
| F | 12.5 | 18 | 225.0 | 156.25 |
| 合计 | 0 | 0 | 580.0 | 437.5 |

$$\hat{\alpha}_1 = \frac{580}{437.5} = 1.3257$$
$$\hat{\alpha}_0 = 70.0 - 1.3257 \times 172.5 = -158.69$$

回归：$\hat{X}_2 = -158.69 + 1.3257 X_1$。

**第二步：算 R²。**

拟合值 $\hat{X}_2$：

| 人 | X₂ | $\hat{X}_2$ | $X_2-\hat{X}_2$ | 残差² |
|----|-----|-----|------|------|
| A | 55 | 53.42 | 1.58 | 2.50 |
| B | 60 | 60.05 | -0.05 | 0.00 |
| C | 65 | 66.68 | -1.68 | 2.81 |
| D | 72 | 73.31 | -1.31 | 1.72 |
| E | 80 | 79.93 | 0.07 | 0.00 |
| F | 88 | 86.56 | 1.44 | 2.07 |

SSE = 2.50+0+2.81+1.72+0+2.07 = 9.10。

SST = $\sum (X_2 - \bar{X}_2)^2$ = 225+100+25+4+100+324 = 778。

$$R^2 = 1 - \frac{9.10}{778} = 1 - 0.0117 = 0.9883$$

**第三步：算 VIF。**

$$\mathrm{VIF} = \frac{1}{1 - 0.9883} = \frac{1}{0.0117} = 85.6$$

VIF = 85.6，远大于 10——**严重多重共线性**。

**直觉**：身高解释了体重 98.8% 的变异，这两个变量几乎是同一个东西。你把它们同时放进回归，Stata 会疯掉——它不知道该把体重涨的原因记在身高账上，还是臂展账上。

**Python 验证**：

```python
import numpy as np
X1 = np.array([160,165,170,175,180,185.])
X2 = np.array([55,60,65,72,80,88.])
r = np.corrcoef(X1, X2)[0,1]
print(f"r = {r:.4f}")          # 0.9941
print(f"VIF = {1/(1-r**2):.2f}") # 85.63
```

## 六、什么时候用？

**什么时候会有多重共线性？**
- 经济变量天然相关：GDP、消费、投资、出口——大家一起涨。
- 放了太多变量：X₁、X₂、X₃……每加一个都和已有的相关。
- 放了"同义反复"变量：身高和臂展、收入和消费、GDP 和 GNP。

**怎么诊断？**
1. **VIF 检验**：`estat vif`，看每个变量的 VIF。
2. **相关系数矩阵**：看 X 之间的相关系数，>0.8 就要小心。
3. **症状**：R² 很高但 t 值都不显著；系数符号和理论相反；删一个变量后另一个系数大变。

**怎么修？**

| 方法 | 什么时候用 |
|------|-----------|
| 删掉一个变量 | 最常用。留经济意义更强的那个。 |
| 合并变量 | 把身高和体重合成 BMI = 体重/身高²。 |
| 岭回归 | 数据实在不能删时（高级，本科论文少用）。 |
| 增加样本 | 共线性是样本问题，样本大了标准误自然小。 |

---

## 七、易错点

1. **多重共线性不是错误，是数据问题**。系数还无偏，只是精度差。不要"修"成无偏——你修不了，只能接受或删变量。
2. **VIF 高不代表模型错了**。如果你关心的是"X₁ 和 X₂ 合起来对 Y 的影响"（F 检验显著），即使单独看不显著，模型整体还是有意义的。**预测仍可用**——只要 X 的未来取值保持同样的共线结构，预测精度不受影响；只有"想解释每个变量单独效应"时，高 VIF 才是问题。
3. **不要为了降 VIF 乱删变量**。删错了会引入[[02_遗漏变量偏误|遗漏变量偏误]]（第 5 章）。VIF 高只是"告诉我们系数不精确"，不是"应该删掉这个变量"。
4. **共线性是样本内的，不是总体的**。换个样本，VIF 可能就低了；增大样本能打破原来的共线结构。
5. **VIF>10 是经验法则，不是绝对阈值**。F=9.9 和 F=10.1 在统计上没有本质区别，关键看系数的实际稳定性。
6. **面板数据里时间不变的变量不要同时放个体[[09_虚拟变量|虚拟变量]]**——会完全共线。

## 八、Stata 代码

```stata
-- 多重共线性诊断流程
sysuse auto, clear
reg price weight length displacement   -- 跑回归
estat vif                              -- 关键命令：看每个变量的 VIF
                                       -- VIF>10 就要警惕

-- 看相关系数矩阵
pwcorr weight length displacement, sig   -- 变量两两相关系数+显著性

-- 修法 1：删掉共线性高的变量
reg price weight displacement           -- 删掉 length

-- 修法 2：合成新变量
gen bmi = weight/(length/100)^2        -- 例子：合成 BMI
reg price bmi ...
```

**输出怎么读**：
- `estat vif` 输出最后一行 Mean VIF，如果 > 5 就要逐个看；
- 单独某个变量 VIF > 10：删它；
- 所有 VIF 都 5~10：加 robust + 解释时小心。

## 九、和别的问题对比

| 问题 | 系数 | 标准误 | t 检验 | 修法 |
|------|------|--------|--------|------|
| [[02_异方差|异方差]] | 无偏 | 错 | 不准 | robust |
| [[03_自相关|自相关]] | 无偏 | 错 | 不准 | Newey-West |
| **多重共线性** | **无偏** | **大** | **不显著** | **删变量/合并** |
| 内生性 | **有偏** | 错 | 错 | IV/FE（第 5 章） |

**关键区别**：前三个问题都不动系数，只影响精度；内生性直接动系数。多重共线性最"温和"——它只是让你看不清，不是让你看错。

## 十、为什么不用别的方法？

- **为什么不用岭回归（Ridge）？** 岭回归通过加惩罚项把膨胀的标准误压下去，但它给所有系数都引入了偏误——你为了"看得清"把系数本身估偏了，而且惩罚系数 λ 选多少没有客观标准。本科论文里审稿人看到非 [[04_OLS截距和拟合值|OLS]] 估计会多问一堆，不如删变量干净透明。
- **为什么不用[[02_主成分分析PCA|主成分分析]]（PCA）合成因子？** PCA 把身高、体重合成一个"体型因子"，标准误是小了，但这个因子没有经济含义——你没法回答"身高每涨 1cm 体重涨多少"，政策含义消失了。PCA 适合做预测，不适合做因果解释。
- **为什么不干脆"忍受高 VIF"，只汇报结果？** 如果你关心的是单个变量系数显不显著（比如"广告投入到底有没有用"），高 VIF 会让 t 值被标准误淹没，你根本分不清是"经济上没影响"还是"样本信息不足"。只有当研究目标是"这组变量合起来对 Y 的影响"（F 检验显著）时，才可以忍受高 VIF 并如实说明。

## 十一、答辩常问（直接背）

1. **问：VIF=12 严重吗？怎么判断？** 答：经验阈值——VIF<5 安全，5~10 警惕，>10 严重。VIF=12 意味着该变量的标准误被 $\sqrt{12}\approx3.5$ 倍地膨胀，t 值被压缩到原来的约 1/3.5，本来显著的系数很可能被淹没，需要删一个共线变量或合并。
2. **问：多重共线性会不会让 OLS 系数有偏？** 答：不会。只要是近似共线性（不是完全共线），OLS 系数依然无偏，只是方差变大、估计不稳定、样本一动系数就跳。真正让系数有偏的是内生性——共线性只是"看不清"，不是"看错"。
3. **问：删哪个变量？删错了会怎样？** 答：删经济意义弱、和核心解释变量纠缠的那个，比如身高和臂展共线就留身高。删错了（把真正重要的变量删了）会引入遗漏变量偏误——系数从"看不清"变成"真看错"，比共线性严重得多。删之前先想清楚经济机制，别只看 VIF 数字下刀。
4. **问：R² 很高但所有 t 都不显著，是什么病？** 答：典型的多重共线性症状——模型整体 F 检验显著（合起来能解释 Y），但每个 X 单独的贡献都因为 X 之间高度相关而估不准。诊断动作：跑 `estat vif`，把 VIF>10 的变量处理掉，重跑后再看 t 值。

---

## 十二、速记卡

> **多重共线性 = 两个 X 说同一件事，模型分不清谁贡献大。**
> - 后果：系数无偏但标准误大、t 值不显著、系数不稳定。
> - 诊断：VIF > 10 有问题（VIF = 1/(1-R²)）。
> - 修法：删一个变量（最常用）、合成新变量、加样本。
> - 记住：共线性不是"系数错了"，是"数据不够信息分辨"。删变量前想清楚经济意义，别为了降 VIF 删错。

## 💡 经济学视角：经济学变量，天生就爱"一起动"

**这个方法是为了解决什么经济学问题？**
物理学家做实验，可以把温度固定住、只改压力。经济学家不行——利率降的时候，货币供应量一定涨；企业扩产的时候，资本 K 和劳动 L 一定同时增加；经济繁荣期，消费、投资、出口全在往上走。**经济学变量不是一个个独立开关，是一根绳上的蚂蚱**。你想把它们同时塞进回归方程让模型"分家"，模型就懵了：你们都一起动，到底是谁在起作用？这就是多重共线性。

**经济学里哪些经典模型正好对应这个方法？**
| 经典模型 | 天然共线的变量 |
|---|---|
| 生产函数 $Q=F(K,L)$ | K 和 L 总是同方向变化（大厂既多资本也多工人） |
| IS-LM 模型 | 利率 r 和货币供给 M 由央行联动决定 |
| 货币需求 $L=L_1(Y)+L_2(r)$ | 收入 Y 涨时交易性需求和投机性需求一起动 |

**举个实证论文的例子：**
《中国制造业全要素生产率研究》把 K、L、能源 E 一起放进去，结果 K 的系数 t 值从 5 掉到 1.2，VIF 高达 18——因为企业越大，资本、劳动、能源三者同步扩张。解法通常是：要么删一个（比如合并 K 和 E 成"中间投入"），要么用索洛余值的思路只估一个技术进步项。**共线性不是模型错了，是数据没给你"分开看"的机会**。
