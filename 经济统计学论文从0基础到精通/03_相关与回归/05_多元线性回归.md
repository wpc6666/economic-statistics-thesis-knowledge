# 05 多元线性回归：控制其他变量不变

## 一、为什么要学这个？

上一篇我们做的是"工资 ~ 教育"的[[KP04_一元回归Stata解读|一元回归]]，发现 b̂ = 0.55。

但你马上会想到一个问题：
- 工资高的人，可能不只是因为教育多，还因为工龄长、是男性、在大城市；
- 如果只看教育，把这些因素都混在一起，b̂ = 0.55 到底是教育的作用，还是工龄的作用？

**这就是一元回归的致命问题：它控制不了其他变量。**

[[KP03_多元回归Stata|多元回归]]就是：**一个 y 对多个 x 同时回归，每个 x 的系数表示"控制其他变量不变时，这个 x 的偏效应"。**

本科论文 90% 用的都是多元回归，不是一元。

---

## 二、是什么？

### 生活比喻：调配药方

一元回归像只开一味药："感冒了？吃阿司匹林。"
多元回归像中医开方子："感冒了，阿司匹林 2 片 + 维生素 C 1 片 + 多喝水。"

每味药的剂量，是在"其他药也吃着"的前提下定的。
如果你单独吃阿司匹林 2 片，可能和"阿司匹林 2 片 + 维C 1 片"的效果不一样。

**多元回归的系数，就是"控制其他变量不变"后的偏效应。**

### 严格定义

$$y_i = \beta_0 + \beta_1 x_{1i} + \beta_2 x_{2i} + \cdots + \beta_k x_{ki} + \varepsilon_i$$

- $y_i$：因变量；
- $x_{1i}, x_{2i}, \ldots, x_{ki}$：k 个自变量；
- $\beta_1, \beta_2, \ldots, \beta_k$：每个自变量的偏效应系数；
- $\varepsilon_i$：误差项。

**系数 $\beta_j$ 的含义**：在保持其他 x 不变的情况下，$x_j$ 每增加 1 单位，y 平均变化 $\beta_j$ 单位。

> 📖 教材笔记里[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP10_多元线性回归与偏回归系数|KP10 多元线性回归与偏回归系数]]对"偏回归系数"这个概念讲得更细——为什么控制其他变量后系数会变、它和简单相关系数有什么区别，建议对照读一遍。

### 为什么"控制其他变量"很重要？

举个例子：
- 数据显示"穿鞋的人成绩更好"（鞋码和成绩正相关）；
- 但你一想：鞋码大的人是成年人，成年人当然成绩好；
- **控制了"年龄"之后**，鞋码对成绩的偏效应就变成 0 了。

这就是多元回归的威力：它能把"年龄"的影响摘出去，单独看鞋码的净效应。

---

## 三、公式怎么来的？（矩阵形式，先有个印象）

一元时：$SSE = \sum(y_i - a - bx_i)^2$，对 a、b 求导=0。

多元时：$SSE = \sum(y_i - \beta_0 - \beta_1 x_{1i} - \cdots - \beta_k x_{ki})^2$，对每个 β 求导=0。

推导方法和一元完全一样，只是未知数多了。

写成矩阵形式（你先眼熟，不用推）：

$$\hat{\boldsymbol{\beta}} = (X'X)^{-1} X'y$$

- $X$：n 行 (k+1) 列的矩阵（每列是一个 x，第一列全是 1 代表截距）；
- $X'$：X 的转置；
- $(X'X)^{-1}$：X'X 的逆矩阵；
- $y$：n 维向量。

**这就是 [[04_OLS截距和拟合值|OLS]] 的矩阵表达式。** 本科论文不会要求你手推矩阵，但你要知道它长这样。

---

## 四、符号表

| 符号 | 是什么 |
|------|--------|
| $y_i$ | 第 i 个观测的因变量 |
| $x_{ji}$ | 第 j 个自变量在第 i 个观测的值 |
| $\beta_0$ | 截距 |
| $\beta_j$ | 第 j 个自变量的斜率（偏效应） |
| $\varepsilon_i$ | 误差项 |
| k | 自变量个数 |

## 五、一个完整的数字例子

**数据**：5 个人的工资（y，千元）、教育年限（x1）、工龄（x2）：

| i | y | x1（教育） | x2（工龄） |
|---|---|-----------|-----------|
| 1 | 3 | 9 | 1 |
| 2 | 4.5 | 12 | 3 |
| 3 | 5 | 12 | 5 |
| 4 | 7 | 16 | 10 |
| 5 | 8.5 | 19 | 15 |

**我们要估计**：$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \varepsilon$

手算矩阵形式太麻烦，直接用 Python：

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm

# 构造数据
df = pd.DataFrame({
    'wage': [3, 4.5, 5, 7, 8.5],
    'edu': [9, 12, 12, 16, 19],
    'tenure': [1, 3, 5, 10, 15]
})

X = df[['edu', 'tenure']]
X = sm.add_constant(X)  # 加截距列
y = df['wage']

model = sm.OLS(y, X).fit()
print(model.summary())
```

**输出（关键部分）**：

```
             coef    std err      t      P>|t|
const       -0.542      1.620   -0.335    0.770
edu          0.398      0.179    2.221    0.157
tenure       0.106      0.124    0.860    0.481
```

### 解释结果

- **β1（教育）= 0.398**：在保持工龄不变时，每多上一年学，工资平均涨 398 元；
- **β2（工龄）= 0.106**：在保持教育不变时，每多工作一年，工资平均涨 106 元；
- **β0 = -0.542**：截距，没经济意义。

**对比一元回归的结果**：一元时 b̂ = 0.551，多元时变成 0.398。
为什么变小了？因为一元时"教育的系数"混进了"工龄的效应"——教育多的人通常工龄少（刚毕业），控制工龄后，教育的净效应变小了。

这就是"控制其他变量"的威力。

### 为什么系数会变？——Frisch-Waugh 直觉

> 📖 教材笔记[[../../教材笔记/02_计量经济学/04_多元线性回归/知识点/KP02_偏回归系数|KP02 偏回归系数]]从数学上讲清了这件事。

**偏回归系数 β₁ 到底是什么？** 分两步看：

1. 先把 edu 对 tenure 回归，取残差 $\tilde{edu}$——这是 edu 中"无法被工龄解释"的那部分变异（"纯教育"）；
2. 再把 wage 对 tenure 回归，取残差 $\tilde{wage}$——这是 wage 中"无法被工龄解释"的那部分变异（"纯工资"）；
3. 最后用 $\tilde{wage}$ 对 $\tilde{edu}$ 做一元回归，斜率就是 β₁ = 0.398。

**一句话**：偏回归系数 = "把其他变量的影响都扣掉之后，x 剩下的部分对 y 剩下的部分的斜率"。

**用教材里 grilic 数据的真实结果对比**：

| 变量 | 一元回归（wage ~ edu） | 多元回归（wage ~ edu + iq + tenure + ...） | 差异原因 |
|------|----------------------|------------------------------------------|---------|
| edu | 0.103 | 0.061 | 一元时混入了智商、工龄等的贡献 |
| iq | — | 0.003 | 只有多元才看得到智商的独立效应 |
| tenure | — | 0.050 | 同上 |

**教育回报率从 10.3% 降到 6.1%**——说明原来的 10.3% 里有一部分是"能力"和"其他因素"的回报，不是纯粹的教育回报。

> ⚠️ **解读多元系数时，必须说"控制了其他变量之后"**。漏掉这几个字，就把净效应读成了简单相关——这是答辩最常见的表述错误。

## 六、多元回归的前提假设

除了一元的 5 条，多元还多一条：

**不存在完全共线性**：任何一个 x 不能是其他 x 的精确线性组合。

比如：
- 你同时放"受教育年限"和"上学年数"——它们是同一个东西，完全共线；
- 你同时放"男生"、"女生"、"性别"——前两个加起来就是第三个，完全共线。

Stata 遇到完全共线性会自动删掉一个变量，并提示 "omitted because of collinearity"。

---

## 七、易错点

1. **系数是偏效应，不是总效应**。β1 = 0.398 是"控制工龄后"的教育效应，不是"教育对工资的总影响"。总影响需要把直接和间接效应加起来。
2. **控制变量不是越多越好**。放太多变量会导致[[04_多重共线性|多重共线性]]（第 4 章讲），而且如果控制了"坏变量"（比如受教育影响的"职业"），会把教育的效应吃掉。
3. **R² 会随变量增加而自动上升**——这是下一章的内容。
4. **不要解释截距**。多元回归的截距是"所有 x=0 时的 y"，现实中几乎不可能。

### 延伸：x 和 y 的关系不是直线怎么办？

工资和工龄常常不是直线——刚开始涨得快，后来涨得慢，甚至回落（倒 U 形）。这时候直接塞 $x$ 进去，直线会拟合得很差。

教材笔记里[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP11_曲线回归与线性化|KP11 曲线回归与线性化]]讲了怎么把常见曲线（双曲线、指数曲线、幂函数、二次曲线）**做变量替换变成线性模型**，再用 OLS 估计。论文里常见的做法：
- 工资取对数 $\ln(wage)$，教育年限原样放——变成半对数模型；
- 工龄放一次项和二次项（$tenure$ 和 $tenure^2$），捕捉倒 U 形；
- 对数-对数模型（两边都取对数）——系数直接弹性解释。

**常见曲线 → 换元 → 线性化对照表**：

| 曲线类型 | 原方程 | 换元方法 | 变换后（可以直接 OLS） | 典型场景 |
|---------|--------|---------|---------------------|---------|
| 双曲线 | $\hat{y} = b_0 + b_1 \frac{1}{x}$ | 令 $x' = 1/x$ | $\hat{y} = b_0 + b_1 x'$ | 流通费用率 vs 零售额（规模越大费用率越低） |
| 对数曲线 | $\hat{y} = b_0 + b_1 \ln x$ | 令 $x' = \ln x$ | $\hat{y} = b_0 + b_1 x'$ | 边际效用递减（x 增长带来的 y 增长越来越慢） |
| 二次曲线 | $\hat{y} = b_0 + b_1 x + b_2 x^2$ | 令 $x' = x^2$ | $\hat{y} = b_0 + b_1 x + b_2 x'$ | 倒 U 形（施肥量 vs 产量、年龄 vs 收入） |
| 指数曲线 | $\hat{y} = b_0 b_1^x$ | 两边取对数 $\ln \hat{y} = \ln b_0 + x \ln b_1$ | $y' = A + Bx$（$y'=\ln y$） | 复利增长、人口增长 |
| 幂函数 | $\hat{y} = b_0 x^{b_1}$ | 两边取对数 | $\ln y = \ln b_0 + b_1 \ln x$ | Cobb-Douglas 生产函数（弹性解释） |

**怎么选？** 先画散点图，看形状最像哪条，试一下，比较 R² 或残差图。

> ⚠️ **指数曲线取对数后要注意**：这时候 OLS 最小化的是 $\sum(\ln y - \ln \hat{y})^2$，不是原来的 $\sum(y - \hat{y})^2$——和直接最小化原方程残差有微小差异。这是对数线性化的代价。

## 八、Stata / Python 代码

```stata
* Stata：多元回归
reg wage edu tenure

* 输出怎么读：
* Coef 列：每个变量的偏效应系数
* P>|t| 列：p 值，<0.05 才算显著
* R-squared：R²
* N = 观测数
```

### 多元回归输出表逐列解读

> 📖 教材笔记[[../../教材笔记/02_计量经济学/04_多元线性回归/知识点/KP03_多元回归Stata|KP03 多元回归 Stata]]把输出表每个数字都讲了一遍。

**上半部分（模型整体统计量）**：

| 数字 | 怎么读 |
|------|--------|
| Number of obs = 758 | 实际用了多少个样本（缺失值会被自动删掉，可能比原始数据少） |
| F(7, 750) = 118.69 | F 统计量，检验"所有系数联合为 0" |
| Prob > F = 0.0000 | F 检验 p 值 < 0.05 → 整个方程显著 |
| R-squared = 0.5126 | 模型解释了 y 变异的 51.3% |
| Adj R-squared = 0.5081 | 惩罚变量个数后的 R²（多元回归必看这个） |
| Root MSE = 0.343 | 回归标准误（残差的标准差） |

**下半部分（每个变量一行）**：和一元回归一样——Coef. / Std.Err. / t / P>\|t\| / 95% 置信区间。

### 想检验"几个变量联合为 0"怎么办？

```stata
* 检验 edu 和 tenure 联合为 0（H0: β_edu = β_tenure = 0）
test edu tenure

* 检验 edu 的系数等于 0.5
test edu = 0.5
```

> ⚠️ **为什么不能分别看两个 t 值？** 因为存在"多重比较问题"——两个 t 检验各自在 5% 水平控制第一类错误，但联合来看，即使两个系数真的都为 0，随机波动也有相当概率让其中一个 t 值超过 1.96。`test` 命令用 F 检验把两个约束作为一个整体来检验，才是正确做法。

```python
# Python
import statsmodels.api as sm

X = df[['edu', 'tenure']]
X = sm.add_constant(X)
model = sm.OLS(df['wage'], X).fit()
print(model.summary())
```

## 九、对比

| | 一元回归 | 多元回归 |
|---|---------|---------|
| 自变量个数 | 1 | 多个 |
| 系数含义 | x 对 y 的总效应 | **控制其他变量后的偏效应** |
| 能不能排除混淆变量 | 不能 | 能 |
| 共线性问题 | 无 | 有（x 之间不能太相关） |
| R² | 较低 | 较高（因为多了变量） |

## 十、为什么不用别的方法？

- **为什么不只做一元回归？** 一元把工龄、性别等效应全混进教育系数里（本例教育系数从一元 0.551 降到多元 0.398），分不清谁在起作用；多元能"控制其他变量不变"，给出净效应。
- **为什么不算几个两两[[01_相关系数|相关系数]]就下结论？** 相关是两两的、对称的，控制不了第三个变量（鞋码和成绩都被年龄驱动）；多元回归把年龄放进去，鞋码的偏效应就归零，这是相关矩阵做不到的。
- **为什么控制变量不是越多越好？** 放太多变量会造成多重共线性（系数标准误暴涨、符号乱跳）；更危险的是控制了"坏控制变量"——比如被教育本身影响的职业，会把教育的真实效应吃掉。

## 十一、答辩常问（直接背）

1. **问：多元回归里 β₁=0.398 到底是什么意思？** 答：保持工龄等其他变量不变时，教育每多 1 年，工资平均变化 0.398 千元。这是"偏效应"不是总效应，总效应还要加上教育通过工龄等渠道的间接影响。
2. **问：为什么一元时教育系数 0.551，控制工龄后变成 0.398？** 答：一元系数混进了工龄的影响——教育多的人工龄往往短，两个效应叠加；多元把工龄控制住，教育的净效应就回落了，这正是控制变量的作用。
3. **问：跑出来提示 "omitted because of collinearity" 是什么意思？** 答：你放的某个 x 是其他 x 的精确线性组合（比如同时放男生、女生、性别），完全共线导致 (X'X) 不可逆，软件自动删掉一个；删掉重复或冗余变量即可。

---

## 十二、速记卡

> **多元回归 = 一个 y 对多个 x 同时回归。**
> **每个系数 = 控制其他变量不变时，这个 x 的偏效应。**
> **矩阵形式：β̂ = (X'X)⁻¹ X'y。**
> **控制变量能排除混淆（鞋码 vs 成绩的例子）。**
> **控制变量不是越多越好，要防共线性。**

## 💡 经济学视角：多元线性回归——"其他条件不变"的数学实现

**这个方法是为了解决什么经济学问题？**
经济学教科书最爱说一句话："其他条件不变，价格涨了需求降"。问题是现实里"其他条件"从来不变——你观察到工资高的人，往往教育也多、经验也足。那工资高到底是学历的功劳还是工龄的功劳？多元回归就是把其他变量一起放进方程，把它们的影响各自"控制住"，单独看某一个 x 对 y 的净效应。生产函数 Q = f(K, L) 就是最经典的二元回归：资本和劳动同时影响产出，得拆开估。

**经济学里哪些经典模型是多元回归？**

| 经济学模型 | 回归形式 | 在控制什么 |
|---|---|---|
| 生产函数 | Q = β₁K + β₂L | 控制资本看劳动的边际产出 |
| 工资方程 | lnW = β₁edu + β₂exp + β₃gender | 控制教育经验看性别工资差 |
| 需求函数 | Q = β₁P + β₂I + β₃P_替代品 | 控制收入和替代品看自身价格效应 |

**举个实证论文的例子：**
《中国制造业边际报酬递减的检验》用工业企业数据跑 lnQ = β₁lnK + β₂lnL，发现固定资本后 β₂ ≈ 0.5（劳动的产出弹性），且资本越密集的企业 β₂ 越小——证实了边际报酬递减规律：活多人更多，多一个工人带来的产出增量在下降。
