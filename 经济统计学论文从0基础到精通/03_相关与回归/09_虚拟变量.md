# 09 虚拟变量：把"性别/地区"变成 0 和 1

## 一、为什么要学这个？

你的数据里有"性别"这个变量：男 / 女。
回归要求 x 是数字，你不能直接把"男""女"塞进回归方程。

怎么办？**把它变成 0 和 1**：
- 男 = 1；
- 女 = 0。

这就叫**虚拟变量**（dummy variable）。

经济学论文里几乎所有分类变量都要这么处理：性别、地区、行业、是否国企、东部中部西部……

---

## 二、是什么？

### 生活比喻：开关

虚拟变量就像一个开关：
- 开（=1）：这个人是男的；
- 关（=0）：这个人不是男的（是女的）。

回归系数告诉你：**开关从关拨到开，y 平均变多少。**

### 严格定义

**虚拟变量** $D_i$：只能取 0 或 1 的变量。

$$D_i = \begin{cases} 1, & \text{如果第 i 个人属于某类} \\ 0, & \text{否则} \end{cases}$$

### 系数怎么解释？

回归方程：$y = \beta_0 + \beta_1 D + \varepsilon$

- 当 D=0（女）：$E[y|D=0] = \beta_0$
- 当 D=1（男）：$E[y|D=1] = \beta_0 + \beta_1$

**$\beta_1$ = 男性平均工资 - 女性平均工资。**

就这么简单。

> ⚠️ 但这个"性别工资差 3083 元"**不能直接写成"性别歧视 3083 元"**。男女在行业、加班、连续工作年限上都不同，这些混淆变量没控制住之前，β₁ 只是相关，不是因果。教材笔记里[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP12_相关不等于因果与应用注意|KP12 相关不等于因果与应用注意]]专门讲了这种"回归系数一眼看去像因果、其实不是"的坑——写讨论部分前务必读。

---

## 三、多分类变量怎么办？

如果有 3 类：东部、中部、西部。

**错误做法**：设三个虚拟变量 east, central, west，全放进回归。
**为什么错？** east + central + west = 1（每个人必属于其中一类），完全共线性。

**正确做法**：**留一个做基准组**。
- 设 east = 1 代表东部，0 代表其他；
- 设 central = 1 代表中部，0 代表其他；
- west 不设——它是基准组。

**系数解释**：
- β_east：东部相对于**西部**的工资差异；
- β_central：中部相对于**西部**的工资差异。

**基准组可以任选**，不影响整体拟合，只影响系数解释。论文里一般选最常见或最不重要的做基准。

## 四、符号表

| 符号 | 是什么 |
|------|--------|
| $D_i$ | 虚拟变量，0 或 1 |
| $\beta_D$ | 虚拟变量的系数 = 两组均值之差 |
| 基准组 | 被省略的那一类（D=0 的组） |

## 五、一个完整的数字例子

**数据**：5 个人的工资（y，千元）和性别（D：男=1，女=0）：

| i | y | D（男=1） |
|---|---|-----------|
| 1 | 3 | 0 |
| 2 | 4.5 | 0 |
| 3 | 5 | 1 |
| 4 | 7 | 1 |
| 5 | 8.5 | 1 |

### 手算（用 [[04_OLS截距和拟合值|OLS]] 公式）

均值：
$$\bar{y} = 5.6, \quad \bar{D} = 3/5 = 0.6$$

| i | $D_i - \bar{D}$ | $y_i - \bar{y}$ | 乘积 | $(D_i-\bar{D})^2$ |
|---|-----------------|-----------------|------|---------------------|
| 1 | -0.6 | -2.6 | 1.56 | 0.36 |
| 2 | -0.6 | -1.1 | 0.66 | 0.36 |
| 3 | 0.4 | -0.6 | -0.24 | 0.16 |
| 4 | 0.4 | 1.4 | 0.56 | 0.16 |
| 5 | 0.4 | 2.9 | 1.16 | 0.16 |
| 求和 | | | **3.70** | **1.20** |

$$\hat{\beta}_D = \frac{3.70}{1.20} = 3.083$$

$$\hat{\beta}_0 = \bar{y} - \hat{\beta}_D \bar{D} = 5.6 - 3.083 \times 0.6 = 3.75$$

### 解释结果

- **β₀ = 3.75**：女性（D=0）的平均工资 = 3750 元；
- **β_D = 3.083**：男性比女性平均工资高 3083 元；
- 男性平均工资 = 3.75 + 3.083 = 6.833 千元。

**验证**：女性均值 = (3+4.5)/2 = 3.75 ✅；男性均值 = (5+7+8.5)/3 = 6.833 ✅。

**所以虚拟变量回归 = 两组均值之差，就这么简单。**

### Python 验证

```python
import numpy as np
import statsmodels.api as sm

y = np.array([3, 4.5, 5, 7, 8.5])
D = np.array([0, 0, 1, 1, 1])

X = sm.add_constant(D)
model = sm.OLS(y, X).fit()
print(model.summary())
# const=3.75, x1=3.083
```

## 六、虚拟变量和交互项（简单提一下）

如果你想知道"教育对工资的影响，男女是否不同"，要加**交互项**：

$$y = \beta_0 + \beta_1 edu + \beta_2 male + \beta_3 (edu \times male) + \varepsilon$$

- β₁：女性的教育回报率；
- β₃：男性教育回报率比女性高多少；
- 男性教育回报率 = β₁ + β₃。

本科论文一般做到这里就够了。

### 截距虚拟变量 vs 斜率虚拟变量：别搞混

> 📖 教材笔记[[../../教材笔记/02_计量经济学/08_模型设定与数据问题/知识点/KP03_虚拟变量|计量·虚拟变量]]专门区分了这两种用法。

虚拟变量能改变**截距**，也能改变**斜率**，看你怎么放：

| 类型 | 模型形式 | β₂ 的含义 | 图形 |
|------|---------|----------|------|
| **截距虚拟变量** | y = β₀ + β₁x + β₂D | 两组**截距之差**（平行的两条线） | 台阶式平行 |
| **斜率虚拟变量**（交互项） | y = β₀ + β₁x + β₂(D·x) | 两组**斜率之差**（从同一点发散） | 从原点分叉 |
| **截距+斜率都变** | y = β₀ + β₁x + β₂D + β₃(D·x) | 截距和斜率都不同 | 两条完全独立的线 |

**生活直觉**：
- 截距不同 = 两条平行的线，高低不同但倾斜程度一样（男女都有教育回报率，但起薪不同）；
- 斜率不同 = 从同一点出发，越走越远（教育对男女工资的影响幅度不同）；
- 截距斜率都不同 = 两条完全独立的线（最一般的情况）。

**Stata 写法**：
```stata
* 截距虚拟变量：reg wage edu male
* 斜率虚拟变量：reg wage edu c.edu#male  （或 gen edu_male = edu*male）
* 截距+斜率都变：reg wage edu male c.edu#male
```

### Chow 检验：两组回归到底有没有结构差异？

**问题**：跑了两个回归（女性一个、男性一个），怎么判断这两个回归真的不一样？

**方法**：Chow 检验（结构变动检验）——

原假设 H₀：两组回归的截距**和**所有斜率全部相同（可以用一条线拟合两组数据）。

- 如果不拒绝 H₀ → 两组没区别，合并跑一个回归就行；
- 如果拒绝 H₀ → 两组有结构差异，必须分开跑（或用交互项）。

**Stata 里怎么做**：
```stata
* 用虚拟变量+交互项，联合检验 D 和 D*x 是否显著
reg wage edu male c.edu#male
test male c.edu#male   // 联合检验，F 检验
* 如果 F 对应的 p < 0.05 → 两组有结构差异
```

> ⚠️ **单个虚拟变量的 t 检验 ≠ Chow 检验**。t 检验只比较截距差；Chow 检验是对整个结构（截距+斜率）的联合检验。

## 七、易错点

1. **n 类分类变量只设 n-1 个虚拟变量**，留一个做基准。否则完全共线性。
2. **基准组选择影响系数解释，不影响 R²**。选谁都行，但要在论文里说清楚"以西部为基准组"。
3. **虚拟变量系数是均值差，不是百分比**。要解释百分比的话，对 y 取对数：$\ln y = \beta_0 + \beta_1 D + \varepsilon$，这时 β₁ ≈ 两组对数工资差。
4. **不要把虚拟变量当连续变量解释**。D=0.5 没意义，它只能是 0 或 1。

## 八、Stata / Python 代码

```stata
* Stata：性别虚拟变量
gen male = (gender == "男")   // 男=1，女=0

* 多分类：地区（留西部做基准）
gen east = (region == "东部")
gen central = (region == "中部")
* west 不设，是基准组

reg wage edu male east central
```

```python
import pandas as pd

# 假设 df 有 gender 列（"男"/"女"）
df['male'] = (df['gender'] == '男').astype(int)

# 多分类：用 pandas 自动生成（drop_first 留一个做基准）
dummies = pd.get_dummies(df['region'], prefix='region', drop_first=True)
df = pd.concat([df, dummies], axis=1)
```

## 九、对比

| 变量类型 | 怎么处理 | 系数解释 |
|---------|---------|---------|
| 连续变量 | 直接放 | x 变 1 单位，y 变 β |
| 二分类（性别） | 设 1 个虚拟变量 | β = 两组均值差 |
| 多分类（地区 n 类） | 设 n-1 个虚拟变量 | β = 相对于基准组的差 |
| 定序变量 | 可当连续（谨慎）或设虚拟变量 | 当连续时假设等距 |

## 十、为什么不用别的方法？

- **为什么不直接把"男/女"当数字 1/2 塞进回归？** 那样"2"没有量纲意义，回归会误读成"男比女大 1 个单位"的连续效应，系数解释完全错；必须设成 0/1 开关，系数才是两组均值差。
- **为什么 n 类地区只设 n-1 个虚拟变量？** 设 n 个时，n 个虚拟变量加起来恒等于 1，和截距完全共线，(X'X) 不可逆，软件会自动删一个并提示 omitted；留一个做基准组是数学上的必然。
- **为什么不分别对男女各跑一个回归？** 分组回归会把样本劈成两半、每组样本量减半、标准误变大，还没法检验"两组系数是否真的不同"；用 male 虚拟变量（加交互项）一个方程搞定，样本量不损失，还能直接出差异的显著性。

## 十一、答辩常问（直接背）

1. **问：虚拟变量的系数怎么解释？** 答：D=1 组相对于基准组（D=0）的因变量均值差。本例 β_D=3.083 就是男性比女性平均工资高 3083 元；女性均值就是截距 3.75。
2. **问：换一个基准组，结果会变吗？** 答：R²、拟合、系数显著性都不变，只变系数的解释口径——从"相对西部的差"变成"相对中部的差"；论文里必须写明以谁为基准。
3. **问：想知道教育回报男女不同，模型怎么写？** 答：加交互项 y = β₀+β₁edu+β₂male+β₃(edu×male)。β₁ 是女性教育回报，β₃ 是男性比女性高出的部分，男性教育回报 = β₁+β₃。

---

## 十二、速记卡

> **虚拟变量 = 0/1 开关，把分类变量变成回归能用的数字。**
> **n 类设 n-1 个，留一个做基准组。**
> **系数 = 该组相对于基准组的均值差。**
> **基准组任选，不影响 R²，只影响解释。**
> **交互项 = 两个变量相乘，看效应是否不同。**

## 💡 经济学视角：虚拟变量——把"城乡、男女、政策前后"塞进回归

**这个方法是为了解决什么经济学问题？**
很多经济学问题本身就是"组与组之间的差别"：城镇户口 vs 农村户口，男性 vs 女性，政策前 vs 政策后。这些类别不是数字，是标签。虚拟变量就是把标签翻译成 0 和 1：是城镇户口 = 1，农村 = 0。放进回归，系数就是"两组人平均差多少"。性别工资差距、城乡收入差距、政策试点效应，全靠它来量化。

**经济学里哪些经典问题用虚拟变量回答？**

| 问题 | 虚拟变量设计 | 系数含义 |
|---|---|---|
| 性别工资差距 | female = 1（女）/ 0（男） | 女性比男性平均少挣多少 |
| 城乡收入差距 | urban = 1（城）/ 0（乡） | 城镇户口多挣多少 |
| 政策效果（DID） | treat × post | 试点组在政策后多变化了多少 |
| 行业差异 | 行业哑变量 | 控制行业固定效应 |

**举个实证论文的例子：**
《中国性别工资差距的分解（2002—2018）》用 CHIP 数据跑 lnW = α + βfemale + γedu + δexp + ...，发现 β 从 -0.20 缩小到 -0.10——控制教育和经验后，女性工资仍然比男性低约 10%（e^-0.10 ≈ 0.90）。这个差距缩小了一半，但仍然显著存在。
