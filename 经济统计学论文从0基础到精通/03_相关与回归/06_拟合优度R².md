# 06 拟合优度 R²：模型解释了多少？

> 📖 这一篇讲的 R²，教材笔记里叫[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP09_拟合优度R2|KP09 拟合优度 R²]]，那里从三个平方和（TSS/ESS/RSS）出发推导 R²，和下面的路径完全一致，可以对照看。

## 一、为什么要学这个？

导师看完你的回归结果，第一句话通常是："R² 多少？"

- R² = 0.3：你的模型只解释了工资变异的 30%，还有 70% 没解释；
- R² = 0.8：模型解释得很好。

**R² 是衡量"你的直线贴散点贴得有多紧"的指标。**

不学会怎样？你论文里 R² = 0.1 还写"模型拟合良好"，导师会笑。

---

## 二、是什么？

### 生活比喻：射击比赛

你打靶，真实成绩是 y。
- 如果你不看任何变量，直接猜均值 ȳ——这是"基线模型"，偏差是 $y_i - \bar{y}$；
- 如果你用回归直线预测，偏差是 $y_i - \hat{y}_i = e_i$。

**R² 就是看：用了回归之后，偏差比基线模型小了多少。**

### 三个平方和

| 名称 | 公式 | 是什么 |
|------|------|--------|
| **TSS**（总平方和） | $\sum(y_i - \bar{y})^2$ | 不用 x，直接猜均值的总偏差 |
| **ESS**（解释平方和） | $\sum(\hat{y}_i - \bar{y})^2$ | 回归直线"解释了"的偏差 |
| **RSS**（残差平方和） | $\sum(y_i - \hat{y}_i)^2$ | 回归直线"没解释"的偏差 |

**关键恒等式**：

$$TSS = ESS + RSS$$

**直觉**：真实值和均值的总偏差，被分成两部分——回归直线解释了的（ESS），和没解释的残差（RSS）。

### R² 定义

$$R^2 = \frac{ESS}{TSS} = 1 - \frac{RSS}{TSS}$$

- $R^2 = 1$：RSS = 0，所有点都在直线上，完美拟合；
- $R^2 = 0$：ESS = 0，直线和均值线一样，x 啥也没解释；
- $0 < R^2 < 1$：模型解释了一部分。

---

## 三、公式怎么来的？

### 第一步：分解 TSS

$$y_i - \bar{y} = (y_i - \hat{y}_i) + (\hat{y}_i - \bar{y})$$

**这一步是因为**：左边是"真实值离均值多远"，右边拆成"真实值离直线多远"加"直线离均值多远"。

两边平方再求和：

$$\sum(y_i - \bar{y})^2 = \sum[(y_i - \hat{y}_i) + (\hat{y}_i - \bar{y})]^2$$

展开：

$$TSS = \sum(y_i - \hat{y}_i)^2 + \sum(\hat{y}_i - \bar{y})^2 + 2\sum(y_i - \hat{y}_i)(\hat{y}_i - \bar{y})$$

**交叉项 = 0**（这是 [[04_OLS截距和拟合值|OLS]] 的数学性质，因为 Σe = 0 且 Σx·e = 0），所以：

$$TSS = RSS + ESS$$

### 第二步：R² = ESS/TSS

ESS 占 TSS 的比例，就是"模型解释的部分"。

---

## 四、符号表

| 符号 | 是什么 |
|------|--------|
| TSS | Total Sum of Squares，总平方和 |
| ESS | Explained Sum of Squares，解释平方和 |
| RSS | Residual Sum of Squares，残差平方和 |
| R² | 拟合优度，[0, 1] |

**注意**：有些教材把 RSS 叫 SSR，ESS 叫 ESS，名字不统一，但公式一样。

## 五、一个完整的数字例子手算

用上一章的 5 个点（[[KP04_一元回归Stata解读|一元回归]]，â=-1.888，b̂=0.551）：

| i | y | ŷ | y-ȳ | (y-ȳ)² | ŷ-ȳ | (ŷ-ȳ)² | e=y-ŷ | e² |
|---|---|---|------|---------|------|---------|-------|------|
| 1 | 3 | 3.071 | -2.6 | 6.76 | -2.529 | 6.396 | -0.071 | 0.005 |
| 2 | 4.5 | 4.724 | -1.1 | 1.21 | -0.876 | 0.767 | -0.224 | 0.050 |
| 3 | 5 | 4.724 | -0.6 | 0.36 | -0.876 | 0.767 | 0.276 | 0.076 |
| 4 | 7 | 6.928 | 1.4 | 1.96 | 1.328 | 1.764 | 0.072 | 0.005 |
| 5 | 8.5 | 8.581 | 2.9 | 8.41 | 2.981 | 8.886 | -0.081 | 0.007 |
| 求和 | | | | **18.70** | | **18.58** | | **0.143** |

**验证恒等式**：ESS + RSS = 18.58 + 0.143 = 18.72 ≈ TSS = 18.70（小误差四舍五入）。✅

**R²**：

$$R^2 = \frac{ESS}{TSS} = \frac{18.58}{18.70} = 0.9936$$

**R² ≈ 0.994**——几乎完美拟合，因为这 5 个点本来就几乎在一条直线上。

### Python 验证

```python
import numpy as np

y = np.array([3, 4.5, 5, 7, 8.5])
y_hat = np.array([3.071, 4.724, 4.724, 6.928, 8.581])

tss = np.sum((y - y.mean())**2)
ess = np.sum((y_hat - y.mean())**2)
rss = np.sum((y - y_hat)**2)

print(f"TSS = {tss:.2f}")     # 18.70
print(f"ESS = {ess:.2f}")     # 18.58
print(f"RSS = {rss:.3f}")     # 0.143
print(f"R² = {ess/tss:.4f}")  # 0.9936
```

## 六、R² = 1 和 R² = 0 分别意味着什么？

### R² = 1

所有点都在回归直线上，RSS = 0。
**现实中几乎不可能**——除非你只有 2 个点（两点定一直线，R² 必为 1）。
经济学论文里 R² = 0.8 已经算很高了。

### R² = 0

回归直线和均值线一模一样，x 对 y 一点解释力都没有。
**意味着**：你的自变量完全没用，模型和"直接猜均值"一样差。

### 经济学论文里 R² 多少算正常？

- 微观面板数据：R² = 0.2 ~ 0.5 很常见（人与人之间差异太大）；
- 宏观时间序列：R² = 0.8 ~ 0.9 常见（趋势性强）；
- 不要追求高 R²——R² 高不代表因果对，R² 低不代表模型错。

---

## 七、加变量 R² 必升（重要性质）

**R² 有个讨厌的性质**：你往回归里加任何一个变量，哪怕是随机噪声，R² 也会上升（或不变）。

为什么？因为 SSE 公式里，多一个变量，你就多一个"自由度"去拟合数据，RSS 只会变小不会变大。

**这就引出了调整 R²（Adjusted R²）**：

$$\bar{R}^2 = 1 - \frac{RSS/(n-k-1)}{TSS/(n-1)}$$

它对加太多变量做惩罚。变量越多，调整 R² 惩罚越大。

**论文里一般两个都报**：R² 和调整 R²。
如果加了一个变量，R² 升了但调整 R² 降了，说明这个变量没用。

### 为什么多元回归一定要看调整 R²？

> 📖 教材笔记[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP09_拟合优度R2|KP09 拟合优度 R²]]专门讲了这个区别。

**打个比方**：你装修房子，每多一面墙就多挂一幅画。墙上挂的画越多，看起来越"丰富"（R² 越高），但最后一面墙挂的可能只是废纸——为了挂而挂的。

调整 R² 就是在问：**这面新墙挂的画，值不值得？**

它的公式里有个惩罚项 $(n-k-1)$：k（自变量个数）越大，惩罚越重。

| 情况 | R² | 调整 R² | 说明 |
|------|-----|--------|------|
| 加了个有用变量 | ↑ | ↑ | 真正提升了解释力 |
| 加了个噪声变量 | ↑ | ↓ | 靠自由度硬凑出来的 R²，被惩罚打回原形 |
| 一元回归 | = R² | ≈ R² | k=1 时惩罚很小，两者几乎一样 |

**经验法则**：一元回归里 R² 和调整 R² 差不多；多元回归里一定要看调整 R²。

---

## 七·五、一元回归里 R² = r²（重要关系）

> 📖 教材笔记[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP03_相关系数r的直觉|KP03 相关系数 r 的直觉]]和[[../../教材笔记/02_计量经济学/03_一元线性回归/知识点/KP03_拟合优度R2|计量·拟合优度 R²]]都提到了这个关系。

**一元回归里，可以证明 $R^2 = r^2$**——相关系数的平方。

**为什么？** 因为：
- 相关系数 r 衡量 x 和 y 的线性相关程度；
- 一元回归里，ŷ 完全由 x 决定；
- 所以"x 解释了 y 变异的多少"（R²），就等于"x 和 y 的线性相关有多强"（r²）。

**用前面 5 个人的数据验证**：
- r = 0.996（[[01_相关系数|上一篇]]算的）
- r² = 0.996² = 0.992
- R² = 0.994（前面手算的）

对上了 ✅（小差异是四舍五入）。

**注意**：
- r 带方向（正/负），R² 不带方向（永远非负）；
- 想看"是正相关还是负相关"看 r；想看"解释了多少比例"看 R²；
- **多元回归里这个关系不成立**——因为多元里没有单一的 x 对 y 的相关系数，R² 衡量的是"整组 x"对 y 的解释比例。

---

## 八、易错点

1. **R² 高 ≠ 模型对**。你用 GDP 预测货币供应量，R² = 0.99，但这可能是"共同趋势"，不是因果。
2. **R² 低 ≠ 模型错**。微观数据 R² = 0.1 很正常，关键看系数是否显著、符号是否对。
3. **R² 不能跨数据集比**。工资数据 R² = 0.3 和 GDP 数据 R² = 0.8，没法比谁好。
4. **R² 不是"解释了百分之多少的 y"**。它是"解释了 y 变异的百分之多少"。一字之差，意思完全不同。

## 九、Stata / Python 代码

```stata
reg wage edu tenure
* Stata 输出右上角直接显示：
* R-squared = 0.xxx
* Adj R-squared = 0.xxx
```

```python
import statsmodels.api as sm

X = sm.add_constant(df[['edu', 'tenure']])
model = sm.OLS(df['wage'], X).fit()

print(f"R² = {model.rsquared:.4f}")
print(f"调整 R² = {model.rsquared_adj:.4f}")
```

## 十、对比

| 指标 | 范围 | 用途 |
|------|------|------|
| R² | [0, 1] | 模型拟合优度 |
| 调整 R² | 可能为负 | 对过多变量做惩罚 |
| [[01_相关系数|相关系数]] r | [-1, 1] | 两个变量的线性相关 |

**注意**：一元回归里，$R^2 = r^2$（相关系数的平方）。[[KP03_多元回归Stata|多元回归]]里这个关系不成立。

---

## 十一、为什么不用别的方法？

- **为什么不用残差和 Σe 直接衡量拟合好坏？** 残差和在 OLS 下恒等于 0（正负抵消），再好再差的模型都等于 0，分不出高低；必须用残差平方和 RSS，或它占 TSS 的比例 R²。
- **为什么不只看 R²、还要看调整 R²？** R² 有个作弊性质：随便加个噪声变量它也只升不降，会诱导你堆变量；调整 R² 按变量个数惩罚，加了没用的变量它会下降，能防止为了凑高 R² 而过拟合。
- **为什么不用相关系数 r 代替 R²？** r 只在一元回归里等于 √R²；多元回归里一个因变量对多个自变量没有单一相关系数。R² 衡量"整组 x"对 y 的解释比例，r 做不到。

---

## 十二、答辩常问（直接背）

1. **问：R²=0.3 是不是说明模型很差？** 答：不一定。微观个人数据 R²=0.2~0.5 很常见，因为人与人差异本就大；关键看系数符号对不对、显不显著，而不是硬追高 R²。宏观时间序列 R²=0.8~0.9 才正常。
2. **问：加了一个变量，R² 从 0.5 升到 0.52，调整 R² 反而降了，说明什么？** 答：这个新变量是噪声，它靠多一个自由度硬拟合了样本，没有真正提升解释力，不该留。
3. **问：R² 能不能跨数据集比较？** 答：不能。被解释变量和样本都不同时（工资 vs GDP），R² 没有可比性；而且 R² 高可能只是共同趋势（GDP 和货币量都随时间涨），不代表因果对。

---

## 十三、速记卡

> **TSS = ESS + RSS（总偏差 = 解释的 + 没解释的）。**
> **R² = ESS/TSS = 1 - RSS/TSS。**
> **R²=1 完美拟合，R²=0 x 啥也没解释。**
> **加变量 R² 必升，所以要看调整 R²。**
> **R² 高不代表因果对，R² 低不代表模型错。**

## 💡 经济学视角：拟合优度 R²——你的经济模型说清了多少故事？

**这个方法是为了解决什么经济学问题？**
工资因人而异，有的高有的低。你的模型（教育 + 经验 + 性别）能解释其中多少比例？R² 就是这个比例：R² = 0.8 意味着你选的这几个解释变量，把工资差异的 80% 都说清楚了；剩下 20% 是运气、行业、人脉这些你没放进模型的东西。经济学家用 R² 判断模型"够不够格"——太低说明重要变量漏了，太高要警惕是不是过拟合。

**经济学里 R² 的典型量级：**

| 研究场景 | 常见 R² | 怎么理解 |
|---|---|---|
| 宏观时间序列（GDP 增速解释） | 0.3—0.6 | 经济预测天生难 |
| 微观工资方程 | 0.2—0.4 | 工资里有很大一部分"说不清" |
| 消费函数（省级面板） | 0.7—0.9 | 收入几乎决定消费 |
| 金融日度收益率 | < 0.05 | 股价短期近乎随机游走 |

**举个实证论文的例子：**
《消费函数的稳定性检验》跑 C = α + βY，R² 常年在 0.85 以上——居民消费 85% 的 variation 能用收入解释，这验证了凯恩斯消费函数在中国的适用性。加进利率、财富等变量后 R² 只涨到 0.87，说明传统消费函数已经差不多够解释了，再多加变量是边际改进。
