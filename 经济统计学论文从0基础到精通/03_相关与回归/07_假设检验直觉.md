## 一、为什么要学这个？

你跑回归出来，教育年限的系数是 0.398。
导师问："这个 0.398 是真的有效应，还是碰巧抽出来的？"

你怎么回答？

- 如果样本量很大、这个 0.398 很稳定——那它是真的；
- 如果样本只有 5 个、0.398 可能是随机波动——那它可能是假的。

**假设检验就是帮你判断：这个系数是真信号，还是噪声？**

p 值、5% 显著性、星号（***），都是这一章的内容。

---

## 二、是什么？

### 生活比喻：法庭判案

想象你是法官，被告是"教育年限对工资有影响"。

**法庭原则：无罪推定。**
- **原假设 H₀**：被告无罪（教育对工资**没有**影响，β = 0）；
- **备择假设 H₁**：被告有罪（教育对工资**有**影响，β ≠ 0）。

> 📖 关于"为什么原假设要设成'没效应'、等号为什么永远在 H₀ 这边"，教材笔记里讲得更细：[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP02_原假设与备择假设|KP02 原假设与备择假设]]。

**证据**：你的回归系数 0.398 就是证据。
- 如果证据很强（系数离 0 很远），就推翻原假设——判"有罪"（教育真的有影响）；
- 如果证据不够强（系数离 0 很近），就不能推翻原假设——"无罪释放"（不能说教育有影响）。

**p 值是什么？**

p 值 = "如果被告真的无罪（H₀ 成立），我们看到这么强证据的概率"。

> 💡 换句话说：**p 值就是在"假设原假设是真的"这个平行世界里，我们观察到当前数据（或比当前更极端数据）的概率有多小。** 它越小，说明原假设这个平行世界越离谱。详细的小白解释看[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP06_P值|KP06 P 值]]。

- p = 0.001：如果教育真的没影响，我们抽样本抽出 0.398 这么大系数的概率只有 0.1%——太离谱了，所以我们不信 H₀，判有罪；
- p = 0.30：如果教育真的没影响，我们看到这个证据的概率有 30%——很正常，不能说被告有罪。

### 显著性水平 5%

我们约定一个阈值：**p < 0.05 就算"证据够强"**。
- p < 0.05：在 5% 水平显著（一颗星 *）；
- p < 0.01：在 1% 水平显著（三颗星 ***）；
- p > 0.05：不显著。

**为什么是 5%？** 历史上 Fisher 定的，没有深刻道理，就是惯例。这个 5% 在统计上叫**显著性水平 α**，详细讨论看[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP04_显著性水平|KP04 显著性水平 α]]——它的真实含义是"我们愿意承担多大比例的冤枉好人的风险"。

## 三、假设检验的五步法

> 📖 这五步是统计学里所有假设检验（Z 检验、t 检验、F 检验、卡方检验……）的通用骨架，教材笔记[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP01_假设检验的逻辑|KP01 假设检验的逻辑]]把它概括成"反证法 + 小概率事件原理"：先假设 H₀ 成立，再看小概率事件有没有发生，如果发生了就推翻 H₀。下面是具体操作。

1. **设原假设**：$H_0: \beta = 0$（这个变量没影响）；
2. **设备择假设**：$H_1: \beta \neq 0$（有影响，双尾）；
3. **算检验统计量**：t = b̂ / SE(b̂)（系数除以标准误）；
4. **算 p 值**：在 H₀ 成立时，看到这么大 t 值的概率；
5. **下结论**：p < 0.05 拒绝 H₀，否则不拒绝。

### 为什么原假设总是"没有效果"？

> 📖 教材笔记[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP02_原假设与备择假设|KP02 原假设与备择假设]]讲了这个问题。

你可能会问：为什么不设 H₀: β = 0.5（"教育真的有影响"）？那样直接证明多好？

**数学原因**：只有 H₀ 带等号时，分布才是确定的，才能算概率。

- 如果 H₀: β = 0 → 分布完全确定（t = b̂/SE，均值为 0）
- 如果 H₀: β = 0.5 → 分布的均值是 0.5，但我们不知道它的位置……那 p 值怎么算？

**逻辑原因**：我们想证明的是"有影响"，但统计推断的规则是"推翻一个默认假设"。默认"没影响"，只有数据足够有力地反对它，我们才承认"有影响"。这和法庭"默认无罪，证据不足则无罪释放"是一个道理。

**一句话**：H₀ 是"无罪推定"——我们要尽量避免"冤枉好人"（第一类错误），而不是"放过坏人"（第二类错误）。

### p 值不是"结果正确的概率"

> 📖 教材笔记[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP06_P值|KP06 P 值]]专门纠正了这个误解。

**最常见的错误理解**：p = 0.04 意味着"这个结论有 4% 的概率是错的"或"原假设有 4% 的概率是对的"。

**正确定义**：p = 0.04 意味着——**如果原假设是真的**，我们只有 4% 的概率看到这么极端（或更极端）的数据。

**类比**：法庭上 p 值 = "如果被告真的无罪，证据竟如此不利的概率"。这个概率越小，我们越倾向于"有罪"。但它**不是**"被告有罪的概率"——被告要么有罪要么无罪，没有概率可言。

> ⚠️ **p = 0.04 和 p = 0.06 差别不大**——0.05 只是人为划定的线。p = 0.051 和 p = 0.049 在统计上几乎一样，但很多论文会因为差 0.002 就"显著"或"不显著"，这是对 0.05 的迷信。

| 符号 | 是什么 |

| $H_0$ | 原假设（默认对） |
| $H_1$ | 备择假设（想证明的） |
| $\alpha$ | 显著性水平（通常 0.05） |

| $\hat{\beta}$ | 估计系数 |

## 五、一个完整的数字例子

**问题**：回归出来教育系数 b̂ = 0.398，标准误 SE = 0.179。这个系数显著吗？

### 第一步：设假设

- H₀: β = 0（教育对工资没影响）；
- H₁: β ≠ 0。

### 第二步：算 t 值

$$t = \frac{\hat{\beta}}{SE(\hat{\beta})} = \frac{0.398}{0.179} = 2.221$$

### 第三步：看 p 值

自由度 = n - k - 1 = 5 - 2 - 1 = 2。
查 t 分布表（或 Python 算），t = 2.221、自由度 2 时，p ≈ 0.157。

### 第四步：下结论

p = 0.157 > 0.05——**不拒绝 H₀**。
意思：在 5% 水平下，我们不能说教育对工资有影响。

**为什么？** 因为样本太小（5 个），标准误还是偏大（0.179），0.398 这个系数虽然离 0 不算近，但 5 个样本的 t 分布尾巴很厚，可能就是随机波动。

### Python 验证

```python
from scipy import stats

t_stat = 0.398 / 0.179
df = 5 - 2 - 1  # 自由度
p_value = 2 * (1 - stats.t.cdf(abs(t_stat), df))

print(f"t = {t_stat:.3f}")        # 2.221
print(f"p = {p_value:.3f}")        # 0.157
```

## 六、两类错误（直觉）

> 📖 教材笔记里这一节叫[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP03_两类错误|KP03 两类错误]]，配了经典的"医生看病"和"法官判案"对照表，建议对照读。

### 法官判案的四格表

还是用法庭比喻。被告实际上要么真有罪、要么真无罪；法官要么判有罪、要么判无罪。组合起来就是四种结局：

|  | **实际：被告无罪（H₀ 真）** | **实际：被告有罪（H₀ 假）** |
|---|---|---|
| **法官判：有罪（拒绝 H₀）** | ❌ **第一类错误**：冤枉好人<br>统计学术语叫"**弃真错误**"，概率 = $\alpha$ | ✅ 正确判决（抓住坏人）<br>这个概率叫**检验力** = $1 - \beta$ |
| **法官判：无罪（不拒绝 H₀）** | ✅ 正确判决（无罪释放） | ❌ **第二类错误**：放走坏人<br>统计学术语叫"**取伪错误**"，概率 = $\beta$ |

### 换成回归的语言

- **第一类错误（弃真，α）**：教育其实**没用**，但你的回归显著、你说它有用——**虚报效应**。
  - 法官版：把好人错判入狱。
  - 论文版：你报告了一个其实不存在的效应。
- **第二类错误（取伪，β）**：教育其实**有用**，但你的回归不显著、你没检测出来——**漏报效应**。
  - 法官版：把坏人无罪释放。
  - 论文版：真实存在的效应被你错过，原因通常是样本太小、标准误太大。

### α 和 β 的跷跷板关系

- **5% 显著性水平 α**，就是我们主动约束"冤枉好人"的概率上限是 5%——法庭上我们宁可错放三千，不可冤枉一个。
- 但 α 压得越低（比如 1%），门槛越高，就越容易"放走坏人"——**β 会变大**，检验力 $1-\beta$ 下降。
- 想同时降低 α 和 β？只有一个办法：**加大样本量 n**。样本越大，证据越清楚，法官越不容易判错。这就是为什么论文里样本量被反复强调。

### α 怎么选？不同场景对照表

> 📖 教材笔记[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP04_显著性水平|KP04 显著性水平]]讲了 α 的选择逻辑。

| α | 含义 | 什么时候用 | 典型场景 |
|---|------|-----------|---------|
| 0.10 | 10% 水平显著（*） | 探索性研究、样本小、初步证据 | 预实验、 pilot study |
| 0.05 | 5% 水平显著（**） | **默认惯例**，社科论文最常用 | 大多数论文 |
| 0.01 | 1% 水平显著（***） | 严格审查、重要结论、避免误判 | 医学临床试验、政策评估 |
| 0.001 | 0.1% 水平（****） | 极高要求、大数据 | 遗传学、大规模审计 |

**为什么 5% 是惯例？** 因为统计学家 Fisher 在 1925 年拍板的——"5% 是个合理的门槛，不算太松也不算太严"。这不是自然规律，是行业约定俗成。

**论文里怎么报**：
- 表注写："* p<0.10, ** p<0.05, *** p<0.01"
- 每个系数后面标星号
- 不要只说"显著"，要说"在 5% 水平下显著"

## 七、单尾检验还是双尾检验？

> 📖 教材笔记里[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP05_单尾检验与双尾检验|KP05 单尾检验与双尾检验]]专门讲了怎么选，下面是浓缩版。

### 先看 H₁ 长什么样

- **双尾检验**：$H_1: \beta \neq 0$（只问"有没有影响"，不管正负）。
  - 对应场景："教育对工资有没有影响？"——可能正可能负，你没把握。
  - p 值算的是"系数离 0 这么远**或更远**"的概率，**左右两个尾巴加起来**。
- **单尾检验**：$H_1: \beta > 0$（或 $<0$）（事先就知道方向）。
  - 对应场景："多上一年学，工资是不是**更高**？"——经济学理论已经告诉我们方向是正的。
  - p 值只算**一个尾巴**，所以同样的数据，单尾 p 值是双尾的一半，**更容易显著**。

### 怎么选？小白决策法

1. **写论文默认用双尾**。这是最保守、审稿人最不会质疑的做法。
2. 只有当你**有非常硬的理论依据**说方向一定是正（或一定是负），才用单尾——比如"教育年限"对"工资"，人力资本理论明明白白说正。
3. **不要为了凑显著而临时改单尾**。先看数据显著不显著，不显著再换单尾——这是 p-hacking，审稿人一眼看穿。
4. 选了单尾就要在论文里写清楚："本文采用单尾检验，因为……（理论依据）"。

### 数字直觉

同一个 t = 1.8、自由度 = 20：
- 双尾 p = 0.086（不显著）；
- 单尾 p = 0.043（显著了！）。

看到没？方向对了之后，单尾把"边缘显著"变成了"显著"。但这个权力不能滥用。

## 八、检验与置信区间的对偶关系

> 📖 教材笔记里[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP10_检验与置信区间的关系|KP10 检验与置信区间的关系]]画了一张图把这件事讲透，下面是它的直觉版。

### 一句话

**"在 5% 水平下不拒绝 H₀: β = 0"，等价于"β = 0 落在 β̂ 的 95% 置信区间里面"。**

反过来：
- **95% 置信区间包含 0** → 双尾 p > 0.05，不显著；
- **95% 置信区间不包含 0**（整个区间在 0 的同一边）→ 双尾 p < 0.05，显著。

### 用前面的例子验证

前面 edu 的回归结果：b̂ = 0.398，SE = 0.179。
Stata 输出里给的 95% 置信区间是 **[-0.374, 1.171]**。

- 这个区间**包含 0**（-0.374 < 0 < 1.171）→ 不显著；
- 前面算出来的 p = 0.157 > 0.05 → 不显著。

两个结论完全一致 ✅。

### 为什么要知道这个对偶？

1. **论文里置信区间和 p 值是一回事的两种说法**，审稿人两个都看。
2. **置信区间比 p 值信息量大**：p 值只告诉你"显不显著"，置信区间还告诉你"效应可能多大、多小"。比如 CI = [0.001, 0.002]，虽然显著，但效应小到没有经济意义。
3. **读 Stata 输出时一眼就能判断**：看置信区间那两列，如果 0 在中间，就是不显著，不用再去查 p 值。

## 九、易错点

1. **p 值不是"H₀ 成立的概率"**。p 值是"如果 H₀ 成立，看到这么大证据的概率"。这两个说法天差地别。
2. **p < 0.05 ≠ 系数很大**。样本量极大时，哪怕系数只有 0.001 也会显著——统计显著但经济上不重要。
3. **p > 0.05 ≠ 没有效应**。可能是样本太小、检验力不够（第二类错误）。
4. **不显著也能写论文**。你可以说"在 5% 水平下不显著，可能是样本量不足"，不要只报显著的结果。
5. **三颗星（***）不代表更重要**，只代表 p < 0.01，统计上更确定。

## 十二、为什么不用别的方法？

- **为什么不能只看系数大小判断有没有用？** 系数大但样本只有 5 个，很可能是随机噪声；检验把"信号除以噪声"（t=b̂/SE）[[KP11_标准化_ZScore|标准化]]，配合 5% 阈值，让不同人、不同研究的判断有统一、可重复的标准。
- **为什么不用 R² 高就说变量有用？** R² 会随堆变量自动上升，高 R² 还可能来自共同趋势；检验是针对单个系数 β=0 的直接证据，R² 给不了这个。
- **为什么不能 p=0.06 就说"边缘显著、差不多"？** 5% 是事先约定的证据门槛，p=0.06 就是没达到；硬说边缘显著等于随意降低标准，审稿人会质疑。正确做法是说明样本量不足、检验力不够。

## 十三、答辩常问（直接背）

1. **问：p=0.157，到底能不能说教育对工资有影响？** 答：不能。p=0.157>0.05，在 5% 水平不拒绝 H₀:β=0；意思是"现有样本下证据不够强"，不等于证明没影响，很可能是 n=5 样本太小、标准误太大。
2. **问：p 值是不是"原假设成立的概率"？** 答：不是。p 值是"假设 H₀ 真的成立，我们却抽到这么强（或更强）证据的概率"，是在 H₀ 成立这个前提条件下算出的条件概率，不能反过来读成 β=0 的概率。
3. **问：大样本下系数只有 0.001 也三颗星，是不是说明效应很强？** 答：不是。这是统计显著但经济上不重要——样本极大时标准误极小，微乎其微的系数也能显著；要同时报告系数大小和它的经济含义。

## 十四、速记卡

> **假设检验 = 法庭判案：无罪推定，证据够强才定罪。**
> **H₀: β=0（没效应），H₁: β≠0（有效应）。**
> **p 值 = H₀ 成立时看到这么强证据的概率。**
> **p<0.05 拒绝 H₀，p>0.05 不拒绝。**
> **第一类错误=弃真α（冤枉好人），第二类错误=取伪β（放走坏人），加大样本能同时降。**
> **论文默认双尾；有硬理论依据才用单尾，且不能事后改。**
> **95% 置信区间包含 0 ⇔ p>0.05 不显著。**
> **统计显著 ≠ 经济重要。**

## 💡 经济学视角：假设检验直觉——"这个政策真的有用吗"的判断逻辑

**这个方法是为了解决什么经济学问题？**
政府发了消费券，当地消费真涨了吗？涨了是政策的功劳，还是本来就要涨？假设检验就是给这种判断装一个"防自欺"的装置：先假设"政策完全没用"（原假设 β = 0），然后看数据出现当前这种情况的概率 p 有多小；如果 p < 0.05，就说"不太可能是巧合，政策大概率真有用"。整个政策评估、因果推断的根基就是这个直觉。

**经济学里哪些决策靠假设检验拍板？**
- 财政支出乘数：政府多花 1 块，GDP 真能多涨 1 块以上吗？
- 最低工资政策：涨最低工资真的会让失业上升吗？
- 教育回报率：多读一年书，工资真的显著更高吗？
- 通胀目标制：盯住通胀真能降低波动吗？

**举个实证论文的例子：**
《消费券政策的乘数效应——来自某城市试点的证据》跑 DID 回归，关键交互项系数估出来 0.8，p = 0.03（< 0.05）——说明发消费券真的让当地消费多涨了 8%，这个效果在统计上站得住，不是随机波动。作者据此建议：地方政府在经济下行期发消费券是有效的稳需求工具。
