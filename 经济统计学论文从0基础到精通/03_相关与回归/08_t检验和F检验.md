# 08 t 检验和 F 检验：单个系数 vs 整体回归

> - 如果检验对象是"总体比例 p"（比如合格率、投票率），逻辑一样、公式略不同：[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP09_总体比例检验|KP09 总体比例检验]]

## 一、为什么要学这个？

回归输出表里有两类检验：
- **t 检验**：每个变量一行，检验"这个系数是不是 0"；
- **F 检验**：表的底部，检验"所有系数联合起来是不是都等于 0"。

导师会问：
- "你这个教育系数 t 值多少？显著吗？" → t 检验；
- "你整个模型 F 值多少？整体显著吗？" → F 检验。

**这两个检验回答的问题不一样。**

---

## 二、是什么？

### t 检验：单个系数是不是 0？

**问题**：$\beta_1 = 0$ 吗？（教育对工资没影响？）

**t 统计量**：

$$t = \frac{\hat{\beta}_1}{SE(\hat{\beta}_1)}$$

- 分子：估计的系数；
- 分母：系数的标准误（衡量这个估计准不准）。

**直觉**：t 值 = 信号 / 噪声。
- 信号强、噪声小 → t 大 → 显著；
- 信号弱、噪声大 → t 小 → 不显著。

**判断**：|t| > 1.96（大样本）≈ p < 0.05。
或者直接看 p 值。

> 💡 这里的 1.96 就是标准正态分布（Z 分布）在 5% 双尾下的临界值，来自[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP07_总体均值Z检验|KP07 Z 检验]]；小样本时要把 1.96 换成 t 分布临界值（自由度越小，这个数越大，比如自由度=2 时是 4.303），对应[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP08_总体均值t检验|KP08 t 检验]]。回归里默认用 t 分布，因为总体方差永远未知。

### Z 检验 vs t 检验：什么时候用哪个？

> 📖 教材笔记[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP07_总体均值Z检验|KP07 Z 检验]]和[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP08_总体均值t检验|KP08 t 检验]]专门讲了这个选择。

| 条件 | 用什么 | 为什么 |
|------|--------|--------|
| 总体 σ 已知，不管 n 大小 | **Z** | σ 已知，抽样分布精确正态 |
| 总体 σ 未知，**n ≥ 30** | **Z**（用 s 代替 σ） | 大样本下 s ≈ σ，CLT 保证近似正态 |
| 总体 σ 未知，**n < 30** | **t**（自由度 = n-1） | 小样本 s 波动大，t 分布尾巴更厚 |

**为什么小样本要用 t 分布？** 因为 t 统计量里有两个随机变量：样本均值 x̄ 和样本标准差 s。小样本时 s 本身也在抖，有时偏大有时偏小，导致 t 比 Z 更分散。n 大了 s 稳定了，t 就趋近 Z。

**常用 t 临界值（双尾 α=0.05）对照**：

| 自由度 n-1 | t 临界值 | 对比 Z=1.96 |
|-----------|---------|------------|
| 5 | 2.571 | 大很多 |
| 10 | 2.228 | 大一些 |
| 20 | 2.086 | 接近 |
| 30 | 2.042 | 很接近 |
| ∞ | 1.96 | 等于 Z |

**经验法则**：n > 30 就不用纠结了，t 和 Z 几乎一样。

### 为什么大样本下 t ≈ Z？——中心极限定理

> 📖 教材笔记[[../../教材笔记/02_计量经济学/05_大样本OLS/知识点/KP01_大样本理论|计量·大样本理论]]讲了这件事。

**核心直觉**：不管原始数据的分布多怪（工资右偏、疾病计数离散、收入极度不均），只要样本量够大，t 统计量的抽样分布就**自动近似标准正态**。

这就是**中心极限定理（CLT）**的威力——它把"乱七八糟的总体分布"在大样本下"洗成"钟形。

**掷骰子类比**：
- n=1：掷 1 次，结果 1-6 完全离散，不是正态；
- n=100：算 100 次的平均值，分布已经很接近钟形；
- n=10000：几乎就是标准正态了。

回归里也是一样：哪怕扰动项不是正态分布，只要 n 足够大（通常几百个观测），t 统计量就渐近正态，直接用 1.96 当临界值就行。

> ⚠️ **CLT 不是万能的**。如果数据有强自相关（时间序列）、整群抽样（cluster）、或者极端值主导样本，CLT 的结论会失效——这时候要用稳健标准误、聚类标准误、Newey-West 等方法补救（后面章节会讲）。

### 总体比例检验（补充）

> 📖 教材笔记[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP09_总体比例检验|KP09 总体比例检验]]

如果检验对象是**比例**（合格率、支持率、市场份额），逻辑和均值 Z 检验一样，只是公式略不同：

$$Z = \frac{p - P_0}{\sqrt{P_0(1-P_0)/n}}$$

- p：样本比例
- P₀：H₀ 假设的总体比例
- 适用条件：nP₀ ≥ 5 且 n(1-P₀) ≥ 5（大样本）

**典型场景**："某产品合格率号称 80%，抽 400 个测出来 84%，问是否属实？"

---

### F 检验：所有系数联合起来是不是都等于 0？

**问题**：$\beta_1 = \beta_2 = \cdots = \beta_k = 0$？（整个模型有没有用？）

**F 统计量**：

$$F = \frac{ESS / k}{RSS / (n - k - 1)}$$

- 分子：模型解释的平均变异；
- 分母：没解释的平均变异。

**直觉**：F 值大，说明模型解释的远大于没解释的——整体显著。

**判断**：F 值对应的 p < 0.05，说明整个回归模型是显著的（至少有一个变量有影响）。

## 三、t 检验和 F 检验的关系

[[KP04_一元回归Stata解读|一元回归]]里：$F = t^2$。
（一元回归只有一个系数，F 检验"所有系数=0"就等于 t 检验"那个系数=0"。）

[[KP03_多元回归Stata|多元回归]]里：
- t 检验 = 一个个看；
- F 检验 = 整体看。

**什么时候用哪个？**
- 你关心"教育有没有影响" → t 检验；
- 你关心"我这个模型整体靠不靠谱" → F 检验。

### 为什么不能分别看 t 检验来代替 F 检验？

> 📖 教材笔记[[../../教材笔记/02_计量经济学/05_大样本OLS/知识点/KP02_假设检验|计量·假设检验]]讲了这个"多重比较问题"。

**错误想法**：我有 3 个变量，只要它们的 t 检验都不显著，就说明这 3 个变量联合起来也不显著。

**为什么错？** 因为存在"多重比较问题"——

- 每个 t 检验在 5% 水平控制第一类错误；
- 但 3 个 t 检验**联合**来看，即使 3 个系数真的都为 0，随机波动也有相当概率让其中至少一个 t 值超过 1.96；
- 检验个数越多，"碰巧显著"的越多。

**F 检验**把"3 个系数同时为 0"作为**一个整体约束**来检验，正确控制了联合第一类错误概率。

**Stata 里怎么做**：
```stata
reg lnw s iq expr tenure
* 检验 s、iq、expr 联合为 0（H0: β_s = β_iq = β_expr = 0）
test s iq expr
```

> ⚠️ 论文里如果你的模型有 10 个变量，千万别只说"其中 8 个不显著所以模型没用"——要用 F 检验整体判断。

| k | 自变量个数 |
| n | 样本量 |
| df | 自由度 |

## 五、一个完整的数字例子

**回归结果**：

```
             coef    std err      t      P>|t|
const       -0.542      1.620   -0.335    0.770
edu          0.398      0.179    2.221    0.157
tenure       0.106      0.124    0.860    0.481

R-squared = 0.994
F-statistic = 178.1
Prob (F-statistic) = 0.006
```

### 读 t 检验

- 教育：t = 2.221，p = 0.157 > 0.05 → 不显著；
- 工龄：t = 0.860，p = 0.481 > 0.05 → 不显著；
- 截距：t = -0.335，p = 0.770 → 不显著。

**意思**：在 5% 水平下，单个看每个变量都不显著（因为样本太小，只有 5 个）。

### 读 F 检验

- F = 178.1，p = 0.006 < 0.05 → **整体回归高度显著**。

**意思**：虽然单个变量看都不显著，但联合起来看，模型整体有很强的解释力。
（这是经典的"F 显著但单个 t 不显著"现象——样本量太小，t 检验功效不够，但 F 检验能捕捉到整体信号。）

### 论文里怎么写？

> "回归结果显示，模型整体在 1% 水平上显著（F = 178.1, p = 0.006），R² = 0.994。
> 但由于样本量较小（n=5），单个系数的 t 检验均不显著，未来需扩大样本进一步检验。"

## 六、Stata 输出怎么读？

Stata 的 `reg` 输出长这样：

```
Source |       SS           df       MS
-------+---------------------------
Model  |  18.60              2       9.30
Residual |  0.10              2       0.05
-------+---------------------------
Total  |  18.70              4       4.68

Number of obs = 5
F(2, 2) = 178.1
Prob > F = 0.006
R-squared = 0.994

------------------------------------------------------------------------
wage |    Coef.   Std.Err.    t    P>|t|   [95% Conf. Interval]
-----+------------------------------------------------------------------
edu  |    0.398    0.179     2.22  0.157   -0.374    1.171
tenure|   0.106    0.124     0.86  0.481   -0.426    0.639
_cons|   -0.542    1.620    -0.33  0.770   -7.511    6.426
------------------------------------------------------------------------
```

**各部分怎么读**：
- 右上角：观测数、F 值、p 值、R²；
- 上半部分：ANOVA 表（Model/Residual/Total 的 SS）；
- 下半部分：每个变量的系数、标准误、t、p、置信区间。

> 💡 **最后两列 [95% Conf. Interval] 是"省钱"的读法**：不用看 p 值，只要这个区间里**包含 0**，系数就不显著；区间整个在 0 的一边，就显著。这就是[[../../教材笔记/05_统计学原理/07_假设检验/知识点/KP10_检验与置信区间的关系|KP10 检验与置信区间的关系]]里讲的对偶性——本例 edu 的 CI = [-0.374, 1.171] 包住了 0，所以 p=0.157 不显著，两句话完全一致。

---

## 七、易错点

1. **F 显著不代表每个变量都显著**。F 只说"至少有一个变量有用"，具体哪个要 t 检验。
2. **F 显著但单个 t 可能都不显著**（小样本/共线性导致）。这是本例的情况：F=178.1 整体高度显著，但 edu 和 tenure 的 t 都不显著——因为 n=5 太小，单个系数的标准误被拉大了。
3. **自由度别算错**：t 检验自由度 = n - k - 1；F 检验分子自由度 = k，分母自由度 = n - k - 1。
4. **标准误不是系数的误差**，是"估计这个系数时的不确定性"。标准误大 = 样本不够。
5. **p 值和 t 值是一一对应的**，看哪个都行，但论文里一般报 p 值和星号。

## 八、Stata / Python 代码

```stata
* Stata：做 t 检验和 F 检验
reg wage edu tenure

* 单独检验：edu 和 tenure 联合为 0
test edu tenure
* 如果 p<0.05，拒绝"两者都为0"

* 检验 edu = 0.5
test edu = 0.5
```

```python
import statsmodels.api as sm

X = sm.add_constant(df[['edu', 'tenure']])
model = sm.OLS(df['wage'], X).fit()

print(f"F 统计量: {model.fvalue:.2f}")
print(f"F 检验 p 值: {model.f_pvalue:.4f}")

# 单独检验 edu = 0.5
print(model.f_test('edu = 0.5'))
```

## 九、对比

| | t 检验 | F 检验 |
|---|--------|--------|
| 检验对象 | 单个系数 | 所有系数联合 |
| 原假设 | β_j = 0 | β_1 = ... = β_k = 0 |
| 统计量 | b̂ / SE | ESS/k ÷ RSS/(n-k-1) |
| 用途 | 看某个变量有没有用 | 看整个模型有没有用 |

---

## 十、为什么不用别的方法？

- **为什么不能只看 F 检验就说每个变量都显著？** F 只检验"所有系数联合为 0"，通过只说明至少有一个变量有用，具体是谁、符号对不对必须靠逐个 t 检验；F 显著但 t 全不显著，在小样本里很常见。
- **为什么不能只做 t 检验、不报告 F？** 逐个 t 检验不检验"模型整体是否有解释力"，而且分别做多次检验会抬高犯错概率；F 检验一次性给出模型整体是否成立的证据，是论文表的必报项。
- **为什么不用 R² 替代检验？** R² 会随加变量自动上升，不涉及不确定性；t/F 把系数和它的标准误放在一起比，才回答"这个信号是真的还是噪声"。

---

## 十一、答辩常问（直接背）

1. **问：一元回归里 t 和 F 是什么关系？** 答：F = t²。因为一元只有一个系数，"所有系数联合为 0"就等于"那个系数为 0"，两个检验是一回事，开平方就能对上。
2. **问：你的模型 F=178.1（p=0.006）整体高度显著，但每个变量 t 都不显著，怎么解释？** 答：n=5 样本太小，单个 t 检验区分真假的功效不够、标准误大；F 检验联合两个变量能捕捉到整体信号。处理方式是如实报告并说明需扩样本，而不是删变量凑显著。
3. **问：t 统计量怎么算、多大算显著？** 答：t = b̂ / SE(b̂)，即信号除以噪声；大样本下 |t|>1.96 约等于 p<0.05，|t|>2.58 约等于 p<0.01。自由度 = n-k-1。

---

## 十二、速记卡

> **t 检验：单个系数是不是 0。t = b̂/SE，|t|>1.96 显著。**
> **F 检验：所有系数联合是不是 0。F = (ESS/k)/(RSS/(n-k-1))。**
> **一元回归里 F = t²。**
> **F 显著 = 模型整体有用；t 显著 = 单个变量有用。**
> **看输出：先看 F 整体，再看 t 单个。**

## 💡 经济学视角：t 检验和 F 检验——从"感觉有效"到"数据证明有效"

**这个方法是为了解决什么经济学问题？**
t 检验回答"单独看，政策这个变量的效果是不是真信号"；F 检验回答"整张回归表整体上是不是有意义"。经济学家写论文时，审稿人第一眼看的就是 t 值和 p 值——系数估出来是 0.8 不算数，t 值要大于 2、p 值要小于 0.05 才算数。否则你说的那个"政策效果"，可能只是样本里碰巧长这样。

**经济学里 t / F 检验分别拍什么板？**

| 检验 | 回答的问题 | 政策语境 |
|---|---|---|
| t 检验（单个系数） | 这个变量真的有影响吗？ | 消费券真的拉动消费吗？ |
| F 检验（整体） | 整个模型成立吗？ | 你选的这堆变量能解释 GDP 吗？ |
| F 检验（分组） | 两组回归系数真的不一样吗？ | 国企和民企的投资行为真不同吗？ |

**举个实证论文的例子：**
《新能源汽车补贴政策效果评估》回归里补贴变量的 t 值 = 3.2，p = 0.001——高度显著，说明补贴确实拉动了销量；同时 F 值 = 45，p < 0.001——整个模型整体成立。两个检验都过了，结论才敢写进政策建议：退坡补贴要慢一点，不然销量会明显掉。
