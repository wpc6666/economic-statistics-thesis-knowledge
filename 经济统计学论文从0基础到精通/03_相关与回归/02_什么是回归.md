# 02 什么是回归？

## 一、为什么要学这个？

[[01_相关系数|相关系数]]告诉你"教育和工资有关系"，但它没告诉你：
- 多上一年学，工资到底涨多少？
- 如果我没上过学（x=0），工资大概是多少？
- 一个 16 年教育的人，我预测他工资是多少？

**回答这些问题，就需要回归。**

回归不是什么高深的东西，它就是：**给你一堆散点，找一条直线贴上去。**

不学会怎样？你论文里"每多上一年学，工资涨 X 元"这句话就写不出来。

---

## 二、是什么？

### 生活比喻：给散点"穿直线"

想象你把 5 个人的（教育年限，工资）画在坐标纸上：

```
工资
8.5 |                    ● (19, 8.5)
7   |              ● (16, 7)
5   |        ●(12,5)
4.5 |     ● (12, 4.5)
3   |  ● (9, 3)
    +------------------- 教育年限
      9  12  16  19
```

这 5 个点大概排成一条斜线。回归就是：**用一把尺子画一条直线，让这条直线"尽量贴近"所有点。**

这条直线写出来就是：

$$\hat{y} = \hat{a} + \hat{b} x$$

- $\hat{a}$：截距（直线和 y 轴的交点）；
- $\hat{b}$：斜率（x 每加 1，直线上升多少）；
- $\hat{y}$：直线上预测出来的 y 值（拟合值）。

### 总体回归 vs 样本回归：别搞混这两条线

> 📖 教材笔记[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP07_一元线性回归模型|KP07 一元线性回归模型]]把这件事讲得很细。这里是关键区分：

**总体里真实的那条线**（我们永远看不到、但想估计的）：

$$y = \beta_0 + \beta_1 x + \varepsilon$$

- $\beta_0, \beta_1$：真实但未知的截距和斜率（希腊字母）
- $\varepsilon$：**随机扰动项**——x 解释不了的那部分（能力、运气、家庭背景……打包成一个数）
- 为什么要有 $\varepsilon$？因为影响 y 的因素不止 x 一个。比如工资除了受教育影响，还受能力、工龄、行业、运气影响。这些因素打包进 $\varepsilon$，承认模型不完美。

**我们用样本估计出来的那条线**（能算出来、能写在论文里的）：

$$\hat{y} = \hat{a} + \hat{b} x, \quad e = y - \hat{y}$$

- $\hat{a}, \hat{b}$：$\beta_0, \beta_1$ 的估计值（a hat, b hat）
- $e$：**残差**——$\varepsilon$ 的样本对应物

**两者关系**：

$$y = \underbrace{\hat{a} + \hat{b} x}_{\hat{y}\text{（拟合值）}} + \underbrace{e}_{\text{残差}}$$

**一句话**：$\beta$ 是"真相"，$\hat{a}, \hat{b}$ 是"我们猜的真相"；$\varepsilon$ 是"真相里的噪声"，$e$ 是"我们猜完后剩下的噪声"。

### 回归 vs 相关

> 📖 教材笔记里专门有一篇对比这两件事：[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP06_相关分析vs回归分析|KP06 相关分析 vs 回归分析]]——相关分析对称、回归分析不对称；相关只问"有没有关系"，回归问"关系长什么样、能不能预测"。下面这张表就是它的浓缩版。

| | 相关 | 回归 |
|---|------|------|
| 有没有方向 | 没有（x 和 y 对称） | 有（y 是因变量，x 是自变量） |
| 回答什么问题 | "它们有没有关系" | "x 变 1 单位，y 变多少" |
| 能不能预测 | 不能 | 能（给定 x 预测 y） |
| 系数范围 | [-1, 1] | 无单位限制 |

**相关是对称的**：r(x,y) = r(y,x)。
**回归是不对称的**：y 对 x 回归 ≠ x 对 y 回归。因为一个是"工资由教育决定"，另一个是"教育由工资决定"，经济意义完全不同。

> ⚠️ 不管是相关还是回归，都**不等于因果**。教材笔记里[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP12_相关不等于因果与应用注意|KP12 相关不等于因果与应用注意]]列了常见的误用情形（遗漏变量、反向因果、伪相关），写论文讨论部分一定要读。

## 三、公式怎么来的？（先给个直觉，下一篇详推）

我们要找一条直线 $\hat{y} = a + bx$，让它"尽量贴近"所有点。

怎么衡量"贴近"？

每个点 $(x_i, y_i)$ 到直线的**垂直距离**是：

$$e_i = y_i - \hat{y}_i = y_i - (a + bx_i)$$

这个 $e_i$ 叫**残差**（residual）——真实值和直线预测值之间的差。

我们想让所有残差加起来最小。但直接加会正负抵消（上一章讲过），所以**平方**：

$$SSE = \sum_{i=1}^{n} e_i^2 = \sum_{i=1}^{n} [y_i - (a + bx_i)]^2$$

**SSE = Sum of Squared Errors，残差平方和。**

**[[04_OLS截距和拟合值|OLS]]（Ordinary Least Squares，普通最小二乘法）就是找到那组 (a, b)，让 SSE 最小。**

这就是回归的全部秘密——**最小化残差平方和**。

## 四、符号表

| 符号 | 怎么读 | 是什么 |
|------|--------|--------|
| $y$ | "y" | 因变量（被解释变量） |
| $x$ | "x" | 自变量（解释变量） |
| $\hat{a}$ | "a hat" | 估计的截距 |
| $\hat{b}$ | "b hat" | 估计的斜率 |
| $\hat{y}_i$ | "y i hat" | 第 i 个点的拟合值（直线上的值） |
| $e_i$ | "e i" | 第 i 个点的残差 = $y_i - \hat{y}_i$ |
| SSE | "S S E" | 残差平方和 |
| OLS | "O L S" | 普通最小二乘法 |

## 五、一个完整的数字例子（先手算感受）

用同样的 5 个点：

| i | x | y |
|---|---|---|
| 1 | 9 | 3 |
| 2 | 12 | 4.5 |
| 3 | 12 | 5 |
| 4 | 16 | 7 |
| 5 | 19 | 8.5 |

**我们先用一条近似直线感受一下残差的概念**：$\hat{y} = -1.2 + 0.5x$（后面手推 OLS 会得到精确解，这里先看残差怎么算）。

### 算每个点的拟合值和残差

| i | x | y | $\hat{y} = -1.2 + 0.5x$ | $e = y - \hat{y}$ | $e^2$ |
|---|---|---|-------------------------|-------------------|-------|
| 1 | 9 | 3 | 3.3 | -0.3 | 0.09 |
| 2 | 12 | 4.5 | 4.8 | -0.3 | 0.09 |
| 3 | 12 | 5 | 4.8 | 0.2 | 0.04 |
| 4 | 16 | 7 | 6.8 | 0.2 | 0.04 |
| 5 | 19 | 8.5 | 8.3 | 0.2 | 0.04 |
| 求和 | | | | | **0.30** |

SSE = 0.30。

**OLS 就是找到那条直线，让这个 SSE 最小。**
下一篇我们会从 SSE 出发，对 a 和 b 求导，推出来 $\hat{b}$ 和 $\hat{a}$ 的精确公式。

### Python 验证

```python
import numpy as np

x = np.array([9, 12, 12, 16, 19])
y = np.array([3, 4.5, 5, 7, 8.5])

# numpy 的 polyfit 直接做 OLS
b, a = np.polyfit(x, y, 1)
print(f"截距 a = {a:.3f}")   # -1.889
print(f"斜率 b = {b:.3f}")   # 0.551

# 算 SSE
y_hat = a + b * x
residuals = y - y_hat
sse = np.sum(residuals**2)
print(f"SSE = {sse:.4f}")   # 0.143
```

> 💡 **注意**：刚才手算用的近似直线 -1.2+0.5x 的 SSE=0.30，而 polyfit 给出的 OLS 最优直线 SSE=0.143，确实更小——这就是为什么要学 OLS：它自动找到让残差平方和最小的那条直线。下一篇我们就从零推导这个最优解。

## 六、回归的前提假设（OLS 五大假设，先有个印象）

后面第 4 章会详细讲，这里先列出来：

1. **线性**：y 和 x 之间是线性关系（$y = a + bx + \varepsilon$）；
2. **严格外生性**：$E[\varepsilon | x] = 0$——误差项和 x 不相关；
3. **不存在完全共线性**：x 不是常数，也不能是其他 x 的精确线性组合；
4. **同方差**：误差项方差不随 x 变；
5. **无[[03_自相关|自相关]]**：不同观测的误差项之间不相关。

违反这些假设，回归系数可能有偏、不可信。第 4 章教你怎么诊断和修。

---

## 七、易错点

1. **回归 ≠ 因果**。即使你跑出了 b=0.5，也不能说"多上一年学导致工资涨 500"——可能有遗漏变量（能力、家庭背景）。
2. **截距常常没经济意义**。比如 $\hat{a} = -1.2$，意思是"0 年教育时工资 -1200 元"——现实中没人是 0 年教育，这个截距只是直线和 y 轴的交点，不要硬解释。
3. **不要外推**。你用 9~19 年教育的数据拟合的直线，不能用来预测 0 年教育（x=0）或者 30 年教育（博士）——那是外推，直线在数据范围外可能不对。
4. **残差不是"错误"**。它是模型没解释的部分，本来就存在。你不能因为有残差就说回归失败了。

## 八、Stata / Python 代码

```stata
* Stata：一行命令做 OLS
clear
input edu wage
9 3
12 4.5
12 5
16 7
19 8.5
end

reg wage edu   // 因变量在前，自变量在后
```

```python
# Python：同样的事
import numpy as np
import statsmodels.api as sm

x = np.array([9, 12, 12, 16, 19])
y = np.array([3, 4.5, 5, 7, 8.5])

# 加常数项（Stata 自动加，Python 要手动加）
X = sm.add_constant(x)

model = sm.OLS(y, X).fit()
print(model.summary())
```

**Stata 输出怎么读**：
- `Coef` 列：截距和斜率的估计值；
- `Std. Err.`：标准误；
- `t`：t 值；
- `P>|t|`：p 值；
- `R-squared`：R²（下下章讲）。

## 十、为什么不用别的方法？

- **为什么不只算相关系数就够了？** 相关系数对称、没有方向，回答不了"多上一年学工资涨多少"这种带方向、带量纲的问题，也不能给定 x 预测 y；你要一个斜率数字，就必须用回归。
- **为什么不直接手动画一条直线？** 随手画没有准则，两个人画的直线不一样、不可复现；OLS 用"最小化残差平方和"这一个明确准则，结果唯一、别人能重复出来。
- **为什么不用曲线而用直线？** 本科阶段样本量小，经济关系在局部区间近似直线；曲线要多估参数、容易过拟合。先用直线，等残差图出现规律弯曲，再考虑加二次项。

---

## 十一、答辩常问（直接背）

1. **问：OLS 到底在最小化什么？** 答：最小化残差平方和 SSE = Σ(y_i - a - bx_i)²，残差是真实值减拟合值。平方是为了让正负误差不抵消，而且处处可导、有解析解。
2. **问：回归出来 b=0.5，能不能说多上一年学导致工资涨 500 元？** 答：不能。回归本身不解决因果，可能有遗漏变量（能力、家庭背景）。b=0.5 只是"在这个模型里，x 每加 1，y 平均差 0.5"，要 causal 还需[[03_工具变量IV|工具变量]]等。
3. **问：截距 a = -1.2 怎么解释？** 答：不要硬解释。它是 x=0 时直线和 y 轴的交点，而数据里没人是 0 年教育，超出了数据范围（外推），它只是数学上的交点。

---

## 十二、速记卡

> **回归 = 找一条直线贴合散点。**
> **OLS = 最小化残差平方和 SSE = Σ(y - a - bx)²。**
> **斜率 b = x 每加 1，y 平均变多少。**
> **截距 a = 直线和 y 轴交点，常常没经济意义。**
> **回归 ≠ 因果**，它只是描述直线关系。

## 💡 经济学视角：什么是回归——把经济学里的函数"用数据估出来"

**这个方法是为了解决什么经济学问题？**
经济学课本里写"需求定律：价格涨，需求量降"，但到底降多少？这是定性的话。回归分析干的事，就是拿真实数据把这个函数关系估出来：P 涨 1 块，Q 到底少买几件？课本给的是箭头方向，回归给的是斜率大小。需求函数、生产函数、消费函数——所有你在西经课本上看到的函数，现实中都要靠回归从数据里"猜"出来。

**经济学里哪些经典函数要靠回归估计？**

| 经济学函数 | 回归长什么样 | 估出来的系数叫什么 |
|---|---|---|
| 需求函数 | Q = α + βP | β = 价格对需求量的影响 |
| 生产函数 | lnQ = α + βlnL + γlnK | β、γ = 劳动和资本的产出弹性 |
| 消费函数 | C = α + βY | β = 边际消费倾向 MPC |
| 工资方程 | lnW = α + βedu + γexp | β = 教育回报率 |

**举个实证论文的例子：**
《中国制造业生产函数估计》用规模以上工业企业数据跑 lnQ = α + βlnL + γlnK，估出 β ≈ 0.45、γ ≈ 0.55——意思是劳动投入每加 1%，产出加 0.45%；资本每加 1%，产出加 0.55%。两个加起来 ≈ 1，规模报酬不变，跟教科书假设对上了。
