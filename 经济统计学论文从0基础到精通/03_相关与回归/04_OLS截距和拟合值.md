# 04 OLS 截距、拟合值和残差

> 📖 这一篇用的模型就是[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP07_一元线性回归模型|KP07 一元线性回归模型]]：总体里真实的那条线是 $y = \beta_0 + \beta_1 x + \varepsilon$，我们用样本估计出来的是 $\hat{y} = \hat{a} + \hat{b}x$。下面的"拟合值 ŷ"和"残差 e"就是连接这两条线的桥。

## 一、为什么要学这个？

上一篇我们推出来了 b̂ 和 â 的公式。这一篇要把它们用起来：
- 给定一个新的 x，预测 y 是多少？（拟合值 ŷ）
- 真实值和预测值差多少？（残差 e）
- 残差有什么性质？能告诉我们什么？

**论文里"预测"和"残差分析"都是从这里来的。**

---

## 二、是什么？

### 三个核心量

```
真实值 y_i
   |
   |  ← 残差 e_i = y_i - ŷ_i（真实和预测的差）
   ↓
拟合值 ŷ_i = â + b̂ x_i（直线上预测出来的值）
```

- **拟合值 ŷ**：回归直线上对应 x_i 的那个点；
- **残差 e**：真实值 y_i 和拟合值 ŷ_i 之间的差；
- **截距 â**：直线和 y 轴的交点（x=0 时的 ŷ）。

### 残差的两个重要性质

OLS 估计出来的残差，有两个数学性质：

**性质1：残差和为 0。**
$$\sum_{i=1}^{n} e_i = 0$$

**为什么？** 回忆推导时对 a 求导得到的方程：$\sum(y_i - a - bx_i) = 0$，也就是 $\sum e_i = 0$。

**性质2：残差和 x 不相关。**
$$\sum_{i=1}^{n} x_i e_i = 0$$

**为什么？** 那是对 b 求导得到的方程：$\sum x_i(y_i - a - bx_i) = 0$，也就是 $\sum x_i e_i = 0$。

**这两个性质是 OLS 的"副产品"**，不是你额外假设的，是数学推导自动出来的。

---

## 三、公式怎么来的？

### 拟合值公式

$$\hat{y}_i = \hat{a} + \hat{b} x_i$$

把 â = ȳ - b̂x̄ 代进去：

$$\hat{y}_i = \bar{y} - \hat{b}\bar{x} + \hat{b} x_i = \bar{y} + \hat{b}(x_i - \bar{x})$$

**这个形式更好用**：它告诉你——
- 当 x_i = x̄ 时，ŷ_i = ȳ（直线过均值点）；
- 当 x_i 比均值大 1 单位，ŷ_i 比 ȳ 大 b̂ 单位。

### 残差公式

$$e_i = y_i - \hat{y}_i = y_i - \hat{a} - \hat{b}x_i$$

---

## 四、符号表

| 符号 | 是什么 |
|------|--------|
| $\hat{y}_i$ | 第 i 个观测的拟合值（预测值） |
| $e_i$ | 第 i 个观测的残差 |
| $\hat{a}$ | 估计的截距 |
| $\hat{b}$ | 估计的斜率 |

## 五、一个完整的数字例子手算

用上一篇的结果：â = -1.888，b̂ = 0.551。

| i | x | y | ŷ = -1.888 + 0.551x | e = y - ŷ | e² |
|---|---|---|---------------------|-----------|------|
| 1 | 9 | 3 | -1.888 + 4.959 = 3.071 | -0.071 | 0.0050 |
| 2 | 12 | 4.5 | -1.888 + 6.612 = 4.724 | -0.224 | 0.0502 |
| 3 | 12 | 5 | 4.724 | 0.276 | 0.0762 |
| 4 | 16 | 7 | -1.888 + 8.816 = 6.928 | 0.072 | 0.0052 |
| 5 | 19 | 8.5 | -1.888 + 10.469 = 8.581 | -0.081 | 0.0066 |
| **求和** | | **28** | **28.03** | **-0.028 ≈ 0** | **0.143** |

### 验证性质1：残差和 ≈ 0

-0.071 - 0.224 + 0.276 + 0.072 - 0.081 = -0.028

接近 0（小误差是因为 â 和 b̂ 四舍五入）。✅

### 验证性质2：Σx·e ≈ 0

$$9 \times (-0.071) + 12 \times (-0.224) + 12 \times 0.276 + 16 \times 0.072 + 19 \times (-0.081)$$

$$= -0.639 - 2.688 + 3.312 + 1.152 - 1.539 = -0.402$$

接近 0（同样因为四舍五入）。✅

### 预测一个新值

问题：一个 14 年教育的人，预测他工资多少？

$$\hat{y} = -1.888 + 0.551 \times 14 = -1.888 + 7.714 = 5.826 \text{（千元）}$$

答：预测月工资约 5826 元。

**注意**：这个预测是"在 9~19 年教育范围内"的插值，可信。
如果有人问"0 年教育预测多少"——那是外推，不可信。

### Python 验证

```python
import numpy as np

x = np.array([9, 12, 12, 16, 19])
y = np.array([3, 4.5, 5, 7, 8.5])

b, a = np.polyfit(x, y, 1)
y_hat = a + b * x
residuals = y - y_hat

print(f"拟合值: {y_hat}")
print(f"残差: {residuals}")
print(f"残差和: {residuals.sum():.6f}")  # ~0
print(f"Σx·e: {np.sum(x * residuals):.6f}")  # ~0
print(f"SSE: {np.sum(residuals**2):.4f}")  # 0.143
```

## 六、残差能告诉我们什么？

残差不是垃圾——它是"模型没解释的部分"，里面藏着信息：

1. **残差 vs x 的图**：如果残差随 x 变大而变大 → [[02_异方差|异方差]]（第 4 章讲）；
2. **残差 vs 排序的图**：如果残差有规律地波动 → [[03_自相关|自相关]]（时间序列数据常见）；
3. **大残差点**：可能是异常值，回去查；
4. **残差均值为 0**：说明模型没有系统性高估或低估。

---

## 七、易错点

1. **残差和为 0 不是巧合**，是 OLS 的数学性质。如果你算出来残差和不是 0，说明你 â 或 b̂ 算错了。
2. **拟合值不是真实值**。ŷ 是直线预测的，y 才是真实观测。不要把 ŷ 当成"修正后的 y"。
3. **截距 â 常常没经济意义**。x=0 在数据范围外时，â 只是数学上的交点。
4. **不要外推**。在 x 范围内插值可信，超出范围外推危险。

## 八、Stata / Python 代码

```stata
* Stata：算完回归后，自动生成拟合值和残差
reg wage edu
predict yhat   // 生成拟合值 ŷ
predict e, residuals  // 生成残差 e

* 看一眼
list edu wage yhat e in 1/5

* 画残差图
rvfplot  // residual vs fitted plot
```

```python
# Python
import numpy as np
import statsmodels.api as sm

x = np.array([9, 12, 12, 16, 19])
y = np.array([3, 4.5, 5, 7, 8.5])
X = sm.add_constant(x)

model = sm.OLS(y, X).fit()

y_hat = model.fittedvalues
residuals = model.resid

print(f"残差和: {residuals.sum():.6f}")
print(f"R²: {model.rsquared:.4f}")
```

## 八·五、Stata 输出每个数字怎么读

> 📖 教材笔记[[../../教材笔记/02_计量经济学/03_一元线性回归/知识点/KP04_一元回归Stata解读|KP04 一元回归 Stata 解读]]把这件事讲得非常细。你跑一次 `reg wage edu`，Stata 吐出一大堆东西，每个数字什么意思？

**典型输出长这样**（用教材里 grilic 数据 `reg lnw s` 为例）：

```
      Source |       SS           df       MS
-------------+------------------------------
       Model |   35.20              1       35.20
    Residual |  104.08            756        0.138
-------------+------------------------------
       Total |  139.29            757        0.184

Number of obs =     758

         lnw |      Coef.   Std. Err.      t    P>|t|     [95% Conf. Interval]
-------------+----------------------------------------------------------------
           s |    .09662      .00604    15.99   0.000       .0848     .1085
       _cons |    4.3915      .08211    53.48   0.000      4.2303     4.5527
------------------------------------------------------------------------------
```

**逐块读**：

| 位置 | 数字 | 怎么读 |
|------|------|--------|
| 上半部分·Model SS | 35.20 | ESS（解释平方和）——模型解释了多少 |
| 上半部分·Residual SS | 104.08 | RSS（残差平方和）——没解释的部分 |
| 上半部分·Total SS | 139.29 | TSS（总平方和） |
| 右上·Number of obs | 758 | 实际用了多少个样本（缺失值会被自动删掉） |
| 右上·F | 255.70 | F 统计量，检验整个方程是否显著 |
| 右上·Prob > F | 0.0000 | F 检验的 p 值，<0.05 整体显著 |
| 右上·R-squared | 0.2527 | R² = 25.3% 的工资变异被教育解释了 |
| 右上·Adj R-squared | 0.2518 | 惩罚变量个数后的 R² |
| 右上·Root MSE | 0.3711 | 回归标准误（残差的标准差） |
| 下半·Coef. | 0.0966 | 教育的系数——每多一年学，工资对数涨 0.0966（≈ 9.7%） |
| 下半·Std. Err. | 0.0060 | 系数的标准误（估计有多不准） |
| 下半·t | 15.99 | t = Coef. / Std.Err. = 0.0966/0.0060 |
| 下半·P>\|t\| | 0.000 | p 值——注意这不是真的 0，是 p < 0.001 |
| 下半·[95% Conf. Interval] | [0.085, 0.109] | 95% 置信区间，不跨 0 就显著 |

**三个最容易踩的坑**：
1. **P>\|t\| = 0.000 不是 p=0**，是 Stata 只显示三位小数，实际意思是 p < 0.001。
2. **Coef. 大 ≠ 效应重要**。样本量极大时，0.001 的系数也能三颗星——统计显著但经济上不重要。
3. **_cons（截距）一般不用认真解释**。本例 4.39 是"教育=0 年时工资对数的预测值"，现实中没人是 0 年教育，属于外推。

## 九、对比

| 量 | 是什么 | 用途 |
|----|--------|------|
| 真实值 y | 观测到的数据 | 因变量 |
| 拟合值 ŷ | 直线预测的值 | 预测、画图 |
| 残差 e | y - ŷ | 诊断模型、找异常值 |
| SSE | Σe² | 衡量模型拟合好坏 |

---

## 十、为什么不用别的方法？

- **为什么不直接拿 y 的均值 ȳ 做预测？** 均值预测完全不看 x，是"基线模型"，对教育、工龄等信息零利用；回归拟合值 ŷ=ȳ+b̂(x-x̄) 在均值基础上叠加了 x 的信息，平方误差更小。
- **为什么不直接分男女、分地区各报一个均值？** 分组均值处理不了连续变量（工龄），也没法同时控制多个因素；回归用一个方程把连续和[[09_虚拟变量|虚拟变量]]全纳入，还能靠残差图做诊断。
- **为什么不把 ŷ 当成"修正后的真实数据"？** ŷ 是[[KP05_模型预测|模型预测]]、不是观测，把它当真值会丢掉残差里的信息；你要研究的恰恰是 y 的变异，以及残差里藏着的异常值和异方差信号。

---

## 十一、答辩常问（直接背）

1. **问：残差和为什么必须等于 0？** 答：这是 OLS 对截距求导=0 的直接结果（Σ(y-a-bx)=0 即 Σe=0），是数学性质、不是假设。算出来残差和不为 0，说明 â 或 b̂ 算错了。
2. **问：让你预测一个 14 年教育的人工资，你怎么算？能预测 0 年教育吗？** 答：ŷ = -1.888 + 0.551×14 ≈ 5.83 千元。14 年在样本 9~19 年范围内是插值，可信；0 年教育在数据范围外是外推，直线可能不成立，不能预测。
3. **问：残差图能看出什么问题？** 答：残差随拟合值变大而扇形张开→异方差；残差按时间有规律波动→自相关；某个点残差特别大→可能是异常值，回去查原始数据。

---

## 十二、速记卡

> **ŷ = â + b̂x = ȳ + b̂(x - x̄)（直线过均值点）。**
> **e = y - ŷ（真实减预测）。**
> **OLS 两个副产品：Σe = 0，Σx·e = 0。**
> **残差图用来诊断异方差、自相关、异常值。**
> **插值可信，外推危险。**
