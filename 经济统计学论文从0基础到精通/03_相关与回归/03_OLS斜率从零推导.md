## 一、为什么要学这个？

很多同学学回归，记住了 Stata 一行 `reg y x`，但导师问：

- "你这个斜率公式是怎么来的？"
- "为什么要最小化平方，不最小化绝对值？"
- "正规方程是什么？"

你答不上来。

**答辩的时候，这种问题经常问。** 你说"我从 SSE 出发，对 a 和 b 求导等于零，解出来……"，导师立刻就知道你是真懂。

---

## 二、我们的目标是什么？

我们有一条直线：

$$\hat{y}_i = a + b x_i$$

残差：

$$e_i = y_i - \hat{y}_i = y_i - a - b x_i$$

残差平方和：

$$SSE = \sum_{i=1}^{n} e_i^2 = \sum_{i=1}^{n} (y_i - a - b x_i)^2$$

**我们要找两个数 â 和 b̂，让 SSE 最小。**

这是一个二元函数求最小值的问题。[[08_答辩PPT怎么做|怎么做]]？**对 a 和 b 分别求偏导，让导数等于零。**

为什么让导数等于零？因为函数在最小值点，切线是平的，斜率为零——这是你学过的"导数=0 找极值"。

---

## 三、第一步：对 a 求偏导，令它等于零

SSE 是关于 a 和 b 的函数：

$$SSE(a, b) = \sum_{i=1}^{n} (y_i - a - b x_i)^2$$

对 a 求偏导（把 b 当常数，只对 a 求导）：

$$\frac{\partial SSE}{\partial a} = \sum_{i=1}^{n} 2(y_i - a - b x_i) \cdot (-1)$$

**这一步是因为**：外层是平方，导数是 2 倍内层；内层 $(y_i - a - bx_i)$ 对 a 求导是 $-1$。链式法则。

令导数等于零（最小值点）：

$$\sum_{i=1}^{n} 2(y_i - a - b x_i)(-1) = 0$$

两边除以 -2：

$$\sum_{i=1}^{n} (y_i - a - b x_i) = 0$$

**这一步是因为**：常数 -2 不影响等号，直接约掉。

展开[[03_求和号Σ是什么|求和号]]：

$$\sum y_i - \sum a - b \sum x_i = 0$$

$\sum a$ 就是 n 个 a 加起来 = $na$，所以：

$$\sum y_i - na - b\sum x_i = 0$$

**这一步是因为**：a 和 b 对所有 i 都一样，可以提到求和号外面。

两边除以 n：

$$\frac{1}{n}\sum y_i - a - b\frac{1}{n}\sum x_i = 0$$

注意 $\frac{1}{n}\sum y_i = \bar{y}$，$\frac{1}{n}\sum x_i = \bar{x}$，所以：

$$\bar{y} - a - b\bar{x} = 0$$

移项：

$$\hat{a} = \bar{y} - \hat{b}\bar{x} \quad \text{（方程1）}$$

**这一步是因为**：我们找到了 â 和 b̂ 的关系——截距等于均值点 $(\bar{x}, \bar{y})$ 往回退。
**这也告诉我们一个重要事实：OLS 直线一定经过 $(\bar{x}, \bar{y})$ 这个点。**

---

## 四、第二步：对 b 求偏导，令它等于零

现在对 b 求偏导（把 a 当常数）：

$$\frac{\partial SSE}{\partial b} = \sum_{i=1}^{n} 2(y_i - a - b x_i) \cdot (-x_i)$$

**这一步是因为**：外层平方求导是 2 倍内层；内层 $(y_i - a - bx_i)$ 对 b 求导是 $-x_i$。链式法则。

令导数等于零：

$$\sum_{i=1}^{n} 2(y_i - a - b x_i)(-x_i) = 0$$

两边除以 -2：

$$\sum_{i=1}^{n} x_i(y_i - a - b x_i) = 0 \quad \text{（方程2）}$$

**这一步是因为**：常数 -2 约掉，把 $x_i$ 乘进去。

---

## 五、第三步：把 â = ȳ - b̂x̄ 代入方程2

方程 2 里有个 a，我们已经从方程 1 知道 a = ȳ - bx̄，代进去：

$$\sum_{i=1}^{n} x_i \left[ y_i - (\bar{y} - b\bar{x}) - b x_i \right] = 0$$

展开括号：

$$\sum x_i (y_i - \bar{y} + b\bar{x} - b x_i) = 0$$

把 b 提出来：

$$\sum x_i \left[ (y_i - \bar{y}) - b(x_i - \bar{x}) \right] = 0$$

**这一步是因为**：$-b\bar{x} + bx_i = -b(x_i - \bar{x})$。

展开：

$$\sum x_i(y_i - \bar{y}) - b \sum x_i(x_i - \bar{x}) = 0$$

移项：

$$b \sum x_i(x_i - \bar{x}) = \sum x_i(y_i - \bar{y})$$

所以：

$$\hat{b} = \frac{\sum x_i(y_i - \bar{y})}{\sum x_i(x_i - \bar{x})}$$

---

## 六、第四步：化简成更漂亮的形式

上面这个式子对，但还能化简。

**关键技巧**：利用 $\sum(x_i - \bar{x}) = 0$ 这个事实。
（因为 $\sum x_i - n\bar{x} = n\bar{x} - n\bar{x} = 0$。）

我们来证明分子：

$$\sum x_i(y_i - \bar{y}) = \sum (x_i - \bar{x})(y_i - \bar{y})$$

**证明**：右边展开：

$$\sum (x_i - \bar{x})(y_i - \bar{y}) = \sum x_i(y_i - \bar{y}) - \bar{x}\sum(y_i - \bar{y})$$

但 $\sum(y_i - \bar{y}) = 0$（同样的道理），所以第二项是 0。
右边 = $\sum x_i(y_i - \bar{y})$ = 左边。✅

同理，分母：

$$\sum x_i(x_i - \bar{x}) = \sum (x_i - \bar{x})^2$$

**证明**：右边展开：

$$\sum (x_i - \bar{x})^2 = \sum x_i(x_i - \bar{x}) - \bar{x}\sum(x_i - \bar{x}) = \sum x_i(x_i - \bar{x}) - 0$$

所以分母也化简了。

---

## 七、最终公式

$$\hat{b} = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2}$$

$$\hat{a} = \bar{y} - \hat{b}\bar{x}$$

**这就是 OLS 的两个核心公式。**

记住它的直觉：
- **分子**：x 和 y "一起偏离均值"的程度（就是[[01_相关系数|相关系数]]的分子）；
- **分母**：x 自己的波动；
- **b̂ = 两者的比值**——x 每偏离均值 1 单位，y 平均偏离均值多少。

---

## 八、符号表

| 符号 | 是什么 |
|------|--------|
| $SSE$ | 残差平方和 |
| $a, b$ | 直线的截距和斜率（待估参数） |
| $\hat{a}, \hat{b}$ | 估计出来的截距和斜率 |
| $e_i$ | 第 i 个残差 |
| $\bar{x}, \bar{y}$ | x 和 y 的均值 |
| $\partial / \partial a$ | 对 a 求偏导 |

## 九、用 5 个真实数字手算一遍

**数据**（和前面一样）：

| i | x（教育年限） | y（工资/千元） |
|---|--------------|---------------|
| 1 | 9 | 3 |
| 2 | 12 | 4.5 |
| 3 | 12 | 5 |
| 4 | 16 | 7 |
| 5 | 19 | 8.5 |

### 第一步：算均值

$$\bar{x} = \frac{9+12+12+16+19}{5} = 13.6$$

$$\bar{y} = \frac{3+4.5+5+7+8.5}{5} = 5.6$$

### 第二步：算每个观测的偏离

| i | $x_i - \bar{x}$ | $y_i - \bar{y}$ | $(x_i-\bar{x})(y_i-\bar{y})$ | $(x_i-\bar{x})^2$ |
|---|-----------------|-----------------|------------------------------|-------------------|
| 1 | -4.6 | -2.6 | 11.96 | 21.16 |
| 2 | -1.6 | -1.1 | 1.76 | 2.56 |
| 3 | -1.6 | -0.6 | 0.96 | 2.56 |
| 4 | 2.4 | 1.4 | 3.36 | 5.76 |
| 5 | 5.4 | 2.9 | 15.66 | 29.16 |
| **求和** | | | **33.70** | **61.20** |

### 第三步：代入 b̂ 公式

$$\hat{b} = \frac{33.70}{61.20} = 0.5506 \approx 0.55$$

### 第四步：算 â

$$\hat{a} = \bar{y} - \hat{b}\bar{x} = 5.6 - 0.5506 \times 13.6 = 5.6 - 7.488 = -1.888$$

等等——这个结果和我们之前猜的 -1.2 + 0.5x 不一样？

让我用 Python 精确验证一下。

```python
import numpy as np

x = np.array([9, 12, 12, 16, 19])
y = np.array([3, 4.5, 5, 7, 8.5])

b, a = np.polyfit(x, y, 1)
print(f"b = {b:.4f}")   # 0.5506
print(f"a = {a:.4f}")   # -1.8879
```

**Python 确认**：b̂ = 0.5506，â = -1.8879。

我之前在 [[02_什么是回归]] 里写的 -1.2 + 0.5x 是近似值，手推出来的精确值是 -1.888 + 0.551x。

**这就是为什么要手推——你自己算一遍，才知道精确结果。**

### 解释结果

- **b̂ = 0.55**：每多上一年学，月工资平均涨 550 元（因为 y 单位是千元）。
- **â = -1.89**：0 年教育时工资 -1890 元——没经济意义，只是直线和 y 轴交点。
- **这条直线经过 (13.6, 5.6)**——我们之前推过，OLS 直线必过均值点。

### 验证 SSE 确实最小

用这条直线算 SSE：

$$\hat{y}_i = -1.888 + 0.551 x_i$$

| i | x | y | ŷ | e = y - ŷ | e² |
|---|---|---|------|-----------|------|
| 1 | 9 | 3 | 3.07 | -0.07 | 0.0049 |
| 2 | 12 | 4.5 | 4.72 | -0.22 | 0.0484 |
| 3 | 12 | 5 | 4.72 | 0.28 | 0.0784 |
| 4 | 16 | 7 | 6.93 | 0.07 | 0.0049 |
| 5 | 19 | 8.5 | 8.58 | -0.08 | 0.0064 |

SSE = 0.143。

**如果你换任何其他直线**，比如 ŷ = -1.2 + 0.5x，SSE = 0.30（前面算过），比 0.143 大。
这就验证了：OLS 这条直线确实让 SSE 最小。✅

## 十、这个推导的前提假设

我们在推导过程中，用到了：
1. **线性关系**：假设 y 和 x 是直线关系；
2. **$\sum(x_i - \bar{x}) = 0$**：这是数学恒等式，永远成立；
3. **x 不是常数**：如果 x 都一样（分母为 0），b̂ 算不出来——这就是"完全共线性"问题。

OLS 真正的统计假设（外生性、同方差等）不影响**点估计**的公式——即使假设违反，b̂ 这个数学表达式照样能算出来，只是它**不可信、不可做推断**。

## 十·五、为什么是"平方"？为什么不是绝对值？

> 📖 教材笔记[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP08_最小二乘法OLS|KP08 最小二乘法 OLS]]专门回答了这个问题。下面是浓缩版。

你可能会问：残差有正有负，我直接加绝对值 $\sum|e_i|$ 不就行了？为什么要平方？

**三个理由**：

| 理由 | 平方 | 绝对值 |
|------|------|--------|
| 正负不抵消 | ✅ 平方后全是正的 | ✅ 绝对值也是正的 |
| 数学可导 | ✅ 处处光滑可导，一求导就出解析解 | ❌ 在 0 点不可导，没有解析解，只能数值迭代 |
| 放大大误差 | ✅ 偏离远的点罚得更狠（e=2 罚 4，e=1 罚 1） | 偏离远和偏离近罚得一样（|2| 和 |1| 只差 2 倍） |

**最关键的是第二条**：绝对值在 0 点有个"尖角"，导数不存在，你没法用"求导=0"的方法找到最小值。而平方函数处处光滑，求导一步到位，直接解出 b̂ 和 â 的公式。

> 💡 更深一层：平方损失等于假设误差服从正态分布（高斯极大似然推导出来也是 OLS）。这就是为什么 OLS 在经典假设下是"最优线性无偏估计量（BLUE）"。

---

## 十·六、OLS 的两个正交性质是数学必然，不是假设

> 📖 计量经济学教材笔记[[../../教材笔记/02_计量经济学/03_一元线性回归/知识点/KP02_OLS正交性|KP02 OLS正交性]]专门讲了这件事。

你可能注意到了：我们对 a 求偏导=0 得到 $\sum e_i = 0$，对 b 求偏导=0 得到 $\sum x_i e_i = 0$。

**这两个等式是从 SSE 最小化直接推出来的——不是你额外假设的，是数学自动给的。**

换句话说：只要你用 OLS（最小化残差平方和），残差就自动满足这两个性质。你不需要额外假设"残差和为 0"——它一定为 0。

**推论**：因为 $\sum e_i = 0$，两边除以 n，残差的均值 $\bar{e} = 0$。又因为 $e_i = y_i - \hat{y}_i$，所以 $\bar{y} = \bar{\hat{y}}$——**y 的均值等于拟合值的均值**。

> ⚠️ 但要注意：**样本残差正交 ≠ 总体扰动项外生**。$\sum x_i e_i = 0$ 是样本层面的代数性质，永远成立；而 $E(\varepsilon | x) = 0$ 是总体层面的假设，需要你对数据生成过程的信念。两者不是一回事。

---

## 十一、易错点

1. **分子分母别搞反**。分子是 x 和 y 的"交叉项"，分母是 x 自己的平方。搞反了 b̂ 就变成了"y 对 x 的回归"的倒数，完全错了。
2. **分母不能是 0**。如果所有 x 都一样，分母 = 0，回归没法做。这就是为什么"常数变量不能放进回归"。
3. **â 常常没意义**。它是直线和 y 轴的交点，x=0 在数据范围外时不要硬解释。
4. **OLS 直线一定过 (x̄, ȳ)**。这是一个好的检验：你算完 â 和 b̂，代一下 ŷ = â + b̂x̄ 应该等于 ȳ，不等就是算错了。

## 十二、Stata / Python 代码

```stata
* Stata：手工算 OLS（和 reg 命令对比）
clear
input edu wage
9 3
12 4.5
12 5
16 7
19 8.5
end

* 方法1：直接 reg
reg wage edu

* 方法2：手工算（验证公式）
sum edu
scalar xbar = r(mean)
sum wage
scalar ybar = r(mean)

gen dx = edu - xbar
gen dy = wage - ybar
gen cross = dx * dy
gen dx2 = dx * dx

quietly sum cross
scalar numerator = r(sum)
quietly sum dx2
scalar denominator = r(sum)

scalar b_hat = numerator / denominator
scalar a_hat = ybar - b_hat * xbar

display "b_hat = " b_hat   // 0.5506
display "a_hat = " a_hat   // -1.8879
```

```python
# Python：同样的手工计算
import numpy as np

x = np.array([9, 12, 12, 16, 19])
y = np.array([3, 4.5, 5, 7, 8.5])

xbar = x.mean()
ybar = y.mean()

dx = x - xbar
dy = y - ybar

b_hat = np.sum(dx * dy) / np.sum(dx**2)
a_hat = ybar - b_hat * xbar

print(f"b_hat = {b_hat:.4f}")  # 0.5506
print(f"a_hat = {a_hat:.4f}")  # -1.8879
```

## 十三、对比：为什么用 OLS 不用别的？

| 方法 | 最小化什么 | 优点 | 缺点 |
|------|-----------|------|------|
| OLS | 残差**平方**和 | 可求导、有解析解、大样本下最优 | 对极端值敏感 |
| LAD（最小绝对偏差） | 残差**绝对值**和 | 抗极端值 | 不可求导，要数值解 |
| 最小化最大残差 | 最大的那个 e | 控制最坏情况 | 只用了一个点 |

**OLS 之所以成为标准，是因为它数学上漂亮（有解析解），而且在经典假设下是最优线性无偏估计量（BLUE）。**

---

## 十四、为什么不用别的方法？

- **为什么不用最小绝对偏差 LAD（中位数回归）？** LAD 最小化 |e| 之和、抗极端值，但绝对值在 0 点不可导、没有解析解，只能数值迭代，小样本下结果不稳定；本科论文审稿人默认 OLS，换 LAD 要额外花篇幅解释。
- **为什么不用最小化最大残差（切比雪夫准则）？** 它只盯着最大的那个误差，几乎只用了一个点的信息，对整组散点的代表性极差，也求不出简洁公式。
- **为什么不"过两个点随手画条线"代替求导？** 两点定一线是任意选的，换两个点斜率完全不同、不可复现；对 SSE 求导=0 是让所有点的误差整体最小，结果唯一、可重复。

## 十五、答辩常问（直接背）

1. **问：斜率公式 b̂ 的分子分母各是什么？** 答：分子 Σ(x-x̄)(y-ȳ) 是 x 和 y 一起偏离均值的交叉项，分母 Σ(x-x̄)² 是 x 自己的波动。分子分母别搞反，搞反就变成"y 对 x 回归"了。
2. **问：OLS 直线为什么一定过 (x̄, ȳ)？** 答：因为对截距 a 求导=0 得到 Σe=0，即 Σ(y-a-bx)=0，整理就是 a = ȳ - b·x̄，代回 ŷ=a+bx̄ 就得 ȳ。这是验算捷径，代进去不等于 ȳ 就是算错了。
3. **问：违反同方差、外生性这些假设，b̂ 还算得出来吗？** 答：算得出来。b̂ 只是个数学优化公式，不需要统计假设；假设违反影响的是它"无偏、能做 t/F 推断"的性质，不是能不能算出这个数。

---

## 十六、速记卡

> **OLS = 最小化 SSE = Σ(y - a - bx)²。**
> **对 a 求导=0 → â = ȳ - b̂x̄（直线过均值点）。**
> **对 b 求导=0 → b̂ = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)²。**
> **分子是 x 和 y 一起偏离的程度，分母是 x 自己的波动。**
> **推导过程不依赖统计假设，只是数学优化；要做推断才需要假设。**
