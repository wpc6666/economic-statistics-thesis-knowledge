# 01 相关系数：两个变量"一起动"的程度

## 一、为什么要学这个？

新闻说："研究发现，吃海参的孩子智商更高。"

你第一反应：真的假的？

第二反应：会不会是——吃海参的家庭本来就有钱，有钱的家庭本来就更重视教育，孩子智商自然高？

**这就是"相关不等于因果"的问题。**

吃海参和智商，在数据上看起来是"一起动"的——吃海参多的孩子，智商测试分数也高。但这背后是不是海参导致了智商高？不一定。

**相关系数**就是衡量"两个变量一起动"的程度。它只告诉你"它们是不是一起变"，不告诉你"谁导致谁"。

> 📖 配套教材笔记：这里说的"一起动"，在统计学原理里叫[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP01_函数关系vs相关关系|相关关系]]，和"函数关系"（给定 x 必然推出 y）是两回事；相关的方向、形式（线性/非线性）先看[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP02_相关方向与相关形式|KP02 相关方向与相关形式]]。

不学会怎样？你写论文时连"教育和工资有没有关系"都说不清楚，更别说后面的回归了。

### 函数关系 vs 相关关系：先分清这两类

拿到两个变量，先问自己一个问题：**x 定了，y 是不是也定死了？**

| | 函数关系 | 相关关系 |
|---|---------|---------|
| 给定 x 后 y | **唯一确定** | 围绕某个平均值上下波动 |
| 有随机扰动吗 | 没有 | 有（影响 y 的因素不止 x 一个） |
| 散点图 | 严格落在一条线/曲线上 | 绕着一条线/曲线抖动 |
| 典型例子 | 圆半径定了，面积就定了 | 收入定了，汽车拥有量只是"平均而言"更高 |
| 能 100% 预测吗 | 能 | 只能预测"平均水平" |

**经济社会问题 99% 是相关关系**——因为影响 y 的因素太多了，不可能用一个 x 严格决定 y。回归分析整套工具，就是为相关关系设计的。

> 💡 两者还有联系：当随机扰动消失（所有影响因素都被控制住），相关关系就退化成函数关系。所以**函数关系是相关关系的特例**。

## 二、是什么？

### 生活比喻：两个舞者

想象两个人跳舞：
- A 跳得好，B 也跳得好 → 两人步伐一致，正相关；
- A 跳得好，B 反而跳砸了 → 反着来，负相关；
- A 跳得好跳得坏，B 毫无反应 → 没关系。

**皮尔逊相关系数 r**，就是给"舞者配合度"打一个分：
- $r = +1$：完全正相关（A 举左手，B 也举左手）；
- $r = -1$：完全负相关（A 举左手，B 举右手）；
- $r = 0$：完全没关系（各跳各的）；
- $r = 0.9$：高度正相关（很一致，但不是百分百）。

> 💡 对 r 的直觉、不同 r 值对应什么样的散点图，教材笔记里有更系统的图解：[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP03_相关系数r的直觉|KP03 相关系数 r 的直觉]]。

### 严格定义

皮尔逊相关系数：

$$r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2} \sqrt{\sum_{i=1}^{n}(y_i - \bar{y})^2}}$$

这个公式看起来吓人，其实就三部分：

1. **分子**：$\sum(x_i - \bar{x})(y_i - \bar{y})$ —— 两个变量"一起偏离均值"的程度；
2. **分母左**：$\sqrt{\sum(x_i - \bar{x})^2}$ —— x 自己的波动（就是标准差 × √(n-1)）；
3. **分母右**：$\sqrt{\sum(y_i - \bar{y})^2}$ —— y 自己的波动。

**除以分母的作用**：把结果[[KP11_标准化_ZScore|标准化]]到 [-1, 1] 之间。
不除的话，x 单位是元、y 单位是年，没法比。

---

## 三、公式怎么来的？

### 第一步：我们想衡量"x 大的时候 y 是不是也大"

第 $i$ 个观测：$x_i - \bar{x}$ 是 x 离均值多远，$y_i - \bar{y}$ 是 y 离均值多远。

如果 x 比均值大时 y 也比均值大——两个都是正的，乘积是正的；
如果 x 比均值大时 y 比均值小——一正一负，乘积是负的。

把所有乘积加起来：$\sum(x_i - \bar{x})(y_i - \bar{y})$。
- 这个和是正的 → 整体正相关；
- 这个和是负的 → 整体负相关；
- 这个和接近 0 → 没关系。

**这一步是因为**：乘积的正负号刚好反映了"同方向还是反方向"。

### 第二步：这个和的大小跟单位有关

如果 x 是"元"，加 1000 元，乘积就变大很多；
如果 x 是"万元"，加 0.1 万元，乘积一样，但数字小 10000 倍。

**所以要标准化**：除以 x 自己的波动和 y 自己的波动。
这样不管你用什么单位，r 永远在 [-1, 1]。

### 第三步：为什么开根号？

因为 $\sum(x_i - \bar{x})^2$ 的单位是"元²"，开根号变回"元"，才能和分子的单位对上。

## 四、符号表

| 符号 | 怎么读 | 是什么 |
|------|--------|--------|
| $x_i, y_i$ | "x 第 i 个, y 第 i 个" | 第 i 个观测的两个变量值 |
| $\bar{x}, \bar{y}$ | "x 拔, y 拔" | x 和 y 的均值 |
| $r$ | "r" | 皮尔逊相关系数，范围 [-1, 1] |
| $n$ | "n" | 样本量 |

## 五、一个完整的数字例子手算

> 💡 下面这步手算流程和教材笔记里的[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP04_相关系数手算|KP04 相关系数手算]]完全一致，那里有更详细的表格和中间量，可以对照看一遍。

**数据**：5 个人的受教育年限 x（年）和月工资 y（千元）：

| i | x（教育年限） | y（工资/千元） |
|---|--------------|---------------|
| 1 | 9 | 3 |
| 2 | 12 | 4.5 |
| 3 | 12 | 5 |
| 4 | 16 | 7 |
| 5 | 19 | 8.5 |

### 第一步：算均值

$$\bar{x} = \frac{9+12+12+16+19}{5} = \frac{68}{5} = 13.6$$

$$\bar{y} = \frac{3+4.5+5+7+8.5}{5} = \frac{28}{5} = 5.6$$

### 第二步：算每个观测的偏离

| i | $x_i - \bar{x}$ | $y_i - \bar{y}$ | $(x_i-\bar{x})(y_i-\bar{y})$ | $(x_i-\bar{x})^2$ | $(y_i-\bar{y})^2$ |
|---|-----------------|-----------------|------------------------------|-------------------|-------------------|
| 1 | -4.6 | -2.6 | 11.96 | 21.16 | 6.76 |
| 2 | -1.6 | -1.1 | 1.76 | 2.56 | 1.21 |
| 3 | -1.6 | -0.6 | 0.96 | 2.56 | 0.36 |
| 4 | 2.4 | 1.4 | 3.36 | 5.76 | 1.96 |
| 5 | 5.4 | 2.9 | 15.66 | 29.16 | 8.41 |
| **求和** | | | **33.7** | **61.2** | **18.7** |

### 第三步：代入公式

$$r = \frac{33.7}{\sqrt{61.2} \times \sqrt{18.7}} = \frac{33.7}{7.823 \times 4.324} = \frac{33.7}{33.83} \approx 0.996$$

**r ≈ 0.996**——几乎完全正相关。

### Python 验证

```python
import numpy as np

x = [9, 12, 12, 16, 19]
y = [3, 4.5, 5, 7, 8.5]

r = np.corrcoef(x, y)[0, 1]
print(f"r = {r:.4f}")  # 0.9960
```

### 简捷公式（不用先算均值）

实际手算时，如果不想先算 x̄ 和 ȳ，可以用这个等价公式：

$$r = \frac{n\sum xy - \sum x \sum y}{\sqrt{n\sum x^2 - (\sum x)^2} \sqrt{n\sum y^2 - (\sum y)^2}}$$

**为什么有这个公式？** 把定义式展开、通分、化简，就得到这个不依赖均值的版本。用计算器或 Excel 算的时候这个更方便——因为你直接加总 x、y、xy、x²、y² 就行，不用先算均值再算每个偏离。

**用上面 5 个人的数据验证一下**：
- Σx = 68，Σy = 28，Σxy = 9×3 + 12×4.5 + 12×5 + 16×7 + 19×8.5 = 27 + 54 + 60 + 112 + 161.5 = 414.5
- Σx² = 81 + 144 + 144 + 256 + 361 = 986
- Σy² = 9 + 20.25 + 25 + 49 + 72.25 = 175.5

代入：分子 = 5×414.5 - 68×28 = 2072.5 - 1904 = 168.5
分母 = √(5×986 - 68²) × √(5×175.5 - 28²) = √(4930-4624) × √(877.5-784) = √306 × √93.5 = 17.49 × 9.67 = 169.1

r = 168.5 / 169.1 ≈ 0.996 ✅ 和前面定义式的结果一样。

### r=0.9 到底多大？

经验判断：

| r 的范围 | 相关程度 |
|---------|---------|
| \|r\| < 0.3 | 弱相关 |
| 0.3 < \|r\| < 0.5 | 中等相关 |
| 0.5 < \|r\| < 0.7 | 较强相关 |
| \|r\| > 0.7 | 高度相关 |

注意：这是经验法则，不是绝对标准。经济学论文里，r=0.5 就算很强了。

### r 也要做显著性检验

上面算出来 r = 0.996，但这是**样本相关系数**。样本只有 5 个人，会不会是碰巧？教材笔记里[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP05_相关系数显著性检验|KP05 相关系数显著性检验]]讲了怎么用 t 检验判断"这个 r 是不是显著不等于 0"——思路和[[07_假设检验直觉|下一篇讲的回归里的假设检验]]一模一样：先设 H₀: ρ = 0，再算 t = r·√(n-2)/√(1-r²)，查 p 值。**小样本下，哪怕 r 看起来很大，也可能不显著。**

**手算一个反例**（教材笔记[[../../教材笔记/05_统计学原理/08_相关与回归/知识点/KP04_相关系数手算|KP04]]的数据：5 个学生的学习时间 x 和考试分数 y，算出来 r = 0.853）：

$$t = 0.853 \times \sqrt{\frac{5-2}{1-0.853^2}} = 0.853 \times \sqrt{\frac{3}{0.272}} = 0.853 \times 3.32 = 2.83$$

查 t 表（自由度 n-2 = 3），5% 双尾临界值 = 3.182。

**|t| = 2.83 < 3.182 → 不拒绝 H₀！**

意思是：虽然 r = 0.853 看起来挺大，但 5 个样本太少，统计上还不能说"学习时间和分数真的相关"。

**生活直觉**：
- 小样本 + 高 r：可能不显著（上面这个例子就是）
- 大样本 + 中等 r：可能显著（n=100，r=0.2 也可能显著）

> ⚠️ **这就是为什么不能只看 r 的大小下结论**——一定要看显著性。

## 六、相关 ≠ 因果（最重要的易错点）

### 经典例子：冰淇淋和溺水

统计数据：**冰淇淋销量越高，溺水死亡人数越多。r = 0.8。**

难道是冰淇淋导致溺水？当然不是。

真相：**夏天来了**——天热了，买冰淇淋的人多了，游泳的人也多了，溺水的人自然多了。

冰淇淋和溺水，都被"气温"这个第三个变量影响着。它们相关，但谁也不导致谁。

### 经济学里的经典例子

- 喝啤酒的人工资更高？——可能是爱社交的人既爱喝啤酒又会来事涨工资；
- 上过补习班的学生成绩差？——可能是成绩差的才去补；
-  taller 的人工资高？——可能是身高反映童年营养，童年营养好的人本来就发展好。

**相关系数只告诉你"它们一起动"，不告诉你"谁导致谁"。**

要做因果，需要后面第 5 章的[[03_工具变量IV|工具变量]]、自然实验等方法。

## 七、什么时候用相关系数？

- 探索性分析：先看两个变量有没有关系，再决定要不要回归；
- 检验[[04_多重共线性|多重共线性]]：两个解释变量之间 r > 0.8，可能共线性问题；
- 论文里描述性统计的相关系数矩阵表。

---

## 八、易错点

1. **相关 ≠ 因果**。上面已经讲了。
2. **r 只衡量线性关系**。如果两个变量是 U 形关系（先降后升），r 可能接近 0，但其实有关系——只是不是直线关系。
3. **极端值会严重拉偏 r**。一个离群点可以把 r 从 0.3 拉到 0.9。
4. **样本量小的时候 r 不稳定**。5 个点算出来 r=0.99，换 5 个点可能就变成 0.3。
5. **r 大不代表有经济意义**。两个变量统计上高度相关，但可能都是被第三个变量驱动的。

## 九、Python 代码

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['Hiragino Sans GB', 'PingFang SC']
plt.rcParams['axes.unicode_minus'] = False

# 构造数据
df = pd.DataFrame({
    'edu': [9, 12, 12, 16, 19],
    'wage': [3, 4.5, 5, 7, 8.5]
})

# 算相关系数矩阵
print("=== 相关系数矩阵 ===")
print(df.corr())

# 画散点图 + 回归线
plt.figure(figsize=(6, 5))
plt.scatter(df['edu'], df['wage'], s=80, color='steelblue')

# 加一条拟合直线（后面会教怎么算）
b, a = np.polyfit(df['edu'], df['wage'], 1)
x_line = np.linspace(8, 20, 100)
plt.plot(x_line, a + b*x_line, 'r--', label=f'r = {df["edu"].corr(df["wage"]):.3f}')

plt.xlabel('教育年限（年）')
plt.ylabel('月工资（千元）')
plt.title('教育年限 vs 工资 散点图')
plt.legend()
plt.tight_layout()
plt.savefig('corr_scatter.png', dpi=150)
plt.show()
```

## 十、对比

| 指标 | 衡量什么 | 范围 | 缺点 |
|------|---------|------|------|
| 皮尔逊 r | 线性相关 | [-1, 1] | 只看线性，被极端值拉偏 |
| 斯皮尔曼 ρ | 排序相关 | [-1, 1] | 只看排名，不看距离 |
| 回归系数 | x 变 1 单位 y 变多少 | 无界 | 要有因变量自变量之分 |

---

## 十一、为什么不用别的方法？

- **为什么不直接画散点图就下结论？** 散点图只给肉眼印象，没有数字、不能放进论文的描述性统计表，也做不了显著性检验；而且人眼对弱相关、U 形关系的判断很不可靠，必须算一个 r。
- **为什么不用斯皮尔曼等级相关代替皮尔逊 r？** 斯皮尔曼只看排名、不看数值距离，会丢掉"x 大多少、y 大多少"的强度信息；当两变量本来近似直线关系时，皮尔逊 r 用了全部数值信息、检验功效更高。
- **为什么不直接上回归而要先算相关系数？** 回归得先指定谁是因变量、谁是自变量，还要假设线性、考虑控制变量；探索阶段你还不确定方向，相关系数是对称的、零成本，先看一眼有没有关系、方向正负，再决定要不要回归。

---

## 十二、答辩常问（直接背）

1. **问：r = 0.8，能不能说吃海参导致智商高？** 答：不能。相关不等于因果，r=0.8 只说明两者同方向变动，很可能被"家庭收入"这个第三变量同时推高。要做因果必须用工具变量或自然实验。
2. **问：r 多大算高？** 答：经验法则是 |r|>0.7 高度相关、0.5~0.7 较强、0.3~0.5 中等、<0.3 弱相关；但这是经验不是标准，经济学论文里 r=0.5 已经算很强。
3. **问：为什么 U 形关系 r 可能接近 0？** 答：皮尔逊 r 只衡量直线关系，U 形是先降后升的曲线，一正一负的乘积在求和时相互抵消，r≈0 但其实关系很强——这正是 r 只抓线性关系的局限。

---

## 十三、速记卡

> **r = 两个变量一起偏离均值的程度，标准化到 [-1, 1]。**
> **r=1 完全正相关，r=-1 完全负相关，r=0 没关系。**
> **相关 ≠ 因果**：冰淇淋和溺水都被夏天驱动。
> **r 只看线性关系**，U 形关系 r 会接近 0。
> 极端值会严重拉偏 r。
