# 07 随机效应 RE 与 Hausman 检验：FE 和 RE 选哪个？

## 一、为什么要学这个？

上一节我们学了 FE：每个人减自己的均值。

但 FE 有个缺点：它**浪费信息**——它把"人与人之间的差异"（between 变异）全扔了，只用"一个人内部的变化"（within 变异）。

如果你确信 $\alpha_i$ 和 X 无关，那其实不用这么浪费——可以用 RE（随机效应），把 between 变异也用上，估出来的系数更有效（标准误更小）。

问题是：**你怎么知道 $\alpha_i$ 和 X 无关？**

答：**Hausman 检验**。

---

## 二、是什么？（比喻 + 定义）

### 比喻：两种调查方法

你想研究"教育 X → 工资 Y"。

- **FE 的做法**：跟踪同一个人多年，看他自己学历变了工资怎么变。好处：排除天生差异。坏处：同一个人学历变化很少，信息少。
- **RE 的做法**：既看人与人的学历差异，也看每个人自己随时间的学历变化。好处：信息多、标准误小。坏处：前提是"学历高低和天生能力无关"——这个前提通常不成立。

**Hausman 检验**就是帮你判断：RE 的前提成不成立？成立就用 RE（更高效），不成立就用 FE（更稳健）。

### 严格定义

**RE 模型**：
$$Y_{it} = \beta_0 + \beta_1 X_{it} + u_i + \varepsilon_{it}$$

RE 假设 $u_i$（个体效应）是随机的，且和 $X_{it}$ **不相关**：
$$\mathrm{Cov}(u_i, X_{it}) = 0$$

这是一个强假设。如果它成立，RE 比 FE 更有效（用了更多信息）；如果不成立，RE 有偏。

**FE 不做这个假设**——它允许 $u_i$ 和 X 相关，直接把 $u_i$ 消掉。

### RE 的 GLS 变换和 θ 直觉（[[../../教材笔记/02_计量经济学/11_面板数据/知识点/KP02_随机效应模型|KP02 随机效应模型]]）

RE 不是"直接混合 OLS"，它做了一个加权变换：

$$Y_{it} - \theta \bar{Y}_i = \beta_0 + \beta_1 (X_{it} - \theta \bar{X}_i) + \text{残差}$$

其中 $\theta \in [0,1]$：
- $\theta = 0$：不减均值 → 退化成混合 OLS；
- $\theta = 1$：全减均值 → 退化成 FE；
- RE 是两者之间的折中，**介于混合 OLS 和 FE 之间**。

$\theta$ 多大取决于 $\sigma_u^2$（个体效应方差）和 $\sigma_\varepsilon^2$（特异扰动方差）的比例：
- $\sigma_u^2$ 大（个体差异主导）→ θ 接近 1 → RE 接近 FE；
- $\sigma_u^2$ 小（个体差异可忽略）→ θ 接近 0 → RE 接近混合 OLS。

> **局限**：RE 只对**随时间变化**的变量有效。如果 X 对同一个人多年不变（如性别、民族），$X_{it}-\theta\bar X_i=0$，信息被 θ 加权后废掉，估不出来。

---

## 三、公式怎么来的？（Hausman 检验的思路）

**核心逻辑**：

- 如果 RE 的假设成立（$u_i$ 和 X 无关），那 FE 和 RE 都无偏，只是 RE 更有效。两者估出来的系数应该**差不多**。
- 如果 RE 的假设不成立（$u_i$ 和 X 相关），那 FE 无偏、RE 有偏。两者估出来的系数应该**差很多**。

**Hausman 统计量**：

$$H = (\hat{\beta}_{RE} - \hat{\beta}_{FE})' [\mathrm{Cov}(\hat{\beta}_{FE}) - \mathrm{Cov}(\hat{\beta}_{RE})]^{-1} (\hat{\beta}_{RE} - \hat{\beta}_{FE})$$

- 原假设 H₀：RE 是一致的（$u_i$ 和 X 无关）。
- 备择 H₁：RE 不一致，FE 才一致。
- H 服从 $\chi^2(k)$ 分布，k 是解释变量个数。

**判读**：
- p > 0.05：不拒绝 H₀，RE 可以用（更有效）；
- p < 0.05：拒绝 H₀，必须用 FE。

---

## 四、符号表

| 符号 | 含义 |
|------|------|
| $u_i$ | 随机效应（RE 视角下的个体效应） |
| $\hat{\beta}_{RE}$ | RE 估的系数 |
| $\hat{\beta}_{FE}$ | FE 估的系数 |
| $H$ | Hausman 统计量 |
| $k$ | 解释变量个数 |

## 五、一个完整的数字例子（逻辑演示）

**假设**：我们用上面 2 人 3 年的迷你数据，估工龄 β。

- FE 估出 $\hat{\beta}_{FE} = 2.00$（上一节手算过）；
- RE 估出 $\hat{\beta}_{RE} \approx 2.10$（RE 在 FE 和混合 [[04_OLS截距和拟合值|OLS]] 之间）。

**两者差 0.10**——这个差大不大？

- 如果标准误是 0.5，差 0.10 不算什么，Hausman p>0.05，用 RE；
- 如果标准误是 0.05，差 0.10 就是 2 个标准误，Hausman p<0.05，必须用 FE。

**直觉**：Hausman 检验就是在问"FE 和 RE 的系数差异，能不能用抽样误差解释？"能，就用 RE（高效）；不能，就用 FE（稳健）。

**Python 演示 Hausman 检验思路**：

```python
import numpy as np
# 假设我们已经跑了 FE 和 RE，得到系数和协方差矩阵
beta_fe = np.array([2.0])
beta_re = np.array([2.1])
cov_fe = np.array(0.04)
cov_re = np.array(0.03)

# Hausman 统计量
diff = beta_re - beta_fe
cov_diff = cov_fe - cov_re
H = diff @ np.linalg.inv(cov_diff) @ diff
print(f"H = {H:.3f}")   # 卡方统计量
# 和卡方(1)临界值 3.84 比较
```

## 六、什么时候用？

| 情况 | 选什么 |
|------|--------|
| Hausman p<0.05（绝大多数经济数据） | **FE** |
| Hausman p>0.05，且你要估时间不变变量 | RE |
| 数据是随机抽样、个体效应真的随机 | RE |
| 本科论文 | **默认 FE**，别纠结 |

**为什么本科论文默认 FE？**

1. 经济数据里 $u_i$ 和 X 几乎总是相关（能力和教育相关、文化和制度相关）；
2. FE 更稳健，审稿人不会挑刺；
3. RE 的假设太强，被质疑了不好辩护。

---

## 七、易错点

1. **Hausman 检验的原假设是"RE 一致"**，不是"FE 一致"。别记反了。
2. **Hausman 检验在加了聚类标准误后怎么用？** Stata 的 `xtoverid` 命令可以做稳健版本。本科论文直接用 FE 就行，不用纠结这个。
3. **RE 不是"不要[[06_固定效应FE|固定效应]]"**。RE 也控制了个体效应，只是用 GLS 方法，假设它随机。
4. **随机效应不是"随机误差"**——别被名字骗了。RE 里的 $u_i$ 是系统性的个体差异，不是噪声。
5. **FE 永远比 RE 稳健**。当你不确定时，选 FE 不会错。
6. **小样本时 Hausman p>0.05 可能是"检验功效低"，不是 RE 真的成立**。样本 < 100 时检验抓不住 RE 的偏离，别盲信 p 值；经济直觉上大概率还是该选 FE。
7. **Hausman 之前先做 Breusch-Pagan LM 检验**：原假设 $H_0: \sigma_u^2 = 0$（不存在个体效应，直接混合 OLS）。p > 0.05 说明连个体效应都没有，混合 OLS 就够了；p < 0.05 才在 FE 和 RE 之间做选择。Stata：`xtreg, re` 后 `xttest0`。

---

## 八、Stata 代码

```stata
-- Hausman 检验完整流程
use "panel.dta", clear
xtset id year

-- 第一步：先跑 FE，保存结果
xtreg y x1 x2 i.year, fe
estimates store fe

-- 第二步：再跑 RE
xtreg y x1 x2 i.year, re
estimates store re

-- 第三步：Hausman 检验
hausman fe re
-- 输出：
-- chi2(3) = ...   Prob>chi2 = ...
-- p<0.05：选 FE
-- p>0.05：选 RE

-- 论文里怎么写？
-- "Hausman 检验拒绝随机效应原假设（p<0.05），故采用固定效应模型。"
```

## 九、和别的方法对比

| 方法 | 假设 | 优点 | 缺点 |
|------|------|------|------|
| 混合 OLS | 没有个体效应 | 简单 | 有偏 |
| **FE** | **u_i 和 X 可以相关** | **稳健、不依赖强假设** | **低效、估不出时间不变变量** |
| RE | u_i 和 X 不相关 | 高效、能估时间不变变量 | 假设强、有偏风险 |

**论文建议**：FE + 聚类标准误 + 年份[[09_虚拟变量|虚拟变量]]。这是最安全[[KP05_评价标准值xi0的选择|的选择]]。

## 十、为什么不用别的方法？

- **为什么不凭经验直接选 FE、不跑 Hausman？** 经验上经济数据绝大多数 p<0.05 选 FE 没错，但答辩被问"你跑了 Hausman 吗"答不上来就尴尬。`hausman fe re` 是一条命令、5 秒钟出结果，它给你选 FE 的统计依据，不是凭感觉拍脑袋。
- **为什么不用混合 OLS 替代 RE？** 混合 OLS 完全不控制个体效应，α_i 和 X 一相关就有偏；RE 至少用 GLS 加权利用了 between 信息。p>0.05 时 RE 比混合 OLS 和 FE 都更有效，标准误更小。
- **为什么不直接默认 RE（它标准误小、还能估时间不变变量）？** RE 的假设 Cov(u_i,X)=0 太强，经济数据里几乎总是被违反。一旦违反，RE 系数有偏、且不收敛到真实值——省下的那点标准误，换来的是整篇实证废掉，得不偿失。

## 十一、答辩常问（直接背）

1. **问：Hausman 检验的原假设是什么？p 值怎么读？** 答：原假设 H₀ 是"RE 一致"（即 u_i 和 X 不相关）。p>0.05 不拒绝 H₀ → RE 可用（更高效）；p<0.05 拒绝 H₀ → 必须用 FE。注意别记反：H₀ 是 RE 好，不是 FE 好。
2. **问：Hausman 检验背后的逻辑是什么？** 答：如果 RE 假设成立，FE 和 RE 都无偏，系数应该差不多；如果假设不成立，FE 无偏、RE 有偏，两者系数会差很多。H 统计量就是在问"这个系数差异能不能用抽样误差解释"，服从 χ²(k) 分布。
3. **问：本科论文为什么默认选 FE？** 答：三个原因：① 经济数据里 u_i 和 X 几乎总是相关（能力和教育、文化和制度）；② FE 更稳健，审稿人挑不出刺；③ RE 的强假设被质疑了不好辩护。RE 唯一的用武之地，是你确实要估时间不变变量、且 Hausman p>0.05。
4. **问：RE 是不是"不要固定效应"？** 答：不是。RE 里也有 u_i（个体效应），它也在控制个体差异，只是用 GLS 加权估计、并假设 u_i 和 X 无关。"随机效应"不是"随机误差"——u_i 是系统性的个体差异，不是噪声。

---

## 十二、速记卡

> **RE vs FE：**
> - RE 假设个体效应和 X 无关（强假设）；
> - FE 不做这个假设（稳健）；
> - Hausman 检验：p<0.05 选 FE，p>0.05 选 RE。
> - **本科论文默认 FE，别赌 RE。**
> - FE 是"和自己比"，RE 是"既和别人比又和自己比"——前者稳，后者省。

## 💡 经济学视角：FE 还是 RE？这是个"信不信"的问题

**这个方法是为了解决什么经济学问题？**
面板数据摆在你面前，到底用 FE 还是 RE？本质是一个**信念问题**：你相不相信"个体效应 α_i 和你的解释变量 X 无关"？如果你信（比如研究全国随机抽样的家庭，家庭偏好大概率和政策变量无关），RE 更省、更有效；如果你不信（比如研究各省市场化，地方制度禀赋显然和 X 共生），FE 更稳。Hausman 检验就是用数据替你做这个信念判断。

**经济学里哪些经典模型正好对应这个方法？**
社会主义市场经济里，"政府与市场关系"是典型的不随时间变的制度变量——你几乎不可能假设它和解释变量 X 独立。所以研究中国地区问题的论文，99% 默认 FE。RE 更多用在微观调查数据（CFPS、CHIP）这类"个体随机抽样"场景，因为抽样随机性保证了 α_i 和 X 不相关。

**举个实证论文的例子：**
《环保投入对地区碳排放的影响》用 30 省 15 年面板，Hausman 检验 p=0.02 < 0.05，必须选 FE。如果作者硬上 RE，估出来环保投入系数显著为负、政策含义是"多投环保就能减排"；换成 FE 后系数缩水一半、显著性消失——因为原来显著的部分，其实是"环保投入多的省份本来就是经济发达、能源结构清洁的省份"。**选错 FE/RE，结论直接反着写**。
