# 02 遗漏变量偏误：漏了一个能力，偏误有多大？

<div style="text-align:right;margin:10px 0;"><a href="../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


## 一、为什么要学这个？

你研究"教育 → 工资"，数据里只有教育和工资，没有"能力"。

你跑 [[04_OLS截距和拟合值|OLS]] 得到"多上一年学涨 621 元"。

但你知道真实的教育回报应该是 500 元——那多出来的 121 元是哪来的？

**这 121 元就是遗漏变量偏误。** 它是内生性最常见的形式，也是本科论文里最容易被导师抓的把柄。

这一章给你一个**公式**，让你在跑回归之前就能判断："我漏了这个变量，系数会偏高还是偏低？"

---

## 二、是什么？（比喻 + 定义）

### 比喻：抢功劳

一个项目，甲和乙一起干。

- 甲出了 50 分力；
- 乙出了 30 分力；
- 项目最后得了 80 分。

老板不知道乙的存在，问甲："你一个人干了多少分？"甲说："我干了 80 分。"

**甲的 80 分，就是有偏估计。** 真实是 50，多出来的 30 是乙的功劳。

回到经济学：
- 甲 = 教育 X；
- 乙 = 能力 Z（被遗漏了）；
- 项目成绩 = 工资 Y。

OLS 把能力的功劳全算到教育头上了。

### 严格定义

真实模型：
$$Y = \beta_0 + \beta_1 X + \beta_2 Z + \varepsilon$$

但我们漏了 Z，只跑：
$$Y = \tilde{\beta}_0 + \tilde{\beta}_1 X + u$$

那么：
$$E(\tilde{\beta}_1) = \beta_1 + \beta_2 \cdot \frac{\mathrm{Cov}(X, Z)}{\mathrm{Var}(X)}$$

**偏误 = $\beta_2 \times \mathrm{Cov}(X,Z)/\mathrm{Var}(X)$。**

---

## 三、公式怎么来的？（不跳步）

### 第一步：Z 和 X 的关系

因为我们漏了 Z，Z 其实混进了误差项 u 里：$u = \beta_2 Z + \varepsilon$。

OLS 估计量：
$$\tilde{\beta}_1 = \frac{\mathrm{Cov}(X, Y)}{\mathrm{Var}(X)}$$

### 第二步：把 Y 展开

$$\mathrm{Cov}(X, Y) = \mathrm{Cov}(X, \beta_0 + \beta_1 X + \beta_2 Z + \varepsilon)$$

常数 β₀ 对协方差没贡献（Cov(X, 常数)=0），所以：

$$\mathrm{Cov}(X, Y) = \beta_1 \mathrm{Cov}(X, X) + \beta_2 \mathrm{Cov}(X, Z) + \mathrm{Cov}(X, \varepsilon)$$

最后一项 $\mathrm{Cov}(X, \varepsilon)=0$（假设 ε 和 X 无关）。而 $\mathrm{Cov}(X,X) = \mathrm{Var}(X)$。

### 第三步：代入

$$\tilde{\beta}_1 = \frac{\beta_1 \mathrm{Var}(X) + \beta_2 \mathrm{Cov}(X, Z)}{\mathrm{Var}(X)}$$
$$= \beta_1 + \beta_2 \cdot \frac{\mathrm{Cov}(X, Z)}{\mathrm{Var}(X)}$$

**这就是偏误公式。**

### 偏误方向怎么判断？

偏误的符号 = $\beta_2$ 的符号 × Cov(X,Z) 的符号。

| β₂ 的符号 | Cov(X,Z) 的符号 | 偏误方向 | 例子 |
|-----------|-----------------|----------|------|
| + | + | **正偏**（高估） | 能力对工资+，能力和教育正相关 → 高估教育回报 |
| + | - | 负偏（低估） | —— |
| - | + | 负偏（低估） | —— |
| - | - | 正偏（高估） | —— |

**最常见的是第一行**：遗漏变量 Z 对 Y 是正作用，Z 和 X 也正相关 → 你高估了 X 的作用。

---

## 四、符号表

| 符号 | 含义 |
|------|------|
| $\beta_1$ | X 对 Y 的真实因果效应 |
| $\beta_2$ | 遗漏变量 Z 对 Y 的真实效应 |
| $Z$ | 被遗漏的变量 |
| $\tilde{\beta}_1$ | 漏了 Z 时 OLS 估出的系数 |
| $\mathrm{Cov}(X,Z)$ | X 和 Z 的协方差 |
| $\mathrm{Var}(X)$ | X 的方差 |
| 偏误 | $\tilde{\beta}_1 - \beta_1$ |

---

## 五、一个完整的数字例子

**真实世界**：
- 工资 Y = 1000 + 500×教育 X + 300×能力 Z + ε
- 教育和能力正相关：Cov(X,Z) = 0.8，Var(X) = 2.0

**第一步：算偏误。**

$$\text{偏误} = \beta_2 \times \frac{\mathrm{Cov}(X,Z)}{\mathrm{Var}(X)} = 300 \times \frac{0.8}{2.0} = 300 \times 0.4 = 120$$

**第二步：我们估出的系数。**

$$\tilde{\beta}_1 = 500 + 120 = 620$$

也就是：漏了能力后，OLS 说"多上一年学涨 620 元"，但真实是 500 元——**高估了 120 元**。

**第三步：Python 模拟验证。**

```python
import numpy as np
import statsmodels.api as sm
np.random.seed(0)
n = 200
ability = np.random.normal(0, 1, n)
edu = 12 + 2*ability + np.random.normal(0, 1, n)
wage = 1000 + 500*edu + 300*ability + np.random.normal(0, 50, n)

# 错误模型（漏 ability）
X_bad = sm.add_constant(edu)
print("漏能力: b_edu =", sm.OLS(wage, X_bad).fit().params[1])
# 输出 ≈ 621（真实=500，偏误≈121）

# 正确模型（控制 ability）
X_good = sm.add_constant(np.column_stack([edu, ability]))
print("控能力: b_edu =", sm.OLS(wage, X_good).fit().params[1])
# 输出 ≈ 510（接近真实500）

# 公式预测偏误
bias_formula = 300 * np.cov(edu, ability, ddof=0)[0,1] / np.var(edu)
print("公式预测偏误 =", bias_formula)  # ≈ 121
```

**实际输出**：
- 漏能力：621.49（真实 500，偏误 +121）
- 控能力：510.06（接近 500）
- 公式预测偏误：120.99 ≈ 121 ✅

公式和模拟对上了。

## 六、什么时候用？

**写论文必用。** 任何一个回归，你都要在心里过一遍：

1. 我漏了什么 Z？
2. Z 对 Y 是正还是负作用？（β₂ 符号）
3. Z 和我的 X 是正相关还是负相关？（Cov(X,Z) 符号）
4. 两个符号相乘，我的系数是高估还是低估？

这就是论文里"内生性讨论"部分的核心。

---

## 七、易错点

1. **偏误公式的前提是：Z 只通过 X 影响 Y 这条路被截断**。如果 Z 直接影响 Y（这是常态），公式才成立。
2. **不要把"遗漏变量"和"遗漏高阶项"搞混**。后者是函数形式问题（比如该加 X² 没加），用 RESET 检验；前者是内生性问题，要用 IV。
3. **偏误方向经常和你想的相反**。比如"警察越多犯罪越多"——警察 X 对犯罪 Y 的真实效应是负的（警察减少犯罪），但因为犯罪多的地方多派警察（Cov(X,Y犯罪机会)>0），你估出来是正的。这叫**反向因果型遗漏偏误**。
4. **知道偏误方向很重要**：如果你知道自己高估了 X 的效应，那真实效应只会更小——你的结论只会更保守。
5. **不能靠"多放控制变量"解决一切**。放进去的变量如果本身内生，会引入新问题。
6. **只有"与 X 相关"的遗漏变量才有偏**。如果漏掉的 Z 对 Y 有影响、但和所有已包含的 X 都不相关（比如研究教育回报时漏掉"左利手还是右利手"），它只增大扰动项方差、不产生偏误。口诀：**相关才会偏**。
7. **遗漏变量偏误 n→∞ 不消失**。它是"不一致"的——样本从 200 加到 20000，偏误还在那里。这是它和[[02_异方差|异方差]]、[[03_自相关|自相关]]最关键的区别：后两者加大样本标准误会自己修正，遗漏变量偏误不会。

### 教材原例：grilic 工资回归（[[../../教材笔记/02_计量经济学/08_模型设定与数据问题/知识点/KP01_遗漏变量偏差|KP01 遗漏变量偏差]]）

```stata
use grilic.dta, clear
reg lnwage educ                          // 裸回归：b_educ ≈ 0.103
reg lnwage educ iq expr tenure ...       // 控制 iq 后：b_educ ≈ 0.061
```

差异 = 0.103 - 0.061 = **0.042 个百分点**——不控制智商时，教育回报率被高估了 4.2 个百分点。原因：智商高的人既受教育更多，工资也更高，不控制 iq 就把 iq 的功劳算到了教育头上。

### 反直觉例子：运动 vs 体重

真实模型：体重 = β₁ + β₂×运动 + β₃×肌肉量 + ε
- β₂ < 0（运动减脂，体重降）
- β₃ > 0（肌肉重，体重增）
- 运动多的人肌肉量也大（正相关，δ=2）

漏掉肌肉量时：$\tilde\beta_2 = -0.3 + 0.5 \times 2 = +0.7$——估出来"运动让人长胖"！完全错误。原因：运动多的人肌肉重，体重当然高，但这不代表运动本身让人胖。

```stata
// 输出 b_edu ≈ 621（高估）

-- 正确模型：控制 ability

// 输出 b_edu ≈ 510（接近真实500），b_ability ≈ 276

-- 论文里怎么写？

```

## 九、和别的方法对比

| 情况 | 你知道 Z 吗 | 怎么办 |
|------|------------|--------|
| Z 可观测、有数据 | 知道 | 放进模型，控制它 |
| Z 不可观测、但不随时间变 | 不知道 | **[[06_固定效应FE|固定效应]] FE**（06 文件） |
| Z 不可观测、但有[[03_工具变量IV|工具变量]] Z_iv | 不知道 | **工具变量 IV**（03 文件） |
| Z 不可观测、也没 IV、也没面板 | 不知道 | 老实承认局限，跑稳健性讨论 |

## 十、为什么不用别的方法？

- **为什么不直接跑 OLS（不控制 Z）？** 漏了 Z 后 $E(\tilde{\beta}_1) = \beta_1 + \beta_2 \cdot \mathrm{Cov}(X,Z)/\mathrm{Var}(X)$，偏误方向由 β₂ 符号 × Cov(X,Z) 符号决定。教育-工资案例里 Z=能力对 Y 为正、与 X 正相关，直接跑 OLS 会把教育回报从真实 500 高估到 620。
- **为什么不能靠"多放控制变量"解决一切？** 你只能放进"有数据的 Z"，能力、偏好、文化这些看不见的变量你测不到；而且新放进去的变量如果本身和 ε 相关（坏控制变量，比如同时被 X 和 Y 影响的"中介变量"），会引入新的内生性，越修越糟。
- **为什么不用 FE / IV 替代这个偏误公式？** FE / IV 是"动手解决"，偏误公式是"动手之前先判断方向"。论文内生性讨论部分必须先用这个公式论证：我漏掉的 Z 会让系数高估还是低估——这是上 IV / FE 之前的逻辑铺垫，两者是先后关系，不是替代关系。

## 十一、答辩常问（直接背）

1. **问：遗漏变量偏误的公式是什么？怎么判断偏误方向？** 答：偏误 = β₂ × Cov(X,Z)/Var(X)，其中 β₂ 是遗漏变量 Z 对 Y 的真实效应，Cov(X,Z) 是 Z 和 X 的相关。方向 = β₂ 符号 × Cov(X,Z) 符号：同号为正偏（高估 X 作用），异号为负偏（低估）。最常见是"Z 对 Y 正、Z 和 X 正"→ 高估。
2. **问：警察越多犯罪越多，是警察导致犯罪吗？** 答：不是。这是反向因果型遗漏偏误：警察 X 对犯罪 Y 的真实效应是负的（警察减少犯罪），但犯罪多的地方才多派警察（Cov(X, 犯罪机会)>0），把系数推成正的。看到正相关绝不能直接下因果结论。
3. **问：知道偏误方向有什么实际用？** 答：如果你论证出 OLS 高估了 X 的效应，那真实效应只会更小——结论方向不变但更保守，审稿人反而放心；怕的是你不知道方向，连真实系数可能翻不翻转都说不清。
4. **问：偏误公式和 RESET 检验是一回事吗？** 答：不是。偏误公式处理的是"漏了一个相关的 Z"（内生性问题，要用 IV / FE）；RESET 检验处理的是"函数形式错了"（该加 X² 没加，属于多项式设定问题）。两者病因不同，药方也不同。

---

## 十二、速记卡

> **遗漏变量偏误 = $\beta_2 \times \mathrm{Cov}(X,Z)/\mathrm{Var}(X)$。**
> - 方向判断：β₂ 符号 × Cov(X,Z) 符号。
> - 最常见：Z 对 Y 正、Z 和 X 正 → 高估 X 的作用。
> - 写论文必问：我漏了什么？它对 Y 是正是负？它和我的 X 相关吗？
> - 知道偏误方向，比知道偏误大小更重要——它告诉你结论该往哪个方向修正。

## 💡 经济学视角：为什么"多读一年书多赚 10%"可能是假象

**这个方法是为了解决什么经济学问题？**
估计教育回报时，最头疼的不是数据少，是**有一个看不见摸不着的东西叫"个人能力"**。能力强的人，读书更轻松所以多读了几年；能力强的人，工作起来也更吃香所以工资更高。你只拿"教育年限"去解释"工资"，能力这个漏掉的变量会悄悄把它的功劳算到教育头上——**这就是遗漏变量偏误，最经典的版本**。

**经济学里哪些经典模型正好对应这个方法？**
劳动经济学里的工资决定方程 $w=f(教育,经验,能力,其他)$，能力在明瑟（Mincer）最初的模型里是被塞进扰动项的。但现代劳动经济学意识到：能力和教育强相关，放进 ε 里就污染了 MLR.4 假设。这就是为什么劳动经济学变成了微观计量里最活跃的分支——它天天和"能力"这个幽灵搏斗。

**举个实证论文的例子：**
早期 Mincer 方程跑全国普查数据，教育回报估出来 8%–10%；后来 Angrist、Krueger 用出生季度做 IV，把"能力"这层噪音剥掉，估出来的教育回报反而稳定在 7%–9%——也就是说早期 OLS 大约高估了 1–2 个百分点。这 1–2 个点的差别，背后就是"国家要不要多投教育"的政策判断。
