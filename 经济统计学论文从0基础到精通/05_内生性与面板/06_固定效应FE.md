# 06 固定效应 FE：和自己比，排除天生差异

## 一、为什么要学这个？

你研究"上大学 X → 工资 Y"。

截面数据的问题：上大学的人本来就更聪明、家境更好。你看到"大学生工资高"，分不清是大学的功劳，还是天生的。

**面板固定效应的思路**：跟踪同一个人 10 年，看他上大学**之前**和**之后**的工资变化。

- 这个人的智商、家境、性格，10 年内基本不变；
- 唯一变的是：他上大学了；
- 那工资变化，就只能归因于上大学。

这就是 FE：**每个人和自己比，把所有不随时间变的东西全部消掉。**

---

## 二、是什么？（比喻 + 定义）

### 比喻：称体重的前后对比

你想知道"跑步能不能减肥"。

- 找 100 个人：胖子本来就不爱跑步，瘦子也不一定跑——组间对比有偏。
- 找 1 个人，连续记录他跑步前 1 个月、跑步后 1 个月的体重。同一个人，基因、饮食、作息都不变，唯一变量是跑步。

FE 就是第二种做法。

### 严格定义

模型：
$$Y_{it} = \beta_0 + \beta_1 X_{it} + \alpha_i + \varepsilon_{it}$$

其中 $\alpha_i$ 是个体固定效应（不随时间变）。

**关键假设**：$\alpha_i$ 可以和 $X_{it}$ 相关——这正是 FE 的优势。它不像 RE 那样假设无关，而是直接把 $\alpha_i$ 控制掉。

**怎么控制？三种等价做法**：

1. **最小二乘[[09_虚拟变量|虚拟变量]] LSDV**：给每个个体加一个虚拟变量（除了一个参考组）。N=31 个省就加 30 个虚拟变量。
2. **within 估计量（去均值法）**：每个人减自己的时间均值。
3. **一阶差分 FD**：相邻两期相减，$(y_{it}-y_{i,t-1})$，α_i 同样被减掉。T=2 时 FD 和 within 完全相同；T>2 时 within 更有效。

三种方法估出来的 $\beta_1$ 完全一样。论文里 `xtreg, fe` 默认用 within。

---

## 三、公式怎么来的？（within 估计量）

### 第一步：对模型两边按个体取时间平均

$$\bar{Y}_i = \beta_0 + \beta_1 \bar{X}_i + \alpha_i + \bar{\varepsilon}_i$$

其中 $\bar{Y}_i = \frac{1}{T}\sum_{t=1}^T Y_{it}$，其他类似。

### 第二步：原模型减去平均后的模型

$$Y_{it} - \bar{Y}_i = \beta_1 (X_{it} - \bar{X}_i) + (\varepsilon_{it} - \bar{\varepsilon}_i)$$

**看到没？$\alpha_i$ 消失了！** 因为它对同一个体的所有期都一样，减均值时减掉了。$\beta_0$ 也消失了（常数减常数）。

### 第三步：对去均值后的数据跑 [[04_OLS截距和拟合值|OLS]]

$$\hat{\beta}_{FE} = \frac{\sum_{i=1}^{N}\sum_{t=1}^{T} (X_{it}-\bar{X}_i)(Y_{it}-\bar{Y}_i)}{\sum_{i=1}^{N}\sum_{t=1}^{T} (X_{it}-\bar{X}_i)^2}$$

这就是 **within 估计量**——只用每个人"内部随时间的变异"来识别 $\beta_1$。

**直觉**：FE 完全忽略"人与人之间的差异"（between 变异），只用"一个人自己不同时间的差异"（within 变异）。

---

## 四、符号表

| 符号 | 含义 |
|------|------|
| $i$ | 个体下标 |
| $t$ | 时间下标 |
| $\alpha_i$ | 个体固定效应（不随 t 变） |
| $\bar{Y}_i$ | 个体 i 在所有期的 Y 均值 |
| $X_{it} - \bar{X}_i$ | 去均值后的 X（within 变异） |
| $\hat{\beta}_{FE}$ | FE 估计量 |

---

## 五、一个完整的数字例子（手算）

**数据**：2 个人，3 年。

| 人 | t | X（工龄） | Y（工资，千） |
|----|---|-----------|---------------|
| A | 1 | 1 | 3 |
| A | 2 | 2 | 5 |
| A | 3 | 3 | 7 |
| B | 1 | 2 | 6 |
| B | 2 | 3 | 8 |
| B | 3 | 4 | 10 |

**真实模型**：$Y_{it} = 1 + 2 X_{it} + \alpha_i + \varepsilon_{it}$
- $\alpha_A = 0$（A 的基础工资）
- $\alpha_B = 3$（B 天生工资高 3 千）
- $\beta_1 = 2$（工龄每加 1 年，工资涨 2 千）

**第一步：算每个人的均值。**

$\bar{X}_A = (1+2+3)/3 = 2$，$\bar{Y}_A = (3+5+7)/3 = 5$。

$\bar{X}_B = (2+3+4)/3 = 3$，$\bar{Y}_B = (6+8+10)/3 = 8$。

**第二步：去均值。**

| 人 | t | X-X̄ | Y-Ȳ |
|----|---|-----|-----|
| A1 | -1 | -2 |
| A2 | 0 | 0 |
| A3 | 1 | 2 |
| B1 | -1 | -2 |
| B2 | 0 | 0 |
| B3 | 1 | 2 |

**第三步：算 within 估计量。**

分子：$\sum (X-\bar{X})(Y-\bar{Y}) = (-1)(-2) + 0 + 1\times2 + (-1)(-2) + 0 + 1\times2$
$= 2 + 0 + 2 + 2 + 0 + 2 = 8$

分母：$\sum (X-\bar{X})^2 = 1 + 0 + 1 + 1 + 0 + 1 = 4$

$$\hat{\beta}_{FE} = \frac{8}{4} = 2$$

**FE 估出 β=2，正好等于真实值。** 个体效应 $\alpha_B - \alpha_A = 3$ 被减掉了，工龄效应被干净识别。

**对比混合 OLS**：把 6 个观测直接回归，得到 β=2.27——把 B 天生工资高的效应混进去了，有偏。

Python 验证：

```python
import numpy as np
x1 = np.array([1,2,3.]); y1 = np.array([3,5,7.])
x2 = np.array([2,3,4.]); y2 = np.array([6,8,10.])
xd = np.concatenate([x1-x1.mean(), x2-x2.mean()])
yd = np.concatenate([y1-y1.mean(), y2-y2.mean()])
print("FE =", np.sum(xd*yd)/np.sum(xd**2))   # 2.0
```

## 六、什么时候用？

**FE 能解决的内生性**：所有**不随时间变**的遗漏变量。

- 个人层面：天生能力、性别、民族、出生地、性格；
- 公司层面：企业文化、地理位置、创始团队；
- 省级层面：地理禀赋、文化传统、制度基因。

**FE 不能解决的内生性**：随时间变的遗漏变量。比如"2020 年疫情"同时影响 X 和 Y，但它对所有人都有影响——这要靠**时间固定效应** λ_t 来控制。

**双向固定效应**：$\alpha_i + \lambda_t$ 一起控制，是论文标配。

---

## 七、易错点

1. **FE 估不出时间不变变量的系数**。你放"性别"进去，Stata 会自动删掉它——因为性别被 α_i 吸收了。想估性别效应，换 RE 或换数据。
2. **within 变异小，标准误就大**。如果 X 对同一个人多年都不变，FE 根本估不出它的效应（X-it - X̄i = 0）。
3. **标准误要聚类到个体层面**。面板数据同一人的不同年观测相关，不聚类标准误会太小。用 `vce(cluster id)`。
4. **FE 解决不了反向因果**。如果 Y 反过来影响 X（比如工资高了才去读书），FE 也救不了。
5. **样本期太短，FE 不准**。T=2 时 FE 和差分法一样，自由度损失大。

---

## 八、Stata 代码

```stata
-- 固定效应完整流程
use "panel.dta", clear
xtset id year

-- 最简 FE
xtreg y x1 x2, fe

-- 双向 FE（加年份固定效应）
xtreg y x1 x2 i.year, fe

-- 聚类标准误（论文标配）
xtreg y x1 x2 i.year, fe vce(cluster id)

-- 看个体效应是否显著（F 检验）
xtreg y x1 x2 i.year, fe
estimates store fe
-- Stata 输出最后一行 F test that all u_i=0: p<0.05 说明 FE 优于混合OLS

-- LSDV 写法（等价，但 N 大时慢）
reg y x1 x2 i.id i.year
```

## 九、和别的方法对比

| 方法 | 控制时间不变遗漏变量 | 估时间不变变量 | 效率 |
|------|---------------------|---------------|------|
| 混合 OLS | 不控制 | 能 | 高（有偏） |
| **FE** | **控制** | **不能** | 中 |
| RE | 假设无关 | 能 | 高（假设强） |
| IV | 解决所有内生性 | 能 | 低（找 IV 难） |

**什么时候 FE 比 IV 好？** 当你的遗漏变量主要是"时间不变"的，FE 不需要找 IV 就能解决。当遗漏变量随时间变，FE 救不了，才需要 IV。

---

## 十、为什么不用别的方法？

- **为什么不用混合 OLS？** 混合 OLS 把 N×T 个观测当成截面，假装不同个体截距一样。B 天生工资高 3 千、工龄也长，混合 OLS 会把这 3 千算进工龄系数里（估出 β=2.27，真实是 2），系统性偏高。
- **为什么不用 RE？** RE 假设个体效应 u_i 和 X 无关（Cov(u_i,X)=0），经济数据里这个假设几乎不成立（能力和教育相关、文化和制度相关）。Hausman 检验 p<0.05 就拒绝 RE，必须用 FE。FE 不做这个假设，允许 u_i 和 X 相关，直接减掉。
- **为什么不用 IV？** IV 要找一个好 Z，而且排他性靠论证、靠不住，容易被审稿人追着打。FE 只要有面板数据、且遗漏变量不随时间变，就能干净识别 β，不需要找 IV。只有当内生性来自随时间变的因素或反向因果时，FE 才救不了、才需要 IV。

## 十一、答辩常问（直接背）

1. **问：固定效应的本质是什么？** 答：对每个个体减去自己的时间均值（within 估计）：Y_it − Ȳ_i = β₁(X_it − X̄_i) + 残差。α_i 对同一个体所有期都一样，减均值时被减掉，β₁ 只用"一个人自己不同时间的变异"识别，彻底排除了天生差异。
2. **问：FE 为什么估不出"性别"这种变量的系数？** 答：性别不随时间变，X_it − X̄_i = 0（对同一个人每年性别都一样），within 变异为 0，信息全被 α_i 吸收了。想估性别效应，只能用 RE 或者换截面方法。
3. **问：FE 能解决所有内生性吗？** 答：不能。FE 只解决"不随时间变"的遗漏变量（能力、文化、出生地）；随时间变的遗漏变量要加时间固定效应 λ_t；反向因果（Y 反过来影响 X）FE 救不了，必须上 IV 或 DID。
4. **问：FE 的标准误为什么要聚类到个体层面（cluster id）？** 答：同一个人不同年份的观测不是独立的（他今年和明年的工资相关），不聚类会低估标准误、高估 t 值。`vce(cluster id)` 修正组内[[03_自相关|自相关]]和[[02_异方差|异方差]]，是面板论文的标配。

---

## 十二、速记卡

> **FE = 每个人减去自己的均值，"和自己比"。**
> - 控制所有不随时间变的个体特征（能力、性别、出生地）。
> - within 估计量：$\sum(X_{it}-\bar{X}_i)(Y_{it}-\bar{Y}_i) / \sum(X_{it}-\bar{X}_i)^2$。
> - 代价：时间不变变量估不出来。
> - 论文标配：双向 FE（个体+年份）+ 聚类标准误。
> - 记住：**FE 解决"天生差异"，不解决"随时间变的冲击"（那靠时间 FE）和"反向因果"（那靠 IV/DID）。**

## 💡 经济学视角：固定效应，就是把"说不清的东西"锁进柜子里

**这个方法是为了解决什么经济学问题？**
研究"市场化程度对经济增长的影响"时，你会发现：浙江、广东天生商业文化浓，东北、西北计划经济惯性大。这些"地区性格"不会一年一变，但它们实实在在影响着增长。你又没办法用一个变量把它们量化——怎么办？**固定效应的思路是：既然说不清、测不准，干脆把每个省"自己和自己比"，地区天生差异 α_i 自动被减掉**。

**经济学里哪些经典模型正好对应这个方法？**
社会主义市场经济体制下，政府和市场的关系在不同省份差别巨大：有的地方"有为政府"，有的地方"有效市场"，这种制度禀赋几十年不变。FE 不去解释它，而是默认它存在、把它吸收掉，专注估计"随着时间变化的政策变量"的边际效应。这其实是政经方法论里"具体问题具体分析"在计量上的翻译。

**举个实证论文的例子：**
《营商环境优化对企业全要素生产率的影响》用 280 个地级市 × 5 年面板。不控制 FE 时，营商环境系数 0.12，t=2.1；加了城市 FE 后系数变成 0.08，t=1.7——原来显著的部分，其实是"营商环境本来就好的城市，企业 TFP 本来就高"。FE 一上，结论稳健多了，这也是为什么现在论文几乎都标配双向 FE。
