# 04 两阶段最小二乘 2SLS：IV 怎么算出来？

## 一、为什么要学这个？

上一节我们给了 IV 的公式：$\hat{\beta}_{IV} = \mathrm{Cov}(Z,Y)/\mathrm{Cov}(Z,X)$。

但这只是一元情形。现实里你有很多控制变量、多个[[03_工具变量IV|工具变量]]、甚至多个内生变量——公式就不够用了。

**2SLS（两阶段最小二乘）就是 IV 的通用计算方法**。它把 IV 拆成两次 [[04_OLS截距和拟合值|OLS]]，你在 Stata 里敲一行 `ivregress 2sls` 就完事，但你得知道背后发生了什么。

答辩时老师问"你这 2SLS 第一阶段和第二阶段分别是什么"，你得答得上来。

---

## 二、是什么？（比喻 + 定义）

### 比喻：二手鞋

你想买一双鞋（因果效应），但市场上的鞋（X）被商家做过手脚——尺码不准（X 和 ε 相关）。

2SLS 分两步：

1. **第一阶段**：找一个"标准尺码表"（工具变量 Z），用它把每双鞋的"真实尺码"标出来（$\hat{X}$）。这一步把 X 里的水分挤掉。
2. **第二阶段**：用标好真实尺码的鞋（$\hat{X}$），去和你的脚（Y）比大小——这就是干净的因果关系。

### 严格定义

**第一阶段**：把内生变量 X 对所有外生变量（工具变量 Z + 外生控制变量）回归：

$$X = \pi_0 + \pi_1 Z + \pi_2 W + v$$

得到预测值 $\hat{X}$。

**第二阶段**：把 Y 对 $\hat{X}$（而不是原始 X）和外生控制变量回归：

$$Y = \beta_0 + \beta_1 \hat{X} + \beta_2 W + \text{error}$$

$\hat{\beta}_1$ 就是 2SLS 估计量。

**为什么要分两阶段？** 因为 $\hat{X}$ 是 X 中"被 Z 解释的部分"——这部分和 ε 无关，用它回归 Y 就避开了内生性。

---

## 三、公式怎么来的？（为什么 2SLS 是 OLS 的推广）

### 第一步：从矩阵看

OLS 的解是：
$$\hat{\beta}_{OLS} = (X'X)^{-1} X'Y$$

2SLS 的解是：
$$\hat{\beta}_{2SLS} = (X'P_Z X)^{-1} X'P_Z Y$$

其中 $P_Z = Z(Z'Z)^{-1}Z'$ 是"投影矩阵"——把 X 投影到 Z 张成的空间上。

### 第二步：特殊情况——Z = X

如果工具变量就是 X 本身（没有内生性时），那 $P_Z = P_X$，代入：

$$\hat{\beta}_{2SLS} = (X'P_X X)^{-1} X'P_X Y = (X'X)^{-1} X'Y = \hat{\beta}_{OLS}$$

**这就是为什么说"OLS 是 2SLS 在没有内生性时的特例"**。方法系谱图里那条箭头，说的就是这个。

### 第三步：手算为什么不能直接做两次 OLS？

注意：第二阶段的标准误不能直接用 OLS 的。因为 $\hat{X}$ 是估计出来的，带了误差。Stata 的 `ivregress 2sls` 会自动算对标准误——**你不要真的手动跑两次 reg**，那会得到错的标准误。

## 四、符号表

| 符号 | 含义 |
|------|------|
| $X$ | 内生解释变量 |
| $Z$ | 工具变量（外生） |
| $W$ | 外生控制变量 |
| $\hat{X}$ | 第一阶段预测值 |
| $\pi$ | 第一阶段系数 |
| $\beta_1$ | 我们要估的因果效应 |
| $P_Z$ | 投影矩阵（本科不用手算） |

## 五、一个完整的数字例子（手算迷你版）

**数据**：5 个观测。X 是内生变量，Z 是工具变量，Y 是结果。

| 观测 | Z | X | Y |
|------|---|---|---|
| 1 | 1 | 2.1 | 5.2 |
| 2 | 2 | 3.9 | 9.1 |
| 3 | 3 | 6.2 | 15.3 |
| 4 | 4 | 8.1 | 19.8 |
| 5 | 5 | 9.8 | 24.7 |

**第一阶段：X 对 Z 回归。**

$\bar{Z}=3$，$\bar{X}=6.02$。

| obs | Z-Z̄ | X-X̄ | 乘积 | (Z-Z̄)² |
|-----|-----|-----|------|--------|
| 1 | -2 | -3.92 | 7.84 | 4 |
| 2 | -1 | -2.12 | 2.12 | 1 |
| 3 | 0 | 0.18 | 0 | 0 |
| 4 | 1 | 2.08 | 2.08 | 1 |
| 5 | 2 | 3.78 | 7.56 | 4 |
| 合计 | 0 | 0 | 19.6 | 10 |

$$\hat{\pi}_1 = \frac{19.6}{10} = 1.96$$
$$\hat{\pi}_0 = 6.02 - 1.96 \times 3 = 0.14$$

第一阶段：$\hat{X} = 0.14 + 1.96 Z$。

算出每个 $\hat{X}$：

| obs | Z | $\hat{X}$ |
|-----|---|-----------|
| 1 | 1 | 2.10 |
| 2 | 2 | 4.06 |
| 3 | 3 | 6.02 |
| 4 | 4 | 7.98 |
| 5 | 5 | 9.94 |

**第二阶段：Y 对 $\hat{X}$ 回归。**

$\bar{Y} = 14.82$，$\bar{\hat{X}} = 6.02$。

| obs | $\hat{X}-\bar{\hat{X}}$ | $Y-\bar{Y}$ | 乘积 | $(\hat{X}-\bar{\hat{X}})^2$ |
|-----|-----|-----|------|--------|
| 1 | -3.92 | -9.62 | 37.71 | 15.37 |
| 2 | -1.96 | -5.72 | 11.21 | 3.84 |
| 3 | 0 | 0.48 | 0 | 0 |
| 4 | 1.96 | 4.98 | 9.76 | 3.84 |
| 5 | 3.92 | 9.88 | 38.73 | 15.37 |
| 合计 | 0 | 0 | 97.41 | 38.43 |

$$\hat{\beta}_{1,2SLS} = \frac{97.41}{38.43} = 2.536$$
$$\hat{\beta}_{0,2SLS} = 14.82 - 2.536 \times 6.02 = -0.45$$

第二阶段：$\hat{Y} = -0.45 + 2.54 \hat{X}$。

**对比 OLS**：直接用 X 回归 Y，得到 $\hat{\beta}_{OLS}=2.535$。

在这个迷你例子里 2SLS ≈ OLS——因为我没在数据里加入内生性。这恰恰说明：**当 X 没有内生性时，2SLS 退化为 OLS**（正如[[03_第三节_定量指标的无量纲化|第三节]]所说）。

**Python 验证**：

```python
import numpy as np
Z = np.array([1,2,3,4,5.])
X = np.array([2.1,3.9,6.2,8.1,9.8])
Y = np.array([5.2,9.1,15.3,19.8,24.7])
# 第一阶段
pi1 = np.sum((Z-Z.mean())*(X-X.mean()))/np.sum((Z-Z.mean())**2)
pi0 = X.mean() - pi1*Z.mean()
X_hat = pi0 + pi1*Z
# 第二阶段
b1 = np.sum((X_hat-X_hat.mean())*(Y-Y.mean()))/np.sum((X_hat-X_hat.mean())**2)
b0 = Y.mean() - b1*X_hat.mean()
print(f"2SLS: Y = {b0:.3f} + {b1:.3f}*X_hat")  # -0.445 + 2.536
```

## 六、什么时候用？

- 有内生性 + 至少一个工具变量；
- 工具变量通过了弱 IV 检验（第一阶段 F>10）；
- 样本量足够（IV 比 OLS 效率低，需要更大样本）。

---

## 七、易错点

1. **不要真的分两次跑 reg**。第二阶段标准误是错的。必须用 `ivregress 2sls` 一条命令。
2. **第一阶段 R² 低不代表[[KP03_弱工具变量|弱工具变量]]**。要看 F 统计量，不是 R²。
3. **过度识别检验（Sargan/Hansen J）**：当工具变量个数 > 内生变量个数时，p>0.1 才能接受"所有 IV 都外生"。
4. **恰好识别时无法检验外生性**。你只能靠经济理论说服审稿人。
5. **2SLS 估的是 LATE**，不是 ATE——只对"被工具变量影响的那群人"有效。

### 过度识别检验怎么读？（[[../../教材笔记/02_计量经济学/09_工具变量法/知识点/KP04_过度识别与Hausman|KP04 过度识别与 Hausman]]）

**什么时候才能做？** 只有工具变量个数 L **严格多于**内生变量个数 K（过度识别）时。恰好识别（L=K）时没有多余的工具可用来"互相检验"，自由度为零。

**核心思想**：如果所有 IV 都外生，那 2SLS 的残差应该和所有 IV 都不相关。把残差对所有外生变量回归，构造 $nR^2 \sim \chi^2(L-K)$。

| 检验 | 适用条件 | Stata 命令 |
|------|----------|-----------|
| Sargan | 同方差假设 | `estat overid` |
| Hansen J | **异方差稳健**（更通用） | `estat overid, robust` |

**判断规则**：原假设 $H_0$ = 所有 IV 都外生。
- p > 0.05：不拒绝，IV 外生性合理 ✅；
- p < 0.05：至少有一个 IV 不干净 ✗，需要逐一排查换 IV。

### Hausman / DWH 内生性检验：到底该用 OLS 还是 IV？

**逻辑**：比较 OLS 和 2SLS 的系数。
- 如果解释变量外生 → OLS 一致且有效、IV 也一致但更不精确，两者系数应该**差不多**；
- 如果解释变量内生 → OLS 不一致、IV 一致，两者系数会**差很多**。

**决策规则**（[[../../教材笔记/02_计量经济学/09_工具变量法/知识点/KP04_过度识别与Hausman|KP04]]）：
- 原假设 $H_0$：解释变量外生（OLS 一致）；
- p > 0.05：不拒绝，**用 OLS**（更有效，别多此一举上 IV）；
- p < 0.05：拒绝，**必须用 IV**（OLS 有偏）。

**异方差稳健做法（DWH）**：把第一阶段残差 $\hat v$ 放进原回归，看 $\hat v$ 的 t 检验——显著就说明原变量内生。Stata 里 `estat endog` 自动做这件事。

> **陷阱**：OLS 和 IV 系数差很多，不一定全是内生性——也可能是 IV 估的是 LATE、OLS 反映的是 ATE，两组人群本就不同。严谨表述：差异 + 强工具 + 理论论证，三者齐备才能说"OLS 有内生性偏误"。

## 八、Stata 代码

```stata
-- 2SLS 完整流程
use "mydata.dta", clear

-- 一元 IV：一个内生变量 edu，一个工具变量 birth_quarter
ivregress 2sls wage exper tenure (edu = birth_quarter)

-- 多个工具变量（过度识别，可做 Hansen J 检验）
ivregress 2sls wage exper tenure (edu = birth_quarter sibling_size)
estat overid             -- Hansen J 检验，p>0.1 接受外生

-- 多个内生变量
ivregress 2sls wage exper (edu ability = birth_quarter parent_edu)

-- 看第一阶段
estat firststage         -- 第一阶段 F 统计量
```

## 九、和别的方法对比

| 方法 | 内生性 | 效率 | 对工具变量要求 |
|------|--------|------|---------------|
| OLS | 有偏 | 最高 | 不需要 |
| **2SLS/IV** | **一致** | **较低** | **需要好 IV** |
| LIML | 一致 | 小样本更稳 | 同 2SLS |
| GMM | 一致 | [[02_异方差|异方差]]下更优 | 多个 IV 时 |

**本科论文用 2SLS 就够了**。LIML/GMM 是进阶内容。

---

## 十、为什么不用别的方法？

- **为什么不能真的分两次跑 reg（先 reg X~Z，再 reg Y~X̂）？** X̂ 是估计出来的、带误差，第二阶段直接 reg Y~X̂ 算出的标准误是错的（系统性偏小），会让你误判显著性。必须用 `ivregress 2sls` 一条命令，Stata 会自动用正确公式修正标准误。
- **为什么不直接用 OLS？** 当 X 内生时 OLS 有偏且不收敛；2SLS 虽然效率低（标准误更大），但系数一致。只有当 DWH 内生性检验 p>0.05（说明 X 其实不内生）时，OLS 才是更优选择——这时上 IV 反而白白损失效率。
- **为什么不用 LIML / GMM？** 本科论文不需要。2SLS 在大样本下和它们渐近等价；LIML 只是小样本或弱 IV 下更稳，GMM 只在异方差严重、工具变量很多时才占优。审稿人看本科论文，2SLS + 第一阶段 F>10 + 过度检验 p>0.1 就够了。

## 十一、答辩常问（直接背）

1. **问：2SLS 的两个阶段分别在做什么？** 答：第一阶段把内生变量 X 对所有外生变量（工具 Z + 外生控制 W）回归，得到预测值 X̂——这是 X 中"能被 Z 解释、与 ε 无关的干净部分"；第二阶段用 X̂ 替换原始 X 回归 Y，得到因果效应 β̂₁。
2. **问：为什么说"OLS 是 2SLS 的特例"？** 答：当工具变量就是 X 本身（即没有内生性）时，投影矩阵 P_Z = P_X，2SLS 公式 (X'P_ZX)⁻¹X'P_Z Y 退化为 OLS 公式 (X'X)⁻¹X'Y。所以 IV 方法族是 OLS 的推广，没有内生性时自然变回 OLS。
3. **问：2SLS 结果出来后必须报告哪三个检验？** 答：① 第一阶段 F>10（弱 IV 检验）；② DWH 内生性检验 p<0.05（证明你确实需要 IV，而不是多此一举）；③ 过度识别 Hansen J 检验 p>0.1（IV 个数 > 内生变量时，证明所有 IV 都外生）。
4. **问：第一阶段 R² 很低，是不是说明工具变量不行？** 答：不是。弱工具看 F 统计量，不看 R²。第一阶段 R² 低很正常（X 本来就受很多因素影响），只要 F>10、第一阶段系数显著，Z 就够用。

---

## 十二、速记卡

> **2SLS = 两次 OLS，但标准误由 Stata 自动算对。**
> - 第一阶段：X 对 Z 回归，得到 $\hat{X}$（X 中干净的部分）。
> - 第二阶段：Y 对 $\hat{X}$ 回归，得到因果效应。
> - 当 Z=X 时，2SLS 退化为 OLS——所以说 IV 是 OLS 的推广。
> - 不要手动跑两次 reg，用 `ivregress 2sls`。
> - 第一阶段 F>10 是底线。

## 💡 经济学视角：2SLS 就是把"准实验"搬进回归方程

**这个方法是为了解决什么经济学问题？**
央行说"加息能压通胀"，财政说"补贴能促消费"——但你直接跑"利率→通胀"回归，一定会被反向因果污染：央行就是看着通胀高才加息的。怎么办？找一个"外生冲击"当工具变量：比如央行换届、外部金融危机、兄弟省份的政策溢出。2SLS 就是把这种"准实验"洗成回归系数的标准流水线。

**经济学里哪些经典模型正好对应这个方法？**
- **财政政策**：拿"国债发行节奏"或"中央转移支付外生变化"当工具，估财政乘数；
- **货币政策**：拿"联邦基金利率意外成分"（Romer & Romer 叙事法）当工具，估货币政策冲击对产出的影响；
- 自动稳定器（累进税、失业保险）本身就是内置工具，不需要额外找 Z。

**举个实证论文的例子：**
《中国地方政府债务对经济增长的影响》直接 OLS 显示"债务越高增长越快"——因为增长快的地方本来就敢借债。作者用"中央代发地方债试点"这个准实验当工具变量，2SLS 结果翻转成"债务率超过阈值后增长被拖慢"。这一翻，直接改写了"地方债该不该扩"的政策讨论。
