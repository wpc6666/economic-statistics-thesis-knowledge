# 05 结果怎么读怎么写？（回归表逐格解读 + esttab 导出三线表）

## 一、为什么要学这个？

Stata 跑完回归，吐出来一大屏，密密麻麻的数字。

很多同学的做法是：
- 直接把 Stata 截图贴进 Word——被导师骂"你这是作业不是论文"；
- 把所有数字都抄进表里——被骂"谁要看你 R² 是多少"；
- 写"结果显著为正"——被骂"正多少？1 还是 100？"

**论文里的回归表，是给人看的，不是给 Stata 看的。**

这一节教你三件事：Stata 输出里每个数字是什么意思、一张正规的三线表怎么用 esttab 一键导出到 Word、怎么用一句话把结果说清楚。

## 二、Stata 输出每个数字什么意思

先看一张典型的 Stata 回归输出：

```
------------------------------------------------------------------------------
       theil |      Coef.   Std. Err.      t    P>|t|     [95% Conf. Interval]
-------------+----------------------------------------------------------------
     ln_dig |  -.2473654   .0681234    -3.63   0.000    -.3814567   -.1132741
    ln_pgdp |   .1234567   .0534567     2.31   0.021     .0182345    .2286789
        gov |   .0567891   .0504567     1.12   0.261    -.0423456    .1559238
      _cons |   .8765432   .2345678     3.74   0.000     .4152345    1.3378519
------------------------------------------------------------------------------
```

逐列解释：

### Coef.（系数）

**自变量每增加 1 个单位，因变量平均变化多少个单位。**

- 系数为正：自变量增加，因变量也增加；
- 系数为负：自变量增加，因变量减少；
- 如果自变量和因变量都取了对数（如 ln_gdp 和 ln_pop），系数就是弹性——"人口每增加 1%，GDP 平均增加 0.345%"。

### Std. Err.（标准误）

**系数估计值的波动大小。** 标准误越小，系数估得越准、越稳定。同样的系数，标准误越小，t 值越大，越容易显著。

### t 值

**t = Coef. / Std. Err.，衡量"这个系数是不是真的不等于 0"。**

经验法则：
- |t| > 2.58：粗略认为在 1% 水平上显著；
- |t| > 1.96：粗略认为在 5% 水平上显著；
- |t| < 1.96：大概率不显著。

### P>|t|（p 值，最关键的一列）

**这个系数"实际上等于 0"的概率有多大。**

| p 值范围 | 显著性 | 星号 |
|---|---|---|
| p < 0.01 | 在 1% 水平上显著 | *** |
| 0.01 ≤ p < 0.05 | 在 5% 水平上显著 | ** |
| 0.05 ≤ p < 0.10 | 在 10% 水平上显著 | * |
| p ≥ 0.10 | 不显著 | 无星号 |

**不显著不代表没用，只代表"用这份数据、这个模型，证明显著性不够"。** 不要硬说显著，也不要把不显著的变量藏起来。

### R²（[[06_拟合优度R²|拟合优度]]）

**这个模型解释了因变量多少比例的变异。**

- 社会科学（经济学、社会学）的 R² 不要追求太高，0.3 到 0.8 都算正常；
- R² = 0.9 以上反而要警惕：是不是模型里放了和因变量几乎一回事的变量？
- [[KP01_固定效应模型|固定效应模型]]要报告"组内 R²"（within R²），不是普通 R²。

### F 值和模型整体显著性

- F 检验的是"所有自变量的系数同时等于 0 吗"；
- Prob > F = 0.0000：拒绝"所有系数都为 0"，说明整个模型整体是显著的，不是白跑。

## 三、一张正规回归表长什么样？

### 反面教材（把 Stata 输出直接贴进来）

```
. reg y x control1 control2

      Source |       SS           df       MS      Number of obs   =       341
-------------+----------------------------------   F(3, 337)       =     45.23
       Model |  1234.56789         3  411.522631   Prob > F        =    0.0000
    Residual |  3056.78901       337  9.07059053   R-squared       =    0.2879

           y |      Coef.   Std. Err.      t    P>|t|     [95% Conf. Interval]
```

## 四、逐格解读一张完整回归表

以"数字经济对城乡收入差距"为例，把一张 3 列的表一格一格念给你听。

**表 5-2 数字经济对城乡收入差距的基准回归结果**

| 变量 | (1) theil | (2) theil | (3) theil |
|---|---|---|---|
| ln_dig | -0.312\*\*\* | -0.247\*\*\* | -0.189\*\*\* |
| | (-4.22) | (-3.63) | (-3.20) |
| ln_pgdp | | 0.123\*\* | 0.089\* |
| | | (2.31) | (1.85) |
| urban | | -0.092\*\* | -0.067\*\* |
| | | (-2.45) | (-2.03) |
| 常数项 | 1.234\*\*\* | 0.876\*\*\* | 1.567\*\* |
| | (5.67) | (3.74) | (2.45) |
| 省份固定效应 | 否 | 否 | 是 |
| 年份固定效应 | 否 | 否 | 是 |
| N | 360 | 360 | 360 |
| 组内 R² | 0.215 | 0.486 | 0.612 |

注：括号内为 t 值（列(3)为省份层面聚类稳健 t 值）；\*\*\*、\*\*、\* 分别表示在 1%、5%、10% 水平上显著。

### 核心解释变量那一行（ln_dig）

- 列(1)系数 -0.312：只放 ln_dig 时，ln_dig 每增加 1，theil 减少 0.312。负号 = 数字经济越发达，城乡差距越小，方向对。
- 列(2)系数 -0.247：加入控制变量后，系数从 -0.312 缩到 -0.247，说明原来被控制变量"贡献"了一部分，方向没变。
- 列(3)系数 -0.189：控制省份、年份固定效应后，系数进一步缩到 -0.189，依然为负，依然显著（1% 水平）。

**一句话总结**："核心解释变量 ln_dig 的系数在三列中始终为负、始终在 1% 水平上显著，系数大小从 -0.312 逐步收敛到 -0.189，说明数字经济发展显著缩小了城乡收入差距，且这一结论在加入控制变量和固定效应后依然成立。"

### 控制变量行

控制变量不用每个都详细解释，但核心的几个要提一句。edu 不显著就别编故事。常数项的经济意义通常不重要，不要在正文里解释。

### N 和 R²

- N = 360：30 个省 × 12 年 = 360 个观测值。如果某列 N 突然变小（360 → 320），说明那一列有变量缺失值被自动删掉了，要去查。
- 列(3)报告"组内 R²"（within R²）= 0.612：固定效应模型不报告普通 R²，报告组内 R²，意思是"控制了省份之间的固有差异后，模型解释了省份内部年度变异的 61.2%"。

## 五、一句话报告结果的模板（背下来）

> 💡 写统计结果不是"把数字抄一遍"，而是**用数据当证据论证一个观点**。忘了报告该怎么组织结构？翻到 [[../../教材笔记/05_统计学原理/11_统计分析/知识点/KP08_统计分析报告的特点与结构|KP08 统计分析报告的特点与结构]] 复习"基本情况→成绩/问题→原因分析→对策建议"四段式；写完初稿再对照 [[../../教材笔记/05_统计学原理/11_统计分析/知识点/KP09_统计分析报告常见毛病|KP09 常见毛病]] 自查有没有犯流水账、数字堆砌的毛病。

核心变量跑出来无非三种情况：显著为正、显著为负、不显著。下面三套模板直接套。

### 模板 A：核心变量显著为正

> 核心解释变量 X 的系数为 0.XXX，在 1%（或 5%）水平上显著为正（t = X.XX）。这表明，在控制其他因素不变的情况下，X 每提高 1 个单位（或 1%），Y 平均提高 0.XXX 个单位（或 %），假设 H0（X 对 Y 无影响）被拒绝。这一结果与理论预期一致，可能的解释是……（一句话机制）。

### 模板 B：核心变量显著为负

> 核心解释变量 X 的系数为 -0.XXX，在 1%（或 5%）水平上显著为负（t = -X.XX）。这表明，在控制其他因素不变的情况下，X 每提高 1 个单位（或 1%），Y 平均下降 0.XXX 个单位（或 %）。这一结果表明 X 对 Y 具有显著的抑制作用，可能的机制是……（一句话）。

### 模板 C：核心变量不显著（p > 0.10）

> 核心解释变量 X 的系数为 0.XXX，但未通过 10% 水平的显著性检验（t = X.XX，p = 0.XXX）。这表明在本样本区间、本模型设定下，X 对 Y 的直接影响尚未得到统计上的支持。可能的原因包括：（1）样本量有限，统计功效不足；（2）X 的作用存在滞后效应；（3）X 的边际作用在本样本区间已趋于饱和。后续研究可通过扩大样本区间、采用滞后变量或更精细的度量方式进一步检验。

**模板 C 的使用铁律**：绝对不要把不显著写成"有正向影响但不明显"；绝对不要把不显著的变量从表里删掉（那是 p-hacking）。可以做的：诚实报告 + 分析可能原因 + 指出未来方向。

### 取对数后的情况

如果 X 或 Y 取了对数，要翻译成弹性：

> 数字经济指数（lnX）的系数为 0.215\*\*，在 5% 水平显著为正，表明数字经济发展水平每提高 1%，产业结构高级化指数提高约 0.215%。

## 六、系数不显著怎么办？

这是本科论文最常见的痛点。核心变量跑出来 p = 0.2，不显著，怎么办？

### 6.1 先冷静判断：是真不显著，还是方法不对

按下面顺序排查：

1. **检查数据有没有问题**：变量是不是取反了？单位统一吗？有没有缺失值被自动删了导致样本量骤降？
2. **换个变量度量方式**：GDP 总量不显著？换人均 GDP？名义 GDP 不显著？换实际 GDP？水平值不显著？取对数试试？
3. **加控制变量或换控制变量组合**：少了关键控制变量，核心变量的系数可能被污染。但也不要乱塞变量。
4. **换样本**：极端值带偏了？缩尾后再跑？某个异常年份影响太大？去掉那一年？
5. **换估计方法**：[[04_OLS截距和拟合值|OLS]] 不显著？试试固定效应？静态模型不显著？试试滞后一期？

### 6.2 实在不显著怎么办

**接受它，如实报告。** 本科论文不要求结果必须显著。很多好论文的贡献就是"发现原来大家以为显著的东西其实不显著"。

**绝对不要做的事**：
- 把不显著的变量从表里删掉，只放显著的；
- 把 p = 0.18 硬说成"边缘显著"；
- 反复换模型、换变量、换样本，直到跑出显著为止（这叫 p-hacking，学术不端）。

## 七、用 esttab 一键导出三线表到 Word

跑完回归只是第一步，怎么把结果变成论文里能用的三线表，才是新手最容易卡住的地方。**不要手敲结果表——手敲必错，错了老师一眼就看出来。用 Stata 命令一键导出。**

### 7.1 安装

第一次用，先在 Stata 命令窗口跑：

```stata
* 安装 estout 包（包含 esttab、estout、eststo、estpost）
ssc install estout, replace
```

### 7.2 第一步：存回归结果（eststo）

每次跑完一个回归，用 `eststo` 把结果存起来，取个短名字：

```stata
* === 清空之前存的模型（防止新旧混在一起） ===
eststo clear

* === 模型1：只放核心解释变量 ===
xtreg theil ln_dig, fe
eststo m1

* === 模型2：加人均GDP ===
xtreg theil ln_dig ln_pgdp, fe
eststo m2

* === 模型3：加全部控制变量 ===
xtreg theil ln_dig ln_pgdp gov ind urban edu, fe
eststo m3

* === 模型4：加年份固定效应 ===
xtreg theil ln_dig ln_pgdp gov ind urban edu i.year, fe
eststo m4
```

### 7.3 第二步：导出 rtf 文件（Word 能直接打开）

```stata
* === 导出到Word能打开的rtf格式 ===
esttab m1 m2 m3 m4 using "结果表.rtf", replace ///
    b(%9.3f) ///                    // 系数保留3位小数
    se(%9.3f) ///                   // 标准误也保留3位，放在系数括号里
    star(* 0.1 ** 0.05 *** 0.01) /// // 显著性星号对应水平
    mtitles("(1) OLS" "(2) FE" "(3) FE+控制" "(4) 双向FE") /// // 每一列的标题
    keep(ln_dig ln_pgdp gov ind urban edu) /// // 只显示这些变量
    stats(N r2, labels("观测值" "R²")) /// // 表底部显示的统计量
    title("表5-1  基准回归结果") /// // 表题
    addnote("注：括号内为省级聚类稳健标准误；***、**、*分别表示在1%、5%、10%水平上显著。" "数据来源：作者根据《中国统计年鉴》整理。") ///
    compress                       // 压缩列间距
```

### 7.4 调成三线表

esttab 导出的 rtf 默认有完整边框，不是三线表。两种方法调成三线表：

**方法 A：用 `booktabs` 选项（一步到位）**

在 esttab 命令里加 `booktabs` 选项，导出时自动只画顶线、表头线、底线三条横线，没有竖线。

**方法 B：Word 打开后手动调（万能方法）**

1. 双击 `结果表.rtf` 用 Word 打开；
2. 全选表格 → 菜单栏"表格设计" → "边框" → 先选"无框线"；
3. 选中最上面一行（表头行）→ 边框 → "下框线"，粗细设为 0.75 磅；
4. 选中整个表格 → 边框 → "上框线"和"下框线"，粗细设为 1.5 磅；
5. 完成：只剩三条线，没有竖线。

三线表的详细规范见 `../12_毕业论文实战/[[02_三线表怎么做]].md`。

### 7.5 其他常用导出场景

```stata
* === 导出描述性统计表 ===
estpost summarize theil ln_dig ln_pgdp ind urban edu
esttab using "描述统计.rtf", replace ///
    cells("count(fmt(0)) mean(fmt(3)) sd(fmt(3)) min(fmt(3)) max(fmt(3))") ///
    noobs nonumber title("表5-1  描述性统计") ///
    addnote("数据来源：作者根据《中国统计年鉴》整理。")

* === 导出相关系数矩阵 ===
estpost correlate theil ln_dig ln_pgdp ind urban, matrix listwise
esttab using "相关系数.rtf", replace ///
    unstack not noobs nonote nonumber ///
    title("表5-2  相关系数矩阵")

* === 导出异质性分组表（东中西部分别回归） ===
eststo clear
xtreg theil ln_dig controls if region==1, fe
eststo east
xtreg theil ln_dig controls if region==2, fe
eststo middle
xtreg theil ln_dig controls if region==3, fe
eststo west
esttab east middle west using "异质性.rtf", replace ///
    b(%9.3f) se(%9.3f) star(* 0.1 ** 0.05 *** 0.01) ///
    mtitles("东部" "中部" "西部") keep(ln_dig) ///
    stats(N r2, labels("观测值" "R²")) ///
    title("表5-5  异质性分析：分地区回归")
```

### 7.6 常见问题

| 问题 | 解决 |
|------|------|
| rtf 用 Word 打开后中文乱码 | 不要直接双击，打开 Word → "文件" → "打开" → 选中 rtf；或改用 csv 导出，用 Excel 打开再复制到 Word |
| 表格太宽，Word 一页放不下 | 加 `compress` 选项；减少列数（拆成两张表）；减少变量（`keep(ln_dig)` 只放核心变量）；Word 里单独这一页横向 |
| 想加"是/否"表示固定效应控制了没有 | 手动在 Word 里加几行："省份固定效应 否 是 是 是"，这是论文标准做法 |

## 八、哪些数字该报，哪些不该报？

| 该报 | 不该报 |
|------|--------|
| 核心解释变量 X 的系数、标准误、星号 | SS（平方和）、MS（均方） |
| 控制变量的系数（挑重要的报） | Root MSE（均方根误差） |
| N（观测值数） | 每个变量的 t 值（表里报标准误就行） |
| R² 或 Within R² | 95% 置信区间（表里不用报） |
| 固定效应是否控制 | F 值（可以不报） |
| 常数项 | 颜色底纹（论文表格黑白印刷） |

## 九、常见错误写法对照

| 错误写法 | 为什么错 | 正确写法 |
|---|---|---|
| "ln_dig 的系数为 -0.189，非常显著。" | "非常显著"不是学术用语 | "ln_dig 的系数为 -0.189，在 1% 水平上显著（t = -3.20）。" |
| "数字经济显著促进了城乡差距缩小。" | 系数是负的，"促进缩小"搭配别扭 | "数字经济发展显著缩小了城乡收入差距。" |
| "R² = 0.612，模型拟合极好。" | 0.612 算不错，但"极好"夸张 | "组内 R² 为 0.612，模型具有较好的解释力。" |
| "控制变量都不显著，说明它们没用。" | 不显著 ≠ 没用 | "控制变量中，gov 和 edu 未通过显著性检验，其作用有待进一步研究。" |
| "p = 0.000，说明系数真的是 -0.189。" | p = 0.000 是"几乎不可能为 0" | "p < 0.001，强烈拒绝原假设，系数估计可靠。" |

## 十、答辩时老师常追问的 5 个问题（提前背好）

## 十一、速记卡

> **回归表三要素**：系数（3 位小数）+ 括号里标准误 + 右上角星号。
> **Stata 输出**：先看 N、F、R²，再看核心变量的系数、t、p。
> **一句话模板**：X 的系数为 X\*\*，在 X% 水平显著为正/负，表明 X 每提高 1 单位，Y 平均提高/降低 X 单位。
> **导出三线表**：eststo 存模型 → esttab 导出 rtf → Word 手动调三线表。
> **该报**：核心变量系数、N、R²、固定效应。**不该报**：t 值、p 值、F 值、SS、MS、Root MSE。
> **不显著**：先排查数据和方法，实在不显著就如实写，不要 p-hacking。
> **本质**：论文表是给人看的，不是给 Stata 看的。
