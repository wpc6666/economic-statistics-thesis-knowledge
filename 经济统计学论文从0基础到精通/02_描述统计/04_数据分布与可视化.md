# 04 数据分布与可视化：画出来看！

## 一、为什么要学这个？

一张图胜过一千行数字。

你跟导师说"我的工资数据均值 6500，标准差 2300"，导师脑子里没画面。
你给他画一张直方图——他一眼就看到：哦，右偏，有几个高管工资特别高，其他人集中在 4000~8000。

**论文里的图，不是装饰，是证据。**

不学会怎样？你的论文全是数字，没有一张图，审稿人读起来干巴巴，也不容易发现数据里的问题。
更糟的是——有些问题只有画图才能发现，比如双峰分布（其实是两群人混在一起了）、离群点（数据录入错误）。

---

## 二、是什么？

### 四种最常用的图

> 传统教材把"用图形展示数据"这件事系统地讲过一遍：[[../../教材笔记/05_统计学原理/03_统计数据整理/知识点/KP08_统计图|统计图]]里分了条形图、饼图、折线图、曲线图、茎叶图、箱线图等，每种图的适用场景都有明确规范。下面这四种是论文里真正用得上的。

| 图名 | 用来干嘛 | 配什么变量 |
|------|----------|-----------|
| **直方图** | 看一个连续变量的分布形状 | 单个连续变量 |
| **箱线图** | 看中位数、四分位、异常值 | 连续变量 × 分类变量分组 |
| **散点图** | 看两个连续变量的关系 | 两个连续变量 |
| **饼图/柱状图** | 看分类变量的占比 | 分类变量 |

### 生活比喻：体检报告上的图

- **直方图** = 把所有人的身高按区间堆起来，看是"中间高两边低"（正态）还是"右边拖个尾巴"（右偏）；
- **箱线图** = 一个盒子装中间 50% 的人，两条须伸到最小最大，外面的点就是"异常身高"；
- **散点图** = 横轴身高、纵轴体重，每个点是一个人，看是不是"个子高的人也重"；
- **饼图** = 把全班按性别切成两块，看男生女生各占多少。

## 三、每种图怎么看？

### 1. 直方图（Histogram）

**怎么画**：把连续数据切成等宽的区间（bin），数每个区间里有多少个观测，画成柱子。

> 切完组数出来的那张"每组多少人"的表，教材里叫 [[../../教材笔记/05_统计学原理/03_统计数据整理/知识点/KP05_频数分布数列|频数分布数列]]。分几组、组距多宽、组限怎么取（含不含端点），都是有讲究的——分组数常用 [[../../教材笔记/05_统计学原理/03_统计数据整理/知识点/KP04_斯特吉斯经验公式|斯特吉斯经验公式]] 参考：$K = 1 + 3.322\lg n$。

**怎么读**：
- **对称钟形** → [[07_正态分布|正态分布]]，均值中位数差不多；
- **右偏**（尾巴拖向右边）→ 有几个特别大的值（收入、房价）；
- **左偏**（尾巴拖向左边）→ 有几个特别小的值（考试不及格）；
- **双峰** → 可能是两群人混在一起（比如本科生和研究生的工资）。

### 2. 箱线图（Boxplot）

**怎么画**：
- 盒子中间那条线 = 中位数；
- 盒子上下边 = Q1 和 Q3；
- 须 = 延伸到不超过 $1.5 \times IQR$ 的最远点；
- 须外面的点 = 异常值。

**怎么读**：
- 盒子长 = IQR 大，中间一半人散；
- 线歪在盒子哪头 = 数据偏哪边；
- 外面的点 = 异常值，要回去查是不是录错了。

### 3. 散点图（Scatter Plot）

**怎么画**：横轴一个变量，纵轴一个变量，每个观测画一个点。

**怎么读**：
- 点从左下到右上 = 正相关（x 大 y 也大）；
- 点从左上到右下 = 负相关（x 大 y 小）；
- 点乱成一团 = 没相关；
- 点弯成曲线 = 不是线性关系，要做变换。

### 4. 饼图和柱状图

**饼图**：看占比，适合类别少（≤5 类）。类别多了别用饼图——切太碎没人看得清。
**柱状图**：看频数比较，类别多了也能用。

**论文里推荐柱状图，少用饼图**——饼图在黑白打印时看不清。

### 5. 直方图 vs 条形图（新手最爱混）

这两个长得很像，但完全不是一回事：

| | 直方图 | 条形图 |
|---|---|---|
| 横轴 | 连续变量（组距） | 离散类别 |
| 矩形排列 | 紧挨着（无空隙） | 中间有空隙 |
| 用途 | 频数分布 | 类别比较 |

**为什么直方图要挨紧？** 因为连续变量是连续的——160和170之间没有断开，柱子自然挨在一起。而条形图的类别是离散的——男生和女生是两个不同的盒子，中间留空隙表示"不连续"。

> **画错了会怎样？** 把直方图中间留空，读者会以为数据是离散的；把条形图挨紧，读者会以为类别之间有连续关系。

### 6. 不等距分组怎么画直方图？

上面讲的都是等距分组（每组宽度一样）。但有时候你会遇到不等距分组——比如收入分布，大多数人集中在低收入区间，组距窄一点；高收入人少，组距宽一点。

**问题来了**：如果组距不一样宽，直接画柱子，宽的组会显得特别大，形状就扭曲了。

**解决方案：换算成"频数密度"**：

$$频数密度 = \frac{次数}{组距}$$

画直方图时，纵轴用频数密度，不用原始次数。这样每个矩形的面积才和次数成正比。

**例子**：
- 低收入组：5人，组距100 → 频数密度 = 5/100 = 0.05
- 高收入组：5人，组距400 → 频数密度 = 5/400 = 0.0125

画出来：低收入组的柱子宽100、高0.05；高收入组的柱子宽400、高0.0125。两个矩形面积都是5，刚好相等——代表两组人数一样多。

> **论文里什么时候碰到？** 收入、房价这种右偏分布，经常用不等距分组。Stata和Python的`hist()`默认都是等距的，你要自己处理不等距。

## 四、统计表：论文里的三线表规范

图讲完了，再讲讲表。[[../../教材笔记/05_统计学原理/03_统计数据整理/知识点/KP07_统计表结构|统计表]]不是随便画个表格——它有固定骨架和学术规范。

### 4.1 统计表的结构

一张规范的统计表 = 三部分：

```
┌────────── 总标题（表名）──────────┐
│                                │
│ 横标目（行标题）  │ 纵标目（列标题）│
│                │ 数字资料       │
└──────────────────────────────┘
```

- **总标题**：写在表上方，要写清时间、地点、内容（如"表2-1 2023年中国31省份GDP"）
- **横标目**：行标题，一般是被研究对象（如各省）
- **纵标目**：列标题，一般是说明指标（如GDP、人口、人均GDP）
- **数字资料**：表内具体数值，同栏精度要一致

### 4.2 三线表：论文标配

学术规范要求用**三线表**——去掉所有不必要的横竖线，只保留三条横线：

```
─────────────────────────────  ← 顶线（粗）
        2023年中国31省份GDP
─────────────────────────────  ← 表头线（粗）
省份    GDP（万亿元）    人口（亿人）
─────────────────────────────  ← 底线（粗）
广东      13.5           1.27
江苏      12.8           0.85
山东       9.2           1.02
─────────────────────────────
注：数据来源：国家统计局2024年统计公报。
```

**三条线**：顶线、表头线、底线。左右不封口，纵栏细线，横行不画线。

### 4.3 制表规则（别犯这些错）

1. **标题在表上方**，图的标题在图下方——别搞反
2. **表号按章节编**：表2-1、表2-2……（第2章第1张表）
3. **数据要注明单位**：GDP（万亿元）、人口（亿人）
4. **无数字用"—"，不详用"……"**——不要留空格
5. **资料来源放表下方**："资料来源：国家统计局2024年统计公报"
6. **同栏数据精度一致**：都保留两位小数，别有的一位有的三位

> **Excel风格网格表为什么不行？** 全是横竖线，视觉嘈杂，突出不了数字。三线表把多余的线全去掉，眼睛直接落在数字上。

## 六、一个完整的数字例子 + Python 画图

**数据**：500 个人的月工资（元），其中 10 个高管工资特别高。

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 设置中文字体
plt.rcParams['font.sans-serif'] = ['Hiragino Sans GB', 'PingFang SC']
plt.rcParams['axes.unicode_minus'] = False

# 生成模拟数据：490个普通员工 + 10个高管
np.random.seed(42)  # 固定随机种子，每次结果一样
normal = np.random.normal(loc=6000, scale=1500, size=490)  # 均值6000，标准差1500
execs = np.random.normal(loc=30000, scale=5000, size=10)   # 高管均值3万

wage = np.concatenate([normal, execs])
df = pd.DataFrame({'wage': wage})

print(f"样本量: {len(df)}")
print(f"均值: {df['wage'].mean():.0f}")
print(f"中位数: {df['wage'].median():.0f}")
print(f"标准差: {df['wage'].std():.0f}")
```

### 图1：直方图

```python
plt.figure(figsize=(8, 4))
plt.hist(df['wage'], bins=30, edgecolor='black', alpha=0.7)
plt.axvline(df['wage'].mean(), color='red', linestyle='--', label=f'均值={df["wage"].mean():.0f}')
plt.axvline(df['wage'].median(), color='green', linestyle='--', label=f'中位数={df["wage"].median():.0f}')
plt.xlabel('月工资（元）')
plt.ylabel('人数')
plt.title('工资分布直方图')
plt.legend()
plt.tight_layout()
plt.savefig('hist_wage.png', dpi=150)
plt.show()
```

**读图**：大部分人在 4000~8000，但右边拖了个长尾巴到 3 万——右偏。均值（红）被尾巴拉到中位数（绿）右边。

### 图2：箱线图

```python
plt.figure(figsize=(6, 4))
plt.boxplot(df['wage'], vert=False, labels=['工资'])
plt.xlabel('月工资（元）')
plt.title('工资箱线图')
plt.tight_layout()
plt.savefig('box_wage.png', dpi=150)
plt.show()
```

**读图**：盒子挤在左边（普通员工），右边一串点是高管（异常值）。

### 图3：散点图（工资 vs 教育年限）

```python
# 再加一列教育年限
df['edu'] = np.random.normal(loc=14, scale=3, size=500)

plt.figure(figsize=(6, 5))
plt.scatter(df['edu'], df['wage'], alpha=0.5, s=20)
plt.xlabel('教育年限（年）')
plt.ylabel('月工资（元）')
plt.title('工资 vs 教育年限 散点图')
plt.tight_layout()
plt.savefig('scatter_wage_edu.png', dpi=150)
plt.show()
```

**读图**：整体上教育年限多的人工资高，但右边高管那团点很扎眼——后面回归时要考虑要不要单独处理。

## 七、什么时候用什么图？

| 你想展示什么 | 用什么图 |
|-------------|----------|
| 一个连续变量的分布 | 直方图 |
| 连续变量按分组比较（男女工资对比） | 箱线图 |
| 两个连续变量的关系 | 散点图 |
| 分类变量的占比 | 柱状图（少用饼图） |
| 时间趋势 | 折线图 |
| 多个变量的均值比较 | 柱状图 |

## 八、易错点

1. **直方图的 bin 数不是越多越好**。bin 太多，噪声也画出来了；bin 太少，形状被掩盖。一般 20~30 个 bin 比较合适。
2. **箱线图的异常值不是错误数据**。它只是"离中间远"，可能是真的高收入，不一定是录入错误——要回去查。
3. **散点图不要只看趋势，要看有没有特殊结构**。比如高管那团点，会把回归系数带偏。
4. **饼图类别超过 5 个别用**。切太碎，打印出来全是黑块。
5. **图一定要有标题、坐标轴标签、单位**。很多同学画图不写标签，别人不知道纵轴是元还是万元。
6. **直方图和条形图搞混**。直方图柱子挨紧（连续变量），条形图柱子留空（离散类别）。
7. **不等距分组直接画直方图**。宽组会显得过大，要换算成频数密度（次数/组距）。
8. **统计表用Excel风格全网格**。论文里必须用三线表——顶线、表头线、底线，左右不封口。

## 十、对比

| 图 | 优点 | 缺点 |
|----|------|------|
| 直方图 | 看分布形状最直观 | bin 数选择影响形状 |
| 箱线图 | 紧凑，能标异常值 | 看不出双峰 |
| 散点图 | 看两变量关系 | 点太多时看不清（加 alpha 透明度） |
| 饼图 | 看占比直观 | 类别多了没法看，黑白打印糊 |

---

## 十一、速记卡

> **直方图 vs 条形图**：直方图挨紧（连续变量），条形图留空（离散类别）。
> **不等距分组**：纵轴用频数密度（次数/组距），不然宽组会显得过大。
> **论文表格 = 三线表**：顶线、表头线、底线，左右不封口，标题在表上方，资料来源在表下方。
> **直方图看分布形状（对称/偏/双峰）。**
> **箱线图看中位数+异常值。**
> **散点图看两变量关系（正相关/负相关/没关系）。**
> **柱状图比分类，饼图少用。**
> 画图三要素：标题、坐标轴标签、单位。
