# 05 数据清洗：脏数据怎么洗？

## 一、为什么要学这个？

行话叫"Garbage In, Garbage Out"（垃圾进，垃圾出）。

你花了一周学回归，跑了一个很漂亮的模型，R² = 0.8，t 值都显著——结果导师问："你这数据里有缺失值你处理了吗？那个工资 100 万的是真的吗？"

你回去一看：3000 行数据里，200 行工资是空的，还有 1 行工资是 10000000（录入时多打了个 0）。

**你的漂亮模型，全是建立在脏数据上的。**

数据清洗占整个论文工作量的 60%~80%。你以为写论文是跑模型，其实大部分时间在跟脏数据搏斗。

不学会怎样？你的结论不可信，导师让你重做。

---

## 二、是什么？

### 生活比喻：洗菜

你从菜市场买回来一把青菜，直接下锅？不行。

要先：
1. **挑掉烂叶子**（删除明显错误的）；
2. **洗掉泥**（处理缺失值）；
3. **切掉虫眼**（处理异常值）；
4. **泡一泡去农药**（极端值缩尾处理）。

**数据清洗就是这个过程。**

> 教材里把清洗的第一步叫 [[../../教材笔记/05_统计学原理/03_统计数据整理/知识点/KP01_数据审核|数据审核]]——从数据刚拿到手时就要做四件事：**完整性**（该填的有没有漏）、**准确性**（数字合不合常理，比如年龄 200 岁）、**及时性**（数据是不是太老了）、**适用性**（口径跟你研究的问题对不对得上）。下面讲的缺失值、异常值处理，都是在数据审核之后才动手的。

### 三类最常见的脏数据问题

| 问题 | 是什么 | 例子 |
|------|--------|------|
| **缺失值** | 某些观测的某变量是空的 | 1000 人里有 50 人没填工资 |
| **异常值** | 明显不符合常理的值 | 工资 10000000 元（多打了个 0） |
| **极端值** | 虽然是真的，但特别大/小 | 马云的收入（真的高，但会带偏结果） |

---

## 三、缺失值怎么处理？

### 方法1：直接删除（listwise deletion）

**做法**：只要某一行有任何一个变量缺失，就把这一行整个删掉。

**什么时候用**：
- 缺失比例很小（<5%）；
- 缺失是随机的（不是"穷人才不填工资"这种系统性缺失）。

**风险**：删多了样本变小，统计效力下降。

### 方法2：均值/中位数填充

**做法**：用这个变量的均值（或中位数）把空填上。

**什么时候用**：
- 缺失比例中等（5%~20%）；
- 数据是连续的、没有明显偏态（偏态用中位数）。

**风险**：填充后这个变量的标准差会变小（因为多了一堆等于均值的数），低估真实波动。

### 方法3：回归插补

**做法**：用其他变量预测缺失值——比如一个人没填工资，但他有教育年限、工龄，你用这两个变量回归预测他的工资。

**什么时候用**：
- 缺失比例较大；
- 你有其他相关信息可以用来预测。

**风险**：插补的值太"完美"，会高估回归的 R²。

### 方法4：不处理，用 Stata 的 `mi` 多重插补

这是最严谨的做法，但复杂，本科论文一般不需要。

## 四、异常值怎么识别？

### 方法1：3σ 原则

**做法**：算均值 $\bar{x}$ 和标准差 $s$，超出 $\bar{x} \pm 3s$ 的就算异常值。

**直觉**：[[07_正态分布|正态分布]]里，99.7% 的数据都在均值 ±3σ 以内，超出的就是小概率事件，值得怀疑。

**公式**：
$$\text{异常值} = \{x_i : |x_i - \bar{x}| > 3s\}$$

**风险**：3σ 假设数据正态分布。如果数据本身就偏（比如收入），3σ 会把很多正常的高收入误判为异常。

### 方法2：箱线图 IQR 法

**做法**：
- 下界 = $Q_1 - 1.5 \times IQR$
- 上界 = $Q_3 + 1.5 \times IQR$
- 超出这个范围的算异常值。

**优点**：不假设正态分布，对偏态数据更稳健。

**论文里推荐用 IQR 法**。

---

## 五、异常值怎么处理？

识别出来之后怎么办？

| 处理方式 | [[08_答辩PPT怎么做|怎么做]] | 什么时候用 |
|----------|--------|-----------|
| **核实并修正** | 回去查原始数据，看是不是录错了 | 第一选择！大概率是录入错误 |
| **删除** | 这一行直接删掉 | 确认是错误数据 |
| **缩尾处理**（winsorize） | 把超出 1% 的值替换成 1% 分位数的值 | 是真实的极端值（如高管工资），不想删 |
| **取对数** | $\ln(x)$ | 收入、GDP 这种偏态数据，取对数后变对称 |

**注意**：删除异常值一定要在论文里说明——"本文对工资变量进行了 1% 水平的缩尾处理"。不能偷偷删，审稿人会查。

## 六、符号表

| 符号 | 是什么 |
|------|--------|
| $\bar{x}$ | 均值 |
| $s$ | 标准差 |
| $Q_1, Q_3$ | 四分位数 |
| $IQR$ | 四分位距 |
| $w_p$ | 第 p 百分位数（如 $w_{0.01}$ 是 1% 分位数） |

## 七、一个完整的数字例子手算

**数据**：10 个人的月工资：

```
3000  3500  4000  4500  5000  5500  6000  6500  7000  100000
```

最后一个 100000 明显可疑（是不是多打了个 0？）。

### 第一步：算均值和标准差

$$\bar{x} = \frac{3000+3500+\cdots+7000+100000}{10} = \frac{150000}{10} = 15000$$

$$s \approx 29920 \quad \text{（手算略，Python 验证）}$$

### 第二步：用 3σ 原则识别

上界 = $\bar{x} + 3s = 15000 + 3 \times 29920 = 104760$

100000 < 104760——按 3σ 原则，100000 居然不算异常值？
这是因为 100000 本身把均值和标准差都拉大了，3σ 原则被自己的"嫌疑犯"污染了。

**这就是为什么 3σ 不适合偏态数据。**

### 第三步：用 IQR 法识别

排序后：3000, 3500, 4000, 4500, 5000, 5500, 6000, 6500, 7000, 100000

- $Q_1$ = 第 2.5 个数 = (3500+4000)/2 = 3750
- $Q_3$ = 第 7.5 个数 = (6000+6500)/2 = 6250
- $IQR = 6250 - 3750 = 2500$
- 上界 = $Q_3 + 1.5 \times IQR = 6250 + 3750 = 10000$

100000 > 10000——**IQR 法把它识别为异常值了**。

### 第四步：怎么处理？

先回去查原始数据——如果是录入错误（本来是 10000），就改成 10000。
如果确认是真的（这个公司老板真的拿 10 万），就做缩尾：把 100000 替换成 1% 分位数或上界 10000。

### Python 验证

```python
import numpy as np

wage = [3000, 3500, 4000, 4500, 5000, 5500, 6000, 6500, 7000, 100000]

# IQR法
q1 = np.percentile(wage, 25)
q3 = np.percentile(wage, 75)
iqr = q3 - q1
upper = q3 + 1.5 * iqr
print(f"Q1={q1}, Q3={q3}, IQR={iqr}, 上界={upper}")
# Q1=4125, Q3=5875, IQR=1750, 上界=8500

outliers = [x for x in wage if x > upper]
print(f"异常值: {outliers}")  # [100000]

# 缩尾：把大于上界的替换成上界
wage_winsorized = [min(x, upper) for x in wage]
print(f"缩尾后: {wage_winsorized}")
```

## 八、什么时候能直接删/补？

**原则**：能不删就不删，能核实就核实。

| 情况 | 建议做法 |
|------|---------|
| 缺失 <5%，随机缺失 | 删除 |
| 缺失 5%~20%，连续变量 | 均值/中位数填充 |
| 缺失很多，但其他变量能预测 | 回归插补 |
| 明显录入错误（多打个 0） | 修正 |
| 真实的极端值（富豪） | 缩尾或取对数 |

---

## 九、易错点

1. **不要先跑回归再回头删异常值**。这叫"窥探数据"（data snooping），会让你的结果不可信。正确流程：先清洗，再分析。
2. **删除异常值要在论文里写清楚**。"本文对工资变量在 1% 和 99% 分位数进行了缩尾处理"——这是标准做法，不丢人。
3. **缺失值不是越少越好**。如果你填充得太完美，后面回归的 R² 会虚高，审稿人一看就知道你插补过了。
4. **不要把所有异常值都删了**。有时候异常值本身就是研究对象——比如你研究"富豪的消费行为"，那马云就是你的核心样本，删了就没了。

## 十、Python 代码（完整清洗流程）

```python
import pandas as pd
import numpy as np

# 读数据
df = pd.read_csv('raw_data.csv')

print("=== 清洗前 ===")
print(f"行数: {len(df)}")
print(f"缺失值:\n{df.isnull().sum()}")

# 1. 处理缺失值：工资用中位数填充
df['wage'] = df['wage'].fillna(df['wage'].median())

# 2. 识别异常值（IQR法）
q1 = df['wage'].quantile(0.25)
q3 = df['wage'].quantile(0.75)
iqr = q3 - q1
upper = q3 + 1.5 * iqr
lower = q1 - 1.5 * iqr

print(f"\n工资上界: {upper:.0f}, 下界: {lower:.0f}")
print(f"异常值数量: {((df['wage'] > upper) | (df['wage'] < lower)).sum()}")

# 3. 缩尾处理（替换为上/下界）
df['wage_clean'] = df['wage'].clip(lower=lower, upper=upper)

# 4. 保存清洗后的数据
df.to_csv('clean_data.csv', index=False)
print("\n=== 清洗完成，已保存 clean_data.csv ===")
```

## 十一、对比

| 方法 | 适用问题 | 优点 | 缺点 |
|------|---------|------|------|
| 删除缺失值 | 小比例随机缺失 | 简单 | 样本变小 |
| 均值填充 | 连续变量小比例缺失 | 简单 | 标准差被低估 |
| 3σ 识别异常值 | 正态分布数据 | 简单 | 偏态数据不准 |
| IQR 识别异常值 | 任何分布 | 稳健 | 不假设分布 |
| 缩尾处理 | 真实极端值 | 不删数据，消除影响 | 改变了原始值 |
| 取对数 | 收入/GDP 偏态数据 | 变对称 | 系数解释变百分比 |

---

## 十二、速记卡

> **缺失值**：小比例删，中比例均值/中位数填，大比例回归插补。
> **异常值识别**：3σ 假设正态，IQR 更通用——论文用 IQR。
> **异常值处理**：先核实是不是录错了；是真的极端值就缩尾或取对数。
> **清洗完再跑回归**，不要先跑再回头删。
> **所有处理都要在论文里写清楚**。
