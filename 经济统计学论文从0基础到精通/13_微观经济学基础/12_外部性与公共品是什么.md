# 12 外部性与公共品是什么？（小白版）

## 一、为什么要学这个？

**凌晨 2 点，你在观音桥酒吧喝完酒，打车回家。司机一脚油门，排气管对着路边的共享单车喷——你没付钱，但路人被动吸了一口尾气。**

这就是**负外部性**：你做一件事，自己爽了（或赚钱了），但代价让别人承担。

反过来：你在阳台种了满墙三角梅，路过的人抬头都能看一眼，他们没给你钱，但你给大家带来了美——这是**正外部性**。

**不学会怎样？**
你写论文研究"环境污染""教育补贴""疫苗接种""垃圾分类"，连"为什么政府要收排污费""为什么教育要补贴"都讲不清。
**外部性是市场失灵的第二种**（第一种是垄断），也是环境经济学、健康经济学、公共经济学的核心概念。

---

## 二、是什么？

### 生活比喻：火锅店里的二手烟

- 老王在火锅店抽烟：自己爽 100 分；
- 旁边桌小张被动吸二手烟：不爽 -30 分；
- 火锅店老板也没收费（老王没为"污染小张"付钱）；
- **老王决策时只算自己的 100 分，没算小张的 -30 分**——于是他抽多了。

**私人成本** = 老王自己的烟钱；
**社会成本** = 烟钱 + 小张的健康损失；
**外部性** = 社会成本 - 私人成本 = 小张的 -30 分。

### 严格定义

> **外部性（Externality）**：经济主体的行为对**旁观者**产生了**未被市场交易反映**的影响。
>
> - **负外部性**：给旁观者带来成本（污染、噪音、二手烟）；
> - **正外部性**：给旁观者带来收益（教育、打疫苗、种花）。
>
> **私人成本（Private Cost）**：生产者自己承担的成本。
>
> **社会成本（Social Cost）** = 私人成本 + 外部成本。
>
> **私人收益（Private Benefit）**：消费者自己得到的收益。
>
> **社会收益（Social Benefit）** = 私人收益 + 外部收益。
>
> **外部性为什么导致市场失灵？**
> - 负外部性：私人成本 < 社会成本 → 生产太多（污染超量）；
> - 正外部性：私人收益 < 社会收益 → 生产太少（教育供给不足）。
>
> **科斯定理（Coase Theorem）**：如果产权清晰、交易成本为零，不管初始产权归谁，私人谈判能达到帕累托有效率的结果。

### 公共品的两个特征

| 特征 | 含义 | 例子 |
|------|------|------|
| **非排他性** | 没法不让别人用 | 路灯、国防、空气 |
| **非竞争性** | 多一个人用不增加成本 | 路灯多照一个人不费电 |

**四类物品**：

|  | 排他 | 非排他 |
|--|--|--|
| **竞争** | 私人物品（奶茶） | 公共资源（渔场、公共草场） |
| **非竞争** | 俱乐部物品（有线电视、影院） | **纯公共品**（国防、路灯） |

**公共品的问题**：**搭便车（Free Rider）**——反正不付钱也能用，那我干嘛付钱？结果私人市场供给不足，必须政府来。

### 符号表

| 符号 | 怎么读 | 是什么 | 生活类比 |
|------|--------|--------|----------|
| $MC_p$ | "marginal cost private" | 私人边际成本 | 工厂自己的生产成本 |
| $MC_s$ | "marginal cost social" | 社会边际成本 | 私人成本 + 污染成本 |
| $MB_p$ | "marginal benefit private" | 私人边际收益 | 教育给你自己的工资 |
| $MB_s$ | "marginal benefit social" | 社会边际收益 | 私人收益 + 犯罪率下降等外部收益 |
| $t$ | "tax" | 庇古税 | 对污染收的税 |
| $Q^*$ | "Q star" | 社会最优产量 | 把外部性算进去后的产量 |

## 三、公式怎么来的？（手把手推）

### 3.1 负外部性下的市场均衡 vs 社会最优

**假设**：某化工厂生产 Q 吨产品。
- 私人边际成本 $MC_p = 2Q$（工厂自己的成本）；
- 污染给周边居民带来的边际外部成本 $MEC = Q$（越多越污染）；
- 需求曲线 $P = 100 - Q$（即私人边际收益 $MB_p = 100 - Q$）。

**第一步：市场均衡（只算私人成本）**。

厂商按 $MC_p = MB_p$ 决策：

$$2Q = 100 - Q \;\Rightarrow\; Q_{市场} = \frac{100}{3} \approx 33.3$$

**第二步：社会最优（算上外部成本）**。

社会边际成本 $MC_s = MC_p + MEC = 2Q + Q = 3Q$。

社会最优：$MC_s = MB_p$：

$$3Q = 100 - Q \;\Rightarrow\; Q_{社会} = 25$$

**第三步：对比**。

- 市场产量 33.3 吨，社会最优 25 吨；
- **市场多生产了 8.3 吨**——这就是负外部性导致的过量生产；
- 对应的无谓损失（DWL）是 $MC_s$ 和 $MB_p$ 曲线之间、$Q_{社会}$ 和 $Q_{市场}$ 之间的三角形面积。

**第四步：怎么纠正？**

**庇古税（Pigouvian Tax）**：政府对每单位产品收 $t = MEC = Q_{社会} = 25$ 的税（即按社会最优产量处的外部成本收税）。

征税后，厂商的私人边际成本变成 $MC_p + t = 2Q + 25$。

令 $2Q + 25 = 100 - Q$：

$$3Q = 75 \;\Rightarrow\; Q = 25$$

**看！征税后厂商自动调到社会最优产量 25**——庇古税的巧妙之处就在这：让厂商把外部成本"内部化"。

### 3.2 正外部性（教育）的类似推导

**假设**：个人上大学的私人收益 $MB_p = 100 - Q$（Q 是上大学人数），社会收益（因为教育让社会更文明、犯罪率降）$MEB = 20$（每多一个大学生给社会带来 20 的额外收益）。

- 私人市场均衡：$MB_p = MC$（假设 $MC = 50$），即 $100 - Q = 50$，$Q_{市场} = 50$；
- 社会最优：$MB_s = MB_p + MEB = 120 - Q = MC = 50$，$Q_{社会} = 70$；
- **市场少了 20 万人上大学**——教育供给不足；
- **纠正**：政府给每个大学生补贴 20 元（庇古补贴），把私人收益抬到社会收益水平。

### 3.3 公共品的需求曲线怎么加？

私人物品：个人需求曲线**横向相加**（同一价格，所有人的消费量加起来）。

公共品：个人需求曲线**纵向相加**（同一数量，所有人的边际收益加起来——因为大家同时消费同一个数量）。

**例子**：路灯。
- 小王愿付 $MB_1 = 10 - Q$；
- 小李愿付 $MB_2 = 20 - 2Q$；
- 社会边际收益 $MB_s = MB_1 + MB_2 = 30 - 3Q$；
- 路灯的边际成本 $MC = 15$；
- 社会最优：$30 - 3Q = 15$ → $Q = 5$（装 5 盏路灯）。

**关键区别**：私人物品是"横向加"（同一价格，量相加），公共品是"纵向加"（同一数量，价相加）——因为公共品大家共享同一个数量。

## 四、一个完整的数字例子（Python 验证）

**题目**：重庆某工业园区排放废水，私人边际成本 $MC_p = 10 + Q$，污染给下游渔民带来的边际外部成本 $MEC = 0.5Q$，需求 $P = 100 - Q$。

问：
(1) 没有干预时，市场均衡产量？
(2) 社会最优产量？
(3) 庇古税多少？
(4) 无谓损失多大？

**手算**：

(1) 市场均衡：$MC_p = P$：
- $10 + Q = 100 - Q$；
- $2Q = 90$；
- $Q_{市场} = 45$；
- $P = 55$。

(2) 社会最优：$MC_s = MC_p + MEC = 10 + Q + 0.5Q = 10 + 1.5Q = P$：
- $10 + 1.5Q = 100 - Q$；
- $2.5Q = 90$；
- $Q_{社会} = 36$；
- $P = 64$。

(3) 庇古税：在 $Q_{社会}=36$ 处，$MEC = 0.5 \times 36 = 18$ 元/吨。

(4) 无谓损失：
- 在 $Q_{市场}=45$ 处，$MC_s = 10 + 1.5 \times 45 = 77.5$，但社会收益（需求）只有 $P = 55$；
- 多生产的那 $45 - 36 = 9$ 吨，每吨的"社会成本 > 社会收益"的差额从 $Q=36$ 时的 0 增加到 $Q=45$ 时的 $77.5 - 55 = 22.5$；
- 三角形面积 $= \frac{1}{2} \times 9 \times 22.5 = 101.25$。

**Python 验证**：

```python
import numpy as np
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['PingFang SC']
plt.rcParams['axes.unicode_minus'] = False

Q = np.arange(0, 80, 0.1)
MC_p = 10 + Q
MEC = 0.5*Q
MC_s = MC_p + MEC
P = 100 - Q

# 市场均衡
Q_market = 45
P_market = 55

# 社会最优
Q_social = 36
P_social = 64

plt.figure(figsize=(10, 6))
plt.plot(Q, MC_p, 'b-', lw=2, label='私人边际成本 MCp = 10+Q')
plt.plot(Q, MC_s, 'r-', lw=2, label='社会边际成本 MCs = 10+1.5Q')
plt.plot(Q, P, 'g-', lw=2, label='需求 P = 100-Q')
plt.scatter([Q_market], [P_market], color='blue', s=100, zorder=5, label=f'市场均衡 Q={Q_market}')
plt.scatter([Q_social], [P_social], color='red', s=100, zorder=5, label=f'社会最优 Q={Q_social}')
plt.xlabel('产量 Q（吨）')
plt.ylabel('价格/成本（元）')
plt.title('负外部性：市场生产过多，庇古税纠正')
plt.legend()
plt.grid(alpha=0.3)
plt.ylim(0, 110)
plt.savefig('externality.png', dpi=150, bbox_inches='tight')
plt.show()

# 无谓损失
DWL = 0.5 * (Q_market - Q_social) * (MC_s[int(Q_market*10)-1] - P[int(Q_market*10)-1])
print(f"市场均衡 Q={Q_market}, 社会最优 Q={Q_social}")
print(f"庇古税 = {0.5*Q_social} 元/吨")
print(f"无谓损失 = {DWL:.2f}")
```

输出：
```
市场均衡 Q=45, 社会最优 Q=36
庇古税 = 18.0 元/吨
无谓损失 = 101.25
```

## 五、什么时候能用？（前提条件）

1. **外部性可测**：污染的量、教育的外部收益，得能量化；
2. **产权清晰**（科斯定理应用时）：否则没法谈判；
3. **交易成本低**（科斯定理应用时）：受影响的人不多、能凑到一起谈；
4. **政府能收税/补贴**（庇古税应用时）：税率能按 $MEC$ 设定。

---

## 六、什么时候不能用？（易错点）

1. **外部性 ≠ 所有影响**：同事换了个发型让你不爽，这不是外部性（没影响生产/消费的市场交易）。
2. **庇古税税率 = 外部成本，不是产量**：按每吨收 18 元，不是按总污染收。
3. **科斯定理有前提**：交易成本为零、产权清晰——现实中大污染涉及几千户居民，交易成本极高，科斯谈判不成立，还得靠政府。
4. **公共品 ≠ 政府提供的东西**：政府提供的不一定是公共品（公立学校是俱乐部物品，因为要考试录取）；市场提供的也不一定是私人物品（私人捐的路灯）。
5. **搭便车问题**：公共品靠私人募捐基本失败，必须强制税收。

## 七、容易和什么搞混？

| 概念 | 一句话 | 关键 |
|------|--------|------|
| **负外部性** | 生产太多（污染） | 私人成本 < 社会成本 |
| **正外部性** | 生产太少（教育） | 私人收益 < 社会收益 |
| **庇古税** | 对负外部性收税 | 让私人成本 = 社会成本 |
| **庇古补贴** | 对正外部性补贴 | 让私人收益 = 社会收益 |
| **科斯定理** | 产权清晰 + 交易成本为零，私人谈判达最优 | 不依赖政府 |
| **公共品** | 非排他 + 非竞争 | 搭便车，私人市场供给不足 |
| **公共资源** | 非排他 + 竞争 | 公地悲剧（渔场、草场） |
| **俱乐部物品** | 排他 + 非竞争 | 有线电视、影院 |

## 八、在论文里怎么用？

### 8.1 环境经济学（最经典，IV 是标配）

**题目例**：《空气污染对居民健康的影响——基于重庆市面板数据》
- 理论：工厂排放是负外部性，健康是外部成本；
- 实证：$\text{健康}_{it} = \beta_0 + \beta_1 \text{污染}_{it} + \beta_2 X_{it} + \varepsilon_{it}$；
- **内生性问题**：污染高的地区可能本来医疗条件就差（遗漏变量），健康差的人多的地方政府可能更严治污（反向因果）；
- **工具变量**：用"逆温天数"（气象条件影响污染扩散，但不直接影响健康）做 IV；
- 统计方法链接：[[../05_内生性与面板/03_工具变量IV|工具变量IV]]（环境经济学经典工具）、[[../05_内生性与面板/06_固定效应FE|固定效应]]（控制城市不随时间变的特征）。

### 8.2 教育的正外部性

**题目例**：《高等教育的社会回报——基于中国省际面板》
- 理论：教育有正外部性（犯罪率降、技术溢出）；
- 实证：人均 GDP 增长率 vs 大学毛入学率；
- 用 FE 控制省份固定效应；
- 比较"私人回报"（明瑟方程估的工资涨幅）和"社会回报"（GDP 增长）。

### 8.3 公共品供给评价（熵值法综合评价）

**题目例**：《重庆市公共服务供给水平综合评价——基于熵值法》
- 指标：每千人医生数、人均道路面积、绿化率、图书馆数；
- 用熵值法定权重（数据驱动，不靠专家拍脑袋）；
- 算各区县公共品得分，对比财政投入与实际供给；
- 统计方法链接：[[../07_综合评价方法/03_熵值法|熵值法]]。

### 8.4 碳交易与庇古税实证

**题目例**：《碳排放交易试点的减排效果——基于 DID 模型》
- 碳交易 = 把外部性内部化的市场手段（类似庇古税）；
- 用 DID：试点省 vs 非试点省，试点前后排放变化；
- 评估庇古手段的实际效果。

**本科生常见踩坑**：
- 把外部性写一遍定义就完事，没算"市场均衡 vs 社会最优"的差距；
- 用 OLS 直接回归"污染→健康"，完全不处理内生性——环境经济学里这是大忌；
- 把公共品和"政府提供"划等号；
- 庇古税税率写成"每吨多少钱"但没说是社会最优产量处的 MEC。

## 九、现实意义

- **为什么重庆要收污水处理费？** 工厂排污是负外部性，收费 = 庇古税，让企业自己处理污水。
- **为什么义务教育免费还补贴？** 教育是正外部性，私人市场供给不足，政府出钱补上。
- **为什么打疫苗要免费？** 你打疫苗不仅自己不得病，还不让别人得（群体免疫）——正外部性，私人接种率不够，必须强制/免费。
- **为什么公共草场容易荒？** 公共资源（非排他+竞争），每个人都想多放一只羊，结果草场沙化——"公地悲剧"。
- **为什么路灯由政府装？** 私人装了别人白看，没人愿意掏钱——非排他 + 非竞争，纯公共品，只能靠税。
- **为什么重庆推行"河长制"？** 河流是公共资源，以前大家排污没人管（公地悲剧），现在指定一个负责人，把产权"清晰化"——科斯定理思路。
- **为什么共享单车乱停被罚？** 你骑车方便是私人收益，但占道是负外部性，平台和用户都没算这个成本。

## 十、速记卡

> **外部性**：你的行为影响了没参与交易的旁观者。
> **负外部性**（污染）：私人成本 < 社会成本 → 生产太多 → 用**庇古税**纠正。
> **正外部性**（教育、疫苗）：私人收益 < 社会收益 → 生产太少 → 用**庇古补贴**纠正。
> **庇古税** = 社会最优产量处的边际外部成本，让厂商把外部成本内部化。
> **科斯定理**：产权清晰 + 交易成本为零，私人谈判能达最优（不依赖政府）。
> **公共品** = 非排他 + 非竞争（路灯、国防）→ 搭便车 → 必须政府提供。
> **公共资源** = 非排他 + 竞争（渔场、草场）→ 公地悲剧。
> **公共品的需求曲线**：所有人的边际收益纵向相加（不是横向）。
