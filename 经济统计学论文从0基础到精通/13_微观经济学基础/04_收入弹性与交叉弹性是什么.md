# 04 收入弹性与交叉弹性是什么？（小白版）

<div style="text-align:right;margin:10px 0;"><a href="../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


## 一、为什么要学这个？

**收入涨了，你会多买什么？**
- 工资从 5000 涨到 1 万，你会多下馆子、多旅游，但你不会多买三袋大米——甚至会少吃食堂多点外卖。
- 这就是**收入弹性**在回答：收入变 1%，你对某商品的购买量变百分之几？

**隔壁咖啡店涨价了，奶茶店会怎样？**
- 喜茶涨价 5 块，蜜雪冰城销量暴涨——这是**替代品**在联动；
- 奶茶涨价 5 块，珍珠的销量反而跌——这是**互补品**在联动。
- 这就是**交叉弹性**在回答：别的商品价格变 1%，我这款商品的购买量变百分之几？

**不学会怎样？**
你写论文研究"消费升级"，连"正常品/低档品/奢侈品"都不会分；研究"市场竞争"，连"替代品/互补品"都不会标——导师直接打回。

## 二、是什么？

### 生活比喻

**收入弹性**：就像你工资涨了请朋友吃饭，去的是海底捞还是沙县？
- 去海底捞 → 收入弹性 > 1（奢侈品）；
- 还去沙县但多了一份蒸饺 → 收入弹性 0~1（正常品）；
- 反而吃更少泡面了 → 收入弹性 < 0（低档品）。

**交叉弹性**：
- 喜茶涨价，蜜雪涨销量 → 正交叉弹性（替代品）；
- 奶茶涨价，珍珠销量跌 → 负交叉弹性（互补品）；
- 奶茶涨价，牙膏销量不动 → 交叉弹性 ≈ 0（没关系）。

### 严格定义

> **需求收入弹性（Income Elasticity of Demand）$E_i$**：其他条件不变，需求量变动百分比除以**收入**变动百分比。
>
> $$E_i = \frac{\Delta Q / Q}{\Delta I / I}$$
>
> $I$ 是消费者收入。
>
> **需求交叉弹性（Cross-price Elasticity of Demand）$E_{xy}$**：其他条件不变，**X 商品需求量**变动百分比除以 **Y 商品价格**变动百分比。
>
> $$E_{xy} = \frac{\Delta Q_x / Q_x}{\Delta P_y / P_y}$$

### 收入弹性分类

| $E_i$ | 类型 | 例子 | 收入涨 10%，购买量变 |
|-------|------|------|----------------------|
| $E_i < 0$ | 低档品 | 泡面、公交、拼多多 | 减少（-2%） |
| $0 < E_i < 1$ | 必需品（正常品） | 米盐、理发、牙膏 | 增加（+5%） |
| $E_i > 1$ | 奢侈品（高档品） | 旅游、健身、奶茶、苹果手机 | 增加（+15%） |
| $E_i = 0$ | 中性 | 食盐（吃多吃少都那点） | 不变 |

### 交叉弹性分类

| $E_{xy}$ | 关系 | 例子 |
|----------|------|------|
| $E_{xy} > 0$ | **替代品** | 喜茶 vs 奈雪、地铁 vs 打车 |
| $E_{xy} < 0$ | **互补品** | 奶茶 vs 珍珠、汽车 vs 汽油、打印机 vs 墨盒 |
| $E_{xy} = 0$ | **无关品** | 奶茶 vs 牙膏 |

### 符号表

| 符号 | 怎么读 | 是什么 | 生活类比 |
|------|--------|--------|----------|
| $E_i$ | "E i" | 收入弹性 | 工资涨了买什么 |
| $I$ | "I" | 收入 | 月工资 |
| $E_{xy}$ | "E x y" | 交叉弹性 | Y 涨价 X 销量变多少 |
| $P_y$ | "P y" | Y 商品价格 | 隔壁咖啡店价格 |

## 三、公式怎么来的？（手把手推）

### 3.1 收入弹性

**问题**：小王月收入从 8000 涨到 10000（涨 25%），每月下馆子次数从 4 次涨到 6 次（涨 50%）。下馆子的收入弹性是多少？

**第一步**：$\% \Delta I = (10000 - 8000)/8000 = 25\%$。
**第二步**：$\% \Delta Q = (6-4)/4 = 50\%$。
**第三步**：$E_i = 50\% / 25\% = 2.0$。

**读结果**：$E_i = 2.0 > 1$，**下馆子是奢侈品**——收入涨 1%，下馆子次数涨 2%。

**再算一个**：小王月收入涨 25%，每月买泡面从 4 包掉到 2 包（跌 50%）。

- $\% \Delta Q = (2-4)/4 = -50\%$；
- $E_i = -50\% / 25\% = -2.0$；
- **泡面是低档品**——收入涨反而少买。

### 3.2 交叉弹性

**问题**：喜茶从 25 涨到 30（涨 20%），蜜雪冰城销量从 100 杯涨到 130 杯（涨 30%）。

- $\% \Delta P_y$（喜茶价格变）= 20%；
- $\% \Delta Q_x$（蜜雪销量变）= 30%；
- $E_{xy} = 30\% / 20\% = 1.5$。
- **正交叉弹性，两者是替代品**。

**再算一个**：奶茶从 15 涨到 18（涨 20%），珍珠销量从 50 份掉到 40 份（跌 20%）。

- $\% \Delta P_y = 20\%$；
- $\% \Delta Q_x = -20\%$；
- $E_{xy} = -20\% / 20\% = -1.0$；
- **负交叉弹性，奶茶和珍珠是互补品**。

**这一步为什么正就是替代、负就是互补？**
- 替代品：Y 涨价 → 消费者跑去买 X → X 销量涨（同方向）；
- 互补品：Y 涨价 → 买 Y 的人少了 → 跟着买 X 的人也少了（反方向）。

## 四、一个完整的数字例子（Python 验证）

**题目**：某城市居民消费数据

| 商品 | 收入涨 10% 时，购买量变动 | 类型 |
|------|---------------------------|------|
| 大米 | +2% | 必需品 |
| 奶茶 | +15% | 奢侈品 |
| 泡面 | -5% | 低档品 |

**问题**：
(1) 算每种商品的收入弹性；
(2) 当城市人均收入从 5 万涨到 6 万，预计每种商品销量变动多少？

**手算**：

(1)
- 大米 $E_i = 2\%/10\% = 0.2$；
- 奶茶 $E_i = 15\%/10\% = 1.5$；
- 泡面 $E_i = -5\%/10\% = -0.5$。

(2) 收入涨 20%：
- 大米销量变 = 0.2 × 20% = +4%；
- 奶茶销量变 = 1.5 × 20% = +30%；
- 泡面销量变 = -0.5 × 20% = -10%。

**Python 验证**：

```python
goods = {
    '大米': {'%ΔQ': 2, '%ΔI': 10},
    '奶茶': {'%ΔQ': 15, '%ΔI': 10},
    '泡面': {'%ΔQ': -5, '%ΔI': 10},
}

income_change = 20  # 收入涨 20%

for name, d in goods.items():
    ei = d['%ΔQ'] / d['%ΔI']
    pred = ei * income_change
    if ei < 0:
        category = '低档品'
    elif ei < 1:
        category = '必需品'
    else:
        category = '奢侈品'
    print(f"{name}: Ei = {ei:.2f} ({category}), 收入涨20%时销量变 {pred:+.1f}%")
```

输出：
```
大米: Ei = 0.20 (必需品), 收入涨20%时销量变 +4.0%
奶茶: Ei = 1.50 (奢侈品), 收入涨20%时销量变 +30.0%
泡面: Ei = -0.50 (低档品), 收入涨20%时销量变 -10.0%
```

## 五、什么时候能用？（前提条件）

1. **其他条件不变**：只看收入或别的商品价格，其他因素（偏好、人口、季节）不动；
2. **消费者是理性的**：收入涨了会按偏好重新选择；
3. **时间维度明确**：长期弹性比短期大（消费者有时间调整习惯）。

---

## 六、什么时候不能用？（易错点）

1. **把低档品和劣等品混为一谈**：低档品不是"质量差"，而是"收入涨了就少买"——比如拼多多、泡面、公交。
2. **必需品和奢侈品没有绝对边界**：对富豪来说，奶茶是必需品；对贫困学生来说，奶茶是奢侈品。弹性要分人群估。
3. **替代品和互补品是动态的**：微信出现后，短信和电话从互补变替代；电动车起来后，汽油和汽车从互补变替代。
4. **交叉弹性 ≠ 因果**：Y 涨价 X 销量涨，可能是 Y 和 X 都被第三个因素（比如流行趋势）推高，要做稳健性检验。

---

## 七、容易和什么搞混？

| 概念 | 一句话 | 公式 |
|------|--------|------|
| **价格弹性** | 自己价变 1%，自己量变多少 | $\Delta Q/Q \div \Delta P/P$ |
| **收入弹性** | 收入变 1%，自己量变多少 | $\Delta Q/Q \div \Delta I/I$ |
| **交叉弹性** | 别人价变 1%，自己量变多少 | $\Delta Q_x/Q_x \div \Delta P_y/P_y$ |
| **供给弹性** | 自己价变 1%，供给量变多少 | $\Delta Q_s/Q_s \div \Delta P/P$ |

## 八、在论文里怎么用？

### 8.1 消费升级/降级研究（最常见）

**题目例**：《中国居民消费结构升级的测度——基于收入弹性的分析》
- 模型：$\ln Q_k = \alpha_k + \beta_k \ln I + \gamma X + \varepsilon$，其中 $k$ 是食品、衣着、居住、交通、文教医疗等消费类别；
- $\beta_k$ 就是第 $k$ 类商品的收入弹性；
- 比较不同年份 $\beta_k$ 的变化：如果食品 $\beta$ 下降、文教娱乐 $\beta$ 上升，说明消费升级；
- 政策含义：随着收入增长，应该重点投资文教娱乐、健康产业。

### 8.2 产业结构预测

- 一个国家食品 $E_i < 1$，工业 $E_i \approx 1$，服务 $E_i > 1$；
- 所以收入增长时，服务业占比会越来越大——这就是**配第-克拉克定理**；
- 论文里用各省面板数据验证这个定理。

### 8.3 市场竞争分析

**题目例**：《网约车与出租车的替代关系研究——基于交叉弹性的证据》
- 用滴滴价格变动对出租车订单量的影响估交叉弹性；
- 如果 $E_{xy} > 0$ 且显著，说明两者是替代品；
- 政策含义：监管不能只盯出租车，网约车涨价比出租车涨价影响更大。

### 8.4 雾霾/环保政策

- 汽油和汽车是互补品；
- 提高油价 → 汽车销量跌 → 雾霾减少；
- 估汽油的交叉弹性（对汽车销量），用来评估燃油税的减排效果。

**本科生常见踩坑**：
- 把"必需品"和"弹性小"直接划等号——必需品是 $0<E_i<1$，不是价格弹性小；
- 用全国平均收入弹性套到具体省份——东部沿海和西部农村消费结构完全不同；
- 没控制价格只回归收入——收入和价格经常联动（通胀），不控制会偏误；
- 把交叉弹性正的都叫替代品——要排除"共同被第三方因素推高"的情况。


**📊 对应统计方法**：

- [[../03_相关与回归/05_多元线性回归|多元线性回归]] —— 同时放入自身价格、收入、相关品价格，一次回归同时估出需求价格弹性、收入弹性和交叉弹性。
- [[../03_相关与回归/09_虚拟变量|虚拟变量]] —— 用虚拟变量区分必需品/奢侈品、城乡、收入分组，比较不同人群的弹性差异。

## 九、现实意义

- **为什么拼多多越卖越好？** 经济下行预期下，消费者感觉"未来收入要降"，低档品需求反升——口红效应。
- **为什么蜜雪冰城 2020 年后爆发？** 喜茶奈雪贵了，消费者收入预期下降，转向平价奶茶——替代品弹性在起作用。
- **为什么油价涨了电动车卖疯了？** 汽油和电动车交叉弹性为正（替代关系）。
- **为什么打印机便宜墨盒贵？** 互补品定价策略：打印机便宜吸引你买，然后靠墨盒持续赚钱。

## 十、速记卡

> **收入弹性 $E_i$**：收入涨 1%，购买量变百分之几。
> - 负 = 低档品（泡面）；
> - 0~1 = 必需品（米盐）；
> - >1 = 奢侈品（旅游、奶茶）。
>
> **交叉弹性 $E_{xy}$**：Y 涨价 1%，X 销量变百分之几。
> - 正 = 替代品（喜茶 vs 蜜雪）；
> - 负 = 互补品（奶茶 vs 珍珠）。
>
> **回归里**：$\ln Q = \alpha + \beta \ln I + ...$，$\beta$ 就是收入弹性。
