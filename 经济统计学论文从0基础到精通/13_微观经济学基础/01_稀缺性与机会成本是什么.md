# 01 稀缺性与机会成本是什么？（小白版）

## 一、为什么要学这个？

你打开外卖 APP，满减券 25-12、35-18、50-25——你手里只有 30 块，选哪个？
这就是经济学最底层的问题：**钱就这么多，你还想吃爽，怎么办？**

- **时间稀缺**：今晚 3 小时，是写论文、刷剧、还是打游戏？选了一个，另外两个就没了；
- **钱稀缺**：一个月 4000 生活费，房租 1500，吃饭 1500，剩下 1000 能买奶茶还是买衣服？
- **数据稀缺**：写论文时样本只有 300 个，是全放回归还是分样本？

**不学会怎样？**
你会以为"成本就是我花出去的钱"——错。**真正的成本是你为了它放弃的最好那个东西。**
论文里说"教育投资的成本"，你写"学费"就太浅了，导师会追问："那不上学去打工能赚的工资呢？"——那叫**机会成本**，是人力资本理论的核心。

---

## 二、是什么？

### 生活比喻：你的银行卡就是被切的蛋糕

你这个月有 3000 块零花钱，想象成一个圆蛋糕：

```
      3000 块
     /        \
    /  蛋糕    \
   |  切三块：  |
   |  吃 / 玩 / 存 |
```

- **稀缺性**：这个蛋糕就这么大，你切多了"吃"，"玩"那块就小了；
- **机会成本**：你切给"吃"1500，意味着你放弃了拿这 1500 去"玩"能买到的最爽体验——**那个没吃到的爽，就是这 1500 块的机会成本**。

### 严格定义

> **稀缺性（Scarcity）**：人类欲望无限，而满足欲望的资源（时间、钱、劳动力、自然资源）有限，这种"想要的比能给的多"的矛盾，就是稀缺性。
>
> **机会成本（Opportunity Cost）**：把某种资源用于某用途时，**所放弃的其他用途中价值最高的那一个**，就是该用途的机会成本。

注意三个关键词：**所放弃的、其他用途中、价值最高的**——不是你放弃的所有东西加起来，而是"最好的那个备胎"。

### 符号表

| 符号 | 怎么读 | 是什么 | 生活类比 |
|------|--------|--------|----------|
| $OC$ | "opportunity cost" | 机会成本 | 选了火锅放弃的那家烤肉的快乐 |
| $r$ | "r" | 一般利率/贴现率（后面跨期决策用） | 存银行的利息 |
| $NPV$ | "net present value" | 净现值 | 未来能赚的钱折到今天值多少 |

## 三、公式怎么来的？（手把手推）

### 3.1 机会成本的基本公式

假设你有 **2 个小时**，可以做三件事：

| 选项 | 收益（你主观打分） |
|------|---------------------|
| A. 写论文 | 100 分（写完有成就感） |
| B. 打游戏 | 80 分 |
| C. 刷剧 | 60 分 |

**第一步**：选 A（写论文）。
**第二步**：放弃了 B 和 C。
**第三步**：放弃的选项中价值最高的是 B（80 分）。
**所以选 A 的机会成本 = 80 分**。

写成式子：

$$OC(A) = \max\{收益(B), 收益(C)\} = \max\{80, 60\} = 80$$

**这一步为什么是取 max 而不是加和？**
因为这 2 个小时你**同一时间只能干一件事**。放弃 B 和放弃 C 不是叠加的——你不会因为没打游戏又没刷剧而双倍痛苦，你最痛的是没打成游戏（80 分），没刷剧（60 分）相对已经没那么痛了。所以机会成本只数"最爽的那个备胎"。

### 3.2 上大学的机会成本怎么算？

很多人算"上大学成本 = 学费 + 生活费"，这是错的。

**第一步**：上大学 4 年，学费 6000/年 × 4 = 24000；
**第二步**：生活费 20000/年 × 4 = 80000（但你就算不上学也得吃饭住房子，所以生活费不算增量成本——这是沉没成本思维，后面讲）；
**第三步**：如果不上学，你高中毕业直接打工，平均月薪 4000，4 年 = 4000 × 12 × 4 = 192000；
**第四步**：这 192000 是**放弃的最高收入**，就是机会成本。

$$OC(\text{上大学}) = \underbrace{24000}_{学费} + \underbrace{192000}_{\text{放弃的工资}} = 216000 \text{ 元}$$

**对比一下**：只算学费是 2.4 万，加上机会成本是 21.6 万——**真实成本是账面的 9 倍**。这就是为什么"读书无用论"一戳就破：你只算了学费，没算放弃的工资，更没算毕业后多赚的工资。

## 四、一个完整的数字例子

**题目**：小王暑假有 2 个月（60 天），三个选择：

- A. 在奶茶店打工：每天 150 元，共 9000 元；
- B. 考驾照：花学费 5000 元，但毕业后拿本；
- C. 在家躺平：0 收入，但爽。

问：
(1) 选 A 的机会成本是多少？
(2) 选 B 的机会成本是多少？
(3) 选 C 的机会成本是多少？

**手算**：

(1) 选 A：放弃 B 和 C。B 的"价值"怎么量？B 要花 5000 拿驾照，净收益不是直接的钱，但我们可以把"拿到驾照"的价值和 C 的爽感放一起比。简化：放弃 B 意味着没拿到驾照（心里给它标价 8000），放弃 C 意味着没躺平（标价 2000）。最高的是 8000。
$$OC(A) = 8000 \text{ 元}$$
但如果直接按"钱"算，放弃 B 还额外花了 5000 学费——所以更准确：选 A 的机会成本 = 放弃拿本的爽 + 省下 5000 学费？这就乱了。

**换个干净点的算法**——把三个选项的"净货币收益"列出来：

| 选项 | 直接货币 | 放弃的 |
|------|----------|--------|
| A | +9000 | 没花 5000 学费（=省了 5000） |
| B | -5000 | 没赚 9000 工资 |
| C | 0 | 没赚 9000 |

(1) 选 A：放弃 B 的"拿本收益"和 C 的"躺平收益"。假设拿本对你值 12000，躺平对你值 3000，最高是 12000。**OC(A) = 12000**。
(2) 选 B：放弃 A（9000）和 C（3000），最高是 9000。**OC(B) = 9000**。
(3) 选 C：放弃 A（9000）和 B（拿本值 12000），最高是 12000。**OC(C) = 12000**。

**Python 验证**：

```python
# 三个选项的主观估值
A = 9000    # 奶茶店打工净收益（元）
B = 12000 - 5000  # 拿本爽感 - 学费 = 7000
C = 3000    # 躺平爽感

options = {'A': A, 'B': B, 'C': C}

def opportunity_cost(chosen):
    others = [v for k, v in options.items() if k != chosen]
    return max(others)

for chosen in ['A', 'B', 'C']:
    print(f"选 {chosen} 的机会成本 = {opportunity_cost(chosen)} 元")
```

输出：
```
选 A 的机会成本 = 7000 元
选 B 的机会成本 = 9000 元
选 C 的机会成本 = 9000 元
```

你看，Python 里 B 的净收益直接算了（12000 爽感 - 5000 学费 = 7000），所以结果更干净。

## 五、什么时候能用？（前提条件）

1. **资源有多种用途**：如果这块地只能种玉米不能干别的，那机会成本就是 0（或者就是种玉米的会计成本）；
2. **资源是稀缺的**：如果时间无限，怎么挥霍都行，谈不上"放弃"；
3. **能比较价值**：虽然主观，但你得能给备胎打分。

---

## 六、什么时候不能用？（易错点）

1. **把会计成本当机会成本**：开奶茶店花了 5 万装修，这是会计成本。但你要是把这笔钱存银行能拿 2000 利息，那 2000 也是机会成本——论文里算"隐性成本"必须算上。
2. **把沉没成本当机会成本**：已经花掉、收不回的钱（比如装修砸了就砸了），不参与未来决策。"来都来了""票都买了"是典型的沉没成本谬误。
3. **算上了所有放弃的选项**：错！只取最高那个备胎。
4. **忽略时间价值**：今年的 1 万和 10 年后的 1 万不一样，要贴现（后面跨期决策讲）。

---

## 七、容易和什么搞混？

| 概念 | 一句话 | 区别 |
|------|--------|------|
| **机会成本** | 放弃的最好备胎 | 前瞻性、主观、决策时用 |
| **会计成本** | 账面上花出去的钱 | 后瞻性、客观、报税用 |
| **沉没成本** | 已经花出去收不回的 | 不影响未来决策 |
| **显性成本** | 真掏腰包的 | 工资、原料、房租 |
| **隐性成本** | 没掏钱但放弃了的 | 自己当老板的工资、自有资金的利息 |

**总成本 = 显性成本 + 隐性成本（=机会成本）**。

---

## 八、在论文里怎么用？

本科生写经济统计学论文，机会成本出现在这几个地方：

1. **人力资本投资（最常见）**：
   - 题目例：《教育回报率的估计——基于 CHIP 数据的明瑟方程》
   - 机会成本怎么用：明瑟方程 $ln W = \beta_0 + \beta_1 S + \beta_2 X + \beta_3 X^2 + \varepsilon$ 里，$S$ 是受教育年限，$\beta_1$ 就是"每多上一年学带来的工资涨幅"——本质就是把"上学的机会成本（放弃的工资）"和"毕业后的额外收益"做对比。
   - 文献综述里必须引 Schultz、Becker 的人力资本理论，里面反复讲"教育成本 = 直接成本 + 机会成本"。

2. **劳动力供给决策**：
   - 题目例：《女性劳动参与率影响因素研究》
   - 机会成本怎么用：已婚女性"在家带娃"的机会成本是她市场工资。工资越高，辞职在家的代价越大，劳动参与率越高——这就是为什么城市高学历女性劳动参与率反而高。

3. **迁徙/打工决策**：
   - 题目例：《农民工外出务工的决策机制——基于托达罗模型》
   - 机会成本 = 农村务农收入；预期城市收入 - 机会成本 = 净迁移收益。

4. **创业研究**：
   - 个体工商户的隐性成本（自己劳动的工资、自有资金利息）必须算，否则利润被高估。

**本科生常见踩坑**：
- 只算学费不算放弃工资 → 被导师批"人力资本理论基础不牢"；
- 把沉没成本（已经花的培训费）当成继续投入的理由 → 典型的沉没成本谬误；
- 用全国平均工资估算机会成本，没考虑个体异质性（同样高中毕业，去上海打工 vs 留农村，工资天差地别）。

## 九、现实意义

- **996 是怎么来的**：互联网大厂把你下班后的时间机会成本压到 0（因为加班有加班费），于是你自愿把所有时间都给公司——但真实的机会成本是你的健康、家庭、副业。
- **为什么年轻人宁愿送外卖也不进工厂**：工厂月薪 5000 包吃住，外卖骑手平均 8000 但累。选外卖的人，机会成本是工厂的 5000；选工厂的人，机会成本是外卖的 8000——每个人对"累"的估值不同，决策就不同。
- **双十一为什么忍不住剁手**：你以为"满减省了 100"，但你为了凑单多买的 200 块没用东西，机会成本是这 200 块能买的别的东西。

---

## 十、速记卡

> **稀缺性 = 想要的 > 能给的。**
> **机会成本 = 选了 A，放弃的所有备胎中最爽的那个。**
> 算成本时永远问一句："我要是不干这个，把时间/钱拿去干别的，最赚的那个能赚多少？"——那才是真成本。
> 上大学的真实成本 = 学费 + 放弃的工资，不是只算学费。
