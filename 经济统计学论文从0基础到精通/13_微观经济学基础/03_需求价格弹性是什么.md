# 03 需求价格弹性是什么？（小白版·重点篇）

## 一、为什么要学这个？

奶茶店老板最关心的问题：**我涨价 1 块，销量会掉多少？**

- 一杯奶茶从 15 涨到 18（涨 20%），销量从 100 掉到 80（掉 20%）——那我总收入没变，涨不涨无所谓；
- 如果销量从 100 掉到 50（掉 50%）——涨价反而亏，不能涨；
- 如果销量从 100 掉到 95（掉 5%）——涨价爽爆了，赶紧涨。

这就是**需求价格弹性**在回答的问题：**价格变动 1%，需求量反向变动百分之几？**

**不学会怎样？**
- 你写论文做回归，跑出价格系数 -0.5，不知道这是"弹性大"还是"弹性小"；
- 你不知道为什么盐涨价 10 倍大家还得买（弹性小），为什么奶茶涨价 2 块大家就跑了（弹性大）；
- 论文里写"粮食价格上涨对农民收入的影响"，连"谷贱伤农"的道理都讲不清。

**这一篇是本科论文里最常被要求用到的弹性概念**，奶茶定价手算 + Python 验证都要走一遍。

---

## 二、是什么？

### 生活比喻：弹性就是"反应强度"

想象两个人被针扎了一下：

- **张三**：针尖刚碰皮就跳起来大叫——反应剧烈（弹性大）；
- **李四**：扎深了才动一下——反应迟钝（弹性小）。

**需求价格弹性**就是消费者被价格"扎"了之后，购买量反应有多剧烈：
- 奢侈品被涨价扎一下，反应剧烈（弹性 >1）；
- 盐、米被涨价扎一下，几乎没反应（弹性 <1）。

### 严格定义

> **需求价格弹性（Price Elasticity of Demand）$E_d$**：在其他条件不变时，**需求量变动的百分比**除以**价格变动的百分比**。
>
> $$E_d = \frac{\% \Delta Q_d}{\% \Delta P} = \frac{\Delta Q_d / Q_d}{\Delta P / P}$$
>
> 因为需求曲线向右下倾斜，$\Delta Q_d$ 和 $\Delta P$ 反方向，所以 $E_d$ 是负数。经济学上习惯**取绝对值**报告，写成 $|E_d|$。

### 弹性的五种类型

| $|E_d|$ | 名字 | 例子 | 涨价后总收入 |
|--------|------|------|--------------|
| = 0 | 完全无弹性 | 救命药、死刑犯的断头饭 | 涨多少赚多少 |
| < 1 | 缺乏弹性 | 盐、米、卫生纸 | 涨价总收入涨 |
| = 1 | 单位弹性 | 少见的理论情形 | 涨价总收入不变 |
| > 1 | 富有弹性 | 奶茶、旅游、奢侈品 | 涨价总收入跌 |
| = ∞ | 完全弹性 | 完全竞争市场里的单个农户 | 涨一分钱都卖不掉 |

### 符号表

| 符号 | 怎么读 | 是什么 | 生活类比 |
|------|--------|--------|----------|
| $E_d$ | "E d" | 需求价格弹性 | 消费者对价格的反应强度 |
| $\Delta Q_d$ | "delta Q d" | 需求量的变动量 | 多买或少买了几杯 |
| $\Delta P$ | "delta P" | 价格变动量 | 涨了几块 |
| $P, Q$ | "P, Q" | 价格、需求量 | 当前价、当前销量 |

## 三、公式怎么来的？（手把手推）

### 3.1 为什么要用"百分比"而不是绝对值？

假设两种商品：
- 盐：从 2 元涨到 2.2 元（涨 0.2 元），销量从 1000 斤掉到 990 斤（掉 10 斤）；
- 奶茶：从 15 元涨到 15.2 元（涨 0.2 元），销量从 100 杯掉到 50 杯（掉 50 杯）。

**用绝对值比**：销量掉了 10 vs 50，看不出啥。
**用百分比比**：
- 盐：涨 0.2/2 = 10%，掉 10/1000 = 1%，弹性 = 1%/10% = 0.1；
- 奶茶：涨 0.2/15 = 1.33%，掉 50/100 = 50%，弹性 = 50%/1.33% = 37.5。

**这一步为什么用百分比？**
因为盐本来就便宜（2 块），涨 0.2 块就是涨了一大截；奶茶本来就贵（15 块），涨 0.2 块只是零头。**用百分比才能把"便宜商品的小变动"和"贵商品的大变动"放到同一把尺子上量。**这跟货币单位无关——你换成美元、人民币、日元，百分比都一样。

### 3.2 弧弹性（中点公式）

**问题**：从 P=15 涨到 P=18，和从 P=18 跌到 P=15，用起终点算弹性结果不一样。

- 从 15 涨到 18：
  - $\% \Delta P = (18-15)/15 = 20\%$
  - 销量从 100 掉到 80：$\% \Delta Q = (80-100)/100 = -20\%$
  - 弹性 = -20% / 20% = -1
- 从 18 跌到 15：
  - $\% \Delta P = (15-18)/18 = -16.7\%$
  - 销量从 80 涨到 100：$\% \Delta Q = (100-80)/80 = 25\%$
  - 弹性 = 25% / -16.7% = -1.5

**同样一段路，来回算不一样**——这不行。

**解决办法：用中点**。把起点和终点的平均值当分母：

$$E_d = \frac{(Q_2 - Q_1) / \frac{Q_1+Q_2}{2}}{(P_2 - P_1) / \frac{P_1+P_2}{2}}$$

代入上面例子：
- $\% \Delta Q = (100-80)/90 = 22.2\%$
- $\% \Delta P = (18-15)/16.5 = 18.2\%$
- 弹性 = -22.2% / 18.2% = -1.22

**为什么用中点？** 因为"从 A 到 B"和"从 B 到 A"是同一段，弹性必须一样才对称。中点公式让方向无关。

### 3.3 点弹性

当价格变化非常小（微积分意义上），中点就变成导数：

$$E_d = \frac{dQ}{dP} \cdot \frac{P}{Q}$$

**这一步怎么来的？**
把弧弹性公式里的 $\Delta$ 想成无穷小，$\Delta Q/\Delta P$ 就变成导数 $dQ/dP$；分母的平均 Q、平均 P 就收敛到当前点的 P、Q。

### 3.4 弹性和总收入的关系

总收入 $TR = P \times Q$。

- 涨价：P 涨了，但 Q 掉了，TR 是涨还是跌？取决于谁动得猛。
- 如果 $|E_d| > 1$（Q 掉得比 P 涨得猛），涨价 → TR 跌；
- 如果 $|E_d| < 1$（P 涨得比 Q 掉得猛），涨价 → TR 涨；
- 如果 $|E_d| = 1$，TR 不变。

**推导**：
$$\frac{dTR}{dP} = \frac{d(P \cdot Q)}{dP} = Q + P \cdot \frac{dQ}{dP}$$
提公因子 Q：
$$= Q \left(1 + \frac{P}{Q} \cdot \frac{dQ}{dP}\right) = Q(1 + E_d)$$

**这一步怎么读**：TR 对 P 的导数 = Q(1+E_d)。因为 E_d 是负数，当 |E_d| < 1 时，1+E_d > 0，TR 随 P 涨而涨；当 |E_d| > 1 时，1+E_d < 0，TR 随 P 涨而跌。

**这就是"薄利多销"的数学根据**——富有弹性的商品，降价能多卖货，总收入反而涨。

## 四、一个完整的数字例子（奶茶店手算 + Python）

**题目**：喜茶某款多肉葡萄，价格和销量数据：

| | 价格 P（元） | 销量 Q（杯/天） |
|---|---|---|
| 涨价前 | 25 | 200 |
| 涨价后 | 30 | 160 |

问：
(1) 用起点法算弹性；
(2) 用中点法算弹性；
(3) 判断富有还是缺乏弹性；
(4) 涨价后总收入涨了还是跌了？

**手算**：

(1) 起点法（以 P=25 为基）：
- $\% \Delta P = (30-25)/25 = 5/25 = 20\%$
- $\% \Delta Q = (160-200)/200 = -40/200 = -20\%$
- $E_d = -20\% / 20\% = -1.0$

(2) 中点法：
- $\bar P = (25+30)/2 = 27.5$
- $\bar Q = (200+160)/2 = 180$
- $\% \Delta P = 5/27.5 = 18.18\%$
- $\% \Delta Q = -40/180 = -22.22\%$
- $E_d = -22.22\% / 18.18\% = -1.22$

(3) $|E_d| = 1.22 > 1$，**富有弹性**。

(4) 涨价前 TR = 25 × 200 = 5000 元；
涨价后 TR = 30 × 160 = 4800 元；
**TR 跌了 200 元**——符合"富有弹性商品涨价总收入跌"的规律。

**Python 验证**：

```python
# 输入数据
P1, Q1 = 25, 200
P2, Q2 = 30, 160

# (1) 起点法
ed_start = ((Q2 - Q1) / Q1) / ((P2 - P1) / P1)
print(f"起点法弹性 = {ed_start:.3f}")

# (2) 中点法
P_bar = (P1 + P2) / 2
Q_bar = (Q1 + Q2) / 2
ed_mid = ((Q2 - Q1) / Q_bar) / ((P2 - P1) / P_bar)
print(f"中点法弹性 = {ed_mid:.3f}")

# (3) 判断
print(f"|Ed| = {abs(ed_mid):.2f} -> {'富有弹性' if abs(ed_mid) > 1 else '缺乏弹性'}")

# (4) 总收入
TR1 = P1 * Q1
TR2 = P2 * Q2
print(f"涨价前 TR = {TR1} 元, 涨价后 TR = {TR2} 元, 变化 = {TR2 - TR1} 元")
```

输出：
```
起点法弹性 = -1.000
中点法弹性 = -1.222
|Ed| = 1.22 -> 富有弹性
涨价前 TR = 5000 元, 涨价后 TR = 4800 元, 变化 = -200 元
```

**手算和 Python 一致 ✅**。

## 五、什么时候能用？（前提条件）

1. **其他条件不变**：收入、偏好、替代品价格都没变，只看 P 和 Q；
2. **商品有替代品可比较**：完全无替代的商品（救命药）弹性接近 0；
3. **时间范围明确**：短期弹性小，长期弹性大（消费者换习惯需要时间）。

**弹性大小的决定因素**：
- **替代品多少**：替代品越多，弹性越大（奶茶有喜茶、奈雪、蜜雪、自己泡——弹性大）；
- **必需品 vs 奢侈品**：必需品弹性小，奢侈品弹性大；
- **支出占收入比重**：占比越大弹性越大（买车弹性大、买牙签弹性小）；
- **时间长短**：长期弹性大于短期。

## 六、什么时候不能用？（易错点）

1. **把斜率当弹性**：$Q_d = a - bP$ 的斜率是 $-b$，但弹性 $= -b \cdot P/Q$，在直线上每一点弹性都不一样（从 ∞ 到 0）。
2. **吉芬商品弹性为正**：违反需求定律，别拿正常品公式套。
3. **炫耀品弹性为正**：LV 越涨越有人买，这是社会信号需求，不是普通需求。
4. **短期数据估长期弹性**：涨价 1 个月销量掉一点，3 个月后消费者换习惯了销量掉更多——用短期数据估出来的弹性偏小。
5. **跨商品种类比弹性**：盐弹性 0.1，奶茶弹性 2.0，直接比"盐比奶茶"没意义，要在同一类商品内部比。

## 七、容易和什么搞混？

| 概念 | 一句话 | 区别 |
|------|--------|------|
| **需求价格弹性** | P 变 1%，Q 变百分之几 | 本文主角 |
| **需求收入弹性** | 收入变 1%，Q 变百分之几 | 下一篇 |
| **需求交叉弹性** | 别的商品 P 变 1%，本商品 Q 变百分之几 | 下一篇 |
| **供给价格弹性** | P 变 1%，供给量变百分之几 | 厂商视角 |
| **斜率** | $\Delta Q / \Delta P$ | 绝对量比，不是百分比 |
| **弧弹性 vs 点弹性** | 一段 vs 一点 | 数据离散用弧，连续用点 |

## 八、在论文里怎么用？（重点）

**这是本科生实证论文最常用的弹性概念**，没有之一。

### 8.1 最经典的回归形式：双对数模型

```
ln Q = α + β · ln P + γ X + ε
```

- 这里 $\beta$ 就是需求价格弹性（因为对数的差就是百分比）；
- 理论预期 $\beta < 0$（需求定律）；
- $|\beta| > 1$ 富有弹性，$|\beta| < 1$ 缺乏弹性。

**题目例**：《中国城镇居民食品需求弹性研究——基于 CHIP 数据》
- 被解释变量：ln(食品支出)
- 核心解释变量：ln(食品价格)
- 控制变量：ln(收入)、家庭规模、年龄、地区虚拟变量
- 结果：β = -0.3（食品是必需品，缺乏弹性）✅ 符合理论

### 8.2 弹性在政策分析里的角色

**题目例**：《成品油消费税对居民交通消费的影响》
- 油价从 7 元涨到 8 元（涨 14%）；
- 估出 $E_d = -0.2$；
- 消费量变动 = -0.2 × 14% = -2.8%；
- 政策含义：涨税对开车量影响不大，但能增加财政收入（因为缺乏弹性）。

**题目例**：《烟草税控烟效果评估》
- 香烟 $E_d$ 大约 -0.4（短期）到 -0.8（长期）；
- 涨价 100%，消费量降 40%~80%；
- 这就是 WHO 推荐"烟草税是最有效的控烟手段"的根据。

### 8.3 弹性和"谷贱伤农"

- 粮食 $E_d \approx 0.1 \sim 0.2$（极缺乏弹性）；
- 丰收 → 供给右移 → 均衡价暴跌；
- 因为需求曲线几乎垂直，价格跌 20%，销量只涨 2%；
- 总收入 = P × Q = 跌 20% × 涨 2% = 净跌 18%；
- **农民越丰收越穷**——这就是国家粮食保护价收购的理论基础。

**本科生常见踩坑**：
- 把回归系数 $\beta$ 直接当"价格涨 1 元销量变多少"——错，双对数模型里 $\beta$ 就是弹性；
- 没区分弧弹性和点弹性：离散数据用弧弹性，连续数据用点弹性；
- 用全国汇总数据估弹性，没考虑城乡差异、收入分组——高收入人群和低收入人群对同一种商品的弹性天差地别；
- 把弹性和斜率混为一谈——导师问"你的需求曲线斜率是多少"和"弹性是多少"，答案不一样。

## 九、现实意义

- **航空公司差别定价**：商务客弹性小（必须出差），旅游客弹性大（随时可以换时间）。所以头等舱贵、提前订票便宜——用价格歧视榨取弹性小的乘客的剩余。
- **双十一**：商家降价 50%，销量翻 5 倍——因为消费者对"便宜多少"反应剧烈（弹性 >1），但只在双十一这个时点。
- **疫情期口罩涨价 10 倍还抢**：短期弹性接近 0（必须戴），长期弹性大（找到替代品、囤货）。
- **滴滴高峰加价**：加价 1.5 倍，司机涌出来（供给弹性大），乘客少打车（需求弹性小——因为赶时间）。

---

## 十、速记卡

> **弹性 = 消费者对价格的反应强度。**
> **$E_d = \frac{\Delta Q/Q}{\Delta P/P}$**，取绝对值报告。
> **|E_d| > 1 富有弹性**（奶茶、旅游）→ 降价能多赚；
> **|E_d| < 1 缺乏弹性**（盐、米、药）→ 涨价能多赚。
> **直线上每一点弹性都不一样**（别和斜率搞混）。
> **双对数回归里 $\beta$ 就是弹性**，预期为负。
