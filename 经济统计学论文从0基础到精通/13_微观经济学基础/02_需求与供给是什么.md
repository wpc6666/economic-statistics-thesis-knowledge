# 02 需求与供给是什么？（小白版）

## 一、为什么要学这个？

菜市场里，白菜从 2 块涨到 4 块，你就少买半斤；老板看白菜好卖，明天就多进 200 斤——这就是需求和供给在打架。

- **双十一**：商家把价格压到最低，需求量爆炸（双十一当天订单量是平时几十倍）——需求定律；
- **口罩**：2020 年初口罩 5 块一个没人买，疫情一来 50 块一个还抢——需求曲线整体右移；
- **打车**：晚高峰加价 1.5 倍，司机就涌出来了——供给定律。

**不学会怎样？**
你写论文分析"价格变动对销量的影响"，连"需求曲线是斜率负的"都说不清，被导师一句"你这模型的经济含义是什么"问倒。
**需求供给是微观经济学的牛顿定律**，后面所有弹性、消费者均衡、市场结构全是从这两条线推出来的。

---

## 二、是什么？

### 生活比喻：需求和供给就是天平两端

想象一杆秤：

```
   买家（需求）         卖家（供给）
   想买便宜的           想卖贵的
        \               /
         \             /
          \           /
           \         /
            平衡点（均衡价格）
```

- **需求**：价格越便宜，买家越想买；
- **供给**：价格越贵，卖家越想卖；
- **均衡**：两条线交叉的那个点，买家想买的量 = 卖家想卖的量。

### 严格定义

> **需求（Demand）**：在其他条件不变的情况下，消费者在**每一个价格水平**下**愿意且能够**购买的商品数量。
>
> **需求定律（Law of Demand）**：其他条件不变，价格上升，需求量下降；价格下降，需求量上升。需求曲线向右下方倾斜。
>
> **供给（Supply）**：在其他条件不变的情况下，生产者在**每一个价格水平**下**愿意且能够**出售的商品数量。
>
> **供给定律**：价格上升，供给量上升；价格下降，供给量下降。供给曲线向右上方倾斜。
>
> **均衡价格（Equilibrium Price）**：需求量 = 供给量时的价格，此时没有过剩也没有短缺。

**关键区分**：
- **需求量变动**：商品自身价格变了，导致"沿着需求曲线滑动"；
- **需求变动**：价格以外的因素（收入、偏好、其他商品价格）变了，导致"整条需求曲线平移"。

### 符号表

| 符号 | 怎么读 | 是什么 | 生活类比 |
|------|--------|--------|----------|
| $Q_d$ | "Q d" | 需求量 | 你愿意买的奶茶杯数 |
| $Q_s$ | "Q s" | 供给量 | 奶茶店愿意卖的杯数 |
| $P$ | "P" | 价格 | 一杯多少钱 |
| $I$ | "I" | 收入（Income） | 你这个月工资 |
| $P_r$ | "P r" | 相关商品价格 | 旁边咖啡店的价格 |
| $E_d$ | "E d" | 需求价格弹性 | 价格变 1% 量变百分之几 |

## 三、公式怎么来的？（手把手推）

### 3.1 最简单的需求函数

假设你对奶茶的需求：

- 价格 5 元时，你想买 10 杯/月；
- 价格每涨 1 元，你少买 1 杯；
- 价格 0 元时（白送），你最多买 15 杯（喝到吐）。

**第一步**：设价格为 $P$，需求量为 $Q_d$。
**第二步**：P = 0 时，$Q_d = 15$——这是需求曲线的截距，写成 $a = 15$。
**第三步**：P 每涨 1，$Q_d$ 降 1——斜率 $-b = -1$（b 是正数，前面加负号）。
**第四步**：写成方程：

$$Q_d = a - bP = 15 - P$$

**检验**：P = 5 时，$Q_d = 15 - 5 = 10$ ✅ 对上。

### 3.2 供给函数

奶茶店：

- 价格 3 元时，店老板愿意卖 0 杯（亏本不干）；
- 价格每涨 1 元，老板多做 2 杯。

**第一步**：P = 3 时 $Q_s = 0$，这是供给曲线的"启动价"。
**第二步**：P 每涨 1，$Q_s$ 加 2，斜率 +2。
**第三步**：写成方程：$Q_s = 2(P - 3) = 2P - 6$。

$$Q_s = c + dP = -6 + 2P$$

（这里 $c = -6$，$d = 2$，截距是负的，符合"价格低于 3 元不供给"。）

### 3.3 求均衡价格

均衡条件：$Q_d = Q_s$。

$$15 - P = -6 + 2P$$

**第一步**：把含 P 的移到右边，常数移到左边：
$$15 + 6 = 2P + P$$
$$21 = 3P$$

**第二步**：两边除以 3：
$$P^* = 7$$

**第三步**：把 P = 7 代回需求曲线求均衡数量：
$$Q^* = 15 - 7 = 8$$

**所以**：均衡价格 7 元，均衡数量 8 杯/月。
**手算检验**：P = 7 时，供给 = -6 + 2×7 = 8 ✅ 两边都是 8。

## 四、一个完整的数字例子

**题目**：共享单车的需求和供给函数：

$$Q_d = 1000 - 5P$$
$$Q_s = -200 + 10P$$

问：
(1) 均衡价格和数量？
(2) 政府规定骑行价不能超过 80 元（限制价格），市场会怎样？
(3) 政府规定骑行价不能低于 150 元（支持价格），市场会怎样？

**手算**：

(1) 令 $Q_d = Q_s$：
$$1000 - 5P = -200 + 10P$$
$$1200 = 15P$$
$$P^* = 80$$
$$Q^* = 1000 - 5\times 80 = 600$$

(2) 限制价格 P = 80，正好等于均衡价，市场刚好平衡，不短缺也不过剩。
但如果限到 P = 60：
- $Q_d = 1000 - 300 = 700$
- $Q_s = -200 + 600 = 400$
- 短缺 = 700 - 400 = 300 万辆车抢不到。

(3) 支持价格 P = 150：
- $Q_d = 1000 - 750 = 250$
- $Q_s = -200 + 1500 = 1300$
- 过剩 = 1300 - 250 = 1050 万辆车没人骑，堆在路边。

**Python 验证**：

```python
import matplotlib.pyplot as plt
import numpy as np
plt.rcParams['font.sans-serif'] = ['PingFang SC']
plt.rcParams['axes.unicode_minus'] = False

P = np.arange(0, 200, 1)
Qd = 1000 - 5*P
Qs = -200 + 10*P

plt.figure(figsize=(8,5))
plt.plot(Qd, P, label='需求 Qd=1000-5P', linewidth=2)
plt.plot(Qs, P, label='供给 Qs=-200+10P', linewidth=2)
plt.axhline(80, color='red', linestyle='--', label='均衡价 P*=80')
plt.axhline(60, color='green', linestyle=':', label='限制价 P=60')
plt.axhline(150, color='orange', linestyle=':', label='支持价 P=150')
plt.xlabel('数量 Q（万辆）')
plt.ylabel('价格 P（元）')
plt.title('共享单车供需图')
plt.legend()
plt.grid(alpha=0.3)
plt.savefig('supply_demand.png', dpi=150, bbox_inches='tight')
plt.show()
```

看图：两条线交点就是均衡；限制价在均衡价下方 → 横线和需求的交点在右、和供给的交点在左 → 中间那段水平距离就是短缺。

## 五、什么时候能用？（前提条件）

1. **其他条件不变**（ceteris paribus）：收入、偏好、相关商品价格、技术都不动，只看 P 和 Q 的关系；
2. **完全竞争市场**：单个买家/卖家都是价格接受者，没有垄断；
3. **商品是同质的**：所有奶茶都一样，不然你买喜茶还是蜜雪冰城就不只是价格问题。

---

## 六、什么时候不能用？（易错点）

1. **把"需求量变动"和"需求变动"搞混**：
   - 奶茶涨价 → 你少买 = **沿需求曲线滑动**（需求量变了）；
   - 你月工资翻倍 → 哪怕奶茶价格不变，你也多买 = **整条需求曲线右移**（需求变了）。
2. **吉芬商品**：穷人主食（土豆）涨价，你反而多买，因为吃不起肉了只能吃更多土豆——需求曲线向右上倾斜。但这是极端情况，论文里别拿个例当普遍。
3. **炫耀性商品**（凡勃伦效应）：LV 包越涨越有人买，因为买的就是"贵"本身——不适用普通需求定律。
4. **时间维度**：短期需求弹性小（来不及换习惯），长期弹性大（能换替代品）。论文里用横截面数据还是时间序列，要讲清楚。

---

## 七、容易和什么搞混？

| 概念 | 一句话 | 区别 |
|------|--------|------|
| **需求量变动** | P 变导致 Q 变 | 沿曲线滑动 |
| **需求变动** | 其他因素变导致 P-Q 关系整体变 | 曲线平移 |
| **需求定律** | P↓ → Q↑ | 是个规律 |
| **需求函数** | Q_d = a - bP | 是个公式 |
| **需求曲线** | 函数的几何图画法 | 是张图 |
| **市场需求** | 所有人需求加总 | 个人需求的横向加总 |

## 八、在论文里怎么用？

这是本科生实证论文里**最最常见**的理论基础。

1. **价格与销量的回归（最经典）**：
   - 题目例：《成品油价格变动对居民交通消费的影响》
   - 模型：$ln Q = \alpha + \beta \ln P + \gamma X + \varepsilon$
   - $\beta$ 就是需求价格弹性（下一篇讲），按需求定律预期 $\beta < 0$。
   - 如果跑出来 $\beta > 0$ 还显著，你要警觉：是不是搞反了因果？是不是炫耀品？是不是吉芬商品？

2. **政策评估（支持价格/限制价格）**：
   - 题目例：《最低工资标准对就业的影响——基于供给需求框架》
   - 画图：劳动供给 = 工人愿意干的量，劳动需求 = 企业愿意雇的量。最低工资设高于均衡价 → 劳动供给 > 劳动需求 → 失业。
   - 这就是斯蒂格勒经典论文的逻辑。

3. **减税效应**：
   - 题目例：《新能源汽车购置补贴退坡的影响》
   - 补贴相当于需求曲线右移（每辆车实际付的钱少了）。退坡 = 需求左移。
   - 用差分法或双重差分（DID）估计。

4. **疫情/冲击的供需移动**：
   - 题目例：《新冠疫情对口罩市场的冲击——基于供需均衡分析》
   - 需求右移（恐慌）+ 供给短期跟不上 → 价格暴涨。

**本科生常见踩坑**：
- 把回归出的 $P$ 系数解释成"价格涨 1 元销量变多少"——这是斜率不是弹性，要除以平均 P；
- 没控制"其他条件不变"：收入、人口、替代品价格都不控，直接跑 P→Q，结果被遗漏变量偏误搞乱；
- 分不清"沿曲线滑动"和"曲线移动"，论文里画图时把两条线画成一条。


**📊 对应统计方法**：

- [[../03_相关与回归/02_什么是回归|回归分析]] —— 用回归把需求量对价格、收入等变量做拟合，估计需求曲线和供给曲线的形状。

## 九、现实意义

- **谷贱伤农**：粮食是必需品，需求弹性小。丰收 → 供给右移 → 均衡价暴跌 → 农民总收入反而降。这就是国家要保护价收购的原因。
- **房租管制**：政府规定房租不能涨（限制价格），低于均衡价 → 需求 > 供给 → 租房排队、黑市、二房东加价。
- **疫情口罩**：2020 年初口罩从 0.5 元涨到 5 元，然后工厂加班加点、其他行业转产口罩，供给曲线慢慢右移，价格慢慢回落——这就是供给定律在起作用。

---

## 十、速记卡

> **需求 = 价低多买，供给 = 价高多卖。**
> **两条线一交叉，就是均衡。**
> 价格变 = 沿曲线滑动；其他因素变 = 整条线平移。
> 限制价低于均衡 → 短缺；支持价高于均衡 → 过剩。
> 所有价格类回归的底层，都是这两条线。
