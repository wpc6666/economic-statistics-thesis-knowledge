## 一、为什么要学这个？

**重庆火锅一条街，A 和 B 两家挨着开。A 降 20 块，B 跟不跟？**

- 如果 A 降、B 不降：A 抢走近一半客人，A 赚 2 万、B 亏 5 千；
- 如果两家都降：一起少赚，但客人总量没变，各赚 5 千；
- 如果都不降：各赚 1.5 万。

**A 心里想**："我先降了再说，B 肯定跟——那大家一起惨。但如果我不降，B 偷偷降怎么办？"
这就是**寡头博弈**——几家大厂互相盯着，谁都不敢先动，但谁都怕对方先动。

**不学会怎样？**
你写论文研究"价格战""合谋""反垄断"，连"为什么加油站老是一起涨价""为什么 OPEC 老在吵架"都解释不清。
**寡头是现实中最常见的市场结构**（航空、电信、银行、家电、外卖平台），比完全竞争和完全垄断都常见得多。

## 二、是什么？

### 生活比喻：两个加油站在国道边

- 左边加油站 A、右边加油站 B，相隔 100 米；
- 油价就盯对方：A 涨 1 毛，B 半小时内必跟；A 降 1 毛，B 当天必跟；
- 你是司机，加哪家都一个价——**两家像心照不宣地合谋，但谁也不违法**。

这就是**寡头市场**：少数几家大厂，互相盯着对方的一举一动。

### 严格定义

> **寡头（Oligopoly）**：市场上只有少数几家大厂，产品可以同质（钢铁、石油）或差异（汽车、手机），进入有壁垒。
>
> **寡头的关键特征**：厂商之间**相互依存**——A 的决策直接影响 B 的利润，所以 A 决策时必须猜 B 会怎么反应。
>
> **博弈论（Game Theory）**：研究决策主体行为直接相互作用时的决策均衡。
>
> **囚徒困境（Prisoner's Dilemma）**：博弈双方**各自理性**选择"背叛"，结果比"合作"都差的均衡。
>
> **纳什均衡（Nash Equilibrium）**：给定对方策略，自己没有动机改变策略的状态。

### 囚徒困境的标准支付矩阵

|  | B 合作（不降价） | B 背叛（降价） |
|--|--|--|
| **A 合作**（不降价） | A: 1.5万, B: 1.5万 | A: -0.5万, B: 2万 |
| **A 背叛**（降价） | A: 2万, B: -0.5万 | A: 0.5万, B: 0.5万 |

**怎么读**：每个格子里，前一个数是 A 的利润，后一个是 B 的利润。

**A 怎么想？**
- 如果 B 合作：A 合作赚 1.5 万，背叛赚 2 万 → 背叛更好；
- 如果 B 背叛：A 合作亏 0.5 万，背叛赚 0.5 万 → 背叛更好；
- **不管 B 怎么选，A 背叛都更好——"背叛"是 A 的占优策略**。

**B 怎么想？** 同理，"背叛"也是 B 的占优策略。

**结果**：双方都背叛，各赚 0.5 万——比都合作的 1.5 万差远了。这就是**困境**：理性选择带来集体非理性。

### 符号表

| 符号 | 怎么读 | 是什么 | 生活类比 |
|------|--------|--------|----------|
| $N$ | "number" | 厂商数 | 几家大厂 |
| $\pi_i$ | "pi i" | 厂商 i 的利润 | A 或 B 赚多少 |
| $q_i$ | "q i" | 厂商 i 的产量 | A 或 B 产多少 |
| $BR_i$ | "best response" | 最优反应函数 | A 对 B 的策略怎么回应 |
| $NE$ | "Nash equilibrium" | 纳什均衡 | 谁都不想单方面变 |

## 三、公式怎么来的？（手把手推）

### 3.1 古诺模型（Cournot）——数量竞争

**假设**：两家厂商（A、B），生产同质产品，同时决定产量 $q_A$、$q_B$。市场价格由总需求决定：

$$P = a - b(q_A + q_B)$$

**A 的利润**：

$$\pi_A = P \cdot q_A - c \cdot q_A = (a - b(q_A + q_B)) q_A - c q_A$$

**A 决策时把 B 的产量 $q_B$ 当常数**（这是古诺的关键假设），对 $q_A$ 求导：

$$\frac{\partial \pi_A}{\partial q_A} = a - b(2q_A + q_B) - c = 0$$

**解出 A 的最优反应函数**：

$$q_A = \frac{a - c - b q_B}{2b}$$

**同理，B 的最优反应函数**：

$$q_B = \frac{a - c - b q_A}{2b}$$

**纳什均衡**：两个方程联立。把 $q_B$ 代入 $q_A$：

$$q_A = \frac{a - c}{2b} - \frac{1}{2} \cdot \frac{a - c - b q_A}{2b}$$

化简：

$$q_A = \frac{a-c}{2b} - \frac{a-c}{4b} + \frac{q_A}{4}$$

$$\frac{3}{4} q_A = \frac{a-c}{4b}$$

$$q_A^* = q_B^* = \frac{a-c}{3b}$$

**总产量**：$Q = q_A + q_B = \frac{2(a-c)}{3b}$。
**市场价格**：$P = a - bQ = a - \frac{2(a-c)}{3} = \frac{a+2c}{3}$。

**对比三种情况**（设 a=100, b=1, c=10）：
- 完全竞争：P = c = 10，Q = 90；
- 古诺双寡头：P = (100+20)/3 = 40，Q = 60；
- 完全垄断：MR = 100 - 2Q = 10 → Q = 45，P = 55。

**看！** 寡头的结果（P=40, Q=60）在完全竞争（P=10, Q=90）和完全垄断（P=55, Q=45）之间——**厂商越少，越接近垄断**。

### 3.2 伯特兰模型（Bertrand）——价格竞争

**假设**：两家厂商，生产同质产品，同时定价格 $p_A$、$p_B$。

**消费者行为**：所有人都买价格低的那家；如果 $p_A = p_B$，平分市场。

**A 怎么想？**
- 如果 $p_B > MC$：A 把 $p_A$ 定在比 $p_B$ 低 1 分钱，抢走全部市场；
- 但 B 也这么想——于是价格战一直打到 $p_A = p_B = MC$。

**结论**：哪怕只有两家厂商，只要价格竞争，结果就是完全竞争的价格（P = MC）！

**古诺 vs 伯特兰的区别**：
- 古诺（产量竞争）：寡头结果介于竞争和垄断之间；
- 伯特兰（价格竞争）：寡头结果直接等于完全竞争。

这就是著名的"伯特兰悖论"——两家厂商就足够带来竞争结果。

### 3.3 合谋的卡特尔

如果两家厂商能坐下来谈判，像垄断者一样决策：

- 总产量 $Q_m = \frac{a-c}{2b}$（完全垄断产量）；
- 每家分一半：$q_A = q_B = \frac{a-c}{4b}$；
- 价格 $P_m = \frac{a+c}{2}$（垄断价格）；
- 每家利润 $\pi_i = \frac{(a-c)^2}{8b}$。

**对比古诺**：合谋利润（(a-c)²/8b）> 古诺利润（(a-c)²/9b）。

**但合谋不稳定**：A 偷偷多产（背叛），利润从 (a-c)²/8b 跳到 ... 这就是卡特尔老吵架的原因（OPEC 天天吵）。

## 四、一个完整的数字例子（Python 验证）

**题目**：a=100, b=1, c=10，两家厂商。

问：
(1) 完全竞争、古诺双寡头、完全垄断三种情况下的产量、价格、利润？
(2) 如果形成卡特尔（合谋），产量、价格、利润？
(3) 囚徒困境矩阵：合谋时各家利润 vs 一方背叛时的利润？

**手算**：

(1) 三种情况：

| 情况 | 总产量 Q | 价格 P | 每家利润 |
|------|----------|--------|----------|
| 完全竞争 | 90 | 10 | 0 |
| 古诺 | 60 | 40 | (40-10)×30 = 900 |
| 完全垄断 | 45 | 55 | 仅一家时 1012.5；卡特尔平分各 506.25 |

(2) 卡特尔：
- 总 Q = 45，每家 q = 22.5；
- P = 55；
- 每家利润 = (55-10)×22.5 = 1012.5。

(3) 囚徒困境：
- A 合谋、B 合谋：各赚 1012.5；
- A 背叛（偷偷多产）：A 把产量从 22.5 提到 30（古诺最优），B 还在 22.5；
  - 总产量 = 30 + 22.5 = 52.5；
  - 价格 P = 100 - 52.5 = 47.5；
  - A 利润 = (47.5-10)×30 = 1125；
  - B 利润 = (47.5-10)×22.5 = 843.75；
- 双方都背叛（古诺）：各赚 900。

**支付矩阵**：

|  | B 合谋 | B 背叛 |
|--|--|--|
| **A 合谋** | 1012.5, 1012.5 | 843.75, 1125 |
| **A 背叛** | 1125, 843.75 | 900, 900 |

**验证占优策略**：
- A 看 B 合谋：合谋 1012.5 vs 背叛 1125 → 背叛；
- A 看 B 背叛：合谋 843.75 vs 背叛 900 → 背叛；
- **背叛是 A 的占优策略**。B 同理。
- **纳什均衡**：双方都背叛，各赚 900——比合谋的 1012.5 差。

**Python 验证**：

```python
a, b, c = 100, 1, 10

def profit(qi, qj):
    P = a - b*(qi + qj)
    return (P - c) * qi

# 古诺最优反应
def best_response(qj):
    return (a - c - b*qj) / (2*b)

# 迭代找纳什均衡
qA, qB = 20, 20
for _ in range(20):
    qA = best_response(qB)
    qB = best_response(qA)
print(f"古诺均衡: qA={qA:.1f}, qB={qB:.1f}")
print(f"总产量={qA+qB:.1f}, 价格={a-b*(qA+qB):.1f}")
print(f"每家利润={profit(qA, qB):.1f}")

# 卡特尔
q_cartel = (a-c)/(4*b)
print(f"\n卡特尔: q每家={q_cartel:.1f}, 总产量={2*q_cartel:.1f}")
P_cartel = a - b*2*q_cartel
print(f"价格={P_cartel:.1f}, 每家利润={(P_cartel-c)*q_cartel:.1f}")

# 背叛
qA_dev = 30
qB_coop = 22.5
P_dev = a - b*(qA_dev + qB_coop)
print(f"\nA背叛, B合谋: P={P_dev:.1f}")
print(f"A利润={(P_dev-c)*qA_dev:.1f}, B利润={(P_dev-c)*qB_coop:.1f}")
```

输出：
```
古诺均衡: qA=30.0, qB=30.0
总产量=60.0, 价格=40.0
每家利润=900.0

卡特尔: q每家=22.5, 总产量=45.0
价格=55.0, 每家利润=1012.5

A背叛, B合谋: P=47.5
A利润=1125.0, B利润=843.8
```

## 五、什么时候能用？（前提条件）

1. **厂商数少**（通常 2~10 家）；
2. **进入有壁垒**（不然新厂商涌入，变成完全竞争）；
3. **厂商之间相互依存**（A 的决策直接影响 B）；
4. **博弈规则清楚**：同时决策还是序贯决策？一次博弈还是重复博弈？

**关键修正**：
- **重复博弈**：如果今天背叛了，明天对方会报复（"以牙还牙"），合谋可以维持；
- **序贯博弈**：先发优势（Stackelberg 模型）——先动的厂商能抢更大份额。

---

## 六、什么时候不能用？（易错点）

1. **一次博弈 ≠ 重复博弈**：超市天天见面，合谋能维持；一次性的招标（每次对手不同），合谋很难。
2. **古诺和伯特兰不能混**：产量竞争结果温和，价格竞争结果激烈——选哪个取决于现实中厂商到底在定什么。
3. **合谋违法**：寡头之间"心照不宣"的价格跟随，虽然没有书面协议，但《反垄断法》也能管（"协同行为"）。
4. **囚徒困境不是万能模型**：如果厂商有"利他偏好""长期关系"，合作解能维持。
5. **N=100 就不是寡头了**：厂商太多，互相影响可忽略，退回完全竞争。

---

## 七、容易和什么搞混？

| 概念 | 一句话 | 关键 |
|------|--------|------|
| **古诺模型** | 同时定产量 | 产量竞争，结果介于竞争和垄断 |
| **伯特兰模型** | 同时定价格 | 价格竞争，结果等于完全竞争 |
| **Stackelberg** | 先后定产量 | 先发优势 |
| **卡特尔** | 明着合谋 | 违法，OPEC 是例外（国际协议） |
| **纳什均衡** | 谁都不想单方面变 | 博弈的稳定状态 |
| **占优策略** | 不管对方怎么选，自己都该这么选 | 囚徒困境里"背叛"是占优策略 |

## 八、在论文里怎么用？

### 8.1 价格战实证（最经典）

**题目例**：《中国家电行业价格战研究——基于囚徒困境模型》
- 彩电、空调行业，几家大厂（海尔、格力、美的）；
- 价格战 = 双方都"背叛"，利润集体下降；
- 用**面板数据**看：价格、利润、市场份额的时间序列；
- 统计方法链接：[[../05_内生性与面板/05_面板数据是什么|面板数据]]（厂商 × 年份）、[[../03_相关与回归/01_相关系数|相关系数]]（A 厂价格变化和 B 厂价格变化的相关性——相关高说明跟价行为）。

### 8.2 合谋与反垄断

**题目例**：《中国成品油市场的合谋行为研究》
- 中石油、中石化两家；
- 用"价格跟随"检验：A 调价后 B 在几天内跟调？
- 高频数据（日度油价）回归，看跟价滞后；
- 政策含义：是否触发《反垄断法》调查。

### 8.3 OPEC 行为研究

**题目例**：《OPEC 减产协议的稳定性——基于重复博弈视角》
- 成员国偷偷超产（背叛） vs 守约（合作）；
- 用产量数据看谁在"作弊"；
- 重复博弈模型解释：为什么协议经常破裂但过段时间又恢复。

### 8.4 平台竞争

**题目例**：《外卖平台的双寡头竞争——美团 vs 饿了么》
- 补贴大战 = 囚徒困境（双方都亏钱换份额）；
- 补贴退坡 = 心照不宣的合谋；
- 用用户留存数据、商家抽成数据看均衡。

**本科生常见踩坑**：
- 把寡头等同于垄断——寡头之间有竞争，只是没那么激烈；
- 只用囚徒困境一个模型套所有寡头——还要分古诺、伯特兰、Stackelberg；
- 没说"一次博弈 vs 重复博弈"——这是合谋能否维持的关键；
- 用相关系数测"价格跟随"但没排除成本冲击（原材料涨价大家一起涨不是合谋）。

## 九、现实意义

- **为什么加油站老是一起涨价？** 寡头之间心照不宣的合谋（默契合谋），谁都不想当叛徒。
- **为什么 OPEC 老在吵架？** 沙特想减产保价，尼日利亚偷偷超产——典型的囚徒困境。
- **为什么 2010 年外卖平台烧钱大战？** 囚徒困境：谁先停补贴谁丢份额，只能一起烧。
- **为什么航空燃油附加费一起调？** 几大航空公司寡头默契，一家提了其他必跟。
- **为什么重庆火锅街不打价格战？** 重复博弈 + 地理位置固定，背叛会被邻居报复——合谋能维持。
- **为什么滴滴收购快的后，补贴立刻退坡？** 从双寡头（囚徒困境）变成完全垄断（自己定利润最大化价）。

---

## 十、速记卡

> **寡头 = 几家大厂互相盯**，决策时必须猜对方怎么反应。
> **囚徒困境**：各自理性选背叛，结果比合作都差。
> **占优策略**：不管对方怎么选，自己这么选都更好（囚徒困境里"背叛"是占优策略）。
> **纳什均衡**：给定对方策略，自己没动机单方面变。
> **古诺**（产量竞争）：结果介于竞争和垄断之间。
> **伯特兰**（价格竞争）：结果直接等于完全竞争（哪怕只有两家）。
> **重复博弈**：今天背叛明天被报复，合谋能维持；**一次博弈**：合谋必破裂。
