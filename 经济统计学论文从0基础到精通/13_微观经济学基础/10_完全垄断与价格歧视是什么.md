# 10 完全垄断与价格歧视是什么？（小白版）

## 一、为什么要学这个？

**重庆江北机场，你点一碗小面 38 块，外面店里 8 块——凭什么？**

- 机场里就这几家店；
- 你饿了，下飞机要赶飞机，没时间出去吃；
- 它定多少钱你就得交多少钱。

这就是**垄断势力**在起作用——它不是完全垄断（机场里有 3 家），但因为**位置锁定**，它对你这种"弹性小"的旅客就能狠加价。

**不学会怎样？**
你写论文研究"数字平台垄断""医药专利定价""大数据杀熟"，连"为什么垄断厂商能定高价""价格歧视有哪三种"都讲不清。
**垄断是市场失灵的第一种**，也是《反垄断法》《价格法》监管的核心对象。

---

## 二、是什么？

### 生活比喻：学校里唯一的复印店

- 全校就一家复印店，期末周复印 1 张 1 毛，成本 1 分；
- 学生不复印不行，只能忍；
- 老板还会玩花样：考试周涨价 50%，开学季降价拉新。

### 严格定义

> **完全垄断（Monopoly）**：市场上只有一个卖者，产品没有相近替代品，存在高进入壁垒。
>
> **垄断成因**：
> 1. **规模经济**（自然垄断）：自来水管网，一家最便宜，第二家铺管网就是浪费；
> 2. **专利/版权**：医药专利期内独家生产 20 年；
> 3. **资源控制**：戴比尔斯控制全球钻石矿；
> 4. **政府特许**：烟草、食盐、电网。
>
> **垄断厂商面对的需求曲线**：就是**整个市场需求曲线**（向右下倾斜）——它不是价格接受者，是价格制定者。
>
> **边际收益 MR < P**：因为多卖一件必须给所有商品降价，所以多卖一件的净收益 < 价格。
>
> **利润最大化条件**：MR = MC（和竞争厂商形式一样，但因为 MR < P，结果 P > MC）。
>
> **加成公式**：$P = MC / (1 - 1/|E_d|)$——需求越缺乏弹性，加价越狠。

### 价格歧视的三种类型

| 类型 | 一句话 | 重庆生活例子 |
|------|--------|--------------|
| **一级价格歧视** | 对每个顾客收他愿付的最高价 | 看病议价、二手车砍价、拍卖 |
| **二级价格歧视** | 按购买量/时间定价 | 量大从优、阶梯电价、晚场电影票便宜 |
| **三级价格歧视** | 按顾客群体分市场定价 | 学生票、老人票、商务舱 vs 经济舱 |

**关键条件**：能隔开市场，不让低价顾客倒卖给高价顾客（套利）。

### 符号表

| 符号 | 怎么读 | 是什么 | 生活类比 |
|------|--------|--------|----------|
| $MR$ | "marginal revenue" | 边际收益 | 多卖一件多赚多少 |
| $P$ | "P" | 价格 | 垄断定价 |
| $MC$ | "marginal cost" | 边际成本 | 多做一件多花多少 |
| $E_d$ | "E d" | 需求价格弹性 | 顾客对价格多敏感 |
| $L$ | "Lerner" | 勒纳指数 | $(P-MC)/P$，测垄断势力 |

## 三、公式怎么来的？（手把手推）

### 3.1 为什么垄断厂商 MR < P？

**问题**：垄断厂商面对线性需求曲线 $P = a - bQ$。

**第一步**：总收益 $TR = P \cdot Q = (a - bQ)Q = aQ - bQ^2$。
**第二步**：边际收益 $MR = dTR/dQ = a - 2bQ$。
**第三步**：对比价格 $P = a - bQ$。
**第四步**：MR 截距和 P 一样（都是 a），但斜率是 P 的两倍（-2b vs -b）。
**第五步**：对任意 Q > 0，MR < P。

**直觉解释**：多卖一件，新这件赚 P；但为了多卖这件，原来 Q 件都得降价 $\Delta P$，老商品共损失 $Q \cdot \Delta P$。所以净收益：

$$MR = P - Q \cdot \frac{dP}{dQ} < P$$

**对比完全竞争**：完全竞争厂商面对水平需求曲线，$dP/dQ = 0$，所以 $MR = P$。

### 3.2 加成公式推导（勒纳指数的来源）

**第一步**：从上面 $MR = P + Q \cdot dP/dQ$ 出发。
**第二步**：两边除以 P：

$$\frac{MR}{P} = 1 + \frac{Q}{P} \cdot \frac{dP}{dQ}$$

**第三步**：回忆需求价格弹性定义 $E_d = \frac{dQ}{dP} \cdot \frac{P}{Q}$，所以 $\frac{Q}{P} \cdot \frac{dP}{dQ} = \frac{1}{E_d}$。代入：

$$\frac{MR}{P} = 1 + \frac{1}{E_d}$$

**第四步**：因为 $E_d < 0$（需求曲线向下），写成绝对值 $|E_d|$：

$$MR = P \left(1 - \frac{1}{|E_d|}\right)$$

**第五步**：令 $MR = MC$（利润最大化）：

$$P \left(1 - \frac{1}{|E_d|}\right) = MC$$

**第六步**：解出 P：

$$P = \frac{MC}{1 - 1/|E_d|}$$

**第七步**：移项整理，得勒纳指数：

$$L = \frac{P - MC}{P} = \frac{1}{|E_d|}$$

**读公式**：
- $|E_d| = \infty$（完全弹性）：$P = MC$，回到完全竞争；
- $|E_d| = 2$：$P = 2MC$，加价 100%；
- $|E_d| = 1.2$：$P = 6MC$，加价 5 倍——刚需药就是这种情况。

**关键含义**：**顾客越不敏感（弹性小），垄断厂商加价越狠**。

### 3.3 利润最大化手算

**题目**：需求曲线 $P = 100 - Q$，$MC = 20$（常数）。

**第一步**：$TR = (100-Q)Q = 100Q - Q^2$。
**第二步**：$MR = 100 - 2Q$。
**第三步**：令 $MR = MC$：$100 - 2Q = 20$，$Q^* = 40$。
**第四步**：$P^* = 100 - 40 = 60$。
**第五步**：利润 $= (P - MC) \times Q = (60-20) \times 40 = 1600$。

**对比完全竞争**：$P = MC = 20$，$Q = 80$。
**垄断结果**：产量少一半（40 vs 80），价格高三倍（60 vs 20）——这就是垄断的**无谓损失（Deadweight Loss）**：那些愿付 20~60 元的顾客，在垄断下根本买不到，社会福利被白白浪费。

## 四、一个完整的数字例子（Python 验证）

**题目**：学校复印店面对学生需求 $P_s = 0.5 - 0.001Q_s$，老师需求 $P_t = 1 - 0.002Q_t$，MC = 0.05 元/张。

问：
(1) 不能分隔市场时（统一定价），垄断价和产量？
(2) 完全竞争下的价格和产量？
(3) 能分隔市场（三级价格歧视）时，两个市场分别怎么定价？

**手算**：

(1) 统一定价：
- 合并需求曲线：当 P ≤ 0.5 时，总需求 $Q = Q_s + Q_t = (0.5-P)/0.001 + (1-P)/0.002$。
- 化简：$Q = 500 - 1000P + 500 - 500P = 1000 - 1500P$，反解 $P = 2/3 - Q/1500$。
- $TR = (2/3 - Q/1500)Q = 2Q/3 - Q^2/1500$。
- $MR = 2/3 - 2Q/1500$。
- 令 $MR = MC$：$2/3 - 2Q/1500 = 0.05$ → $2Q/1500 = 0.6167$ → $Q = 462.5$。
- $P = 2/3 - 462.5/1500 = 0.667 - 0.308 = 0.358$ 元/张。

(2) 完全竞争：$P = MC = 0.05$。
- $Q_s = (0.5-0.05)/0.001 = 450$，$Q_t = (1-0.05)/0.002 = 475$，总 $Q = 925$。

(3) 三级价格歧视：
- 学生市场：$MR_s = 0.5 - 0.002Q_s$，令 $= MC = 0.05$ → $Q_s = 225$，$P_s = 0.5 - 0.225 = 0.275$；
- 老师市场：$MR_t = 1 - 0.004Q_t$，令 $= MC = 0.05$ → $Q_t = 237.5$，$P_t = 1 - 0.002×237.5 = 0.525$；
- **老师弹性小（工作必印），定价 0.525；学生弹性大（能印电子版），定价 0.275**。

**Python 验证**：

```python
def monopoly(a, b, mc):
    """需求 P = a - bQ, 求 MR = a - 2bQ = mc 时的 Q, P, 利润"""
    Q = (a - mc) / (2 * b)
    P = a - b * Q
    profit = (P - mc) * Q
    return Q, P, profit

# 统一定价（合并需求）
Q_all, P_all, pi_all = monopoly(2/3, 1/1500, 0.05)
print(f"统一定价: Q={Q_all:.1f}, P={P_all:.3f}, 利润={pi_all:.2f}")

# 完全竞争
Q_comp = (2/3 - 0.05) / (1/1500)
print(f"完全竞争: Q={Q_comp:.1f}, P=0.050")

# 三级价格歧视
Qs, Ps, pi_s = monopoly(0.5, 0.001, 0.05)
Qt, Pt, pi_t = monopoly(1.0, 0.002, 0.05)
print(f"学生市场: Q={Qs:.1f}, P={Ps:.3f}, 利润={pi_s:.2f}")
print(f"老师市场: Q={Qt:.1f}, P={Pt:.3f}, 利润={pi_t:.2f}")
print(f"价格歧视总利润 = {pi_s + pi_t:.2f} vs 统一定价利润 = {pi_all:.2f}")
```

输出：
```
统一定价: Q=462.5, P=0.358, 利润=142.9
完全竞争: Q=925.0, P=0.050
学生市场: Q=225.0, P=0.275, 利润=50.6
老师市场: Q=237.5, P=0.525, 利润=112.8
价格歧视总利润 = 163.4 vs 统一定价利润 = 142.9
```

**结论**：价格歧视让老板多赚 14%（163.4 vs 142.9）——这就是为什么平台想尽办法"千人千价"。

## 五、什么时候能用？（前提条件）

1. **市场上只有一家厂商**（或有强垄断势力）；
2. **没有相近替代品**（否则顾客跑了）；
3. **进入壁垒高**（专利、规模经济、牌照、关键资源）；
4. **价格歧视还要求**：
   - 能隔开市场（学生证、护照、时间窗口）；
   - 不同市场需求弹性不同；
   - 不能倒卖（否则套利者会把低价货倒到高价市场）。

---

## 六、什么时候不能用？（易错点）

1. **有垄断地位 ≠ 能任意涨价**：涨价会吸引潜在竞争者（哪怕暂时没进来，威胁也在），垄断厂商定价要考虑"潜在进入者"。
2. **自然垄断不能简单拆**：自来水拆成 5 家，管网重复铺，成本反而更高。正确做法是**政府监管定价**，而不是拆厂。
3. **价格歧视不总是坏事**：学生票让穷学生也能消费，社会总福利可能改善（一级价格歧视甚至是帕累托有效的——把所有剩余给生产者，但没有无谓损失）。
4. **一级价格歧视几乎做不到**：现实中只能接近（议价、拍卖、定制报价）。
5. **"市场份额大" ≠ 垄断**：还要看进入壁垒和替代品。微信市场份额 90%，但它有替代（QQ、钉钉、支付宝聊天），所以不算反垄断法意义上的"支配地位"。

## 七、容易和什么搞混？

| 概念 | 一句话 | 关键区别 |
|------|--------|----------|
| **完全垄断** | 一家独大 | 市场上就一个卖家 |
| **自然垄断** | 规模经济导致一家最便宜 | 是垄断的一种成因，不是垄断的全部 |
| **寡头垄断** | 几家大厂互相盯 | 下一篇讲，厂商之间有博弈 |
| **价格歧视** | 对不同人收不同价 | 是垄断厂商的定价策略，不是垄断本身 |
| **垄断势力** | 厂商定价高于边际成本的能力 | 用勒纳指数 L 测 |
| **寻租** | 为维护垄断地位花钱 | 游说、行贿、申请专利 |

## 八、在论文里怎么用？

### 8.1 垄断势力测度（勒纳指数法）

**题目例**：《中国数字平台的垄断势力测度——基于勒纳指数的方法》
- 理论基础：$L = (P - MC)/P = 1/|E_d|$；
- 实证：用平台财务数据估 MC（平均成本近似），用需求回归估 $|E_d|$；
- 对比：电商平台 vs 传统零售业的 L 值，判断平台是否拥有超额垄断势力；
- 统计方法链接：[[../03_相关与回归/02_什么是回归|回归分析]]（估计需求弹性）、[[../03_相关与回归/09_虚拟变量|虚拟变量]]（区分平台/传统业）。

### 8.2 三级价格歧视实证（最经典）

**题目例**：《航空公司差别定价的福利效应——基于中国民航数据》
- 理论：不同群体弹性不同，厂商分市场定价；
- 实证：同一航班不同舱位、不同购票时间的价格差异；
- 用**虚拟变量**标记"学生/老人/商务"群体，回归价格差异：
  $$P_{it} = \beta_0 + \beta_1 \cdot \text{商务舱} + \beta_2 \cdot \text{提前天数} + \beta_3 \cdot \text{淡季} + \varepsilon_{it}$$
- $\beta_1$ 就是"商务舱相对经济舱的加价幅度"；
- 统计方法链接：[[../03_相关与回归/09_虚拟变量|虚拟变量]]（分组定价）、[[../06_受限因变量/02_Logit模型|Logit]]（乘客选舱位的选择行为）。

### 8.3 医药专利定价与福利分析

**题目例**：《专利保护期内药品定价的福利分析——以某抗癌药为例》
- 专利 = 临时垄断，垄断价 vs 社会最优价（P=MC）差距；
- 用消费者剩余变化（积分面积）算无谓损失；
- 政策讨论：专利期多长合适？强制许可？医保谈判？

### 8.4 大数据杀熟实证

**题目例**：《在线平台的"千人千价"现象研究——以网约车为例》
- 同一路程，不同用户（新/老、iOS/安卓、消费力）看到不同价格；
- 用**虚拟变量**标记用户群体，回归价格差异；
- 这本质是三级价格歧视（按用户弹性分市场）。

**本科生常见踩坑**：
- 把"市场份额大"等同于"垄断"——还要看进入壁垒；
- 价格歧视只写"价格不同"，没分三种类型，没说"隔开市场"的前提；
- 直接用加成公式但没说清楚 $E_d$ 怎么估（要回归，不是看出来的）；
- 把"自然垄断"和"行政垄断"混为一谈——前者是技术原因，后者是政策原因。

## 九、现实意义

- **为什么电影票有学生票？** 学生弹性大（没钱），商务客弹性小（报销），隔开市场定不同价——三级价格歧视。
- **为什么航空公司提前订票便宜？** 提前订票的多是旅游客（弹性大），临时买票的多是商务客（弹性小）——通过"时间窗口"隔开市场。
- **为什么 12306 没有学生软卧折扣？** 因为能倒卖（学生票买了卖给商务客）——隔开不了市场，价格歧视失败。
- **为什么互联网平台搞大数据杀熟？** 同一商品，老用户（弹性小、懒得换）定价高，新用户（弹性大、要优惠才来）定价低——三级价格歧视。
- **为什么感冒药 OTC 很便宜，但处方药（比如胰岛素）贵到离谱？** 处方药患者没得选（弹性小），垄断药企就能狠加价——这就是为什么要医保谈判。
- **为什么重庆机场餐饮比外面贵 3 倍？** 位置锁定 = 临时垄断，旅客弹性小（赶时间）——机场租金贵也是因为它知道你会被加价。

## 十、速记卡

> **垄断厂商面对向下倾斜的需求曲线**，所以 MR < P。
> **利润最大化**：MR = MC（和竞争形式一样），但因为 MR < P，所以 P > MC。
> **加成公式**：P = MC / (1 - 1/|E_d|)——弹性越小加价越狠。
> **勒纳指数**：L = (P-MC)/P = 1/|E_d|，L 越大垄断势力越强。
> **价格歧视三类型**：一级（每人最高价）、二级（按量）、三级（按群体）。
> **价格歧视前提**：能隔开市场 + 不同群体弹性不同 + 不能倒卖。
> **无谓损失**：垄断下产量比竞争少，那些愿付 P 和 MC 之间的顾客买不到，社会福利被浪费。
