# 05 效用与边际效用递减是什么？（小白版）

## 一、为什么要学这个？

**为什么第一杯奶茶爽到飞起，第三杯想吐？**

- 第一次喝喜茶：100 分爽；
- 第二次喝：50 分爽；
- 第三次喝：10 分爽（还撑）；
- 第四次喝：-20 分（恶心）。

这就是**边际效用递减**——多吃的每一口，带来的爽感越来越少。

**不学会怎样？**
你写论文分析"消费者为什么这么花钱"，连"为什么人们不把所有钱都花在同一种商品上"都解释不清。
**效用最大化**是整个消费者理论的基石，所有需求曲线都从这里推出来。

---

## 二、是什么？

### 生活比喻：吃自助餐

- 你刚坐下：第一盘小龙虾爽到起飞（边际效用 100）；
- 第二盘：还行（60）；
- 第三盘：勉强吃（20）；
- 第四盘：服务员劝你别点了——再吃边际效用为负（吃撑到难受）。

**总效用**是你吃到撑时累计的爽感总和；
**边际效用**是你多吃一盘增加的那点爽感。

### 严格定义

> **效用（Utility, U）**：消费者从商品或服务中获得的**主观满足程度**。
>
> **总效用（Total Utility, TU）**：消费一定数量商品得到的全部满足感。
>
> **边际效用（Marginal Utility, MU）**：**多消费一单位**商品所增加的满足感。
>
> $$MU = \frac{\Delta TU}{\Delta Q}$$
>
> **边际效用递减规律（Law of Diminishing Marginal Utility）**：在其他条件不变时，随着消费者连续消费某种商品，**每多消费一单位带来的边际效用是递减的**。

### 符号表

| 符号 | 怎么读 | 是什么 | 生活类比 |
|------|--------|--------|----------|
| $TU$ | "total utility" | 总效用 | 吃完整顿自助餐的爽感总和 |
| $MU$ | "marginal utility" | 边际效用 | 多吃一盘多爽多少 |
| $Q$ | "Q" | 消费量 | 吃了几盘 |
| $\lambda$ | "lambda 兰姆达" | 货币的边际效用 | 一块钱带来的爽感 |

## 三、公式怎么来的？（手把手推）

### 3.1 从效用函数到边际效用

假设奶茶的效用函数：

$$TU(Q) = 10Q - Q^2$$

**问：第 1 杯、第 2 杯、第 3 杯的边际效用各是多少？**

**第一步**：Q=0 时，TU = 0。
**第二步**：Q=1 时，TU = 10 - 1 = 9。
**第三步**：第 1 杯的 MU = TU(1) - TU(0) = 9 - 0 = 9。
**第四步**：Q=2 时，TU = 20 - 4 = 16。
**第五步**：第 2 杯的 MU = TU(2) - TU(1) = 16 - 9 = 7。
**第六步**：Q=3 时，TU = 30 - 9 = 21。
**第七步**：第 3 杯的 MU = 21 - 16 = 5。

**看出规律**：MU 从 9 → 7 → 5，每次少 2——这就是边际效用递减。

**用微积分直接算**：
$$MU = \frac{dTU}{dQ} = 10 - 2Q$$

- Q=1 时 MU = 8（连续模型）；
- Q=2 时 MU = 6；
- Q=3 时 MU = 4。

（和离散算法差一点，是因为微积分是"无穷小变化"，但趋势一样。）

### 3.2 消费者均衡（等边际原则）

**问题**：你有 20 块，奶茶 5 块一杯，可乐 5 块一瓶。你怎么花？

**核心逻辑**：**最后一块钱花在奶茶上带来的爽 = 花在可乐上带来的爽**，否则你就会把钱从爽的低的那边挪到爽的高的那边。

**写成公式**：

$$\frac{MU_{奶茶}}{P_{奶茶}} = \frac{MU_{可乐}}{P_{可乐}} = \lambda$$

**这一步怎么理解？**
- $MU/P$ = 每花 1 块钱买到的爽；
- 两边相等 = 最后一块钱不管花哪都一样爽；
- $\lambda$ = 每一块钱的"平均爽感"（货币的边际效用）。

**举个数字**：
- 奶茶 MU = 10，P = 5，MU/P = 2；
- 可乐 MU = 8，P = 5，MU/P = 1.6；
- 奶茶每块钱爽 2，可乐每块钱爽 1.6 → 把可乐的钱挪到奶茶上，整体爽感增加；
- 一直挪到两边相等为止。

## 四、一个完整的数字例子（Python 验证）

**题目**：你有 100 块，只能买奶茶（10 元/杯）和披萨（20 元/块）。

效用表：

| 数量 | 奶茶 MU | 披萨 MU |
|------|---------|---------|
| 1 | 50 | 100 |
| 2 | 40 | 80 |
| 3 | 30 | 60 |
| 4 | 20 | 40 |
| 5 | 10 | 20 |

问：买几杯奶茶、几块披萨，效用最大？

**手算（每块钱爽感）**：

| 数量 | 奶茶 MU/P=MU/10 | 披萨 MU/P=MU/20 |
|------|------------------|------------------|
| 1 | 5 | 5 |
| 2 | 4 | 4 |
| 3 | 3 | 3 |
| 4 | 2 | 2 |
| 5 | 1 | 1 |

**注意**：每一行两边的 MU/P 都相等（因为设计的时候披萨的 MU 正好是奶茶的 2 倍，价格也是 2 倍）。

**预算约束**：$10Q_{奶茶} + 20Q_{披萨} = 100$，即 $Q_{奶茶} + 2Q_{披萨} = 10$。

**试几个组合**：
- Q_奶茶=6, Q_披萨=2：60+40=100 ✅，总效用 = (50+40+30+20+10+0) + (100+80) = 150+180 = 330
- Q_奶茶=4, Q_披萨=3：40+60=100 ✅，总效用 = (50+40+30+20) + (100+80+60) = 140+240 = 380
- Q_奶茶=2, Q_披萨=4：20+80=100 ✅，总效用 = (50+40) + (100+80+60+40) = 90+280 = 370

**最大的是 Q_奶茶=4, Q_披萨=3**，总效用 380。此时：
- 奶茶第 4 杯 MU/P = 20/10 = 2；
- 披萨第 3 块 MU/P = 60/20 = 3；

哎不相等？因为离散情况下，最后一块钱花在披萨上（3）比奶茶上（2）爽，但再买一块披萨就超预算了——**离散均衡允许不完全相等，但已经没法改进**。

**Python 验证**：

```python
milk_tea_mu = [50, 40, 30, 20, 10, 0]
pizza_mu = [100, 80, 60, 40, 20, 0]
budget = 100
price_mt = 10
price_pz = 20

best = None
for q_mt in range(0, 11):
    for q_pz in range(0, 6):
        cost = q_mt * price_mt + q_pz * price_pz
        if cost > budget:
            continue
        tu = sum(milk_tea_mu[:q_mt]) + sum(pizza_mu[:q_pz])
        if best is None or tu > best[2]:
            best = (q_mt, q_pz, tu)

print(f"最优组合：奶茶 {best[0]} 杯 + 披萨 {best[1]} 块，总效用 {best[2]}")
```

输出：
```
最优组合：奶茶 4 杯 + 披萨 3 块，总效用 380
```

✅ 和手算一致。

## 五、什么时候能用？（前提条件）

1. **效用可以比较**：基数效用论假设你能给"爽感"打绝对分（100 分、50 分）；
2. **边际效用递减**：每多吃一份，爽感下降（这是心理规律）；
3. **消费者理性**：在预算约束下追求效用最大。

（现实中效用很难绝对打分，后来发展出序数效用论——只比较"哪份组合更好"，不打绝对分，下一篇讲。）

---

## 六、什么时候不能用？（易错点）

1. **把边际效用和总效用搞混**：MU 降但只要 MU > 0，TU 还在涨；MU < 0 时 TU 才开始降。
2. **边际效用递减不是"我吃腻了"**：是连续消费同一种商品时，不是吃撑的时候。
3. **吸毒/赌博**：上瘾品的边际效用不一定递减（越吸越想吸），这个模型不适用。
4. **收藏品**：第一套邮票的爽感不如集齐一整套的爽感——边际效用可能递增。

---

## 七、容易和什么搞混？

| 概念 | 一句话 |
|------|--------|
| **总效用 TU** | 累计爽感 |
| **边际效用 MU** | 多一份的爽感 |
| **边际效用递减** | MU 越吃越小 |
| **消费者均衡** | MU_x/P_x = MU_y/P_y |
| **消费者剩余** | 你愿付的最高价 - 实际付的价（下几篇讲） |

---

## 八、在论文里怎么用？

### 8.1 需求曲线的推导（理论基础）

- 边际效用递减 → 你买得越多，MU 越小 → 你愿意出的价越低 → 需求曲线向右下倾斜；
- 这就解释了"为什么需求曲线向下"——是效用理论的必然结果；
- 文献综述里引 Marshall 的基数效用论。

### 8.2 边际效用递减解释"消费多样化"

**题目例**：《中国居民食品消费多样化研究》
- 为什么人们吃饭不只吃米饭？因为米饭的 MU 递减很快，吃多了爽感掉得快；
- 换菜吃，每种菜的 MU 都还有正的，整体效用更大；
- 用熵指数或多样性指数衡量食品消费的多元化。

### 8.3 消费者剩余与定价

**题目例**：《网约车动态定价的福利分析》
- 消费者剩余 = Σ(愿付价 - 实际价)；
- 高峰加价时，实际价接近消费者愿付价 → 剩余被挤压；
- 用积分公式算消费者剩余的变化。

### 8.4 行为经济学修正

- 现实中人们不是完全理性的效用最大化者；
- 论文里可以引入"参考点依赖""损失厌恶"——Kahneman 的前景理论；
- 比如：同样一杯奶茶，涨价后买就比降价时买感觉贵——损失厌恶。

**本科生常见踩坑**：
- 说"边际效用递减所以总效用递减"——错，MU 降但正的时候 TU 还在涨；
- 把效用当"幸福指数"来回归——效用是抽象概念，不能直接观测，论文里用消费支出、选择偏好做代理；
- 没说清楚"基数 vs 序数"——本科论文大多用序数效用论（下一篇的无差异曲线）。

## 九、现实意义

- **自助餐为什么能赚钱？** 你吃回本的边际效用很快掉到 0，但店家的平均成本是固定的——大部分人吃不回成本。
- **为什么奶茶第二杯半价？** 第二杯的 MU 已经很低，半价刺激你买第二杯；不然第二杯 MU 掉到不值得原价买。
- **为什么游戏要让你"开局爽"？** 让你第一次体验高 MU，上瘾后持续付费。
- **为什么公司给员工发奖金不发商品？** 每个人的 MU 不同，发钱让员工自己选效用最大的东西。

---

## 十、速记卡

> **效用 = 主观爽感。**
> **边际效用 = 多吃一份多爽多少。**
> **边际效用递减 = 第一杯爽，第二杯腻，第三杯吐。**
> **消费者均衡 = MU_x/P_x = MU_y/P_y = λ**——最后一块钱花哪都一样爽。
> MU > 0 时 TU 还在涨，MU < 0 时 TU 才掉。
