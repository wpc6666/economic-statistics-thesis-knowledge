# 11 寡头与博弈论囚徒困境是什么？（小白版）

## 一、为什么要学这个？

**两家奶茶店挨着，要不要打价格战？**

- 如果都不降价：每家月赚 10 万；
- 如果 A 降价 B 不降：A 抢生意赚 15 万，B 亏 2 万；
- 如果都降价：每家月赚 3 万（两败俱伤）。

**最后结果**：A 怕 B 降价自己亏，先降；B 怕 A 降价自己亏，也降——**两家都降到 3 万**，明明合作能赚 10 万。

这就是**囚徒困境**——个人理性导致集体非理性。

**不学会怎样？**
你写论文研究"价格战""合谋""卡特尔""互联网平台竞争"，连"为什么 OPEC 总吵架""为什么 3Q 大战两败俱伤"都解释不清。

---

## 二、是什么？

### 生活比喻：两个小偷被分开审

警察抓了两个小偷，分开审：
- 如果都不招：证据不足，各判 1 年；
- 如果 A 招 B 不招：A 立功释放，B 判 10 年；
- 如果都招：各判 5 年。

**理性选择**：不管对方招不招，我招都更划算（招了是 0 或 5，不招是 10 或 1）→ **都招**，结果各判 5 年——比都不招（1 年）差远了。

### 严格定义

> **寡头（Oligopoly）**：市场上**少数几家大厂商**控制大部分份额。产品可能同质（钢铁）也可能差异（汽车）。
>
> **博弈论（Game Theory）**：研究**策略性决策**——你的最优选择取决于对方怎么选。
>
> **囚徒困境（Prisoner's Dilemma）**：博弈中每个人都有占优策略，但**双方都选占优策略的结果比合作更差**。
>
> **占优策略（Dominant Strategy）**：不管对方怎么选，我这个选择都更优。
>
> **纳什均衡（Nash Equilibrium）**：给定对方策略，每个人都不想改变自己的策略。

### 寡头模型

| 模型 | 一句话 | 例子 |
|------|--------|------|
| **古诺模型** | 同时决定产量 | 可口可乐 vs 百事 |
| **伯川德模型** | 同时决定价格 | 国美 vs 苏宁 |
| **斯塔克尔伯格模型** | 领导者先定，追随者跟 | 华为 vs 小米 |
| **卡特尔** | 合谋定垄断价 | OPEC |

### 符号表

| 符号 | 怎么读 | 是什么 |
|------|--------|--------|
| $Q_1, Q_2$ | "Q 一、Q 二" | 两个寡头的产量 |
| $P$ | "P" | 市场价格 |
| $\pi_1, \pi_2$ | "pi 一、pi 二" | 两个寡头的利润 |

## 三、公式怎么来的？（手把手推）

### 3.1 古诺双寡头模型

**问题**：市场需求 P = 100 - Q，其中 Q = Q1 + Q2。两个厂商 MC 都是 10。

**厂商 1 的利润**：
$$\pi_1 = P \cdot Q_1 - 10 Q_1 = (100 - Q_1 - Q_2)Q_1 - 10Q_1$$

**对 Q1 求导（把 Q2 当给定）**：
$$\frac{\partial \pi_1}{\partial Q_1} = 100 - 2Q_1 - Q_2 - 10 = 0$$
$$Q_1 = \frac{90 - Q_2}{2} = 45 - \frac{Q_2}{2}$$

这是厂商 1 的**反应函数**——你产多少，我最优产多少。

**同理**：$Q_2 = 45 - Q_1/2$。

**联立**：把 Q2 代入 Q1：
$$Q_1 = 45 - \frac{1}{2}(45 - \frac{Q_1}{2}) = 45 - 22.5 + \frac{Q_1}{4}$$
$$\frac{3Q_1}{4} = 22.5$$
$$Q_1 = 30$$

对称地：Q2 = 30。
市场 Q = 60，P = 100 - 60 = 40。
每个厂商利润 = (40-10) × 30 = 900。

**对比**：
- 完全垄断（一个厂商）：Q = 45，P = 55，利润 2025；
- 古诺双寡头：Q = 60，P = 40，每个利润 900，合计 1800；
- 完全竞争：Q = 90，P = 10。

**看规律**：寡头产量介于垄断和竞争之间，价格也介于两者之间。

### 3.2 卡特尔（合谋）

如果两家合谋像一个垄断者：
- 联合利润最大化：Q = 45，P = 55；
- 每家分一半：Q1 = Q2 = 22.5，每家利润 = (55-10)×22.5 = 1012.5。

**但每家都想偷偷多产**：如果 Q2 = 22.5，Q1 的最优反应是 45 - 22.5/2 = 33.75。
- 偷偷多产到 33.75，Q1 利润 = (100-33.75-22.5-10)×33.75 = 33.75×43.75 = 1477；
- 但 Q2 也这么想，最后回到古诺均衡 Q1 = Q2 = 30。

**这就是卡特尔不稳定的原因**——每个人都有欺骗动机。

## 四、一个完整的数字例子（Python 验证）

**题目**：囚徒困境支付矩阵（单位：万元/月）：

| | B 不降价 | B 降价 |
|---|----------|--------|
| **A 不降价** | A=10, B=10 | A=-2, B=15 |
| **A 降价** | A=15, B=-2 | A=3, B=3 |

问：
(1) A 的占优策略？
(2) 纳什均衡？
(3) 如果重复博弈 100 次，结果会怎样？

**手算**：

(1) A 看 B：
- 如果 B 不降价：A 不降价赚 10，A 降价赚 15 → 选降价；
- 如果 B 降价：A 不降价亏 2，A 降价赚 3 → 选降价；
- **不管 B 怎么选，A 都降价** → A 的占优策略是降价。

对称地，B 的占优策略也是降价。

(2) 纳什均衡：双方都降价（3, 3）。
- 给定对方降价，自己不降价亏 2，改了更差 → 没人愿意改。

(3) 有限次重复博弈（100 次）：
- 最后一次（第 100 次）：没有下一次了，双方都背叛；
- 第 99 次：知道第 100 次一定背叛，第 99 次也背叛（因为没法惩罚）；
- 倒推到第 1 次：**每次都背叛**。
- （这就是"倒推归纳法"。）

**Python 验证**：

```python
import numpy as np

# 支付矩阵：actions = [不降价, 降价]
# A 的支付
A_payoff = np.array([[10, -2],
                      [15, 3]])
# B 的支付
B_payoff = np.array([[10, 15],
                     [-2, 3]])

# 找占优策略
for i in range(2):  # A 的两个策略
    if A_payoff[i, 0] > A_payoff[1-i, 0] and A_payoff[i, 1] > A_payoff[1-i, 1]:
        print(f"A 的占优策略: {'不降价' if i==0 else '降价'}")

# 找纳什均衡
print("\n纳什均衡搜索:")
for i in range(2):
    for j in range(2):
        a_best = (A_payoff[i, j] >= A_payoff[1-i, j])
        b_best = (B_payoff[i, j] >= B_payoff[i, 1-j])
        if a_best and b_best:
            print(f"  ({'不降价' if i==0 else '降价'}, {'不降价' if j==0 else '降价'})")
```

输出：
```
A 的占优策略: 降价

纳什均衡搜索:
  (降价, 降价)
```

## 五、什么时候能用？（前提条件）

1. **少数几家厂商**（3~5 家）；
2. **厂商相互依赖**：你的决策影响对方，对方决策反过来影响你；
3. **进入有壁垒**：否则长期会回到完全竞争。

---

## 六、什么时候不能用？（易错点）

1. **无限次重复博弈能走出囚徒困境**："以牙还牙"策略（tit-for-tat）能维持合作——不是所有寡头都打价格战。
2. **产品差异大时，价格战不那么惨烈**：苹果和三星不打价格战，打创新战。
3. **合谋违法**：OPEC 是国际卡特尔，国内卡特尔违反反垄断法。
4. **不要把寡头和垄断竞争混**：寡头是几家，垄断竞争是多家。

---

## 七、容易和什么搞混？

| 概念 | 一句话 |
|------|--------|
| **寡头** | 几家大厂 |
| **卡特尔** | 寡头合谋像垄断者 |
| **囚徒困境** | 个人理性导致集体非理性 |
| **纳什均衡** | 给定对方策略，没人想改 |
| **占优策略** | 不管对方怎么选都最优 |

---

## 八、在论文里怎么用？

### 8.1 价格战实证

**题目例**：《中国家电行业价格战——基于囚徒困境的解释》
- 2000 年代长虹、TCL、康佳反复降价；
- 用古诺模型估计"合谋产量"和"古诺产量"的差距；
- 看厂商的实际产量偏离合谋多少，验证欺骗动机。

### 8.2 合谋稳定性研究

**题目例**：《OPEC 产量配额执行率研究》
- OPEC 给每个成员国定配额；
- 现实中经常超产；
- 用面板数据回归：超产和"未来预期价格""剩余产能"的关系。

### 8.3 平台竞争

**题目例**：《网约车平台的博弈——滴滴 vs 美团》
- 两家都烧钱补贴（伯川德模型）；
- 最后滴滴收购快的、合并优步，一家独大；
- 用博弈论解释"为什么打不下去最后合并"。

### 8.4 创新博弈

**题目例**：《华为和小米的研发投入博弈》
- 两家都投研发（合谋）vs 一家投一家搭便车；
- 用序贯博弈模型解释"为什么头部企业研发投入远超中小企业"。

**本科生常见踩坑**：
- 把纳什均衡等同于最优解——囚徒困境里纳什均衡（都背叛）比合作差；
- 把重复博弈当成一次性博弈——无限次重复能合作；
- 没说清楚"厂商相互依赖"这个寡头的核心特征。

## 九、现实意义

- **为什么 OPEC 总吵架？** 每个成员国都想偷偷多产（高价下多产多赚），但所有人都多产价就崩。
- **为什么航空公司不轻易打价格战？** 一次价格战让所有公司亏损，大家都记得教训。
- **为什么外卖平台补贴大战停了？** 烧钱补贴是伯川德博弈，最后两败俱伤，合并收场。
- **为什么双十一各家不敢再降价？** 电商平台都知道降价 = 囚徒困境，所以转向"满减""优惠券"这种非价格竞争。

---

## 十、速记卡

> **寡头 = 几家大厂，相互依赖。**
> **囚徒困境 = 每个人都有占优策略，但结果集体非理性。**
> **纳什均衡 = 给定对方策略，没人想改。**
> **卡特尔不稳定**：每个成员都想偷偷多产。
> **无限次重复博弈能走出困境**，有限次不能（倒推）。
