# 12 外部性与公共品是什么？（小白版）

## 一、为什么要学这个？

**你室友凌晨两点打游戏，你睡不着——这是负外部性。**
**小区里有人种满了花，路过的人都觉得好看——这是正外部性。**

市场自己管不了这些事：
- 工厂排污水，自己不掏钱，但下游居民遭殃；
- 你打疫苗，自己防了病，还保护了身边人；
- 路灯你装了，整条街的人都能用，但没人愿意出钱装。

**这就是市场失灵**——价格机制没把这些"外溢影响"算进去。

**不学会怎样？**
你写论文研究"碳税""教育补贴""公共品供给""环境污染"，连"庇古税""科斯定理""搭便车"都讲不清。

---

## 二、是什么？

### 生活比喻：你的抽烟连累室友

- 你抽烟爽（私人收益）；
- 室友吸二手烟（你没付钱的成本）；
- 市场上烟的价格只反映你的私人成本，没反映室友的健康损失；
- 所以你抽得太多——**负外部性导致过度消费**。

### 严格定义

> **外部性（Externality）**：经济主体的行为对**旁观者**产生了**未被市场价格反映**的影响。
>
> **负外部性**：给旁观者带来成本（污染、噪音、二手烟）；
> **正外部性**：给旁观者带来收益（教育、打疫苗、种花）。
>
> **私人成本 vs 社会成本**：
> - 私人成本 PC = 生产者自己花的钱；
> - 社会成本 SC = PC + 边际外部成本 MEC（负外部性时）；
> - 市场均衡：私人 MC = 私人 MB；
> - 社会最优：社会 MC = 社会 MB；
> - 负外部性时，市场产量 > 社会最优产量。
>
> **公共品（Public Goods）**：
> - **非排他性**：没法不让别人用（路灯、国防）；
> - **非竞争性**：一个人用不减少别人用（路灯你看不影响我看）；
> - 对比：私人物品（面包）排他、竞争；公共资源（鱼塘）竞争但不排他；俱乐部品（电影院）排他但不竞争。
>
> **搭便车（Free Rider）**：公共品非排他，没人愿意出钱，都想别人出钱自己用。

### 符号表

| 符号 | 怎么读 | 是什么 |
|------|--------|--------|
| $MPC$ | "marginal private cost" | 私人边际成本 |
| $MEC$ | "marginal external cost" | 边际外部成本 |
| $MSC$ | "marginal social cost" | 社会边际成本 |
| $MPB$ | "marginal private benefit" | 私人边际收益 |
| $MEB$ | "marginal external benefit" | 边际外部收益 |
| $MSB$ | "marginal social benefit" | 社会边际收益 |

## 三、公式怎么来的？（手把手推）

### 3.1 负外部性：排污的均衡

**问题**：化工厂私人边际成本 $MPC = 2Q$，需求 $MB = 100 - Q$。每生产一吨污染造成下游居民 10 元/吨的损失（$MEC = 10$）。

**第一步**：市场均衡（化工厂只看私人成本）：
- 令 MPC = MB：2Q = 100 - Q → 3Q = 100 → Q_m = 33.3；
- P_m = 100 - 33.3 = 66.7。

**第二步**：社会最优（社会成本 MPC + MEC）：
- MSC = 2Q + 10；
- 令 MSC = MB：2Q + 10 = 100 - Q → 3Q = 90 → Q* = 30；
- P* = 100 - 30 = 70。

**看结果**：市场产量 33.3 > 社会最优 30——**多排了 3.3 吨**，这就是负外部性的"过度生产"。

### 3.2 庇古税怎么定？

**问题**：征多少税能让化工厂回到社会最优？

**思路**：让化工厂的私人成本 = 社会成本。
- 征从量税 t：化工厂的 MPC' = 2Q + t；
- 在 Q* = 30 时，要让 MPC'(30) = MSC(30)；
- 2×30 + t = 2×30 + 10 → t = 10。

**结论**：**庇古税 = 边际外部成本 MEC = 10 元/吨**。
- 这一步的关键：让生产者面对的价格反映全部社会成本。

### 3.3 正外部性：教育补贴

**问题**：教育的私人收益 $MPB = 100 - Q$，社会额外收益 $MEB = 20$（教育外溢：社会治安好、生产力高），MC = 40。

**市场均衡**（学生只看私人收益）：
- 令 MPB = MC：100 - Q = 40 → Q_m = 60。

**社会最优**：
- MSB = MPB + MEB = 120 - Q；
- 令 MSB = MC：120 - Q = 40 → Q* = 80。

**看结果**：市场教育投入 60 < 社会最优 80——**教育不足 20**。

**补贴**：给学生补贴 s = MEB = 20，让私人面对的收益变成 MPB + s = 120 - Q，达到社会最优。

## 四、一个完整的数字例子（Python 验证）

**题目**：燃煤电厂私人边际成本 MPC = 100 + 2Q，需求 MB = 500 - Q。每烧一吨煤排碳造成 50 元/吨的社会损失（MEC = 50）。

问：
(1) 市场均衡产量和价格？
(2) 社会最优产量和价格？
(3) 庇古税多少？

**手算**：

(1) 市场均衡：MPC = MB：
- 100 + 2Q = 500 - Q；
- 3Q = 400；
- Q_m = 133.3；P_m = 366.7。

(2) 社会最优：MSC = MPC + MEC = 150 + 2Q：
- 150 + 2Q = 500 - Q；
- 3Q = 350；
- Q* = 116.7；P* = 383.3。

(3) 庇古税 t = MEC = 50 元/吨。

**Python 验证**：

```python
import matplotlib.pyplot as plt
import numpy as np
plt.rcParams['font.sans-serif'] = ['PingFang SC']
plt.rcParams['axes.unicode_minus'] = False

Q = np.arange(0, 200, 1)
MPC = 100 + 2*Q
MB = 500 - Q
MSC = 150 + 2*Q

plt.figure(figsize=(9, 6))
plt.plot(Q, MB, label='MB（需求）', linewidth=2)
plt.plot(Q, MPC, label='MPC（私人成本）', linewidth=2)
plt.plot(Q, MSC, label='MSC（社会成本=MPC+MEC）', linewidth=2, linestyle='--')
plt.scatter([133.3], [366.7], color='red', s=100, zorder=5, label='市场均衡 (133, 367)')
plt.scatter([116.7], [383.3], color='green', s=100, zorder=5, label='社会最优 (117, 383)')
plt.xlabel('产量 Q（吨）')
plt.ylabel('价格/成本（元）')
plt.title('负外部性：市场过度生产')
plt.legend()
plt.grid(alpha=0.3)
plt.savefig('externality.png', dpi=150, bbox_inches='tight')
plt.show()
```

**看图**：MSC 在 MPC 上方，市场均衡点在社会最优右边（过度生产）。

## 五、什么时候能用？（前提条件）

1. **外部性能识别**：污染的受害者能找到、能估值；
2. **科斯定理前提**：产权清晰、交易成本低——可以通过私下谈判解决外部性；
3. **公共品非排他、非竞争**：严格满足这两个条件才是公共品。

---

## 六、什么时候不能用？（易错点）

1. **不是所有影响都是外部性**：我抢了你生意，你亏损——这是竞争转移，不是外部性（财富再分配，不是社会净损失）。
2. **公共品 ≠ 公共供给的物品**：公立学校由政府提供，但它是俱乐部品（有竞争性、能排他）。
3. **搭便车不总是坏事**：互联网开源软件、维基百科，靠自愿贡献。
4. **庇古税不是越重越好**：太重让企业全跑了，要等于 MEC。

---

## 七、容易和什么搞混？

| 概念 | 一句话 |
|------|--------|
| **负外部性** | 污染、噪音——市场过度生产 |
| **正外部性** | 教育、疫苗——市场供给不足 |
| **庇古税** | 对负外部性征税 = MEC |
| **庇古补贴** | 对正外部性补贴 = MEB |
| **公共品** | 非排他、非竞争（路灯、国防） |
| **公共资源** | 竞争但非排他（鱼塘、牧场） |
| **科斯定理** | 产权清晰时私下谈判能解决外部性 |

## 八、在论文里怎么用？

### 8.1 环境经济学（最经典）

**题目例**：《碳税对中国碳排放的影响——基于 CGE 模型》
- 碳税 = 庇古税，让化石燃料价格反映碳排放的社会成本；
- 估计二氧化碳的边际损害（Social Cost of Carbon）；
- 模拟不同税率下碳排放、GDP、福利的变化。

### 8.2 教育外部性

**题目例**：《高等教育的外部性测度——基于省级面板数据》
- 用各省人均受教育年限对周边省份生产率的影响；
- 估计 MEB；
- 政策含义：教育补贴应该多大。

### 8.3 公共品供给

**题目例**：《农村公共品供给的决定因素——以农村公路为例》
- 非排他、非竞争；
- 中央和地方政府责任划分；
- "一事一议"制度下农民的出资意愿。

### 8.4 环境规制的效果

**题目例**：《排污权交易制度对企业减排的影响——基于 DID》
- 科斯定理的应用：把排污权界定清楚，让企业交易；
- 对比"命令控制"和"排污权交易"的成本效果。

**本科生常见踩坑**：
- 把"公共品"和"公有制"混了——公共品是经济属性，不是所有制；
- 庇古税没说清楚"等于 MEC"——不是拍脑袋定；
- 科斯定理的"交易成本"前提经常被忽略——现实中几百个污染受害者谈判成本极高。

## 九、现实意义

- **为什么要收排污费？** 让工厂面对社会成本，减少过度生产。
- **为什么大学有补贴？** 教育有正外部性，私人市场投入不足。
- **为什么路灯由政府装？** 私人装了所有人都能用，没人愿意出钱（搭便车）。
- **为什么广场舞扰民要管？** 大妈跳得爽，但附近居民遭殃——负外部性。
- **为什么疫苗免费？** 打疫苗有正外部性（群体免疫），私人接种意愿不够。

---

## 十、速记卡

> **外部性 = 你的行为影响别人，但价格没反映。**
> **负外部性**（污染）→ 市场过度生产 → 庇古税 = MEC；
> **正外部性**（教育）→ 市场供给不足 → 庇古补贴 = MEB。
> **公共品**：非排他 + 非竞争 → 搭便车 → 政府提供。
> **科斯定理**：产权清晰 + 交易成本低，私下谈判也能解决外部性。
