## 一、为什么要学这个？

**你有 50 块，买奶茶和披萨，怎么组合最爽？**

- 1 杯奶茶 + 2 块披萨；
- 2 杯奶茶 + 1.5 块披萨；
- 3 杯奶茶 + 1 块披萨；

哪组最爽？这就是**消费者均衡**在回答的问题。

**不学会怎样？**
你会以为上一篇的"等边际原则"就够了——但现实中效用没法打绝对分（你没法说"这杯奶茶 50 分"），只能说"我觉得 A 组合比 B 好"。
**无差异曲线**就是把这种"主观排序"画出来的工具，是微观经济学里画图最多的一个概念。

---

## 二、是什么？

### 生活比喻：你在地图上看等高线

想象一座山，你站在山腰：
- 往东走 1 公里，高度不变（等高线）；
- 往南走 1 公里，高度不变；
- 所有"高度相同"的点连起来就是等高线。

**无差异曲线**就是：**所有"爽感相同"的商品组合连起来**。

- A 组合（1 奶茶 + 2 披萨）和 B 组合（2 奶茶 + 1.5 披萨）——你觉得一样爽，那 A 和 B 在同一条无差异曲线上；
- 换个更爽的组合（3 奶茶 + 2 披萨）——这就在更高的一条无差异曲线上。

### 严格定义

> **无差异曲线（Indifference Curve, IC）**：给消费者带来**同等满足程度**的两种商品所有组合的轨迹。
>
> **边际替代率（Marginal Rate of Substitution, MRS）**：在保持效用不变的前提下，**多消费一单位 X，愿意放弃多少 Y**。
>
> $$MRS_{xy} = -\frac{\Delta Y}{\Delta X} = \frac{MU_x}{MU_y}$$
>
> （前面加负号是因为 $\Delta X$ 增加时 $\Delta Y$ 为负，加负号让 MRS 为正数。）
>
> **预算线（Budget Line）**：在收入和商品价格给定的条件下，消费者**全部收入**能买到的两种商品所有组合。
>
> $$P_x \cdot X + P_y \cdot Y = I$$
>
> **消费者均衡**：预算线和无差异曲线**相切**的那个点，此时 $MRS_{xy} = P_x/P_y$。

### 无差异曲线的性质

1. **向右下方倾斜**（多拿一种就得少拿另一种）；
2. **凸向原点**（边际替代率递减）；
3. **离原点越远越爽**（组合越多越好）；
4. **任意两条不相交**（不然逻辑矛盾）。

### 符号表

| 符号 | 怎么读 | 是什么 | 生活类比 |
|------|--------|--------|----------|
| $IC$ | "indifference curve" | 无差异曲线 | 爽感等高线 |
| $MRS_{xy}$ | "MRS x y" | 边际替代率 | 多一杯奶茶愿意放弃几块披萨 |
| $P_x, P_y$ | "P x, P y" | X、Y 价格 | 奶茶、披萨单价 |
| $I$ | "I" | 收入 | 你这个月能花的钱 |

## 三、公式怎么来的？（手把手推）

### 3.1 为什么 MRS = MU_x / MU_y？

**问题**：你多喝一杯奶茶（X 加 1），爽感增加 $MU_x$；为了保持爽感不变，要少吃几块披萨（Y 减 $\Delta Y$），爽感减少 $MU_y \cdot \Delta Y$。

**保持爽感不变**：增加的爽 = 减少的爽，即：

$$MU_x \cdot \Delta X + MU_y \cdot \Delta Y = 0$$

**移项**：

$$-\frac{\Delta Y}{\Delta X} = \frac{MU_x}{MU_y}$$

左边就是 MRS，所以：

$$MRS_{xy} = \frac{MU_x}{MU_y}$$

**这一步怎么读**：你愿意用多少 Y 换一个 X，取决于 X 和 Y 各自的边际效用之比。X 越爽（MU_x 大），你越愿意用 Y 换它。

### 3.2 消费者均衡条件

**问题**：无差异曲线和预算线相切意味着什么？

**预算线的斜率** = $-P_x/P_y$（把预算线方程 $P_x X + P_y Y = I$ 改写为 $Y = I/P_y - (P_x/P_y)X$）。

**无差异曲线的斜率** = $-MRS_{xy} = -MU_x/MU_y$。

**相切**：两条线斜率相等：

$$MRS_{xy} = \frac{P_x}{P_y}$$

**代入 MRS 表达式**：

$$\frac{MU_x}{MU_y} = \frac{P_x}{P_y}$$

**整理**：

$$\frac{MU_x}{P_x} = \frac{MU_y}{P_y}$$

**看！这就是上一篇的"等边际原则"！**——两种推导殊途同归。

## 四、一个完整的数字例子（Python 验证）

**题目**：小王收入 I = 100 元，奶茶 P_x = 10 元，披萨 P_y = 20 元。效用函数 $U = X \cdot Y$（柯布-道格拉斯）。

问：最优消费组合 (X*, Y*)？

**手算**：

**第一步**：预算线 $10X + 20Y = 100$，化简为 $X + 2Y = 10$。

**第二步**：用均衡条件 $MU_x/MU_y = P_x/P_y$。

- $MU_x = \partial U/\partial X = Y$（对 X 求偏导，把 Y 当常数）；
- $MU_y = \partial U/\partial Y = X$；
- $MU_x/MU_y = Y/X$。

**第三步**：令 $Y/X = P_x/P_y = 10/20 = 0.5$，即 $Y = 0.5X$。

**第四步**：代入预算线：$X + 2(0.5X) = 10$，即 $2X = 10$，$X^* = 5$。

**第五步**：$Y^* = 0.5 \times 5 = 2.5$。

**结论**：最优组合 = 5 杯奶茶 + 2.5 块披萨。

**验证**：
- 花费 = 5×10 + 2.5×20 = 50 + 50 = 100 ✅
- 效用 = 5 × 2.5 = 12.5

**Python 画图**：

```python
import matplotlib.pyplot as plt
import numpy as np
plt.rcParams['font.sans-serif'] = ['PingFang SC']
plt.rcParams['axes.unicode_minus'] = False

# 预算线: 10X + 20Y = 100 => Y = 5 - 0.5X
X = np.arange(0, 10, 0.1)
Y_budget = 5 - 0.5*X

# 无差异曲线: U = X*Y = 12.5 => Y = 12.5/X
Y_indiff = 12.5 / X

plt.figure(figsize=(8, 6))
plt.plot(X, Y_budget, label='预算线 10X+20Y=100', linewidth=2)
plt.plot(X[1:], Y_indiff[1:], label='无差异曲线 U=XY=12.5', linewidth=2, color='red')
plt.scatter([5], [2.5], color='green', s=100, zorder=5, label='最优点 (5, 2.5)')
plt.xlabel('奶茶 X（杯）')
plt.ylabel('披萨 Y（块）')
plt.xlim(0, 10)
plt.ylim(0, 6)
plt.title('消费者均衡：预算线与无差异曲线相切')
plt.legend()
plt.grid(alpha=0.3)
plt.savefig('consumer_equilibrium.png', dpi=150, bbox_inches='tight')
plt.show()
```

看图：绿色点就是切点，预算线和无差异曲线刚好碰一下，再爽的组合就超预算了。

## 五、什么时候能用？（前提条件）

1. **消费者能排序偏好**：A 和 B 哪个好能比出来（不需要绝对打分）；
2. **偏好稳定**：今天和明天口味不变；
3. **边际替代率递减**：无差异曲线凸向原点；
4. **收入和价格给定**：消费者是价格接受者。

---

## 六、什么时候不能用？（易错点）

1. **完全替代品**（比如 1 元和 2 元硬币）：无差异曲线是直线，MRS 不变，没有相切的内点解；
2. **完全互补品**（左脚鞋和右脚鞋）：无差异曲线是 L 形，最优解在拐角；
3. **上瘾品/炫耀品**：偏好不随数量递减；
4. **离散商品**（你只能买整数杯奶茶）：无差异曲线不是连续的。

---

## 七、容易和什么搞混？

| 概念 | 一句话 | 公式 |
|------|--------|------|
| **无差异曲线** | 爽感相同的组合 | U(X, Y) = 常数 |
| **预算线** | 钱能买的组合 | P_x X + P_y Y = I |
| **MRS** | 无差异曲线斜率 | MU_x/MU_y |
| **预算线斜率** | -P_x/P_y | —— |
| **消费者均衡** | 两线相切 | MRS = P_x/P_y |

---

## 八、在论文里怎么用？

### 8.1 需求曲线的推导（理论）

- 收入变化 → 预算线平移 → 新的切点 → 新的 X 需求量；
- 把不同收入下的 X 需求量连起来，就是**恩格尔曲线**（收入-消费曲线）；
- 这是研究"消费升级"的理论基础。

### 8.2 价格变化的替代效应和收入效应

**题目例**：《猪肉价格上涨对居民肉类消费的影响》
- 猪肉涨价 → 预算线绕着 Y 轴转 → 新切点；
- 分解：①替代效应（换吃鸡肉）+ ②收入效应（实际收入降）；
- 用 Slutsky 分解或 Hicks 分解定量。

### 8.3 政策福利分析

**题目例**：《现金补贴 vs 实物补贴的福利比较》
- 发钱：预算线整体外移；
- 发米（实物）：预算线在"米"那个方向多一截；
- 画图比较两种政策下消费者能达到的最高无差异曲线——**现金补贴一般不劣于实物补贴**，因为消费者有选择自由。

### 8.4 柯布-道格拉斯效用函数的实证

- $U = X^\alpha Y^{1-\alpha}$；
- 推导出来：消费者把收入的 $\alpha$ 比例花在 X 上，$(1-\alpha)$ 花在 Y 上；
- 这是恩格尔定律的简化版——食品支出占比随收入下降。

**本科生常见踩坑**：
- 把无差异曲线画成凹的（凸向原点才对）；
- 说"相切时两条曲线斜率相等"但不写 MRS = P_x/P_y；
- 用柯布-道格拉斯效用函数时，没注意它意味着"每种商品的支出占比固定"——现实中收入涨了食品占比是降的，要用 Stone-Geary 效用函数（线性支出系统）。

## 九、现实意义

- **为什么工资涨了人们少逛街多下馆子？** 收入效应 + 替代效应。
- **为什么苹果手机贵还卖爆？** 果粉的无差异曲线极度偏向苹果，MRS 很高。
- **为什么公司发购物卡比发现金差？** 购物卡把你锁在那家店，预算线被掰弯，效用不如现金。
- **为什么双十一冲动消费？** 降价瞬间预算线外移，你觉得"现在不买亏"——这是跨期决策，不是当期均衡。

---

## 十、速记卡

> **无差异曲线 = 爽感等高线**，凸向原点。
> **预算线 = 钱能买的组合**，斜率 = -P_x/P_y。
> **消费者均衡 = 两线相切**：MRS = P_x/P_y，即 MU_x/P_x = MU_y/P_y。
> 离原点越远的无差异曲线越爽，但够不着（超预算）。
