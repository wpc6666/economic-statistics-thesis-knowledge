# 10 完全垄断与价格歧视是什么？（小白版）

## 一、为什么要学这个？

**自来水公司凭什么一家独大？**

- 全市就一家自来水厂；
- 你不可能自己挖条水管接水；
- 它定多少钱你就得交多少钱。

这就是**完全垄断**——市场上只有一个卖家，而且没有替代品。

**不学会怎样？**
你写论文研究"国企定价权""反垄断""数字平台垄断"，连"垄断厂商为什么能定高价""价格歧视的三种类型"都讲不清。
**垄断是市场失灵的第一种**，也是政府监管的重点。

## 二、是什么？

### 生活比喻：学校里唯一的复印店

- 全校就一家复印店；
- 复印 1 张 1 毛，成本 1 分；
- 学生不复印不行，只能忍；
- 老板还能玩花样：期末考试周涨价 50%，开学季降价。

### 严格定义

> **完全垄断（Monopoly）**：市场上只有一个卖者，产品没有相近替代品，存在进入壁垒。
>
> **垄断成因**：
> 1. **规模经济**（自然垄断）：自来水管网，一家最便宜；
> 2. **专利/版权**：医药专利期内独家；
> 3. **资源控制**：南非钻石公司控制矿源；
> 4. **政府特许**：烟草、食盐。
>
> **垄断厂商面对的需求曲线**：就是**整个市场需求曲线**（向右下倾斜）。
>
> **边际收益 MR < P**：因为多卖一件必须给所有商品降价，所以多卖一件的收益 < 价格。
>
> **利润最大化**：MR = MC（和竞争厂商一样的条件，但结果不同）。
>
> **加成公式**：$P = MC / (1 - 1/|E_d|)$——弹性越小，加价越狠。

### 价格歧视的三种类型

| 类型 | 一句话 | 例子 |
|------|--------|------|
| **一级价格歧视** | 对每个顾客收他愿付的最高价 | 医生对富人收高价、对穷人收低价 |
| **二级价格歧视** | 按购买量定价 | 量大从优、阶梯电价 |
| **三级价格歧视** | 按顾客群体分市场定价 | 学生票、老人票、商务舱 vs 经济舱 |

**关键条件**：能隔开市场，不让低价顾客倒卖给高价顾客。

### 符号表

| 符号 | 怎么读 | 是什么 | 生活类比 |
|------|--------|--------|----------|
| $MR$ | "marginal revenue" | 边际收益 | 多卖一件多赚多少 |
| $P$ | "P" | 价格 | 垄断定价 |
| $E_d$ | "E d" | 需求价格弹性 | 顾客对价格多敏感 |

## 三、公式怎么来的？（手把手推）

### 3.1 为什么垄断厂商 MR < P？

**问题**：垄断厂商面对需求曲线 $P = a - bQ$。

**第一步**：总收益 $TR = P \cdot Q = (a - bQ)Q = aQ - bQ^2$。
**第二步**：边际收益 $MR = dTR/dQ = a - 2bQ$。
**第三步**：对比价格 $P = a - bQ$。
**第四步**：MR 截距和 P 一样（都是 a），但斜率是 P 的两倍（-2b vs -b）。
**第五步**：所以对任意 Q > 0，MR < P。

**直觉解释**：多卖一件，新这件赚 P，但为了多卖这件，所有原来 Q 件都得降价 $\Delta P$，所以净收益 = P - Q·ΔP < P。

### 3.2 加成公式推导

从 MR = MC：

$$MR = P(1 - 1/|E_d|) = MC$$

**这一步怎么来的？**
回忆上一篇需求价格弹性：$MR = d(PQ)/dQ = P + Q \cdot dP/dQ$。
两边除以 P：
$$MR/P = 1 + (Q/P)(dP/dQ) = 1 + 1/E_d$$

（因为 $E_d = (dQ/dP)(P/Q)$，所以 $(Q/P)(dP/dQ) = 1/E_d$。）

整理：
$$MR = P(1 + 1/E_d) = P(1 - 1/|E_d|)$$

**令 MR = MC**：
$$P(1 - 1/|E_d|) = MC$$
$$P = \frac{MC}{1 - 1/|E_d|}$$

**读公式**：
- $|E_d| = \infty$（完全弹性）：P = MC（回到完全竞争）；
- $|E_d| = 2$：P = MC/(1-1/2) = 2MC，加价 100%；
- $|E_d| = 1.2$：P = MC/(1-1/1.2) = 6MC，加价 5 倍。

**关键含义**：**顾客越不敏感（弹性小），垄断厂商加价越狠**。

### 3.3 利润最大化手算

**题目**：需求曲线 P = 100 - Q，MC = 20（常数）。

**第一步**：TR = (100-Q)Q = 100Q - Q²。
**第二步**：MR = 100 - 2Q。
**第三步**：令 MR = MC：100 - 2Q = 20 → Q* = 40。
**第四步**：P* = 100 - 40 = 60。
**第五步**：利润 = (P - MC) × Q = (60-20) × 40 = 1600。

**对比完全竞争**：P = MC = 20，Q = 80。
**垄断结果**：产量少一半（40 vs 80），价格高三倍（60 vs 20）——这就是垄断的效率损失。

## 四、一个完整的数字例子（Python 验证）

**题目**：学校复印店面对学生需求 $P = 0.5 - 0.001Q$（每张复印价 P 元，Q 是张数），MC = 0.05 元/张。

问：
(1) 垄断定价和垄断产量？
(2) 如果完全竞争，价格和产量？
(3) 价格歧视：学生需求 P = 0.5 - 0.001Q，老师需求 P = 1 - 0.002Q，隔开两个市场怎么定价？

**手算**：

(1) 垄断：
- TR = (0.5 - 0.001Q)Q = 0.5Q - 0.001Q²；
- MR = 0.5 - 0.002Q；
- 令 MR = MC：0.5 - 0.002Q = 0.05 → Q* = 225；
- P* = 0.5 - 0.225 = 0.275 元/张。

(2) 完全竞争：P = MC = 0.05；
- 0.05 = 0.5 - 0.001Q → Q = 450。

(3) 三级价格歧视：
- 学生市场：MR_s = 0.5 - 0.002Q_s，令 MR_s = MC：0.5 - 0.002Q_s = 0.05 → Q_s = 225，P_s = 0.275；
- 老师市场：MR_t = 1 - 0.004Q_t，令 MR_t = MC：1 - 0.004Q_t = 0.05 → Q_t = 237.5，P_t = 1 - 0.002×237.5 = 0.525；
- **老师弹性小（工作必印），定价 0.525；学生弹性大（能印电子版），定价 0.275**。

**Python 验证**：

```python
# 垄断 vs 竞争
def monopoly(demand_a, demand_b, mc):
    # P = a - bQ, MR = a - 2bQ
    Q = (demand_a - mc) / (2 * demand_b)
    P = demand_a - demand_b * Q
    profit = (P - mc) * Q
    return Q, P, profit

Q_m, P_m, pi_m = monopoly(0.5, 0.001, 0.05)
print(f"垄断: Q={Q_m:.1f} 张, P={P_m:.3f} 元/张, 利润={pi_m:.2f} 元")

Q_c = (0.5 - 0.05) / 0.001
P_c = 0.05
print(f"竞争: Q={Q_c:.1f} 张, P={P_c:.3f} 元/张")

# 三级价格歧视
Qs, Ps, _ = monopoly(0.5, 0.001, 0.05)
Qt, Pt, _ = monopoly(1.0, 0.002, 0.05)
print(f"学生市场: Q={Qs:.1f}, P={Ps:.3f}")
print(f"老师市场: Q={Qt:.1f}, P={Pt:.3f}")
```

输出：
```
垄断: Q=225.0 张, P=0.275 元/张, 利润=50.62 元
竞争: Q=450.0 张, P=0.050 元/张
学生市场: Q=225.0, P=0.275
老师市场: Q=237.5, P=0.525
```

## 五、什么时候能用？（前提条件）

1. **市场上只有一家厂商**；
2. **没有相近替代品**；
3. **进入壁垒高**（专利、规模经济、牌照）；
4. **价格歧视还要求**：能隔开市场、不同市场弹性不同、不能倒卖。

---

## 六、什么时候不能用？（易错点）

1. **有垄断地位 ≠ 能任意涨价**：涨价会吸引潜在竞争者（哪怕暂时没进来）。
2. **自然垄断不能简单拆**：自来水拆成 5 家，管网重复铺，成本反而高。
3. **价格歧视不总是坏事**：学生票让穷学生也能消费，社会福利可能改善。
4. **一级价格歧视几乎做不到**：现实中只能接近（议价、拍卖）。

---

## 七、容易和什么搞混？

| 概念 | 一句话 |
|------|--------|
| **完全垄断** | 一家独大 |
| **自然垄断** | 规模经济导致一家最便宜（水电煤） |
| **价格歧视** | 对不同人收不同价 |
| **垄断势力** | 厂商定价高于边际成本的能力 |
| **寻租** | 为维护垄断地位花钱（游说、行贿） |

## 八、在论文里怎么用？

### 8.1 数字平台垄断研究

**题目例**：《数字平台的垄断势力测度——基于勒纳指数》
- 用加成公式 $L = (P - MC)/P = 1/|E_d|$；
- 估计平台的需求弹性，反推勒纳指数；
- 和传统行业对比，看平台是否垄断。

### 8.2 医药专利定价

**题目例**：《专利保护期内药品定价的福利分析》
- 专利 = 临时垄断；
- 垄断价 vs 社会最优价（P=MC）的差距；
- 讨论"专利期多长合适"——太短没激励研发，太长垄断太久。

### 8.3 价格歧视实证

**题目例**：《航空公司差别定价的福利效应》
- 用同一航班不同舱位价格、提前订票折扣；
- 估计商务客 vs 旅游客的需求弹性；
- 算价格歧视带来的消费者剩余变化。

### 8.4 国企改革

**题目例**：《自然垄断行业的政府监管——以电网为例》
- 自然垄断不能拆（规模经济）；
- 但可以用**边际成本定价**或**平均成本定价**监管；
- 对比"放任垄断定价"和"监管定价"的福利。

**本科生常见踩坑**：
- 把"市场份额大"等同于"垄断"——还要看进入壁垒；
- 价格歧视写成"歧视性定价"就完事，没分三种类型；
- 没说清楚"价格歧视的前提是隔开市场"。

## 九、现实意义

- **为什么电影票有学生票？** 学生弹性大（没钱），商务客弹性小（报销），隔开市场定不同价。
- **为什么航空公司提前订票便宜？** 提前订票的多是旅游客（弹性大），临时买票的多是商务客（弹性小）——通过时间隔开市场。
- **为什么 12306 没有学生软卧折扣？** 因为能倒卖（学生票买了卖给商务客）——隔开不了市场。
- **为什么互联网平台搞大数据杀熟？** 同一商品，老用户（弹性小）定价高，新用户（弹性大）定价低——三级价格歧视。

---

## 十、速记卡

> **垄断厂商面对向下倾斜的需求曲线**，MR < P。
> **利润最大化**：MR = MC（和竞争一样），但因为 MR < P，所以 P > MC。
> **加成公式**：P = MC / (1 - 1/|E_d|)——弹性越小加价越狠。
> **价格歧视三类型**：一级（每人最高价）、二级（按量）、三级（按群体）。
> **价格歧视前提**：能隔开市场 + 不同群体弹性不同。
