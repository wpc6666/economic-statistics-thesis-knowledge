# 02 指标无量纲化：把万亿和百分比放到同一把尺子上

## 一、为什么要学这个？

**真实痛点：**

你拿到 31 个省份的数据，要算"综合发展指数"。你选了这些指标：
- GDP：从 1 万亿到 12 万亿（量级 10¹²）；
- 失业率：从 2% 到 5%（量级 10⁰）；
- 人均可支配收入：从 2 万到 8 万（量级 10⁴）；
- 绿化覆盖率：从 30% 到 50%（量级 10¹）。

**直接加权求和会发生什么？** GDP 一项就把其他三项淹了——1 万亿对 2 万，差了 50 万倍。最后排名只跟 GDP 有关，其他指标等于没加。

**不学会怎样？**
- 你论文里直接 `总分 = GDP + 失业率 + 收入`，老师一看就知道你没做无量纲化；
- 你不知道"正向指标"和"负向指标"要分别处理；
- 你选了 Z-score 还是极差归一化，说不出区别。

## 二、是什么？（先打比方）

### 生活比喻：奥运会换算分数

奥运会上：
- 百米赛跑：9.58 秒（数值越小越好）；
- 跳远：8.95 米（数值越大越好）；
- 举重：263 公斤（数值越大越好）。

**你能把"9.58 + 8.95 + 263"加起来当总分吗？** 当然不能——单位不一样。

奥运会的做法：把每个项目都换算成"相对成绩"。比如：
- 百米：世界纪录 9.58 秒作为 100 分，每慢 0.1 秒扣 X 分；
- 跳远：世界纪录 8.95 米作为 100 分，每差 0.01 米扣 X 分。

**无量纲化** = 把所有指标都换算成"在自己这门课里考了多少分"，然后才能加起来。

### 严格定义

> **无量纲化**：把不同单位、不同量级的指标，通过数学变换，都映射到同一个区间（通常 [0,1]）上，使得它们可以比较、可以加总。

## 三、公式怎么来的？

### 方法 1：极差归一化（最常用）

**正向指标**（越大越好，如 GDP）：
$$r_{ij} = \frac{x_{ij} - \min_i x_{ij}}{\max_i x_{ij} - \min_i x_{ij}}$$

**负向指标**（越小越好，如失业率）：
$$r_{ij} = \frac{\max_i x_{ij} - x_{ij}}{\max_i x_{ij} - \min_i x_{ij}}$$

**怎么来的？**
- 让最大值对应 1，最小值对应 0；
- 中间的值按比例落在 (0,1) 之间；
- 这样所有指标都被拉到 [0,1]，量纲消失了。

### 方法 2：Z-score [[KP11_标准化_ZScore|标准化]]

$$z_{ij} = \frac{x_{ij} - \bar{x}_j}{s_j}$$

其中 $\bar{x}_j$ 是第 j 列的均值，$s_j$ 是标准差。

**特点**：
- 结果均值为 0，标准差为 1；
- 可能出现负数（说明这个样本比平均差）；
- 适合后续做[[03_因子分析|因子分析]]、聚类，不太适合直接加权求和。

### 方法 3：归一化到单位向量（[[05_TOPSIS法|TOPSIS]] 专用）

$$r_{ij} = \frac{x_{ij}}{\sqrt{\sum_i x_{ij}^2}}$$

**特点**：把一列向量变成单位长度，所有 $r_{ij}$ 都在 [0,1]，但最小值不一定是 0。TOPSIS 里用这个。

### 方法 0：先把"定性指标"变成定量数据

很多指标天生就不是数字——满意度、口碑等级、城市排名。在做无量纲化之前，得先把它们"翻译"成数。

[[../../教材笔记/01_综合评价/03_指标无量纲化/知识点/KP01_定性指标及其类型|定性指标分三种]]：

| 类型 | 长什么样 | 怎么翻译 | 例子 |
|------|----------|----------|------|
| **次序指标** | 排名 1、2、3……n | 倒扣公式：$y_i = 1 - \dfrac{x_i - 0.5}{n}$ | 全班成绩排名 |
| **等级指标** | 优/良/中/差 | 给每档配系数：优=1、良=0.5、中=0.2、差=0.1 | 口碑分档 |
| **主观指标** | 问卷调查结果 | 算频率/比重：满意率=满意人数÷总人数 | 85% 的人满意 |

> 🥤 **奶茶店比方**：
> - 次序：5 家店人气排了名（第1名到第5名），用倒扣公式翻成 0.9~0.1 的得分；
> - 等级：口碑分成优秀/良好/合格三档，分别给 1、0.5、0.1；
> - 主观：发了 100 份问卷，90 人满意，满意率就是 90%。

**注意**：名次本身是"越小越好"的逆指标，所以公式前面有个 $1-$ 倒扣过来；$(x_i-0.5)$ 是为了让最后一名不得 0（否则加权时它就消失了）。

### 方法 1.5：适度指标正向化（居中最好的指标）

[[../../教材笔记/01_综合评价/03_指标无量纲化/知识点/KP07_适度指标正向化|有些指标不是越大越好、也不是越小越好，而是"居中最好"]]——比如资产负债率（40%~60% 最健康）、体温（37℃）、经济增速。

**做法**：先定一个"最佳值" $x_0$，然后算实际值离它多远，再取倒数：

$$y_i = \frac{1}{|x_i - x_0|}$$

> 🎂 **糖度比方**：最佳糖度是 5 分糖。A 店正好 5 分（偏差 0，得最高分），B 店 6 分（偏差 1，得 1 分），C 店 8 分（偏差 3，得 1/3≈0.33 分）。离最佳值越远，得分越低。

**坑**：当 $x_i = x_0$ 时分母为 0，要单独给它最高分。

### 方法 4：阈值比较法（对标外部标准）

$$y_i = \frac{x_i}{x_0}$$

不是跟样本内比，而是跟一个**外部标准**比：计划目标、行业最好水平、国家标准。结果直接读作"完成了标准的几倍"——1.0 刚好达标，0.5 只完成一半，1.5 超额一半。

> 🎯 **销售比方**：日销目标 200 杯，A 店卖了 100 杯得 0.5，B 店卖了 200 杯得 1.0，C 店卖了 300 杯得 1.5。

### 方法 5：比重法

$$p_{ij} = \frac{x_{ij}}{\sum_i x_{ij}}$$

把每列变成一列比重，加起来等于 1。用于看结构占比（如各省 GDP 占全国的比重）。**注意**：不能有负数，否则正负会在总和里抵消。

## 三点五、直线型、折线型、曲线型：什么时候用哪种？

上面讲的极差归一化、Z-score、阈值法，都属于**直线型**——评价值随实际值线性变化。但现实中有些指标不是直线关系：

| 类型 | 特点 | 什么时候用 | 例子 |
|------|------|------------|------|
| **直线型** | 等量增加→等量得分 | 绝大多数常规指标 | GDP、收入、分数 |
| **折线型** | 有"门槛+封顶"，分段线性 | 低于某值无效、高于某值不再加分 | 小康进程（温饱线以下0分，达标后封顶100分） |
| **曲线型** | 越往上每一步越值钱（阶段效应） | 非线性关系明显 | 主导产业弹性（过了临界点贡献加速变大） |

[[../../教材笔记/01_综合评价/03_指标无量纲化/知识点/KP15_无量纲化方法选择|选择判别链]]：

1. 指标有没有"低于某值无效、高于某值封顶"？→ **有就用折线型**；
2. 指标有没有"不同水平段等量变化意义不同"？→ **有且能标定参数就用曲线型**；
3. 都没有 → **直线型**（实践中 90% 的情况）。

> 🪜 **爬台阶比方**：
> - 直线型 = 走平路，每走 1 米得 1 分；
> - 折线型 = 不到门槛不给分、到了门槛就封顶；
> - 曲线型 = 越往上爬，每步越值钱。

> 💡 **原书建议**：曲线型理论上最准，但参数难定、主观性强；只要不改变相对排名，用直线型近似就够了。所以论文里 90% 都用直线型。

## 四、每个符号是什么？

| 符号 | 怎么读 | 是什么 |
|------|--------|--------|
| $x_{ij}$ | "x i j" | 第 i 个对象第 j 个指标的原始值 |
| $\min_i x_{ij}$ | "第j列最小" | 这一列里的最小值 |
| $\max_i x_{ij}$ | "第j列最大" | 这一列里的最大值 |
| $r_{ij}$ | "r i j" | 规范化后的值 |
| $\bar{x}_j$ | "x 拔 j" | 这一列的均值 |
| $s_j$ | "s j" | 这一列的标准差 |

## 五、一个完整的数字例子

**问题**：5 个学生，2 门课：数学（分，越大越好）、迟到次数（次，越小越好）。

| 学生 | 数学 x₁ | 迟到 x₂ |
|------|---------|---------|
| 甲   | 60      | 5       |
| 乙   | 70      | 3       |
| 丙   | 80      | 2       |
| 丁   | 90      | 1       |
| 戊   | 100     | 0       |

### 方法 1：极差归一化

**数学（正向）**：
- min=60, max=100, 极差=40
- 甲：(60-60)/40 = 0
- 乙：(70-60)/40 = 0.25
- 丙：(80-60)/40 = 0.5
- 丁：(90-60)/40 = 0.75
- 戊：(100-60)/40 = 1.0

**迟到（负向）**：
- min=0, max=5, 极差=5
- 甲：(5-5)/5 = 0
- 乙：(5-3)/5 = 0.4
- 丙：(5-2)/5 = 0.6
- 丁：(5-1)/5 = 0.8
- 戊：(5-0)/5 = 1.0

规范化后：

| 学生 | r_数学 | r_迟到 |
|------|--------|--------|
| 甲   | 0      | 0      |
| 乙   | 0.25   | 0.4    |
| 丙   | 0.5    | 0.6    |
| 丁   | 0.75   | 0.8    |
| 戊   | 1.0    | 1.0    |

### 方法 2：Z-score

数学列：
- 均值 = (60+70+80+90+100)/5 = 80
- 样本标准差 $s = \sqrt{\frac{(60-80)^2+\cdots+(100-80)^2}{4}}$
  $= \sqrt{\frac{400+100+0+100+400}{4}} = \sqrt{250} = 15.81$
- Z 值：
  - 甲：(60-80)/15.81 = -1.26
  - 乙：(70-80)/15.81 = -0.63
  - 丙：(80-80)/15.81 = 0
  - 丁：(90-80)/15.81 = +0.63
  - 戊：(100-80)/15.81 = +1.26

（Python 验证过：`np.std([60,70,80,90,100], ddof=1) = 15.81`。）

### 方法 3：向量归一化（TOPSIS 用）

数学列平方和 = 3600+4900+6400+8100+10000 = 33000
$\sqrt{33000} = 181.66$
- 甲：60/181.66 = 0.330
- 乙：70/181.66 = 0.385
- 丙：80/181.66 = 0.440
- 丁：90/181.66 = 0.495
- 戊：100/181.66 = 0.550

## 六、前提假设

1. **同一列指标，方向一致**。不能一列里有的"越大越好"有的"越小越好"——先把负向的翻过来；
2. **没有极端异常值**。如果一个 outliers 特别大，极差归一化会把其他所有样本压到接近 0；
3. **样本量不能太小**。3 个样本算 Z-score，标准差很不稳。

---

## 七、易错点

1. **负向指标忘了反向**。直接套正向公式，结果失业率越高得分越高。
2. **用样本标准差还是总体标准差？** Z-score 里用样本标准差 $s$（ddof=1），不是总体 $\sigma$（ddof=0）。
3. **极差归一化后出现 0 或 1**。0 在[[06_熵值法-TOPSIS组合|熵值法]]里会触发 ln(0)，需要加一个很小的数（如 0.0001），或者换用向量归一化。
4. **Z-score 后出现负数**。负数不能直接加权求和（因为熵值法要求 p_ij>0），要再平移一下。
5. **不同指标用不同的归一化方法**。所有指标必须用同一种，否则又不可比了。

---

## 八、Python 代码

```python
import numpy as np

X = np.array([
    [60, 5],
    [70, 3],
    [80, 2],
    [90, 1],
    [100, 0]
], dtype=float)

# 列1正向，列2负向
R = np.zeros_like(X)
# 极差归一化
R[:,0] = (X[:,0]-X[:,0].min())/(X[:,0].max()-X[:,0].min())
R[:,1] = (X[:,1].max()-X[:,1])/(X[:,1].max()-X[:,1].min())
print("极差归一化:")
print(np.round(R,3))

# Z-score
Z = (X - X.mean(axis=0)) / X.std(axis=0, ddof=1)
print("\nZ-score:")
print(np.round(Z,3))

# 向量归一化（TOPSIS用）
V = X / np.sqrt((X**2).sum(axis=0))
print("\n向量归一化:")
print(np.round(V,3))
```

## 九、方法选择总表（一张表搞定）

### 9.1 定量指标：三大类无量纲化方法

| 大类 | 具体方法 | 公式 | 结果范围 | 用在哪 |
|------|----------|------|----------|--------|
| **直线型** | **极差归一化** | $(x-\min)/(\max-\min)$ | [0,1] | 熵值法、加权求和（最常用） |
| **直线型** | **Z-score 标准化** | $(x-\bar{x})/s$ | 均值0、标准差1 | 因子分析、聚类、回归 |
| **直线型** | **向量归一化** | $x/\sqrt{\sum x^2}$ | [0,1] | **TOPSIS 专用** |
| **直线型** | **阈值比较法** | $x/x_0$ | 可>1 | 有外部目标值（计划完成率） |
| **直线型** | **比重法** | $x/\sum x$ | 和=1 | 看结构占比 |
| **折线型** | 分段函数 | 门槛下=0，中间线性，上限封顶=1 | [0,1] | 有门槛+封顶的指标（小康进程） |
| **曲线型** | 哥西曲线等 | 非线性 S 形 | [0,1] | 阶段效应明显（主导产业弹性） |

### 9.2 定性指标：先翻译再无量纲化

| 数据类型 | 翻译方法 | 一句话 |
|----------|----------|--------|
| 名次排名 | 倒扣公式 $y=1-(x-0.5)/n$ | 第1名≈1分，最后一名≈0但不为0 |
| 优良中差 | 系数转换法 | 优=1、良=0.5、中=0.2、差=0.1（专家定） |
| 问卷满意度 | 频率/比重法 | 满意人数÷总人数=满意率 |
| 适度指标（居中最好） | 偏差倒数法 $y=1/\|x-x_0\|$ | 离最佳值越近得分越高 |

### 9.3 怎么选？三问决策链

```
你的指标是什么类型？
├─ 名次/评语/问卷？ → 先定性→定量翻译，再做下面的无量纲化
├─ 居中最好的适度指标？ → 先偏差倒数法正向化
└─ 普通定量指标？
   ├─ 有门槛+封顶？ → 折线型
   ├─ 阶段非线性？ → 曲线型（参数难定，实践常退化成直线型）
   └─ 普通情况？ → 直线型
      ├─ 跑熵值法/加权求和？ → 极差归一化
      ├─ 跑TOPSIS？ → 向量归一化
      ├─ 跑因子/聚类/回归？ → Z-score
      ├─ 对标外部目标？ → 阈值比较法
      └─ 看结构占比？ → 比重法
```

## 十、为什么不用别的方法？

- **为什么不直接用原始数据加权？** GDP 万亿、失业率百分比、收入万元，量级差几十万倍，直接加权求和会被 GDP 完全主导，其他指标名存实亡。无量纲化就是把所有指标拉到同一把尺子上才能相加。
- **为什么不用 Z-score 跑熵值法或 TOPSIS？** Z-score 结果有负数、不落在 [0,1]，而熵值法要算比重 $p_{ij}$ 和 $\ln(p_{ij})$，负数和 0 都会让公式报错或失真；TOPSIS 的理想解也要求先映射到非负区间。所以熵值法配极差归一化、TOPSIS 配向量归一化，是固定搭配。
- **为什么不三种方法混着用？** 三种归一化各有固定用途（极差→加权求和/熵值法，Z-score→因子/聚类，向量→TOPSIS），关键约束是**同一篇论文里所有指标必须用同一种**，混用又把刚建立起来的可比性破坏了。

## 十一、答辩常问（直接背）

1. **问：正向指标和负向指标的归一化公式差在哪？** 答：正向 $r=(x-\min)/(\max-\min)$，越大越好；负向 $r=(\max-x)/(\max-\min)$，把"越小越好"翻成"越大越好"。本文件例子里迟到次数（负向）戊（0 次）得 1.0、甲（5 次）得 0，方向就对了；忘了反向会让失业率越高的城市得分越高。
2. **问：跑熵值法和跑 TOPSIS，为什么要用不同的归一化？** 答：熵值法算权重用极差归一化（结果落在 [0,1]、能算比重）；TOPSIS 算距离用向量归一化（把列向量变单位长度）。组合使用时这是两个独立步骤，不能从头到尾只用一种。
3. **问：极差归一化后出现 0，进熵值法怎么办？** 答：0 会触发 $\ln(0)$，两种处理——数学上约定 P=0 时 $P\ln P=0$（极限为 0），或者给 0 加一个很小的数（如 1e-12）。Python 里用 `np.where(P==0, 1e-12, P)`。
4. **问：Z-score 用样本标准差还是总体标准差？** 答：用样本标准差（ddof=1）。本文件数学列 5 个学生的 $s=15.81$，就是按 ddof=1 算的；用总体标准差会低估[[03_离散程度|离散程度]]。

## 十二、速记卡

> **无量纲化 = 把所有指标拉到同一把尺子上。**
> **先定性→定量**（名次倒扣、等级配系数、问卷算比重），再做无量纲化。
> 正向指标：$r = (x-\min)/(\max-\min)$
> 负向指标：$r = (\max-x)/(\max-\min)$
> 适度指标（居中最好）：$y = 1/|x-x_0|$
> 跑熵值法用极差归一化，跑 TOPSIS 用向量归一化，跑因子分析用 Z-score。
> 有门槛封顶用折线型，阶段非线性用曲线型（实践常退化成直线型）。
> **最大的坑：负向指标忘了反向；定性指标直接当精确数用。**

## 💡 经济学视角：GDP 和人口怎么能加在一起？先标准化

**这个方法是为了解决什么经济学问题？**
你要给 31 个省打分，GDP 是 5 万亿~12 万亿，人口是 3000 万~1.2 亿，森林覆盖率是 15%~65%——这三个数单位完全不同，量纲差 10000 倍，直接加权求和，GDP 会把其他指标"碾压"掉。无量纲化就是把所有指标都变成 0~1 之间的纯数，让大家"站在同一起跑线上"再比。

**经济学里哪些指标必须无量纲化？**

| 指标 | 原始单位 | 处理方向 |
|---|---|---|
| GDP 总量 | 亿元（万亿级） | 正向，越大越好 |
| 人均收入 | 元（万级） | 正向 |
| 森林覆盖率 | %（0~100） | 正向 |
| 失业率 | % | **负向**（越低越好）要反向 |
| 单位 GDP 能耗 | 吨标煤/万元 | 负向，越低越好 |

关键判断：**正向指标**（越大越好，如人均 GDP）和**负向指标**（越小越好，如失业率、碳排放）方向不同，反向指标要先取倒数或用 $(max-x)/(max-min)$ 翻转。

**举个实证论文的例子：**
《长江经济带绿色发展评价》选了 18 个指标，其中"单位 GDP 能耗""PM2.5 浓度"是负向，"森林覆盖率""污水处理率"是正向。作者先做极差标准化：正向 $x'=(x-min)/(max-min)$，负向 $x'=(max-x)/(max-min)$。不做这一步，能耗高的省分数反而高，结论完全反了。
