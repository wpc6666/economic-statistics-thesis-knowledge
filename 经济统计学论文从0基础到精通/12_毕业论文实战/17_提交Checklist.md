# 17 毕业论文提交 Checklist

> 从选题到答辩的完整检查清单。每完成一项打一个勾。建议打印出来贴在桌前。
> 这是最后一道关卡：全部打勾 = 可以安心提交。

---

## 一、选题与开题（第 1~2 周）

- [ ] 选题有明确的现实问题和研究对象
- [ ] 数据来源已确认可公开获得（年鉴/统计局/国研网/[[../../教材笔记/05_统计学原理/02_统计数据采集/知识点/KP04_数据采集方法|问卷]]）
- [ ] [[KP02_指标体系|指标体系]]/变量选择已初步拟定，且每个变量都能找到数据
- [ ] 研究方法已初步选定（面板 FE/DID/[[06_熵值法-TOPSIS组合|熵值法]]等，决策见 `../11_方法选择决策/01_方法选择决策树`）
- [ ] 开题报告按学校模板写完，导师签字通过（写法见 `11_开题报告怎么写`）
- [ ] 文献综述已读 15 篇以上核心文献

## 二、数据与指标（第 3~4 周）

- [ ] 所有原始数据已收集完整，录入 Excel
- [ ] 每个数据都标注了来源（年鉴页码/网址/年份）
- [ ] 逆向指标已识别并列出
- [ ] 缺失值已处理（删除/插补，并说明方法）
- [ ] 变量体系已最终定稿，无找不到数据的变量

## 三、计算与实证（第 5~6 周）

- [ ] 面板数据已 `xtset`，描述统计与[[01_相关系数|相关系数]]已跑
- [ ] 基准回归完成，核心系数方向与假设一致
- [ ] 至少做了 3 种[[06_稳健性检验|稳健性检验]]（替换变量/缩样本/换方法，见 `../10_论文写作全流程/06_稳健性检验`）
- [ ] 至少做了 1 种内生性处理（滞后一期/[[03_工具变量IV|工具变量]]）
- [ ] 异质性分析完成
- [ ] 所有计算用软件复现过一遍，数字对得上
- [ ] 结果有分析，不是只报数字

## 四、论文写作（第 7~8 周）

- [ ] 摘要 200~300 字，包含问题、方法、数据、结论
- [ ] 关键词 3~8 个
- [ ] 引言有"背景→不足→问题→方法→安排"逻辑链（写法见 `05_引言怎么写`）
- [ ] 文献综述按主题组织，不是罗列（写法见 `../10_论文写作全流程/02_文献综述怎么做`）
- [ ] 方法章节有公式 + 符号解释 + 选择依据
- [ ] 实证章节有表、有图、有分析（正反例见 `06_实证部分错误vs正确`）
- [ ] 结论紧扣实证，对策建议具体、不空泛
- [ ] 参考文献 ≥ 15 篇，按 GB/T 7714 格式（格式见 `03_参考文献GB-T7714`）
- [ ] 致谢已写

## 五、格式（定稿前）

- [ ] 页边距：左 2.8cm，右/上/下 2.5cm
- [ ] 全文行距固定值 26 磅
- [ ] 正文中文宋体、英文 Times New Roman 小四号，首行缩进 2 字符
- [ ] 标题层级：一、→（一）→1.→（1）
- [ ] 目录自动生成，只显示到二级标题，字体为黑色
- [ ] 表格全部为三线表，表题在表上方（做法见 `02_三线表怎么做`）
- [ ] 图题在图下方，坐标轴有名称和单位
- [ ] 公式用公式编辑器，按章编号（5.1）
- [ ] 页码：封面无；前置部分罗马数字；正文阿拉伯数字从 1 开始
- [ ] 无错别字、无大段空行

## 六、查重（定稿前 2 周）

- [ ] 已用第三方系统自查一次（流程见 `09_查重与降重`）
- [ ] 重复率低于学校要求（一般 ≤ 15%~20%）
- [ ] 标红段落已全部改完
- [ ] 引用部分已规范标注

## 七、答辩（最后 1 周）

- [ ] [[08_答辩PPT怎么做|PPT]] 10~12 页，按"背景→方法→结果→结论"组织（做法见 `08_答辩PPT怎么做`）
- [ ] 自己掐表排练 3 遍以上，控制在规定时间
- [ ] 准备了 20+ 个常见问题的应答思路（见 `07_答辩50问`）
- [ ] 论文打印 3~5 份
- [ ] PPT 已拷贝 U 盘 + 邮箱备份
- [ ] 着装整洁，提前 10~30 分钟到场试投影（流程见 `16_答辩流程与礼仪`）

---

**合计：约 45 项检查点。全部打勾 = 可以安心提交。**

---

## 💡 经济学视角：Checklist就是论文生产的"质量控制流程"

**Checklist在解决什么经济学问题？**
经济学里讲"交易成本"——论文写到最后，格式错误、引用错漏这些小问题，单独看都不致命，但积少成多会让评委质疑你的严谨性，相当于给论文打了个"质量折扣"。Checklist的作用就是用最低成本（花1小时过一遍45项）避免这种系统性折价。

**核心逻辑：**
实证分析（实然）和规范分析（应然）的边界在提交前最后核对——你的结论有没有超出数据支持的范围？政策建议有没有跟实证结果脱节？这两条过一遍，论文的经济学成色就稳了。
