# 05 SPSS 操作指引（零基础照做）

## 一、这是什么

SPSS 是一个"点菜单就能跑统计"的软件，不用写代码。综合评价里它主要负责四件事：

1. 数据录入；
2. [[KP11_标准化_ZScore|标准化]]（Z-score）；
3. [[02_主成分分析PCA|主成分分析]] / [[03_因子分析|因子分析]]；
4. 信效度检验。

打个比方：SPSS 像自动麻将机，你把牌（数据）摆进去，按个按钮（点菜单），它自己码好（出结果），你只管看牌面（输出表）。

SPSS 不能直接做 [[04_AHP层次分析法|AHP]] 和[[06_熵值法-TOPSIS组合|熵值法]]——这两个用 Excel 或专门软件，详见../07_综合评价方法/09_Excel[[09_Excel熵值法计算|熵值法计算]].md。

---

## 二、为什么要做

- 标准化、主成分、因子分析手算不现实，SPSS 一点菜单就出结果；
- 论文里要贴 SPSS 的输出表（如 KMO 检验、总方差解释表），这是规范做法。

---

## 三、具体[[08_答辩PPT怎么做|怎么做]]

### 0. 打开软件与数据录入

1. 打开 SPSS，出现两个窗口："**数据视图（Data View）**"和"**变量视图（Variable View）**"。
2. 点下方"**变量视图**"，逐行输入变量：
   - 第一行 Name 填 `gdp`，Type 选 `Numeric`；
   - 同理建 `urate`、`fiscal`、`doctor`；
   - 第一列建 `district`，Type 选 `String`（放样本名）。
3. 切回"**数据视图**"，一行一个样本，把数字敲进去。
4. 也可以直接 `文件 → 打开 → 数据` 读入 `.xlsx`。

---

### 1. 标准化（Z-Score 无量纲化）

菜单路径：

```
分析(Analyze) → 描述统计(Descriptive Statistics) → 描述(Descriptives)
```

操作步骤：

- 把 gdp、fiscal、doctor 选进"变量"框；
- 勾选左下角 **"将标准化得分另存为变量"**（Save standardized values as variables）；
- 点"确定"。

结果：数据视图里多出 `Zgdp`、`Zfiscal`、`Zdoctor` 三列，就是标准化后的值（均值 0、标准差 1）。

口径：$z = (x - \bar{x}) / S$。

---

### 2. 主成分分析（指标多、要降维时用）

菜单路径：

```
分析(Analyze) → 降维(Dimension Reduction) → 因子(Factor)
```

操作步骤：

1. 把要降维的指标选进"变量"框；
2. 点右侧 **"描述(Descriptives)"**：勾选 **KMO 和 Bartlett 球形度检验** → 继续；
3. 点 **"抽取(Extraction)"**：方法选"主成分"，勾选"碎石图"，提取标准选"特征值大于 1" → 继续；
4. 点 **"得分(Scores)"**：勾选 **"保存为变量"**（回归法）→ 继续；
5. 点"确定"。

输出：KMO/Bartlett 表、总方差解释表、成分矩阵、碎石图；数据视图多出主成分得分列。

---

### 3. 因子分析（要给公共因子起名字时）

菜单路径和主成分一样（同走"降维 → 因子"），差别在：

- 点 **"旋转(Rotation)"**：选 **"最大方差法(Varimax)"** → 继续；
- 其余同上。

旋转后看"旋转成分矩阵"，把每个高载荷指标归到对应因子下起名（如"经济因子""医疗因子"）。

---

### 4. AHP 和熵值法怎么办

- **AHP**：SPSS 不内置。用 Excel 手算判断矩阵和权重，或用免费软件 **yaahp**（画层次结构、自动算一致性）。
- **熵值法**：SPSS 不直接出权重。用 Excel 公式算（详见../07_综合评价方法/[[09_Excel熵值法计算]].md），或用 SPSS 的"转换 → 计算变量"配合 Excel。本科论文推荐 Excel。

---

## 四、输出表怎么读

| 输出表 | 在哪 | 看什么 |
|---|---|---|
| KMO 和 Bartlett 检验 | 因子分析第 1 张 | KMO>0.6 且 Bartlett 的 p<0.05 才能做因子/主成分 |
| 解释的总方差 | 第 2 张 | 提取出的主成分累计方差贡献率，一般要 >70% |
| 成分矩阵 / 旋转成分矩阵 | 第 3 张 | 每个指标在哪个主成分上载荷高（>0.5） |
| 碎石图 | 图形 | 陡坡前的主成分个数 |

---

## 五、常见错误与避坑

1. **变量名写成中文长句**：SPSS 变量名不支持长中文，先在变量视图用短英文名。
2. **不勾"将标准化得分另存为变量"**：结果只出描述统计，没生成标准化列。
3. **KMO 小于 0.6 还硬做因子分析**：说明指标不适合降维，应回到指标筛选。
4. **把 AHP、熵值法硬塞进 SPSS 找菜单**：找不到就是没有，这两个用 Excel/yaahp。
5. **输出表不复制进论文**：论文要贴 KMO、总方差解释表，并标注"资料来源：SPSS 输出"。
6. **样本量太少做因子分析**：因子分析要求样本量是指标数的 5 倍以上，小样本别做。
