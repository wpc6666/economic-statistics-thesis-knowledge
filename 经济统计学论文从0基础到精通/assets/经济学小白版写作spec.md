# 经济学概念·小白版写作风格 spec（所有 Subagent 必读）

> 本 spec 是 13_微观 / 14_宏观 / 15_政经三个目录所有概念文件的**统一写作标准**。
> 写完每一篇，对照本 spec 自检一遍再交付。

---

## 一、文件命名与标题

- 文件名：`编号_概念名.md`，例如 `03_需求价格弹性是什么.md`
- 一级标题：`# 03 需求价格弹性是什么？（小白版）`
- 编号在本目录内连续，章节总结里要能对上。

---

## 二、固定 10 段结构（一个都不能少）

每篇严格按下面 10 段写：

### 一、为什么要学这个？
- 从生活痛点切入（奶茶/打车/外卖/双十一/租房/炒股/找工作）。
- 讲清楚"不学会会怎样"——后面论文里哪里会卡住。
- 3-6 个 bullet，不要长篇大论。

### 二、是什么？
- **先生活比喻**：用一个具体的生活场景把概念讲明白（"函数就是自动售货机"那种）。
- **再严格定义**：引用框 `> **XX**：……`，把学术定义写准确。
- **符号表**：所有符号用表格列出来（符号/怎么读/是什么/生活类比）。
- 可以配一张对比表（几种类型/几个相关概念放一起）。

### 三、公式怎么来的？（手把手推导，不跳步）
- 从直觉出发，一步一步推。
- **每一步都要写"这一步是因为……"**，告诉读者这一步在数学上凭什么能这么写。
- 禁止出现："显然""易证""由定理可知""不难看出""众所周知"。
- 如果概念没有公式（比如政治经济学的商品拜物教），这一段改成"这套道理是怎么推出来的？"，用逻辑链条代替数学推导。

### 四、一个完整的数字例子
- 给一组具体数字，从头到后手算一遍。
- 中间结果全部写出来（均值、偏离、求和、最终值），不要跳。
- 最后用 Python 验证一遍（给代码块），告诉读者 Python 跑出来和手算一致。
- 例子要接地气（奶茶定价、打车费、月工资、双十一销量）。

### 五、什么时候能用？（前提条件）
- 这个概念/模型成立需要什么假设。
- 数据要满足什么条件。

### 六、什么时候不能用？（易错点）
- 违反假设会发生什么。
- 导师/审稿人会怎么挑刺。
- 3-5 条 bullet。

### 七、容易和什么搞混？
- 一张对比表：这个概念 vs 长得像的另一个概念，区别在哪。

### 八、在论文里怎么用？（本任务**特别强调**）
这一段是经济学和原 KP 笔记最大的不同，必须写足：
- **实证论文里什么时候会用到这个概念**？（举例：做价格弹性，论文里通常用 `lnQ = a + b·lnP + ε` 回归，b 就是弹性）
- **它对应论文里的哪个变量/哪个模型/哪张表**？
- **本科毕业论文常见用法**：是用来做文献综述的理论基础？还是用来解释回归系数？还是用来做政策建议？
- **常见踩坑**：本科生写这个概念时最容易犯什么错（比如把弹性和斜率搞混、把 GDP 和 GNP 搞混）。

### 九、现实意义
- 这个概念能解释什么真实世界现象？（谷贱伤农、双十一、航空公司差别定价、央行加息、996、外卖骑手困在系统里……）
- 2-4 个例子。

### 十、速记卡
- 引用框，3-5 句话，一句话总结这个概念的灵魂。
- 考前扫一眼就能回忆起来。

## 三、语言风格铁律

1. **大白话**：像跟一个数学挂过科的同学聊天。
2. **禁止词**：显然、易证、由定理可知、不难看出、众所周知、易得、同理可得（要写"同理"必须把那一步重新推一遍）。
3. **生活例子**：奶茶、打车、外卖、双十一、租房、找工作、炒股、发工资、点外卖凑满减。
4. **公式必须有解释**：每个公式下面用大白话翻译一遍"这个公式在说什么"。
5. **希腊字母不吓人**：第一次出现时写中文读音（β 贝塔、ε 艾普西龙、σ 西格玛）。
6. **不堆术语**：用一个术语前，先用生活例子铺垫。

## 五、00_章节总结.md 的格式

每个目录必须有一个 `00_章节总结.md`，包含：

1. **一句话总览**：这一章学完你会什么。
2. **核心概念清单表**：| 序号 | 概念 | 一句话 | 对应原 KP |
3. **核心公式大表**：所有公式一张表（公式/是什么/一句话）。
4. **概念关系图**：用 mermaid `graph TD` 画一张，展示这些概念怎么串起来。
5. **十大易错点**：bullet 列表。
6. **论文里怎么用这一章**：讲清楚这一章的概念在实证论文里扮演什么角色（理论基础？变量设计？机制分析？政策建议？）。
7. **自测题**：5-8 道简答/计算题，不附答案（让读者回头找对应文件）。
8. **配套教材笔记链接**：全部列出来。
