# 02 主成分分析 PCA：找方差最大的方向

## 一、为什么要学这个？

上一节我们知道"100 个指标要压成 3 个"。但怎么压？凭什么用 $0.7X_1 + 0.7X_2$ 这个权重，而不是 $0.5X_1 + 0.5X_2$？

**主成分分析（Principal Component Analysis, PCA）** 就是回答这个问题的：它用一套数学规则，自动算出"最优的加权组合"是什么。

这个规则一句话：**找方差最大的方向**。

什么叫方差最大？还是用学生成绩举例：

- 你把所有学生的"数学+语文"成绩画在散点图上，点是斜着分布的；
- 你沿着"从左下到右上"这条斜方向看，学生之间的差异最大（有人 90/85，有人 50/55，差很多）；
- 你沿着"垂直于这条斜线"的方向看，学生之间的差异很小（都是 70 分上下偏一点）。

**PCA 说：我就沿着差异最大的那条方向，把所有点投影过去。这条方向就是第一主成分。**

为什么选差异最大的方向？因为差异最大 = 信息最多。如果一个方向上所有点都挤在一起，那这个方向没有区分度，扔掉不可惜。

**不学会怎样？**
- 你自己拍脑袋定权重（比如 $0.5X_1 + 0.5X_2$），压出来的综合指标不是最优的，损失了大量信息；
- 论文里用了 PCA 但说不清"为什么这个权重是对的"，答辩被问倒。

---

## 二、是什么？（先打比方）

### 生活比喻：给山脉拍全景照

想象你站在一片山区，眼前是连绵起伏的山。你要拍一张全景照，让照片里能看到最多的山峰。

你怎么选相机角度？
- 你**转一下身体**，找到一个角度，让视野里山峰最多、山谷最少——这就是"方差最大方向"；
- 第一照片 = 第一主成分 PC1：抓住最主要的地形起伏；
- 如果你还想再拍一张补全细节，你**转 90 度**，拍那些第一照片没拍到的侧面沟壑——这就是第二主成分 PC2。

PCA 干的事就是：**自动转角度，找到能看到最多信息的那个方向。**

### 严格定义

> **主成分分析 PCA**：对 $p$ 个原始变量 $X_1, X_2, \dots, X_p$，找它们的线性组合
> $$PC_1 = a_{11}X_1 + a_{12}X_2 + \dots + a_{1p}X_p$$
> 使得 $PC_1$ 的方差最大；然后在与 $PC_1$ 不相关的方向上，找第二个方差最大的 $PC_2$；依此类推，得到 $p$ 个主成分，按方差从大到小排列。

约束条件：每个主成分的系数平方和 $a_{11}^2 + a_{12}^2 + \dots + a_{1p}^2 = 1$（否则可以无限放大权重让方差变大，没意义）。

## 三、公式怎么来的？（从直觉到数学）

**第一步：我们要优化什么？**

目标：找一组系数 $a_1, a_2, \dots, a_p$，让 $PC = a_1X_1 + a_2X_2 + \dots + a_pX_p$ 的方差最大。

**第二步：方差怎么表示？**

回忆第 2 章：随机变量 $PC$ 的方差等于
$$\text{Var}(PC) = \text{Var}(a_1X_1 + \dots + a_pX_p)$$

用方差的性质展开（$p=2$ 时）：
$$\text{Var}(a_1X_1 + a_2X_2) = a_1^2\text{Var}(X_1) + a_2^2\text{Var}(X_2) + 2a_1a_2\text{Cov}(X_1, X_2)$$

**第三步：写成矩阵形式**

把系数打包成向量 $\mathbf{a} = (a_1, a_2, \dots, a_p)^T$，把原始变量的协方差矩阵记为 $\Sigma$（$p \times p$ 的矩阵，对角线是各变量方差，非对角线是协方差）。

那么：
$$\text{Var}(PC) = \mathbf{a}^T \Sigma \mathbf{a}$$

**第四步：加上约束**

不能让 $\mathbf{a}$ 无限大，所以约束：
$$\mathbf{a}^T \mathbf{a} = 1$$

**第五步：这个优化问题的解是什么？**

用拉格朗日乘数法（第 1 章学过），最后得到：
$$\Sigma \mathbf{a} = \lambda \mathbf{a}$$

这是**特征方程**。$\lambda$ 是特征值，$\mathbf{a}$ 是特征向量。

意思是：
- 第一主成分 PC1 的方向 = 协方差矩阵 $\Sigma$ 的**最大特征值对应的特征向量**；
- PC1 的方差 = 那个最大特征值 $\lambda_1$；
- 第二主成分 = 第二大特征值对应的特征向量，方差 = $\lambda_2$；
- ……

**这就是 PCA 的数学本质：对协方差矩阵做特征值分解。**

---

## 四、每个符号是什么？

| 符号 | 怎么读 | 是什么 |
|------|--------|--------|
| $X_1, \dots, X_p$ | "X一到Xp" | 原始变量（比如 GDP、消费、教育） |
| $PC_1, PC_2$ | "P C 一" | 第一、第二主成分（新的综合指标） |
| $a_{ij}$ | "a i j" | 第 i 个主成分里，第 j 个原始变量的权重（载荷） |
| $\Sigma$ | "西格玛" | 原始变量的协方差矩阵（p×p） |
| $\lambda_i$ | "lambda i" | 第 i 个特征值 = 第 i 个主成分的方差 |
| $\mathbf{a}$ | "向量a" | 权重向量（特征向量） |
| $\text{Var}(PC_i)$ | "PCi的方差" | 第 i 个主成分包含的信息量 |
| 贡献率 | —— | $\lambda_i / (\lambda_1 + \dots + \lambda_p)$，第 i 个主成分解释了多少比例的信息 |

## 五、一个完整的数字例子（手算）

**数据**：5 个学生，2 门课（数学 $X_1$、语文 $X_2$）。

| 学生 | $X_1$（数学） | $X_2$（语文） |
|------|------|------|
| A | 90 | 85 |
| B | 80 | 75 |
| C | 60 | 65 |
| D | 50 | 55 |
| E | 70 | 70 |

**第一步：算均值**

$\bar{X}_1 = (90+80+60+50+70)/5 = 350/5 = 70$

$\bar{X}_2 = (85+75+65+55+70)/5 = 350/5 = 70$

**第二步：算离均差（每个数减均值）**

| 学生 | $X_1 - \bar{X}_1$ | $X_2 - \bar{X}_2$ |
|------|------|------|
| A | 20 | 15 |
| B | 10 | 5 |
| C | -10 | -5 |
| D | -20 | -15 |
| E | 0 | 0 |

**第三步：算协方差矩阵 $\Sigma$**

用样本协方差（除以 $n-1=4$）：

$\text{Var}(X_1) = (20^2 + 10^2 + (-10)^2 + (-20)^2 + 0^2)/4 = (400+100+100+400+0)/4 = 1000/4 = 250$

$\text{Var}(X_2) = (15^2 + 5^2 + (-5)^2 + (-15)^2 + 0^2)/4 = (225+25+25+225+0)/4 = 500/4 = 125$

$\text{Cov}(X_1, X_2) = (20\times15 + 10\times5 + (-10)\times(-5) + (-20)\times(-15) + 0)/4 = (300+50+50+300+0)/4 = 700/4 = 175$

所以协方差矩阵：
$$\Sigma = \begin{pmatrix} 250 & 175 \\ 175 & 125 \end{pmatrix}$$

**第四步：求特征值**

特征方程 $\det(\Sigma - \lambda I) = 0$：

$$(250 - \lambda)(125 - \lambda) - 175^2 = 0$$

展开：
$$31250 - 250\lambda - 125\lambda + \lambda^2 - 30625 = 0$$

$$\lambda^2 - 375\lambda + 625 = 0$$

用求根公式：
$$\lambda = \frac{375 \pm \sqrt{375^2 - 4\times625}}{2} = \frac{375 \pm \sqrt{140625 - 2500}}{2} = \frac{375 \pm \sqrt{138125}}{2}$$

$\sqrt{138125} \approx 371.65$

所以：
- $\lambda_1 = (375 + 371.65)/2 \approx 373.32$
- $\lambda_2 = (375 - 371.65)/2 \approx 1.67$

**第五步：算贡献率**

总方差 = $\lambda_1 + \lambda_2 = 375$（正好等于 $\text{Var}(X_1) + \text{Var}(X_2) = 250 + 125 = 375$，这不是巧合，是数学性质）。

第一主成分贡献率 = $373.32 / 375 \approx 99.6\%$

意思是：数学和语文这两门课的成绩，99.6% 可以用"总成绩"这一个维度概括。它们几乎完全相关。

**第六步：求第一主成分的权重（特征向量）**

把 $\lambda_1 = 373.32$ 代回 $\Sigma \mathbf{a} = \lambda \mathbf{a}$：

$$250 a_1 + 175 a_2 = 373.32 a_1$$

$$175 a_1 + 125 a_2 = 373.32 a_2$$

从第一式：
$$175 a_2 = 123.32 a_1$$

$$a_2 = 0.704 a_1$$

加上约束 $a_1^2 + a_2^2 = 1$：

$$a_1^2 + 0.496 a_1^2 = 1$$

$$1.496 a_1^2 = 1$$

$$a_1 \approx 0.818, \quad a_2 \approx 0.576$$

所以第一主成分：
$$PC_1 = 0.818 X_1 + 0.576 X_2$$

**第七步：算每个学生的 PC1 得分**

（注意：要用[[KP11_标准化_ZScore|标准化]]后的数据算，或者直接用离均差。这里直接用原始数据减去均值后代入。）

- A: $0.818\times20 + 0.576\times15 = 16.36 + 8.64 = 25.0$
- B: $0.818\times10 + 0.576\times5 = 8.18 + 2.88 = 11.06$
- C: $0.818\times(-10) + 0.576\times(-5) = -8.18 - 2.88 = -11.06$
- D: $0.818\times(-20) + 0.576\times(-15) = -16.36 - 8.64 = -25.0$
- E: $0$

排名：A > B > E > C > D。

## 五·五、PCA 综合评价的完整流水线（论文直接照抄）

上面手算的是"数学原理"。但你毕业论文真正做的是"给 31 个省份打分排名"，这叫 **PCA 综合评价**。它有一套固定的七步流水线，任何一篇用 PCA 打分的论文都是这个套路：

| 步骤 | 做什么 | 一句话解释 |
|------|--------|-----------|
| ① | **z-score 标准化** | $z_{ij}=(x_{ij}-\bar x_j)/S_j$，把不同量纲拉成同一把尺子 |
| ② | **求相关矩阵 $R$** | 看哪些指标一起涨 |
| ③ | **求特征根 $\lambda$ 和特征向量** | 找方差最大的新方向 |
| ④ | **算方差贡献率、累积贡献率** | 每个主成分装了百分之几信息 |
| ⑤ | **选主成分个数 $k$** | 累积贡献率 ≥ 80%（综合评价常用 85%） |
| ⑥ | **解释主成分含义、命名** | 看系数大小和符号给主成分起名 |
| ⑦ | **算综合得分 $F$ 并排序** | 按贡献率加权，得出最终排名 |

**两个关键数学性质**（答辩爱问）：

**性质一：总方差守恒。** 把上面例子的特征根加起来：$\lambda_1+\lambda_2=373.32+1.67=375$，正好等于原来两个变量的方差之和 $250+125=375$。这不是巧合——正交变换只是"旋转坐标系"，不改变数据的总散布，只是把信息重新分配：前几个主成分装走大部分，后面的基本是噪音。所以**丢掉后面的主成分 = 扔掉噪音，不是扔信息**。

**性质二：综合得分 $F$ 怎么构造。** 选了前 $k$ 个主成分后，不是简单相加，而是**按每个主成分装了多少信息（方差贡献率）来加权**：

$$F=\frac{\lambda_1 y_1+\lambda_2 y_2+\cdots+\lambda_k y_k}{\sum_{i=1}^{p}\lambda_i}$$

- 分子：每个主成分得分乘以它的特征根（信息含量）；
- 分母：**全部 $p$ 个**特征根之和（不是前 $k$ 个！），这样权数总和小于 1，反映"我们只保留了部分信息"。

**为什么不只取第一主成分 $y_1$ 排名？** 因为 $y_1$ 往往只装了一半左右的信息，单用它是以偏概全。教材里的例子：贵州因为"产值利税率"这个第三主成分突出，用贡献率加权法从第 11 名升到第 7 名；广东反之从第 6 降到第 11。只用 $y_1$ 就把这部分信息丢了。

**注意 $F$ 的正负号**：因为数据标准化后均值为 0，$F=0$ 就代表"全国平均水平"；$F<0$ 只表示"低于平均"，30 个省里十几个为负是正常分布，**不是说这个省"经济为负"**。

### 主成分怎么命名？（第⑥步的诀窍）

主成分是数学产物，你必须给它起个经济名字，否则白降。诀窍是**看系数的大小和符号**：

| 观察到的系数 | 怎么命名 |
|-------------|---------|
| 某几个指标系数明显偏大（>0.5） | 主成分主要反映这几个指标，按它们的领域起名（如"经济实力"） |
| 所有指标系数都差不多大且为正 | 是"综合水平/共性因素" |
| 系数一正一负 | 是两者之差（如"续航 − 价格"=性价比） |
| 系数乱七八糟、谁也不突出 | **千万别硬起名**，先做旋转或删掉奇异样本 |

### 选几个主成分？三条准则打架了怎么办？

| 准则 | 做法 | 结果倾向 |
|------|------|---------|
| 累积贡献率 ≥ 85% | 信息保留比例 | 主成分偏多 |
| **Kaiser 准则**（特征根 > 1） | 单个主成分方差 > 平均 | 主成分偏少 |
| 碎石图拐点 | 特征根从陡变平处截断 | 辅助验证 |

**易错点（高频）**：Kaiser 准则"特征根 > 1"**只在从相关阵出发时才有意义**。因为标准化后每个指标方差都是 1，平均特征根 $\bar\lambda=1$——如果一个主成分的方差还不如单个原始指标，留它干嘛。如果你是从**协方差阵**出发（变量同量纲），特征根的尺度取决于量纲，" > 1"就没有比较基准了，不能用 Kaiser 准则。

三条准则结果不一致时：**综合评价优先保信息，以累积贡献率 85% 为主**，再看碎石图和主成分能不能命名。

### 两个改进技巧（知道即可）

- **均值化代替 z-score**：$z_{ij}=x_{ij}/\bar x_j$。z-score 把每个指标方差都拉成 1，抹掉了"哪个指标在省际间波动大"这部分信息；均值化只除均值不除标准差，保留波动差异，第一主成分提取效率更高（教材例子能多装约 14% 信息）。代价：均值化后 $\bar\lambda\neq1$，选 k 要用 $\lambda>\bar\lambda$ 而不是 $\lambda>1$。
- **主成分旋转**：当初始载荷"平铺"、没法命名时，可以借[[03_因子分析|因子分析]]的方差最大旋转，让系数向 0 或 ±1 两极分化。旋转不改变综合得分 $F$，只改善可解释性。

## 六、前提假设

1. **原始变量之间要有相关性**。如果[[01_相关系数|相关系数]]都是 0，特征值全都相等，PCA 压完还是 p 维，没意义。
2. **变量要标准化**（除以各自的标准差）。因为 GDP 的方差（万亿）和教育经费占比的方差（百分比）量纲差太远，不标准化的话，方差大的变量会主导主成分。
3. **样本量 $n$ 要大于变量数 $p$**，最好 $n > 5p$。
4. **PCA 只处理线性关系**。如果变量之间是 U 形关系，PCA 抓不住。

---

## 七、易错点

1. **不标准化就跑 PCA**：GDP 方差巨大，会完全主导第一主成分，其他指标被忽略。
2. **主成分命名瞎编**：PC1 = 0.8GDP + 0.7消费 + 0.6教育，你命名为"经济发展水平"没问题；但如果 PC1 载荷乱七八糟，硬要给它起名字就是自欺欺人。
3. **把主成分当因果变量**：PC1 只是指标加权，不能说"PC1 导致了幸福感"。
4. **主成分个数拍脑袋**：不是越多越好。一般取"累计贡献率 > 80%"的主成分个数。也可以用 Kaiser 准则：只取特征值 > 1 的主成分。
5. **PCA 对异常值敏感**：一个离群点会把主成分方向拉偏，先做箱线图检查。

## 八、Python 代码（验证手算结果）

```python
import numpy as np
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

# 原始数据
X = np.array([[90, 85], [80, 75], [60, 65], [50, 55], [70, 70]])

# 标准化（减去均值，除以标准差）
scaler = StandardScaler()
X_std = scaler.fit_transform(X)

# 跑 PCA
pca = PCA()
pca.fit(X_std)

print("特征值（方差）：", pca.explained_variance_)
print("贡献率：", pca.explained_variance_ratio_)
print("主成分权重（载荷矩阵）：")
print(pca.components_)
# 输出应该和手算的 0.818, 0.576 接近（注意标准化后特征向量符号可能相反）

# 算每个学生的主成分得分
scores = pca.transform(X_std)
print("主成分得分：")
print(scores)
```

**和手算的差异**：Python 跑的是标准化后的数据，特征向量方向会一样（可能符号相反），但数值因为标准化会和手算略有不同。这是正常的——实际应用中**必须标准化**，手算为了简单没标准化。

## 九、PCA 和回归的区别

| | [[KP03_多元回归Stata|多元回归]] | PCA |
|---|---------|-----|
| 目标 | 用 X 预测 Y | 找 X 内部方差最大的方向 |
| 有没有 Y | 有（因变量） | 没有（纯探索 X 结构） |
| 系数 | 回归系数（解释 X 对 Y 的影响） | 载荷（解释 X 之间的关系） |
| 约束 | 最小化残差平方和 | 最大化方差 |
| 用途 | 因果/预测 | 降维、去共线性、可视化 |

**一句话**：回归是"X 怎么影响 Y"，PCA 是"X 自己内部怎么分布"。

## 十、为什么不用别的方法？

- **为什么不用[[03_因子分析|因子分析]]代替 PCA？** 因子分析多了"特殊因子"假设和旋转步骤，计算更复杂，而且要求 KMO > 0.6。如果你的目的只是"压完维度、消除共线性、接着跑回归"，PCA 一步到位、结果确定（对协方差矩阵做特征分解），不需要额外假设；只有当你需要向导师解释"这几个维度分别代表什么经济含义"时，因子分析的旋转才有价值。
- **为什么不把指标标准化之后直接放进回归？** 标准化只解决量纲问题，解决不了指标之间高度相关的问题——GDP、消费、收入一起放，VIF 还是会超过 10，系数照样乱跳。PCA 压出来的主成分之间互不相关，从根上消除共线性。
- **为什么不自己拍脑袋定权重（比如 0.5X₁+0.5X₂）？** 拍脑袋权重不是方差最大方向，压缩后信息损失大。PCA 的权重是数学优化出来的：第一主成分方向上样本差异最大、保留信息最多，而且有特征值和贡献率作为判断依据，答辩时说得清、算得明。

## 十一、答辩常问（直接背）

1. **问：你保留几个主成分？怎么定的？** 答：两条标准一起用——Kaiser 准则（Kaiser criterion）只保留特征根 > 1 的主成分，再看碎石图（scree plot）：碎石曲线从陡峭转为平缓的"拐弯"处之前截断，同时满足累计方差贡献率 > 80%。我这里取前 3 个，累计贡献率 82%。
2. **问：PCA 之前为什么必须标准化？不标准化会怎样？** 答：因为 GDP 的单位是万亿、方差巨大，而"城镇化率"是百分比、方差很小。不标准化的话，方差大的 GDP 会完全主导第一主成分，其他指标被忽略——压出来的主成分其实只反映了 GDP。标准化后所有指标方差为 1，比较才公平。
3. **问：PCA 是监督方法还是无监督方法？** 答：无监督。PCA 只用 X 的数据，不需要任何因变量 Y 或类别标签，它自己在 X 的内部结构里找方差最大的方向。这一点和"已知每类是谁"的[[05_判别分析|判别分析]]正好相反。
4. **问：第一主成分代表什么？命名的依据是什么？** 答：看载荷（loadings）。PC1 = 0.818X₁ + 0.576X₂，载荷都在 0.5 以上且同方向，说明这两个指标在同一个方向上，可以命名为"经济发展水平"。命名必须由载荷矩阵读出来，不能凭空编——载荷乱七八糟还硬起名字，答辩一问就崩。

## 十二、速记卡

> **PCA = 对协方差矩阵做特征值分解，找方差最大的方向。**
> 第一主成分 = 最大特征值对应的特征向量，它解释最多信息。
> 贡献率 = 该特征值 / 所有特征值之和。
> 必须先标准化！必须先标准化！必须先标准化！
> 取主成分个数：累计贡献率 > 80%，或特征值 > 1。
> PCA 是因子分析的特例（下一节讲）。
