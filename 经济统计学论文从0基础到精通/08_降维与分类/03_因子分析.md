# 03 因子分析：[[02_主成分分析PCA|PCA]] 的升级版

## 一、为什么要学这个？

PCA 压完维度，有个问题：**主成分是数学产物，不好解释。**

比如你压完 25 个经济指标，得到第一主成分：
$$PC_1 = 0.8GDP + 0.7消费 + 0.6教育 + 0.5医疗 + 0.3科技 + \dots$$

你命名为"经济发展水平"。但你心里清楚：这些指标其实分属不同领域——GDP、消费是"经济规模"，教育、医疗是"公共服务"，科技、专利是"创新能力"。

PCA 把它们全混在一起，让你**一个大杂烩代表所有东西**。这在数学上最优（方差最大），但在经济学解释上很糟糕。

**因子分析（Factor Analysis, FA）** 说：我们假设这些指标背后，有几个**潜在的、看不见的因子**在驱动它们。

比如：
- 你测了 8 个指标：GDP、消费、收入、教育经费、医生数、床位数、专利数、研发投入；
- 因子分析假设：这 8 个指标其实被 **3 个看不见的因子**驱动：
  - 因子 F1 = "经济实力"（GDP、消费、收入在它上面载荷大）；
  - 因子 F2 = "公共服务"（教育、医疗在它上面载荷大）；
  - 因子 F3 = "科技创新"（专利、研发在它上面载荷大）。

**不学会怎样？**
- 用 PCA 压完，主成分含义模糊，答辩时导师问"你第一主成分代表什么经济含义"，你答不上来；
- 想做问卷分析（比如消费者满意度），20 道题背后肯定有几个潜变量（品牌感知、质量感知、价格感知），不用因子分析你根本挖不出来。

## 二、是什么？（先打比方）

### 生活比喻：体检报告

你去医院体检，医生给你测了 20 个指标：血压、血糖、心率、肺活量、血常规 10 项、尿常规 5 项……

这 20 个指标背后，其实只反映 **3 个潜在的"身体系统"**：
- 心血管系统（血压、心率、心电图）；
- 代谢系统（血糖、血脂、尿酸）；
- 呼吸系统（肺活量、血氧）。

你测得的每个指标，都是"某个潜在系统"加"一些随机噪音"的混合体。

**因子分析**就是：从 20 个测得指标里，反推出背后那 3 个潜在系统是什么，以及每个指标主要由哪个系统决定。

### 严格定义

> **因子分析模型**：每个原始变量 $X_j$（[[KP11_标准化_ZScore|标准化]]后）可以写成
> $$X_j = a_{j1}F_1 + a_{j2}F_2 + \dots + a_{jm}F_m + \varepsilon_j$$
> 其中：
> - $F_1, \dots, F_m$ 是**公共因子**（潜在的、看不见的），$m < p$；
> - $a_{ji}$ 是**因子载荷**（第 j 个变量在第 i 个因子上的权重）；
> - $\varepsilon_j$ 是**特殊因子**（该变量独有的噪音，其他变量共享不到）。

和 PCA 的区别：
- PCA：$PC_i$ 是 $X_j$ 的**线性组合**（反向的）；
- FA：$X_j$ 是 $F_i$ 的**线性组合加噪音**（正向的）。

FA 多了一个"特殊因子 $\varepsilon_j$"假设。PCA 假设所有方差都被主成分解释，FA 假设一部分方差被公共因子解释，另一部分是变量独有的。

## 三、公式怎么来的？

**第一步：假设**

我们假设每个变量 $X_j$ 由 $m$ 个公共因子 $F_i$ 线性决定，再加一个独有噪音 $\varepsilon_j$：

$$X_j = a_{j1}F_1 + \dots + a_{jm}F_m + \varepsilon_j$$

**第二步：模型的方差分解**

$X_j$ 的总方差（标准化后 = 1）可以拆成两部分：

$$\text{Var}(X_j) = \underbrace{a_{j1}^2 + a_{j2}^2 + \dots + a_{jm}^2}_{\text{共同度 } h_j^2} + \underbrace{\text{Var}(\varepsilon_j)}_{\text{特殊方差}}$$

- **共同度 $h_j^2$**：第 j 个变量的方差中，被公共因子解释的比例（0 到 1 之间）；
- 特殊方差：剩下没被解释的部分。

我们希望 $h_j^2$ 尽量大——说明这个变量主要被公共因子驱动，不是乱七八糟的噪音。

**第三步：估计载荷矩阵**

最常用的方法是**主成分法**：先跑 PCA，取前 $m$ 个特征向量，然后把它们缩放一下，变成因子载荷。

所以：**PCA 是 FA 的第一步，FA = PCA + [[KP02_因子旋转|因子旋转]]。**

**第四步：因子旋转**（关键步骤）

PCA 出来的载荷矩阵，每个变量在多个因子上都有中等载荷，分不清主次。

因子旋转（最常用**最大方差旋转 Varimax**）的目的：**让每个变量尽量只在一个因子上载荷大，在其他因子上接近 0。**

这样你就能说清楚："GDP 主要由因子 1 决定，医疗主要由因子 2 决定。"

## 三·五、载荷矩阵 A 的三层读法（答辩必问）

估计出来的载荷矩阵 $A=(a_{ji})$ 是一张 $p$ 行（指标）× $m$ 列（因子）的表。这张表有三层读法，很多人学完因子分析只会看第一层。

### 第一层：单个载荷 $a_{ji}$ ——它其实是个"相关系数"

$a_{ji}$ **不是回归系数，而是指标 $X_j$ 与公因子 $F_i$ 的相关系数**。因为模型 $X_j=\sum_i a_{ji}F_i+\varepsilon_j$ 两边对 $F_i$ 取协方差，标准化后正好得到 $a_{ji}=\mathrm{Corr}(X_j,F_i)$。

- 绝对值越大，说明这个指标和这个因子关系越紧；
- 符号为正 = 同向，符号为负 = 反向；
- **多大算"高载荷"？** 经验阈值：$|a_{ji}|\geq 0.7$ 算强（该指标主要被这个因子决定）；0.4~0.7 算中等；<0.4 算弱。0.7 这个线记住——因为 $0.7^2\approx0.5$，意味着这个因子解释了该指标约一半的方差。

**怎么用它命名因子**：看 $A$ 的**第 $i$ 列**，把这一列里 $|a_{ji}|$ 大的那几个指标挑出来，它们共同定义因子 $F_i$ 的含义。比如第 1 列里 GDP=0.94、消费=0.89、收入=0.97 都大 → $F_1$ 叫"经济实力"。

### 第二层：行平方和 $h_j^2$ ——这个指标能不能被因子代表

$$h_j^2=\sum_{i=1}^{m}a_{ji}^2$$

因为 $\mathrm{Var}(X_j)=1=h_j^2+\mathrm{Var}(\varepsilon_j)$，所以 $h_j^2$ 就是"全部公因子对 $X_j$ 方差的解释比例"。

- $h_j^2\approx1$（如 0.95）→ 这个指标几乎全被公因子代表，留着；
- $h_j^2<0.4$ → 这个指标大半是独有噪音，和别的指标不共享信息，**删掉它**重新做。

### 第三层：列平方和 $g_i$ ——这个因子到底有多重要

$$g_i=\sum_{j=1}^{p}a_{ji}^2,\qquad \text{贡献率}=\frac{g_i}{p}$$

$g_i$ 是第 $i$ 个公因子对**全部 $p$ 个指标**方差的总贡献。主成分法估计下 $g_i=\lambda_i$（和 PCA 的特征根直接对应）。列平方和越大、贡献率越高，这个因子越是"主力"。

**一张表总结三层读法**：

| 读法 | 算什么 | 回答什么问题 | 用途 |
|------|--------|-------------|------|
| $a_{ji}$ | 单个载荷（相关系数） | 这个指标和这个因子紧不紧 | **给因子命名** |
| $h_j^2$ | 行平方和 | 这个指标能不能被代表 | **删烂指标** |
| $g_i/p$ | 列平方和占比 | 这个因子重不重要 | **选因子个数、定权数** |

## 四、每个符号是什么？

| 符号 | 是什么 |
|------|--------|
| $X_j$ | 第 j 个原始变量（标准化后） |
| $F_i$ | 第 i 个公共因子（潜在变量，看不见） |
| $a_{ji}$ | 因子载荷：Xj 在 Fi 上的权重 |
| $\varepsilon_j$ | 特殊因子：Xj 独有的噪音 |
| $h_j^2$ | 共同度：Xj 的方差被公共因子解释的比例 |
| $m$ | 公共因子个数（< p） |
| 旋转矩阵 | 正交旋转，让载荷向 0 或 1 两极分化 |

## 五、一个数字例子（迷你版）

**数据**：3 个学生，每个学生测了 3 门课：数学 $X_1$、物理 $X_2$、语文 $X_3$。

| 学生 | $X_1$ | $X_2$ | $X_3$ |
|------|-------|-------|-------|
| A | 90 | 85 | 60 |
| B | 70 | 75 | 85 |
| C | 60 | 65 | 90 |

**观察**：
- 数学和物理成绩高度相关（A 高、C 低）——像同一个"理科因子"驱动；
- 语文和它们负相关（A 低、C 高）——像"文科因子"驱动。

**因子分析的结论**（假设我们提取 2 个因子）：

载荷矩阵（旋转后）大概长这样：

| 变量 | 因子1（理科） | 因子2（文科） | 共同度 $h_j^2$ |
|------|------|------|------|
| 数学 $X_1$ | 0.95 | 0.10 | 0.91 |
| 物理 $X_2$ | 0.90 | 0.20 | 0.85 |
| 语文 $X_3$ | 0.05 | 0.95 | 0.90 |

**怎么读**：
- 数学和物理在因子 1 上载荷 0.9 以上，在因子 2 上接近 0——因子 1 代表"理科能力"；
- 语文在因子 2 上载荷 0.95，在因子 1 上接近 0——因子 2 代表"文科能力"；
- 共同度都在 0.85 以上，说明每个变量 85% 以上的方差被这两个因子解释了，模型不错。

**[[KP03_因子得分|因子得分]]**：每个学生在两个因子上的得分：

| 学生 | 理科因子得分 | 文科因子得分 |
|------|------|------|
| A | 高（+） | 低（-） |
| B | 中 | 中 |
| C | 低（-） | 高（+） |

这比 PCA 清晰多了——PCA 可能把数学、物理、语文全混在一个主成分里，你根本看不出"理科/文科"这个结构。

## 五·五、旋转怎么选？因子得分怎么算？

### 三种旋转流派

| 旋转方法 | 类型 | 让什么两极分化 | 什么时候用 |
|---------|------|---------------|-----------|
| **方差最大旋转 Varimax** | 正交 | 每列的载荷向 0/±1 分散 | **默认选它**，因子独立假设下效果最稳 |
| 四次方最大 Quartimax | 正交 | 每行的载荷向 0/±1（每个变量只归一个因子） | 变量数远多于因子数时 |
| 等量最大 Equamax | 正交 | 列和行同时兼顾 | 两者折中 |
| **Promax / 斜交旋转** | 斜交 | 允许因子之间相关 | 理论上认为"经济水平"和"教育水平"会互相影响时 |

**正交 vs 斜交怎么选？** 先问自己：你相信背后的因子是互相独立的吗？
- 问卷量表分析通常默认因子独立 → Varimax；
- 如果你的因子在现实里明明有关（比如"消费能力"和"收入水平"），硬正交旋转会扭曲结构 → Promax。

### 因子得分：为什么 FA 的得分是"估"出来的？

PCA 的主成分得分 $y_i=u_i'X$ 是**精确计算**的（$u_i$ 已知）。但 FA 里模型 $X=AF+\varepsilon$ 有个"反向"问题：我们要从已知的 $X$ 反推未知的 $F$，而方程数（$p$）多于未知因子数（$m<p$），**没有精确解**，只能估计。

最常用的是 **Thomson 回归法**：把 $F$ 当因变量、$X$ 当自变量做回归，得到
$$\hat F = A'R^{-1}X$$

**这意味着什么？**
- PCA 得分 = 精确投影；
- FA 因子得分 = 带估计误差的近似值。

所以论文里报告 FA 综合排名时，要知道这个排名本身带不确定性。这也是为什么同样一套数据，PCA 排名和 FA 排名会有出入——不是谁错了，而是 FA 多了"估计"这一步。

### FA 综合评价九步流水线

和 PCA 综合评价长得像，但后五步是 FA 特有：

| 步骤 | FA 做法 | 和 PCA 的区别 |
|------|--------|--------------|
| ①~④ | 标准化 → 求 $R$ → 求特征根 → 定因子数 | **完全相同** |
| ⑤ | 初始载荷 $a_{ji}=\sqrt{\lambda_i}\cdot u_{ji}$ | PCA 用特征向量直接当系数 |
| ⑥ | **旋转后再命名因子** | PCA 不旋转，硬解释 |
| ⑦ | Thomson 法估因子得分 $\hat F=A'R^{-1}X$ | PCA 得分精确 |
| ⑧ | 加权 $\hat F=\sum \omega_i\hat F_i$，$\omega_i=\lambda_i/\sum\lambda_i$ | 权数逻辑相同 |
| ⑨ | 排序分类 | 相同 |

**一句话**：FA 比 PCA 多了"旋转 + 估计得分"两步，换来的是"因子含义清晰、能解释差距出在哪个因子上"。代价是得分带误差、计算量更大。

## 六、前提假设

1. **变量之间要有较强的相关性**（KMO 检验 > 0.6 才适合做因子分析）；
2. **变量是连续的**（或近似连续）；
3. **样本量 $n$ 至少是变量数的 5 倍**；
4. **公共因子之间不相关**（正交旋转的假设）；
5. **特殊因子 $\varepsilon_j$ 之间不相关，且与公共因子不相关**。

---

## 七、易错点

1. **KMO 不达标硬做因子分析**：KMO < 0.5 说明变量之间相关性太弱，不适合做因子分析，做了结果也没法解释。
2. **因子个数拍脑袋**：要用碎石图（scree plot）和累计方差贡献率决定。看碎石图"拐弯"在哪里，就取到哪里。
3. **旋转方法选错**：默认用最大方差旋转（正交旋转）。如果你理论上认为因子之间相关（比如"经济水平"和"教育水平"可能互相影响），要用斜交旋转。
4. **共同度太低**：某个变量共同度 < 0.4，说明它大部分方差是独有噪音，应该考虑删掉这个变量。
5. **把因子得分当因果变量**：因子得分是潜在变量的估计值，不是真实的因果变量。

## 八、Python 代码

```python
import pandas as pd
from factor_analyzer import FactorAnalyzer
from factor_analyzer.factor_analyzer import calculate_kmo

# 假设 data 是你的数据框（行=样本，列=指标）
# 这里用一个示例
data = pd.DataFrame({
    'GDP': [10, 12, 8, 15, 6],
    '消费': [8, 9, 7, 12, 5],
    '教育': [7, 8, 6, 10, 5],
    '医疗': [6, 7, 5, 9, 4],
    '专利': [5, 8, 3, 12, 2]
})

# 第一步：KMO 检验
kmo_all, kmo_model = calculate_kmo(data)
print(f"KMO 值：{kmo_model:.3f}")
# KMO > 0.6 才适合做因子分析

# 第二步：提取 2 个因子，做最大方差旋转
fa = FactorAnalyzer(n_factors=2, rotation='varimax', method='principal')
fa.fit(data)

# 第三步：看载荷矩阵
loadings = pd.DataFrame(fa.loadings_, 
                        index=data.columns, 
                        columns=['因子1', '因子2'])
print("因子载荷矩阵：")
print(loadings)

# 第四步：看共同度
print("共同度：")
print(pd.DataFrame(fa.get_communalities(), index=data.columns, columns=['共同度']))

# 第五步：算因子得分（每个样本在两个因子上的位置）
factor_scores = fa.transform(data)
print("因子得分：")
print(factor_scores)
```

## 九、因子分析 vs PCA

| | PCA | 因子分析 |
|---|-----|---------|
| 模型方向 | 主成分 = 原始变量的线性组合 | 原始变量 = 公共因子的线性组合 + 噪音 |
| 有没有噪音 | 没有（所有方差都被主成分解释） | 有特殊因子 |
| 可解释性 | 差（主成分是大杂烩） | 好（旋转后每个因子含义清晰） |
| 用途 | 降维、去共线性、主成分回归 | 问卷分析、潜变量提取、维度结构探索 |
| 数学关系 | PCA 是 FA 的第一步 | FA = PCA + 旋转 + 加特殊因子 |

**简单记**：
- 你只想"压完数据跑回归" → 用 PCA；
- 你想"搞清楚指标背后有几个维度" → 用因子分析。

## 十、为什么不用别的方法？

- **为什么不直接用 PCA 压？** PCA 出来的主成分是"大杂烩"：GDP、消费、教育全混在第一主成分里，你没法说清它到底代表经济规模还是公共服务。因子分析通过因子旋转（最常用最大方差旋转 Varimax），让每个指标只在一个因子上高载荷，旋转后"GDP、收入归因子1，教育、医疗归因子2"，维度结构一眼可辨——做问卷量表分析、写论文"维度划分"部分必须用它。
- **为什么不用 [[04_AHP层次分析法|AHP]]/专家打分直接定维度？** AHP 的维度是专家先验拍出来的，没有数据支撑，答辩时容易被问"你的维度划分是数据说的还是你自己说的"。因子分析从相关矩阵里反推潜在结构，客观得多，而且能输出 KMO、巴特利特球形检验、共同度这些可写进论文的检验指标。
- **为什么 KMO 不达标还要硬做？** KMO < 0.5 说明指标之间共同因子太弱，这时候硬做因子分析，旋转出来的因子载荷乱七八糟、没法命名。正确做法是先删共同度低的指标，或者退回 PCA（PCA 对相关性要求更低，压完至少能跑回归），而不是强行报告一个解释不通的因子结构。

## 十一、答辩常问（直接背）

1. **问：你怎么判断这份数据适不适合做因子分析？** 答：看两个检验。KMO 统计量要 > 0.6（> 0.7 更好），巴特利特球形检验 p < 0.05（拒绝"相关矩阵是单位阵"的原假设）。我这份数据 KMO = 0.76，巴特利特 p < 0.001，适合做。
2. **问：提取几个因子？怎么定的？** 答：Kaiser 准则取特征根 > 1 的因子，配合碎石图（scree plot）看"拐弯"位置，再让累计方差贡献率达到 70% 以上。我这里取 3 个因子，累计贡献率 72%。
3. **问：最大方差旋转（Varimax）是干嘛的？不旋转不行吗？** 答：不旋转时每个指标在多个因子上都有中等载荷，分不清主次；Varimax 正交旋转让载荷向 0 或 ±1 两极分化——每个指标只在一个因子上高载荷，这样才能给因子起名字（"经济实力""公共服务""科技创新"）。旋转不改变模型[[06_拟合优度R²|拟合优度]]，只改变可解释性。
4. **问：共同度（communality）是干嘛的？太低怎么办？** 答：共同度 h² 是每个指标的方差中被公共因子解释的比例。如果某个指标共同度 < 0.4，说明它六成以上的方差是自己独有的噪音，和其他指标不共享信息，应该把它删掉重新做因子分析。

---

## 十二、速记卡

> **因子分析 = 假设指标背后有几个看不见的潜在因子，反推这些因子是什么。**
> 载荷：变量在因子上的权重（>0.5 算高载荷）。
> 共同度：变量的方差被公共因子解释的比例（>0.4 合格）。
> 旋转：让载荷向 0 或 1 两极分化，方便解释。
> KMO > 0.6 才适合做。
> PCA 是"压完就走"，因子分析是"压完还要搞清楚每个维度是什么"。
