# 12 索洛模型与经济增长是什么？（小白版）

## 一、为什么要学这个？

一个国家为什么会变富？为什么中国过去 40 年增长这么快？为什么日本"失去了二十年"？索洛模型就是回答这些问题的。

**写论文的时候**：

- 做"经济增长因素分解"论文，核心是增长核算方程；
- 做"全要素生产率（TFP）测算"论文，索洛残差就是 TFP；
- 做"人口红利/老龄化对经济增长"论文，索洛模型是理论基础。

**不学会会怎样？** 你会以为只要高储蓄就能永远高增长（错了，长期人均增长只靠技术进步），会搞混水平效应和增长效应。

---

## 二、是什么？

### 生活比喻：索洛模型就是"水库模型"

一个国家的资本 $K$ 像一个水库：
- **进水**：投资 $I = sY$（储蓄转化为投资）；
- **出水**：折旧 $\delta K$（机器用旧了）+ 给新增工人配资本 $nK$（人口增长）。

当进水 = 出水时，水库水位稳定——这就是**稳态**。长期里，如果没有技术进步，人均水位不变，人均产出不增长。

### 严格定义

**生产函数**（柯布-道格拉斯）：

$$Y = K^\alpha (AL)^{1-\alpha}$$

- $Y$：产出；$K$：资本；$L$：劳动；$A$：技术水平；
- $\alpha$：资本产出弹性（约 1/3）。

**人均形式**（除以 $L$）：

$$y = \frac{Y}{L} = k^\alpha, \quad k = \frac{K}{L}$$

**资本积累方程**：

$$\Delta k = s \cdot f(k) - (n + \delta)k$$

- $s \cdot f(k)$：人均投资（储蓄全部转化为投资）；
- $(n+\delta)k$：**持平投资**——给新增工人配资本（$nk$）+ 替换折旧（$\delta k$）。

**稳态条件**：$\Delta k = 0$：

$$s \cdot f(k^*) = (n + \delta)k^*$$

**增长核算方程**：

$$\frac{\Delta Y}{Y} = \alpha \frac{\Delta K}{K} + (1-\alpha)\frac{\Delta L}{L} + \frac{\Delta A}{A}$$

最后一项 $\Delta A/A$ 叫**全要素生产率（TFP）增长率**，也叫"索洛残差"——不能用资本和劳动解释的增长，就是技术进步。

---

## 三、公式怎么来的？（手把手推）

**第一步：稳态条件怎么来的？**

资本积累方程 $\Delta k = s f(k) - (n+\delta)k$。稳态时人均资本 $k$ 不再变化，$\Delta k = 0$：

$$s f(k^*) = (n+\delta)k^*$$

**第二步：用具体生产函数 $f(k) = k^{1/2}$ 解稳态**

代入：

$$s \cdot (k^*)^{1/2} = (n+\delta) k^*$$

两边除以 $(k^*)^{1/2}$：

$$s = (n+\delta) (k^*)^{1/2}$$

所以：

$$(k^*)^{1/2} = \frac{s}{n+\delta}$$

两边平方：

$$k^* = \left(\frac{s}{n+\delta}\right)^2$$

人均产出：

$$y^* = (k^*)^{1/2} = \frac{s}{n+\delta}$$

**第三步：增长核算方程怎么来的？**

对 $Y = K^\alpha (AL)^{1-\alpha}$ 取对数：

$$\ln Y = \alpha \ln K + (1-\alpha)\ln A + (1-\alpha)\ln L$$

对时间求导（$\dfrac{d\ln X}{dt} = \dfrac{\dot X}{X} = \dfrac{\Delta X}{X}$）：

$$\frac{\Delta Y}{Y} = \alpha \frac{\Delta K}{K} + (1-\alpha)\frac{\Delta L}{L} + (1-\alpha)\frac{\Delta A}{A}$$

（教材里常把技术进步率 $\Delta A/A$ 简写，把 $(1-\alpha)$ 吸收进去，写成 $\Delta A/A$。）

## 四、一个完整的数字例子 + Python 验证

**题目**：已知 $f(k) = k^{1/2}$，$s = 0.3$，$n = 0.02$，$\delta = 0.08$。求稳态 $k^*$ 和 $y^*$。

**手算**：

稳态条件：$s \cdot k^{1/2} = (n+\delta)k$

代入数字：

$$0.3 \cdot k^{1/2} = (0.02 + 0.08)k = 0.1 k$$

两边除以 $k^{1/2}$：

$$0.3 = 0.1 \cdot k^{1/2}$$

$$k^{1/2} = 3$$

$$k^* = 9$$

$$y^* = (k^*)^{1/2} = 3$$

**储蓄率提高到 s=0.4**：

$$0.4 = 0.1 \cdot k^{1/2} \Rightarrow k^{1/2} = 4 \Rightarrow k^* = 16, y^* = 4$$

储蓄率从 30% 提到 40%，人均产出从 3 涨到 4——富了 33%，但长期增长率还是 0（无技术进步）。

**增长核算例子**：某国年资本增长 3%，劳动增长 1%，GDP 增长 4%，$\alpha = 1/3$。

$$\frac{\Delta A}{A} = 4\% - \frac{1}{3}\times 3\% - \frac{2}{3}\times 1\% = 4\% - 1\% - 0.67\% = 2.33\%$$

技术进步贡献了 2.33 个百分点，是最大头。

```python
import numpy as np

# 索洛稳态
def steady_state(s, n, delta):
    k_star = (s / (n + delta))**2
    y_star = s / (n + delta)
    return k_star, y_star

for s in [0.3, 0.4]:
    k, y = steady_state(s, 0.02, 0.08)
    print(f"s = {s}: k* = {k:.2f}, y* = {y:.2f}")

# 增长核算
dY, dK, dL = 0.04, 0.03, 0.01
alpha = 1/3
dA = dY - alpha*dK - (1-alpha)*dL
print(f"\nTFP 增长 = {dA*100:.2f}%")

# 画索洛相图
k = np.linspace(0, 20, 100)
inv = 0.3 * k**0.5
breakeven = 0.1 * k

import matplotlib.pyplot as plt
plt.figure(figsize=(7,5))
plt.plot(k, inv, label='实际投资 s·f(k)', linewidth=2)
plt.plot(k, breakeven, label='持平投资 (n+δ)k', linewidth=2)
plt.axvline(9, color='red', linestyle=':', label='稳态 k*=9')
plt.xlabel('人均资本 k')
plt.ylabel('人均投资')
plt.title('索洛模型相图')
plt.legend()
plt.grid(alpha=0.3)
plt.savefig('solow.png', dpi=150, bbox_inches='tight')

# 输出：
# s = 0.3: k* = 9.00, y* = 3.00
# s = 0.4: k* = 16.00, y* = 4.00
# TFP 增长 = 2.33%
```

## 五、什么时候能用？（前提条件）

- 规模报酬不变（柯布-道格拉斯生产函数）。
- 资本边际报酬递减（$f''(k) < 0$）。
- 储蓄率 $s$、人口增长率 $n$、折旧率 $\delta$ 外生给定。
- 无技术进步时，长期人均增长为 0；有技术进步时，人均增长 = 技术进步率 $g$。

---

## 六、什么时候不能用？（易错点）

1. **稳态不是"增长停止"**：总产出按人口 $n$ 增长，人均产出不增长（无技术进步时）。
2. **长期人均增长只靠技术进步**：这是索洛模型最重要的结论——高储蓄只有水平效应，没有增长效应。
3. **条件收敛 vs 绝对收敛**：储蓄率、人口增长率相同的国家才收敛到同一稳态。穷国增长快只是因为离自己稳态远，不是"穷本身"。
4. **索洛残差是"我们无知的度量"**：TFP 不只是技术，还包括制度、资源配置、规模经济。

---

## 七、容易和什么搞混？

| 概念 | 一句话 |
|---|---|
| 水平效应 | 储蓄率提高 → 人均产出水平更高 |
| 增长效应 | 技术进步率提高 → 人均产出长期增长率更高 |
| 条件收敛 | 参数相同的国家收敛到同一稳态 |
| 绝对收敛 | 所有国家不管参数如何都收敛（不对） |
| 黄金律 | 让消费最大化的储蓄率 |

## 八、在论文里怎么用？

**1. 经济增长类论文的理论骨架**。论文题目举例：

- 《中国全要素生产率测算与分解》——用索洛残差法或 DEA-Malmquist 指数；
- 《人口老龄化对中国经济增长的影响——基于索洛模型》——n 上升，稳态 k* 下降；
- 《储蓄率下降对中国长期增长的影响》——s 下降，水平效应下降；
- 《创新驱动发展战略的增长效应》——技术进步率 g 上升。

**2. 论文里 TFP 怎么算？**

两步：
1. 从统计年鉴拿实际 GDP、资本存量（永续盘存法算）、就业人数；
2. 代入增长核算方程：$\Delta A/A = \Delta Y/Y - \alpha \Delta K/K - (1-\alpha)\Delta L/L$。

**3. 常见踩坑**：

- **资本存量不是现成数据**：要用永续盘存法自己算：$K_t = K_{t-1}(1-\delta) + I_t$。论文里要写清楚基年和折旧率。
- **$\alpha$ 不要拍脑袋**：用收入法 GDP 里资本报酬占比（中国约 0.4-0.5），不要直接套美国的 1/3。
- **做"收敛"论文要分样本**：沿海内部条件收敛成立，沿海和内地之间不收敛（参数不同）。

## 九、现实意义

- **中国过去 40 年高增长**：起点低（k 远低于稳态），向稳态收敛——"追赶效应"。但越来越接近稳态，必须靠技术进步。
- **"人口红利消失"**：n 下降，稳态 k* 上升，但总产出增长变慢——中国从"人口红利"转向"人才红利"。
- **拉美陷阱**：1970 年代后只靠资本投入，没有技术进步，增长停滞。中国要避免这个，所以搞"新质生产力"。

---

## 十、速记卡

> **稳态：投资 = 持平投资，$s f(k^*) = (n+\delta)k^*$。**
> 长期人均增长只靠技术进步（索洛残差 = TFP）。
> 储蓄率高 → 人均产出水平高（水平效应），但不提高长期增长率。
> 穷国追赶快是因为离稳态远，不是因为穷本身。
