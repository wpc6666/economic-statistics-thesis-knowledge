# 03 失业与奥肯定律是什么？（小白版）

## 一、为什么要学这个？

毕业季你刷 BOSS 直聘投了 100 份简历没回音——这就是失业。宏观里的失业不是"没工作"这么简单，它有严格的统计口径，还和 GDP 死死绑在一起。**写论文的时候**：

- 做"就业政策效果"论文，核心解释变量是失业率；
- 做"经济增长与就业"论文，一定会遇到奥肯定律；
- 做"产业结构升级对就业的影响"论文，要区分摩擦性、结构性、周期性失业。

**不学会会怎样？** 你会把"失业率 = 没工作的人 / 总人口"算错（分母是劳动力，不是总人口），会把"失业率下降"一律当好事（可能是大家都放弃找工作了）。

---

## 二、是什么？

### 生活比喻：劳动力市场像婚恋市场

1000 人城市里，16 岁以上有 800 人。但**不是所有人都在"找对象"（找工作）**：

- 500 人在上班（已婚）；
- 50 人在相亲找对象（失业，正在找工作）；
- 250 人是学生、退休、全职太太、躺平不找对象（**不属于"在找对象市场"**）。

那么"在找对象市场"的人只有 550 个（500+50）。**相亲成功率 = 500/550，相亲失败率 = 50/550 = 9.1%**——不是 50/800。这是新手最常算错的地方。

### 严格定义

劳动统计部门把成年人（16 岁以上）分成三类：

| 类别 | 定义 | 例子 |
|---|---|---|
| **就业者** | 有报酬地工作 | 上班的、自由职业 |
| **失业者** | 没工作，但**最近 4 周在主动找工作** | 投简历没回音 |
| **不属于劳动力** | 既不就业也不在找工作 | 学生、退休、全职主妇、**沮丧工人** |

$$\text{劳动力} = \text{就业人数} + \text{失业人数}$$

$$\text{失业率 } u = \frac{\text{失业人数}}{\text{劳动力人数}} \times 100\%$$

### 失业分三种

| 类型 | 原因 | 持续 | 例子 |
|---|---|---|---|
| **摩擦性失业** | 找工作需要时间 | 几周到几个月 | 应届生找工作、跳槽空窗 |
| **结构性失业** | 技能和岗位长期对不上 | 几个月到几年 | 胶片摄影师被数码淘汰 |
| **周期性失业** | 经济衰退总需求不足 | 随经济周期波动 | 2008 裁员潮、2020 疫情失业 |

**自然失业率 $u_n$** = 摩擦性 + 结构性。哪怕经济再好，这两种也消灭不了。**充分就业 ≠ 失业率为 0，而是周期性失业 = 0**。

### 奥肯定律

> **奥肯定律**：失业率每比自然失业率高 1 个百分点，实际 GDP 就比潜在 GDP 低大约 2 个百分点。

$$\frac{Y - Y_f}{Y_f} = -\beta(u - u_n), \quad \beta \approx 2 \text{（美国经验）}$$

大白话：**失业率比"正常水平"高 1%，经济就少生产 2%**。

---

## 三、公式怎么来的？（手把手推）

**第一步：算失业率**

某国劳动调查数据（亿人）：劳动年龄人口 2.474，就业者 1.457，失业者 0.097。

$$\text{劳动力} = 1.457 + 0.097 = 1.554 \text{ 亿}$$

$$u = \frac{0.097}{1.554} \times 100\% = 6.24\%$$

**这一步为什么分母是劳动力不是总人口？** 因为"学生、退休、躺平"的人本来就没想工作，把他们算进分母会稀释失业率，掩盖真实问题。政策关心的是"有多少想工作却找不到的人"。

**第二步：用奥肯定律算 GDP 缺口**

已知 $Y_f = 100$ 万亿，$u_n = 4\%$，实际 $u = 6\%$。

失业率缺口 = $u - u_n = 6\% - 4\% = 2$ 个百分点。

$$\frac{Y - Y_f}{Y_f} = -2 \times 2\% = -4\%$$

$$Y = Y_f \times (1 - 4\%) = 100 \times 0.96 = 96 \text{ 万亿}$$

**这一步的经济含义**：一个工人失业，不只是少了他一个人的产出——他失业后消费减少（不敢点奶茶、不敢打车），奶茶店和出租车司机收入下降，又让更多人失业。这就是乘数效应，所以 $\beta > 1$（美国是 2）。

## 四、一个完整的数字例子 + Python 验证

**题目**：某国某年总劳动力 1 亿人，其中摩擦性失业 200 万、结构性失业 300 万、周期性失业 250 万。$Y_f = 50$ 万亿，$\beta = 2$。求：(1) 实际失业率；(2) 自然失业率；(3) 是否充分就业；(4) 实际 GDP。

**手算**：

(1) 失业总人数 = 200 + 300 + 250 = 750 万

$$u = \frac{750}{10000} \times 100\% = 7.5\%$$

(2) 自然失业率：

$$u_n = \frac{200 + 300}{10000} \times 100\% = 5\%$$

(3) 周期性失业率 = $250/10000 = 2.5\% > 0$，所以**没达到充分就业**，经济处于衰退。

(4) GDP 缺口：

$$\frac{Y - Y_f}{Y_f} = -2 \times (7.5\% - 5\%) = -2 \times 2.5\% = -5\%$$

$$Y = 50 \times (1 - 5\%) = 47.5 \text{ 万亿}$$

```python
labor_force = 10000  # 万人
friction = 200       # 摩擦性失业万人
struct = 300         # 结构性失业万人
cyclic = 250         # 周期性失业万人
Yf = 50              # 万亿
beta = 2

total_unemp = friction + struct + cyclic
u = total_unemp / labor_force * 100
un = (friction + struct) / labor_force * 100
Y_gap = -beta * (u - un)
Y = Yf * (1 + Y_gap/100)

print(f"实际失业率 u = {u:.1f}%")
print(f"自然失业率 un = {un:.1f}%")
print(f"GDP 缺口 = {Y_gap:.1f}%")
print(f"实际 GDP = {Y:.2f} 万亿")
# 输出：
# 实际失业率 u = 7.5%
# 自然失业率 un = 5.0%
# GDP 缺口 = -5.0%
# 实际 GDP = 47.50 万亿
```

## 五、什么时候能用？（前提条件）

- 奥肯定律是**美国经验规律**，$\beta \approx 2$；中国学术界估计在 1-2 之间，不能直接套用 2。
- 它是**短期关系**：长期里失业率回到自然率，GDP 缺口为 0。
- 劳动统计要能把"失业者"和"不属于劳动力"区分开——中国调查失业率口径和欧美不完全一致。

---

## 六、什么时候不能用？（易错点）

1. **失业率下降不一定是好事**：经济衰退时大量人放弃找工作变成"沮丧工人"，退出劳动力，失业率反而下降——但这不是因为大家都找到工作了。
2. **失业率只反映"有没有工作"，不反映"工作好不好"**：计算机博士送外卖，统计上算就业，实际是人力资源浪费。
3. **自然失业率是估计值，不是直接统计**：不同机构估出来 4%？5%？6%？没有标准答案。
4. **失业回滞（hysteresis）**：长期衰退让工人技能退化，自然失业率本身上升——周期性失业"变成"了结构性失业。

---

## 七、容易和什么搞混？

| 概念 | 一句话 | 区别 |
|---|---|---|
| 失业率 | 失业者 / 劳动力 | 分母是劳动力 |
| 劳动参与率 | 劳动力 / 劳动年龄人口 | 多少人在工作或找工作 |
| 自然失业率 | 充分就业时的失业率 | 摩擦+结构，消灭不了 |
| 周期性失业 | 经济衰退导致的 | 政府要救的就是这个 |
| 充分就业 | 周期性失业 = 0 | 不是失业率 = 0 |

---

## 八、在论文里怎么用？

**1. 失业率是劳动经济学论文的核心变量**。论文题目举例：

- 《重庆市青年失业问题研究》——被解释变量是调查失业率（分年龄、分学历）；
- 《最低工资标准对就业的影响》——双重差分（DID），处理组是上调最低工资的城市，被解释变量是城镇登记失业率；
- 《数字经济发展对就业结构的影响》——被解释变量是第三产业就业占比、城镇调查失业率。

**2. 奥肯定律在论文里怎么用？**

- 做经济增长类论文时，用奥肯定律把 GDP 缺口换算成失业率缺口，作为稳健性检验。
- 写文献综述或政策建议时，引用"奥肯定律估计 $\beta \approx 2$"，说明为什么政府要稳增长——保增长就是保就业。
- 本科论文也可以直接做一个简单回归：$\Delta \ln GDP_t = a + b \cdot \Delta u_t + \varepsilon_t$，预期 $b \approx -2$。

**3. 常见踩坑**：

- 中国有两个失业率：**城镇登记失业率**（主动去社保局登记的，偏低）和**城镇调查失业率**（抽样调查，更准）。论文里一定要说明用哪个，不能混用。
- 跨城市比较失业率时，要考虑流动人口——年轻人去大城市找工作，老家失业率统计不到。
- 不要把"失业率下降"一律解释成经济好转——要看劳动参与率是不是同时下降了。

---

## 九、现实意义

- **央行判断经济冷热的核心指标**：实际失业率 < 自然失业率 → 经济过热要加息；> → 经济衰退要降息。
- **2020 年美国失业率冲到 14.7%**，按奥肯定律 GDP 缺口超过 20%——这就是美联储紧急放水的原因。
- **中国 2023-2024 年 16-24 岁青年调查失业率冲到 21%**——这是结构性问题（大学生供过于求、产业升级慢），不是简单的总需求不足，所以光发消费券解决不了。

---

## 十、速记卡

> **失业率 = 失业者 / 劳动力，不是 / 总人口。**
> 失业分三种：摩擦（找工作要时间）、结构（技能对不上）、周期（经济差）。
> 自然失业率 = 摩擦 + 结构，消灭不了；充分就业 = 周期性失业 = 0。
> 奥肯定律：失业率超自然率 1%，GDP 缺口约 -2%。
