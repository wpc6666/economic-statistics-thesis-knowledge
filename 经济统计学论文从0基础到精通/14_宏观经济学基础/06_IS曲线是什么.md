# 06 IS 曲线是什么？（小白版）

## 一、为什么要学这个？

上一章我们假设投资 $I$ 是固定的。现实里企业投不投资，要看**利率**——利率 5% 时借 100 万一年利息 5 万，企业觉得划算就投；利率涨到 10%，利息 10 万，很多项目就不划算了。

**写论文的时候**：

- 做"货币政策传导"论文，要讲清楚利率怎么通过投资影响 GDP——这就是 IS 曲线；
- 做"利率冲击对房地产投资的影响"论文，本质是估计 IS 曲线里 $d$（投资对利率的敏感度）；
- 做"财政政策挤出效应"论文，IS 曲线右移后利率怎么升、投资怎么降，全靠它。

**不学会会怎样？** 你会以为央行降息 GDP 就立刻涨，不知道中间要经过"利率→投资→收入"这条链子，也不知道为什么"推绳子"在衰退时不管用。

---

## 二、是什么？

### 生活比喻：IS 曲线就是"利率和 GDP 的对照表"

| 利率 r | 企业愿借多少 I | 均衡 GDP Y |
|---|---|---|
| 2%（便宜） | 1000 亿 | 5000 亿 |
| 5%（适中） | 600 亿 | 3000 亿 |
| 10%（贵） | 200 亿 | 1000 亿 |

**利率越高 → 投资越少 → GDP 越低**。把这些 (Y, r) 点画在图上，就是一条向右下倾斜的线——IS 曲线。

### 严格定义

> **IS 曲线**：产品市场达到均衡（计划投资 = 计划储蓄，或 $Y = C + I + G$）时，**利率 $r$ 与国民收入 $Y$** 各种组合的轨迹。

- **I** = Investment（投资）
- **S** = Saving（储蓄）
- IS 曲线就是 $I = S$ 这个均衡条件下所有 (Y, r) 点的集合。

### 符号表

| 符号 | 怎么读 | 是什么 | 生活类比 |
|---|---|---|---|
| $r$ | "利率" | 实际利率 | 借钱的成本 |
| $I = e - dr$ | —— | 投资函数 | $e$ 是自主投资，$d$ 是投资对利率的敏感度 |
| $e$ | "e" | 自主投资 | 不管利率多少都要投的（如更新设备） |
| $d$ | "d" | 投资利率敏感系数 | 利率涨 1%，投资减多少 |
| $S = -\alpha + (1-\beta)Y$ | —— | 储蓄函数 | 上一章推过的 |

---

## 三、公式怎么来的？（手把手推）

**第一步：写出产品市场均衡条件**

两部门经济（家庭 + 企业），均衡时计划投资 = 计划储蓄：

$$I = S$$

**第二步：代入投资函数和储蓄函数**

$$e - dr = -\alpha + (1-\beta)Y$$

左边是投资（利率越高投资越少），右边是储蓄（收入越高储蓄越多）。

**第三步：解出 Y**

把含 $Y$ 的项留在右边，其他移到左边：

$$e - dr + \alpha = (1-\beta)Y$$

两边除以 $(1-\beta)$：

$$Y = \frac{\alpha + e - dr}{1-\beta}$$

**这一步为什么 r 前面是负号？** 因为 r 在分子里是减项。r 上升 → 分子变小 → Y 变小。所以 IS 曲线向右下倾斜。

**展开看看**：

$$Y = \frac{\alpha + e}{1-\beta} - \frac{d}{1-\beta} r$$

- 截距 $(\alpha + e)/(1-\beta)$：利率 r=0 时的均衡收入。
- 斜率 $-d/(1-\beta)$：r 每涨 1 个单位，Y 下降多少。

## 四、一个完整的数字例子 + Python 验证

**题目**：已知 $\alpha = 100$（自发消费），$\beta = 0.8$（MPC），$e = 200$（自主投资），$d = 50$（投资对利率敏感度）。

**第一步：写 IS 方程**

$$Y = \frac{100 + 200 - 50r}{1 - 0.8} = \frac{300 - 50r}{0.2} = 1500 - 250r$$

**第二步：算不同利率下的 Y**

- $r = 2\%$：$Y = 1500 - 250 \times 2 = 1500 - 500 = 1000$
- $r = 4\%$：$Y = 1500 - 250 \times 4 = 1500 - 1000 = 500$
- $r = 6\%$：$Y = 1500 - 250 \times 6 = 0$

利率从 2% 涨到 6%，GDP 从 1000 跌到 0——利率每涨 1 个百分点，GDP 跌 250。

```python
import numpy as np
import matplotlib.pyplot as plt

alpha, beta = 100, 0.8
e, d = 200, 50

# IS 方程：Y = (alpha + e - d*r) / (1 - beta)
def is_curve(r):
    return (alpha + e - d * r) / (1 - beta)

for r in [2, 4, 6]:
    print(f"r = {r}%, Y = {is_curve(r):.1f}")

# 画 IS 曲线
r = np.linspace(0, 8, 100)
Y = is_curve(r)

plt.figure(figsize=(7, 5))
plt.plot(Y, r, linewidth=2, label='IS: Y = 1500 - 250r')
plt.xlabel('国民收入 Y')
plt.ylabel('利率 r (%)')
plt.title('IS 曲线（向右下倾斜）')
plt.grid(alpha=0.3)
plt.legend()
plt.gca().invert_yaxis()  # 纵轴 r 向下增大，符合习惯
plt.savefig('is_curve.png', dpi=150, bbox_inches='tight')

# 输出：
# r = 2%, Y = 1000.0
# r = 4%, Y = 500.0
# r = 6%, Y = 0.0
```

## 五、什么时候能用？（前提条件）

- 短期模型：**价格水平 P 不变**（价格还没引入）。
- 投资只看利率（不看收入、不看预期）——这是简化，现实里投资也受收入影响。
- 两部门（家庭 + 企业）；加政府和进出口后方程会变，但形状还是右下倾斜。

---

## 六、什么时候不能用？（易错点）

1. **IS 曲线不包含价格**：这是短期模型，放开价格就变成 AD 曲线（见 [[09_AD-AS模型是什么|AD-AS 篇]]）。
2. **沿 IS 移动 vs IS 移动要分清**：
   - 利率变 → **沿 IS 移动**（点在曲线上滑）；
   - 自发支出变（政府多花钱、老百姓更敢花）→ **IS 整条移动**。
3. **IS 曲线斜率由 β 和 d 决定**：
   - β 大（MPC 大）→ 乘数大 → IS 平缓；
   - d 大（投资对利率敏感）→ IS 平缓；
   - d 小（困难时期再降息也没人投资）→ IS 很陡，货币政策"推绳子"失效。

---

## 七、容易和什么搞混？

| 概念 | 方向 | 讲哪个市场 |
|---|---|---|
| IS 曲线 | 向右下倾斜 | 产品市场（投资=储蓄） |
| LM 曲线 | 向右上倾斜 | 货币市场（货币需求=货币供给） |
| AD 曲线 | 向右下倾斜 | 物价 P 和总需求 Y 的关系 |
| 微观需求曲线 | 向右下倾斜 | 一种商品价格和需求量 |

---

## 八、在论文里怎么用？

**1. IS 曲线是讲"货币政策传导"的理论框架**。论文题目举例：

- 《中国货币政策利率传导机制的实证研究》——被解释变量是固定资产投资，核心解释变量是贷款基准利率/MLF 利率；
- 《房地产价格、利率与居民消费》——用 IS 曲线框架讲利率怎么影响房贷成本、影响消费；
- 《地方政府融资平台投资对利率的敏感度》——估计 $d$。

**2. 论文里怎么"看到"IS 曲线？**

你跑回归：

$$I_t = a + b \cdot r_t + \varepsilon_t$$

$b$ 就是 $-d$。中国经验估计，国企、政府项目对利率不敏感（$d$ 小），民企、房地产对利率敏感（$d$ 大）——这就是为什么货币政策对民企影响大、对国企影响小。

**3. 常见踩坑**：

- **不要把 IS 曲线当因果线直接回归**：IS 是均衡点集合，不是你观测到的散点。实证里要分别估计投资函数、消费函数，再组合起来。
- **做"降息为什么没用"的论文**，核心就是讲 IS 曲线太陡（企业对利率不敏感，因为预期差），这时要靠财政政策右移 IS，而不是靠货币政策。

---

## 九、现实意义

- **央行降息，就是想沿着 IS 曲线把 r 往下走，从而把 Y 拉起来**。
- **2015 年中国经济下行，央行多次降息，但 GDP 增速还是往下走**——因为企业预期差，IS 曲线本身在左移（自主投资 e 下降），光靠货币政策沿曲线移动没用。
- **"推绳子"**：凯恩斯名言——货币政策像绳子，你可以拉（加息压通胀），但不能推（降息刺激经济）。衰退时 IS 很陡，降息效果差。

---

## 十、速记卡

> **IS 曲线 = 产品市场均衡时 (Y, r) 的组合，向右下倾斜。**
> 方程：$Y = (\alpha + e - dr)/(1-\beta)$，r 前面是负号。
> 利率变 → 沿 IS 移动；自发支出变 → IS 整条移动。
> IS 陡 = 投资对利率不敏感 = 货币政策"推绳子"失效。
