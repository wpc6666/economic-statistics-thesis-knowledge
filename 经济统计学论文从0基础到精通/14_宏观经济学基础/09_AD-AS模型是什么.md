# 09 AD-AS 模型是什么？（小白版）

## 一、为什么要学这个？

IS-LM 模型里价格 P 是固定的。现实里物价在变——疫情后美国通胀冲到 9%，中国 2023 年 CPI 长期在 0 附近。**AD-AS 模型就是放开价格，让物价和产出一起决定**。

**写论文的时候**：

- 做"通胀成因"论文，要分需求拉上还是成本推动——AD-AS 一张图讲清楚；
- 做"滞胀"论文（1970 年代美国、2022 年欧洲），必须用 AS 左移解释；
- 做"疫情双重冲击"论文，要同时画 AD 左移和 AS 左移。

**不学会会怎样？** 你会以为通胀和衰退不会同时发生（错了，滞胀就是），会以为发钱永远是好事（错了，过度发钱会通胀）。

---

## 二、是什么？

### 生活比喻：AD-AS 就是整个国家的"买卖双方谈判桌"

- **AD（总需求）**：全社会想买多少东西——家庭消费、企业投资、政府购买、净出口。物价越高，想买的越少（右下倾斜）。
- **AS（总供给）**：企业愿意生产多少东西。
  - **短期（SRAS）**：物价涨，工资合同没到期，企业利润高，多生产——右上倾斜。
  - **长期（LRAS）**：工资也能调了，物价涨多少工资涨多少，企业没动力多生产——垂直于潜在产出 $Y_f$。

两条线的交点就是均衡。外来冲击分两种：需求冲击（AD 移动）和供给冲击（AS 移动）。

### 严格定义

**AD 曲线**：在其他条件不变时，物价水平 P 与全社会意愿购买的产品和服务总量 Y 之间的关系。向右下倾斜。

**短期 AS（SRAS）**：

$$Y = Y_f + \alpha(P - P^e)$$

- $Y_f$：潜在产出（充分就业产出）；
- $P^e$：预期价格水平；
- $\alpha$：物价超预期上涨时，企业增加产出的幅度。

**长期 AS（LRAS）**：

$$Y = Y_f \quad (\text{垂直})$$

---

## 三、公式怎么来的？（手把手推）

**为什么 AD 向右下倾斜？** 三条链子：

1. **利率效应（凯恩斯）**：物价 P 涨 → 交易需要更多钱 → 货币需求增加 → 利率 r 上升 → 投资 I 下降 → Y 下降。
2. **财富效应（庇古）**：物价涨 → 你手里现金的实际购买力下降 → 觉得自己穷了 → 消费 C 下降 → Y 下降。
3. **汇率效应（蒙代尔-弗莱明）**：国内物价涨 → 本国商品变贵 → 出口下降、进口上升 → NX 下降 → Y 下降。

三条链子都指向：P 高 → Y 低，所以 AD 右下倾斜。

**为什么短期 AS 向右上倾斜？**

公式 $Y = Y_f + \alpha(P - P^e)$。如果实际物价 P 比人们预期的 $P^e$ 高，企业发现产品卖得贵了，但工资（按预期定的合同）没涨，利润增加，就多生产。

**为什么长期 AS 垂直？**

长期里工资合同到期重签，工人发现物价涨了，要求涨工资——工资涨回去，企业成本回到原来水平，就不增产了。不管 P 是 100 还是 200，产出都固定在 $Y_f$。

## 四、一个完整的数字例子 + Python 验证

**题目**：已知 $Y_f = 1000$，初始 AD：$Y = 2000 - 10P$，SRAS：$Y = 1000 + 100(P - 100)$（$P^e = 100$）。

**第一步：初始短期均衡**

联立 AD = SRAS：

$$2000 - 10P = 1000 + 100(P - 100)$$

展开右边：

$$2000 - 10P = 1000 + 100P - 10000$$

$$2000 - 10P = 100P - 9000$$

把含 P 的项移到右边，常数移到左边：

$$2000 + 9000 = 100P + 10P$$

$$11000 = 110P$$

$$P = 100$$

$$Y = 2000 - 10 \times 100 = 1000$$

正好在 $Y_f = 1000$，长期均衡。

**第二步：AD 右移到 $Y = 2500 - 10P$（扩张性政策）**

$$2500 - 10P = 100P - 9000$$

$$11500 = 110P$$

$$P = 104.55$$

$$Y = 2500 - 10 \times 104.55 = 1454.5$$

短期：$Y = 1454.5 > Y_f$（过热），$P = 104.55 > P^e = 100$。

**第三步：长期调整**

工人发现物价涨了，要求涨工资，$P^e$ 从 100 调到 104.55。新 SRAS：$Y = 1000 + 100(P - 104.55)$。

长期里 $Y$ 回到 $Y_f = 1000$，代入新 AD：

$$1000 = 2500 - 10P$$

$$P = 150$$

**结论**：短期 Y 从 1000 涨到 1454.5，P 从 100 涨到 104.55；长期 Y 回到 1000，P 进一步涨到 150——**扩张性需求政策短期能增产，长期只涨价（货币中性）**。

```python
import numpy as np

Yf = 1000
P = np.linspace(90, 160, 100)

# AD1: Y = 2000 - 10P
AD1 = 2000 - 10*P
# AD2（扩张后）: Y = 2500 - 10P
AD2 = 2500 - 10*P
# SRAS 初始（Pe=100）: Y = 1000 + 100(P-100)
SRAS1 = 1000 + 100*(P - 100)

import matplotlib.pyplot as plt
plt.figure(figsize=(8, 6))
plt.plot(P, AD1, label='AD1', linewidth=2)
plt.plot(P, AD2, label='AD2（扩张后）', linewidth=2, linestyle='--')
plt.plot(P, SRAS1, label='SRAS（Pe=100）', linewidth=2)
plt.axvline(Yf, color='red', linestyle=':', label='LRAS: Y=Yf=1000')
plt.axvline(1000, color='gray', alpha=0)
plt.xlabel('物价 P')
plt.ylabel('产出 Y')
plt.title('AD-AS 模型：需求扩张的短期与长期效应')
plt.legend()
plt.grid(alpha=0.3)
plt.savefig('ad_as.png', dpi=150, bbox_inches='tight')

# 数值验证
print("=== 初始均衡 ===")
P_eq = 11000/110
print(f"P = {P_eq:.2f}, Y = {2000-10*P_eq:.2f}")
print("=== AD 右移后短期均衡 ===")
P_sr = 11500/110
print(f"P = {P_sr:.2f}, Y = {2500-10*P_sr:.2f}")
print("=== 长期均衡 ===")
print(f"Y = 1000, P = {(2500-1000)/10:.2f}")
```

## 五、什么时候能用？（前提条件）

- 短期 AS 向右上倾斜，假设工资和价格有粘性（合同没到期、调价有菜单成本）。
- 长期 AS 垂直，假设工资和价格充分灵活。
- 潜在产出 $Y_f$ 由供给侧（资本、劳动、技术）决定，与物价无关。

---

## 六、什么时候不能用？（易错点）

1. **需求冲击：P 和 Y 同方向变**（AD 右移，P 和 Y 都涨）。
2. **供给冲击：P 和 Y 反方向变**（AS 左移，P 涨、Y 降 = 滞胀）。
3. **长期里经济自动回到 $Y_f$**，但可能要几年，社会代价大——这就是政府干预的理由。
4. **不要把 AD 曲线当微观需求曲线加总**：微观讲一种商品价格和需求量，AD 讲总体物价和总产出。

---

## 七、容易和什么搞混？

| 冲击类型 | AD/AS 怎么移 | 短期结果 | 政策含义 |
|---|---|---|---|
| 需求扩张（发钱降息） | AD 右移 | P↑、Y↑ | 短期刺激，长期通胀 |
| 需求收缩（经济危机） | AD 左移 | P↓、Y↓ | 衰退，要扩需求 |
| 不利供给冲击（石油涨价） | AS 左移 | P↑、Y↓（滞胀） | 两难：扩需求通胀，不干预衰退 |
| 有利供给冲击（技术进步） | AS 右移 | P↓、Y↑ | 黄金时代，不用干预 |

---

## 八、在论文里怎么用？

**1. AD-AS 是宏观经济冲击分析的标准框架**。论文题目举例：

- 《国际油价冲击对中国通胀的传导效应》——不利供给冲击，AS 左移；
- 《疫情后中美通胀对比——需求拉上 vs 供给瓶颈》——美国 AD 过度右移 + AS 左移；
- 《数字经济发展对中国潜在产出的影响》——长期 LRAS 右移。

**2. 论文里怎么用 AD-AS？**

- 做"通胀成因分解"：把通胀率 $\pi_t$ 分解成需求拉动部分（产出缺口）和成本推动部分（油价、工资）。
- 做"产出缺口"估计：$Y_gap = (Y - Y_f)/Y_f$，是央行判断经济冷热的核心指标。
- 论文里跑回归：$\pi_t = a + b \cdot Y_{gap,t} + c \cdot \pi_{oil,t} + \varepsilon_t$，b 显著为正就是需求拉上，c 显著为正就是成本推动。

**3. 常见踩坑**：

- **不要把通胀全归因于需求**：1970 年代滞胀是供给冲击，2022 年美国通胀是需求 + 供给双重。论文里要分清楚。
- **做"政策效果"论文要分短期长期**：短期 AD 移动影响 Y，长期只有 P 变——不能用短期效果推长期。


**📊 对应统计方法**：

- [[../09_时间序列/07_协整与误差修正ECM|协整ECM]] —— AD-AS 模型里产出缺口、物价、货币供应的长期关系用协整，短期波动用 ECM。
- [[../03_相关与回归/02_什么是回归|回归分析]] —— 用回归估计总产出对物价、货币供给、财政支出的反应，得到 AD 曲线斜率。

## 九、现实意义

- **1973 年石油危机**：油价涨 4 倍，SRAS 左移——西方经济陷入"滞胀"（通胀 12%、失业率 9%）。传统凯恩斯政策（扩需求）让通胀更厉害，不干预又要长时间衰退。
- **2020 年疫情**：双重冲击——需求侧大家不敢花钱（AD 左移），供给侧工厂停工（AS 左移）。美国靠大规模发钱扩 AD，短期恢复快，但 2022 年通胀冲到 9%。
- **2022 年俄乌战争**：欧洲能源危机，AS 左移，通胀冲到 10%+，经济衰退——又是一次滞胀困境。

---

## 十、速记卡

> **AD 右下倾斜（物价高需求少），SRAS 右上倾斜（物价高企业多产），LRAS 垂直（长期只看供给）。**
> 需求冲击：P 和 Y 同方向；供给冲击：P 和 Y 反方向（滞胀）。
> 扩张需求短期增产，长期只涨价（货币中性）。
> 长期 Y 由 $Y_f$ 决定，要提高生活水平只能靠技术进步（LRAS 右移）。
