# 07 LM 曲线与货币需求是什么？（小白版）

## 一、为什么要学这个？

凯恩斯问了个奇怪的问题：**人们为什么愿意持有现金，而不是全部买成能生息的债券？** 现金拿在手里不生利息，但大家还是会留一部分。

**写论文的时候**：

- 做"货币需求函数"论文，核心就是估计 $L = kY - hr$ 里的 k 和 h；
- 做"央行放水为什么没用"论文，要讲流动性陷阱；
- 做"利率决定"论文，货币市场均衡就是 LM 曲线。

**不学会会怎样？** 你会以为央行印多少钱 GDP 就涨多少，不知道老百姓和银行可能把钱"憋"在手里不花。

---

## 二、是什么？

### 生活比喻：你钱包里为什么留现金？

- **交易动机**：买菜、交房租，总得留点现金——收入越高，交易越多，留的现金越多。
- **预防动机**：万一突然生病、车坏了，得有应急钱——也是收入越高越留得多。
- **投机动机**：你觉得债券价格要跌，先拿着现金观望——**利率越高，你越愿意买债券（持币机会成本大），持币越少**。

前两个跟收入成正比，第三个跟利率成反比。

### 严格定义

> **流动性偏好（货币需求）$L$**：人们愿意以货币（现金、活期存款）形式持有的财富量。

$$L = L_1(Y) + L_2(r) = kY - hr$$

- $L_1 = kY$：交易 + 预防需求，随收入 Y 增加；
- $L_2 = -hr$：投机需求，随利率 r 上升而下降；
- $k$：货币需求的收入敏感度；
- $h$：货币需求的利率敏感度。

**货币市场均衡条件**：货币需求 = 货币供给。

$$L = \frac{M}{P}$$

$M$ 是名义货币供给（央行定的），$P$ 是价格水平，$M/P$ 是实际货币供给。

### LM 曲线方程

代入 $L = kY - hr$：

$$kY - hr = \frac{M}{P}$$

解出 $Y$：

$$Y = \frac{M/P}{k} + \frac{h}{k} r$$

**r 前面系数是正的**：利率越高，收入越高。所以 LM 曲线**向右上方倾斜**。

---

## 三、公式怎么来的？（手把手推）

**为什么 LM 向右上倾斜？**

- 收入 $Y$ 上升 → 交易需求 $L_1 = kY$ 增加 → 在货币供给 $M/P$ 不变的情况下，钱被交易需求占走了。
- 为了让老百姓愿意少持有投机货币（把钱腾出来给交易用），利率 $r$ 必须上升——利率高了，持币机会成本大，大家才愿意少拿现金。
- 所以 $Y$ 高 → $r$ 高，正向关系。

**债券价格和利率反向的直觉**：一张永远每年付 100 元利息的债券，市场利率 5% 时，它值多少钱？

$$P_b = \frac{100}{0.05} = 2000 \text{ 元}$$

如果利率涨到 10%：

$$P_b = \frac{100}{0.10} = 1000 \text{ 元}$$

**利率上升 → 债券价格下跌 → 持有债券的人亏钱**。所以利率高时大家抢着买债券（预期利率会跌回来、债券价格会涨），持币少；利率低时大家宁可持现金（预期利率要涨、债券要跌），持币多。

## 四、一个完整的数字例子 + Python 验证

**题目**：已知 $k = 0.5$，$h = 100$，实际货币供给 $M/P = 200$。写出 LM 方程，并算 $Y = 600$ 时的均衡利率。

**第一步：写 LM 方程**

$$0.5Y - 100r = 200$$

移项：

$$0.5Y = 200 + 100r$$

两边除以 0.5：

$$Y = 400 + 200r$$

解出 r：

$$r = 0.005Y - 2$$

**第二步：代入 Y = 600**

$$r = 0.005 \times 600 - 2 = 3 - 2 = 1 \text{（即 1%）}$$

**第三步：如果央行把 M/P 增加到 300**

$$0.5Y - 100r = 300$$

$$Y = 600 + 200r$$

同样 $Y = 600$ 时：

$$r = 0.005 \times 600 - 3 = 0$$

利率降到 0——LM 曲线右移了。

```python
import numpy as np
import matplotlib.pyplot as plt

k, h = 0.5, 100
M_P1 = 200  # 初始实际货币供给
M_P2 = 300  # 央行放水后

# LM: Y = (M/P)/k + (h/k)*r
def lm_curve(M_P, r):
    return M_P/k + (h/k)*r

Y = np.linspace(0, 800, 100)
r1 = (k*Y - M_P1)/h
r2 = (k*Y - M_P2)/h

plt.figure(figsize=(7, 5))
plt.plot(Y, r1, linewidth=2, label='LM（M/P=200）')
plt.plot(Y, r2, linewidth=2, linestyle='--', label='LM（M/P=300，央行放水）')
plt.xlabel('国民收入 Y')
plt.ylabel('利率 r (%)')
plt.title('LM 曲线与央行放水')
plt.grid(alpha=0.3)
plt.legend()
plt.savefig('lm_curve.png', dpi=150, bbox_inches='tight')

# 验证 Y=600 时的利率
for M_P in [200, 300]:
    r = (k*600 - M_P)/h
    print(f"M/P={M_P}, Y=600 时 r = {r:.2f}%")

# 输出：
# M/P=200, Y=600 时 r = 1.00%
# M/P=300, Y=600 时 r = 0.00%
```

## 五、什么时候能用？（前提条件）

- 短期：价格 P 不变，所以实际货币供给 M/P 由央行名义货币 M 决定。
- 货币需求只看收入和利率（不看财富、不看预期变化）。
- 两个极端区域（凯恩斯、古典）是理论边界，现实大多在中间区域。

---

## 六、什么时候不能用？（易错点）

1. **流动性陷阱（凯恩斯陷阱）**：利率极低时，人们一致预期利率只会涨、债券价格只会跌，于是不管央行增发多少货币，人们都愿意以现金持有——货币需求无穷大，LM 曲线**水平**。这时货币政策失效。
2. **古典极端**：利率极高，投机货币需求 = 0，货币需求只看收入，LM 曲线**垂直**。这时财政政策完全失效（100% 挤出）。
3. **货币乘数不是央行能完全控制的**：银行如果惜贷、老百姓如果持现金，放水放不到实体经济。

---

## 七、容易和什么搞混？

| 区域 | LM 形状 | 货币政策效果 | 财政政策效果 |
|---|---|---|---|
| 凯恩斯区域（r 极低） | 水平 | **无效**（发多少都被持有） | **完全有效**（无挤出） |
| 中间区域 | 向右上倾斜 | 部分有效 | 部分有效（有挤出） |
| 古典区域（r 极高） | 垂直 | **极有效** | **完全无效**（100% 挤出） |

**L 代表 Liquidity preference（流动性偏好），M 代表 Money supply（货币供给）**——两个单词的首字母。

---

## 八、在论文里怎么用？

**1. 货币需求函数是货币经济学论文的核心**。论文题目举例：

- 《中国货币需求函数的稳定性研究》——跑 $M2/P_t = a + b \cdot Y_t + c \cdot r_t + \varepsilon_t$，看 b、c 是否显著；
- 《数字支付发展对现金需求的影响》——被解释变量是 M0/GDP，核心解释变量是移动支付普及率；
- 《流动性陷阱与中国货币政策有效性》——用 LM 曲线水平段解释为什么降息效果递减。

**2. 论文里 k 和 h 怎么估？**

回归方程：

$$\ln(M2/P)_t = a + b \cdot \ln GDP_t + c \cdot r_t + \varepsilon_t$$

- $b$ 就是货币需求的收入弹性（对应 k）；
- $c$ 就是货币需求的利率敏感度（对应 h）。
- 中国经验估计 b ≈ 1.2-1.5（收入涨 1%，货币需求涨 1.2%），c 不显著（利率管制，老百姓对利率不敏感）。

**3. 常见踩坑**：

- **M2 不是央行想控就控**：M2 = 基础货币 × 货币乘数，乘数受银行和公众行为影响。2008 年后美国银行存了大量超额准备金，货币乘数从 8 跌到 3，QE 放的水没流进实体经济。
- **做"央行放水为什么物价不涨"论文**，答案就在流动性陷阱：钱被银行和老百姓持有，不买债券、不投资、不消费。


**📊 对应统计方法**：

- [[../09_时间序列/07_协整与误差修正ECM|协整ECM]] —— 货币需求 $L(Y,i)$ 与收入、利率的长期关系用协整检验，短期货币市场失衡用 ECM 修正。
- [[../09_时间序列/05_ARIMA建模流程|ARIMA]] —— 对货币供应量或 M2 增速做 ARIMA 建模，预测货币政策走向。

## 九、现实意义

- **2008 年后美国、日本利率降到接近 0**，央行拼命 QE 但经济还是不动——这就是流动性陷阱。老百姓和企业被吓怕了，拿到钱就存着。
- **日本"失去的二十年"**：LM 水平段，货币政策失效，最后靠安倍经济学"三支箭"（财政 + 货币 + 结构改革）才慢慢爬出来。
- **中国 2022-2024 年也在向流动性陷阱靠近**：央行多次降息降准，但居民提前还贷、企业不敢投资——钱在银行体系空转。

---

## 十、速记卡

> **货币需求三动机：交易、预防（看收入 Y）、投机（看利率 r）。**
> $L = kY - hr$，货币市场均衡：$L = M/P$。
> LM 曲线向右上倾斜：Y 高需要更多交易货币，r 必须升。
> 流动性陷阱 = LM 水平 = 货币政策失效；古典区域 = LM 垂直 = 财政政策失效。
