# 04 消费函数与储蓄函数是什么？（小白版）

## 一、为什么要学这个？

你这个月工资 1 万块，花掉 8000、存下 2000。**消费函数**就是描述"收入多少时花多少"的公式。**写论文的时候**：

- 做"居民消费影响因素"论文，核心就是估计消费函数；
- 做"收入差距与消费"论文，要算 MPC（边际消费倾向）；
- 做"财政政策乘数"论文，MPC 是你算乘数的关键参数。

**不学会会怎样？** 你会把 MPC（多赚 1 块花几毛）和 APC（总共花了几成）搞混，会以为收入为 0 时消费也是 0。

---

## 二、是什么？

### 生活比喻：消费函数就是你的"工资-花钱"对照表

| 月工资 Y | 你花掉 C | 你存下 S |
|---|---|---|
| 0（吃老本） | 3000（房租吃饭不能省） | -3000 |
| 5000 | 5000 | 0 |
| 10000 | 8000 | 2000 |
| 20000 | 13000 | 7000 |

凯恩斯发现一条心理规律：**收入涨了，消费也涨，但不会涨那么多**。你从月薪 1 万涨到 1.5 万，多出来的 5000 块你可能只花 3500、存 1500——这就是"边际消费倾向递减"。

### 严格定义

> **消费函数**：消费 $C$ 随可支配收入 $Y$ 变化的关系：

$$C = \alpha + \beta Y$$

- $\alpha$：**自发消费**——就算收入为 0，你也得吃饭租房，靠存款或借钱也要花的钱。
- $\beta$：**边际消费倾向（MPC）**——每多赚 1 块钱，多花多少钱。$0 < \beta < 1$。
- $\beta Y$：**引致消费**——由收入引出来的消费。

**储蓄函数**：$S = Y - C$，代入消费函数：

$$S = Y - (\alpha + \beta Y) = -\alpha + (1-\beta)Y$$

- $-\alpha$：收入为 0 时你得"负储蓄"（吃老本/借钱）。
- $1-\beta$：**边际储蓄倾向（MPS）**——每多赚 1 块钱，多存多少钱。

### 四个比率

| 比率 | 公式 | 含义 |
|---|---|---|
| **APC** 平均消费倾向 | $APC = C/Y$ | 总收入里花掉的比例 |
| **MPC** 边际消费倾向 | $MPC = \Delta C/\Delta Y = \beta$ | 多赚 1 块里花掉的比例 |
| **APS** 平均储蓄倾向 | $APS = S/Y$ | 总收入里存下的比例 |
| **MPS** 边际储蓄倾向 | $MPS = \Delta S/\Delta Y = 1-\beta$ | 多赚 1 块里存下的比例 |

**两条铁律**：

$$APC + APS = 1 \quad (\text{因为 } C+S=Y)$$

$$MPC + MPS = 1 \quad (\text{因为 }\Delta C+\Delta S=\Delta Y)$$

---

## 三、公式怎么来的？（手把手推）

**为什么 APC > MPC？**

把 $C = \alpha + \beta Y$ 代入 APC：

$$APC = \frac{C}{Y} = \frac{\alpha + \beta Y}{Y} = \frac{\alpha}{Y} + \beta$$

**这一步为什么这么拆？** 因为分子是两项相加，除以 $Y$ 就是两项分别除以 $Y$。

**观察**：$\alpha/Y > 0$，所以 $APC = \beta + \text{一个正数} > \beta = MPC$。

**经济含义**：收入越低，$\alpha/Y$ 这一项越大，APC 越超过 MPC——**穷人几乎把全部收入都花掉**（甚至不够花，要借钱）。富人收入高，$\alpha/Y$ 接近 0，APC 接近 MPC。

---

## 四、一个完整的数字例子 + Python 验证

**题目**：已知消费函数 $C = 300 + 0.75Y$（单位：亿元）。求 $Y=1000$ 和 $Y=2000$ 时的 $C$、$S$、APC、MPC、APS、MPS。

**当 $Y=1000$：**

$$C = 300 + 0.75 \times 1000 = 300 + 750 = 1050$$

$$S = Y - C = 1000 - 1050 = -50 \text{（负储蓄，吃老本）}$$

$$APC = C/Y = 1050/1000 = 1.05 \text{（花的比赚的多！）}$$

$$APS = S/Y = -50/1000 = -0.05$$

$$MPC = 0.75, \quad MPS = 0.25$$

**当 $Y=2000$：**

$$C = 300 + 0.75 \times 2000 = 1800$$

$$S = 2000 - 1800 = 200$$

$$APC = 1800/2000 = 0.9$$

$$APS = 200/2000 = 0.1$$

$$MPC = 0.75, \quad MPS = 0.25$$

**观察**：收入从 1000 涨到 2000，多赚 1000，多花 750（MPC=0.75），多存 250（MPS=0.25）。APC 从 1.05 降到 0.9——收入越高，花掉的比例越小。MPC 始终是 0.75（线性消费函数的斜率不变）。

```python
alpha = 300
beta = 0.75

for Y in [1000, 2000]:
    C = alpha + beta * Y
    S = Y - C
    APC = C / Y
    APS = S / Y
    print(f"Y={Y}: C={C:.0f}, S={S:.0f}, APC={APC:.3f}, APS={APS:.3f}, MPC={beta}, MPS={1-beta}")

# 输出：
# Y=1000: C=1050, S=-50, APC=1.050, APS=-0.050, MPC=0.75, MPS=0.25
# Y=2000: C=1800, S=200, APC=0.900, APS=0.100, MPC=0.75, MPS=0.25
```

## 五、什么时候能用？（前提条件）

- 凯恩斯消费函数是**短期**模型：看现期收入对消费的影响。
- 假设 $0 < MPC < 1$：你不会把多赚的 1 块钱全花掉，也不会全存下。
- 线性形式是简化，现实里消费函数可能是曲线（边际消费倾向递减）。

---

## 六、什么时候不能用？（易错点）

1. **APC 可以大于 1**：低收入时花的比赚的多（刷信用卡），这是正常的，不是算错。
2. **MPC 是斜率，APC 是射线斜率**：在图上，MPC 是消费曲线切线的斜率，APC 是该点与原点连线的斜率。
3. **凯恩斯只看现期收入太简单**：后来弗里德曼说消费看**长期平均收入**（恒久收入假说），一次性奖金不会全花掉；莫迪利安尼说人一生平滑消费（生命周期假说）。
4. **临时减税刺激消费效果差**：老百姓知道这是一次性的，不会多花——政策含义：要刺激消费得永久性减税。

## 七、容易和什么搞混？

| 概念 | 一句话 | 和别的关系 |
|---|---|---|
| MPC | 多赚 1 块花几毛 | 消费函数斜率 |
| APC | 总共花了几成 | C/Y |
| MPS | 多赚 1 块存几毛 | = 1 − MPC |
| 自发消费 α | 收入 0 也要花的钱 | 截距 |
| 恒久收入 | 长期平均收入 | 弗里德曼 |

## 八、在论文里怎么用？

**1. 消费函数是宏观实证论文的"母模型"**。论文题目举例：

- 《城乡收入差距对居民消费的影响》——被解释变量是居民消费率（消费/GDP），核心解释变量是城乡收入比；
- 《人口老龄化对中国居民储蓄率的影响》——被解释变量是储蓄率 = 1 − APC；
- 《数字金融发展对居民消费的影响》——被解释变量是消费增速，用 CHFS 或 CFPS 微观数据库。

**2. MPC 在论文里怎么估计？**

跑一个简单回归：

$$\Delta C_t = a + b \cdot \Delta Y_t + \varepsilon_t$$

$b$ 就是 MPC。中国宏观数据估计出来 MPC 大概在 0.5-0.7 之间（比美国低，因为老百姓爱存钱、要为买房教育医疗养老储蓄）。

**3. 常见踩坑**：

- **不要用 GDP 当 Y 跑消费函数**，要用**可支配收入** $Y_d = Y - T$（扣税之后的钱）。宏观数据从统计局"居民人均可支配收入"拿。
- **加时间趋势或滞后消费**：消费有惯性（棘轮效应），今年消费受去年影响——论文里要加 $C_{t-1}$ 当控制变量。
- **中国 MPC 城乡差异大**：农村 MPC 高（穷人），城镇 MPC 低——做异质性分析时要分样本回归。


**📊 对应统计方法**：

- [[../03_相关与回归/02_什么是回归|回归分析]] —— 凯恩斯消费函数 $C=\alpha+\beta Y_d+\varepsilon$，$\beta$ 就是边际消费倾向，用 OLS 直接估。
- [[../09_时间序列/07_协整与误差修正ECM|协整ECM]] —— 消费和收入都是 I(1)，必须用协整检验确认长期关系，再用 ECM 刻画短期偏离的修正。

## 九、现实意义

- **为什么发消费券比发现金更能刺激消费**：消费券"必须花掉"，相当于强制提高 MPC；发现金老百姓可能存起来。
- **为什么疫情后中国消费恢复慢**：老百姓对未来收入没信心，恒久收入预期下降，MPC 变低了——拿到钱就存着，不敢花。
- **为什么要"提振内需"**：中国 MPC 低、储蓄率高（40%+），经济增长过度依赖投资和出口——要让老百姓敢花钱，得搞社保、降房价、减教育医疗负担。

---

## 十、速记卡

> **$C = \alpha + \beta Y$：α 是吃饭钱（收入 0 也要花），β 是 MPC（多赚 1 块花几毛）。**
> MPC + MPS = 1，APC + APS = 1。
> APC > MPC，因为穷人吃饭钱占收入比重大。
> 论文里用可支配收入不是 GDP，MPC 要回归估出来。
