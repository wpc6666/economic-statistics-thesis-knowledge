# 10 菲利普斯曲线是什么？（小白版）

<div style="text-align:right;margin:10px 0;"><a href="../../exam.html" target="_blank" style="display:inline-block;padding:6px 16px;background:#2563eb;color:#fff;border-radius:6px;text-decoration:none;font-size:14px;">📝 开始做题</a></div>


## 一、为什么要学这个？

1958 年，菲利普斯研究英国 1861-1957 年数据，发现一个经验规律：**失业率高的时候，工资涨得慢；失业率低的时候，工资涨得快**。后来萨缪尔森把它改成：**失业率低 → 通胀率高；失业率高 → 通胀率低**。

**写论文的时候**：

- 做"通胀与失业替代关系"论文，核心就是估计菲利普斯曲线斜率；
- 做"货币政策成本"论文，要算牺牲率（压 1% 通胀要牺牲多少 GDP）；
- 做"中国菲利普斯曲线扁平化"论文，要解释为什么通胀越来越低、失业越来越高。

**不学会会怎样？** 你会以为政府可以永远用高通胀换低失业（错了，长期不成立），会搞混短期和长期菲利普斯曲线。

---

## 二、是什么？

### 生活比喻：通胀和失业是"跷跷板"

短期里，通胀和失业像跷跷板两头：
- 政府想把失业压下去（扩需求）→ 企业抢工人 → 工资涨 → 通胀涨；
- 政府想把通胀压下去（紧缩）→ 企业减产 → 裁员 → 失业涨。

但 1970 年代"滞胀"出现后，弗里德曼和菲尔普斯说：**长期里这事儿不成立**——长期菲利普斯曲线是垂直的，通胀和失业没有替代关系。

### 严格定义

**短期菲利普斯曲线**：

$$\pi = \pi^e - \beta(u - u_n)$$

- $\pi$：通胀率；
- $\pi^e$：预期通胀率；
- $u$：实际失业率，$u_n$：自然失业率；
- $\beta$：通胀对失业缺口的敏感度。

**直觉**：失业率低于自然率（经济过热），工资涨得快，通胀就高于预期通胀。

**长期菲利普斯曲线**：长期里预期 $\pi^e$ 会调整到实际 $\pi$，此时 $u = u_n$——不管通胀是多少，失业率都等于自然率。**长期菲利普斯曲线是垂直的**。

---

## 三、公式怎么来的？（手把手推）

短期 AS 方程是 $Y = Y_f + \alpha(P - P^e)$。两边除以 $Y_f$，用增长率近似：

$$\frac{Y - Y_f}{Y_f} = \alpha \frac{P - P^e}{P^e} \approx \alpha(\pi - \pi^e)$$

**这一步为什么可以近似？** 物价增长率 $\pi \approx (P - P_{-1})/P_{-1}$，预期物价增长率 $\pi^e \approx (P^e - P_{-1})/P_{-1}$，所以 $P - P^e$ 除以 $P_{-1}$ 就是 $\pi - \pi^e$。

再用奥肯定律：$\dfrac{Y - Y_f}{Y_f} = -\beta_1(u - u_n)$。

两个式子联立：

$$-\beta_1(u - u_n) = \alpha(\pi - \pi^e)$$

整理：

$$\pi - \pi^e = -\frac{\beta_1}{\alpha}(u - u_n)$$

$$\pi = \pi^e - \beta(u - u_n), \quad \beta = \frac{\beta_1}{\alpha}$$

**这就是菲利普斯曲线**。它和短期 AS 是一枚硬币的两面——AS 讲物价和产出，菲利普斯讲通胀和失业，通过奥肯定律转了一下。

## 四、一个完整的数字例子 + Python 验证

**题目**：已知 $\pi^e = 2\%$，$\beta = 0.5$，$u_n = 5\%$。求：
1. $u = 3\%$ 时的 $\pi$
2. $u = 7\%$ 时的 $\pi$
3. 长期里 $u = 3\%$ 一直维持，$\pi$ 会怎么变？

**手算**：

公式 $\pi = \pi^e - \beta(u - u_n)$。

(1) $u = 3\%$：

$$\pi = 2\% - 0.5 \times (3\% - 5\%) = 2\% - 0.5 \times (-2\%) = 2\% + 1\% = \mathbf{3\%}$$

(2) $u = 7\%$：

$$\pi = 2\% - 0.5 \times (7\% - 5\%) = 2\% - 0.5 \times 2\% = 2\% - 1\% = \mathbf{1\%}$$

(3) **长期调整**：如果政府一直把 $u$ 压在 3%，工人发现通胀是 3% 不是预期的 2%，就会把 $\pi^e$ 从 2% 调到 3%。

新短期菲利普斯曲线：$\pi = 3\% - 0.5(u - 5\%)$。

同样 $u = 3\%$ 时：

$$\pi = 3\% - 0.5 \times (-2\%) = 4\%$$

**结果**：通胀从 3% 涨到 4%。工人再把 $\pi^e$ 调到 4%，通胀涨到 5%……一直到工人预期追上实际通胀，但 $u$ 回不到 3%——长期 $u$ 必须等于 $u_n = 5\%$。

```python
pi_e = 2.0
beta = 0.5
un = 5.0

for u in [3, 7]:
    pi = pi_e - beta*(u - un)
    print(f"u = {u}%, π = {pi:.1f}%")

# 模拟长期调整：政府一直压 u=3%
print("\n=== 长期预期调整过程 ===")
pi_e = 2.0
for t in range(6):
    pi = pi_e - beta*(3 - un)
    print(f"第{t}期：π^e = {pi_e:.1f}%, π = {pi:.1f}%")
    pi_e = pi  # 工人下期预期 = 上期实际通胀

# 输出：
# u = 3%, π = 3.0%
# u = 7%, π = 1.0%
#
# === 长期预期调整过程 ===
# 第0期：π^e = 2.0%, π = 3.0%
# 第1期：π^e = 3.0%, π = 4.0%
# 第2期：π^e = 4.0%, π = 5.0%
# 第3期：π^e = 5.0%, π = 6.0%
# ...
```

## 五、什么时候能用？（前提条件）

- 短期菲利普斯曲线向下倾斜，假设**预期通胀不变**（工人没反应过来）。
- 长期垂直，假设**预期充分调整**。
- $\beta$ 是经验系数，不同国家、不同时期不一样。

---

## 六、什么时候不能用？（易错点）

1. **短期右下倾斜，长期垂直**——别搞混。短期能"骗工人"（货币幻觉），长期工人会调整预期。
2. **供给冲击会让短期菲利普斯曲线整体上移**：石油涨价，同样失业率下通胀更高——这就是 1970 年代滞胀。
3. **牺牲率**：把通胀降 1 个百分点，要牺牲多少 GDP 增长。一般估计为 4-5%（美国 1980 年代沃尔克反通胀，失业率冲到 10%）。
4. **NAIRU**：非加速通胀的失业率，就是自然失业率 $u_n$。

---

## 七、容易和什么搞混？

| | 短期菲利普斯曲线 | 长期菲利普斯曲线 |
|---|---|---|
| 形状 | 向右下倾斜 | 垂直 |
| 失业和通胀 | 有替代关系 | 无替代关系 |
| 预期 | 给定 $\pi^e$ | $\pi^e = \pi$ |
| 政策含义 | 短期能选菜单 | 长期只能调预期 |

---

## 八、在论文里怎么用？

**1. 菲利普斯曲线是宏观实证论文的经典方程**。论文题目举例：

- 《中国菲利普斯曲线的扁平化——基于省级面板数据》——跑 $\pi_{it} = a + b \cdot u_{it} + c \cdot \pi_{t-1} + \varepsilon_{it}$，看 b 绝对值是不是变小了；
- 《通胀预期对中国货币政策的影响》——被解释变量是实际通胀，核心解释变量是居民通胀预期调查；
- 《油价冲击对中国菲利普斯曲线的移动效应》——加油价虚拟变量。

**2. 论文里怎么估计？**

跑回归：

$$\pi_t = a + b \cdot u_t + c \cdot \pi_{t-1} + d \cdot \text{oil}_t + \varepsilon_t$$

- $b < 0$ 显著 → 失业和通胀短期替代；
- $c \approx 1$ → 通胀有持续性（惯性）；
- $d > 0$ → 油价是供给冲击。

**3. 常见踩坑**：

- **中国数据里菲利普斯曲线很平甚至不显著**——因为价格管制、国企工资刚性、统计口径问题。论文里要解释为什么，不要硬套美国参数。
- **做"通缩"论文时**，菲利普斯曲线告诉我们：低通胀 + 高失业 = 经济衰退（AD 左移），要扩需求。
- **别把"短期替代"当"长期政策菜单"**——长期里工人会调整预期，政府不能靠印钱永远把失业压在自然率以下。


**📊 对应统计方法**：

- [[../09_时间序列/07_协整与误差修正ECM|协整ECM]] —— 通胀与失业（或产出缺口）的长期替代关系用协整检验，短期权衡用 ECM 动态调整。
- [[../03_相关与回归/02_什么是回归|回归分析]] —— 菲利普斯曲线本身就是通胀率对失业率的回归，斜率即替代弹性。

---

## 九、现实意义

- **1960 年代美国**：按菲利普斯曲线"选菜单"——要 3% 失业就接受 5% 通胀。结果 1970 年代预期通胀失控，曲线右移，滞胀。
- **1980 年代沃尔克**：美联储主席，加息到 20%，把通胀从 13% 打到 4%，失业率冲到 10%——这就是牺牲率的代价。
- **中国 2022-2024 年**：CPI 长期在 0% 附近，但青年失业率 20%+——菲利普斯曲线异常平坦，因为需求不足 + 预期转弱。

---

## 十、速记卡

> **短期：通胀和失业跷跷板（π = π^e − β(u − u_n)）。**
> **长期：垂直于自然失业率 u_n，没有替代关系。**
> 供给冲击让短期曲线上移（滞胀）；预期调整让曲线移动。
> 政府不能长期靠印钱换低失业——长期工人会反应过来。
