# 01 GDP 与国民收入核算是什么？（小白版）

## 一、为什么要学这个？

你打开新闻："2024 年中国 GDP 增长 5%""重庆市 GDP 突破 3 万亿""美国 GDP 衰退"——这些词每天都在出现。**本科毕业论文做实证，十个题目有八个绕不开 GDP**：

- 做"财政支出对经济增长的影响"——被解释变量就是 GDP 增速；
- 做"老龄化对消费的影响"——要拿居民消费占 GDP 比重；
- 做"数字经济发展对全要素生产率的影响"——控制变量里有人均 GDP。

**不学会会怎样？** 你会把 GDP 和 GNP 搞混、把二手交易算进 GDP、把买股票算成投资，导师一眼就看出来你宏观没入门。更要命的是，你连自己论文里那个核心变量"GDP 增速"到底是什么都讲不清。

---

## 二、是什么？

### 生活比喻：GDP 就是全国一年的"家庭流水账"

想象你家小区只做三件事：张三家烤面包、李四家织布、王五家开理发店。年底把这三家今年新做出来的面包、布、头发服务，按市价加总——就是小区 GDP。

**关键直觉**：一块面包面粉成本 3 块，面包店卖 10 块。GDP 只算最终那 10 块，**不能**把 3 块面粉 + 10 块面包 = 13 块重复算。这就是"最终产品"四个字的意思。

### 严格定义

> **国内生产总值（GDP）**：一定时期内（通常一年或一季度），在一国（或地区）**境内**生产的所有**最终产品与服务**的**市场价值**总和。

四个关键词一个都不能少：

| 关键词 | 含义 | 反例 |
|---|---|---|
| 市场价值 | 用货币加总，不然苹果和橘子没法加 | 你在家自己给自己做的饭不算 |
| 最终产品 | 直接卖给消费者的，不是当原料的 | 面包店买的面粉不算 GDP |
| 境内 | 按地盘算，不按国籍算 | 苹果公司在上海造的手机算中国 GDP |
| 一定时期 | 流量（一年新生产的），不是存量 | 你去年买的二手车今年转手不算今年 GDP |

### 符号表

| 符号 | 怎么读 | 是什么 | 生活类比 |
|---|---|---|---|
| $Y$ | "y" | GDP（国民收入） | 小区一年总流水 |
| $C$ | "c" | 居民消费 | 你买奶茶、看电影 |
| $I$ | "i" | 企业投资 | 建厂房、买设备、盖住宅 |
| $G$ | "g" | 政府购买 | 修高铁、发公务员工资 |
| $X$ | "x" | 出口 | 卖给老外 |
| $M$ | "m" | 进口 | 从老外那买 |
| $NX = X-M$ | "净 X" | 净出口 | 出口减进口 |

## 三、公式怎么来的？（手把手推）

宏观经济里有个"循环流程图"的直觉：企业生产东西卖出去收到钱（支出），这笔钱又以工资、利息、租金、利润的形式发给家庭（收入），家庭再拿去买东西（支出）。

**买者花出去的每一分钱，都是卖者收到的收入。** 所以：

$$\text{产出} = \text{支出} = \text{收入}$$

支出法把全国所有人的购买加起来，按买家身份分成四块：家庭买的、企业买的、政府买的、老外买的（净出口）。

$$Y = C + I + G + NX$$

**大白话翻译**：整个国家一年新生产的东西，最后被这四类人买走了。

**新手最容易搞错的四个点**：

1. **投资 $I$ 不是你炒股**。宏观里的"投资"只指买实物资本（厂房、设备、住宅、存货）。你买股票只是把钱从左口袋换到右口袋，没有新生产东西，不算 GDP。
2. **政府转移支付不算 $G$**。政府发养老金、低保，只是把钱从纳税人手里转到老人手里，没换任何产品服务，所以不计入 GDP。
3. **进口要减掉**。因为你买的耐克鞋是进口的，这笔钱已经算在 $C$ 里了，但它不是中国生产的，所以要减掉 $M$。
4. **住宅不管谁买都算投资 $I$**——这是唯一例外。你自己买的自住婚房，在宏观里也算"住宅投资"。

## 四、一个完整的数字例子

**题目**：某小国某年数据如下（单位：亿元），用支出法算 GDP。

| 项目 | 金额 |
|---|---|
| 居民消费（奶茶、外卖、电影） | 600 |
| 企业建厂房买设备 | 150 |
| 企业存货增加 | 20 |
| 政府公务员工资 | 100 |
| 政府发养老金（转移支付） | 30 |
| 出口 | 80 |
| 进口 | 50 |
| 居民买二手车（去年造的） | 10 |

**第一步：挑出计入的项目**

- $C = 600$（居民消费，全算）
- $I = 150 + 20 = 170$（厂房设备 + 存货增加；二手车是去年造的，不计）
- $G = 100$（公务员工资是政府购买服务；养老金是转移支付，不计）
- $NX = 80 - 50 = 30$

**第二步：代入公式**

$$Y = C + I + G + NX = 600 + 170 + 100 + 30 = \mathbf{900 \text{ 亿元}}$$

**用 Python 验证**：

```python
# 支出法算 GDP
C = 600          # 居民消费
I = 150 + 20     # 厂房设备 + 存货
G = 100          # 政府购买（公务员工资）
X, M = 80, 50    # 出口、进口

Y = C + I + G + (X - M)
print(f"GDP = C+I+G+NX = {C}+{I}+{G}+({X}-{M}) = {Y} 亿元")
# 输出：GDP = C+I+G+NX = 600+170+100+30 = 900 亿元
```

**解读**：这个国家一年新生产了 900 亿元的产品和服务。养老金 30 和二手车 10 都没算进去——一个是转移支付，一个是去年造的。

## 五、什么时候能用？（前提条件）

- 核算对象是**市场交易**产生的价值。自给自足、地下经济不计。
- 支出法要求能把所有购买按 C、I、G、NX 四类准确归类。
- 短期季度 GDP 和年度 GDP 口径一致，才能比增速。

---

## 六、什么时候不能用？（易错点）

1. **GDP ≠ GNP**：GDP 按"地盘"算，GNP 按"国籍"算。苹果公司在上海工厂利润算中国 GDP、美国 GNP。
2. **二手车、二手房、股票债券都不计入当期 GDP**——它们只是产权转移，没有新生产。
3. **自己在家带孩子、自己做饭不计入 GDP**，但请保姆、下馆子就计入——这叫"市场性"原则。
4. **GDP 不等于幸福感**：它不反映收入分配（贫富差距）、不反映家务劳动、不反映环境代价（污染了但 GDP 照样涨）。

---

## 七、容易和什么搞混？

| 概念 | 一句话 | 区别 |
|---|---|---|
| GDP | 地盘上一年新生产的 | 按地域 |
| GNP/GNI | 国籍人一年新生产的 | 按国籍 |
| 名义 GDP | 当年价格算 | 价格和数量都在变 |
| 实际 GDP | 基年价格算 | 只看数量变没变 |
| 居民买股票 | 金融交易 | 不算 I，只是钱换口袋 |

---

## 八、在论文里怎么用？

这一段是本科实证论文最常踩的坑，写细一点。

**1. GDP 是论文里最常见的被解释变量**。本科论文题目举例：

- 《重庆市财政支出对经济增长的影响研究》——被解释变量 $Y$ = 重庆市实际 GDP 增速；
- 《数字经济发展对中国全要素生产率的影响》——被解释变量是 TFP，但控制变量里必有滞后一期人均 GDP；
- 《老龄化、储蓄率与经济增长》——被解释变量是 GDP 增速，核心解释变量是老年抚养比。

**2. 论文里 GDP 变量怎么取？三个坑**：

- **一定要用实际 GDP**（剔除通胀），不能用名义 GDP。不然你回归出来的"增长效应"可能只是通胀效应。数据从国家统计局或 Wind 拿，已经用 GDP 平减指数折算了。
- **要取对数**：$\ln(GDP_t)$。因为 GDP 跨城市跨年份跨度大（几亿到几万亿），取对数让它线性化，系数解释成弹性。
- **增速用 $\ln(GDP_t) - \ln(GDP_{t-1})$**，比简单的 $(GDP_t - GDP_{t-1})/GDP_{t-1}$ 更接近对数增长率。

**3. 解释变量里出现 C、I、G、NX**：做"三驾马车"类论文（消费、投资、出口谁拉动增长），你直接用这四个分项占 GDP 比重作为解释变量。

**4. 常见踩坑**：

- 把"地方一般公共预算支出"直接当 $G$，但 $G$ 在国民核算里是政府购买，不包括转移支付和债务付息。严格做研究要从统计局"支出法 GDP"分项拿，不能直接拿财政支出总额。
- 做城市级论文时，很多城市不公布支出法 GDP 的 I、G 分项，只能拿到总量——这时要在论文里说明数据局限。

---

## 九、现实意义

- **新闻里说"GDP 增长 5%"是什么意思**：已经扣掉通胀，是实际 GDP 增长 5%。政府定经济目标、央行定利率、企业定工资涨幅，都看这个。
- **"三驾马车"**：消费、投资、净出口。中国过去靠投资和出口，现在要转向消费——这就是为什么要发消费券。
- **绿色 GDP**：越来越多人呼吁把污染、资源消耗扣掉，因为 GDP 高不代表百姓真的过得好。

---

## 十、速记卡

> **GDP = 地盘上一年新生产的最终产品服务的市场价。**
> 支出法公式：$Y = C + I + G + NX$，四块钱谁花的对应谁。
> 股票不算投资、转移支付不算 $G$、二手车二手房不算当年 GDP。
> 论文里用**实际 GDP 的对数**当被解释变量，别拿名义 GDP。
