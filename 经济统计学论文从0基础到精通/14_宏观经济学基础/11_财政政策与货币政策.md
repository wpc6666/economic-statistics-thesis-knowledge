# 11 财政政策与货币政策是什么？（小白版）

## 一、为什么要学这个？

经济差了谁来救？两个主角：
- **财政部**（和地方政府）：通过"花钱和收税"调节经济——财政政策。
- **央行**：通过"印钱和调利率"调节经济——货币政策。

**写论文的时候**：

- 做"政策效果评估"论文，核心就是估计财政支出乘数或货币政策传导；
- 做"政策组合"论文，要分析扩财政 + 紧货币等搭配；
- 做"地方政府债务"论文，本质是财政政策可持续性。

**不学会会怎样？** 你会把降准和降息搞混，会以为央行直接印钱给老百姓花，会不知道"自动稳定器"是什么。

---

## 二、是什么？

### 生活比喻：两个医生给经济看病

| | 财政政策（财政部） | 货币政策（央行） |
|---|---|---|
| 工具 | 花钱、收税、转移支付 | 调利率、降准、公开市场操作 |
| 见效速度 | 慢（要走人大审批、项目招标） | 快（央行开会就决定） |
| 瞄准精度 | 高（定向给特定人群/地区） | 低（大水漫灌） |
| 时滞 | 决策时滞长 | 效果时滞长 |
| 衰退时 | **更有效**（LM 水平，无挤出） | 失效（流动性陷阱） |
| 过热时 | 挤出私人投资 | **更有效** |

### 财政政策三大工具

| 工具 | 扩张性（经济差时） | 紧缩性（过热时） |
|---|---|---|
| **政府购买 G** | 搞基建、雇公务员 | 减少支出 |
| **税收 T** | 减税 | 加税 |
| **转移支付 Tr** | 多发养老金、失业救济 | 减少发放 |

### 自动稳定器（不用政府决定）

经济一波动，下面这些东西自动反向调节：

| 自动稳定器 | 衰退时 | 过热时 |
|---|---|---|
| 累进所得税 | 收入下降自动降档，税负减轻 | 收入上升自动升档，税负加重 |
| 失业救济 | 失业多救济自动增加 | 失业少救济自动减少 |
| 农产品价格补贴 | 粮价跌补贴自动增加 | 粮价涨补贴自动减少 |

### 货币政策三大工具

| 工具 | 操作 | 效果 |
|---|---|---|
| **公开市场业务** | 央行买债券 → 向银行体系注入货币 | 扩张 |
| **法定准备金率 $r_r$** | 降准 → 银行可贷资金增加 | 扩张 |
| **再贴现率** | 降息 → 银行借央行钱更便宜 | 扩张 |

**货币乘数**：央行放的基础货币 $B$，通过银行放贷"创造"出更多货币 $M$：

$$M = m \times B, \quad m = \frac{1 + c}{c + r_r}$$

- $c$：现金漏损率（老百姓留多少现金不存银行）；
- $r_r$：法定准备金率。

---

## 三、公式怎么来的？（手把手推货币乘数）

**为什么降准能放水？**

假设老百姓不留现金（$c=0$），法定准备金率 $r_r = 10\%$。央行放 1000 亿基础货币给银行 A：

- 银行 A 留下 100 亿准备金，把 900 亿贷给企业甲；
- 企业甲把 900 亿存进银行 B（假设）；
- 银行 B 留下 90 亿准备金，把 810 亿贷给企业乙；
- 企业乙存进银行 C，银行 C 贷出 729 亿……

总存款创造：

$$1000 + 900 + 810 + 729 + \cdots = \frac{1000}{0.1} = 10000 \text{ 亿}$$

乘数 = $1/r_r = 1/0.1 = 10$。

**加现金漏损 c 后**：每一轮企业贷款，老百姓都留一部分现金不存银行，下一轮可贷资金变少，乘数变小：

$$m = \frac{1 + c}{c + r_r}$$

## 四、一个完整的数字例子 + Python 验证

**题目**：已知现金漏损率 $c = 0.2$，法定准备金率 $r_r = 0.1$，央行投放基础货币 $B = 1000$ 亿。

**第一步：算货币乘数**

$$m = \frac{1 + 0.2}{0.2 + 0.1} = \frac{1.2}{0.3} = 4$$

**第二步：算货币供给**

$$M = m \times B = 4 \times 1000 = 4000 \text{ 亿}$$

**第三步：如果央行降准到 $r_r = 0.05$**

$$m = \frac{1.2}{0.2 + 0.05} = \frac{1.2}{0.25} = 4.8$$

$$M = 4.8 \times 1000 = 4800 \text{ 亿}$$

降准 0.05，货币供给多了 800 亿——这就是为什么每次降准股市都兴奋。

```python
c = 0.2
B = 1000

for rr in [0.10, 0.05]:
    m = (1 + c) / (c + rr)
    M = m * B
    print(f"rr = {rr:.2f}: 货币乘数 m = {m:.2f}, 货币供给 M = {M:.0f} 亿")

# 输出：
# rr = 0.10: 货币乘数 m = 4.00, 货币供给 M = 4000.0 亿
# rr = 0.05: 货币乘数 m = 4.80, 货币供给 M = 4800.0 亿
```

## 五、什么时候能用？（前提条件）

- 财政政策见效，要有闲置资源（不然只会涨价）。
- 货币政策见效，要银行愿意放贷、企业愿意借钱（不然流动性陷阱）。
- 自动稳定器力度有限，不能完全消除波动。

---

## 六、什么时候不能用？（易错点）

1. **央行不能直接控制货币供给**：它只能控制基础货币，货币乘数受银行和公众行为影响。2008 年后美国银行存了大量超额准备金，乘数从 8 跌到 3。
2. **政策时滞**：认识时滞、决策时滞、执行时滞、效果时滞——等政策落地，经济可能已经自己反转了。
3. **李嘉图等价**：政府借钱搞扩张，老百姓知道将来要加税还，现在多存钱——财政政策无效。但现实里月光族多，不完全成立。
4. **流动性陷阱里货币政策失效**：利率已经到底，再降也没用。

---

## 七、容易和什么搞混？

| | 财政政策 | 货币政策 |
|---|---|---|
| 谁操作 | 财政部/地方政府 | 央行 |
| 工具 | 政府购买、税收、转移支付 | 利率、准备金率、公开市场 |
| 影响什么 | IS 曲线移动 | LM 曲线移动 |
| 衰退时 | 更有效 | 可能失效 |
| 主要时滞 | 决策时滞 | 效果时滞 |

## 八、在论文里怎么用？

**1. 政策评估是宏观实证论文的最大类**。论文题目举例：

- 《中国财政支出乘数的估计——基于省级面板》——被解释变量是 GDP 增速，核心解释变量是财政支出增速；
- 《货币政策利率传导效应——基于 TVP-VAR》——看政策利率冲击对产出和通胀的时变脉冲响应；
- 《房地产限购政策的效果评估——DID 方法》——处理组是限购城市，对照组是没限购的；
- 《结构性货币政策工具（如 MLF、再贷款）对小微企业融资的影响》——定向货币政策。

**2. 论文里常见变量设计**：

- 财政政策：地方一般公共预算支出、税收收入、转移支付；
- 货币政策：7 天逆回购利率、MLF 利率、法定准备金率、M2 增速、社融规模；
- 政策虚拟变量：某政策试点城市 = 1，其他 = 0（DID）。

**3. 常见踩坑**：

- **不要把"财政支出"直接当 $G$**：财政支出包括转移支付和债务付息，不完全是政府购买。严格做要从支出法 GDP 拿。
- **货币政策内生性**：央行看到经济差才降息，所以"降息和 GDP 下降同时出现"不代表降息导致衰退。要用工具变量或 VAR。
- **中国是"双支柱"调控**：货币政策 + 宏观审慎（房地产、地方债）——论文里要提到，不能只写传统货币政策。


**📊 对应统计方法**：

- [[../05_内生性与面板/03_工具变量IV|工具变量IV]] —— 政策内生性强（政策会反向响应经济），用工具变量或准自然实验识别政策因果效应。
- [[../05_内生性与面板/05_面板数据是什么|面板数据]] —— 财政/货币政策效果评估常用省级面板，结合 FE 或 DID 识别政策冲击。

## 九、现实意义

- **2008 年"四万亿"**：财政政策（基建）+ 货币政策（降准降息）双扩张，GDP 增速从 6% 拉回 9%。
- **2020 年疫情**：美国直接给每个人发 1200 美元支票（转移支付）；中国搞"新基建"（政府购买）。两种工具各有优劣：发钱快但可能通胀，搞基建慢但形成长期产能。
- **2022-2024 年中国**：央行多次降准降息，但地方债压力大，财政政策受限——政策效果打折扣。

---

## 十、速记卡

> **财政政策：政府花钱收税，移 IS 曲线，衰退时更有效。**
> **货币政策：央行调利率放货币，移 LM 曲线，过热时更有效。**
> 货币乘数 $m = (1+c)/(c+r_r)$：降准就是提乘数。
> 衰退时财政管用，过热时货币管用；流动性陷阱里货币失效。
