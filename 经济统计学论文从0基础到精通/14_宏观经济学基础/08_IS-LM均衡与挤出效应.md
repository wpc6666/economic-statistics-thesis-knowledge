# 08 IS-LM 均衡与挤出效应是什么？（小白版，重点篇）

## 一、为什么要学这个？

IS 曲线讲产品市场，LM 曲线讲货币市场。**两条线的交点**就是两个市场同时均衡的点——这个点决定了整个经济的均衡利率 $r^*$ 和均衡收入 $Y^*$。

**这是宏观经济学最核心的一张图**。写论文的时候：

- 做"财政政策 vs 货币政策哪个更有效"论文，全靠 IS-LM；
- 做"四万亿挤出了多少私人投资"论文，要量化挤出效应；
- 做"政策组合"论文（扩财政 + 紧货币），要分析对利率和产出的影响。

**不学会会怎样？** 你会以为政府花钱 GDP 就按乘数涨，不知道利率会上升、私人投资会被挤掉一大块。

---

## 二、是什么？

### 生活比喻：两个十字路口的红绿灯要一起调

产品市场（IS）和货币市场（LM）像两个相邻十字路口。IS 说"产品市场均衡时利率和收入该怎么配对"，LM 说"货币市场均衡时利率和收入该怎么配对"。**两个市场同时均衡**，就是两个红绿灯都变绿——找它们的交点。

### 严格定义

联立 IS 和 LM 两个方程：

$$\text{IS: } Y = \frac{\alpha + e - dr}{1-\beta}$$

$$\text{LM: } Y = \frac{M/P}{k} + \frac{h}{k} r$$

两个方程两个未知数（$Y, r$），解出来就是共同均衡 $(Y^*, r^*)$。

### 什么是挤出效应？

> **挤出效应**：政府购买增加 → IS 右移 → 新交点 $r$ 上升 → 私人投资 $I = e - dr$ 下降 → 抵消一部分财政扩张效果。

**大白话**：政府借钱搞投资，把利率抬上去了，私人企业本来想贷款投资的，现在觉得贵就不投了——**政府花的钱把私人企业的投资挤掉了**。

---

## 三、公式怎么来的？（手把手推）

**第一步：初始均衡**

已知：
- IS：$Y = 1500 - 250r$
- LM：$Y = 500 + 250r$

联立：IS = LM：

$$1500 - 250r = 500 + 250r$$

**这一步为什么能联立？** 因为均衡点两个市场同时出清，所以同一个 $Y$ 和 $r$ 要同时满足 IS 和 LM。

**第二步：解 r**

把含 r 的项移到右边，常数移到左边：

$$1500 - 500 = 250r + 250r$$

$$1000 = 500r$$

两边除以 500：

$$r^* = 2$$

**第三步：代入求 Y**

$$Y^* = 1500 - 250 \times 2 = 1500 - 500 = 1000$$

验证 LM：$Y = 500 + 250 \times 2 = 1000$ ✓

均衡利率 2%，均衡收入 1000。

**第四步：政府购买增加，IS 右移到 $Y = 2000 - 250r$**

（IS 右移 500，对应 $\Delta G = 100$，因为乘数 $k_G = 5$，无挤出时 $\Delta Y = 500$。）

联立新 IS：

$$2000 - 250r = 500 + 250r$$

$$1500 = 500r$$

$$r = 3$$

$$Y = 500 + 250 \times 3 = 1250$$

**第五步：算挤出了多少**

- 无挤出时（利率不变），$Y$ 应该从 1000 涨到 1500（+500）。
- 实际只涨到 1250（+250）。
- **被挤出的部分 = 1500 - 1250 = 250**。

**为什么会被挤出？** 政府借钱 → 货币需求增加 → 利率从 2% 升到 3% → 私人投资 $I = e - dr$ 减少 $d \times \Delta r = 50 \times 1 = 50$，经过乘数 5，总产出减少 250。

## 四、一个完整的数字例子 + Python 验证

**题目**：已知 $C = 100 + 0.8Y_d$，$I = 200 - 10r$，$G = 100$，$T = 50$，$L = 0.5Y - 20r$，$M/P = 500$。

**第一步：推 IS**

均衡条件 $Y = C + I + G$，代入：

$$Y = 100 + 0.8(Y - 50) + 200 - 10r + 100$$

展开：

$$Y = 100 + 0.8Y - 40 + 200 - 10r + 100$$

合并常数：

$$Y = 360 + 0.8Y - 10r$$

把 $0.8Y$ 移到左边：

$$Y - 0.8Y = 360 - 10r$$

$$0.2Y = 360 - 10r$$

两边除以 0.2：

$$Y = 1800 - 50r$$

**第二步：推 LM**

货币市场均衡 $L = M/P$：

$$0.5Y - 20r = 500$$

$$0.5Y = 500 + 20r$$

$$Y = 1000 + 40r$$

**第三步：初始均衡**

$$1800 - 50r = 1000 + 40r$$

$$800 = 90r$$

$$r = 8.89$$

$$Y = 1000 + 40 \times 8.89 = 1355.6$$

**第四步：政府购买增加到 G=200（ΔG=100）**

新 IS：$Y = 100 + 0.8(Y-50) + 200 - 10r + 200 = 1900 - 50r$

$$1900 - 50r = 1000 + 40r$$

$$900 = 90r$$

$$r = 10$$

$$Y = 1000 + 40 \times 10 = 1400$$

**第五步：算挤出**

- $Y$ 实际增加 = $1400 - 1355.6 = 44.4$。
- 无挤出时（r 不变）：$k_G = 1/(1-0.8) = 5$，$\Delta Y$ 应该 = $5 \times 100 = 500$。
- **被挤掉的 = 500 - 44.4 = 455.6**——91% 都被挤掉了！

```python
import sympy as sp

# 定义变量
Y, r = sp.symbols('Y r')

# 初始 IS 和 LM（G=100）
IS1 = sp.Eq(Y, 100 + 0.8*(Y-50) + 200 - 10*r + 100)
LM = sp.Eq(0.5*Y - 20*r, 500)

sol1 = sp.solve((IS1, LM), (Y, r))
print(f"初始均衡（G=100）：Y = {sol1[Y]:.2f}, r = {sol1[r]:.2f}")

# G 增加到 200
IS2 = sp.Eq(Y, 100 + 0.8*(Y-50) + 200 - 10*r + 200)
sol2 = sp.solve((IS2, LM), (Y, r))
print(f"新均衡（G=200）：Y = {sol2[Y]:.2f}, r = {sol2[r]:.2f}")

deltaY_actual = sol2[Y] - sol1[Y]
deltaY_nocrowd = 5 * 100  # k_G = 5, ΔG = 100
crowded = deltaY_nocrowd - deltaY_actual
print(f"\nΔY 实际 = {deltaY_actual:.2f}")
print(f"ΔY 无挤出（理论）= {deltaY_nocrowd}")
print(f"被挤出 = {crowded:.2f}")
print(f"挤出比例 = {crowded/deltaY_nocrowd*100:.1f}%")

# 输出：
# 初始均衡（G=100）：Y = 1355.56, r = 8.89
# 新均衡（G=200）：Y = 1400.00, r = 10.00
#
# ΔY 实际 = 44.44
# ΔY 无挤出（理论）= 500
# 被挤出 = 455.56
# 挤出比例 = 91.1%
```

## 五、什么时候能用？（前提条件）

- 短期模型：价格 P 不变。
- IS 向右下倾斜、LM 向右上倾斜——两个市场都要在中间区域。
- 政府购买通过发债融资（不是印钱），才会挤出私人投资。

---

## 六、什么时候不能用？（易错点）

1. **流动性陷阱里挤出 = 0**：LM 水平，IS 右移 r 不变，私人投资不被挤——财政政策完全有效。
2. **古典区域里挤出 = 100%**：LM 垂直，IS 右移只推高 r，Y 不变——财政政策完全无效。
3. **IS-LM 交点是短期均衡**，不一定是充分就业均衡。如果 $Y^* < Y_f$，经济萧条，需要扩张政策。
4. **IS-LM 是短期模型**，价格不变；引入价格就变成 AD-AS 模型。

---

## 七、容易和什么搞混？

| 概念 | 一句话 |
|---|---|
| IS-LM 均衡 | 两个市场同时出清的 (Y, r) |
| 挤出效应 | 政府花钱推高利率，挤掉私人投资 |
| 流动性陷阱 | LM 水平，货币政策失效 |
| 古典极端 | LM 垂直，财政政策失效 |

**政策效果速查表**：

| 经济状况 | 财政政策 | 货币政策 |
|---|---|---|
| 衰退（凯恩斯区域） | **完全有效** | 无效 |
| 中间区域 | 有效但有挤出 | 有效但不完全 |
| 过热（古典区域） | 完全无效 | **完全有效** |

## 八、在论文里怎么用？

**1. IS-LM 是宏观政策分析的理论骨架**。论文题目举例：

- 《中国地方政府债务扩张对私人投资的挤出效应》——被解释变量是民间投资增速，核心解释变量是地方政府债务增速，预期系数为负；
- 《货币政策与财政政策协调配合——基于 IS-LM 的实证》——用 VAR 看财政支出冲击和货币冲击对 GDP、利率的脉冲响应；
- 《流动性陷阱下的中国货币政策有效性》——解释为什么降息效果递减。

**2. 论文里怎么估计挤出效应？**

跑回归：

$$I_{it} = a + b \cdot G_{it} + c \cdot r_{it} + \text{控制变量} + \varepsilon_{it}$$

- $b < 0$ 且显著 → 政府支出挤出私人投资；
- $b$ 绝对值越大，挤出越严重。
- 中国实证估计：2008-2015 年挤出不明显（有闲置产能），2015 年后挤出变大（基建饱和）。

**3. 常见踩坑**：

- **不要把"政府投资增加 → GDP 增加"直接说成"乘数效应"**：要控制利率，看挤出有多大。
- **做"政策组合"论文时要分象限讨论**：扩财政+扩货币（严重衰退）、扩财政+紧货币（防泡沫）、紧财政+扩货币（降利率促投资）、双紧（压通胀）。
- **中国的利率还没完全市场化**，IS-LM 直接套要打折——论文里要说明这个制度背景。


**📊 对应统计方法**：

- [[../05_内生性与面板/06_固定效应FE|面板FE]] —— 用跨国/跨省面板估计财政支出对私人投资的挤出效应，控制个体 FE 剔除遗漏变量。

## 九、现实意义

- **2008 年中国"四万亿"**：IS 右移，同时央行降息（LM 也右移）——双管齐下，Y 大涨，r 没涨，挤出很小。因为当时全球金融危机，有大量闲置产能。
- **2015 年中国经济下行**：央行多次降息（LM 右移），但财政没大动作，效果有限——因为企业预期差，IS 曲线本身在左移。
- **2020 年疫情后美国**：财政发钱（IS 右移）+ QE（LM 右移），双扩张，Y 快速恢复，但 2022 年通胀冲到 9%——长期里 AD 过度右移的代价。

---

## 十、速记卡

> **IS-LM 交点 = 产品市场和货币市场同时均衡的 (Y*, r*)。**
> 政府花钱 → IS 右移 → Y 升、r 升 → 私人投资被挤掉一部分。
> 挤出大小看 LM 斜率：LM 越陡挤出越多，LM 水平无挤出。
> 衰退时财政政策管用，过热时货币政策管用。
